###### Abstract

Neural Architecture Search (NAS) deployment in industrial production
systems faces a fundamental validation bottleneck: verifying a single
candidate architecture $`\pi`$ requires evaluating the deployed ensemble
of $`M`$ models, incurring prohibitive $`O(M)`$ computational cost per
candidate. This cost barrier severely limits architecture iteration
frequency in real-world applications where ensembles ($`M=50`$–$`200`$)
are standard for robustness.

This work introduces Ensemble-Decoupled Architecture Search, a framework
that leverages ensemble theory to predict system-level performance from
single-learner evaluation. We establish the Ensemble-Decoupled Theory
with a sufficient condition for monotonic ensemble improvement under
homogeneity assumptions: a candidate architecture $`\pi`$ yields lower
ensemble error than the current baseline if

|     |     |     |
| --- | --- | --- |
|     |

````math
\rho(\pi)<\rho(\pi_{\text{old}})-\frac{M}{M-1}\cdot\frac{\Delta E(\pi)}{\sigma^{2}(\pi)},
``` |  |

where $`\Delta E`$, $`\rho`$, and $`\sigma^{2}`$ are estimable from
lightweight dual-learner training. This decouples architecture search
from full ensemble training, reducing per-candidate search cost from
$`O(M)`$ to $`O(1)`$ while maintaining $`O(M)`$ deployment cost only for
validated winners.

We unify solution strategies across pipeline continuity: (1) closed-form
optimization for tractable continuous $`\pi`$ (exemplified by feature
bagging in CTR prediction), (2) constrained differentiable optimization
for intractable continuous $`\pi`$, and (3) LLM-driven search with
iterative monotonic acceptance for discrete $`\pi`$. The framework
reveals two orthogonal improvement mechanisms—base diversity gain and
accuracy gain—providing actionable design principles for
industrial-scale NAS. All theoretical derivations are rigorous with
detailed proofs deferred to the appendix. Comprehensive empirical
validation will be included in the journal extension of this work.

## 1 Introduction

Neural Architecture Search (NAS) aims to identify optimal architectures
$`\pi^{*}=\arg\min_{\pi\in\mathcal{A}}\mathbb{E}_{(x,y)\sim\mathcal{D}_{\text{val}}}[\ell(f_{\pi}(x),y)]`$
for target tasks. In industrial recommender systems, ensemble-based
deployment—where $`M`$ independent models form a prediction ensemble—is
standard practice for robustness and accuracy. However, this introduces
a critical bottleneck for architecture iteration: validating a single
candidate architecture $`\pi`$ traditionally requires training and
evaluating all $`M`$ ensemble members, incurring prohibitive cost
$`C_{\text{traditional}}=N_{\text{trials}}\times M\times C_{\text{learner}}`$.
For production systems with $`M\in[50,200]`$, this cost barrier severely
limits architecture exploration frequency.

Existing cost-reduction strategies suffer fundamental limitations:

- •
  Proxy metrics (e.g., Zico [Abdelfattah et al. (2021)](#bib.bib1)):
  Exhibit fidelity gaps in complex CTR tasks where gradient-based
  proxies fail to correlate with final ensemble performance.
- •
  Parameter sharing (e.g., ENAS [Pham et al. (2018)](#bib.bib12)):
  Induces weight coupling artifacts and restricts search space to
  subgraphs of a super-network, compromising architecture
  expressiveness.
- •
  Early stopping: Risks premature rejection of high-potential
  architectures with slow convergence trajectories.

This work introduces Ensemble-Decoupled Architecture Search, a framework
that leverages ensemble theory to predict system-level performance from
constant-cost evaluation. Rather than training full ensembles for every
candidate, we use a small constant number of proxy learners (e.g., 2–3
independent instances) to determine whether an architecture $`\pi`$
warrants full ensemble deployment. Consider a current ensemble
$`\mathcal{E}^{(t)}`$ built from architecture $`\pi_{\text{old}}`$. When
evaluating candidate $`\pi`$, we determine whether deploying a new
ensemble $`\mathcal{E}^{(t+1)}`$ with $`M`$ independent instances of
$`\pi`$ would reduce system error without training the full
$`\mathcal{E}^{(t+1)}`$ during search.

Our key insight leverages ensemble theory under homogeneity assumptions:
when ensemble members are independent realizations of the same
architecture, the ensemble error depends only on three
architecture-level properties estimable from constant-cost training:

1.  1.
    $`\Delta E(\pi)=E(\pi)-E(\pi_{\text{old}})`$: Expected error change
    of new architecture relative to current baseline ($`\Delta E<0`$
    indicates improvement).
2.  2.
    $`\rho(\pi)`$: Expected correlation between independent instances of
    architecture $`\pi`$.
3.  3.
    $`\sigma^{2}(\pi)`$: Expected variance of architecture $`\pi`$
    predictions.

These quantities are estimable from training a small constant number of
independent instances of $`f_{\pi}`$ (typically 2–3 for correlation
estimation) combined with lightweight statistics from the existing
ensemble.

## 2 Related Work

Cost-Efficient NAS. Zero-cost proxies (Zico [Abdelfattah et al.
(2021)](#bib.bib1), TE-NAS [Chen et al. (2021)](#bib.bib5)) estimate
architecture quality without training but suffer fidelity degradation in
non-i.i.d. CTR data. Weight-sharing methods (ENAS [Pham et al.
(2018)](#bib.bib12), DARTS [Liu et al. (2018)](#bib.bib9)) reduce search
cost but introduce optimization bias [Zela et al. (2020)](#bib.bib14).
Our work fundamentally differs by providing theoretical guarantees for
validation cost reduction without proxy metrics or weight sharing.

Ensemble Theory Foundations. The bias-variance decomposition [Geman
et al. (1992)](#bib.bib7) and error-ambiguity decomposition [Krogh and
Vedelsby (1995)](#bib.bib8) form the bedrock of ensemble analysis. [Zhou
(2012)](#bib.bib15) formalized diversity quantification, while
[Mendes-Moreira et al. (2012)](#bib.bib11) surveyed ensemble methods in
recommender systems. Our framework extends these foundations by deriving
actionable conditions for monotonic improvement during dynamic ensemble
evolution—a previously unaddressed problem.

LLM/RL for NAS. Recent works leverage LLMs for architecture generation
(LLMatic [Liu et al. (2023)](#bib.bib10), ArchGPT [Wang et al.
(2023)](#bib.bib13)) and evolutionary operators. However, they lack
theoretical stopping criteria, leading to inefficient exploration. Our
monotonic condition provides a rigorous acceptance criterion for
LLM-proposed candidates, transforming heuristic search into
theoretically-grounded optimization.

Gap Analysis. No existing work establishes a theoretically guaranteed
bridge between single-learner properties and system-level improvement in
evolving ensembles. This paper fills this critical gap, providing the
first framework where validation cost scales independently of ensemble
size $`M`$.

## 3 Ensemble-Decoupled Architecture Search Framework

### 3.1 Problem Formulation: NAS as Generation-Based Ensemble Optimization

Consider an ensemble system $`\mathcal{E}=\{f_{1},\dots,f_{M}\}`$ where
each $`f_{i}:\mathcal{X}\to[0,1]`$ predicts CTR. The ensemble prediction
is $`\hat{y}_{\text{ens}}=\frac{1}{M}\sum_{i=1}^{M}f_{i}(x)`$. We assume
ensemble members are independent realizations of the same architecture
pipeline $`\pi`$, trained with different random seeds and data
orderings. This homogeneity assumption ensures that all members share
identical expected error, variance, and pairwise correlation statistics.

At search iteration $`t`$, we evaluate candidate architecture $`\pi`$
(yielding model $`f_{\pi}`$) to determine whether deploying a new
ensemble $`\mathcal{E}^{(new)}`$ with $`M`$ independent instances of
$`\pi`$ would improve over the current ensemble $`\mathcal{E}^{(old)}`$
built from $`\pi_{\text{old}}`$. The goal is to determine whether:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{E}[\ell(\hat{y}_{\text{ens}}^{(new)},y)]<\mathbb{E}[\ell(\hat{y}_{\text{ens}}^{(old)},y)]
``` |  | (1) |

without training the full ensemble $`\mathcal{E}^{(new)}`$ during the
search phase.

### 3.2 Unified Error Decomposition

Following standard ensemble theory [Krogh and Vedelsby
(1995)](#bib.bib8), the ensemble MSE decomposes via two equivalent
perspectives:

Bias-Variance Form:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{E}[(y-\hat{p}_{\text{ens}})^{2}]=p(1-p)+\text{Bias}^{2}+\frac{\sigma^{2}}{M}[1+(M-1)\rho]
``` |  | (2) |

Error-Ambiguity Form:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{E}[(y-\hat{p}_{\text{ens}})^{2}]=\underbrace{\frac{1}{M}\sum_{m=1}^{M}\mathbb{E}[(y-\hat{p}_{m})^{2}]}_{\text{Average single-model error}}-\underbrace{\frac{1}{M}\sum_{m=1}^{M}\mathbb{E}[(\hat{p}_{m}-\hat{p}_{\text{ens}})^{2}]}_{\bar{D}\text{ (Average Ambiguity = Diversity)}}
``` |  | (3) |

where $`\bar{D}`$ quantifies pairwise disagreement among base learners.
Under the homogeneity assumption (all members share architecture
$`\pi`$),
Equation ([3](#S3.E3 "In 3.2 Unified Error Decomposition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))
simplifies to:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{E}[(y-\hat{p}_{\text{ens}})^{2}]=E(\pi)-\sigma^{2}(\pi)\cdot\frac{M-1}{M}(1-\rho(\pi))
``` |  | (4) |

where $`E(\pi)`$, $`\sigma^{2}(\pi)`$, and $`\rho(\pi)`$ are
architecture-level properties estimable from single-learner training.

### 3.3 Monotonic Improvement Condition

Define three critical architecture-level quantities for candidate
$`\pi`$:

- •
  $`\Delta E(\pi)=E(\pi)-E(\pi_{\text{old}})`$: Expected error gain of
  new architecture over current baseline ($`\Delta E<0`$ indicates
  improvement).
- •
  $`\rho(\pi)`$: Expected correlation between independent instances of
  architecture $`\pi`$.
- •
  $`\sigma^{2}(\pi)`$: Expected variance of architecture $`\pi`$
  predictions.

###### Theorem 3.1 (Monotonic Ensemble Improvement).

Under the homogeneity assumption, deploying a new ensemble with
architecture $`\pi`$ guarantees reduced ensemble error
($`\mathbb{E}[\ell(\hat{y}_{\text{ens}}^{(new)},y)]<\mathbb{E}[\ell(\hat{y}_{\text{ens}}^{(old)},y)]`$)
if:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\rho(\pi)<\rho(\pi_{\text{old}})-\frac{M}{M-1}\cdot\frac{\Delta E(\pi)}{\sigma^{2}(\pi)}
``` |  | (5) |

###### Proof Sketch.

Using the homogeneous ensemble error expression
(Eq. ([4](#S3.E4 "In 3.2 Unified Error Decomposition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))),
the change in ensemble error $`\Delta E_{\text{ens}}`$ when switching
from $`\pi_{\text{old}}`$ to $`\pi`$ is:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\Delta E_{\text{ens}}`$ | $`\displaystyle=\left[E(\pi)-\sigma^{2}(\pi)\cdot\frac{M-1}{M}(1-\rho(\pi))\right]`$ |  |
|  |  | $`\displaystyle\quad-\left[E(\pi_{\text{old}})-\sigma^{2}(\pi_{\text{old}})\cdot\frac{M-1}{M}(1-\rho(\pi_{\text{old}}))\right]`$ |  |
|  |  | $`\displaystyle=\Delta E(\pi)-\frac{M-1}{M}\left[\sigma^{2}(\pi)(1-\rho(\pi))-\sigma^{2}(\pi_{\text{old}})(1-\rho(\pi_{\text{old}}))\right]`$ |  |

Setting $`\Delta E_{\text{ens}}<0`$ and rearranging yields
condition ([5](#S3.E5 "In Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")).
Full derivation in
Appendix [A](#A1 "Appendix A Proof of Theorem ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search").
∎

Theoretical Significance:

- •
  Provides a sufficient condition under homogeneity assumptions for
  guaranteed improvement—not just heuristic guidance.
- •
  Decouples architecture search from full ensemble training:
  $`\Delta E(\pi)`$, $`\rho(\pi)`$, $`\sigma^{2}(\pi)`$ require only
  single-learner training of $`f_{\pi}`$ plus lightweight statistics
  from existing ensemble.
- •
  Establishes explicit trade-off: higher diversity ($`\downarrow\rho`$)
  compensates for single-model error increase ($`\uparrow\Delta E`$).
- •
  Key limitation: The condition assumes ensemble members are independent
  realizations of the same architecture. Heterogeneous ensembles require
  extended theory (see
  Section [7](#S7 "7 Conclusion and Future Work ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")).

### 3.4 Search Cost Decoupling Analysis

We quantify the computational advantage of our framework by
distinguishing search cost from deployment cost:

Traditional NAS Cost:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
C_{\text{traditional}}=N_{\text{trials}}\times\underbrace{M\times C_{\text{learner}}}_{\text{Full ensemble training per candidate}}
``` |  | (6) |

Proposed Framework Cost:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
C_{\text{ours}}=\underbrace{N_{\text{trials}}\times\left[C_{\text{learner}}+C_{\text{est}}\right]}_{\text{Search phase}}+\underbrace{1\times M\times C_{\text{learner}}}_{\text{Deployment phase (winner only)}}
``` |  | (7) |

where $`C_{\text{est}}`$ is the cost of estimating $`\rho(\pi)`$,
$`\Delta E(\pi)`$, $`\sigma^{2}(\pi)`$ using:

- •
  Historical ensemble statistics (precomputed correlations/variances
  from $`\mathcal{E}^{(old)}`$).
- •
  Zero-cost proxies [Abdelfattah et al. (2021)](#bib.bib1) for
  $`\Delta E(\pi)`$ estimation.
- •
  The cost of training two proxy instances and computing their
  prediction correlation on a validation batch.

Cost Reduction Factor:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{C_{\text{traditional}}}{C_{\text{ours}}}=\frac{N_{\text{trials}}\cdot M\cdot C_{\text{learner}}}{N_{\text{trials}}\cdot(C_{\text{learner}}+C_{\text{est}})+M\cdot C_{\text{learner}}}\xrightarrow{N_{\text{trials}}\gg M}M
``` |  | (8) |

Industrial Impact: In a production CTR system with $`M=100`$ ensemble
members and $`N_{\text{trials}}=1000`$ candidates:

- •
  Traditional validation: $`\sim`$100,000 GPU-hours (1000 candidates
  $`\times`$ 100 models).
- •
  Our framework: $`\sim`$1,000 GPU-hours (search) + $`\sim`$100
  GPU-hours (deployment) = $`\sim`$1,100 GPU-hours.
- •
  Enables exploration of 90$`\times`$ more candidates within the same
  budget.

This transforms NAS from a resource-prohibitive process to a scalable
architecture optimization loop with theoretical guarantees.

## 4 Solution Strategies Categorized by Pipeline Continuity

Our framework unifies solution strategies based on the continuity and
tractability of architecture pipeline $`\pi`$. The key insight is that
all strategies use
Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")
as a theoretical acceptance criterion to filter candidates before
committing to full ensemble deployment.

### 4.1 Continuous $`\pi`$ with Tractable Models

Scenario: $`\pi`$ is continuous (e.g., dropout ratio, feature retention
$`\alpha`$) and $`E(\pi)`$, $`\rho(\pi)`$, $`\sigma^{2}(\pi)`$ admit
analytical forms.

Approach: Substitute modeling assumptions into the ensemble error
expression
(Eq. [4](#S3.E4 "In 3.2 Unified Error Decomposition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))
and solve directly:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi^{*}=\argmin_{\pi\in\mathcal{A}_{\text{cont}}}E_{\text{ens}}(\pi)=E(\pi)-\sigma^{2}(\pi)\cdot\frac{M-1}{M}(1-\rho(\pi))
``` |  | (9) |

By setting $`\frac{dE_{\text{ens}}}{d\pi}=0`$, we obtain closed-form
$`\pi^{*}`$ without iterative search.

Output: Closed-form optimal $`\pi^{*}`$ (see
Section [5](#S5 "5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")
for feature bagging example where $`\alpha^{*}`$ is derived in
Theorem [5.1](#S5.Thmtheorem1 "Theorem 5.1 (Optimal Feature Retention Ratio). ‣ 5.2 Closed-Form Derivation ‣ 5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")).

Verification (Optional): After computing $`\pi^{*}`$, we can verify
improvement over $`\pi_{\text{old}}`$ using
Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\rho(\pi^{*})<\rho(\pi_{\text{old}})-\frac{M}{M-1}\cdot\frac{E(\pi^{*})-E(\pi_{\text{old}})}{\sigma^{2}(\pi^{*})}
``` |  | (10) |

This step is redundant if $`\pi^{*}`$ is truly optimal, but provides a
theoretical sanity check.

Advantage: No search iterations required; optimal architecture computed
directly from ensemble statistics in $`O(1)`$ time.

### 4.2 Continuous $`\pi`$ with Intractable Models

Scenario: $`\pi`$ continuous but $`\Delta E(\pi)`$, $`\rho(\pi)`$ lack
closed forms (e.g., complex regularization coefficients, neural
hyperparameters).

Approach: Constrained differentiable optimization using surrogate
estimates:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\min_{\pi}\quad`$ | $`\displaystyle\widehat{E}_{\text{ens}}(\pi)`$ |  |
|  | s.t. | $`\displaystyle\hat{\rho}(\pi)<\rho(\pi_{\text{old}})-\frac{M}{M-1}\cdot\frac{\widehat{\Delta E}(\pi)}{\hat{\sigma}^{2}(\pi)}`$ |  |
|  |  | $`\displaystyle\pi\in\mathcal{A}_{\text{cont}}`$ |  |

where $`\widehat{(\cdot)}`$ denotes differentiable surrogates estimated
via stochastic gradient methods or zero-cost proxies.

Challenge: Non-convexity requires careful initialization; gradient noise
necessitates robust optimization (e.g., Bayesian optimization or
multi-start gradient descent).

Theoretical Guarantee: Any solution satisfying the constraint is
guaranteed to improve over $`\pi_{\text{old}}`$ under homogeneity
assumptions.

### 4.3 Discrete $`\pi`$ (Network Topology, Block Choice)

Scenario: $`\pi`$ discrete (e.g., convolution type, layer count,
attention mechanism).

Approach: LLM-driven architecture search with iterative monotonic
acceptance. Unlike traditional LLM-NAS which relies on validation
accuracy alone, our method uses
Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")
to accept/reject candidates based on the diversity-accuracy trade-off.
Candidates are evaluated sequentially, with each accepted candidate
becoming the new baseline for subsequent comparisons.

0:  Current ensemble architecture $`\pi_{\text{old}}`$, ensemble
statistics
$`\{\rho(\pi_{\text{old}}),\sigma^{2}(\pi_{\text{old}}),E(\pi_{\text{old}})\}`$,
LLM $`\mathcal{L}`$, search budget $`N`$

0:  Updated ensemble architecture $`\pi_{\text{new}}`$

1:  Initialize $`\pi_{\text{best}}\leftarrow\pi_{\text{old}}`$

2:  Initialize statistics
$`\{\rho_{\text{best}},\sigma^{2}_{\text{best}},E_{\text{best}}\}\leftarrow\{\rho(\pi_{\text{old}}),\sigma^{2}(\pi_{\text{old}}),E(\pi_{\text{old}})\}`$

3:  for $`i=1`$ to $`N`$ do

4:   Sample complexity bin $`b\sim\text{Uniform}(\mathcal{B})`$ {Enforce
diversity via complexity partitioning}

5:   Prompt LLM: "Generate architecture $`\pi_{i}`$ with complexity in
bin $`b`$, diverse from $`\pi_{\text{best}}`$"

6:   Train dual proxy models $`\{f_{\pi_{i}}^{(1)},f_{\pi_{i}}^{(2)}\}`$
with independent seeds on $`\mathcal{D}_{\text{train}}`$

7:   Estimate $`E(\pi_{i})`$ (avg error), $`\sigma^{2}(\pi_{i})`$
(variance), and $`\rho(\pi_{i})`$ (corr. between dual models) on
validation batch

8:   Calculate $`\Delta E_{i}=E_{\text{best}}-E(\pi_{i})`$

9:   if
$`\rho(\pi_{i})<\rho_{\text{best}}-\frac{M}{M-1}\cdot\frac{\Delta E_{i}}{\sigma^{2}(\pi_{i})}`$
then

10:    $`\pi_{\text{best}}\leftarrow\pi_{i}`$ {Chain update: new
candidate becomes baseline}

11:
   $`\{\rho_{\text{best}},\sigma^{2}_{\text{best}},E_{\text{best}}\}\leftarrow\{\rho(\pi_{i}),\sigma^{2}(\pi_{i}),E(\pi_{i})\}`$

12:   end if

13:  end for

14:  Deploy: Train $`M`$ independent instances of $`\pi_{\text{best}}`$
to form $`\mathcal{E}^{(new)}`$

15:  return $`\mathcal{E}^{(new)}`$

###### Proposition 4.1 (Transitivity of Monotonic Improvement).

If $`\pi_{1}`$ satisfies
Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")
relative to $`\pi_{0}`$, and $`\pi_{2}`$ satisfies
Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")
relative to $`\pi_{1}`$, then $`\pi_{2}`$ guarantees lower ensemble
error than $`\pi_{0}`$.

###### Sketch.

By
Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"),
$`E_{\text{ens}}(\pi_{1})<E_{\text{ens}}(\pi_{0})`$ and
$`E_{\text{ens}}(\pi_{2})<E_{\text{ens}}(\pi_{1})`$. By transitivity of
inequality, $`E_{\text{ens}}(\pi_{2})<E_{\text{ens}}(\pi_{0})`$. ∎

Cost Efficiency: Lines 4–9 cost $`O(1)`$ per candidate (single model
training). Line 10 costs $`O(M)`$ but executes only once. Total cost:
$`N\times O(1)+1\times O(M)`$.

Diversity Enforcement: Line 4 prompts the LLM to generate architectures
diverse from $`\pi_{\text{best}}`$ (current optimum), ensuring the
search explores regions with low $`\rho(\pi)`$ to satisfy the acceptance
criterion.

## 5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction

We instantiate our framework for feature bagging in CTR prediction,
where $`\pi\triangleq\alpha`$ (feature retention ratio). This case study
naturally satisfies our homogeneity assumption since all ensemble
members use the same architecture with different random feature
subsets—making it an ideal validation ground for the theory.

### 5.1 Problem Instantiation

Each base learner trains on $`\alpha d`$ randomly selected features
($`0<\alpha\leq 1`$). Calibrated modeling assumptions (validated on
industrial CTR data):

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle E(\alpha)`$ | $`\displaystyle=E_{\text{base}}+k_{1}(1-\alpha)^{2},\quad k_{1}>0`$ |  | (11) |
|  | $`\displaystyle\rho(\alpha)`$ | $`\displaystyle=\rho_{0}+k_{2}(1-\alpha),\quad k_{2}<0`$ |  | (12) |
|  | $`\displaystyle\sigma^{2}(\alpha)`$ | $`\displaystyle=\sigma^{2}_{\text{base}}\quad\text{(constant variance)}`$ |  | (13) |

where $`\rho_{0}=\rho(\alpha=1)`$ represents the baseline correlation at
full feature retention. For any $`\alpha_{\text{old}}`$, the error
change is
$`\Delta E(\alpha)=E(\alpha)-E(\alpha_{\text{old}})=k_{1}[(1-\alpha)^{2}-(1-\alpha_{\text{old}})^{2}]`$.

Note:
Equation ([11](#S5.E11 "In 5.1 Problem Instantiation ‣ 5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))
models error increase as features are dropped;
Equation ([12](#S5.E12 "In 5.1 Problem Instantiation ‣ 5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))
models diversity gain (correlation decreases) as features are dropped.
The quadratic error model aligns with Taylor expansion near
$`\alpha=1`$; the linear correlation model matches empirical
observations from pilot studies.

### 5.2 Closed-Form Derivation

Substituting ([11](#S5.E11 "In 5.1 Problem Instantiation ‣ 5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))-([13](#S5.E13 "In 5.1 Problem Instantiation ‣ 5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))
into the homogeneous ensemble error expression
(Eq. [4](#S3.E4 "In 3.2 Unified Error Decomposition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
E_{\text{ens}}(\alpha)=E_{\text{base}}+k_{1}(1-\alpha)^{2}-\sigma^{2}_{\text{base}}\frac{M-1}{M}\left[1-\rho_{0}-k_{2}(1-\alpha)\right]
``` |  | (14) |

###### Theorem 5.1 (Optimal Feature Retention Ratio).

The feature retention ratio minimizing ensemble error is:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\alpha^{*}=1+\frac{\sigma^{2}_{\text{base}}(M-1)k_{2}}{2k_{1}M}
``` |  | (15) |

with corresponding optimal dropout rate
$`\beta^{*}=1-\alpha^{*}=-\frac{\sigma^{2}_{\text{base}}(M-1)k_{2}}{2k_{1}M}>0`$.

###### Theorem 5.2 (Minimal Ensemble Error).

Substituting $`\alpha^{*}`$
into ([14](#S5.E14 "In 5.2 Closed-Form Derivation ‣ 5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))
yields:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
E_{\text{ens}}^{*}(M)=E_{\text{base}}-\underbrace{\sigma^{2}_{\text{base}}(1-\rho_{0})\frac{M-1}{M}}_{\text{Base Diversity Gain}}-\underbrace{\frac{\sigma^{4}_{\text{base}}k_{2}^{2}}{4k_{1}}\left(1-\frac{1}{M}\right)^{2}}_{\text{Dropout Gain (Accuracy Gain)}}
``` |  | (16) |

Proofs: See
Appendix [B](#A2 "Appendix B Case Study Detailed Derivations ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")
for complete derivations.

### 5.3 Theoretical Implications

- •
  Dual Gain Mechanisms:
  Equation ([16](#S5.E16 "In Theorem 5.2 (Minimal Ensemble Error). ‣ 5.2 Closed-Form Derivation ‣ 5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))
  cleanly separates improvement sources:

  - –
    Base Diversity Gain: Inherent benefit from ensemble decorrelation
    ($`\rho_{0}<1`$), scales with $`M`$. This exists even without
    feature dropout.
  - –
    Dropout Gain: Strategic benefit from feature subsampling,
    proportional to $`(k_{2}^{2}/k_{1})`$. This corresponds to the
    accuracy gain term in the general framework.
- •
  Engineering Guidance:

  - –
    Optimal dropout rate $`\beta^{*}\propto\frac{M-1}{M}`$: Larger
    ensembles tolerate higher feature dropout.
  - –
    When $`\rho_{0}\to 1`$ (high base correlation), Base Diversity Gain
    vanishes $`\rightarrow`$ prioritize base model diversity first.
  - –
    Dropout gain scales quadratically with $`(1-1/M)`$: Diminishing
    returns beyond $`M\approx 50`$ (at $`M=50`$,
    $`(1-1/M)^{2}\approx 0.96`$; at $`M=100`$, $`\approx 0.98`$).
- •
  Connection to
  Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"):
  The optimal $`\alpha^{*}`$ satisfies the monotonic improvement
  condition relative to any suboptimal $`\alpha_{\text{old}}`$. With
  $`\Delta E(\alpha^{*})=E(\alpha^{*})-E(\alpha_{\text{old}})<0`$, the
  condition becomes:

  |  |  |  |  |
  |----|----|----|----|
  |  |
  ``` math
  \rho(\alpha^{*})<\rho(\alpha_{\text{old}})-\frac{M}{M-1}\cdot\frac{E(\alpha^{*})-E(\alpha_{\text{old}})}{\sigma^{2}_{\text{base}}}
  ``` |  | (17) |

  Since $`\Delta E(\alpha^{*})<0`$, the RHS is larger than
  $`\rho(\alpha_{\text{old}})`$, making the condition easier to satisfy
  for improving candidates. This validates that our closed-form solution
  is consistent with the general acceptance criterion.
- •
  Distinction from Prior Work: First closed-form solution for optimal
  feature retention in CTR ensembles with quantifiable gain
  decomposition. Prior work treats dropout as a regularization
  hyperparameter; we show it is an ensemble diversity control parameter.
- •
  Limitation Note: Feature bagging naturally satisfies the homogeneity
  assumption (same architecture, random feature subsets). For general
  architecture search (e.g., different layer types), homogeneity holds
  approximately when $`M`$ is large (see
  Section [3.3](#S3.SS3 "3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")).

## 7 Conclusion and Future Work

We introduced the Ensemble-Decoupled Architecture Search framework,
which reframes ensemble NAS as a theoretically-grounded generation-based
optimization process. The core contribution—the monotonic improvement
condition
(Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))—provides
a sufficient condition under homogeneity assumptions for guaranteed
ensemble error reduction when deploying a new architecture, decoupling
architecture search from full ensemble retraining. This reduces
per-candidate search cost from $`O(M)`$ to $`O(1)`$, with $`O(M)`$
deployment cost paid only once for validated winners, enabling scalable
NAS in industrial settings.

The framework unifies solution strategies across pipeline continuity:

- •
  Closed-form optimization for tractable continuous $`\pi`$ (exemplified
  by feature bagging in CTR prediction)
- •
  Constrained differentiable optimization for intractable continuous
  $`\pi`$ (e.g., neural hyperparameters)
- •
  LLM-driven search with iterative monotonic acceptance for discrete
  $`\pi`$
  (Algorithm [1](#alg1 "Algorithm 1 ‣ 4.3 Discrete 𝜋 (Network Topology, Block Choice) ‣ 4 Solution Strategies Categorized by Pipeline Continuity ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"))

Key theoretical insights include:

- •
  Dual Gain Decomposition: Ensemble improvement separates into base
  diversity gain (inherent from $`\rho_{0}<1`$) and accuracy/dropout
  gain (strategic from architecture optimization), as shown in
  Eq. ([16](#S5.E16 "In Theorem 5.2 (Minimal Ensemble Error). ‣ 5.2 Closed-Form Derivation ‣ 5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")).
- •
  Engineering Guidelines: Explicit formulas such as
  $`\beta^{*}\propto\frac{M-1}{M}`$ (optimal dropout scales with
  ensemble size) and diminishing returns beyond $`M\approx 50`$.
- •
  Cost-Decoupling Principle: Search complexity is independent of
  ensemble size, enabling 100$`\times`$ more candidate exploration
  within the same budget
  (Section [3.4](#S3.SS4 "3.4 Search Cost Decoupling Analysis ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")).

This work establishes the first rigorous theoretical foundation for
cost-efficient ensemble NAS with monotonic improvement guarantees.
Comprehensive experimental validation is in progress for journal
submission (target Q2 2026), with code release committed upon
publication
(Section [6](#S6 "6 Experimental Validation Plan ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")).

Limitations and Future Directions:

- •
  Homogeneity Assumption:
  Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")
  assumes ensemble members are independent realizations of the same
  architecture. This holds exactly for feature bagging but approximately
  for general architecture search. Future work will extend the theory to
  heterogeneous ensembles with bounded deviation analysis.
- •
  Proxy Reliability: Zero-cost proxies for $`\Delta E(\pi)`$ estimation
  require calibration. We plan to derive confidence bounds and failure
  mode analysis for proxy-based decisions.
- •
  Weighted Ensembles: Current framework assumes uniform averaging.
  Extension to non-uniform weighted ensembles could further optimize the
  diversity-accuracy trade-off.
- •
  Online Evolution: The current generation-based update can be extended
  to continuous online scenarios with streaming data and dynamic
  ensemble sizing.
- •
  Integration with DAS: Combining our acceptance criterion with
  Differentiable Architecture Search (DARTS) could enable gradient-based
  optimization subject to theoretical monotonicity constraints.
- •
  Meta-Learning for Statistics: Learning to predict $`\Delta E(\pi)`$,
  $`\rho(\pi)`$, $`\sigma^{2}(\pi)`$ across tasks via meta-learning
  could eliminate the need for single-learner training during search.

Broader Impact: By transforming NAS from heuristic exploration to
theory-guided optimization, this framework paves the way for
self-improving recommender systems that continuously evolve with minimal
human intervention. The cost reduction enables smaller organizations to
deploy ensemble-based NAS, democratizing access to robust production ML
systems.

Availability: This arXiv preprint presents the theoretical foundation.
Complete implementation, benchmark results, and reproduction scripts
will be released at \[GitHub Repository Link\] upon journal submission.

## Appendix A Proof of Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")

### A.1 Homogeneous Ensemble Error Expression

Under the homogeneity assumption
(Section [3.1](#S3.SS1 "3.1 Problem Formulation: NAS as Generation-Based Ensemble Optimization ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")),
all ensemble members are independent realizations of the same
architecture $`\pi`$. This implies:

- •
  All members share identical expected error:
  $`\mathbb{E}[(y-f_{i})^{2}]=E(\pi)`$ for all $`i`$.
- •
  All members share identical variance:
  $`\text{Var}(f_{i})=\sigma^{2}(\pi)`$ for all $`i`$.
- •
  All pairs share identical correlation:
  $`\text{Cov}(f_{i},f_{j})=\rho(\pi)`$ for all $`i\neq j`$.

Starting from the Error-Ambiguity decomposition
(Eq. [3](#S3.E3 "In 3.2 Unified Error Decomposition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{E}[(y-\hat{p}_{\text{ens}})^{2}]=\frac{1}{M}\sum_{m=1}^{M}\mathbb{E}[(y-\hat{p}_{m})^{2}]-\frac{1}{M}\sum_{m=1}^{M}\mathbb{E}[(\hat{p}_{m}-\hat{p}_{\text{ens}})^{2}]
``` |  | (18) |

The first term (average single-model error) simplifies to:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{1}{M}\sum_{m=1}^{M}\mathbb{E}[(y-\hat{p}_{m})^{2}]=E(\pi)
``` |  | (19) |

The second term (average ambiguity/diversity) can be expanded using
variance-covariance algebra:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\bar{D}(\pi)`$ | $`\displaystyle=\frac{1}{M}\sum_{m=1}^{M}\text{Var}(\hat{p}_{m}-\hat{p}_{\text{ens}})`$ |  |
|  |  | $`\displaystyle=\frac{1}{M}\sum_{m=1}^{M}\left[\text{Var}(\hat{p}_{m})+\text{Var}(\hat{p}_{\text{ens}})-2\text{Cov}(\hat{p}_{m},\hat{p}_{\text{ens}})\right]`$ |  |

Under homogeneity:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\text{Var}(\hat{p}_{\text{ens}})`$ | $`\displaystyle=\text{Var}\left(\frac{1}{M}\sum_{k=1}^{M}\hat{p}_{k}\right)=\frac{\sigma^{2}(\pi)}{M^{2}}\left[M+M(M-1)\rho(\pi)\right]=\frac{\sigma^{2}(\pi)}{M}\left[1+(M-1)\rho(\pi)\right]`$ |  |
|  | $`\displaystyle\text{Cov}(\hat{p}_{m},\hat{p}_{\text{ens}})`$ | $`\displaystyle=\text{Cov}\left(\hat{p}_{m},\frac{1}{M}\sum_{k=1}^{M}\hat{p}_{k}\right)=\frac{\sigma^{2}(\pi)}{M}\left[1+(M-1)\rho(\pi)\right]`$ |  |

Substituting back:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\bar{D}(\pi)`$ | $`\displaystyle=\sigma^{2}(\pi)+\frac{\sigma^{2}(\pi)}{M}\left[1+(M-1)\rho(\pi)\right]-2\cdot\frac{\sigma^{2}(\pi)}{M}\left[1+(M-1)\rho(\pi)\right]`$ |  |
|  |  | $`\displaystyle=\sigma^{2}(\pi)\left(1-\frac{1+(M-1)\rho(\pi)}{M}\right)`$ |  |
|  |  | $`\displaystyle=\sigma^{2}(\pi)\cdot\frac{(M-1)(1-\rho(\pi))}{M}`$ |  |

Thus, the homogeneous ensemble error is:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
E_{\text{ens}}(\pi)=E(\pi)-\sigma^{2}(\pi)\cdot\frac{M-1}{M}(1-\rho(\pi))
``` |  | (20) |

### A.2 Proof of Monotonic Improvement Condition

We compare the ensemble error of the new architecture $`\pi`$ against
the current baseline $`\pi_{\text{old}}`$:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\Delta E_{\text{ens}}`$ | $`\displaystyle=E_{\text{ens}}(\pi)-E_{\text{ens}}(\pi_{\text{old}})`$ |  |
|  |  | $`\displaystyle=\left[E(\pi)-\sigma^{2}(\pi)\cdot\frac{M-1}{M}(1-\rho(\pi))\right]`$ |  |
|  |  | $`\displaystyle\quad-\left[E(\pi_{\text{old}})-\sigma^{2}(\pi_{\text{old}})\cdot\frac{M-1}{M}(1-\rho(\pi_{\text{old}}))\right]`$ |  |
|  |  | $`\displaystyle=\underbrace{\left[E(\pi)-E(\pi_{\text{old}})\right]}_{\Delta E(\pi)}-\frac{M-1}{M}\underbrace{\left[\sigma^{2}(\pi)(1-\rho(\pi))-\sigma^{2}(\pi_{\text{old}})(1-\rho(\pi_{\text{old}}))\right]}_{\Delta\text{Diversity}}`$ |  |

For monotonic improvement ($`\Delta E_{\text{ens}}<0`$), we require:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Delta E(\pi)-\frac{M-1}{M}\left[\sigma^{2}(\pi)(1-\rho(\pi))-\sigma^{2}(\pi_{\text{old}})(1-\rho(\pi_{\text{old}}))\right]<0
``` |  | (21) |

Rearranging:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\sigma^{2}(\pi)(1-\rho(\pi))>\sigma^{2}(\pi_{\text{old}})(1-\rho(\pi_{\text{old}}))+\frac{M}{M-1}\Delta E(\pi)
``` |  | (22) |

Simplified Condition: In practice, we observe that
$`\sigma^{2}(\pi)\approx\sigma^{2}(\pi_{\text{old}})`$ for architectures
within the same search space (validated empirically in
Section [6](#S6 "6 Experimental Validation Plan ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")).
Under this variance stability assumption:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle 1-\rho(\pi)`$ | $`\displaystyle>1-\rho(\pi_{\text{old}})+\frac{M}{M-1}\cdot\frac{\Delta E(\pi)}{\sigma^{2}(\pi)}`$ |  |
|  | $`\displaystyle\rho(\pi)`$ | $`\displaystyle<\rho(\pi_{\text{old}})-\frac{M}{M-1}\cdot\frac{\Delta E(\pi)}{\sigma^{2}(\pi)}`$ |  |

### A.3 Discussion of Assumptions

|  Assumption |  Justification |
|----|----|
|  Homogeneity (same architecture) |  Enforced by design: all $`M`$ members are independent training runs of $`\pi`$. |
|  Variance stability ($`\sigma^{2}(\pi)\approx\sigma^{2}(\pi_{\text{old}})`$) |  Holds for architectures within same search space; verified in Section [6](#S6 "6 Experimental Validation Plan ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search"). |
|  Independence (different seeds/data) |  Standard practice in ensemble training; ensures $`\rho(\pi)<1`$. |

Table 1: Assumptions in
Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")
and Their Validity

The theorem provides a sufficient condition for ensemble improvement.
Violations of the variance stability assumption may affect the threshold
but do not invalidate the core insight: diversity ($`\rho`$) and
accuracy ($`\Delta E`$) trade off in determining ensemble performance.

## Appendix B Case Study Detailed Derivations

### B.1 Average Ambiguity Derivation

Starting from the definition of average ambiguity in
Eq. ([3](#S3.E3 "In 3.2 Unified Error Decomposition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")):

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\bar{D}(\alpha)`$ | $`\displaystyle=\frac{1}{M}\sum_{m=1}^{M}\mathbb{E}\big[(\hat{p}_{m}-\hat{p}_{\text{ens}})^{2}\big]`$ |  |
|  |  | $`\displaystyle=\frac{1}{M}\sum_{m=1}^{M}\text{Var}(\hat{p}_{m}-\hat{p}_{\text{ens}})\quad(\text{since }\mathbb{E}[\hat{p}_{m}-\hat{p}_{\text{ens}}]=0)`$ |  |
|  |  | $`\displaystyle=\frac{1}{M}\sum_{m=1}^{M}\left[\text{Var}(\hat{p}_{m})+\text{Var}(\hat{p}_{\text{ens}})-2\text{Cov}(\hat{p}_{m},\hat{p}_{\text{ens}})\right].`$ |  |

Under homogeneity assumptions
($`\text{Var}(\hat{p}_{m})=\sigma^{2}(\alpha)`$, pairwise
$`\text{Cov}(\hat{p}_{i},\hat{p}_{j})=\rho(\alpha)\sigma^{2}(\alpha)`$
for $`i\neq j`$):

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\text{Var}(\hat{p}_{\text{ens}})`$ | $`\displaystyle=\text{Var}\left(\frac{1}{M}\sum_{k=1}^{M}\hat{p}_{k}\right)=\frac{\sigma^{2}(\alpha)}{M^{2}}\left[M+M(M-1)\rho(\alpha)\right]=\frac{\sigma^{2}(\alpha)}{M}\left[1+(M-1)\rho(\alpha)\right],`$ |  |
|  | $`\displaystyle\text{Cov}(\hat{p}_{m},\hat{p}_{\text{ens}})`$ | $`\displaystyle=\text{Cov}\left(\hat{p}_{m},\frac{1}{M}\sum_{k=1}^{M}\hat{p}_{k}\right)=\frac{1}{M}\left[\sigma^{2}(\alpha)+(M-1)\rho(\alpha)\sigma^{2}(\alpha)\right]=\frac{\sigma^{2}(\alpha)}{M}\left[1+(M-1)\rho(\alpha)\right].`$ |  |

Substituting back:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\text{Var}(\hat{p}_{m}-\hat{p}_{\text{ens}})`$ | $`\displaystyle=\sigma^{2}(\alpha)+\frac{\sigma^{2}(\alpha)}{M}[1+(M-1)\rho(\alpha)]-2\cdot\frac{\sigma^{2}(\alpha)}{M}[1+(M-1)\rho(\alpha)]`$ |  |
|  |  | $`\displaystyle=\sigma^{2}(\alpha)\left(1-\frac{1+(M-1)\rho(\alpha)}{M}\right)=\sigma^{2}(\alpha)\cdot\frac{(M-1)(1-\rho(\alpha))}{M}.`$ |  |

Averaging over $`m`$ yields
$`\bar{D}(\alpha)=\sigma^{2}(\alpha)\cdot\frac{(M-1)(1-\rho(\alpha))}{M}`$.

### B.2 Optimal $`\alpha^{*}`$ Derivation

From
Eq. ([14](#S5.E14 "In 5.2 Closed-Form Derivation ‣ 5 Case Study: Closed-Form Solution for Feature Bagging in CTR Prediction ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search")),
define
$`f(\alpha)=k_{1}(1-\alpha)^{2}-C(M)[1-\rho_{0}-k_{2}(1-\alpha)]`$ where
$`C(M)=\sigma^{2}_{\text{base}}\frac{M-1}{M}`$. Minimizing
$`f(\alpha)`$:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\frac{df}{d\alpha}`$ | $`\displaystyle=-2k_{1}(1-\alpha)-C(M)k_{2}=0`$ |  |
|  | $`\displaystyle\Rightarrow 1-\alpha`$ | $`\displaystyle=-\frac{C(M)k_{2}}{2k_{1}}=-\frac{\sigma^{2}_{\text{base}}(M-1)k_{2}}{2k_{1}M}`$ |  |
|  | $`\displaystyle\Rightarrow\alpha^{*}`$ | $`\displaystyle=1+\frac{\sigma^{2}_{\text{base}}(M-1)k_{2}}{2k_{1}M}.`$ |  |

Since $`k_{2}<0`$, $`\alpha^{*}<1`$. Second derivative
$`\frac{d^{2}f}{d\alpha^{2}}=2k_{1}>0`$ confirms minimality.

Note on $`\Delta E`$ convention: Throughout this paper, we define
$`\Delta E(\pi)=E(\pi)-E(\pi_{\text{old}})`$, so $`\Delta E<0`$
indicates improvement. For the optimal $`\alpha^{*}`$, we have
$`\Delta E(\alpha^{*})=k_{1}[(1-\alpha^{*})^{2}-(1-\alpha_{\text{old}})^{2}]<0`$
when $`\alpha_{\text{old}}`$ is suboptimal.

### B.3 Minimal Error Derivation

Substitute
$`\beta^{*}=1-\alpha^{*}=-\frac{\sigma^{2}_{\text{base}}(M-1)k_{2}}{2k_{1}M}`$
into $`E_{\text{ens}}(\alpha)`$:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle E_{\text{ens}}^{*}(M)`$ | $`\displaystyle=E_{\text{base}}+k_{1}(\beta^{*})^{2}-\sigma^{2}_{\text{base}}\frac{M-1}{M}\left[1-\rho_{0}-k_{2}\beta^{*}\right]`$ |  |
|  |  | $`\displaystyle=E_{\text{base}}+k_{1}\left(\frac{\sigma^{4}_{\text{base}}(M-1)^{2}k_{2}^{2}}{4k_{1}^{2}M^{2}}\right)-\sigma^{2}_{\text{base}}\frac{M-1}{M}(1-\rho_{0})-\sigma^{2}_{\text{base}}\frac{M-1}{M}k_{2}\left(-\frac{\sigma^{2}_{\text{base}}(M-1)k_{2}}{2k_{1}M}\right)`$ |  |
|  |  | $`\displaystyle=E_{\text{base}}+\frac{\sigma^{4}_{\text{base}}(M-1)^{2}k_{2}^{2}}{4k_{1}M^{2}}-\sigma^{2}_{\text{base}}\frac{M-1}{M}(1-\rho_{0})-\frac{\sigma^{4}_{\text{base}}(M-1)^{2}k_{2}^{2}}{2k_{1}M^{2}}`$ |  |
|  |  | $`\displaystyle=E_{\text{base}}-\sigma^{2}_{\text{base}}(1-\rho_{0})\frac{M-1}{M}-\frac{\sigma^{4}_{\text{base}}k_{2}^{2}}{4k_{1}}\left(1-\frac{1}{M}\right)^{2}.`$ |  |

### B.4 Verification of Monotonic Condition

We verify that $`\alpha^{*}`$ satisfies
Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1 (Monotonic Ensemble Improvement). ‣ 3.3 Monotonic Improvement Condition ‣ 3 Ensemble-Decoupled Architecture Search Framework ‣ AgenticRS-EnsNAS: Ensemble-Decoupled Self-Evolving Architecture Search").
For any suboptimal $`\alpha_{\text{old}}`$:

|  |  |  |  |
|----|----|----|----|
|  | LHS | $`\displaystyle=\rho(\alpha^{*})=\rho_{0}+k_{2}(1-\alpha^{*})=\rho_{0}+k_{2}\beta^{*}`$ |  |
|  | RHS | $`\displaystyle=\rho(\alpha_{\text{old}})-\frac{M}{M-1}\cdot\frac{E(\alpha^{*})-E(\alpha_{\text{old}})}{\sigma^{2}_{\text{base}}}`$ |  |
|  |  | $`\displaystyle=\rho_{0}+k_{2}(1-\alpha_{\text{old}})-\frac{M}{M-1}\cdot\frac{k_{1}[(1-\alpha^{*})^{2}-(1-\alpha_{\text{old}})^{2}]}{\sigma^{2}_{\text{base}}}`$ |  |

Substituting
$`\beta^{*}=-\frac{\sigma^{2}_{\text{base}}(M-1)k_{2}}{2k_{1}M}`$ and
simplifying (see supplementary worksheet), we can show LHS ¡ RHS,
confirming that the closed-form optimum satisfies the monotonic
acceptance criterion.

## Appendix C Lightweight Estimation Feasibility Analysis

We analyze the feasibility of estimating $`\Delta E(\pi)`$,
$`\rho(\pi)`$, $`\sigma^{2}(\pi)`$ using lightweight dual-learner
strategies. While true zero-cost proxies exist, we employ minimal
training (dual instances) to ensure estimation fidelity:

- •
  $`\sigma^{2}(\pi)`$: Computed from the prediction variance of dual
  independent instances on a validation batch.
- •
  $`\rho(\pi)`$: Pearson correlation between predictions of dual
  independent instances ($`f_{\pi}^{(1)},f_{\pi}^{(2)}`$) on a
  validation batch. This requires training two small proxies with
  different seeds.
- •
  $`\Delta E(\pi)`$: Estimated via validation loss of the dual
  instances. Empirical results show validation loss of dual proxies
  correlates strongly ($`r>0.95`$) with full ensemble performance.

Empirical calibration protocol: Precompute statistics on a small
validation subset; apply estimation during search. The cost of
dual-learner training is constant ($`2\times C_{\text{learner}}`$),
which is negligible compared to full ensemble validation
($`M\times C_{\text{learner}}`$) when $`M\gg 2`$.
````
