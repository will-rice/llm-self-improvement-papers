###### Abstract

Reinforcement Learning from Human Feedback (RLHF) has been commonly used
to align the behaviors of Large Language Models (LLMs) with human
preferences. Recently, a popular alternative is Direct Policy
Optimization (DPO), which replaces an LLM-based reward model with the
policy itself, thus obviating the need for extra memory and training
time to learn the reward model. However, DPO does not consider the
relative qualities of the positive and negative responses, and can lead
to sub-optimal training outcomes. To alleviate this problem, we
investigate the use of intrinsic knowledge within the on-the-fly
fine-tuning LLM to obtain relative qualities and help to refine the loss
function. Specifically, we leverage the knowledge of the LLM to design a
refinement function to estimate the quality of both the positive and
negative responses. We show that the constructed refinement function can
help self-refine the loss function under mild assumptions. The
refinement function is integrated into DPO and its variant Identity
Policy Optimization (IPO). Experiments across various evaluators
indicate that they can improve the performance of the fine-tuned models
over DPO and IPO.

## 1 Introduction

Large Language Models (LLMs) have demonstrated significant capabilities
across various natural language processing tasks \[[34](#bib.bib34);
[49](#bib.bib49); [42](#bib.bib42); [1](#bib.bib1)\]. Ensuring that
these LLMs produce the desired responses and behaviors that are aligned
with human preferences is crucial for safe and controllable AI systems
\[[33](#bib.bib33)\]. To achieve this, a popular method is Reinforcement
Learning from Human Feedback (RLHF) \[[13](#bib.bib13); [1](#bib.bib1);
[5](#bib.bib5)\], which first trains a reward model using human-labeled
response pairs, and then uses this to adjust the policy parameters of
the LLM \[[5](#bib.bib5); [33](#bib.bib33)\]. However, the reward model
is often constructed by another LLM, which requires further training and
storage \[[3](#bib.bib3)\].

To reduce the storage and training time of the reward model, a variety
of methods have been proposed recently \[[17](#bib.bib17);
[47](#bib.bib47); [3](#bib.bib3)\]. In particular, a prominent solution
is the Direct Policy Optimization (DPO) \[[3](#bib.bib3)\], which
replaces the reward model with the policy itself, thus obviating the
need for an explicit reward model. Recently, numerous variants of DPO
have also been developed \[[44](#bib.bib44); [4](#bib.bib4);
[3](#bib.bib3); [18](#bib.bib18); [39](#bib.bib39)\].

The objective of DPO is to consistently increase the likelihood of
human-preferred responses while reducing the likelihood of the undesired
ones. However, this strategy does not consider the relative qualities of
the positive and negative responses, and can lead to suboptimal training
outcomes, particularly when the preferred responses are not
substantially superior, or when the undesired responses are not
adequately inferior \[[3](#bib.bib3); [43](#bib.bib43);
[16](#bib.bib16)\].

To alleviate this issue, Amini et al. \[[3](#bib.bib3)\] and Zhou et al.
\[[53](#bib.bib53)\] propose the use of a score function to self-refine
the objective. However, this approach requires the availability of an
ideal reward or score function, which may not be always feasible.
Similarly, Cui et al. \[[16](#bib.bib16)\] and Tunstall et al.
\[[43](#bib.bib43)\] employ GPT-4 \[[1](#bib.bib1)\] to select
high-quality response pairs by scoring them. This method requires a
strong LLM to effectively filter the dataset, which again may not always
be practical. These considerations raise the question: _Can we achieve
this by using the inherent knowledge within the policy itself?_

Recently, self-alignment has attracted increasing attention due to its
ability to leverage the inherent knowledge of LLMs to enhance alignment
capabilities, obviating the necessity for additional human-annotated
data \[[30](#bib.bib30); [2](#bib.bib2); [27](#bib.bib27);
[46](#bib.bib46)\]. Inspired by this, we propose to utilize on-the-fly
fine-tuning of an LLM’s knowledge to help evaluate the quality of
positive and negative responses. The underlying premise is that even
relatively weak LLMs possess some ability to assess the quality of
responses \[[23](#bib.bib23); [22](#bib.bib22)\]. Consequently, our
objective is to exploit this capability to more effectively evaluate
response quality, thereby enhancing the efficiency and accuracy of the
fine-tuned model.

In this paper, we investigate the use of intrinsic knowledge within the
LLM to self-refine the loss function. In summary, the contributions of
this work are as follows:

- •
  We leverage the knowledge of the LLM to design a refinement function,
  which estimates the quality of positive and negative responses.
- •
  We demonstrate that the constructed refinement function can help
  self-refine the loss function under mild assumptions.
- •
  By utilizing the refinement function, we propose two novel approaches
  based on DPO and its variant Identity Policy Optimization (IPO)
  \[[4](#bib.bib4)\].

Experimental results across various evaluators indicate that the
proposed self-refined methods improve the performance of the fine-tuned
models compared to their counterparts.

## 2 Preliminaries

### 2.1 Classical RLHF with Bradley-Terry Reward Model

Given a pre-trained large language model (LLM) $`\pi_{\text{ref}}`$ as
initialization, Reinforcement Learning from Human Feedback (RLHF)
\[[13](#bib.bib13); [1](#bib.bib1); [5](#bib.bib5)\] aims to learn an
LLM $`\pi`$ that aligns with human values and preferences. Specifically,
let $`x`$ be the query, $`y`$ be the output of $`\pi`$, and $`r`$ be a
reward function that evaluates the performance of $`y`$ given $`x`$,
RLHF tries to maximize $`r`$ while ensuring that the trained LLM $`\pi`$
does not deviate significantly from the pre-trained model
$`\pi_{\text{ref}}`$. This can be formulated as the following
optimization problem \[[33](#bib.bib33); [31](#bib.bib31);
[1](#bib.bib1)\]:

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\max_{\pi}\mathbb{E}_{x\sim\mathcal{D},y\sim\pi(\cdot|x)}r(y|x)-\beta\mathbb{D}_{\mathrm{KL}}[\pi(y|x)\|\pi_{\text{ref}}(y|x)],
``` |  | (1) |

where $`\mathbb{D}_{\mathrm{KL}}[\pi(y|x)\|\pi_{\text{ref}}(y|x)]`$ is
the Kullback-Leibler divergence between $`\pi`$ and
$`\pi_{\text{ref}}`$, and $`\beta`$ is a constant.

Since $`r`$ is unknown, the user needs to provide a set of preferences
$`D\equiv\{(x_{i},y^{+}_{i},y^{-}_{i})\}^{N}_{i=1}`$, where
$`y^{+}_{i}`$ (resp. $`y^{-}_{i}`$) is the positive (resp. negative)
response for query $`x_{i}`$. A suitable model, typically another LLM
(parameterized by $`\omega`$) \[[26](#bib.bib26); [1](#bib.bib1)\], then
learns the reward function by maximizing the probability
$`p(y_{i}^{+}\succ y_{i}^{-}|x)`$ that $`y_{i}^{+}`$ is preferred over
$`y_{i}^{-}`$ (denoted $`y_{i}^{+}\succ y_{i}^{-}`$) \[[33](#bib.bib33);
[3](#bib.bib3); [4](#bib.bib4)\]. Typically, this probability is defined
by the Bradley-Terry preference model \[[8](#bib.bib8);
[13](#bib.bib13)\] as:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p(y_{i}^{+}\succ y_{i}^{-}|x_{i})\equiv\sigma(r(y_{i}^{+}|x_{i})-r(y_{i}^{-}|x_{i})),
``` |  | (2) |

where $`\sigma(\cdot)`$ is the logistic function. The optimal $`r`$ can
then be obtained by maximizing the log likelihood

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\max_{r}\mathbb{E}_{(x,y^{+},y^{-})\sim\mathcal{D}}\log[\sigma(r(y_{i}^{+}|x_{i})-r(y_{i}^{-}|x_{i}))].
``` |  | (3) |

With the obtained $`r`$, we can then find $`\pi`$ by optimizing
([1](#S2.E1 "In 2.1 Classical RLHF with Bradley-Terry Reward Model ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")).

### 2.2 Direct Preference Optimization (DPO)

In RLHF, the reward model is represented by a LLM \[[33](#bib.bib33)\].
This can be time- and memory-expensive. It is observed that the optimal
$`\pi`$ in
([1](#S2.E1 "In 2.1 Classical RLHF with Bradley-Terry Reward Model ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"))
indeed has the closed form \[[35](#bib.bib35)\]:
$`\pi(y|x)\propto\pi_{\text{ref}}(y|x)\exp\left(\frac{r(y|x)}{\beta}\right),`$
and so

|     |                                                              |     |     |
|-----|--------------------------------------------------------------|-----|-----|
|     |
       ``` math
       r(y|x)=\beta\log\frac{\pi(y|x)}{\pi_{\text{ref}}(y|x)}+c(x),
       ```                                                           |     | (4) |

where
$`c(x)\equiv\sum_{y\in\mathcal{Y}}\pi_{\text{ref}}(y\mid x)\exp\left(\frac{1}{\beta}r(y|x)\right)`$,
and $`\mathcal{Y}`$ is the set of responses. By plugging this into
([3](#S2.E3 "In 2.1 Classical RLHF with Bradley-Terry Reward Model ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")),
the optimal policy can be found directly by maximizing:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\max\nolimits_{\pi}\mathbb{E}_{(x,y^{+},y^{-})\sim\mathcal{D}}\log\sigma\left(\beta\log\frac{\pi(y^{+}|x)}{\pi_{\text{ref}}(y^{+}|x)}-\beta\log\frac{\pi(y^{-}|x)}{\pi_{\text{ref}}(y^{-}|x)}\right).
``` |  | (5) |

### 2.3 Identity Policy Optimisation (IPO)

DPO aims to maximize
([1](#S2.E1 "In 2.1 Classical RLHF with Bradley-Terry Reward Model ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")).
However, our goal is to maximize the preference rather than the reward
\[[45](#bib.bib45)\]. Consequently, a better option is to maximize the
preference probabilities $`p(y\succ y^{\prime}|x)`$. To this end, IPO
\[[4](#bib.bib4)\] optimizes the following objective:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\max_{\pi}\mathbb{E}_{x\sim\mathcal{D},y^{+}\sim\pi(\cdot|x),y^{-}\sim\pi_{\text{ref}}(\cdot|x)}p(y^{+}\succ y^{-}|x)-\beta\mathbb{D}_{\mathrm{KL}}[\pi(y^{+}|x)\|\pi_{\text{ref}}(y^{-}|x)].
``` |  | (6) |

Similar to DPO, following \[[4](#bib.bib4)\], the optimal $`\pi`$ also
has a closed-form solution:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi(y^{+}|x)\propto\pi_{\text{ref}}(y^{-}|x)\exp\left(\mathbb{E}_{y^{+}\sim\pi_{\text{ref}}(\cdot|x)}p(y^{+}\succ y^{-}|x)/\beta\right).
``` |  | (7) |

The loss for IPO is then defined as:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{E}_{(x,y^{+},y^{-})\sim\mathcal{D}}\left[\left(\log\frac{\pi(y^{+}|x)}{\pi_{\text{ref}}(y^{+}|x)}-\log\frac{\pi(y^{-}|x)}{\pi_{\text{ref}}(y^{-}|x)}-\frac{1}{2\beta}\right)^{2}\right].
``` |  | (8) |

### 2.4 Self-Alignment

The proposed method is also related to
self-alignment \[[27](#bib.bib27); [46](#bib.bib46); [29](#bib.bib29)\],
which uses the LLM’s own knowledge to improve the alignment. For
example, self-judgement \[[27](#bib.bib27); [46](#bib.bib46);
[40](#bib.bib40); [29](#bib.bib29); [50](#bib.bib50)\] uses the LLM as a
judge to evaluate the generated answer. Self-improving
\[[30](#bib.bib30); [2](#bib.bib2); [11](#bib.bib11); [10](#bib.bib10);
[9](#bib.bib9)\] improves LLM by playing game with another LLM opponent.
Our work uses the self-alignment ability of LLM to construct a
refinement function to adjust the quality of responses.

## 3 Proposed Method

### 3.1 Limitation of Maximizing Bradley-Terry Preference

Let $`r^{*}`$ and $`r`$ be the true and learned reward function
respectively. For any tuple $`(x,y^{+},y^{-})\in D`$, the true reward of
the positive response $`y^{+}`$ should exceed that of the negative
response $`y^{-}`$, i.e.,
$`y^{+}\succ y^{-}\Leftrightarrow r^{*}(y^{+}|x)>r^{*}(y^{-}|x)`$.
Consider two tuples $`(x_{i},y_{i}^{+},y_{i}^{-})`$ and
$`(x_{j},y_{j}^{+},y_{j}^{-})`$. When
$`r^{*}(y_{i}^{+}|x_{i})-r^{*}(y_{i}^{-}|x_{i})>r^{*}(y_{j}^{+}|x_{j})-r^{*}(y_{j}^{-}|x_{j})`$,
we prefer
$`p(y_{i}^{+}\succ y_{i}^{-}|x_{i})>p(y_{j}^{+}\succ y_{j}^{-}|x_{j})`$,
and so
$`\sigma(r(y_{i}^{+}|x_{i})-r(y_{i}^{-}|x_{i}))>\sigma(r(y_{j}^{+}|x_{j})-r(y_{j}^{-}|x_{j}))`$
from
([2](#S2.E2 "In 2.1 Classical RLHF with Bradley-Terry Reward Model ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")).
In other words, the more informative tuple
$`(x_{i},y_{i}^{+},y_{i}^{-})`$ should be more important. However, RLHF
simply maximizes
([3](#S2.E3 "In 2.1 Classical RLHF with Bradley-Terry Reward Model ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")),
which considers all tuples in the dataset $`D`$ equally.

### 3.2 Refining the Reward Difference between Positive and Negative Responses

#### 3.2.1 Intuition

To alleviate this problem, we propose adding a refinement function
$`\Delta(y^{-},y^{+};x):\mathcal{Y}\times\mathcal{Y}\times\mathcal{X}\rightarrow\mathbb{R}`$
(where $`\mathcal{X}`$ and $`\mathcal{Y}`$ are the sets of queries and
responses, respectively) to adjust $`r(y^{+}|x)-r(y^{-}|x)`$, so that
problem
([3](#S2.E3 "In 2.1 Classical RLHF with Bradley-Terry Reward Model ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"))
is modified to:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\max_{\pi}\mathbb{E}_{(x,y^{+},y^{-})\sim\mathcal{D}}\log[\sigma(r(y^{+}|x)-r(y^{-}|x)-\lambda\Delta(y^{-},y^{+};x))],
``` |  | (9) |

where $`\lambda`$ is a positive constant. Intuitively, when
$`\Delta(y^{-},y^{+};x)`$ is large,
$`\sigma(r(y^{+}|x)-r(y^{-}|x)-\lambda\Delta(y^{-},y^{+};x))`$ becomes
small, and the optimization in
([9](#S3.E9 "In 3.2.1 Intuition ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"))
will tend to enlarge the “distance” $`r(y^{+}|x)-r(y^{-}|x)`$ between
the positive and negative responses. Thus, for two tuples
$`(x,y^{+},y^{-})`$ and $`(x,\tilde{y}^{+},\tilde{y}^{-})`$
corresponding to the same query $`x`$, we want to design a $`\Delta`$
such that when
$`\Delta(y^{-},y^{+};x)>\Delta(\tilde{y}^{-},\tilde{y}^{+};x)`$, their
true reward values satisfy:

|  |  |  |
|----|----|----|
|  |
``` math
r^{*}(y^{+}|x)-r^{*}(y^{-}|x)>r^{*}(\tilde{y}^{+}|x)-r^{*}(\tilde{y}^{-}|x).
``` |  |

In other words, a larger difference $`r^{*}(y^{+}|x)-r^{*}(y^{-}|x)`$ in
the true reward values between the positive and negative responses
corresponds to a larger $`\Delta(y^{-},y^{+};x)`$, and vice versa.
However, obviously the difficulty is that we do not have access to
$`r^{*}`$.

#### 3.2.2 Implementing $`\Delta`$ via Prompting

First, we assume that the LLM is capable of learning a reward function
that aligns with the true reward function. This premise is formalized as
follows:

###### Assumption 3.1.

LLM $`\pi`$ can construct a reward model $`r`$ such that for any
$`(x,y^{+},y^{-})`$ with $`y^{+}\succ y^{-}`$, the corresponding reward
values satisfy $`r(y^{+}|x)>r(y^{-}|x)`$.

As $`r^{*}`$ is unknown, with a capable LLM, a natural idea is to use
$`r`$ as a proxy of $`r^{*}`$. Recall from
Section [3.2.1](#S3.SS2.SSS1 "3.2.1 Intuition ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")
that a large $`r^{*}(y^{+}|x)-r^{*}(y^{-}|x)`$ should correspond to a
large $`\Delta(y^{-},y^{+};x)`$. Using
([4](#S2.E4 "In 2.2 Direct Preference Optimization (DPO) ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")),
one can define $`\Delta`$ as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Delta_{\text{naive}}=r(y^{+}|x)-r(y^{-}|x)=\beta\left(\log\frac{\pi(y^{+}|x)}{\pi_{\text{ref}}(y^{+}|x)}-\log\frac{\pi(y^{-}|x)}{\pi_{\text{ref}}(y^{-}|x)}\right).
``` |  | (10) |

Substituting this into the DPO objective
([5](#S2.E5 "In 2.2 Direct Preference Optimization (DPO) ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")),
we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathbb{E}_{(x,y^{+},y^{-})\sim\mathcal{D}}\log\sigma\left(\beta\log\frac{\pi(y^{+}|x)}{\pi_{\text{ref}}(y^{+}|x)}-\beta\log\frac{\pi(y^{-}|x)}{\pi_{\text{ref}}(y^{-}|x)}-\lambda\Delta_{\text{naive}}(y^{-},y^{+};x)\right)`$ |  |  |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\mathbb{E}_{(x,y^{+},y^{-})\sim\mathcal{D}}\log\sigma\left((\beta-\lambda\beta)\log\frac{\pi(y^{+}|x)}{\pi_{\text{ref}}(y^{+}|x)}-(\beta-\lambda\beta)\log\frac{\pi(y^{-}|x)}{\pi_{\text{ref}}(y^{-}|x)}\right).`$ |  |

However, this is the same as the original DPO objective except for a
scaling of the regularization parameter $`\beta`$, and thus is not
useful.

To alleviate this problem, our idea is to first improve the LLM
performance by concatenating the query $`x`$ with a prompt $`p`$, as
$`p\oplus x`$, where $`\oplus`$ denotes concatenation. With
([4](#S2.E4 "In 2.2 Direct Preference Optimization (DPO) ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"))
the reward with this prompt-augmented query is:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
r(y|p\oplus x)=\beta\log\frac{\pi(y|p\oplus x)}{\pi_{\text{ref}}(y|p\oplus x)}+c(x).
``` |  | (11) |

With a good prompt, this $`r`$ is expected to be a good proxy of
$`r^{*}`$. Specifically, we use the following prompt $`p`$.

Please generate a response with a usefulness rating of 100 out of 100
for the following query. Note that the response should be harmless. The
term 100 indicates the level of usefulness, where 100 is the maximum and
1 is the minimum. Query:

We assume that adding this prompt does not change the preference between
the positive and negative responses ($`y^{+}`$ and $`y^{-}`$).

###### Assumption 3.2.

For a given query $`x`$, if $`y^{+}\succ y^{-}`$, we still have
$`y^{+}\succ y^{-}`$ with the prompt-augmented query $`p\oplus x`$.

Analogous to
([10](#S3.E10 "In 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")),
we consider the following refinement function:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Delta_{\pi}\left(y^{-},y^{+};x\right)\equiv\beta\log\frac{\pi(y^{+}|p\oplus x)\pi_{\text{ref}}(y^{-}|p\oplus x)}{\pi_{\text{ref}}(y^{+}|p\oplus x)\pi(y^{-}|p\oplus x)}.
``` |  | (12) |

Note that we have added subscript $`\pi`$ to explicitly indicate the
dependence of $`\Delta`$ on $`\pi`$. Obviously, when putting this
$`\Delta_{\pi}`$ into the DPO objective
([5](#S2.E5 "In 2.2 Direct Preference Optimization (DPO) ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")),
it does not suffer from the same problem as the
$`\Delta_{\text{naive}}`$ discussed earlier.

The following Proposition shows that $`\Delta_{\pi}`$ in
([12](#S3.E12 "In 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"))
satisfies two important properties. First,
$`\Delta_{\pi}(y^{-},y^{+};x)`$ can be measured relative to the optimal
response $`y^{*}`$, which allows to represent
$`\Delta_{\pi}(y^{-},y^{+};x)`$ in terms of
$`\Delta_{\pi}(y^{-},y^{*};x)`$ and $`\Delta_{\pi}(y^{+},y^{*};x)`$.
Second, the positive response (which has a higher true reward value) is
“closer” to $`y^{*}`$ than the negative response, and vice versa. All
the proofs are in
Appendix [A](#A1 "Appendix A Proofs ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement").

###### Proposition 3.3.

With Assumptions
[3.1](#S3.Thmtheorem1 "Assumption 3.1. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")
and
[3.2](#S3.Thmtheorem2 "Assumption 3.2. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"),
we have (i)
$`\Delta_{\pi}(y^{-},y^{+};x)=\Delta_{\pi}(y^{-},y^{*};x)-\Delta_{\pi}(y^{+},y^{*};x)`$,
where $`y^{*}`$ is the optimal $`y`$ for the given $`x`$; (ii) For any
tuple $`(x,y^{+},y^{-})`$,
$`r^{*}(y^{+}|x)>r^{*}(y^{-}|x)\Leftrightarrow\Delta_{\pi}(y^{+},y^{*};x)<\Delta_{\pi}(y^{-},y^{*};x)`$.

The following Corollary shows that this $`\Delta_{\pi}(y^{-},y^{+};x)`$
satisfies the desired property in
Section [3.2.1](#S3.SS2.SSS1 "3.2.1 Intuition ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"),
namely that a larger difference $`r^{*}(y^{+}|x)-r^{*}(y^{-}|x)`$ in the
true reward values between the positive and negative responses
corresponds to a larger $`\Delta_{\pi}(y^{-},y^{+};x)`$.

###### Corollary 3.3.1.

For any $`(x,y_{i}^{+},y_{i}^{-})`$ and $`(x,y_{j}^{+},y_{j}^{-})`$, if
$`r^{*}(y_{i}^{+}|x)>r^{*}(y_{j}^{+}|x)`$, and
$`r^{*}(y_{i}^{-}|x)<r^{*}(y_{j}^{-}|x)`$ we have
$`r^{*}(y_{i}^{+}|x)-r^{*}(y_{i}^{-}|x)>r^{*}(y_{j}^{+}|x)-r^{*}(y_{j}^{-}|x)\Leftrightarrow\Delta_{\pi}(y_{i}^{-},y_{i}^{+};x)>\Delta_{\pi}(y_{j}^{-},y_{j}^{+};x)`$.

### 3.3 Integration with DPO and IPO

#### 3.3.1 Integration with DPO

First, we show how to integrate the proposed refinement into DPO.
Substituting
([4](#S2.E4 "In 2.2 Direct Preference Optimization (DPO) ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"))
and
([12](#S3.E12 "In 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"))
into
([9](#S3.E9 "In 3.2.1 Intuition ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")),
we obtain:

|  |  |  |  |  |  |
|----|----|----|----|----|----|
|  | $`\displaystyle\max_{\pi}\mathbb{E}_{(x,y^{+},y^{-})\sim\mathcal{D}}\log\sigma(r(y^{+}|x)-r(y^{-}|x)-\lambda\Delta_{\pi}(y^{-},y^{+};x))`$ |  |  |  | (13) |

## 4 Experiments

### 4.1 Setup

Datasets. We evaluate the effectiveness of the proposed methods on three
widely-used benchmark datasets: (i) MT-Bench \[[52](#bib.bib52)\], which
is a multi-turn question set on writing, roleplay, extraction,
reasoning, math, coding, knowledge I (STEM), and knowledge II
(humanities/social science). (ii) Vicuna-Bench \[[12](#bib.bib12)\],
which is a single-turn question set on writing, roleplay, generic,
fermi, counterfactual, coding, math, and knowledge. (iii) Open-LLM
leader-board \[[6](#bib.bib6)\], which includes (a) commonsense
reasoning: Arc \[[14](#bib.bib14)\], HellaSwag \[[48](#bib.bib48)\],
WinoGrande \[[36](#bib.bib36)\]; (b) multi-task language understanding:
MMLU \[[20](#bib.bib20)\]; (c) human falsehood mimic: TruthfulQA
\[[28](#bib.bib28)\]; and (d) math problem solving: GSM8k
\[[15](#bib.bib15)\]. Table
[1](#S4.T1 "Table 1 ‣ 4.1 Setup ‣ 4 Experiments ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")
shows more information on the Hugging-Face Open LLM Leaderboard
datasets.

|--------------------|----------|------------|------------|-------|-----------|------|
|                    | Arc      | TruthfulQA | Winogrande | GSM8k | HellaSwag | MMLU |
| \# few-shot        | 25       | 0          | 5          | 5     | 10        | 5    |

Setup for MT-Bench and Vicuna-Bench. As in \[[35](#bib.bib35)\], we use
Pythia 2.8B \[[7](#bib.bib7)\], a pretrained LLM without supervised
fine-tuning and RLHF, as the backbone model. Following
\[[3](#bib.bib3)\], we first conduct supervised fine tuning (SFT) using
the HH-RLHF dataset \[[5](#bib.bib5)\], which is human preference data
on helpfulness and harmlessness based on positive feedbacks. We then
perform direct alignment using the HH-RLHF dataset on the SFT model.
Finally, we follow \[[35](#bib.bib35)\] to use GPT-4 \[[1](#bib.bib1)\]
as a judge to evaluate the testing performance of the direct alignment
trained model. For performance evaluation, we use the win-rate,
tie-rate, and lose rate as in \[[44](#bib.bib44)\].

Setup for Open-LLM Leader-board. Following \[[43](#bib.bib43);
[10](#bib.bib10)\], we use zephyr-7b-sft-full²² 2
[https://huggingface.co/alignment-handbook/zephyr-7b-sft-full](https://huggingface.co/alignment-handbook/zephyr-7b-sft-full),
a supervised fine-tuned version of Mistral 7B \[[24](#bib.bib24)\], as
the basic model. We directly perform direct alignment using a
large-scale diverse preference dataset Ultra-feedback
\[[16](#bib.bib16)\]. The fine-tuned model is then evaluated on the
testing benchmarks via the platform \[[19](#bib.bib19)\].

Following \[[44](#bib.bib44)\], we use three performance metrics:

i\) Average marginal:
$`\frac{1}{N}\sum^{N}_{i=1}\log\frac{\pi\left(y_{i}^{+}\mid x_{i}\right)}{\pi_{\mathrm{ref}}\left(y_{i}^{+}\mid x_{i}\right)}-\log\frac{\pi\left(y_{i}^{-}\mid x_{i}\right)}{\pi_{\mathrm{ref}}\left(y_{i}^{-}\mid x_{i}\right)}`$,
which measures the gap between positive and negative responses.

\(ii\) Accuracy:
$`\frac{1}{N}\sum^{N}_{i=1}\mathbbm{1}\left(\log\frac{\pi(y_{i}^{+}\mid x_{i})}{\pi_{\mathrm{ref}}(y_{i}^{+}\mid x_{i})}>\log\frac{\pi(y_{i}^{-}\mid x_{i})}{\pi_{\mathrm{ref}}(y_{i}^{-}\mid x_{i})}\right)`$,
which measures the number of tuples with the reward of a positive
response larger than that of the negative response. Here,
$`\mathbbm{1}(\cdot)`$ returns 1 when the argument holds and 0
otherwise.

\(iii\) Accuracy defined on the prompt-augmented tuples:
$`\frac{1}{N}\sum^{N}_{i=1}\mathbbm{1}\left(\log\frac{\pi(y_{i}^{+}\mid p\oplus x_{i})}{\pi_{\mathrm{ref}}(y_{i}^{+}\mid p\oplus x_{i})}>\right.`$
$`\left.\log\frac{\pi(y_{i}^{-}\mid p\oplus x_{i})}{\pi_{\mathrm{ref}}(y_{i}^{-}\mid p\oplus x_{i})}\right)`$,
which measures the accuracy for tuples with input augmented by the
prompt.

Baselines and Implmentation Details. We choose two widely-adopted direct
alignment baselines: (i) DPO \[[35](#bib.bib35)\], and (ii) IPO
\[[4](#bib.bib4)\]. Following \[[35](#bib.bib35)\], $`\beta`$ is set to
0.1 for DPO and IPO. We also set $`\beta=0.1`$ for the proposed Sr-DPO
and Sr-IPO for fair comparison. We select the optimal $`\lambda`$ from
$`\{0.1,0.3,0.5,1\}`$ on the first 50 tuples from the HH-RLHF testing
dataset. For both the HH-RLHF and UltraChat datasets, following
\[[35](#bib.bib35)\], the learning rate is $`5\times 10^{-7}`$, the
optimizer is RMSprop \[[21](#bib.bib21)\], the batch size is 64, and we
also use gradient normalization to help training. The maximal input
token size in training is 512. All experiments are performed on 8 A100
GPUs, and we use fully sharded data parallel \[[51](#bib.bib51)\] for
distributed training.

### 4.4 Correlation between Marginal and Score

Recall that GPT-4 is used as the evaluator. For each instance $`x_{i}`$,
we define the score difference between the corresponding positive
$`y_{i}^{+}`$ and negative $`y_{i}^{-}`$ responses as
$`s^{+}(x_{i})-s^{-}(x_{i})`$, where $`s^{+}(x_{i})`$ (resp.
$`s^{-}(x_{i})`$) is GPT-4’s evaluation score (0-5) of $`y_{i}^{+}`$
(resp. $`y_{i}^{-}`$). Inspired by \[[25](#bib.bib25)\], which uses
correlation to measure the agreements between GPT-4 and testing LLMs,
here we compute the correlation between the marginal
$`\log\frac{\pi\left(y_{i}^{+}\mid x_{i}\right)}{\pi_{\mathrm{ref}}\left(y_{i}^{+}\mid x_{i}\right)}-\log\frac{\pi\left(y_{i}^{-}\mid x_{i}\right)}{\pi_{\mathrm{ref}}\left(y_{i}^{-}\mid x_{i}\right)}`$
and score difference $`s^{+}(x_{i})-s^{-}(x_{i})`$ over 200 random
tuples from the Ultrafeedback-binarized-preferences dataset³³ 3
[https://huggingface.co/datasets/argilla/ultrafeedback-binarized-preferences](https://huggingface.co/datasets/argilla/ultrafeedback-binarized-preferences)
(which already contains $`s^{+}(x)`$’s and $`s^{-}(x)`$’s). In
particular, we use (i) Pearson’s correlation \[[37](#bib.bib37)\], which
measures linear relationships; (ii) Spearman’s rank
correlation \[[38](#bib.bib38)\], which measures monotonic
relationships; and (iii) Kendall’s Tau \[[32](#bib.bib32)\], which
evaluates the strength and direction of associations.

Table
[4](#S4.T4 "Table 4 ‣ 4.5 Training Time ‣ 4 Experiments ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")
shows the correlation. As can be seen, Sr-DPO (resp. Sr-IPO) exhibits
higher correlation values compared to DPO (resp. IPO). This suggests
that Sr-DPO and Sr-IPO can evaluate the qualities of the positive and
negative responses more accurately.

## 5 Conclusion

In this paper, we find that the widely adopted DPO method falls short by
not accounting for the relative qualities of positive and negative
samples, which can lead to sub-optimal training outcomes. To address
this issue, we propose leveraging the intrinsic knowledge within LLMs to
refine the loss function. Our main contributions are three-fold: 1) We
utilize the knowledge of LLMs to create a refinement function that
effectively estimates the quality of both positive and negative
responses. 2) We demonstrate that under mild assumptions, the refinement
function can enable the loss function to self-refine, leading to better
alignment with human preferences. 3) Based on the refinement function,
we develop two practical algorithms that enhance the training process.
Experimental results from various evaluators indicate that the proposed
self-refined methods significantly improve the performance of fine-tuned
models compared to existing approaches.

One limitation of our work is that we do not combine it with online
policy-based direct alignment \[[41](#bib.bib41)\]. We will investigate
this in our future work.

## 6 Broader Impacts

Our work falls under one of the RLHF frameworks, and thus shares similar
social impacts, both positive and negative. On the positive side, our
method can help LLMs avoid generating harmful or unhelpful results by
aligning with human feedback. However, conversely, our method also has
the potential to enable LLMs to generate harmful or unhelpful results if
it is used to align with malicious preferences.

## Appendix A Proofs

### A.1 Proof of Proposition [3.3](#S3.Thmtheorem3 "Proposition 3.3. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")

###### Proof.

\(i\) First property: By directly substituting
$`\Delta_{\pi}(y^{-},y^{*};x)-\Delta_{\pi}(y^{+},y^{*};x)`$ into the
definition of $`\Delta`$ in
([12](#S3.E12 "In 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")),
we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\Delta_{\pi}(y^{-},y^{*};x)-\Delta_{\pi}(y^{+},y^{*};x)`$ | $`\displaystyle=`$ | $`\displaystyle\beta\left(\log\frac{\pi(y^{+}|p\oplus x)}{\pi_{0}(y^{+}|p\oplus x)}-\log\frac{\pi(y^{-}|p\oplus x)}{\pi_{0}(y^{-}|p\oplus x)}\right)`$ |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\beta\log\frac{\pi(y^{+}|p\oplus x)\pi_{0}(y^{-}|p\oplus x)}{\pi(y^{-}|p\oplus x)\pi_{0}(y^{+}|p\oplus x)}`$ |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\Delta_{\pi}\left(y^{-},y^{+};x\right).`$ |  |

\(ii\) Second property: From assumption
[3.1](#S3.Thmtheorem1 "Assumption 3.1. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"),
we have:
$`r\left(y^{+}|x\right)>r\left(y^{-}|x\right),\forall(x,y^{+},y-)`$ with
$`y^{+}\succ y^{-}`$. From
([4](#S2.E4 "In 2.2 Direct Preference Optimization (DPO) ‣ 2 Preliminaries ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")),

|  |  |  |
|----|----|----|
|  |
``` math
r(y^{+}|x)>r\left(y^{-}|x\right)\Leftrightarrow\log\frac{\pi\left(y^{+}\mid x\right)}{\pi_{0}\left(y^{+}\mid x\right)}>\log\frac{\pi\left(y^{-}\mid x\right)}{\pi_{0}\left(y^{-}\mid x\right)}.
``` |  |

From Assumption
[3.2](#S3.Thmtheorem2 "Assumption 3.2. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"),
for the prompt-augmented query $`p\oplus x`$, we still have
$`y^{+}\succ y^{-}`$. By using Assumption
[3.1](#S3.Thmtheorem1 "Assumption 3.1. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")
on $`(p\oplus x,y^{+},y^{-})`$, we have:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\displaystyle\log\frac{\pi(y^{+}|p\oplus x)}{\pi_{0}(y^{+}|p\oplus x)}>\log\frac{\pi(y^{-}|p\oplus x)}{\pi_{0}(y^{-}|p\oplus x)}.
``` |  | (16) |

Thus, from the first property,

|  |  |  |
|----|----|----|
|  |
``` math
\Delta_{\pi}(y^{+},y^{*};x)-\Delta_{\pi}(y^{-},y^{*};x)=-\Delta_{\pi}\left(y^{-},y^{+};x\right)=-\beta\log\frac{\pi(y^{+}|p\oplus x)\pi_{0}(y^{-}|p\oplus x)}{\pi_{0}(y^{+}|p\oplus x)\pi(y^{-}|p\oplus x)}<0
``` |  |

because of
([16](#A1.E16 "In Proof. ‣ A.1 Proof of Proposition ‣ Appendix A Proofs ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")),
and so $`\Delta_{\pi}(y^{+},y^{*};x)<\Delta_{\pi}(y^{-},y^{*};x)`$.
Thus,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
y^{+}\succ y^{-}\Leftrightarrow\Delta_{\pi}\left(y^{+},y^{*};x\right)<\Delta_{\pi}\left(y^{-},y^{*};x\right).
``` |  | (17) |

Since $`y^{+}\succ y^{-}\Leftrightarrow r^{*}(y^{+}|x)>r^{*}(y^{-}|x)`$.
We obtain that
$`r^{*}(y^{+}|x)>r^{*}(y^{-}|x)\Leftrightarrow\Delta_{\pi}\left(y^{+},y^{*};x\right)<\Delta_{\pi}\left(y^{-},y^{*};x\right)`$.
∎

### A.2 Proof of Corollary [3.3.1](#S3.Thmtheorem3.Thmcorollary1 "Corollary 3.3.1. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")

###### Proof.

Using property (ii) in
Proposition [3.3](#S3.Thmtheorem3 "Proposition 3.3. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")
on the assumption $`r^{*}(y_{i}^{+}|x)>r^{*}(y_{j}^{+}|x)`$ in
Corollary [3.3.1](#S3.Thmtheorem3.Thmcorollary1 "Corollary 3.3.1. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement"),

|  |  |  |  |
|----|----|----|----|
|  |
``` math

Similarly, using this on the assumption in
Corollary [3.3.1](#S3.Thmtheorem3.Thmcorollary1 "Corollary 3.3.1. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement")
that $`r^{*}(y_{i}^{-}|x)<r^{*}(y_{j}^{-}|x)`$, we have

|  |  |  |  |
|----|----|----|----|
|  |

Adding these two together, we obtain

|  |  |  |  |  |
|----|----|----|----|----|

|  |  | $`\displaystyle\Leftrightarrow`$ | $`\displaystyle\Delta_{\pi}(y_{i}^{-},y_{i}^{+};x)>\Delta_{\pi}(y_{j}^{-},y_{j}^{+};x),`$ |  |

due to property (i) of
Proposition [3.3](#S3.Thmtheorem3 "Proposition 3.3. ‣ 3.2.2 Implementing Δ via Prompting ‣ 3.2 Refining the Reward Difference between Positive and Negative Responses ‣ 3 Proposed Method ‣ Direct Alignment of Language Models via Quality-Aware Self-Refinement").

|  |  |  |

|  |  |  |

``` |  |

After simplification, we have:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{\pi(y^{+}|x)}{\pi(y^{-}|x)}`$ | $`\displaystyle=`$ | $`\displaystyle\frac{\pi_{\text{ref}}(y^{+}|x)}{\pi_{\text{ref}}(y^{-}|x)}\exp\left(\beta^{-1}[\mathbb{E}_{y^{+}\sim\pi_{\text{ref}}(\cdot|x)}p(y^{+}\succ\pi_{\text{ref}}|x)-\mathbb{E}_{y^{-}\sim\pi_{\text{ref}}(\cdot|x)}p(y^{-}\succ\pi_{\text{ref}}|x)]\right.`$ |  |

$`r(y^{+}|p\oplus x)-r(y^{-}|p\oplus x)=\Delta_{\pi}(y^{-},y^{+};x)`$.
After some simplifications, we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\log\frac{\pi(y^{+}|x)}{\pi_{\text{ref}}(y^{+}|x)}-\log\frac{\pi(y^{-}|x)}{\pi_{\text{ref}}(y^{-}|x)}`$ |  |  |  |
|  |  | $`\displaystyle=`$ | $`\displaystyle\frac{1}{\beta}\left[\mathbb{E}_{y^{+}\sim\pi_{\text{ref}}(\cdot|x)}p(y^{+}\succ\pi_{\text{ref}}|x)-\mathbb{E}_{y^{-}\sim\pi_{\text{ref}}(\cdot|x)}p(y^{-}\succ\pi_{\text{ref}}|x)\right]+\lambda\Delta_{\pi}(y^{-},y^{+};x).`$ |  |

$`\mathbb{E}_{y^{+}\sim\pi_{\text{ref}}(\cdot|x)}p(y^{+}\succ\pi_{\text{ref}}|x)-\mathbb{E}_{y^{-}\sim\pi_{\text{ref}}(\cdot|x)}p(y^{-}\succ\pi_{\text{ref}}|x)=\frac{1}{2}`$
\[[4](#bib.bib4)\], after taking expectations of both sides, we obtain

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\log\frac{\pi(y^{+}|x)}{\pi_{\text{ref}}(y^{+}|x)}-\log\frac{\pi(y^{-}|x)}{\pi_{\text{ref}}(y^{-}|x)}=\frac{1}{2\beta}+\lambda\Delta_{\pi}(y^{-},y^{+};x).`$ |  | (20) |
````
