# Multi-Token Prediction Done Right

Jayden Teoh

MIT

###### Abstract

Multi-Token Prediction (MTP) is now a common ingredient in
language-model pre-training, as it improves downstream performance and
enables faster inference through speculative decoding. We identify a
flaw in standard MTP training, in which a residual component of the MTP
gradient interferes with both next-token and multi-token learning,
increasingly so with scale. Specifically, the MTP cross-entropy gradient
can be decomposed exactly into a KL self-distillation term that pulls
each MTP head toward the model’s own next-token prediction (NTP)
distribution and improves speculative decoding, and a residual that has
a low signal-to-noise ratio and buries the useful KL signal. We
introduce the KL gradient–recovery trick: when two distributions share a
linear output head, the gradient of their KL divergence can be recovered
exactly by combining their cross-entropy gradients through
_straight-through gradient routing_. Unlike minimizing the KL directly,
this trick requires no vocabulary-sized logit matrices and is compatible
with standard fused cross-entropy kernels. This enables Soft Multi-Token
Prediction (Soft-MTP), a _one-line code change_ to MTP that removes the
noisy residual and backpropagates only the KL self-distillation signal
by reusing the existing NTP and MTP cross-entropy computations. Soft-MTP
supports both DeepSeek- and Meta-style MTP, adds no parameters, and
incurs no measurable overhead. From 167M to 1.2B parameters, Soft-MTP
improves over standard MTP with lower NTP perplexity, faster speculative
decoding and higher zero-shot accuracy at every scale, lower MTP
perplexity from 689M onward, and stronger math and code reasoning after
fine-tuning at 1.2B. Soft-MTP also matches, if not exceeds, direct KL
divergence minimization on most metrics. Soft-MTP is, in effect, a free
lunch for MTP optimization. Our code can be found at
[https://github.com/JaydenTeoh/Soft-MTP](https://github.com/JaydenTeoh/Soft-MTP).

## 1 Introduction

Next-token prediction (NTP) has become a general recipe for training
large language models (LLMs), yielding models with remarkable
capabilities across a wide range of tasks ([Radford et al.,
2019](#bib.bib1)). One might argue that the NTP objective is
sufficient—any distribution over token sequences can, in theory, be
factorized autoregressively and modeled by a sufficiently expressive
next-token predictor ([Sutskever, 2023](#bib.bib4)).

Yet, Multi-Token Prediction (MTP) ([Stern et al., 2018](#bib.bib60); [Qi
et al., 2020](#bib.bib8); [Gloeckle et al., 2024](#bib.bib54)), which
trains a model to predict multiple future tokens, has now been widely
adopted in modern LLM training, including in DeepSeek-V3/4
([DeepSeek-AI, 2024](#bib.bib9); [DeepSeek-AI, 2026b](#bib.bib19)),
Nemotron 3 ([NVIDIA, 2025](#bib.bib21)), GLM-5 ([GLM-5-Team,
2026](#bib.bib27)), and Kimi K3 ([Kimi Team, 2026](#bib.bib25)), just to
name a few. MTP offers two main advantages over NTP—better model
performance and more efficient inference. As a learning objective, MTP
has been shown to alleviate the myopic nature of the next-token
supervision ([Bachmann and Nagarajan, 2024](#bib.bib53); [Gloeckle et
al., 2024](#bib.bib54); [Nagarajan et al., 2025](#bib.bib55); [Huang et
al., 2026](#bib.bib44)), leading to stronger downstream performance on
long-horizon domains such as mathematics and code. More importantly, MTP
heads can also be used for speculative decoding ([Leviathan et al.,
2022](#bib.bib58); [Chen et al., 2023](#bib.bib59)) to accelerate model
inference.

Despite the wide adoption of MTP, we still understand little about how
it interacts with next-token prediction and which objective is best for
training the MTP heads. During speculative decoding, a token drafted by
MTP is accepted only if it agrees with the model’s own next-token
prediction. If the goal is to improve speculative decoding, shouldn’t we
directly train the model’s MTP heads to match its own NTP distribution
via self-distillation? Recent work does exactly this ([Teoh et al.,
2025](#bib.bib5); [Zhao et al., 2026a](#bib.bib33)), but naïvely
minimizing an explicit KL divergence requires materializing
vocabulary-sized logit tensors for both the teacher and the student,
which is costly in memory and incompatible with the standard fused
cross-entropy kernels used in modern pre-training ([Hsu et al.,
2025](#bib.bib70); [Wijmans et al., 2025](#bib.bib71)). In practice,
frontier models still train their MTP heads with standard cross-entropy
against the data.

In this paper, we show that the standard MTP cross-entropy gradient
already contains this self-distillation signal. The MTP gradient
decomposes exactly into a KL term
$`{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$, which pulls the
MTP head toward the model’s own next-token distribution, and a residual
$`{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$, which is the NTP
cross-entropy gradient against the data (see
[Section 4](#S4 "4 Decomposing the MTP Gradient ‣ Multi-Token Prediction Done Right")).
We provide evidence that this residual in the MTP loss gradient has a
low signal-to-noise ratio (SNR) and interferes with both NTP and MTP
learning, especially as scale increases. We then introduce the _KL
gradient–recovery trick_: when two distributions share a linear output
head, the gradient of their KL divergence can be recovered exactly from
their cross-entropy gradients through _straight-through gradient
routing_ ([Bengio et al., 2013](#bib.bib29); [van den Oord et al.,
2017](#bib.bib30)), without explicitly computing the KL or materializing
any logits. This trick enables _Soft Multi-Token Prediction (Soft-MTP)_,
which removes the residual and sends only the useful KL
self-distillation gradient through the MTP heads and the shared model
trunk, with a one-line code change (see
[Figure 1](#S0.F1 "In Multi-Token Prediction Done Right")).

From 167M to 1.2B parameters, Soft-MTP improves over standard MTP with
lower NTP perplexity, faster self-speculative decoding in every domain
we test, and higher zero-shot accuracy at every scale, as well as
stronger code and math reasoning after fine-tuning. It also reaches
lower MTP loss from 689M parameters onward. Soft-MTP matches or exceeds
the costly explicit KL self-distillation on most metrics, at no extra
cost over standard MTP. Soft-MTP supports both DeepSeek-style
([DeepSeek-AI, 2024](#bib.bib9)) and Meta-style ([Gloeckle et al.,
2024](#bib.bib54)) MTP architectures, adds no parameters, has negligible
overhead, and remains compatible with fused cross-entropy kernels and
the parallelism used in frontier pre-training. Soft-MTP is, in effect, a
free lunch for MTP optimization.

## 2 Related Work

#### Multi-token prediction.

Predicting several future tokens dates back to blockwise parallel
decoding ([Stern et al., 2018](#bib.bib60)) and ProphetNet ([Qi et al.,
2020](#bib.bib8)). [Gloeckle et al. (2024)](#bib.bib54) showed that MTP
with parallel output heads improves large language models, especially on
code, and DeepSeek-V3 ([DeepSeek-AI, 2024](#bib.bib9)) brought MTP to
frontier-scale pre-training and introduced the sequential MTP modules
now used by many frontier models ([DeepSeek-AI, 2024](#bib.bib9); [Qwen
Team, 2025](#bib.bib18); [LongCat, 2025](#bib.bib20); [GLM Team,
2025](#bib.bib26); [Ling Team, 2025](#bib.bib28); [NVIDIA,
2025](#bib.bib21); [Xiaomi, 2026](#bib.bib23); [GLM-5-Team,
2026](#bib.bib27); [DeepSeek-AI, 2026b](#bib.bib19); [MiniMax,
2026](#bib.bib24); [Kimi Team, 2026](#bib.bib25)). A line of work argues
that MTP helps to counter the myopia of next-token supervision
([Bachmann and Nagarajan, 2024](#bib.bib53); [Gloeckle et al.,
2024](#bib.bib54); [Nagarajan et al., 2025](#bib.bib55); [Huang et al.,
2026](#bib.bib44)). Recent works also go beyond MTP with richer
objectives ([Hu et al., 2025](#bib.bib43); [Ahn et al.,
2025](#bib.bib52); [Liu et al., 2025b](#bib.bib45); [Teoh et al.,
2025](#bib.bib5); [Mahajan et al., 2026](#bib.bib6); [Zuhri et al.,
2026](#bib.bib7)).

#### MTP for speculative decoding.

Speculative decoding drafts several tokens cheaply and verifies them in
parallel using the more expensive target model ([Leviathan et al.,
2022](#bib.bib58); [Chen et al., 2023](#bib.bib59)). MTP heads trained
during pre-training can serve as drafters for speculative decoding. This
is especially useful for accelerating reinforcement learning
post-training, where generating rollouts is often the main bottleneck
([Xiaomi, 2026](#bib.bib23); [Li et al., 2026a](#bib.bib68); [Iso et
al., 2026](#bib.bib72)). Recent work trains drafters to match the
verifier more directly, by minimizing the TV distance ([Samarin et al.,
2026](#bib.bib69); [Li et al., 2026a](#bib.bib68)), and Nemotron 3 Ultra
([NVIDIA, 2026](#bib.bib22)) introduces an _MTP Boosting_ post-training
phase that aligns the MTP heads with the NTP distribution via a
temperature-scaled forward KL objective. Soft-MTP pursues the same goal
during pre-training, at no extra cost over the standard MTP objective.

#### Self-distillation for MTP.

Recent works train MTP heads to match the NTP distribution. They either
compute the KL explicitly ([Teoh et al., 2025](#bib.bib5)), which
requires materializing the teacher’s and the student’s distributions
over the full vocabulary, or approximate it with top-$`k`$ logits ([Zhao
et al., 2026a](#bib.bib33)) or argmax predictions ([Kirchenbauer et al.,
2026](#bib.bib32)). [Chang and gpt-5.5-xhigh (2026)](#bib.bib31) shows a
cool trick to reduce the cost of full-vocabulary distillation by caching
the teacher’s contribution to the KL gradient. However, their method
still requires materializing the teacher’s full-vocabulary distribution,
and it requires the student’s output head to be frozen. We show that
standard MTP already contains the self-distillation gradient, and that
our KL gradient–recovery trick recovers it exactly from the existing
cross-entropy gradients. Soft-MTP therefore incurs no measurable
overhead beyond that of standard MTP and remains compatible with fused
cross-entropy kernels ([Hsu et al., 2025](#bib.bib70); [Wijmans et al.,
2025](#bib.bib71)).

## 3 Background

Let $`x_{1:T}`$ denote a sequence of tokens, where each token is
represented as a one-hot vector $`x_{t}\in\{0,1\}^{V}`$ over a
vocabulary of size $`V`$. A model trunk with parameters $`\theta`$ maps
each prefix sequence $`x_{1:t}`$ to a hidden state
$`\mathbf{h}_{t}^{(0)}\in\mathbb{R}^{d}`$. A linear output head
$`W_{\theta}\in\mathbb{R}^{V\times d}`$ (also commonly called the _“LM
head”_) projects these hidden state representations to logits, followed
by a softmax function, to obtain the next-token probability
distribution:

|     |                                                                                            |     |
| --- | ------------------------------------------------------------------------------------------ | --- |
|     | $`\displaystyle p_{t}^{(0)}=\mathrm{softmax}\left(W_{\theta}\mathbf{h}_{t}^{(0)}\right).`$ |     |

The standard next-token cross-entropy loss is

|     |                                                                                                                                                   |     |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\mathcal{L}_{\text{NTP}}=\sum^{T-1}_{t=1}\mathrm{CE}\left(x_{t+1},p_{t}^{(0)}\right)=-\sum^{T-1}_{t=1}\log p_{t}^{(0)}(x_{t+1}).`$ |     |

### 3.1 Multi-Token Prediction

Multi-Token Prediction (MTP) extends NTP with $`K`$ token prediction
heads to predict $`K`$ additional tokens. The $`k`$-th MTP head produces
a hidden state $`\mathbf{h}_{t}^{(k)}`$ at each position $`t`$, where
$`k\in\{1,\dots,K\}`$. Following typical implementation, the linear
output head $`W_{\theta}`$ is _shared_ with the MTP heads to generate

|     |                                                                                            |     |
| --- | ------------------------------------------------------------------------------------------ | --- |
|     | $`\displaystyle p_{t}^{(k)}=\mathrm{softmax}\left(W_{\theta}\mathbf{h}_{t}^{(k)}\right),`$ |     |

where $`p_{t}^{(k)}`$ predicts the token distribution over
$`x_{t+k+1}`$. The $`k`$-th MTP loss is then given by

|     |                                                                                                                                                                 |     |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\mathcal{L}_{\text{MTP}}^{(k)}=\sum^{T-k-1}_{t=1}\mathrm{CE}\left(x_{t+k+1},p_{t}^{(k)}\right)=-\sum^{T-k-1}_{t=1}\log p_{t}^{(k)}(x_{t+k+1}).`$ |     |

The overall MTP objective is

|     |                                                                                                                                                      |     |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\mathcal{L}_{\text{MTP}}=\mathcal{L}_{\text{NTP}}+\lambda_{\text{MTP}}\cdot\frac{1}{K}\sum_{k=1}^{K}\mathcal{L}_{\text{MTP}}^{(k)},`$ |     |

where $`\lambda_{\text{MTP}}>0`$ is a scalar coefficient. For clarity of
subsequent derivations, we write each loss as a sum over positions.
Implementations typically average each loss over its own number of
targets instead; we account for the resulting rescaling in
[Section B.5](#A2.SS5 "B.5 Loss weighting and per-head normalization ‣ Appendix B Extra Derivations for MTP Gradients ‣ Multi-Token Prediction Done Right")
and show the implementation in
[Algorithm 1](#alg1 "In Appendix A Full Soft-MTP PyTorch Implementation ‣ Multi-Token Prediction Done Right").

## 4 Decomposing the MTP Gradient

![Refer to caption](2610.38331v1/images/pos_aligned_ntp.png)

Figure 2: Illustration of position-aligned NTP distributions.

Note that the analysis that follows is agnostic to the choice of MTP
architecture, be it parallel ([Gloeckle et al., 2024](#bib.bib54)) or
sequential ([DeepSeek-AI, 2024](#bib.bib9)). Consider the $`k`$-th MTP
prediction for position $`t`$:

|     |                                                                                            |     |
| --- | ------------------------------------------------------------------------------------------ | --- |
|     | $`\displaystyle p_{t}^{(k)}=\mathrm{softmax}\left(W_{\theta}\mathbf{h}_{t}^{(k)}\right).`$ |     |

This distribution predicts $`x_{t+k+1}`$. The _position-aligned_ NTP
distribution that predicts the same token $`x_{t+k+1}`$ is

|     |                                                                                                                     |     |
| --- | ------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle q_{t}^{(k)}\coloneqq p_{t+k}^{(0)}=\mathrm{softmax}\left(W_{\theta}\mathbf{h}_{t+k}^{(0)}\right).`$ |     |

[Figure 2](#S4.F2 "In 4 Decomposing the MTP Gradient ‣ Multi-Token Prediction Done Right")
provides a visualization of the position-aligned NTP distributions for
an MTP model with $`K=2`$.

###### Definition 4.1 (Hard MTP gradient).

We define the _hard MTP gradient_ as the gradient of the standard MTP
cross-entropy loss with respect to the $`k`$-th MTP hidden state:

|     |                                   |                                                                                                      |     |     |
| --- | --------------------------------- | ---------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle g_{\text{hard}}`$ | $`\displaystyle\coloneqq\nabla_{\mathbf{h}_{t}^{(k)}}\mathrm{CE}\left(x_{t+k+1},p_{t}^{(k)}\right)`$ |     |     |
|     |                                   | $`\displaystyle=W_{\theta}^{\intercal}\left(p_{t}^{(k)}-x_{t+k+1}\right).`$                          |     | (1) |

The full derivation can be found in
[Appendix B](#A2 "Appendix B Extra Derivations for MTP Gradients ‣ Multi-Token Prediction Done Right").
The hard MTP gradient can be further decomposed as such

|     |                                                                                                                                                                                                                                                                                                                                                                 |     |     |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle g_{\text{hard}}=W_{\theta}^{\intercal}\left(p_{t}^{(k)}-q_{t}^{(k)}+q_{t}^{(k)}-x_{t+k+1}\right)=\underbrace{W_{\theta}^{\intercal}\left(p_{t}^{(k)}-q_{t}^{(k)}\right)}_{{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}}+\underbrace{W_{\theta}^{\intercal}\left(q_{t}^{(k)}-x_{t+k+1}\right)}_{{\color[rgb]{0.6406,0,0}g_{\text{res}}}},`$ |     | (2) |

where $`{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$ is a soft
_KL self-distillation_ component¹¹ 1 We use the term _soft gradients_ by
analogy to “soft targets” in the knowledge distillation literature. and
$`{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$ is a _residual_ component
corresponding to the cross-entropy gradient with respect to the aligned
NTP hidden state. We denote this residual term using
$`{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$ to distinguish this MTP
gradient decomposition component from $`g_{\text{NTP}}`$, which we
reserve for the actual NTP cross-entropy gradient propagated through the
NTP head into the shared model backbone.

### 4.1 The KL self-distillation component

Now, we explain why
$`{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$ corresponds to the
KL self-distillation gradient. Treating the aligned NTP distribution
$`q_{t}^{(k)}`$ as a _stop-gradient_ teacher distribution, the forward
KL divergence from the aligned NTP distribution to the $`k`$-th MTP
distribution is

|     |                                                                                          |     |
| --- | ---------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle D_{\mathrm{KL}}\left(\textbf{sg}(q_{t}^{(k)})\;\|\;p_{t}^{(k)}\right),`$ |     |

where $`\textbf{sg}(\cdot)`$ denotes the stop-gradient operator. The
gradient of the KL objective with respect to the MTP hidden state is

|     |                                                                                                                                                                                                                               |     |     |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle\nabla_{\mathbf{h}_{t}^{(k)}}D_{\mathrm{KL}}\left(\textbf{sg}(q_{t}^{(k)})\|p_{t}^{(k)}\right)=W_{\theta}^{\intercal}\left(p_{t}^{(k)}-q_{t}^{(k)}\right)={\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}.`$ |     | (3) |

We defer the full derivation to
[Appendix B](#A2 "Appendix B Extra Derivations for MTP Gradients ‣ Multi-Token Prediction Done Right").
Thus, because MTP is supervised by the same underlying data distribution
(just with offset token positions) and a shared linear output head
$`W_{\theta}`$ is used, part of the hard MTP gradient already implicitly
performs self-distillation, i.e., it encourages the MTP head to match
the aligned NTP distribution.

## 5 Soft Multi-Token Prediction

The earlier gradient decomposition leads to the question: how can we
retain the self-distillation component
$`{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$ by removing the
residual component $`{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$ from the
hard MTP gradient propagated through the shared model trunk?

A naïve implementation would explicitly construct the aligned NTP
teacher distribution $`q_{t}^{(k)}`$ and $`k`$-th MTP distribution
$`p_{t}^{(k)}`$, and minimize
$`D_{\mathrm{KL}}\left(\textbf{sg}(q_{t}^{(k)})\;\|\;p_{t}^{(k)}\right)`$
directly in the logit space. However, given that the vocabulary size
$`V`$ is large in modern language models, storing large $`T\times V`$
logit matrices during every MTP prediction is costly in memory usage. It
is also incompatible with standard fused cross-entropy kernels, which
are designed to avoid materializing the entire logit matrix in memory,
and are commonly used in language model pre-training. A custom fused KL
kernel could avoid materializing the logits, but it would have to
recompute the teacher logits that the NTP loss already computes, unless
the NTP cross-entropy and all $`K`$ MTP KL terms were fused into a
single custom kernel.

We instead show that the same representation-space KL gradient can be
recovered _exactly_ from the cross-entropy gradients already computed
during standard MTP training, with no measurable overhead. We term this
novel procedure of recovering a KL gradient from the difference of two
cross-entropy gradients under a shared linear output head as the _KL
gradient–recovery trick_. We also show in
[Section 6.3](#S6.SS3 "6.3 Soft-MTP is more efficient than KL-MTP ‣ 6 Experiments ‣ Multi-Token Prediction Done Right")
that recovering the KL gradient using this trick matches, if not
exceeds, direct KL minimization on most metrics.

### 5.1 KL gradient–recovery trick

For clarity, we exclude the $`\lambda_{\text{MTP}}/{K}`$ loss weighting
from our derivations in this section. Note that our earlier gradient
decomposition and the KL gradient–recovery trick are easily extendable
to include the loss weighting, which we defer to
[Section B.5](#A2.SS5 "B.5 Loss weighting and per-head normalization ‣ Appendix B Extra Derivations for MTP Gradients ‣ Multi-Token Prediction Done Right").

From the decomposition derived in
[Equation 2](#S4.E2 "In Definition 4.1 (Hard MTP gradient). ‣ 4 Decomposing the MTP Gradient ‣ Multi-Token Prediction Done Right"),
our intuition lies in injecting a
$`-{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$ gradient term at the MTP
hidden state, so that only
$`{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$ is propagated
through the MTP heads and subsequently the shared model trunk. We start
by augmenting the NTP hidden states

|                                                                                                                 |                                                                                                        |     |     |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | --- | --- |
|                                                                                                                 | $`\displaystyle\tilde{\mathbf{h}}_{t}=\mathbf{h}_{t}^{(0)}+\underbrace{\sum\_{\begin{subarray}{c}k=1\\ |
| t-k\geq 1\end{subarray}}^{K}\left[\textbf{sg}(\mathbf{h}_{t-k}^{(k)})-\mathbf{h}_{t-k}^{(k)}\right]}\_{=\;0}.`$ |                                                                                                        | (4) |

This resembles the stop-gradient routing used in _straight-through
estimators_ ([Bengio et al., 2013](#bib.bib29); [van den Oord et al.,
2017](#bib.bib30)), except our intention is not to approximate an
unavailable gradient, but rather, analytically derive another gradient
quantity. Define the _augmented NTP cross-entropy loss_ as

|     |                                                                                                                                                                |     |     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle\tilde{\mathcal{L}}_{\text{NTP}}=\sum^{T-1}_{t=1}\mathrm{CE}\left(x_{t+1},\text{softmax}\left(W_{\theta}\tilde{\mathbf{h}}_{t}\right)\right).`$ |     | (5) |

Since $`\tilde{\mathbf{h}}_{t+k}`$ is numerically the same as
$`\mathbf{h}_{t+k}^{(0)}`$, we have
$`\text{softmax}\left(W_{\theta}\tilde{\mathbf{h}}_{t+k}\right)=q_{t}^{(k)}`$,
and the gradient of the augmented NTP loss with respect to the NTP
hidden state remains the same. That is, the model’s optimization for the
NTP loss remains unaltered. However, it now injects an extra gradient
with respect to the MTP representation $`\mathbf{h}_{t}^{(k)}`$

|     |                                                                                |                                                                                                                                                     |     |     |
| --- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle\nabla_{\mathbf{h}_{t}^{(k)}}\tilde{\mathcal{L}}_{\text{NTP}}`$ | $`\displaystyle=-\nabla_{\tilde{\mathbf{h}}_{t+k}}\mathrm{CE}\left(x_{t+k+1},\text{softmax}\left(W_{\theta}\tilde{\mathbf{h}}_{t+k}\right)\right)`$ |     |     |
|     |                                                                                | $`\displaystyle=-W_{\theta}^{\intercal}\left(q_{t}^{(k)}-x_{t+k+1}\right)`$                                                                         |     |     |
|     |                                                                                | $`\displaystyle=-{\color[rgb]{0.6406,0,0}g_{\text{res}}},`$                                                                                         |     | (6) |

which is precisely the quantity we needed. Therefore, summing the
contributions of the hard MTP gradient from the ordinary MTP loss and
the gradient of the augmented NTP loss with respect to the MTP hidden
states, we get the self-distillation gradients

|     |                                                                                                                                                                                                                                              |     |     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle\boxed{\nabla_{\mathbf{h}_{t}^{(k)}}\left(\tilde{\mathcal{L}}_{\text{NTP}}+\mathcal{L}^{(k)}_{\text{MTP}}\right)=g_{\text{hard}}-{\color[rgb]{0.6406,0,0}g_{\text{res}}}={\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}}`$ |     | (7) |

as derived in our decomposition in
[Equation 2](#S4.E2 "In Definition 4.1 (Hard MTP gradient). ‣ 4 Decomposing the MTP Gradient ‣ Multi-Token Prediction Done Right").
[Figure 1](#S0.F1 "In Multi-Token Prediction Done Right") illustrates
the straight-through gradient routing and the one-line code change
needed to operationalize the KL gradient–recovery.

### 5.2 Soft-MTP

Our method, _Soft Multi-Token Prediction (Soft-MTP)_, uses the KL
gradient–recovery trick to optimize the parameters of the MTP heads and
the shared model trunk. There are two main distinctions of Soft-MTP
compared to prior self-distillation MTP approaches.

First, the KL gradient–recovery trick operates directly in the NTP
hidden-state space (see
[Equation 4](#S5.E4 "In 5.1 KL gradient–recovery trick ‣ 5 Soft Multi-Token Prediction ‣ Multi-Token Prediction Done Right")),
and avoids the need to materialize any additional logit matrices or
explicitly compute KL divergence. As a result, Soft-MTP introduces
negligible computational and memory overhead over standard MTP.

Second, Soft-MTP still sends cross-entropy gradients from the MTP loss
into the shared linear output head $`W_{\theta}`$, but the parameters of
the upstream modules (i.e., MTP heads and shared model trunk) receive
the self-distillation gradient
$`{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$ instead. We
explain why this is better than direct KL minimization in
[Section 6.3](#S6.SS3 "6.3 Soft-MTP is more efficient than KL-MTP ‣ 6 Experiments ‣ Multi-Token Prediction Done Right").
[Table 1](#S5.T1 "In 5.2 Soft-MTP ‣ 5 Soft Multi-Token Prediction ‣ Multi-Token Prediction Done Right")
presents the anatomy of the gradient routing across different MTP
objectives.

| Method       | Output head $`W_{\theta}`$ | MTP heads and shared trunk |
| ------------ | -------------------------- | -------------------------- |
| Standard MTP | CE gradient                | CE gradient                |
| KL-MTP       | KL gradient                | KL gradient                |
| Soft-MTP     | CE gradient                | KL gradient                |

### 5.3 A bias–variance view of the residual

[Equation 2](#S4.E2 "In Definition 4.1 (Hard MTP gradient). ‣ 4 Decomposing the MTP Gradient ‣ Multi-Token Prediction Done Right")
can also be interpreted from a bias–variance decomposition perspective.
Of its two components, only $`{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$
depends on the sampled target token $`x_{t+k+1}`$;
$`{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$ is determined
entirely by the model’s own NTP and MTP predictions. Let
$`\pi_{t}^{(k)}`$ denote the true distribution of the next token
$`x_{t+k+1}`$ given the prefix $`x_{\leq t+k}`$, which is exactly what
the position-aligned NTP distribution $`q_{t}^{(k)}`$ tries to predict.
Since the one-hot target is a sample $`x_{t+k+1}\sim\pi_{t}^{(k)}`$, the
residual splits into two parts:

|     |                                                                                                                                                                                                                                                                                                                         |     |     |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle{\color[rgb]{0.6406,0,0}g_{\text{res}}}=W_{\theta}^{\intercal}\left(q_{t}^{(k)}-x_{t+k+1}\right)=\underbrace{W_{\theta}^{\intercal}\left(q_{t}^{(k)}-\pi_{t}^{(k)}\right)}_{\text{NTP error}}+\underbrace{W_{\theta}^{\intercal}\left(\pi_{t}^{(k)}-x_{t+k+1}\right)}_{\text{one-hot sampling noise}},`$ |     | (8) |

where the sampling noise has zero mean because
$`\mathbb{E}[x_{t+k+1}]=\pi_{t}^{(k)}`$. The hard MTP gradient is
unbiased but it includes the $`{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$
component and incurs the full one-hot sampling variance. By removing
$`{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$ from the MTP updates,
Soft-MTP removes this variance at the cost of a bias: without the
NTP-error correction term,
$`{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$ is biased toward
the NTP distribution and not the data distribution $`\pi_{t}^{(k)}`$.
These two terms behave very differently as models scale. The bias term
is the NTP teacher’s own prediction error, which keeps _shrinking_ as
the base model scales and/or trains longer. The variance term is the
_irreducible_ noise of sampling a one-hot target, which no amount of
scale or training removes. Therefore, the trade that Soft-MTP makes
becomes increasingly favorable at scale. We observe this empirically in
[Section 6.1](#S6.SS1 "6.1 The residual interferes with learning ‣ 6 Experiments ‣ Multi-Token Prediction Done Right"),
where the residual has a much lower _signal-to-noise_ ratio than the KL
component, and the gap widens with model scale. Furthermore, since MTP
is largely used to accelerate inference, biasing the MTP heads towards
matching the NTP distribution is actually desirable for improving
speculative decoding acceptance²² 2 Technically, the acceptance rate is
determined by the TV distance and KL provides an indirect upper bound
through Pinsker’s inequality (see [Samarin et al. (2026)](#bib.bib69)
and [Li et al. (2026a)](#bib.bib68)). Nonetheless, KL is the more
appropriate training loss here: it is smooth where TV is not, and it
keeps a non-vanishing gradient on tokens the MTP heads underpredict..
Unlike KL-MTP, Soft-MTP still trains the shared output head
$`W_{\theta}`$ with cross-entropy, so the head is fitted to the data
rather than biased toward its own next-token predictions. We explain why
this matters in
[Section 6.3](#S6.SS3 "6.3 Soft-MTP is more efficient than KL-MTP ‣ 6 Experiments ‣ Multi-Token Prediction Done Right").

## 6 Experiments

We now turn to an empirical validation of Soft-MTP. Our study is
organized around three main questions:

1.  1.  How do the self-distillation component
        $`{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$ and residual
        component $`{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$ of the MTP
        cross-entropy gradient affect next-token and multi-token learning?

    In
    [Section 6.1](#S6.SS1 "6.1 The residual interferes with learning ‣ 6 Experiments ‣ Multi-Token Prediction Done Right"),
    we find that $`{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$ has a
    substantially lower _signal-to-noise ratio (SNR)_ than
    $`{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$, yet accounts
    for a large fraction of the MTP gradient norm. Moreover, this
    residual becomes increasingly noisy with model scale, obscuring the
    useful learning signal in the MTP cross-entropy gradient. We further
    find that the residual component is anti-aligned with the NTP update
    direction throughout training, suggesting that the residual not only
    adds noise to MTP learning but also interferes with NTP
    optimization. Soft-MTP reaches a lower NTP loss than standard MTP,
    and the gap widens with scale. From 689M parameters onward, it also
    reaches a lower MTP loss.

2.  2.  Does isolating the self-distillation gradient in Soft-MTP improve
        over standard MTP?

    In
    [Section 6.2](#S6.SS2 "6.2 Soft-MTP outperforms standard MTP ‣ 6 Experiments ‣ Multi-Token Prediction Done Right"),
    we empirically validate the analysis above by comparing Soft-MTP
    against standard MTP. Across model scales, Soft-MTP yields better
    perplexity, downstream accuracy, speculative-decoding acceptance
    rates, and math and code fine-tuning performance. These results
    support our analyses in Question 1—removing the noisy residual
    produces a cleaner and more compatible learning signal.

3.  3.  How does Soft-MTP compare with directly optimizing a KL
        self-distillation objective?

    In
    [Section 6.3](#S6.SS3 "6.3 Soft-MTP is more efficient than KL-MTP ‣ 6 Experiments ‣ Multi-Token Prediction Done Right"),
    we find little benefit from explicitly computing the KL divergence
    or propagating its gradients through the LM head: retaining hard
    cross-entropy supervision at the LM head while propagating the
    recovered KL gradients only through the MTP heads and shared model
    backbone is sufficient to match or exceed the gains of direct
    self-distillation. Moreover, Soft-MTP avoids the computational
    overhead of computing KL divergence and preserves compatibility with
    fused linear cross-entropy kernels. Overall, this suggests that
    Soft-MTP is more efficient.

#### Experimental setup.

We pre-trained LLaMA-style models ([Touvron et al., 2023](#bib.bib35))
of base-model sizes ranging from 167M to 1.2B parameters using NTP and
MTP objectives. For MTP, we used the widely adopted DeepSeek-style
sequential architecture ([DeepSeek-AI, 2024](#bib.bib9)) and added three
MTP heads to predict $`K=3`$ additional future tokens, following common
practice ([Gloeckle et al., 2024](#bib.bib54); [Xiaomi,
2026](#bib.bib23); [MiniMax, 2026](#bib.bib24); [GLM-5-Team,
2026](#bib.bib27)). To study the effect of standard MTP and Soft-MTP
consistently across model sizes, we kept each MTP head at a constant
3.2% of the trunk’s non-embedding parameters and fixed the MTP loss
coefficient at $`\lambda_{\text{MTP}}=1.0`$. We trained all models on
the FineWeb-Edu dataset ([Penedo et al., 2024](#bib.bib64)) for 60,000
steps with a batch size of 0.5M tokens and a sequence length of 2048,
for a total of approximately 31.5B training tokens, which is
$`\sim 1.3\times`$ Chinchilla-optimal ([Hoffmann et al.,
2022](#bib.bib36)) for our largest model size. To be of modern
relevance, we trained our models using the Muon optimizer ([Jordan et
al., 2024b](#bib.bib66)) under the update-RMS rescaling of [Liu et al.
(2025a)](#bib.bib67). Our training hyperparameters are detailed in
[Appendix D](#A4 "Appendix D Experiment Setup and Hyperparameters ‣ Multi-Token Prediction Done Right").
For completeness, we also showed that Soft-MTP improves over standard
MTP using Meta-style MTP heads in
[Appendix C](#A3 "Appendix C Meta-style MTP results ‣ Multi-Token Prediction Done Right").

#### Gradient signal-to-noise.

We first measure the signal-to-noise ratios (SNR) of the different
gradient components w.r.t. the model parameters $`\theta`$:
$`g^{\theta}_{\text{hard}}`$ (hard MTP gradient),
$`{\color[rgb]{0.043,0.2383,0.5703}g^{\theta}_{\mathrm{KL}}}`$ (KL
self-distillation gradient),
$`{\color[rgb]{0.6406,0,0}g^{\theta}_{\text{res}}}`$ (residual MTP
gradient), and $`g^{\theta}_{\text{NTP}}`$ (NTP cross-entropy gradient).
For a gradient component $`g^{\theta}_{c}(\xi)`$ computed on a data
batch $`\xi`$, we define its _signal_ as the squared norm of its
expected direction,
$`S_{c}=\lVert\mathbb{E}_{\xi}[g^{\theta}_{c}]\rVert^{2}`$, and its
_noise_ as the total variance around this direction,
$`N_{c}=\mathbb{E}_{\xi}\lVert g^{\theta}_{c}\rVert^{2}-S_{c}=\operatorname{tr}(\Sigma_{c})`$.
We report $`\mathrm{SNR}_{c}=S_{c}/N_{c}`$ as the signal-to-noise ratio.
This quantity is closely related to the inverse of the _gradient noise
scale_ of [McCandlish et al. (2018)](#bib.bib34); with a fixed batch
size, the two differ only by a constant factor. We estimate the SNR
using $`M=256`$ independent batches, each containing 4 sequences of
length 2048. The naïve signal estimate is biased upward by
$`\operatorname{tr}(\Sigma)/M`$, so we report the unbiased estimator
following [McCandlish et al. (2018, Appendix A.1)](#bib.bib34).

[Figures 3(a)](#S6.F3.sf1 "In Figure 3 ‣ 6.1 The residual interferes with learning ‣ 6 Experiments ‣ Multi-Token Prediction Done Right")
and [3(b)](#S6.F3.sf2 "Figure 3(b) ‣ Figure 3 ‣ 6.1 The residual interferes with learning ‣ 6 Experiments ‣ Multi-Token Prediction Done Right")
compare the SNR of the two gradient components w.r.t. the shared trunk
and MTP head parameters across model scales. Throughout training, the
residual carries roughly $`\mathbf{4\times}`$ lower SNR than the KL
component. The residual becomes increasingly noisy, and the gap widens
as the scale increases, from $`4.1\times`$ at 167M to $`4.6\times`$ at
1.2B (note the log-scale axis). This result corroborates the
bias–variance tradeoff discussed in
[Section 5.3](#S5.SS3 "5.3 A bias–variance view of the residual ‣ 5 Soft Multi-Token Prediction ‣ Multi-Token Prediction Done Right"):
the residual always contains irreducible noise from sampling the one-hot
target, while its signal, i.e., the NTP error, shrinks with scale, so
its SNR falls as models grow. Removing the residual substantially
increases gradient SNR—the KL component has much higher SNR than the
original hard-MTP gradient. Yet despite its low SNR, the residual
accounts for $`\sim`$80% of the MTP gradient reaching the shared trunk
(see
[Figure 3(c)](#S6.F3.sf3 "In Figure 3 ‣ 6.1 The residual interferes with learning ‣ 6 Experiments ‣ Multi-Token Prediction Done Right")).
Thus, although the standard MTP contains the high SNR KL signal
implicitly, the residual obscures it under high-variance updates, which
is why the overall hard-MTP gradient has lower SNR (see
[Figure 3(b)](#S6.F3.sf2 "In Figure 3 ‣ 6.1 The residual interferes with learning ‣ 6 Experiments ‣ Multi-Token Prediction Done Right")).

residual components in

learning. In
[Figure 4(a)](#S6.F4.sf1 "In Figure 4 ‣ Gradient signal-to-noise. ‣ 6.1 The residual interferes with learning ‣ 6 Experiments ‣ Multi-Token Prediction Done Right"),
we take a unit step on the shared trunk’s hidden state along each
component’s gradient (backpropagated from the MTP heads) and re-evaluate
the NTP loss through the frozen output head. This is a proxy for what
each component ‘asks’ the trunk output to become. A step along the KL
component consistently decreases NTP loss, indicating that the
self-distillation signal in MTP reinforces the NTP objective. In
contrast, a step along the residual component in MTP consistently
increases NTP loss. This behavior persists throughout training and is
consistent across model scales. Note that this analysis serves only as a
characterization of the components’ behavior at the trunk–MTP head
interface; the realized update to the trunk’s hidden states during
training also depends on the optimizer used. We empirically corroborate
this residual interference in
[Figure 4(b)](#S6.F4.sf2 "In Figure 4 ‣ Gradient signal-to-noise. ‣ 6.1 The residual interferes with learning ‣ 6 Experiments ‣ Multi-Token Prediction Done Right"):
removing the residual with Soft-MTP lowers the NTP loss, especially as
scale increases. Furthermore, from 689M parameters onward, Soft-MTP also
reaches a lower MTP loss than standard MTP (see
[Figure 4(c)](#S6.F4.sf3 "In Figure 4 ‣ Gradient signal-to-noise. ‣ 6.1 The residual interferes with learning ‣ 6 Experiments ‣ Multi-Token Prediction Done Right")).

#### Speculative decoding.

We evaluated the speculative decoding performance of the standard MTP
and Soft-MTP pre-trained models across FineWeb-Edu, Wikipedia, Books,
Science, and Math. For each domain, we sample 256 prompts of length 512
tokens and generate 512-token continuations using the speculative
sampling algorithm of [Leviathan et al. (2022)](#bib.bib58), drafting
with the $`K=3`$ MTP heads and verifying using the model’s own
next-token head. For each model, we report the acceptance length
(average number of accepted tokens per verification step) and the
inference speedup relative to standard autoregressive sampling from the
base model.
[Table 2](#S6.T2 "In 6.2 Soft-MTP outperforms standard MTP ‣ 6 Experiments ‣ Multi-Token Prediction Done Right")
shows that Soft-MTP produces better drafts and faster decoding than
standard MTP at every scale and in every domain. Averaged over the five
domains, it improves acceptance length by 1.8–2.2% and speedup by
1.4–1.5% at each scale. Its MTP distributions are closer to the model’s
own NTP verifier, with lower KL divergence and TV distance at every
scale. These show that the bias discussed in
[Section 5.3](#S5.SS3 "5.3 A bias–variance view of the residual ‣ 5 Soft Multi-Token Prediction ‣ Multi-Token Prediction Done Right")
works in our favor: the self-distillation gradient pulls the MTP heads
toward exactly the NTP distribution that verifies their drafts.

these hyperparameters, we sweep the MTP weight $`\lambda_{\text{MTP}}`$
and the horizon $`K`$ at the 332M scale, training each model on 7.3B

to update the output head, and we next explain why training it with
cross-entropy, as Soft-MTP does, matters.

#### Why keep cross-entropy at the output head?

Note that the output head $`W_{\theta}`$ is shared in MTP; the same
matrix maps both the NTP and the MTP hidden states to logits. As such,
any gradient from the MTP loss also shapes the NTP readout. Under
Soft-MTP, this gradient is the MTP cross-entropy gradient which, like
the NTP loss, fits the output head to the data distribution. Under
KL-MTP, it is the self-distillation gradient, which fits the head to the
model’s own NTP predictions, and those predictions are themselves also
computed by $`W_{\theta}`$. This creates a shortcut because the KL can
be reduced not only by improving the MTP hidden states, but also by
making the shared readout less sensitive to the directions in which the
MTP and NTP hidden states differ.

Cross-entropy has no such shortcut because its target does not depend on
$`W_{\theta}`$.
[Figure 6](#S6.F6 "In Why keep cross-entropy at the output head? ‣ 6.3 Soft-MTP is more efficient than KL-MTP ‣ 6 Experiments ‣ Multi-Token Prediction Done Right")

product). Standard MTP collapses the readout to about a quarter of the
NTP baseline (131 vs. 496) and KL-MTP to about two thirds (321), while
Soft-MTP stays closest (437). The gradient routing differences between
the objectives (see
[Table 1](#S5.T1 "In 5.2 Soft-MTP ‣ 5 Soft Multi-Token Prediction ‣ Multi-Token Prediction Done Right"))
allow us to pull the two effects apart. Soft-MTP and KL-MTP both send
the KL gradient through the MTP heads and trunk and differ only at the
output head, so the gap between them comes from keeping cross-entropy at
the head. Soft-MTP and standard MTP both use cross-entropy at the head
and differ only in the trunk, so the much larger gap comes from removing
the residual. Soft-MTP combines the best of both worlds in terms of
gradient routing, and it is also the objective with the strongest
perplexity and downstream accuracy results.

## 7 Discussion: Practical Relevance at Frontier Scale

MTP has been widely adopted in modern LLM training. Frontier model
pre-training leverages many parallelism schemes due to tight memory
budgets. Here we discuss the compatibility and relevance of Soft-MTP in
frontier model pre-training.

#### Compatibility with parallelism.

The KL gradient–recovery trick needs only two things where it is
applied: the NTP hidden state $`\mathbf{h}^{(0)}_{t+k}`$ and the MTP
hidden state $`\mathbf{h}^{(k)}_{t}`$ on the same device, and a backward
path from $`\mathcal{L}_{\text{NTP}}`$ to $`\mathbf{h}^{(k)}_{t}`$. On
its own, it adds no communication and no synchronization. Parallelism
that shards parameters, optimizer state or experts therefore leaves it
untouched, e.g., data parallelism and ZeRO ([Rajbhandari et al.,
2020](#bib.bib47)), and expert parallelism ([Lepikhin et al.,
2021](#bib.bib48)) as used by DeepSeek-V3 ([DeepSeek-AI,
2024](#bib.bib9)) and Kimi K3 ([Kimi Team, 2026](#bib.bib25)). Pipeline
parallelism ([Huang et al., 2019](#bib.bib49)) only requires the MTP
modules to sit on the same stage as the output head, which DeepSeek-V3
already does by design so that its MTP module can share the output head.
The only axis that needs extra communication is sequence sharding,
because our trick reads hidden states $`k`$ tokens ahead. This includes
context parallelism, such as ring attention ([Liu et al.,
2024](#bib.bib50)), and sequence parallelism ([Korthikanti et al.,
2022](#bib.bib51)). Even then, the cost is a backward-pass exchange of
at most $`K`$ hidden-state gradients at each shard boundary, independent
of sequence length.

#### KL gradient–recovery trick is more compatible than explicit self-distillation.

An explicit KL needs the teacher’s and the student’s vocabulary-sized
distributions at once, which standard fused cross-entropy kernels cannot
compute without materializing the logits. This is especially costly for
models trained without tensor parallelism, such as DeepSeek-V3
([DeepSeek-AI, 2024](#bib.bib9)), which therefore cannot shard these
tensors along the vocabulary. A custom fused KL kernel can avoid this
materialization, but must recompute the teacher logits that the NTP loss
already computes, unless the NTP cross-entropy and all MTP KL terms are
fused into a single kernel. The KL gradient–recovery trick instead
carries the KL gradient through the hidden state rather than the logits,
so every head keeps its standard, kernel-fused cross-entropy ([Hsu et
al., 2025](#bib.bib70); [Wijmans et al., 2025](#bib.bib71)), and
Soft-MTP adds no vocabulary-sized tensors beyond those standard MTP
already uses. Soft-MTP also matches, if not exceeds, direct KL
minimization on most metrics as shown in
[Section 6.3](#S6.SS3 "6.3 Soft-MTP is more efficient than KL-MTP ‣ 6 Experiments ‣ Multi-Token Prediction Done Right").

#### Future of MTP and extensions to the KL gradient–recovery trick.

MTP has spread rapidly since DeepSeek-V3 adopted it in
2024 ([DeepSeek-AI, 2024](#bib.bib9)), but its longevity in pre-training
is uncertain. DeepSeek-V4.1-Flash ([DeepSeek-AI, 2026a](#bib.bib10))
recently dropped MTP in favor of DSpark ([Cheng et al.,
2026](#bib.bib11)), a speculative decoder trained after pre-training.
Post-trained drafters such as Medusa ([Cai et al., 2024](#bib.bib63)),
EAGLE ([Li et al., 2024b](#bib.bib61); [Li et al., 2024a](#bib.bib62);
[Li et al., 2026b](#bib.bib17)), DFlash ([Chen et al.,
2026](#bib.bib12)) and DSpark ([Cheng et al., 2026](#bib.bib11)) are
convenient, but it remains open how well they work when the base model
was never trained to form predictive representations of future tokens,
e.g., via MTP. Will MTP be retained for the superior downstream accuracy
it provides over NTP-only pre-training ([Gloeckle et al.,
2024](#bib.bib54); [DeepSeek-AI, 2024](#bib.bib9); [MiniMax,
2026](#bib.bib24); [NVIDIA, 2025](#bib.bib21)), at the cost of minimal
additional FLOPs? MTP has also proven useful in small-scale
pre-training, e.g., in Modded-NanoGPT ([Jordan et al.,
2024a](#bib.bib15)), and in data-constrained settings, where it improves
sample efficiency, e.g., in NanoGPT Slowrun ([Vegesna et al.,
2026](#bib.bib16)). Whatever the future of MTP, the KL gradient–recovery
trick applies more broadly—whenever a teacher and a student share a
linear output head, the gradient of the forward KL can be recovered from
their cross-entropy gradients. Many post-training methods compute such a
KL, for example MTP Boosting ([NVIDIA, 2026](#bib.bib22)), on-policy
self-distillation (OPSD; [Zhao et al., 2026b](#bib.bib13)), and score
centering for off-policy RL ([Marek and Ryabinin, 2026](#bib.bib14)).
Such use cases are expensive due to the KL computation overhead, which
may necessitate top-$`k`$ logits approximation. Our KL gradient–recovery
trick avoids that cost, with the caveat that only the MTP heads and
shared trunk receive the exact KL gradient, whereas the shared output
head $`W_{\theta}`$ is updated with cross-entropy. This is also suitable
for methods that already freeze the output head under the KL loss, such
as Next-Latent Prediction ([Teoh et al., 2025](#bib.bib5)), which only
needs the KL gradient with respect to the hidden states.

## 8 Conclusion

The standard MTP cross-entropy gradient can be decomposed into a KL
self-distillation term, which pulls the MTP heads toward the model’s own
next-token distribution, and a residual, which is the next-token
cross-entropy gradient against the data. The residual carries most of
the MTP gradient, yet it has a low signal-to-noise ratio, works against
next-token learning, and becomes noisier with scale. Our KL
gradient–recovery trick removes this residual and recovers the KL term
exactly from the cross-entropy gradients that standard MTP already
computes. This yields Soft-MTP, a one-line change to standard MTP that
adds no parameters, has negligible overhead, and remains compatible with
fused cross-entropy kernels. Soft-MTP improves over standard MTP in NTP
and MTP loss, self-speculative decoding, zero-shot accuracy, and in math
and code reasoning after fine-tuning, all at no extra cost.

\# x, y : \[B, T\] input tokens and pre-shifted labels; y\[:, t\] is the

\# target of position t.

\# K : number of MTP heads.

\# lambda_mtp : auxiliary MTP weight.

\# ce : cross-entropy, mean-reduced over the targets it is given.

\#

\# MTP head k at position t and the NTP head at position t+k predict the

\# SAME token y\[:, t+k\]; that shared label is what cancels the label
term

\# and leaves the KL gradient. Each MTP head has one fewer target than
the

\# head before it: head k has T-k targets, y\[:, k:\].

h_prev = shared_trunk(x)

h0 = norm\[0\](h_prev) \# NTP hidden states are directly from trunk,
\[B, T, d\]

T = y.size(1)

loss_mtp = 0

for k in range(1, K+1):

yk = y\[:, k:\] \# \[B, T-k\] k-th MTP head targets

h_prev = mtp_head\[k-1\](h_prev\[:, :T-k\], x\[:, k:\]) \# DeepSeek's
sequential MTP

hk = norm\[k\](h_prev)

\# hard CE: hk gets lambda_mtp/(K(T-k)) \* CE gradient

loss_mtp += ce(lm_head, hk, yk)

\# straight-through gradient routing

\# s_k undoes the NTP CE's 1/T mean and re-applies k-th MTP head's own

\# 1/(T-k) mean and the 1/K head average, so the routed gradient

\# lands at exactly the scale the MTP head's own CE gradient uses.

s_k = lambda_mtp \* T / (K \* (T - k))

\# h0 is numerically unchanged; only its backward changes

h0\[:, k:\] = h0\[:, k:\] + s_k \* (hk.detach() - hk)

\# NTP loss and the gradients reaching the trunk through h0 are
unchanged

loss_ntp = ce(lm_head, h0, y)

\# backward: hk\[t\] gets -s_k \* (NTP CE grad at h0\[t+k\]); its
one-hot part

\# cancels the one in hk's own CE grad, leaving the KL gradient

\# lambda_mtp / (K(T-k)) \* W^T (p_k\[t\] - p_0\[t+k\])

(loss_ntp + lambda_mtp/K \* loss_mtp).backward()

## Appendix B Extra Derivations for MTP Gradients

Throughout, $`W_{\theta}\in\mathbb{R}^{V\times d}`$ is the shared linear

fed into it (after any final normalization), $`z=W_{\theta}\mathbf{h}`$
are the logits, and $`p=\mathrm{softmax}(z)`$. Targets

|     |                                   |                                                                                                      |     |     |
| --- | --------------------------------- | ---------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle g_{\text{hard}}`$ | $`\displaystyle\coloneqq\nabla_{\mathbf{h}_{t}^{(k)}}\mathrm{CE}\left(x_{t+k+1},p_{t}^{(k)}\right)`$ |     |     |
|     |                                   | $`\displaystyle=W_{\theta}^{\intercal}\left(p_{t}^{(k)}-x_{t+k+1}\right).`$                          |     | (1) |

First, the cross-entropy gradient with respect to the logits. Since
$`\log p_{v}=z_{v}-\log\sum_{u}e^{z_{u}}`$ and $`\sum_{v}y_{v}=1`$,

|     |                                                                                                   |     |
| --- | ------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\mathrm{CE}(y,p)=-\sum_{v}y_{v}\log p_{v}=-y^{\intercal}z+\log\sum_{u}e^{z_{u}},`$ |     |

and differentiating gives
$`\partial\,\mathrm{CE}/\partial z_{v}=-y_{v}+e^{z_{v}}/\sum_{u}e^{z_{u}}=p_{v}-y_{v}`$,
i.e.

|     |                                                                               |     |     |
| --- | ----------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle\nabla_{z}\mathrm{CE}\left(y,\mathrm{softmax}(z)\right)=p-y.`$ |     | (9) |

The $`k`$-th MTP logits are
$`z_{t}^{(k)}=W_{\theta}\mathbf{h}_{t}^{(k)}`$, so
$`\partial z_{t}^{(k)}/\partial\mathbf{h}_{t}^{(k)}=W_{\theta}`$. By the
chain rule and
[Equation 9](#A2.E9 "In B.1 Hard MTP gradient ‣ Appendix B Extra Derivations for MTP Gradients ‣ Multi-Token Prediction Done Right")
with $`y=x_{t+k+1}`$,

|     |                                                                                                                                                                                                                                                                           |     |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\nabla_{\mathbf{h}_{t}^{(k)}}\mathrm{CE}\left(x_{t+k+1},p_{t}^{(k)}\right)=\left(\frac{\partial z_{t}^{(k)}}{\partial\mathbf{h}_{t}^{(k)}}\right)^{\!\intercal}\nabla_{z_{t}^{(k)}}\mathrm{CE}=W_{\theta}^{\intercal}\left(p_{t}^{(k)}-x_{t+k+1}\right).`$ |     |

### B.2 KL self-distillation gradient

We derive
[Equation 3](#S4.E3 "In 4.1 The KL self-distillation component ‣ 4 Decomposing the MTP Gradient ‣ Multi-Token Prediction Done Right"),

|     |                                                                                                                                                                                                                               |     |     |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle\nabla_{\mathbf{h}_{t}^{(k)}}D_{\mathrm{KL}}\left(\textbf{sg}(q_{t}^{(k)})\|p_{t}^{(k)}\right)=W_{\theta}^{\intercal}\left(p_{t}^{(k)}-q_{t}^{(k)}\right)={\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}.`$ |     | (3) |

With a stop-gradient teacher, the forward KL divergence splits into a
cross-entropy and the teacher’s entropy:

|     |                                                                                                                                                                                                                                                     |     |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle D_{\mathrm{KL}}\left(\textbf{sg}(q_{t}^{(k)})\,\|\,p_{t}^{(k)}\right)=\sum_{v}q_{t,v}^{(k)}\log q_{t,v}^{(k)}-\sum_{v}q_{t,v}^{(k)}\log p_{t,v}^{(k)}=-H\left(q_{t}^{(k)}\right)+\mathrm{CE}\left(q_{t}^{(k)},p_{t}^{(k)}\right).`$ |     |

The entropy term does not depend on $`\mathbf{h}_{t}^{(k)}`$, because
the teacher is held fixed. Applying
[Equation 9](#A2.E9 "In B.1 Hard MTP gradient ‣ Appendix B Extra Derivations for MTP Gradients ‣ Multi-Token Prediction Done Right")
with $`y=q_{t}^{(k)}`$ and the same chain rule as above,

|     |                                                                                                                                                                                                                                                                                                                |     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\nabla_{\mathbf{h}_{t}^{(k)}}D_{\mathrm{KL}}\left(\textbf{sg}(q_{t}^{(k)})\,\|\,p_{t}^{(k)}\right)=\nabla_{\mathbf{h}_{t}^{(k)}}\mathrm{CE}\left(q_{t}^{(k)},p_{t}^{(k)}\right)=W_{\theta}^{\intercal}\left(p_{t}^{(k)}-q_{t}^{(k)}\right)={\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}.`$ |     |

### B.3 From hidden states to parameters

The decomposition in
[Equation 2](#S4.E2 "In Definition 4.1 (Hard MTP gradient). ‣ 4 Decomposing the MTP Gradient ‣ Multi-Token Prediction Done Right"),

|     |                                                                                                                                                                                                                                                                                                                                                                 |     |     |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle g_{\text{hard}}=W_{\theta}^{\intercal}\left(p_{t}^{(k)}-q_{t}^{(k)}+q_{t}^{(k)}-x_{t+k+1}\right)=\underbrace{W_{\theta}^{\intercal}\left(p_{t}^{(k)}-q_{t}^{(k)}\right)}_{{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}}+\underbrace{W_{\theta}^{\intercal}\left(q_{t}^{(k)}-x_{t+k+1}\right)}_{{\color[rgb]{0.6406,0,0}g_{\text{res}}}},`$ |     | (2) |

follows from
[Equation 1](#S4.E1 "In Definition 4.1 (Hard MTP gradient). ‣ 4 Decomposing the MTP Gradient ‣ Multi-Token Prediction Done Right")
by adding and subtracting $`q_{t}^{(k)}`$, and holds at the MTP hidden
state. It carries over exactly to every parameter $`\phi`$ upstream of
$`\mathbf{h}_{t}^{(k)}`$, i.e. in the MTP heads and the shared trunk:
for a fixed forward pass, backpropagation is linear in the gradient
arriving at $`\mathbf{h}_{t}^{(k)}`$,

|     |                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\nabla_{\phi}=\left(\frac{\partial\mathbf{h}_{t}^{(k)}}{\partial\phi}\right)^{\!\intercal}\left({\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}+{\color[rgb]{0.6406,0,0}g_{\text{res}}}\right)=\left(\frac{\partial\mathbf{h}_{t}^{(k)}}{\partial\phi}\right)^{\!\intercal}{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}+\left(\frac{\partial\mathbf{h}_{t}^{(k)}}{\partial\phi}\right)^{\!\intercal}{\color[rgb]{0.6406,0,0}g_{\text{res}}}.`$ |     |

This holds for both parallel and sequential MTP heads; in the sequential
case, $`\mathbf{h}_{t}^{(k)}`$ also depends on
$`\mathbf{h}_{t}^{(k-1)}`$, which only changes the Jacobian, not the
linearity.

### B.4 KL gradient–recovery trick

We derive
[Equations 6](#S5.E6 "In 5.1 KL gradient–recovery trick ‣ 5 Soft Multi-Token Prediction ‣ Multi-Token Prediction Done Right")
and [7](#S5.E7 "Equation 7 ‣ 5.1 KL gradient–recovery trick ‣ 5 Soft Multi-Token Prediction ‣ Multi-Token Prediction Done Right").
Recall the augmented NTP hidden states

|                                                                                                                 |                                                                                                        |     |     |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | --- | --- |
|                                                                                                                 | $`\displaystyle\tilde{\mathbf{h}}_{t}=\mathbf{h}_{t}^{(0)}+\underbrace{\sum\_{\begin{subarray}{c}k=1\\ |
| t-k\geq 1\end{subarray}}^{K}\left[\textbf{sg}(\mathbf{h}_{t-k}^{(k)})-\mathbf{h}_{t-k}^{(k)}\right]}\_{=\;0},`$ |                                                                                                        | (4) |

and the augmented NTP loss

|     |                                                                                                                                                                |     |     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle\tilde{\mathcal{L}}_{\text{NTP}}=\sum^{T-1}_{t=1}\mathrm{CE}\left(x_{t+1},\text{softmax}\left(W_{\theta}\tilde{\mathbf{h}}_{t}\right)\right).`$ |     | (5) |

#### Forward pass.

Each bracketed term in
[Equation 4](#S5.E4 "In 5.1 KL gradient–recovery trick ‣ 5 Soft Multi-Token Prediction ‣ Multi-Token Prediction Done Right")
is exactly zero, so $`\tilde{\mathbf{h}}_{t}=\mathbf{h}_{t}^{(0)}`$
numerically, and $`\tilde{\mathcal{L}}_{\text{NTP}}`$ takes the same
value as $`\mathcal{L}_{\text{NTP}}`$.

#### Backward pass.

Let
$`G_{t}\coloneqq\nabla_{\tilde{\mathbf{h}}_{t}}\mathrm{CE}\left(x_{t+1},\mathrm{softmax}(W_{\theta}\tilde{\mathbf{h}}_{t})\right)`$.
Since $`\tilde{\mathbf{h}}_{t}=\mathbf{h}_{t}^{(0)}`$ numerically,
[Equation 9](#A2.E9 "In B.1 Hard MTP gradient ‣ Appendix B Extra Derivations for MTP Gradients ‣ Multi-Token Prediction Done Right")
gives

|     |                                                                                 |     |
| --- | ------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle G_{t}=W_{\theta}^{\intercal}\left(p_{t}^{(0)}-x_{t+1}\right).`$ |     |

The stop-gradient term has zero Jacobian, so
$`\partial\tilde{\mathbf{h}}_{t}/\partial\mathbf{h}_{t}^{(0)}=I`$ and
$`\partial\tilde{\mathbf{h}}_{t}/\partial\mathbf{h}_{t-k}^{(k)}=-I`$.
The NTP hidden states therefore receive exactly the standard NTP
gradient,
$`\nabla_{\mathbf{h}_{t}^{(0)}}\tilde{\mathcal{L}}_{\text{NTP}}=G_{t}`$.
The MTP hidden state $`\mathbf{h}_{t}^{(k)}`$ appears only in
$`\tilde{\mathbf{h}}_{t+k}`$, so, using $`q_{t}^{(k)}=p_{t+k}^{(0)}`$,

|     |                                                                                                                                                                                                                                                         |     |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\nabla_{\mathbf{h}_{t}^{(k)}}\tilde{\mathcal{L}}_{\text{NTP}}=-G_{t+k}=-W_{\theta}^{\intercal}\left(p_{t+k}^{(0)}-x_{t+k+1}\right)=-W_{\theta}^{\intercal}\left(q_{t}^{(k)}-x_{t+k+1}\right)=-{\color[rgb]{0.6406,0,0}g_{\text{res}}},`$ |     |

which is
[Equation 6](#S5.E6 "In 5.1 KL gradient–recovery trick ‣ 5 Soft Multi-Token Prediction ‣ Multi-Token Prediction Done Right").
The NTP target at position $`t+k`$ exists exactly when the $`k`$-th MTP
target at position $`t`$ does ($`t\leq T-k-1`$), so the two losses cover
the same positions. Adding the hard MTP gradient and using
[Equation 2](#S4.E2 "In Definition 4.1 (Hard MTP gradient). ‣ 4 Decomposing the MTP Gradient ‣ Multi-Token Prediction Done Right"),

|     |                                                                                                                                                                                                                                              |     |     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle\boxed{\nabla_{\mathbf{h}_{t}^{(k)}}\left(\tilde{\mathcal{L}}_{\text{NTP}}+\mathcal{L}^{(k)}_{\text{MTP}}\right)=g_{\text{hard}}-{\color[rgb]{0.6406,0,0}g_{\text{res}}}={\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}}`$ |     | (7) |

since
$`g_{\text{hard}}-{\color[rgb]{0.6406,0,0}g_{\text{res}}}=\left({\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}+{\color[rgb]{0.6406,0,0}g_{\text{res}}}\right)-{\color[rgb]{0.6406,0,0}g_{\text{res}}}={\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}`$.

#### Output head.

The augmentation leaves the output head’s gradient unchanged. For the
NTP loss,

|     |                                                                                                                                                                                                                                                          |     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\nabla_{W_{\theta}}\mathrm{CE}\left(x_{t+1},\mathrm{softmax}(W_{\theta}\tilde{\mathbf{h}}_{t})\right)=\left(p_{t}^{(0)}-x_{t+1}\right)\tilde{\mathbf{h}}_{t}^{\intercal}=\left(p_{t}^{(0)}-x_{t+1}\right)\mathbf{h}_{t}^{(0)\intercal},`$ |     |

and the MTP loss still contributes its cross-entropy gradient
$`\left(p_{t}^{(k)}-x_{t+k+1}\right)\mathbf{h}_{t}^{(k)\intercal}`$.
Hence $`W_{\theta}`$ is trained with cross-entropy, while the MTP heads
and the shared trunk receive the KL gradient
([Table 1](#S5.T1 "In 5.2 Soft-MTP ‣ 5 Soft Multi-Token Prediction ‣ Multi-Token Prediction Done Right")).

### B.5 Loss weighting and per-head normalization

In practice, the MTP losses are weighted by $`\lambda_{\text{MTP}}/K`$
and each loss is averaged over its own targets. Let $`N_{0}`$ be the
number of NTP targets and $`N_{k}`$ the number of targets of the
$`k`$-th MTP head, so that

|     |                                                                                                                                                                                                                   |     |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\mathcal{L}=\frac{1}{N_{0}}\sum_{t}\mathrm{CE}\left(x_{t+1},p_{t}^{(0)}\right)+\frac{\lambda_{\text{MTP}}}{K}\sum_{k=1}^{K}\frac{1}{N_{k}}\sum_{t}\mathrm{CE}\left(x_{t+k+1},p_{t}^{(k)}\right).`$ |     |

The MTP loss then contributes
$`\frac{\lambda_{\text{MTP}}}{KN_{k}}\,g_{\text{hard}}`$ at
$`\mathbf{h}_{t}^{(k)}`$, while routing the NTP gradient as above
contributes only
$`-\frac{1}{N_{0}}\,{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$, since the
NTP loss is averaged over $`N_{0}`$ targets. Scaling each
straight-through term by

|     |                                                                                                                                                                                                              |     |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --- |
|     | $`\displaystyle s_{k}=\frac{\lambda_{\text{MTP}}\,N_{0}}{K\,N_{k}},\qquad\tilde{\mathbf{h}}_{t}=\mathbf{h}_{t}^{(0)}+\sum_{k}s_{k}\left[\textbf{sg}(\mathbf{h}_{t-k}^{(k)})-\mathbf{h}_{t-k}^{(k)}\right],`$ |     |

leaves the forward pass unchanged and makes the routed gradient
$`-\frac{s_{k}}{N_{0}}{\color[rgb]{0.6406,0,0}g_{\text{res}}}=-\frac{\lambda_{\text{MTP}}}{KN_{k}}{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$,
so that

|     |                                                                                                                                                                                                                                                                             |     |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\nabla_{\mathbf{h}_{t}^{(k)}}\mathcal{L}_{\text{Soft-MTP}}=\frac{\lambda_{\text{MTP}}}{KN_{k}}\left(g_{\text{hard}}-{\color[rgb]{0.6406,0,0}g_{\text{res}}}\right)=\frac{\lambda_{\text{MTP}}}{KN_{k}}\,{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}},`$ |     |

which is exactly the gradient of the correspondingly weighted KL
objective
$`\frac{\lambda_{\text{MTP}}}{K}\sum_{k}\frac{1}{N_{k}}\sum_{t}D_{\mathrm{KL}}\left(\textbf{sg}(q_{t}^{(k)})\,\|\,p_{t}^{(k)}\right)`$.
With sum rather than mean reduction, $`N_{0}=N_{k}=1`$ and
$`s_{k}=\lambda_{\text{MTP}}/K`$. In the implementation of
[Algorithm 1](#alg1 "In Appendix A Full Soft-MTP PyTorch Implementation ‣ Multi-Token Prediction Done Right"),
the labels are pre-shifted so that $`N_{0}=T`$ and $`N_{k}=T-k`$, giving
$`s_{k}=\lambda_{\text{MTP}}\,T/\left(K(T-k)\right)`$.

## Appendix E [Section 6.1](#S6.SS1 "6.1 The residual interferes with learning ‣ 6 Experiments ‣ Multi-Token Prediction Done Right") Analyses

All three diagnostics below decompose the MTP gradient at the MTP hidden
state into its two components using the exact identity of
[Equation 2](#S4.E2 "In Definition 4.1 (Hard MTP gradient). ‣ 4 Decomposing the MTP Gradient ‣ Multi-Token Prediction Done Right"),
$`g_{\text{hard}}={\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}+{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$,
and then ask what each component does. They are measured _offline_ on
frozen checkpoints. Unless stated otherwise, the estimator uses
$`M=256`$ independent minibatches of $`4`$ sequences each.

### E.1 Gradient signal-to-noise ratio

Let $`\{g_{i}\}_{i=1}^{M}`$ be the per-minibatch mean gradients of one
component, with mean $`\mu`$ and covariance $`\Sigma`$. Writing
$`\bar{g}=\tfrac{1}{M}\sum_{i}g_{i}`$,

|     |                                                                                                                                                                     |     |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\text{signal}=\lVert\bar{g}\rVert^{2},\qquad\text{total}=\tfrac{1}{M}\sum_{i}\lVert g_{i}\rVert^{2},\qquad\text{noise}=\text{total}-\text{signal},`$ |     |

and $`\mathrm{SNR}=\text{signal}/\text{noise}`$. Its reciprocal is the
gradient noise scale of [McCandlish et al. \[2018\]](#bib.bib34),
measured in units of minibatches. The raw ratio is biased: the measured
signal carries a $`\mathrm{tr}\,\Sigma/M`$ sampling floor and the
measured noise is low by a factor $`(M-1)/M`$. We report the debiased
value throughout.

### E.2 Share of the MTP gradient

Because
$`g_{\text{hard}}={\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}+{\color[rgb]{0.6406,0,0}g_{\text{res}}}`$
holds exactly and per batch, each component’s contribution to the
applied gradient is its projection onto it:

|     |                                                                                                                                                                                                     |     |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\mathrm{share}_{c}=\frac{\langle g_{\text{hard}},\,g_{c}\rangle}{\lVert g_{\text{hard}}\rVert^{2}},\qquad\mathrm{share}_{\text{KL}}+\mathrm{share}_{\text{res}}=1\ \text{exactly.}`$ |     |

Expanding
$`\lVert g_{\text{hard}}\rVert^{2}=\lVert{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}\rVert^{2}+\lVert{\color[rgb]{0.6406,0,0}g_{\text{res}}}\rVert^{2}+2\langle{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}},{\color[rgb]{0.6406,0,0}g_{\text{res}}}\rangle`$
expresses both shares in terms of three scalars,
$`\lVert{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}}\rVert^{2}`$,
$`\lVert{\color[rgb]{0.6406,0,0}g_{\text{res}}}\rVert^{2}`$ and
$`\langle{\color[rgb]{0.043,0.2383,0.5703}g_{\mathrm{KL}}},{\color[rgb]{0.6406,0,0}g_{\text{res}}}\rangle`$,
which we pool over batches before taking the ratio. Because the shares
sum to one by construction, they decompose $`g_{\text{hard}}`$ rather
than merely comparing magnitudes. A share can be negative when the two
components point in opposite directions.

### E.3 Proxy effect of each component on the NTP loss

To ask what a unit step along one gradient component would do to the
next-token loss, we take that step in hidden space and re-evaluate. With
$`H`$ the (detached) trunk hidden state, $`g_{c}`$ the component’s
gradient backpropagated from the MTP hidden state through the MTP head
to $`H`$, and $`\mathcal{L}_{\text{NTP}}`$ the NTP cross-entropy,
