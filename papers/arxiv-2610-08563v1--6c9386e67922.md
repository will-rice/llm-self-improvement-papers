###### Abstract

Sequence-level power sampling has recently emerged as a training-free
approach to reasoning by sampling from a sharpened output distribution
of a base large language model (LLM). Nevertheless, existing methods
typically sharpen the base model distribution uniformly across queries,
overlooking variations in query difficulty and in how well the base
model already handles each query. The goal of this work is to equip
power sampling with query adaptivity. Theoretically, we show that the
benefits of further sharpening are determined by the self-reward gap
between correct and incorrect responses. Based on this insight, we
propose _Adaptive Power Sampling_ (APS), which adjusts the sharpening
exponent on a per-query basis at test time using the relationship
between answer agreement and the model’s self-reward. Experiments across
diverse reasoning tasks, including MATH500, HumanEval, and GPQA, show
that APS consistently outperforms power sampling with a fixed sharpening
exponent, without additional training.

## 1 Introduction

Reasoning is fundamentally about generating and identifying high-quality
solution trajectories from a model’s output distribution. Recent work
suggests that post-training often achieves this by redistributing
probability mass toward sequences that are more likely to yield correct
answers ([Huang et al., 2025](#bib.bib16); [Yue et al.,
2025](#bib.bib14); [He et al., 2025](#bib.bib6)). This perspective,
commonly referred to as _sequence-level distribution sharpening_, also
provides a foundation for test-time reasoning ([Karan and Du,
2026](#bib.bib1)). In particular, strong reasoning performance on tasks
such as math and coding can be achieved by sampling from a sharpened
version of the base model’s sequence-level distribution, even when the
base model has not undergone post-training ([Karan and Du,
2026](#bib.bib1); [Ji et al., 2026](#bib.bib3)).

Compared with post-training, a clear advantage of test-time reasoning is
its reduced reliance on post-training data. This benefit, however, comes
at the cost of query-adaptive sharpening. Post-training can implicitly
learn, for each query or prompt, an appropriate degree of sharpening,
concentrating sufficient probability mass on high-quality responses
while preserving enough diversity for the target task. In contrast,
test-time reasoning methods typically commit to a single predetermined
degree of sharpening, “betting on” how concentrated the desired
distribution should be ([Karan and Du, 2026](#bib.bib1); [Azizi et al.,
2026](#bib.bib4); [Ji et al., 2026](#bib.bib3); [Nguyen et al.,
2026](#bib.bib29); [Meng et al., 2026](#bib.bib32)).

Such a fixed choice, however, may not be sufficient. Intuitively, the
appropriate degree of sharpening should vary across problems and
domains, e.g., between math and coding, or also within the same domain,
between, e.g., primary-school and college-level math problems. Motivated
by this intuition, which we further validate experimentally, we study
whether the sharpening strength can instead be determined query-wise at
test time, without relying on post-training data or manual tuning. To
equip power sharpening with adaptivity, we first study how reasoning
performance varies with the sharpening strength. More precisely, let
$`x`$ denote a prompt, and let $`p_{\theta}(y\mid x)`$ denote the
probability that a base model $`\theta`$ generates a complete response
$`y`$ given $`x`$. Test-time sharpening ([Karan and Du,
2026](#bib.bib1)) samples responses from the sharpened distribution
$`\pi_{\alpha}(y\mid x)\propto p_{\theta}(y\mid x)^{\alpha}`$, where
$`\alpha\geq 1`$ controls the degree of distributional sharpening. We
show that for this particular query $`x`$, the preferred sharpening
direction is jointly determined by the relationship between response
correctness and sequence log-likelihood. Stronger sharpening, i.e.,
larger $`\alpha`$, is more beneficial when correct responses tend to
have higher sequence log-likelihood than incorrect ones, and harmful
otherwise. Translating these theoretical insights into practice, we
propose _Adaptive Power Sampling_ (APS), a training-free reasoning
method that dynamically adjusts the sharpening exponent $`\alpha`$ at
test time. Since ground-truth correctness is unavailable, APS leverages
self-consistency ([Wang et al., 2023](#bib.bib18); [Aggarwal et al.,
2023](#bib.bib37)) among sampled answers as a surrogate signal. Combined
with the theoretical characterization above, APS adjusts $`\alpha`$ on
the fly for each query. Such adaptivity improves reasoning performance
across several tasks. In a nutshell, our main contributions are
summarized as follows:

- •
  Motivated by our empirical observation that the preferred sharpening
  strength varies across queries, we develop a theoretical
  characterization of how reasoning performance changes with the
  sharpening strength. For each query, whether a stronger sharpening is
  preferred is determined by the self-reward gap between correct and
  incorrect responses.
- •
  Building on these insights, we propose _Adaptive Power Sampling_
  (APS), which adjusts the sharpening exponent $`\alpha`$ for each query
  at test time using statistics from sampled responses. APS achieves
  query-wise adaptivity analogous to that of RL-based post-training,
  while requiring no additional training or post-training data.
- •
  We evaluate APS on multiple models and reasoning benchmarks, showing
  consistent improvements over fixed-exponent power sampling, and
  competitive performance against RL-post-trained methods.

## 2 Related Work

Reasoning via post-training. Reinforcement learning (RL) has been shown
to improve the reasoning performance of LLMs on mathematical and coding
tasks ([Ouyang et al., 2022](#bib.bib10); [Shao et al.,
2024](#bib.bib11); [DeepSeek-AI, 2025](#bib.bib12); [Yu et al.,
2025](#bib.bib13); [Liu et al., 2025](#bib.bib25); [Lin et al.,
2025](#bib.bib26)). Recent work ([Huang et al., 2025](#bib.bib16); [Yue
et al., 2025](#bib.bib14); [He et al., 2025](#bib.bib6); [Shao et al.,
2025](#bib.bib15); [Song et al., 2025](#bib.bib17)) suggests that RL
post-training can reinforce existing high-probability responses in the
model, highlighting distribution reshaping as an important mechanism
behind reasoning performance improvement. The view motivates
investigating whether similar gains can be achieved by directly
sharpening the model distribution and adapting the sharpening strength
at inference time.

Inference-time scaling improves LLM performance by allocating additional
computation at test time ([Zhang et al., 2025](#bib.bib27); [Hariri et
al., 2026](#bib.bib28)). Representative approaches include repeated
sampling and answer aggregation or selection  ([Wang et al.,
2023](#bib.bib18); [Li et al., 2022](#bib.bib19); [Brown et al.,
2024](#bib.bib7)), verifier- or reward-guided selection of candidate
solutions ([Cobbe et al., 2021](#bib.bib20); [Lightman et al.,
2024](#bib.bib21); [Chow et al., 2025](#bib.bib22)), and explicit search
over intermediate reasoning states ([Xie et al., 2023](#bib.bib23); [Yao
et al., 2023](#bib.bib8); [Zhou et al., 2024](#bib.bib24); [Snell et
al., 2024](#bib.bib9)). While effective, these methods motivate more
direct control of the model’s response distribution at inference time.

Reasoning at test time. Power sampling directly sharpens the model’s
sequence-level distribution by assigning greater weight to
high-probability responses ([Karan and Du, 2026](#bib.bib1)). It
provides a training-free alternative that can achieve reasoning
performance comparable to RL post-training while better preserving
generation diversity. Recent studies have further improved the
efficiency of sequence-level power sampling via, e.g., a future-aware
autoregressive approximation ([Ji et al., 2026](#bib.bib3)), particle
and sequential Monte Carlo methods ([Azizi et al., 2026](#bib.bib4);
[Nguyen et al., 2026](#bib.bib29); [Wang et al., 2026](#bib.bib30)) and
entropy-guided proposals ([Guo et al., 2026](#bib.bib2); [Zhou et al.,
2026](#bib.bib31)). While these methods improve sampling efficiency,
they typically rely on a predetermined sharpening strength across
queries. In contrast, our work studies how the sharpening strength
should be adaptive to individual queries.

Power sampling can also be understood from a theoretical perspective.
([Tomihari and Sato, 2026](#bib.bib5)) connects power sampling with
self-reward KL-regularized RL and self-distillation. In parallel, our
work studies how reasoning performance changes with the sharpening
strength, thereby motivating the adaptive selection of sharpening
strength at test time.

## 3 Preliminaries

### 3.1 Sequence-Level Power Distribution

Given prompt $`x`$, let $`p_{\theta}(y|x)`$ denote the probability of a
base model $`\theta`$ generating a complete response
$`y=(y^{1},\ldots,y^{T})`$. In this work, $`p_{\theta}(y|x)`$ is
referred to as the sequence-level likelihood, and by the autoregressive
factorization, it can be equivalently obtained via
$`p_{\theta}(y|x)=\prod_{t=1}^{T}p_{\theta}(y^{t}|x,y^{<t})`$.

Power sampling, originally proposed in ([Karan and Du,
2026](#bib.bib1)), leverages a sharpened sequence-level distribution to
re-weight the base model’s probability by a sharpening exponent
$`\alpha`$. For $`\alpha\geq 1`$, the sequence-level power distribution
is defined as

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\pi_{\alpha}(y|x)=\frac{p_{\theta}(y|x)^{\alpha}}{Z_{\alpha}(x)},
``` |  | (1) |

where $`Z_{\alpha}(x)=\sum_{y}p_{\theta}(y|x)^{\alpha}`$ is the
normalization constant. The exponent $`\alpha=1`$ recovers the base
model distribution, while a larger $`\alpha`$ concentrates probability
mass on higher-likelihood complete responses. To illustrate the
sharpening effect, consider two complete responses $`y`$ and
$`y^{\prime}`$ with
$`p_{\theta}(y\mid x)>p_{\theta}(y^{\prime}\mid x)`$. For $`\alpha>1`$,
their relative probabilities satisfy

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{\pi_{\alpha}(y\mid x)}{\pi_{\alpha}(y^{\prime}\mid x)}=\left(\frac{p_{\theta}(y\mid x)}{p_{\theta}(y^{\prime}\mid x)}\right)^{\alpha}>\frac{p_{\theta}(y\mid x)}{p_{\theta}(y^{\prime}\mid x)}.
``` |  | (2) |

Thus, increasing $`\alpha`$ further amplifies the relative advantage of
responses with higher base-model likelihood, making the sequence-level
distribution sharper. Note that sequence-level sharpening is
fundamentally different from token-level low-temperature scaling in
autoregressive decoding ([Wang et al., 2020](#bib.bib39)): the former
reweights complete sequences according to their sequence likelihoods,
whereas the latter rescales the next-token distribution locally at each
decoding step. This has been demonstrated multiple times, e.g., ([Karan
and Du, 2026](#bib.bib1); [Azizi et al., 2026](#bib.bib4); [Ji et al.,
2026](#bib.bib3); [Nguyen et al., 2026](#bib.bib29); [Meng et al.,
2026](#bib.bib32)).

### 3.2 One Fixed Exponent Does Not Fit Every Query

Existing power sampling algorithms ([Karan and Du, 2026](#bib.bib1);
[Azizi et al., 2026](#bib.bib4); [Ji et al., 2026](#bib.bib3); [Nguyen
et al., 2026](#bib.bib29); [Meng et al., 2026](#bib.bib32)) rely on a
fixed sharpening exponent $`\alpha`$. While it is natural to expect
different tasks, such as coding and mathematics, to favor different
values of $`\alpha`$, in this subsection we show that even within the
same dataset, no single $`\alpha`$ performs equally well across all
queries.

To illustrate this, we evaluate Qwen2.5-Math-7B ([Yang et al.,
2024b](#bib.bib36)) on 20 randomly sampled queries from the MATH500
dataset ([Lightman et al., 2024](#bib.bib21)). We consider
power-sampling exponents $`\alpha\in\{1,2,4,8,16\}`$. For each query and
each value of $`\alpha`$, we generate $`N=16`$ responses per random seed
using the MCMC sampler of [Karan and Du (2026)](#bib.bib1). We use
$`P(\alpha\mid x)`$ to denote the fraction of correct responses for
query $`x`$ at exponent $`\alpha`$.

Figure 1: Motivating example on MATH500 with Qwen2.5-Math-7B. The left
panel shows representative Pass@1 accuracy curves under power sampling
over $`\alpha\in\{1,2,4,8,16\}`$. The right panel shows the mean oracle
gap $`P^{\star}-P(\alpha)`$.

The results are shown in
Figure [1](#S3.F1 "Figure 1 ‣ 3.2 One Fixed Exponent Does Not Fit Every Query ‣ 3 Preliminaries ‣ Adaptive Power Sampling for LLM Reasoning").
In the left panel, 5 representative queries are plotted to visualize
query-wise optimal $`\alpha`$. In particular, Query A attains its
highest pass@1 accuracy only at $`\alpha=16`$ while Query B already
reaches perfect accuracy at $`\alpha=2`$. In contrast, Queries C–E
achieve their best performance at an intermediate exponent. In the right
panel, we measure the performance loss from using a common exponent
instead of the best exponent for each of the 20 sampled queries. For
each query $`x`$, let $`P^{*}(x)=\max_{a}P(a\mid x)`$ denote its best
accuracy over the tested exponents, and define the oracle gap as
$`P^{*}(x)-P(\alpha\mid x)`$. The gap is smallest at $`\alpha=2`$, with
an average value of $`0.13`$, whereas the fixed choice $`\alpha=4`$ used
in ([Karan and Du, 2026](#bib.bib1)) gives a larger gap of $`0.17`$.
These results jointly show that a single fixed $`\alpha`$ can leave a
noticeable performance gap relative to the best exponent for individual
queries, motivating an adaptive choice of $`\alpha`$ at test time.

## 4 Effect of the Sharpening Strength

In this section, we theoretically study how $`\alpha`$ affects reasoning
performance under the sequence-level power distribution. We characterize
its effect on test-time correctness and identify when sharpening is
beneficial or harmful. Following the same analytical framework, we also
obtain an extension to group-relative RL as a byproduct, where adaptive
sharpening can likewise be beneficial. Throughout this section, we
consider a fixed query $`x`$ and omit the dependence on $`x`$ for
notational simplicity.

### 4.1 Definitions

To examine how the sharpening exponent $`\alpha`$ affects the reasoning
performance, we restrict our discussion to tasks with binary correctness
outcomes, such as mathematics and coding. For a given prompt $`x`$, let
$`r^{\star}(y)\in\{0,1\}`$ denote the binary task reward of a complete
response $`y`$, where $`r^{\star}(y)=1`$ indicates a correct response
and $`r^{\star}(y)=0`$ indicates an incorrect response. Accordingly, we
partition the response space into correct and incorrect sets, i.e.,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{Y}_{C}=\{y:r^{\star}(y)=1\},\quad\mathcal{Y}_{I}=\{y:r^{\star}(y)=0\}.
``` |  | (3) |

The expected performance under exact sampling from $`\pi_{\alpha}`$ is
defined as

|     |                                                    |     |     |
|-----|----------------------------------------------------|-----|-----|
|     |
       ``` math
       P(\alpha)=\mathbb{E}_{\pi_{\alpha}}[r^{\star}(Y)].
       ```                                                 |     | (4) |

Since $`r^{\star}`$ is binary, $`P(\alpha)`$ is also the probability
that a response sampled from $`\pi_{\alpha}`$ is correct. Hence, a
preferred sharpening exponent enlarges $`P(\alpha)`$. Another useful
quantity is the model’s self-reward, which reflects the sequence-level
likelihood assigned to a response $`y`$

|     |                                            |     |     |
|-----|--------------------------------------------|-----|-----|
|     |
       ``` math
       r_{\mathrm{self}}(y)=\log p_{\theta}(y|x).
       ```                                         |     | (5) |

Under $`\pi_{\alpha}`$, the conditional self-reward means and variances
with respect to $`\alpha`$ is defined as

|  |  |  |  |  |  |  |
|----|----|----|----|----|----|----|
|  | $`\displaystyle\mu_{C}(\alpha)`$ | $`\displaystyle=\mathbb{E}_{\pi_{\alpha}}[r_{\mathrm{self}}(Y)\mid r^{\star}(Y)=1],`$ | $`\displaystyle\mu_{I}(\alpha)`$ | $`\displaystyle=\mathbb{E}_{\pi_{\alpha}}[r_{\mathrm{self}}(Y)\mid r^{\star}(Y)=0],`$ |  | (6) |
|  | $`\displaystyle\sigma^{2}_{C}(\alpha)`$ | $`\displaystyle=\mathrm{Var}_{\pi_{\alpha}}[r_{\mathrm{self}}(Y)\mid r^{\star}(Y)=1],`$ | $`\displaystyle\sigma^{2}_{I}(\alpha)`$ | $`\displaystyle=\mathrm{Var}_{\pi_{\alpha}}[r_{\mathrm{self}}(Y)\mid r^{\star}(Y)=0].`$ |  | (7) |

We then define the self-reward gap $`\delta(\alpha)`$ to measure whether
correct responses have higher model log-likelihood than incorrect
responses under the current power distribution

|     |                                                 |     |     |
|-----|-------------------------------------------------|-----|-----|
|     |
       ``` math
       \delta(\alpha)=\mu_{C}(\alpha)-\mu_{I}(\alpha).
       ```                                              |     | (8) |

### 4.2 Theoretical Basis for Adaptive Sharpening

For the test-time objective $`P(\alpha)`$, we study how the expected
reasoning performance changes as $`\alpha`$ increases. From
([1](#S3.E1 "In 3.1 Sequence-Level Power Distribution ‣ 3 Preliminaries ‣ Adaptive Power Sampling for LLM Reasoning")),
increasing $`\alpha`$ shifts relative probability mass toward responses
with higher base-model likelihood. Consequently, the marginal effect of
sharpening on $`P(\alpha)`$ depends on whether model likelihood is
aligned with the task reward. The following theorem makes this relation
exact.

###### Theorem 1.

For the fixed prompt $`x`$ and the reward $`r^{\star}`$ independent of
$`\alpha`$, we have

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{dP(\alpha)}{d\alpha}=\mathrm{Cov}_{\pi_{\alpha}}(r^{\star}(Y),r_{\mathrm{self}}(Y)).
``` |  | (9) |

Theorem [1](#Thmtheorem1 "Theorem 1. ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")
provides an exact characterization of the marginal effect of sharpening.
If task reward and self-reward are positively correlated under the
current power distribution, increasing $`\alpha`$ improves exact
expected performance. Conversely, if the covariance is negative,
additional sharpening moves probability mass in a direction that hurts
the task reward. Interestingly, the covariance in
([9](#S4.E9 "In Theorem 1. ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning"))
can be further decomposed into a simple self-reward gap, as given below.

###### Corollary 1 (Self-reward gap decomposition).

Based on the task reward $`r^{\star}\in\{0,1\}`$, we obtain

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{dP(\alpha)}{d\alpha}=P(\alpha)(1-P(\alpha))\delta(\alpha).
``` |  | (10) |

Corollary 1 has a direct interpretation. Here,
$`P(\alpha)(1-P(\alpha))`$ measures how much room is left for the
correctness probability to change under the current power distribution:
it is largest when correct and incorrect responses are both likely,
i.e., $`P(\alpha)=0.5`$, and it becomes small when the sampler almost
always succeeds or almost always fails. Prior work connects power
sampling to the correlation between task reward and self-reward
 ([Tomihari and Sato, 2026](#bib.bib5)).
Theorem [1](#Thmtheorem1 "Theorem 1. ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")
and Corollary
[1](#Thmcorollary1 "Corollary 1 (Self-reward gap decomposition). ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")
further characterize the local change in expected performance caused by
increasing $`\alpha`$. Since $`P(\alpha)\in[0,1]`$ for binary
$`r^{\star}`$, increasing $`\alpha`$ locally improves performance if
$`\delta(\alpha)>0`$ and locally degrades performance if
$`\delta(\alpha)<0`$. This reveals the source of adaptivity: if
$`\delta(\alpha)`$ is known, we can determine whether increasing or
decreasing $`\alpha`$ would improve performance for this particular
query. Next, we study how $`\delta(\alpha)`$ evolves with $`\alpha`$ to
understand when further sharpening may switch from improving performance
to degrading it, or vice versa.

###### Lemma 1 (Self-reward gap dynamics).

The self-reward gap evolves as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{d\delta(\alpha)}{d\alpha}=\sigma^{2}_{C}(\alpha)-\sigma^{2}_{I}(\alpha).
``` |  | (11) |

The self-reward gap increases when correct sequences have higher
conditional log-probability variance than incorrect sequences, and
decreases under the reverse ordering. Since the sign of
$`dP(\alpha)/d\alpha`$ is determined by $`\delta(\alpha)`$ for binary
$`r^{\star}`$, a larger conditional variance in the correct class moves
the gap toward more positive values and thereby shifts the local effect
of sharpening toward improvement. Besides, we can differentiate the
first-order identity, yielding the second-order characterization of
$`d^{2}P/d\alpha^{2}`$ in Appendix
[B](#A2 "Appendix B Additional theoretical results ‣ Adaptive Power Sampling for LLM Reasoning").

While extending the above local optimality analysis to a
characterization of the globally optimal $`\alpha^{*}\in[1,\infty)`$ is
challenging, we can still gain insight into how $`P(\alpha)`$ evolves
with $`\alpha`$. For binary $`r^{\star}`$, the sign of
$`dP(\alpha)/d\alpha`$ is determined by the sign of $`\delta(\alpha)`$.
Hence, examining $`\delta(\alpha)`$ at the two extremes, $`\alpha=1`$
and $`\alpha\to\infty`$, provides useful information about the global
behavior of $`P(\alpha)`$. The following theorem shows that
$`\delta(\infty)`$ admits a closed-form expression.

###### Theorem 2 (Limit of the self-reward gap).

As $`\alpha\to\infty`$, the self-reward gap $`\Delta_{s}`$ satisfies

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Delta_{s}\triangleq\lim_{\alpha\to\infty}\delta(\alpha)=s_{C}-s_{I},
``` |  | (12) |

where $`s_{C}=\max_{y\in\mathcal{Y}_{C}}r_{\mathrm{self}}(y)`$, and
$`s_{I}=\max_{y\in\mathcal{Y}_{I}}r_{\mathrm{self}}(y)`$.

The signs of $`\delta(1)`$ and $`\Delta_{s}`$ reveal the following four
cases. If both are positive, increasing $`\alpha`$ improves performance
near $`\alpha=1`$ and again for all sufficiently large $`\alpha`$,
although $`\delta(\alpha)`$ may still change sign at intermediate
values, causing $`dP(\alpha)/d\alpha`$ to change sign as well. If
$`\delta(1)>0`$ but $`\Delta_{s}<0`$, increasing $`\alpha`$ initially
improves performance but eventually becomes harmful. If $`\delta(1)<0`$
but $`\Delta_{s}>0`$, increasing $`\alpha`$ is initially harmful but
eventually becomes beneficial. If both are negative, increasing
$`\alpha`$ is harmful near $`\alpha=1`$ and again for sufficiently large
$`\alpha`$.

### 4.3 Extensions to Group-Relative RL

Going beyond test-time reasoning, another related sampling scenario is
group-relative RL, where multiple responses to the same query are scored
and compared to construct relative advantages for policy optimization,
as in GRPO ([Shao et al., 2024](#bib.bib11)). We next show that
replacing such standard rollouts with query-adaptive power sampling can
also be beneficial. This follows from the same analytical framework with
a modified objective, since RL requires informative reward variation
among sampled responses ([Razin et al., 2025](#bib.bib41)), rather than
simply maximizing correctness.

Precisely, for a group of $`K`$ responses independently sampled from
$`\pi_{\alpha}(y\mid x)`$ in group-relative RL, let $`R_{i}`$ denote the
reward of the $`i`$-th response and
$`\bar{R}=K^{-1}\sum_{i=1}^{K}R_{i}`$. For binary correctness rewards,
we define
$`C_{K}(\alpha)=\mathbb{E}\left[\frac{1}{K}\sum_{i=1}^{K}(R_{i}-\bar{R})^{2}\right]`$
denoting the expected within-group reward variation of $`K`$ sampled
responses. Since $`R_{i}`$ is a Bernoulli random variable with success
probability $`P(\alpha)`$, $`C_{K}(\alpha)`$ can be rewritten as

|     |                                                              |     |      |
|-----|--------------------------------------------------------------|-----|------|
|     |
       ``` math
       C_{K}(\alpha)=\frac{K-1}{K}P(\alpha)\bigl(1-P(\alpha)\bigr).
       ```                                                           |     | (13) |

A larger $`C_{K}(\alpha)`$ means more variation in the rewards within a
group, making the relative advantages among sampled responses easier to
distinguish and yielding a clearer signal for policy optimization.
Differentiating
([13](#S4.E13 "In 4.3 Extensions to Group-Relative RL ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning"))
and applying
Corollary [1](#Thmcorollary1 "Corollary 1 (Self-reward gap decomposition). ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")
gives the following theorem.

###### Theorem 3.

For the expected within-group reward variation $`C_{K}(\alpha)`$ defined
above, we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{d\mathcal{C}_{K}(\alpha)}{d\alpha}`$ | $`\displaystyle=\frac{K-1}{K}\left(1-2P(\alpha)\right)\frac{dP(\alpha)}{d\alpha}=\frac{K-1}{K}\left(1-2P(\alpha)\right)P(\alpha)\left(1-P(\alpha)\right)\delta(\alpha).`$ |  | (14) |

Theorem [3](#Thmtheorem3 "Theorem 3. ‣ 4.3 Extensions to Group-Relative RL ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")
reveals how adapting the sharpening exponent $`\alpha`$ affects
correctness probability and within-group reward variation jointly. When
$`P(\alpha)<1/2`$, an adaptation of $`\alpha`$ that increases
$`P(\alpha)`$ also increases $`C_{K}(\alpha)`$. In contrast, once
$`P(\alpha)>1/2`$, the same improvement in $`P(\alpha)`$ is accompanied
by a decrease in $`C_{K}(\alpha)`$. According to
([13](#S4.E13 "In 4.3 Extensions to Group-Relative RL ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")),
$`\mathcal{C}_{K}(\alpha)`$ is maximized at $`P(\alpha)=1/2`$, which
provides a simple criterion for adapting the sharpening strength in
group-relative RL. We therefore adapt $`\alpha`$ to maximize
$`C_{K}(\alpha)`$, or equivalently, to make the correctness probability
close to $`1/2`$. The detailed procedure and experiments are presented
in
Appendix [C](#A3 "Appendix C Adaptive Power Sharpening in group-relative RL ‣ Adaptive Power Sampling for LLM Reasoning").

Lastly, we develop a unified framework that subsumes both the test-time
objective $`P(\alpha)`$ and the within-group reward variation
$`C_{K}(\alpha)`$; see
Appendix [B](#A2 "Appendix B Additional theoretical results ‣ Adaptive Power Sampling for LLM Reasoning").
More broadly, this framework provides a recipe for adapting the
sharpening strength in other power sampling-based settings.

## 5 Adaptive Power Sampling

This section translates the theoretical insights into practical
algorithms.

### 5.1 Estimating the Sharpening Direction

Theorem [1](#Thmtheorem1 "Theorem 1. ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")
and
Corollary [1](#Thmcorollary1 "Corollary 1 (Self-reward gap decomposition). ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")
show that the sharpening exponent $`\alpha`$ can be adjusted to improve
$`P(\alpha)`$ according to the alignment between true reward and model’s
self-reward. In practice, however, the true task reward is unavailable
at test time. To address this challenge, we develop an efficient
algorithm, *Adaptive Power Sampling* (APS), which uses self-consistency
among sampled answers as a surrogate signal to adaptively adjust
$`\alpha`$ during inference.

APS proceeds iteratively. At iteration $`t`$, given the current exponent
$`\alpha_{t}`$, suppose that $`N_{t}\geq 2`$ responses
$`\{y_{i,t}\}_{i=1}^{N_{t}}`$ are available. For simplicity, we omit the
iteration index $`t`$ and write $`y_{i}`$. For each response $`y_{i}`$,
we compute its self-reward as

|     |                                                              |     |      |
|-----|--------------------------------------------------------------|-----|------|
|     |
       ``` math
       s_{i}=r_{\mathrm{self}}(y_{i})=\log p_{\theta}(y_{i}\mid x).
       ```                                                           |     | (15) |

To reduce variations in the scale of self-reward, we standardize the
self-reward of each response as

|     |                                                         |     |      |
|-----|---------------------------------------------------------|-----|------|
|     |
       ``` math
       z_{i}=\frac{s_{i}-\bar{s}_{t}}{\widehat{\sigma}_{s,t}},
       ```                                                      |     | (16) |

where $`\bar{s}_{t}=\frac{1}{N_{t}}\sum_{i=1}^{N_{t}}s_{i}`$ and
$`\widehat{\sigma}_{s,t}=\left[\frac{1}{N_{t}}\sum_{i=1}^{N_{t}}(s_{i}-\bar{s}_{t})^{2}\right]^{1/2}`$.

Since the ground-truth correctness of each response is unavailable at
test time, we design answer agreement as a surrogate signal. This is
inspired by self-consistency methods ([Wang et al., 2023](#bib.bib18);
[Aggarwal et al., 2023](#bib.bib37)) , where agreement across
independently sampled reasoning paths provides a useful indication of
answer confidence and is often associated with answer correctness. By
denoting $`e_{i}`$ as the normalized answer key of $`y_{i}`$, the
answer-agreement score of $`y_{i}`$ is defined as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
v_{i}=\frac{\mathbf{1}[e_{i}\neq\mathrm{invalid}]}{N_{t}-1}\sum_{j\neq i}\mathbf{1}[e_{j}=e_{i}],
``` |  | (17) |

where $`\mathbf{1}[\cdot]`$ denotes the indicator function, which equals
one when the condition inside the brackets is satisfied and zero
otherwise. For a valid answer, $`v_{i}`$ measures the fraction of other
sampled responses giving the same answer as $`y_{i}`$. For an invalid
answer, $`v_{i}=0`$. A larger $`v_{i}`$ indicates stronger support from
the other samples and is treated as evidence that the answer $`y_{i}`$
is more likely to be correct.

Based on the answer-agreement scores and normalized self-rewards, we
therefore define the following score for determining the sharpening
direction, i.e., whether $`\alpha`$ should be increased or decreased:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\widehat{g}_{t}`$ | $`\displaystyle=\frac{1}{N_{t}}\sum_{i=1}^{N_{t}}(v_{i}-\bar{v}_{t})z_{i}=\frac{1}{N_{t}\widehat{\sigma}_{s,t}}\sum_{i=1}^{N_{t}}(v_{i}-\bar{v}_{t})(s_{i}-\bar{s}_{t}).`$ |  | (18) |

where $`\bar{v}_{t}=\frac{1}{N_{t}}\sum_{i=1}^{N_{t}}v_{i}`$. The sign
of $`\hat{g}_{t}`$ reflects whether answer agreement and self-reward
vary in the same direction with $`\hat{\sigma}_{s,t}>0`$. In particular,
$`\hat{g}_{t}>0`$ indicates that responses with stronger agreement tend
to have higher self-reward, which is consistent with the favorable case
identified in Section
[4](#S4 "4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning").
We should therefore increase $`\alpha`$. The magnitude of
$`\hat{g}_{t}`$ further reflects the strength of this relationship and
is used to determine the amount by which $`\alpha`$ is adjusted. If
$`\hat{\sigma}_{s,t}=0`$, the sampled responses have identical
self-reward, and we set $`\hat{g}_{t}=0`$. When all agreement scores are
identical, the samples provide no preferred sharpening direction; APS
keeps $`\alpha_{t}`$ unchanged and collects additional samples.

### 5.2 Adaptive Exponent Update

Given the estimate $`\widehat{g}_{t}`$, APS updates the sharpening
exponent via gradient ascent strategy:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
{\alpha}_{t+1}=\operatorname{clip}\left(\alpha_{t}+\eta\widehat{g}_{t},\alpha_{\min},\alpha_{\max}\right),
``` |  | (19) |

where $`\eta`$ is the stepsize and $`\operatorname{clip}(\cdot)`$
ensures that the updated exponent remains within the appropriate range
$`[\alpha_{\min},\alpha_{\max}]`$. The exponent adaptation is performed
under both sampling-quality and budget constraints. At iteration $`t`$,
we monitor the batch-level MCMC acceptance rate
$`\widehat{q}_{t}=A_{t}/P_{t}`$, where $`A_{t}`$ and $`P_{t}`$ denote
the numbers of accepted and total Metropolis–Hastings (MH) proposals
used to generate the current batch at $`\alpha_{t}`$, respectively. We
use $`\widehat{q}_{t}`$ as a sampler-quality diagnostic ([Karan and Du,
2026](#bib.bib1)). If the optional quality threshold $`q_{\min}`$ is
enabled and $`\widehat{q}_{t}<q_{\min}`$, the adaptive search is
terminated. Let $`C`$ denote the total sample budget and $`c`$ the
number of samples generated so far. The adaptive search continues only
when the remaining budget is sufficient to generate another batch of
$`K`$ samples. The adaptive search also terminates if either
$`|\widehat{g}_{t}|\leq\epsilon`$, indicating insufficient evidence for
changing $`\alpha_{t}`$, or $`\alpha_{t+1}=\alpha_{t}`$, indicating that
the proposed update cannot move the exponent.

APS retains the last exponent passing the sampling-quality check as
$`\alpha^{\star}`$, with $`\alpha^{\star}=1`$ as the initial fallback.
After adaptation, the remaining budget is spent at $`\alpha^{\star}`$,
and samples collected at this exponent are pooled for majority voting
over valid answers, breaking ties by the mean self-reward of supporting
responses.
Algorithm [1](#alg1 "Algorithm 1 ‣ 5.2 Adaptive Exponent Update ‣ 5 Adaptive Power Sampling ‣ Adaptive Power Sampling for LLM Reasoning")
summarizes the procedure. APS adjusts the sharpening strength for each
query through the estimated alignment between answer agreement and
self-reward: its sign determines whether to increase $`\alpha`$, while
its magnitude determines the update size, without requiring ground-truth
answers.

0:  Prompt $`x`$, base model $`p_{\theta}`$, $`\alpha_{1}`$,
$`\alpha_{\min}`$, $`\alpha_{\max}`$, $`K`$, $`C`$, $`\eta`$,
$`q_{\min}`$, $`\epsilon`$

1:  Initialize $`c\leftarrow 0`$, $`\alpha^{\star}\leftarrow 1`$, and
$`\mathcal{B}_{\alpha}\leftarrow\emptyset`$

2:  for $`t=1,2,\ldots`$ while $`c+K\leq C`$ do

3:   Draw $`K`$ sequence-level MCMC samples from
$`p_{\theta}(y|x)^{\alpha_{t}}`$; set $`c\leftarrow c+K`$

4:   For each $`y_{i}`$, extract $`e_{i}`$, $`s_{i}`$, and display
answer $`d_{i}`$

5:   Estimate sampler quality $`\widehat{q}_{t}`$ from the MCMC
acceptance rate

6:   if $`q_{\min}`$ is enabled and $`\widehat{q}_{t}<q_{\min}`$ then

7:    break

8:   end if

9:   Add the current samples to $`\mathcal{B}_{\alpha_{t}}`$, set
$`\alpha^{\star}\leftarrow\alpha_{t}`$ and
$`N_{t}\leftarrow|\mathcal{B}_{\alpha_{t}}|`$, and compute $`v_{i}`$ via
([17](#S5.E17 "In 5.1 Estimating the Sharpening Direction ‣ 5 Adaptive Power Sampling ‣ Adaptive Power Sampling for LLM Reasoning"))

10:   if $`v_{i}=1`$ for all $`i=1,\ldots,N_{t}`$ then

11:    break

12:   else if $`v_{i}=\bar{v}_{t}`$ for all $`i=1,\ldots,N_{t}`$ then

13:    Set $`\alpha_{t+1}\leftarrow\alpha_{t}`$ and continue

14:   end if

15:   Compute $`z_{i}`$ via
([16](#S5.E16 "In 5.1 Estimating the Sharpening Direction ‣ 5 Adaptive Power Sampling ‣ Adaptive Power Sampling for LLM Reasoning"));
if $`\hat{\sigma}_{s,t}=0`$, set $`z_{i}\leftarrow 0`$

16:   Estimate $`\widehat{g}_{t}`$ via
([18](#S5.E18 "In 5.1 Estimating the Sharpening Direction ‣ 5 Adaptive Power Sampling ‣ Adaptive Power Sampling for LLM Reasoning")),
and set $`{\alpha}_{t+1}`$ via
([19](#S5.E19 "In 5.2 Adaptive Exponent Update ‣ 5 Adaptive Power Sampling ‣ Adaptive Power Sampling for LLM Reasoning"))

17:   if $`|\widehat{g}_{t}|\leq\epsilon`$ or
$`{\alpha}_{t+1}=\alpha_{t}`$ or $`c+K>C`$ then

18:    break

19:   end if

20:  end for

21:  Use the remaining budget to sample at $`\alpha^{\star}`$ and add
the samples to $`\mathcal{B}_{\alpha^{\star}}`$; select the most
frequent valid answer, breaking ties by the highest mean self-reward
among its supporting samples

22:  return The corresponding display answer, or an empty answer if all
samples are invalid

## 6 Experiments

### 6.1 Experimental Setup

#### Models.

We evaluate APS on four models: Qwen2.5-7B ([Yang et al.,
2024a](#bib.bib35)), Qwen2.5-Math-7B ([Yang et al., 2024b](#bib.bib36)),
DeepSeek-Math-7B ([Shao et al., 2024](#bib.bib11)), and
DeepSeek-Math-7B-RL ([Shao et al., 2024](#bib.bib11)). Qwen2.5-7B is a
general-purpose model, while Qwen2.5-Math-7B and DeepSeek-Math-7B are
math-focused models.

#### Benchmarks and Baselines.

We use three reasoning benchmarks. MATH500 ([Lightman et al.,
2024](#bib.bib21)) evaluates multi-step mathematical reasoning through
correctness of the final answer. HumanEval ([Chen et al.,
2021](#bib.bib33)) contains 164 Python programming tasks evaluated by
functional correctness. GPQA Diamond ([Rein et al., 2024](#bib.bib34))
contains 198 expert-level multiple-choice questions in physics,
chemistry, and biology. For the compared methods, base decoding denotes
standard autoregressive sampling from the original model distribution,
while low-temperature applies token-level temperature scaling with
$`T=1/\alpha`$ ([Wang et al., 2020](#bib.bib39)). The sequence-level
sampling baselines include several methods that use a fixed sharpening
exponent $`\alpha`$ with different sampling strategies, such as power
sampling ([Karan and Du, 2026](#bib.bib1)), scalable power sampling
(SPS) ([Ji et al., 2026](#bib.bib3)), power sampling with sequential
Monte Carlo (Power-SMC) ([Azizi et al., 2026](#bib.bib4)), and auxiliary
particle power sampling (APPS) ([Nguyen et al., 2026](#bib.bib29)). We
set $`\alpha=4`$ for all the fixed-exponent baselines. More
implementation details are provided in Appendix
[D](#A4 "Appendix D Supplementary Experimental Results ‣ Adaptive Power Sampling for LLM Reasoning").

### 6.2 Main Results

#### Pass@1 Performance.

Table [1](#S6.T1 "Table 1 ‣ Pass@1 Performance. ‣ 6.2 Main Results ‣ 6 Experiments ‣ Adaptive Power Sampling for LLM Reasoning")
summarizes the pass@1 accuracy results on MATH500, HumanEval, and GPQA.
GRPO (MATH) comes from [Shao et al. (2025)](#bib.bib15) for Qwen and
DeepSeek-Math-7B-RL for DeepSeek [Shao et al. (2024)](#bib.bib11).
Compared with base decoding, low-temperature sampling generally yields
performance improvements, showing that sharpening the next-token
distribution at each decoding step can already improve reasoning
performance. The sequence-level sampling baselines with fixed sharpening
exponent, including Power Sampling, SPS, Power-SMC, and APPS, generally
outperform low-temperature sampling, suggesting that sequence-level
distribution sharpening can provide additional gains beyond token-level
temperature scaling. More importantly, APS achieves the best performance
among all baselines in most cases. These results further validate the

[3.2](#S3.SS2 "3.2 One Fixed Exponent Does Not Fit Every Query ‣ 3 Preliminaries ‣ Adaptive Power Sampling for LLM Reasoning"),
where different queries favor different sharpening strengths. Unlike
these fixed-exponent methods, APS adjusts $`\alpha`$ according to the
sampled responses and hence adapts the sharpening strength to the
current query. By adapting $`\alpha`$ online, APS could exploit the
reasoning capability already contained in the base model more
effectively.

We further compare APS with GRPO, which is used to post-train the model
on MATH. Although GRPO achieves strong performance on the in-domain
MATH500 benchmark, its gains are less consistent on HumanEval and GPQA.
In contrast, APS requires no additional training and achieves
consistently strong performance across all three benchmarks. These
results show that adaptive inference-time sharpening can effectively
improve reasoning performance across different tasks without updating
the model parameters or relying on an external reward for post-training.

## 7 Conclusion

This work proposes *Adaptive Power Sampling* (APS) to equip power
sampling for LLM reasoning with query-level adaptivity. Motivated by the
empirical observation that the preferred sharpening strength is not
universal across queries, we theoretically characterize how the effect
of increasing the sharpening strength depends on the self-reward gap
between correct and incorrect responses. We empirically show that this
gap can be estimated using the correlation between answer agreement and
the model’s self-reward. Together, this theoretical characterization and
practical adaptation enable APS to consistently improve test-time
reasoning across diverse models and datasets, achieving consistent
performance gain over power sampling with a fixed sharpening exponent,
without additional training.

## Appendix A Proofs

### A.1 Proof of Theorem [1](#Thmtheorem1 "Theorem 1. ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")

For a fixed prompt $`x`$, according to the definition of $`P(\alpha)`$
in
([4](#S4.E4 "In 4.1 Definitions ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")),
we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{dP(\alpha)}{d\alpha}`$ | $`\displaystyle=\frac{d}{d\alpha}\sum_{y}r^{\star}(y)\frac{p_{\theta}(y\mid x)^{\alpha}}{Z_{\alpha}}`$ |  |  |
|  |  | $`\displaystyle=\sum_{y}r^{\star}(y)\frac{r_{\mathrm{self}}(y)p_{\theta}(y\mid x)^{\alpha}Z_{\alpha}-p_{\theta}(y\mid x)^{\alpha}Z_{\alpha}^{\prime}}{Z_{\alpha}^{2}}`$ |  |  |
|  |  | $`\displaystyle=\sum_{y}r^{\star}(y)\pi_{\alpha}(y)\left[r_{\mathrm{self}}(y)-\frac{Z_{\alpha}^{\prime}}{Z_{\alpha}}\right]`$ |  |  |
|  |  | $`\displaystyle=\mathbb{E}_{\pi_{\alpha}}\left[r^{\star}(Y)r_{\mathrm{self}}(Y)\right]-\mathbb{E}_{\pi_{\alpha}}\left[r^{\star}(Y)\right]\mathbb{E}_{\pi_{\alpha}}\left[r_{\mathrm{self}}(Y)\right]`$ |  |  |
|  |  | $`\displaystyle=\operatorname{Cov}_{\pi_{\alpha}}\left(r^{\star}(Y),r_{\mathrm{self}}(Y)\right)`$ |  | (20) |

where
$`Z_{\alpha}^{\prime}=\sum_{y}p_{\theta}(y\mid x)^{\alpha}\log p_{\theta}(y\mid x)`$.
The proof is thus completed.

### A.2 Proof of Corollary [1](#Thmcorollary1 "Corollary 1 (Self-reward gap decomposition). ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")

For binary $`r^{\star}`$,
$`P(\alpha)=\Pr_{\pi_{\alpha}}(r^{\star}(Y)=1)`$. We then have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\operatorname{Cov}_{\pi_{\alpha}}\left(r^{\star}(Y),r_{\mathrm{self}}(Y)\right)`$ | $`\displaystyle=\mathbb{E}_{\pi_{\alpha}}\left[r^{\star}(Y)r_{\mathrm{self}}(Y)\right]-\mathbb{E}_{\pi_{\alpha}}\left[r^{\star}(Y)\right]\mathbb{E}_{\pi_{\alpha}}\left[r_{\mathrm{self}}(Y)\right]`$ |  |  |
|  |  | $`\displaystyle=P(\alpha)\mu_{C}(\alpha)-P(\alpha)\mathbb{E}_{\pi_{\alpha}}\left[r_{\mathrm{self}}(Y)\right]`$ |  |  |
|  |  | $`\displaystyle=P(\alpha)\left[\mu_{C}(\alpha)-P(\alpha)\mu_{C}(\alpha)-\bigl(1-P(\alpha)\bigr)\mu_{I}(\alpha)\right]`$ |  |  |
|  |  | $`\displaystyle=P(\alpha)\bigl(1-P(\alpha)\bigr)\left[\mu_{C}(\alpha)-\mu_{I}(\alpha)\right]=P(\alpha)\bigl(1-P(\alpha)\bigr)\delta(\alpha),`$ |  | (21) |

where the last step uses
$`\mathbb{E}_{\pi_{\alpha}}[r_{\mathrm{self}}(Y)]=P(\alpha)\mu_{C}(\alpha)+(1{-}P(\alpha))\mu_{I}(\alpha)`$.

### A.3 Proof of Lemma [1](#Thmlemma1 "Lemma 1 (Self-reward gap dynamics). ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")

For fixed $`x`$, define

|  |  |  |  |
|----|----|----|----|
|  |
``` math
Z_{C}(\alpha)=\sum_{y\in\mathcal{Y}_{C}}p_{\theta}(y\mid x)^{\alpha},\qquad Z_{I}(\alpha)=\sum_{y\in\mathcal{Y}_{I}}p_{\theta}(y\mid x)^{\alpha}.
``` |  | (22) |

For $`y\in\mathcal{Y}_{C}`$, the distribution of correct responses under
$`\pi_{\alpha}`$ is denoted as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Pr_{\pi_{\alpha}}\!\left(Y=y\mid r^{\star}(Y)=1\right)=\frac{p_{\theta}(y\mid x)^{\alpha}}{Z_{C}(\alpha)}.
``` |  | (23) |

It follows that

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mu_{C}(\alpha)`$ | $`\displaystyle=\frac{\sum_{y\in\mathcal{Y}_{C}}p_{\theta}(y\mid x)^{\alpha}r_{\mathrm{self}}(y)}{Z_{C}(\alpha)}=\frac{Z_{C}^{\prime}(\alpha)}{Z_{C}(\alpha)}=\frac{d}{d\alpha}\log Z_{C}(\alpha).`$ |  | (24) |

By differentiating
([24](#A1.E24 "In A.3 Proof of Lemma ‣ Appendix A Proofs ‣ Adaptive Power Sampling for LLM Reasoning")),
we obtain

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{d\mu_{C}(\alpha)}{d\alpha}`$ | $`\displaystyle=\frac{\sum_{y\in\mathcal{Y}_{C}}p_{\theta}(y\mid x)^{\alpha}r_{\mathrm{self}}^{2}(y)}{Z_{C}(\alpha)}-\left(\frac{\sum_{y\in\mathcal{Y}_{C}}p_{\theta}(y\mid x)^{\alpha}r_{\mathrm{self}}(y)}{Z_{C}(\alpha)}\right)^{2}`$ |  |  |
|  |  | $`\displaystyle=\mathbb{E}_{\pi_{\alpha}}\left[r_{\mathrm{self}}^{2}(Y)\mid r^{\star}(Y)=1\right]-\mu_{C}^{2}(\alpha)=\sigma_{C}^{2}(\alpha).`$ |  | (25) |

The same calculation for the incorrect responses gives

|     |                                                          |     |      |
|-----|----------------------------------------------------------|-----|------|
|     |
       ``` math
       \frac{d\mu_{I}(\alpha)}{d\alpha}=\sigma_{I}^{2}(\alpha).
       ```                                                       |     | (26) |

Since $`\delta(\alpha)=\mu_{C}(\alpha)-\mu_{I}(\alpha)`$, we have

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{d\delta(\alpha)}{d\alpha}=\sigma_{C}^{2}(\alpha)-\sigma_{I}^{2}(\alpha),
``` |  | (27) |

which proves the lemma.

### A.4 Proof of Theorem [2](#Thmtheorem2 "Theorem 2 (Limit of the self-reward gap). ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")

Taking any $`y,y^{\prime}\in\mathcal{Y}_{C}`$ with
$`r_{\mathrm{self}}(y)<r_{\mathrm{self}}(y^{\prime})`$ as an example, as
$`\alpha\to\infty`$, their conditional probability ratio satisfies

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{\Pr_{\pi_{\alpha}}(Y=y\mid r^{\star}(Y)=1)}{\Pr_{\pi_{\alpha}}(Y=y^{\prime}\mid r^{\star}(Y)=1)}=\exp\left\{\alpha\left[r_{\mathrm{self}}(y)-r_{\mathrm{self}}(y^{\prime})\right]\right\}\rightarrow 0.
``` |  | (28) |

Thus, the conditional distribution over $`\mathcal{Y}_{C}`$ concentrates
on the highest-self-reward responses in the correct class. The same
argument applies to $`\mathcal{Y}_{I}`$. Hence,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\lim_{\alpha\to\infty}\mu_{C}(\alpha)=s_{C},\qquad\lim_{\alpha\to\infty}\mu_{I}(\alpha)=s_{I},
``` |  | (29) |

and therefore

|     |                                                              |     |      |
|-----|--------------------------------------------------------------|-----|------|
|     |
       ``` math
       \lim_{\alpha\to\infty}\delta(\alpha)=s_{C}-s_{I}=\Delta_{s},
       ```                                                           |     | (30) |

which proves the theorem.

## Appendix B Additional theoretical results

### B.1 Second-Order Effect of Sharpening

###### Proposition 1.

The second derivative of the performance with respect to the sharpening
exponent $`\alpha`$ is given by

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{d^{2}P}{d\alpha^{2}}=P(\alpha)(1-P(\alpha))\left[(1-2P(\alpha))\delta(\alpha)^{2}+\sigma^{2}_{C}(\alpha)-\sigma^{2}_{I}(\alpha)\right].
``` |  | (31) |

Proposition
[1](#Thmproposition1 "Proposition 1. ‣ B.1 Second-Order Effect of Sharpening ‣ Appendix B Additional theoretical results ‣ Adaptive Power Sampling for LLM Reasoning")
follows directly by differentiating the first-order performance relation
in
([10](#S4.E10 "In Corollary 1 (Self-reward gap decomposition). ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning"))
and applying
Lemma [1](#Thmlemma1 "Lemma 1 (Self-reward gap dynamics). ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning").
The sign of
([31](#A2.E31 "In Proposition 1. ‣ B.1 Second-Order Effect of Sharpening ‣ Appendix B Additional theoretical results ‣ Adaptive Power Sampling for LLM Reasoning"))
is determined by two factors. First, the term
$`(1-2P(\alpha))\delta^{2}`$ could remain positive on hard queries with
$`P(\alpha)<1/2`$ and negative on easy queries with $`P(\alpha)>1/2`$.
From
Lemma [1](#Thmlemma1 "Lemma 1 (Self-reward gap dynamics). ‣ 4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning"),
the variance-difference term equals $`d\delta(\alpha)/d\alpha`$ and
therefore indicates whether the self-reward gap is widening or narrowing
as $`\alpha`$ increases. This decomposition immediately yields a simple
sufficient condition for concavity. If $`P(\alpha)>1/2`$ and
$`\sigma_{C}^{2}(\alpha)\leq\sigma_{I}^{2}(\alpha)`$, both terms in
([31](#A2.E31 "In Proposition 1. ‣ B.1 Second-Order Effect of Sharpening ‣ Appendix B Additional theoretical results ‣ Adaptive Power Sampling for LLM Reasoning"))
are non-positive, and hence $`\frac{d^{2}P}{d\alpha^{2}}\leq 0`$.
Therefore, for queries that are already more likely to be solved than
not under this variance condition, the performance is locally concave in
$`\alpha`$. If $`\delta(\alpha)>0`$ also holds, the performance still
increases with $`\alpha`$, but at a decreasing rate.

### B.2 Generalization to Sample-Based Objectives

We further generalize the preceding analysis to objectives defined over
multiple responses sampled from the power distribution. Let $`s`$ index
a scenario and $`Y_{1},\ldots,Y_{K_{s}}`$ be independently sampled from
$`\pi_{\alpha}(y\mid x)`$. Let $`\ell_{s}(Y_{1:K_{s}})`$ denote a
statistic of interest with no explicit dependence on $`\alpha`$. We
define the corresponding scenario objective as

|     |                                                             |     |      |
|-----|-------------------------------------------------------------|-----|------|
|     |
       ``` math
       J_{s}(\alpha)=\mathbb{E}\left[\ell_{s}(Y_{1:K_{s}})\right],
       ```                                                          |     | (32) |

where the expectation is taken over the $`K_{s}`$ independent samples
from $`\pi_{\alpha}(\cdot\mid x)`$. Then the following theorem
characterizes how the sharpening exponent $`\alpha`$ affects the
scenario objective defined above.

###### Proposition 2.

The scenario objective in
([32](#A2.E32 "In B.2 Generalization to Sample-Based Objectives ‣ Appendix B Additional theoretical results ‣ Adaptive Power Sampling for LLM Reasoning"))
satisfies

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{dJ_{s}(\alpha)}{d\alpha}=\operatorname{Cov}\left(\ell_{s}(Y_{1:K_{s}}),\sum_{i=1}^{K_{s}}r_{\mathrm{self}}(Y_{i})\right),
``` |  | (33) |

where the covariance is taken over the same $`K_{s}`$ independent
responses sampled from $`\pi_{\alpha}(\cdot\mid x)`$.

###### Proof.

Define the joint distribution of the $`K_{s}`$ independent responses
under prompt $`x`$ as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
q_{\alpha}(y_{1:K_{s}}\mid x)=\prod_{i=1}^{K_{s}}\pi_{\alpha}(y_{i}\mid x).
``` |  | (34) |

Since $`\ell_{s}(Y_{1:K_{s}})`$ has no explicit dependence on
$`\alpha`$, applying the log-derivative identity gives

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{dJ_{s}(\alpha)}{d\alpha}`$ | $`\displaystyle=\mathbb{E}_{q_{\alpha}}\left[\ell_{s}(Y_{1:K_{s}})\frac{\partial}{\partial\alpha}\log q_{\alpha}(Y_{1:K_{s}}\mid x)\right].`$ |  | (35) |

Since the $`K_{s}`$ responses are independently sampled,

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{\partial}{\partial\alpha}\log q_{\alpha}(Y_{1:K_{s}}\mid x)`$ | $`\displaystyle=\sum_{i=1}^{K_{s}}\frac{\partial}{\partial\alpha}\log\pi_{\alpha}(Y_{i}\mid x).`$ |  | (36) |

From the power distribution
$`\pi_{\alpha}(y\mid x)=\frac{p_{\theta}(y\mid x)^{\alpha}}{Z_{\alpha}(x)}`$,
we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{\partial}{\partial\alpha}\log\pi_{\alpha}(Y_{i}\mid x)`$ | $`\displaystyle=\log p_{\theta}(Y_{i}\mid x)-\frac{\partial}{\partial\alpha}\log Z_{\alpha}(x)`$ |  |  |
|  |  | $`\displaystyle=r_{\mathrm{self}}(Y_{i})-\mathbb{E}_{\pi_{\alpha}}\left[r_{\mathrm{self}}(Y)\right].`$ |  | (37) |

Therefore,

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{dJ_{s}(\alpha)}{d\alpha}`$ | $`\displaystyle=\mathbb{E}\left[\ell_{s}(Y_{1:K_{s}})\left(\sum_{i=1}^{K_{s}}r_{\mathrm{self}}(Y_{i})-K_{s}\mathbb{E}_{\pi_{\alpha}}\left[r_{\mathrm{self}}(Y)\right]\right)\right].`$ |  | (38) |

Since the responses are identically distributed,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
K_{s}\mathbb{E}_{\pi_{\alpha}}\left[r_{\mathrm{self}}(Y)\right]=\mathbb{E}\left[\sum_{i=1}^{K_{s}}r_{\mathrm{self}}(Y_{i})\right].
``` |  | (39) |

Hence,

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{dJ_{s}(\alpha)}{d\alpha}`$ | $`\displaystyle\!=\!\mathbb{E}\!\left[\!\ell_{s}(Y_{1:K_{s}})\!\!\left(\sum_{i=1}^{K_{s}}r_{\mathrm{self}}(Y_{i})\!-\!\mathbb{E}\!\left[\sum_{i=1}^{K_{s}}r_{\mathrm{self}}(Y_{i})\!\right]\!\right)\!\right]\!\!=\!\!\operatorname{Cov}\!\left(\!\ell_{s}(Y_{1:K_{s}}),\sum_{i=1}^{K_{s}}r_{\mathrm{self}}(Y_{i})\!\right).`$ |  | (40) |

∎

Proposition [2](#Thmproposition2 "Proposition 2. ‣ B.2 Generalization to Sample-Based Objectives ‣ Appendix B Additional theoretical results ‣ Adaptive Power Sampling for LLM Reasoning")
shows that the marginal effect of sharpening is determined by the
alignment between the scenario-specific statistic and the aggregate
self-reward of the sampled responses. For test-time inference, setting
$`K_{s}=1`$ and $`\ell_{s}(Y)=r^{\star}(Y)`$ recovers the performance
derivative derived in Section
[4.2](#S4.SS2 "4.2 Theoretical Basis for Adaptive Sharpening ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning").
For rollout generation in group-relative RL, taking $`\ell_{s}`$ as the
within-group reward variance recovers $`C_{K}(\alpha)`$. This provides a
common way to analyze how sharpening affects both test-time reasoning
and RL rollout generation.

## Appendix C Adaptive Power Sharpening in group-relative RL

### C.1 Adaptive Sharpening Exponent Selection

In this appendix, we investigate whether the rollout objective derived
in
Appendix [A](#A1 "Appendix A Proofs ‣ Adaptive Power Sampling for LLM Reasoning")
can be used to adapt the sharpening strength for group-relative RL
training, focusing on GRPO. For binary rewards, the analysis of Theorem
[3](#Thmtheorem3 "Theorem 3. ‣ 4.3 Extensions to Group-Relative RL ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")
shows that the sharpening exponent $`\alpha`$ directly controls the
within-group reward variation. Motivated by this result, we adapt
$`\alpha`$ separately for each training prompt before generating the
rollout group used for the subsequent GRPO update.

To translate the rollout objective into a practical procedure, we
compare candidate sharpening exponents using a small number of pilot
responses. For each prompt and each exponent candidate
$`\alpha^{(j)}\in\Delta`$, we generate $`k_{p}`$ pilot responses using
token-level low-temperature $`T=1/\alpha^{(j)}`$ ([Wang et al.,
2020](#bib.bib39)). Since the correctness reward $`r^{\star}`$ is
available during RL post-training, we estimate the correctness
probability for each candidate as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{P}_{j}=\frac{1}{k_{p}}\sum_{i=1}^{k_{p}}r^{\star}\!\left(\tilde{y}^{(j)}_{i}\right),
``` |  | (41) |

where $`\tilde{y}^{(j)}_{i}`$ denotes the $`i`$-th pilot response
associated with candidate exponent $`\alpha^{(j)}`$. Based on
([13](#S4.E13 "In 4.3 Extensions to Group-Relative RL ‣ 4 Effect of the Sharpening Strength ‣ Adaptive Power Sampling for LLM Reasoning")),
the corresponding within-group reward variation is estimated by

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{C}_{K}\!\left(\alpha^{(j)}\right)=\frac{K-1}{K}\widehat{P}_{j}\left(1-\widehat{P}_{j}\right).
``` |  | (42) |

We then select

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\alpha^{\star}=\arg\max_{\alpha^{(j)}\in\Delta}\widehat{C}_{K}\!\left(\alpha^{(j)}\right).
``` |  | (43) |

If there is a tie, we choose the smallest exponent as
$`\alpha^{\star}`$. Note that token-level low-temperature is only used
as a practical approximation to compare candidate exponents; After
selecting $`\alpha^{\star}`$, we draw $`K`$ sequence-level MCMC samples
from $`p_{\theta}(y|x)^{\alpha^{\star}}`$ using the same sampler as in
Section [5](#S5 "5 Adaptive Power Sampling ‣ Adaptive Power Sampling for LLM Reasoning").
These samples form the rollout group, which is evaluated with
correctness reward $`r^{\star}`$ and used for the standard GRPO update.
Algorithm [2](#alg2 "Algorithm 2 ‣ C.1 Adaptive Sharpening Exponent Selection ‣ Appendix C Adaptive Power Sharpening in group-relative RL ‣ Adaptive Power Sampling for LLM Reasoning")
summarizes the complete rollout generation and update procedure.

4:  end for

5:  Select $`\alpha^{\star}`$ using
````
