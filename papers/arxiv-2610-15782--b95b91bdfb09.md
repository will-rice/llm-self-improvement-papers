###### Abstract

^(†)^(†)footnotetext: \*Equal contribution. ^(🖂) Corresponding
authors.  
   $`\dagger`$ This work was performed at Shanghai AI Laboratory.

Vision-language navigation requires agents to follow natural-language
instructions to reach target locations, making high-quality language
supervision essential. Since human annotation is costly, prior work has
explored scalable data synthesis methods. However, existing methods
typically either use separate models for navigation and instruction
generation or couple the two tasks through task-specific components;
most also annotate the full trajectory corpus with a fixed model before
updating, which can cause generated supervision to lag behind the
evolving policy. Therefore, we introduce RSI-Nav, a data-centric
recursive self-improvement framework for navigation via
policy-synchronized language-action dual bootstrapping, which unifies
vision-language-to-action instruction following and
vision-action-to-language instruction generation within a shared model.
Specifically, after supervised fine-tuning establishes fundamental
capabilities, RSI-Nav progressively processes unlabeled trajectories in
small shards. The current model generates instructions for these
trajectories, executes them to evaluate goal completion and path
efficiency, retains qualified samples, and immediately updates itself
before processing the next shard. This shard-wise update keeps newly
generated supervision aligned with the evolving policy. We also
incorporate spatial understanding data, since stronger spatial reasoning
benefits navigation. Extensive experiments show that RSI-Nav reaches
68.6% SR on R2R-CE and 72.4% SR on RxR-CE, while providing stronger
instruction-generation utility and modestly improved spatial
understanding after recursive evolution.

## 1 Introduction

Vision-language navigation (VLN) requires an embodied agent to ground
natural-language instructions in visual observations and execute
sequential actions to reach a target. This task begins with
R2R ([Anderson et al., 2018](#bib.bib49)) and has expanded to
longer-range navigation in RxR ([Ku et al., 2020](#bib.bib47)),
goal-oriented settings such as REVERIE ([Qi et al., 2020](#bib.bib48))
and SOON ([Zhu et al., 2021](#bib.bib50)), and continuous navigation in
VLN-CE ([Krantz et al., 2020](#bib.bib57)). These increasingly
challenging settings place greater demands on language grounding,
spatial reasoning, and long-horizon decision making. Accordingly,
research has progressed from improving navigation architectures and
learning strategies ([Chen et al., 2021](#bib.bib36); [Chen et al.,
2022b](#bib.bib45); [Wang et al., 2023b](#bib.bib53); [An et al.,
2024](#bib.bib55)) to scaling instruction-trajectory supervision through
automatic data synthesis ([Chen et al., 2022a](#bib.bib40); [Wang et
al., 2023c](#bib.bib51); [Wang et al., 2025b](#bib.bib22)).

Scalable data synthesis allows navigation agents to learn from large
amounts of unlabeled trajectories that would otherwise lack language
supervision. Early methods use speaker models and back-translation to
generate instructions for additional trajectories ([Fried et al.,
2018](#bib.bib44); [Tan et al., 2019](#bib.bib10)), while later work
substantially scales this paradigm with larger environments and stronger
instruction generators ([Chen et al., 2022a](#bib.bib40); [Wang et al.,
2023c](#bib.bib51); [Wang et al., 2025b](#bib.bib22); [Wang et al.,
2025a](#bib.bib34)). Despite this progress, current pipelines still
leave substantial room for improvement. Most methods learn instruction
generation and navigation separately, while existing dual-learning
approaches typically rely on task-specific architectures ([Wang et al.,
2022](#bib.bib14); [Wang et al., 2023a](#bib.bib15)), limiting the
benefit of bidirectional language-action learning. In addition,
synthetic instructions are commonly generated by a fixed model, and the
navigation policy is updated only after a large set of trajectories has
been annotated. As the policy improves, the generated supervision can
therefore become increasingly mismatched with the model being trained.
These limitations call for a learning process that jointly exploits the
two directions of language-action grounding while keeping newly
generated supervision synchronized with the current policy.

This connection is particularly natural in navigation. More generally,
complementary capabilities can benefit each other when one provides
feedback for the other. An unlabeled trajectory can first be described
as a route instruction and then executed again from its starting point,
forming two complementary directions of language-action grounding.
Instruction generation maps visual-action experience to language, while
navigation maps language and visual observations back to actions. A
faithful instruction should capture the navigation task well enough to
guide the agent to the intended goal efficiently, making navigation
execution a direct way to evaluate the generated supervision. When both
capabilities are handled by the same evolving model, execution feedback
can filter and improve language supervision, which in turn provides
better data for subsequent navigation learning.

Based on this observation, we introduce RSI-Nav, a data-centric
recursive self-improvement framework for navigation via
policy-synchronized language-action dual bootstrapping. RSI-Nav uses a
shared model to unify instruction following and generation for dual
bootstrapping. We first apply supervised fine-tuning to establish basic
capabilities for navigation and trajectory annotation. The model then
progressively processes unlabeled trajectories in small shards. For each
shard, the model generates instructions and executes them. The resulting
rollouts assess whether generated instructions can guide the current
model to the intended goal efficiently, and only qualified
instruction-trajectory pairs are retained. The model is then immediately
updated before the next shard. As a result, the updated model generates
and evaluates the rollouts used in subsequent training, rather than
relying on data produced by a fixed annotator at the beginning of the
process. This shard-wise update keeps the generated supervision closely
aligned with the evolving policy and forms a recursive process in which
better models produce better training data for subsequent improvement.

Beyond language-action dual learning, we also incorporate spatial
understanding into the same model, as spatial reasoning is crucial for
interpreting routes and making navigation decisions ([Ma et al.,
2022](#bib.bib23); [Cheng et al., 2024](#bib.bib12); [Yang et al.,
2025](#bib.bib24)). Joint training with spatial-understanding data
strengthens this capability and in turn benefits navigation. We evaluate
RSI-Nav on continuous vision-language navigation,
trajectory-to-instruction generation, and spatial understanding. On
R2R-CE ([Krantz et al., 2020](#bib.bib57)) and RxR-CE ([Ku et al.,
2020](#bib.bib47)), RSI-Nav consistently improves navigation performance
over its supervised initialization. The evolved model also maintains
strong spatial understanding, with modest improvements on all four
evaluated benchmarks over its supervised initialization, while its
generated instructions provide stronger training utility for subsequent
navigation. We further analyze the self-improvement process, examining
policy synchronization, dual learning, action-conditioned instruction
generation, and spatial supervision. These analyses explain why the
proposed process improves both generated supervision and the navigation
policy. Generally, our contributions can be summarized as follows:

- •
  We present RSI-Nav, a data-centric recursive self-improvement
  framework that unifies instruction following, instruction generation,
  and spatial understanding within a single model, where dual
  language-action learning provides complementary supervision to improve
  navigation.
- •
  We obtain large-scale execution-verified instructions paired with
  source trajectories as well as a strong unified model. To our
  knowledge, RSI-Nav is the first navigation framework to combine
  unified language-action dual learning with policy-synchronized
  recursive self-improvement.
- •
  We demonstrate strong navigation performance on VLN-CE benchmarks,
  including leading success rates among the compared methods, while
  maintaining strong spatial understanding. Analyses examine key
  components of the pipeline to explain how and why RSI-Nav improves.

## 2 Related Work

Figure 2: Comparison of three VLN training paradigms. (a) Dual-task

#### Vision-and-Language Navigation.

Vision-and-Language Navigation (VLN) requires agents to follow
natural-language instructions and navigate to target locations in visual
environments. Existing scenarios include navigation with detailed action
instructions ([Anderson et al., 2018](#bib.bib49); [Ku et al.,
2020](#bib.bib47); [Thomason et al., 2020](#bib.bib32)), remote object
navigation with coarse-grained instructions ([Zhu et al.,
2021](#bib.bib50); [Qi et al., 2020](#bib.bib48)), and navigation in
continuous environments ([Kolve et al., 2017](#bib.bib33); [Krantz et
al., 2020](#bib.bib57); [Hong et al., 2022](#bib.bib42)). Substantial
progress has been made through vision-language pretraining and history
modeling ([Hao et al., 2020](#bib.bib13); [Chen et al.,
2021](#bib.bib36); [Guhur et al., 2021](#bib.bib41)), explicit map
construction and planning ([Chen et al., 2022b](#bib.bib45); [Wang et
al., 2023b](#bib.bib53); [An et al., 2024](#bib.bib55)), and modern
vision-language models that directly predict navigation actions ([Zhou
et al., 2024](#bib.bib35); [Zheng et al., 2024](#bib.bib52); [Zhang et
al., 2024](#bib.bib6)). However, the high cost of human annotation
remains a major bottleneck, motivating automatic data augmentation and
synthesis. Early methods use speaker models and back-translation ([Fried
et al., 2018](#bib.bib44); [Tan et al., 2019](#bib.bib10)), while later
work exploits large-scale environments and synthetic instructions to
construct millions of instruction-trajectory pairs ([Chen et al.,
2022a](#bib.bib40); [Wang et al., 2023c](#bib.bib51); [Wang et al.,
2025b](#bib.bib22); [Li et al., 2025](#bib.bib66)). Recent studies
further highlight spatial understanding, including situated 3D reasoning
and spatial memory ([Yang et al., 2025](#bib.bib24); [Yin et al.,
2025](#bib.bib25)).

#### Complementary Learning and Mutual Bootstrapping.

Learning complementary capabilities together provides supervision and
supports joint improvement across multiple abilities. In machine
translation, dual learning couples forward and backward translation to
provide richer mutual feedback ([He et al., 2016](#bib.bib62)). Similar
ideas also appear in mathematical reasoning, where a language model acts
as both solver and verifier ([Weng et al., 2023](#bib.bib64); [Lightman
et al., 2023](#bib.bib63)), with recent work jointly training answer
generation and self-verification in a single model ([Zhang et al.,
2025a](#bib.bib65)). These methods broadly share the principle that
complementary capabilities can provide supervision or feedback for one
another. In VLN, instruction following and generation form a similar
bidirectional language-action relationship. Prior work realizes this
through separate speaker and follower models, where generated
instructions mainly serve as augmentation or scoring signals, or through
task-specific architectures and consistency objectives ([Fried et al.,
2018](#bib.bib44); [Wang et al., 2022](#bib.bib14); [Wang et al.,
2023a](#bib.bib15)).

#### Recursive Self-Improvement.

Recursive self-improvement (RSI) broadly studies how an AI system can
contribute to improving its subsequent versions. In the data-centric
setting, RSIBench-Data ([Meng et al., 2026](#bib.bib67)) frames this as
turning model failures and checkpoint feedback into better training data
and, in turn, better models. Related approaches generate, filter, or
verify model outputs for subsequent training in language
reasoning ([Zelikman et al., 2022](#bib.bib39); [Dong et al.,
2023](#bib.bib38); [Xiong et al., 2025](#bib.bib37); [Yuan et al.,
2024](#bib.bib58)) and embodied agents ([Bousmalis et al.,
2023](#bib.bib59); [Lin et al., 2025](#bib.bib60)). In VLN, SRDF ([Wang
et al., 2025b](#bib.bib22)) iteratively refines synthetic instructions,
self-correction methods ([Yu et al., 2026](#bib.bib68)) mine failure
trajectories, and SID-VLN ([Li et al., 2025](#bib.bib66)) reuses
successful exploration trajectories. However, these methods generally
separate data generation and model updates into relatively coarse
rounds, allowing supervision to lag behind the evolving policy.

## 3 Methodology

RSI-Nav learns from unlabeled navigation trajectories through
policy-synchronized language-action dual bootstrapping. As illustrated
in
Fig. [3](#S3.F3 "Figure 3 ‣ 3.1 A Unified Vision-Language-Action Model ‣ 3 Methodology ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping"),
the framework begins with supervised initialization and recursively
improves both the model and its generated supervision. We first
introduce the continuous VLN setting, followed by a shared model that
unifies instruction following, instruction generation, and spatial
understanding in
Sec. [3.1](#S3.SS1 "3.1 A Unified Vision-Language-Action Model ‣ 3 Methodology ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping").
Sec. [3.2](#S3.SS2 "3.2 Policy-Synchronized Recursive Self-Improvement ‣ 3 Methodology ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping")
presents the core data-centric recursive self-improvement process, where
the current policy generates instructions, executes them to assess goal
completion and path efficiency, retains qualified samples, and updates
itself before processing the next trajectory shard. Finally,
Sec. [3.3](#S3.SS3 "3.3 Training Data and Supervision ‣ 3 Methodology ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping")
describes how we curate supervision for initialization and recursive
evolution, including spatial-data replay and newly generated
instruction-trajectory pairs.

#### Preliminary.

We consider vision-language navigation in continuous environments, where
an agent follows a natural-language instruction through low-level
interaction with the environment. At step $`t`$, the agent receives an
egocentric RGB observation $`o_{t}`$ and selects an action
$`a_{t}\in\mathcal{A}=\{\texttt{FORWARD},\texttt{LEFT},\texttt{RIGHT},\texttt{STOP}\}`$.
A navigation trajectory is represented as

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\tau_{i}=\left(o_{1},a_{1},o_{2},a_{2},\ldots,o_{T},a_{T}\right),
``` |  | (1) |

where $`T`$ denotes the trajectory length. Each trajectory starts from
an initial state $`s_{i}^{\mathrm{start}}`$ and terminates at a target
location defined by its final state. Given a natural-language
instruction $`x_{i}`$, the agent is required to reach the corresponding
target efficiently. We use the term *policy-synchronized* rather than
strict on-policy learning. The source trajectories remain offline, while
instruction generation and execution-based evaluation are repeatedly
refreshed by the current model, reducing the gap between generated
supervision and the evolving policy, as detailed in
Sec. [3.2](#S3.SS2 "3.2 Policy-Synchronized Recursive Self-Improvement ‣ 3 Methodology ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping").

### 3.1 A Unified Vision-Language-Action Model

RSI-Nav is built on Qwen3.5-9B and uses a single model for instruction
following, instruction generation, and spatial understanding. All
capabilities share the same model parameters and are distinguished by
task-specific prompts, without separate generators, verifiers, or output
heads. We formulate the two complementary language-action tasks and
present spatial understanding below.

![Refer to caption](2610.15782v1/RSI-Nav_main_final.png)

Figure 3: Overview of RSI-Nav. The current policy generates instructions
for unlabeled trajectories and executes them to evaluate goal completion
and efficiency. Qualified instructions are paired with the original
trajectories to train instruction following and instruction generation
jointly. The model is then updated with the accepted samples and spatial
replay data before processing the next shard.

#### Instruction Following.

At navigation step $`t`$, the agent maintains an observation history
$`H_{t}=\{o_{1},\ldots,o_{t}\}`$ and uniformly samples eight frames as
visual context $`\widetilde{H}_{t}`$. Conditioned on instruction $`x`$,
$`\widetilde{H}_{t}`$, and the task prompt, the model predicts a
four-action chunk $`c_{t}=(a_{t},a_{t+1},a_{t+2},a_{t+3})`$. We optimize
the standard cross-entropy loss over the predicted action chunk:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}_{\mathrm{IF}}=-\log p_{\theta}(c_{t}\mid x,\widetilde{H}_{t})=-\sum_{j=0}^{3}\log p_{\theta}(a_{t+j}\mid x,\widetilde{H}_{t},a_{t:t+j-1}).
``` |  | (2) |

#### Instruction Generation.

For the reverse direction, the model uniformly samples 32 frames
$`\widetilde{V}_{\tau_{i}}`$ from the trajectory and uses the full
action sequence $`A_{\tau_{i}}=(a_{1},\ldots,a_{T})`$ as input. Given
these inputs and the task prompt, the model generates
$`x=(w_{1},\ldots,w_{M})`$ with the objective:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}_{\mathrm{IG}}=-\log p_{\theta}(x\mid\widetilde{V}_{\tau_{i}},A_{\tau_{i}})=-\sum_{m=1}^{M}\log p_{\theta}(w_{m}\mid\widetilde{V}_{\tau_{i}},A_{\tau_{i}},w_{<m}).
``` |  | (3) |

#### Spatial Understanding.

We further incorporate spatial-understanding training data, which
provide an important scaffold for embodied decision making and
navigation ([Gong et al., 2026](#bib.bib69); [Team et al.,
2026](#bib.bib70)). These samples are trained under the same token-level
objective, denoted as $`\mathcal{L}_{\mathrm{spa}}`$.

### 3.2 Policy-Synchronized Recursive Self-Improvement

With the shared instruction-following and instruction-generation model
defined above, RSI-Nav recursively improves on a large corpus of
unlabeled continuous trajectories. We partition the corpus into small,
non-overlapping trajectory shards
$`\mathcal{U}=\{\mathcal{B}_{1},\mathcal{B}_{2},\ldots,\mathcal{B}_{K}\}`$
and process each trajectory once. After each shard, the model is
immediately updated before generating new supervision for the next one.
This fine-grained update keeps data generation and execution-based
evaluation close to the current policy, rather than relying on a fixed
model over the entire corpus.

#### Generate, Execute, and Filter.

For each trajectory $`\tau_{i}\in\mathcal{B}_{k}`$, the model generates
an instruction $`\hat{x}_{i}`$ from the visual-action trajectory and
then follows $`\hat{x}_{i}`$ from the original start state. The endpoint
of $`\tau_{i}`$ serves as the navigation target. This execution tests
whether the generated instruction can guide the current model to the
intended destination efficiently. We retain a sample based on goal
completion and path efficiency. An execution is considered successful if
its final position is within 3 m of the target. We further use SPL to
measure navigation efficiency and define the acceptance indicator as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
q_{i}=\mathbb{I}\left[d_{i}<3\text{ m}\;\land\;\operatorname{SPL}_{i}\geq\tau_{\mathrm{SPL}}\right],
``` |  | (4) |

where $`d_{i}`$ is the geodesic distance from the final position to the
target and $`\tau_{\mathrm{SPL}}`$ is a fixed efficiency threshold. Only
samples satisfying both criteria are retained for subsequent training.

#### Dual Bootstrapping and Shard-Wise Update.

The filtering stage determines which generated instructions are reliable
enough for training. For each accepted pair $`(\tau_{i},\hat{x}_{i})`$,
we retain the original trajectory $`\tau_{i}`$. Since $`\hat{x}_{i}`$ is
generated from $`\tau_{i}`$, successful and efficient execution toward
the same goal provides an execution-grounded check that the instruction
is executable and consistent with the navigation task represented by the
source trajectory. We therefore retain the original trajectory as the
supervision target rather than the executed trajectory, avoiding the
accumulation of execution errors and the cost of repeatedly re-rendering
continuous trajectories in Habitat. Keeping the trajectory fixed also
focuses recursive improvement on the generated language supervision.

Each accepted pair provides supervision for both complementary
directions. For instruction following, $`\hat{x}_{i}`$ is paired with
the observation histories and original actions along $`\tau_{i}`$; for
instruction generation, $`(\widetilde{V}_{\tau_{i}},A_{\tau_{i}})`$ is
paired with $`\hat{x}_{i}`$. For shard $`\mathcal{B}_{k}`$, these
accepted samples form $`\mathcal{D}_{k}^{\mathrm{IF}}`$ and
$`\mathcal{D}_{k}^{\mathrm{IG}}`$, respectively. During the shard-wise
update, we mix them with spatial-understanding data replayed from
supervised initialization. The overall training objective is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}_{k}=\mathcal{L}_{\mathrm{IF}}\left(\mathcal{D}_{k}^{\mathrm{IF}}\right)+\mathcal{L}_{\mathrm{IG}}\left(\mathcal{D}_{k}^{\mathrm{IG}}\right)+\mathcal{L}_{\mathrm{spa}}\left(\mathcal{R}_{k}^{\mathrm{spa}}\right).
``` |  | (5) |

Here, $`\mathcal{L}_{\mathrm{IF}}`$ and $`\mathcal{L}_{\mathrm{IG}}`$
follow the objectives defined in
Sec. [3.1](#S3.SS1 "3.1 A Unified Vision-Language-Action Model ‣ 3 Methodology ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping"),
while $`\mathcal{L}_{\mathrm{spa}}`$ denotes the corresponding loss on
spatial-understanding samples. This decomposition only distinguishes the
three supervision sources; in practice, all samples are mixed and
jointly optimized with a single SFT objective. The resulting
$`\theta_{k}`$ is immediately used to process the next trajectory shard.

#### Recursive Self-Improvement.

The updated model $`\theta_{k}`$ immediately processes the next shard
$`\mathcal{B}_{k+1}`$. Refreshing instruction generation and
execution-based filtering ensures that new supervision is produced by
the latest model rather than a fixed policy. Repeating this cycle allows
the model and its generated supervision to co-evolve across shards,
while replayed spatial-understanding data help maintain the capability
acquired during SFT initialization. The full evolution yields a stronger
unified model and a large collection of execution-verified
instruction-trajectory pairs, detailed in
Sec. [4](#S4 "4 Experiments ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping").

### 3.3 Training Data and Supervision

RSI-Nav is initialized with multi-source supervision for instruction
following, instruction generation, and spatial understanding. We use
continuous navigation data from SRDF ([Wang et al., 2025b](#bib.bib22)),
EnvDrop ([Tan et al., 2019](#bib.bib10)), ScaleVLN ([Wang et al.,
2023c](#bib.bib51)), R2R ([Anderson et al., 2018](#bib.bib49)), and
RxR ([Ku et al., 2020](#bib.bib47)), and construct corresponding
instruction-generation data by reversing the trajectory-instruction
pairs. Since SRDF trajectories are originally discrete, we convert them
into continuous trajectories for training, with details in
Appendix [D](#A4 "Appendix D Discrete-to-Continuous Trajectory Conversion ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping").
We also incorporate spatial-understanding data from VSI-590K ([Yang et
al., 2026](#bib.bib71)), 546K samples from LLaVA-3D ([Zhu et al.,
2024](#bib.bib11)), and MindCube ([Yin et al., 2025](#bib.bib25)). All
data are mixed for standard supervised fine-tuning, with the same
spatial data replayed during recursive evolution. Starting from
unlabeled continuous trajectories, RSI-Nav generates about 2.5M
instruction-following samples and 1.1M instruction-generation samples
through policy-synchronized recursive improvement.

#### Implementation Details.

RSI-Nav is built on Qwen3.5-9B and trained in two stages on 64 GPUs.
First, we perform supervised fine-tuning for one epoch on the
multi-source data described in
Sec. [3.3](#S3.SS3 "3.3 Training Data and Supervision ‣ 3 Methodology ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping"),
using a learning rate of $`5\times 10^{-6}`$, a global batch size of
128, and AdamW optimization. We then conduct recursive self-improvement
on the unlabeled trajectory corpus, partitioned into non-overlapping
shards of 16,384 trajectories. After each shard, qualified
instruction-trajectory pairs are immediately used for model updating
together with spatial-understanding replay before processing the next
shard.

#### Benchmarks and Evaluation Metrics.

We evaluate navigation on R2R-CE ([Krantz et al., 2020](#bib.bib57)) and
RxR-CE ([Ku et al., 2020](#bib.bib47)) using their validation-unseen
splits. Following prior work, we report Navigation Error (NE), Oracle
Success Rate (OSR), Success Rate (SR), and Success weighted by Path
Length (SPL) on R2R-CE, and additionally nDTW on RxR-CE for trajectory
alignment. For trajectory-to-instruction generation, we report BLEU-1,
BLEU-4, METEOR, ROUGE, CIDEr, and SPICE. Since prior methods are mainly
evaluated in discrete Matterport3D environments, whereas RSI-Nav
operates in continuous VLN-CE with Habitat observations, these NLP
scores serve as reference rather than strictly controlled comparisons.
We further evaluate spatial understanding on VSI-Bench ([Yang et al.,
2025](#bib.bib24)), ScanQA ([Azuma et al., 2022](#bib.bib7)), SQA3D ([Ma
et al., 2022](#bib.bib23)), and MindCube ([Yin et al.,
2025](#bib.bib25)), reporting VSI Overall, ScanQA CIDEr, SQA3D EM1-R,
and MindCube Accuracy, respectively. In the main comparison, we
distinguish single-view RGB, panoramic RGB, depth, and odometry inputs,
and separately mark methods using waypoint predictors.

#### Real-World Evaluation Setup.

For real-world evaluation, we deploy RSI-Nav on a DEEP Robotics M20
robot. RSI-Nav runs on a remote server equipped with an NVIDIA GeForce
RTX 4090 GPU and continuously processes egocentric RGB observations and
language instructions to generate navigation actions for closed-loop
execution. We evaluate the agent in both indoor and outdoor environments
with tasks covering obstacle avoidance, narrow-space navigation,
instruction following, open-vocabulary landmark grounding, and
long-horizon navigation.

### 4.1 Main Results

#### Comparison with Prior Methods.

Tab. [1](#S4.T1 "Table 1 ‣ 4 Experiments ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping")
compares RSI-Nav with previous methods on R2R-CE, RxR-CE, and four
spatial-understanding benchmarks. On navigation, RSI-Nav achieves strong
performance on R2R-CE and RxR-CE Val-Unseen, reaching 68.6% SR and 58.6%
SPL on R2R-CE, and 72.4% SR, 56.5% SPL, and 70.6 nDTW on RxR-CE.
Compared with the supervised initialization, recursive evolution
consistently improves navigation success and trajectory alignment,
showing that self-generated and execution-verified instructions provide
supervision beyond the initial SFT stage. The gain in nDTW indicates
that the model better follows the instructed route rather than merely
reaching the goal through alternative paths, which is particularly
important for long-horizon instruction following. For spatial
understanding, RSI-Nav maintains strong performance after evolution,
with modest improvements over its cold-start checkpoint on all four
benchmarks. VSI-Bench increases from 64.6 to 64.9, ScanQA from 93.2 to
96.4, SQA3D from 65.1 to 65.4, and MindCube from 91.8 to 93.5,
suggesting that navigation gains coexist with stable spatial
understanding.

### 4.2 Ablation Studies

#### How Does Policy Synchronization Affect Learning?

We study the update granularity on a fixed subset of 64K unlabeled
trajectories using 64 GPUs, where *candidate* denotes the number of
trajectories processed per GPU before each policy update. As shown in
Tab. [3](#S4.T3 "Table 3 ‣ Real-World Evaluation Setup. ‣ 4 Experiments ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping"),
256 candidates perform best, improving SR and SPL most significantly.
With only 64 candidates, performance also drops, suggesting that each
update changes the policy too little for successive policies and their
generated data to differ meaningfully. In contrast, 1,024 candidates
process the entire subset before updating, approaching the conventional
offline setting and enlarging the policy-data gap. The intermediate
granularity therefore provides a better balance between meaningful
policy evolution and timely supervision refresh. Based on this ablation,
we use 256 candidates per GPU, corresponding to a global shard size of
16,384 trajectories on 64 GPUs, for full-scale recursive evolution.

#### Does Dual Learning Benefit Navigation?

We examine whether instruction generation provides useful supervision
for instruction following. As shown in
Tab. [2](#S4.T2 "Table 2 ‣ Real-World Evaluation Setup. ‣ 4 Experiments ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping"),
adding VA2L data improves SR from 44.7% to 48.8% and SPL from 38.6% to
41.0% over navigation-only training, confirming that trajectory
annotation benefits navigation.
Tab. [5](#S4.T5 "Table 5 ‣ Are Actions Important for Dual Learning? ‣ 4.2 Ablation Studies ‣ 4 Experiments ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping")
further shows that joint instruction following and generation
substantially improves navigation while causing minor changes in
instruction-generation metrics. This indicates that the two tasks can be
jointly optimized with little loss in annotation quality, while the
complementary trajectory-to-language supervision provides clear gains
for navigation.

#### Are Actions Important for Dual Learning?

Under the same visual input, VA2L consistently outperforms V2L,
improving SR from 47.0% to 48.8% and SPL from 38.8% to 41.0%. Although
instruction generation can rely on visual observations alone,
incorporating actions establishes a stronger dual relation between
action-to-language generation and language-to-action navigation. This
indicates that action information helps more effectively transfer
instruction-generation supervision back to navigation; we further
examine this effect from the generation side next.

#### How Does Joint Training Affect Instruction Generation?

For RSI-Nav, we use the jointly trained VL2A-VA2L generator evaluated in
Tab. [5](#S4.T5 "Table 5 ‣ Are Actions Important for Dual Learning? ‣ 4.2 Ablation Studies ‣ 4 Experiments ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping").
We examine the reverse benefit of dual learning from instruction
following to instruction generation. Prior methods are often evaluated
in discrete Matterport3D settings with panoramic observations, whereas
RSI-Nav operates in continuous VLN-CE using low-resolution Habitat
observations; their NLP scores thus serve only as reference rather than
strictly comparable baselines. NLP metrics also mainly measure
similarity to human-written instructions and may not reflect downstream
training utility ([Gadre et al., 2024](#bib.bib56)). We therefore
annotate the same trajectories with different generators and train
identical navigation models on the resulting data. As shown in
Tab. [4](#S4.T4 "Table 4 ‣ Are Actions Important for Dual Learning? ‣ 4.2 Ablation Studies ‣ 4 Experiments ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping"),
although SRDF scores higher on most NLP metrics, RSI-Nav yields
substantially better downstream navigation, improving SR from 36.8% to
41.3% and SPL from 30.4% to 35.1%. Together with the
bidirectional-training results in
Tab. [5](#S4.T5 "Table 5 ‣ Are Actions Important for Dual Learning? ‣ 4.2 Ablation Studies ‣ 4 Experiments ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping"),
these results show that joint VL2A-VA2L training benefits navigation
while preserving instruction-generation quality, and that the resulting
RSI-Nav generator yields stronger downstream utility than prior work.

#### Does Spatial Understanding Benefit Navigation?

Adding spatial-understanding supervision on top of VA2L further improves
all navigation metrics, reducing navigation error while increasing
success rate and efficiency. The gains support the role of spatial
relations and viewpoint reasoning in navigation, highlighting spatial
understanding as complementary supervision.

#### Limitations.

RSI-Nav still relies on simulated environments and an offline trajectory
pool, while execution-based filtering incurs considerable computational
cost. Although we provide qualitative real-world demonstrations,
systematic robustness across diverse real-world environments, unseen
domains, and substantially longer-horizon navigation remains to be
established.

## 5 Conclusion

We introduce RSI-Nav, a data-centric recursive self-improvement
framework for navigation via policy-synchronized language-action dual
bootstrapping. RSI-Nav unifies instruction following, generation, and
spatial understanding in one shared policy, turning unlabeled
trajectories into supervision through instruction generation,
execution-based filtering, and shard-wise updates. By refreshing
supervision with the latest model, RSI-Nav maintains policy-synchronized
learning while jointly training instruction following and generation.
Experiments on R2R-CE and RxR-CE demonstrate strong navigation
improvements, while spatial-understanding evaluations show modest gains
over supervised initialization and generated instructions provide useful
downstream navigation supervision. Ablations examine the effects of
update granularity, dual-task training, action conditioning, and spatial
supervision. Overall, RSI-Nav shows that large-scale unlabeled
navigation trajectories support model improvement through generated and
filtered supervision, providing a scalable direction for self-improving
embodied navigation. We discuss limitations and future work in
Appendix [H](#A8 "Appendix H Limitations and Future Work ‣ Data-Centric Recursive Self-Improvementfor Navigation via Policy-SynchronizedLanguage-Action Dual Bootstrapping").

## Appendix A Evaluation Metrics

We evaluate navigation using NE, SR, OSR, SPL, and nDTW. For episode
$`i`$, let $`P_{i}=(p_{i,0},\ldots,p_{i,T_{i}})`$ denote the executed
trajectory, $`g_{i}`$ the goal, and
$`R_{i}=(r_{i,1},\ldots,r_{i,M_{i}})`$ the reference trajectory. We use
a success threshold of $`\delta=3`$ m. Let $`d_{\mathrm{geo}}`$ denote
geodesic distance on the navigation mesh and $`\mathbf{1}[\cdot]`$ the
indicator function.

#### Navigation Error (NE)

measures the geodesic distance between the final position and the goal:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{NE}=\frac{1}{N}\sum_{i=1}^{N}d_{\mathrm{geo}}(p_{i,T_{i}},g_{i}),
``` |  | (6) |

where $`N`$ is the number of evaluation episodes. Lower NE indicates
that the agent finishes closer to the goal.

#### Success Rate (SR).

An episode is successful if agent executes STOP within the success
threshold:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
S_{i}=\mathbf{1}[\texttt{STOP}\text{ is executed}]\mathbf{1}[d_{\mathrm{geo}}(p_{i,T_{i}},g_{i})<\delta],\qquad\mathrm{SR}=\frac{1}{N}\sum_{i=1}^{N}S_{i}.
``` |  | (7) |

#### Oracle Success Rate (OSR).

OSR measures whether the agent enters the success region at any point
during navigation, regardless of where it stops:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{OSR}=\frac{1}{N}\sum_{i=1}^{N}\mathbf{1}\!\left[\min_{0\leq t\leq T_{i}}d_{\mathrm{geo}}(p_{i,t},g_{i})<\delta\right].
``` |  | (8) |

#### Success weighted by Path Length (SPL).

SPL considers both success and navigation efficiency:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{SPL}=\frac{1}{N}\sum_{i=1}^{N}S_{i}\frac{\ell_{i}}{\max(\ell_{i},L_{i})},
``` |  | (9) |

where $`\ell_{i}=d_{\mathrm{geo}}(p_{i,0},g_{i})`$ is the shortest
start-to-goal distance and
$`L_{i}=\sum_{t=1}^{T_{i}}\|p_{i,t}-p_{i,t-1}\|_{2}`$ is the traveled
distance. Failed episodes receive zero, while successful episodes are
penalized for taking detours.

#### Normalized Dynamic Time Warping (nDTW).

nDTW measures how closely the executed trajectory follows the reference
trajectory while preserving traversal order. The alignment cost is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{DTW}(P_{i},R_{i})=\min_{W\in\mathcal{W}_{i}}\sum_{(t,j)\in W}\|p_{i,t}-r_{i,j}\|_{2},
``` |  | (10) |

where $`\mathcal{W}_{i}`$ contains monotonic alignments connecting the
starts and ends of both trajectories, with each step advancing along
either or both sequences. The normalized score is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{nDTW}=\frac{1}{N}\sum_{i=1}^{N}\exp\left(-\frac{\mathrm{DTW}(P_{i},R_{i})}{M_{i}\delta}\right).
``` |  | (11) |

Our implementation removes consecutive duplicate predicted positions and
uses FastDTW by default to approximate the alignment cost. Higher nDTW
indicates better agreement with the reference route.

NE is reported in meters. SR, OSR, SPL, and nDTW are reported on a
percentage scale, with higher values indicating better performance.

## Appendix D Discrete-to-Continuous Trajectory Conversion

We convert discrete navigation paths into executable trajectories in
Habitat. Given a path $`\tau^{G}=(v_{1},\ldots,v_{N})`$, we query
MatterSim for each viewpoint’s position
$`p_{i}^{G}=(x_{i},y_{i},z_{i})`$ and map it to Habitat coordinates:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\tilde{w}_{i}=(x_{i},z_{i}-1.25,-y_{i}),\qquad w_{i}=(x_{i},h_{i},-y_{i}),
``` |  | (12) |

where $`1.25`$ m is the camera-height offset and $`h_{i}`$ is the floor
height obtained by snapping $`\tilde{w}_{i}`$ to the navigation mesh. If
snapping fails, we use $`h_{i}=z_{i}-1.25`$.

Starting from the first waypoint with the converted initial orientation,
a shortest-path follower follows the waypoints in order, producing

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\tau^{G}\xrightarrow{\text{waypoint following}}\tau^{C}=(s_{0},a_{1},s_{1},\ldots,a_{L},s_{L}),
``` |  | (13) |

where $`s_{l}`$ denotes the agent’s position and orientation after
action $`a_{l}`$, and $`L`$ is the number of executed actions. Each
movement action advances the agent by $`0.25`$ m or turns it left or
right by $`15^{\circ}`$. Trajectories that exhaust the action budget are
discarded. The recorded actions and rendered observations are used to
construct navigation and instruction-generation examples.

orientation, navigation mesh $`\mathcal{M}`$, action budget $`B=500`$

sequence $`A`$, or rejection

1:  $`W\leftarrow[\,]`$, $`A\leftarrow[\,]`$

2:  for $`i=1,\ldots,N`$ do

3:   Query MatterSim for $`(x_{i},y_{i},z_{i})`$ at $`v_{i}`$

4:   $`\tilde{w}_{i}\leftarrow(x_{i},z_{i}-1.25,-y_{i})`$

5:   $`q_{i}\leftarrow\operatorname{Snap}_{\mathcal{M}}(\tilde{w}_{i})`$

6:   $`w_{i}\leftarrow\tilde{w}_{i}`$

7:   if $`q_{i}`$ is valid then

8:    $`w_{i}\leftarrow(x_{i},[q_{i}]_{y},-y_{i})`$ {Adjust height only}

9:   end if

10:   Append $`w_{i}`$ to $`W`$

11:  end for

12:  if $`d_{\mathcal{M}}(w_{1},w_{N})\geq 100\,\mathrm{m}`$ then

13:   return rejection

14:  end if

15:  Initialize Habitat at $`w_{1}`$ with the converted initial
orientation; record $`s_{0}`$

16:  Initialize shortest-path follower $`F`$ with goal radius
$`0.25\,\mathrm{m}`$

17:  for $`i=2,\ldots,N`$ do

18:   loop

19:    if $`|A|\geq B`$ then

20:     return rejection

21:    end if

22:    $`a\leftarrow F.\operatorname{NextAction}(w_{i})`$

23:    if $`a=\texttt{STOP}`$ or $`a=\texttt{None}`$ then

24:     break

25:    end if

26:    Execute $`a`$ in Habitat and append $`a`$ to $`A`$

27:   end loop

28:  end for

29:  return $`(W,s_{0},A)`$

## Appendix H Limitations and Future Work

RSI-Nav’s self-improvement is constrained by the capabilities of its
current policy. Since the same model generates instructions and executes
them for verification, the resulting supervision may reinforce existing
biases. Instructions that are valid but difficult to execute may also be
rejected, potentially favoring easier trajectories and limiting further
improvement. Future work could explore difficulty-aware data selection,
````
