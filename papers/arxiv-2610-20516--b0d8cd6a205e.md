# VASPO: Self-Distillation with Privileged Value Estimation

Fei Wu Affiliation: University of Science and Technology of China   
Zhenrong Zhang Affiliation: IFLYTEK Research    Jianshu Zhang

###### Abstract

On-policy self-distillation provides dense supervision for reasoning
models via a privileged self-teacher. However, this supervision reflects
local token preferences rather than the expected return of an unguided
student continuation. Recent methods combine this signal with GRPO. They
use GRPO for update directions and the teacher for signal scaling.
However, we demonstrate a more effective integration within PPO.
Specifically, we identify complementary positional dynamics: privileged
information enhances a critic’s value-prediction accuracy toward the
response’s end, whereas self-teacher guidance is strong initially, drops
mid-generation, and rebounds finally. These insights motivate
_Value-Augmented Self-Distillation Policy Optimization_ (VASPO), wherein
a self-teacher and critic evaluate identical privileged information at
student-generated prefixes. The critic computes token-level PPO
advantages from predicted continuation returns, while the self-teacher
modulates selected positive advantages via bounded probability ratios.
Across six mathematical reasoning benchmarks, VASPO improves mean
accuracy over PPO by 2.59 and 1.81 percentage points on Qwen3-4B and
OLMo3-7B variants, respectively, and achieves the highest mean accuracy
among evaluated methods on Knights and Knaves. Our code is available at
[https://github.com/cii030/VASPO](https://github.com/cii030/VASPO).

## 1 Introduction

Training reasoning models from verified final answers requires assigning
credit to intermediate decisions. Reinforcement learning with verifiable
rewards (RLVR) supplies a reliable outcome but does not identify which
tokens contributed to it ([Guo et al., 2025](#bib.bib5); [Xiao et al.,
2026](#bib.bib27)). Group Relative Policy Optimization (GRPO) compares
several responses to the same problem and broadcasts each response’s
advantage across its tokens ([Shao et al., 2024](#bib.bib22)). Proximal
Policy Optimization (PPO) instead learns a value model, or critic, to
turn the outcome into advantages ([Schulman et al., 2017](#bib.bib20)).
Both approaches must learn from a reward that arrives only after the
response is complete.

On-policy self-distillation (OPSD) supplies a denser, token-level signal
at student-generated prefixes. The self-teacher reads privileged
information, such as a worked solution or a ground-truth answer, and
scores the sampled tokens ([Zhao et al., 2026](#bib.bib37)). This
guidance can distinguish tokens within a response, but its preferences
conditioned on privileged information are not verifier-grounded measures
of the student’s eventual success. Privileged context can shift the
signal toward style rather than task content ([Pan et al.,
2026](#bib.bib19)), suppress deliberation in reasoning models ([Kaur
et al., 2026](#bib.bib9)), or yield unreliable targets at some prefixes
([Liu et al., 2026a](#bib.bib13)). These observations motivate combining
token guidance with outcome feedback while measuring when that guidance
is useful.

Recent combinations use verifier outcomes to anchor or route privileged
teacher guidance. RLSD modulates group-relative advantages with
teacher–student signals ([Yang et al., 2026a](#bib.bib30)); SSPO applies
step-level weights to GRPO in deep search ([Wu et al.,
2026b](#bib.bib26)). SRPO routes correct and failed responses between
GRPO and self-distillation ([Li et al., 2026](#bib.bib11)). These
methods use privileged information in the teacher branch. None uses the
same privileged information to train a PPO-style prefix-value estimator
for clean student returns. This leaves a separate use of that
information unexplored: estimating the student’s continuation return
before assigning token credit.

Prior work has demonstrated the effectiveness of providing reference
answers as input to the critic ([Zhang et al., 2026c](#bib.bib36)).
Teacher preferences and continuation values serve fundamentally distinct
roles at the same student prefix. While the teacher evaluates immediate
token choices using privileged information, the critic predicts the
expected success rate of the student’s unguided continuation. Thus, a
token highly rated by the privileged teacher does not guarantee that the
student can successfully navigate the remaining complex steps
independently. We posit that a reference solution helps the critic
accurately align incomplete responses, improving PPO value estimation
beyond standard token-level supervision by bridging the gap between
local step correctness and global trajectory success.

We observe different signal profiles for the two readers across response
positions: the critic’s prediction benefit grows toward the end, while
self-teacher divergence is high near the beginning, falls through the
middle, and rebounds in the final position bin. This pattern motivates
using the same privileged information for both token guidance and
continuation-value estimation.

Therefore, we introduce _Value-Augmented Self-Distillation Policy
Optimization_ (VASPO) to leverage shared privileged information for both
signals
(Figure [1](#S0.F1 "Figure 1 ‣ VASPO: Self-Distillation with Privileged Value Estimation")).
In this framework, the actor generates responses conditioned solely on
the standard problem prompt. Concurrently, a self-teacher and a critic
access the fixed privileged information at the student’s sampled
prefixes. The critic’s value estimates and verifier rewards are used to
compute GAE advantages, while clipped teacher–student probability ratios
scale selected positive advantages prior to the PPO update. This design
effectively integrates privileged information into both the
token-guidance and value-estimation paths, all while preserving an
autonomous student continuation as the critic’s true prediction target.

We evaluate VASPO on mathematical reasoning with Qwen3-4B-Instruct-2507
and OLMo3-7B-Instruct-DPO and on Knights and Knaves with Qwen3 only.
Across these settings, VASPO achieves higher average accuracy than the
evaluated baselines. Further controlled evaluations examine the
contribution of privileged value estimation and the roles of the two
signals across response positions. Our contributions are threefold:

- •
  We characterize the positional profiles of privileged information:
  critic prediction benefits grow toward the end, while self-teacher
  divergence is high early, lower in the middle, and rebounds at the
  end.
- •
  We propose VASPO, which shares privileged information between a
  self-teacher and a critic to combine token guidance with
  continuation-value estimation. Critic-derived PPO advantages are
  modulated by bounded teacher preferences, while the actor remains
  prompt-only.
- •
  We demonstrate improved mathematical and logical reasoning. Across six
  mathematical benchmarks, VASPO improves the mean score over PPO by
  2.59 percentage points on Qwen3 and 1.81 points on OLMo3. On Knights
  and Knaves with Qwen3, it also achieves the highest average accuracy
  among the evaluated methods.

## 2 Preliminaries

In this section, we review the two training paradigms that form the
basis of our formulation. RLVR provides an outcome-grounded
policy-gradient objective, while OPSD offers a privileged token-level
signal on the same on-policy prefixes. Finally, we examine how the
contribution of privileged information to these two signals evolves
across different stages of a generated response.

### 2.1 Reinforcement Learning with Verifiable Rewards

Reinforcement learning with verifiable rewards (RLVR) optimizes a
language model against task outcomes that can be checked automatically,
commonly using PPO-style objectives or group-relative variants such as
GRPO ([Schulman et al., 2017](#bib.bib20); [Shao et al.,
2024](#bib.bib22)). Given a prompt $`x\sim\mathcal{D}_{X}`$, where
$`\mathcal{D}_{X}`$ is the training prompt distribution, a policy
$`\pi_{\theta}`$ generates an autoregressive response
$`y=(y_{1},\ldots,y_{T})`$:

|     |     |     |     |
| --- | --- | --- | --- |
|     |

       ``` math
       y\sim\pi_{\theta}(\cdot\mid x),\qquad h_{t}=(x,y_{<t}).
       ```                                                      |     | (1) |

A task verifier assigns a scalar terminal reward $`\mathcal{R}(x,y)`$.
We write $`r_{T}=\mathcal{R}(x,y)`$ and $`r_{t}=0`$ for $`t<T`$, which
gives the discounted return $`G_{t}=\sum_{k=t}^{T}\gamma^{k-t}r_{k}`$
for $`\gamma\in(0,1]`$. We optimize the expected terminal reward

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
J(\theta)=\mathbb{E}_{x\sim\mathcal{D}_{X},\,y\sim\pi_{\theta}(\cdot\mid x)}\bigl[\mathcal{R}(x,y)\bigr].
``` |  | (2) |

PPO estimates token-level credit using a value function $`V_{\phi}`$ and
generalized advantage estimation (GAE). With $`V_{\phi}(h_{T+1})=0`$,
the temporal-difference residual and advantage are

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\delta_{t}`$ | $`\displaystyle=r_{t}+\gamma V_{\phi}(h_{t+1})-V_{\phi}(h_{t}),`$ |  | (3) |
|  | $`\displaystyle A^{\mathrm{PPO}}_{t}`$ | $`\displaystyle=\sum_{\ell=0}^{T-t}(\gamma\lambda_{\mathrm{GAE}})^{\ell}\delta_{t+\ell},`$ |  |  |

where $`\lambda_{\mathrm{GAE}}\in[0,1]`$ controls the bias–variance
trade-off. Let $`\pi_{\theta_{\mathrm{old}}}`$ be the behavior policy
used to collect $`y`$ and define
$`\rho_{t}(\theta)=\pi_{\theta}(y_{t}\mid h_{t})/\pi_{\theta_{\mathrm{old}}}(y_{t}\mid h_{t})`$.
Write $`\rho_{t}^{\mathrm{clip}}(\theta)`$ for this ratio clipped to
$`[1-\epsilon_{\mathrm{clip}},1+\epsilon_{\mathrm{clip}}]`$. The clipped
actor loss is

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\mathcal{L}_{\mathrm{RLVR}}(\theta)`$ |  | (4) |
|  |  | $`\displaystyle=-\mathbb{E}_{x,y,t}\!\left[\min\!\left(\rho_{t}(\theta)A^{\mathrm{PPO}}_{t},\rho_{t}^{\mathrm{clip}}(\theta)A^{\mathrm{PPO}}_{t}\right)\right].`$ |  |  |

The expectation averages over training prompts, collected responses, and
valid token positions. Here the verifier determines the realized
outcome, while the value function provides a prefix-dependent baseline
for assigning token-level credit.

### 2.2 On-Policy Self-Distillation

On-policy self-distillation (OPSD) uses privileged information to obtain
token-level supervision without introducing a separate, larger teacher
model ([Zhao et al., 2026](#bib.bib37)). Specifically, let
$`\mathcal{D}`$ be a training distribution over pairs $`(x,z)`$, whose
prompt marginal is $`\mathcal{D}_{X}`$ and where $`z`$ denotes
privileged information available during training. The policy samples
$`y`$ as in
equation [1](#S2.E1 "In 2.1 Reinforcement Learning with Verifiable Rewards ‣ 2 Preliminaries ‣ VASPO: Self-Distillation with Privileged Value Estimation").
At each resulting prefix $`h_{t}`$, OPSD evaluates a student
distribution and a detached privileged self-teacher distribution:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p_{\theta,t}=\pi_{\theta}(\cdot\mid h_{t}),\qquad q^{z}_{\bar{\theta},t}=\operatorname{sg}\!\left[\pi_{\bar{\theta}}(\cdot\mid h_{t},z)\right],
``` |  | (5) |

where $`\operatorname{sg}`$ denotes stop-gradient and $`\bar{\theta}`$
denotes the parameters of the self-teacher copy. Standard OPSD trains
the policy by minimizing a token-wise divergence along its own
trajectories:

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\mathcal{L}_{\mathrm{OPSD}}(\theta)`$ |  | (6) |
|  |  | $`\displaystyle=\mathbb{E}_{\begin{subarray}{c}(x,z)\sim\mathcal{D}\\
y\sim\pi_{\theta}(\cdot\mid x)\end{subarray}}\!\left[\frac{1}{T}\sum_{t=1}^{T}D\!\left(q^{z}_{\bar{\theta},t}\,\|\,p_{\theta,t}\right)\right],`$ |  |  |

where $`D`$ is a distributional divergence and gradients propagate only
through $`p_{\theta,t}`$. RLVR and OPSD thus evaluate the same prefixes
using complementary signals: a verifier-grounded return and a privileged
next-token distribution, respectively.

### 3.1 Overview of VASPO

VASPO leverages shared privileged information for both value estimation
and self-distillation, while ensuring the student model operates solely
on the standard prompt during training and inference. As illustrated in
Figure [3](#S3.F3 "Figure 3 ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation"),
the framework retains the clipped actor update of PPO but introduces two
privileged readers with distinct roles. The privileged critic estimates
the expected return of an autonomous student continuation, supplying the
values required to compute token-level GAE advantages. Concurrently, the
self-teacher evaluates the student’s sampled tokens using the same
privileged context; its preferences are transformed into bounded
coefficients that scale selected positive advantages. This privileged
information is established prior to rollout and accessed by both readers
at identical student-generated prefixes. The remainder of this section
is organized as follows:
Section [3.2](#S3.SS2 "3.2 Shared Privileged Information ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation")
formalizes the shared privileged information and student rollouts,
Section [3.3](#S3.SS3 "3.3 Privileged Value Estimation ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation")
details the privileged value estimation, and
Section [3.4](#S3.SS4 "3.4 Teacher-Guided PPO Update ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation")
presents the teacher-guided reweighting alongside the actor update.
Algorithm [1](#alg1 "Algorithm 1 ‣ Reweighting the advantage. ‣ 3.4 Teacher-Guided PPO Update ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation")
summarizes the complete VASPO training procedure.

### 3.2 Shared Privileged Information

The privileged information is shared by the teacher and critic, while
the student learns from its own responses. For a prompt $`x`$, we select
privileged information $`z`$ before rollout and keep it fixed. The
student samples $`y`$ from $`\pi_{\theta_{\mathrm{old}}}(\cdot\mid x)`$.
At each prefix $`h_{t}=(x,y_{<t})`$, both readers receive the same $`z`$
and prefix; the student receives no privileged information during either
rollout or deployment.

### 3.3 Privileged Value Estimation

#### Continuation-value prediction.

The critic uses the privileged information to estimate the return of a
continuation generated by the student without privileged input. A worked
solution may help it relate an unfinished response to the steps the task
requires. Its input is the prefix $`h_{t}`$ and privileged information
$`z`$, and its prediction target is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
V^{z}_{\phi}(h_{t},z)\approx\mathbb{E}_{\pi_{\theta_{\mathrm{old}}}}[G_{t}\mid h_{t},z].
``` |  | (7) |

The expectation is over continuations from the student that collected
the rollout. For binary success rewards without discounting, this is the
probability that the student will complete correctly. The critic does
not observe the current token or the continuation it is predicting. The
privileged information supplies task information; the student’s observed
return supplies the training target.

#### Critic pre-update.

We update the critic on each newly collected rollout batch before
computing the advantages used by the actor. With the student held fixed
at $`\pi_{\theta_{\mathrm{old}}}`$, the verifier supplies the terminal
return $`G_{i}=\mathcal{R}(x_{i},y_{i})`$ for response $`i`$. We use
$`\gamma=1`$, so every valid token in this response has the same return
target $`G_{i}`$. This update fits the value estimator to the latest
student trajectories before its predictions determine token credit. The
privileged information enters the critic input, while supervision
remains the student’s observed return.

#### PPO clipped value loss.

Let $`v^{z}_{i,t}=V^{z}_{\phi}(h_{i,t},z_{i})`$ be the current value
prediction and $`v^{z,\mathrm{old}}_{i,t}`$ the prediction stored before
the critic pre-update. With value clip range $`\epsilon_{v}`$, we define

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\bar{v}^{z}_{i,t}=\operatorname{clip}\!\left(v^{z}_{i,t},v^{z,\mathrm{old}}_{i,t}-\epsilon_{v},v^{z,\mathrm{old}}_{i,t}+\epsilon_{v}\right).
``` |  | (8) |

The critic minimizes the PPO clipped value loss

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathcal{L}_{V}(\phi)=\frac{1}{2}\operatorname{Agg}_{m}\!\Bigl[\max\!\bigl(`$ | $`\displaystyle(v^{z}_{i,t}-G_{i})^{2},`$ |  | (9) |
|  |  | $`\displaystyle(\bar{v}^{z}_{i,t}-G_{i})^{2}\bigr)\Bigr],`$ |  |  |

where $`\operatorname{Agg}_{m}`$ aggregates over valid response tokens
under mask $`m`$. Both the return targets and the stored predictions are
detached and fixed throughout this critic update phase. We perform one
such phase per rollout batch and denote the resulting parameters by
$`\phi^{+}`$.

#### Advantages from refreshed values.

After the pre-update, we evaluate the same prefixes again with
$`V^{z}_{\phi^{+}}`$ and recompute $`A^{z}_{t}`$ using the GAE
definition in
equation [3](#S2.E3 "In 2.1 Reinforcement Learning with Verifiable Rewards ‣ 2 Preliminaries ‣ VASPO: Self-Distillation with Privileged Value Estimation"),
with the refreshed privileged critic as the value function. With
$`V^{z}_{\phi^{+}}(h_{T+1},z)=0`$, terminal-only rewards, and
$`\gamma=\lambda_{\mathrm{GAE}}=1`$, the GAE sum telescopes, yielding

|  |  |  |  |
|----|----|----|----|
|  |
``` math
A^{z}_{i,t}=G_{i}-v^{z,+}_{i,t},\qquad v^{z,+}_{i,t}=V^{z}_{\phi^{+}}(h_{i,t},z_{i}).
``` |  | (10) |

Although $`G_{i}`$ is shared across the response, the refreshed baseline
varies with the prefix, retaining PPO’s token-level credit structure. We
detach these advantages and hold them fixed during the subsequent actor
update. There is no second critic update on this batch. This
*privileged-critic advantage* combines the verifier outcome with a
prefix-dependent value informed by privileged information, before any
teacher reweighting.

### 3.4 Teacher-Guided PPO Update

#### From teacher scores to token weights.

The self-teacher evaluates the same tokens sampled by the student, using
the distribution conditioned on privileged information
$`q^{z}_{\bar{\theta},t}`$ from
equation [5](#S2.E5 "In 2.2 On-Policy Self-Distillation ‣ 2 Preliminaries ‣ VASPO: Self-Distillation with Privileged Value Estimation").
Let $`p_{\mathrm{old},t}=\pi_{\theta_{\mathrm{old}}}(\cdot\mid h_{t})`$
be the student’s behavior distribution. We compute the detached
student–teacher gap on the same sampled token $`y_{t}`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
d_{t}=\operatorname{sg}\!\left[\log q^{z}_{\bar{\theta},t}(y_{t})-\log p_{\mathrm{old},t}(y_{t})\right].
``` |  | (11) |

We clip the corresponding probability ratio to obtain a weight:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
w_{t}=\operatorname{clip}\!\left(e^{d_{t}},1-\epsilon_{w},1+\epsilon_{w}\right).
``` |  | (12) |

Here $`0<\epsilon_{w}<1`$ bounds the reweighting. A token assigned more
probability by the teacher receives a weight above one; a token assigned
less receives a weight below one. Clipping bounds how much this
preference can change the critic-derived credit.

#### Token-level mask.

Teacher modulation is restricted to tokens with positive GAE advantages
and a sufficiently large teacher–student gap. The advantage gate selects
tokens that the outcome-grounded update already encourages; the gap gate
leaves near-agreement tokens at their original weight. For each valid
response token, we define

|  |  |  |  |
|----|----|----|----|
|  |
``` math
M_{t}=\mathbf{1}[A^{z}_{t}>0]\,\mathbf{1}\!\left[|\tanh(d_{t}/\tau)|>\delta\right].
``` |  | (13) |

The sign test uses the raw, unwhitened $`A^{z}_{t}`$ recomputed after
the critic pre-update. It is applied at each token position, without
directly checking whether the complete response is correct. Prompt and
padding positions are excluded by the valid-response-token mask. Thus,
$`M_{t}`$ controls where teacher guidance changes the actor advantage;
it does not select the examples used to train the critic.

#### Reweighting the advantage.

We denote the fused advantage by $`A^{z,\mathrm{f}}_{t}`$, where
$`\mathrm{f}`$ indicates teacher fusion, and combine the refreshed GAE
advantage, token mask, and teacher weight as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
A^{z,\mathrm{f}}_{t}=\operatorname{sg}\!\left[A^{z}_{t}\bigl(1+M_{t}(w_{t}-1)\bigr)\right].
``` |  | (14) |

For selected tokens this gives $`A^{z,\mathrm{f}}_{t}=A^{z}_{t}w_{t}`$;
for all other tokens it gives $`A^{z,\mathrm{f}}_{t}=A^{z}_{t}`$. The
teacher therefore strengthens or attenuates selected positive updates,
while negative advantages and unselected tokens retain their original
credit. The positive weight preserves the sign of $`A^{z}_{t}`$. We use
the detached $`A^{z,\mathrm{f}}_{t}`$ in the clipped PPO loss
equation [4](#S2.E4 "In 2.1 Reinforcement Learning with Verifiable Rewards ‣ 2 Preliminaries ‣ VASPO: Self-Distillation with Privileged Value Estimation")
over all valid response tokens.

### 4.1 Experimental Setup

#### Models and Datasets.

We conduct experiments on Qwen3-4B-Instruct-2507 ([Yang et al.,
2025](#bib.bib29)) and OLMo3-7B-Instruct-DPO ([Olmo Team et al.,
2025](#bib.bib18)) for mathematical reasoning, and on
Qwen3-4B-Instruct-2507 for logical reasoning. We train on the full
DeepMath-103K dataset ([He et al., 2026](#bib.bib7)) for mathematics and
Knights and Knaves (KK) ([Xie et al., 2025](#bib.bib28)) puzzles with
4–8 roles for logic. Privileged information consists of the solutions
and answers provided in the datasets.

#### Baselines and Evaluation.

We compare VASPO with Vanilla (the initial checkpoint), DAPO, PPO
([Schulman et al., 2017](#bib.bib20)), OPSD ([Zhao et al.,
2026](#bib.bib37)), and RLSD ([Yang et al., 2026a](#bib.bib30)). For
mathematics, we report avg@32 on AIME24, AIME25, and AIME26
([Mathematical Association of America, n.d.](#bib.bib16)) and HMMT25,
and avg@8 on Minerva Math ([Lewkowycz et al., 2022](#bib.bib10)) and
OlympiadBench ([He et al., 2024](#bib.bib6)). For KK, we report avg@16
on held-out 4–8-role puzzles and out-of-distribution tests with 9, 10,
and 11 roles. Avg@$`K`$ denotes mean correctness over $`K`$ sampled
responses per problem. We assess critic quality using explained variance
(EV), which measures how much return variation is explained by its value
predictions:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{EV}=1-\frac{\operatorname{Var}_{\mathcal{M}}(G_{t}-V_{t})}{\operatorname{Var}_{\mathcal{M}}(G_{t})+\varepsilon_{\mathrm{EV}}},
``` |  | (15) |

where $`\mathcal{M}`$ contains valid response-token positions, $`V_{t}`$
is the raw critic prediction, $`G_{t}`$ is the clean student’s
verifier-return target, and $`\varepsilon_{\mathrm{EV}}>0`$ ensures
numerical stability. Higher EV indicates lower residual variance
relative to return variance.

#### Implementation Details.

We implement VASPO in verl ([Sheng et al., 2025](#bib.bib23)), using
full-parameter training with AdamW and actor/critic learning rates of
$`10^{-6}`$/$`5\times 10^{-6}`$. The global batch size is 128 and the
mini-batch size is 32, with eight responses sampled per prompt. We use
$`\gamma=1`$, $`\lambda_{\mathrm{GAE}}=1`$, PPO clipping
$`\epsilon_{\mathrm{clip}}=0.2`$, reweighting clip $`\epsilon_{w}=0.2`$,
and selection parameters $`\tau=\delta=0.02`$. Training and evaluation
use temperatures of $`1.0`$ and $`0.6`$, respectively, with top-$`p`$
$`0.95`$ and top-$`k`$ $`20`$. The maximum response length is
$`8{,}192`$ tokens for both training and evaluation. Critic pretraining,
evaluation, and training settings are provided in
Appendices [C](#A3 "Appendix C Critic Pretraining ‣ VASPO: Self-Distillation with Privileged Value Estimation"),
[D.2](#A4.SS2 "D.2 Evaluation Details ‣ Appendix D Additional Experimental Details ‣ VASPO: Self-Distillation with Privileged Value Estimation"),
and [D.4](#A4.SS4 "D.4 Training Details ‣ Appendix D Additional Experimental Details ‣ VASPO: Self-Distillation with Privileged Value Estimation"),
respectively. For Qwen3-4B-Instruct-2507, student rollout is the most
time-consuming component, averaging $`191.97`$ s per step over 200
training steps
(Appendix [D.5](#A4.SS5 "D.5 Training-time Analysis ‣ Appendix D Additional Experimental Details ‣ VASPO: Self-Distillation with Privileged Value Estimation")).

#### Mathematical reasoning.

VASPO surpasses all baselines across the mathematical benchmarks on both

Furthermore, VASPO sets the highest average performance on the KK
dataset, improving both in-domain reasoning and out-of-distribution

(Table [2](#S4.T2 "Table 2 ‣ 4.2 Main Results ‣ 4 Experiments ‣ VASPO: Self-Distillation with Privileged Value Estimation")).

PPO. The separation in held-out performance is therefore more pronounced
than in training reward. This pattern is consistent with the hypothesis
that privileged value estimation supports policy learning; the component
ablations and value diagnostics below examine this explanation more
directly.

#### Ablation on fusion strength.

Stronger teacher modulation does not guarantee better performance
(Figure [5](#S4.F5 "Figure 5 ‣ Ablation on token-level mask. ‣ 4.3 Ablation Study ‣ 4 Experiments ‣ VASPO: Self-Distillation with Privileged Value Estimation")).
Modulated by the probability-ratio clip width $`\epsilon_{w}`$ in
equation [12](#S3.E12 "In From teacher scores to token weights. ‣ 3.4 Teacher-Guided PPO Update ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation"),
the default $`\epsilon_{w}=0.2`$ achieves higher final AIME accuracy
than either disabling it (zero) or widening it to $`0.5`$.

#### Ablation on privileged-information content.

Replacing the solution-plus-answer input with an answer-only variant
lowers accuracy across all evaluated benchmarks and role groups
(Table [3](#S4.T3 "Table 3 ‣ 4.3 Ablation Study ‣ 4 Experiments ‣ VASPO: Self-Distillation with Privileged Value Estimation")).
Both readers receive the modified input, while the actor remains
conditioned on the standard prompt.

#### Critic pre-update.

Removing the critic pre-update incurs a consistent accuracy drop across
all mathematical benchmarks and KK role groups
(Table [3](#S4.T3 "Table 3 ‣ 4.3 Ablation Study ‣ 4 Experiments ‣ VASPO: Self-Distillation with Privileged Value Estimation")).
Because self-teacher advantage modulation can amplify actor updates, it
risks exacerbating the distribution shift between the evolving policy
and a critic fitted to outdated rollouts. Updating the critic on the
latest actor trajectories prior to computing advantages enables it to
align with the current policy before the subsequent actor update. This
timely adaptation enhances value-prediction accuracy and yields more
reliable token-level credit, effectively explaining the observed
performance gains.

#### Advantage whitening.

Applying global whitening after teacher modulation degrades performance
across all mathematical benchmarks and KK role groups
(Table [3](#S4.T3 "Table 3 ‣ 4.3 Ablation Study ‣ 4 Experiments ‣ VASPO: Self-Distillation with Privileged Value Estimation")).
Although strictly positive teacher weights preserve the signs of the raw
advantages, the subsequent subtraction of a batch-wide mean can
inadvertently invert the signs of some fused advantages. Consequently,
tokens initially encouraged by the outcome-grounded signal might receive
penalizing updates, or vice versa, severely distorting the intended
optimization directions. This phenomenon accounts for the observed
degradation and strongly advocates for utilizing the fused advantages
without any subsequent global whitening.

### 4.4 Analysis

#### Does privileged information improve value prediction?

Conditioning on reference solutions improves value prediction point
estimates but does not aid calibration
(Figure [9](#A7.F9 "Figure 9 ‣ G.2 Prediction Quality under Independent Continuations ‣ Appendix G Additional Experiments ‣ VASPO: Self-Distillation with Privileged Value Estimation")).
Evaluated on fixed continuations from a frozen Qwen3 actor, the
privileged solution critic yields the highest explained variance and
lowest Brier error across the three checkpoints, whereas the baseline
critic maintains the lowest ECE. The point-estimate rankings alone do
not establish a strict overall advantage.

#### Where do the two signals help?

The critic’s benefit varies significantly by prefix position and
source-response correctness. Aggregate diagnostics indicate that
solution conditioning degrades accuracy at early prefixes but improves
it at late prefixes, with mixed results in the middle. Paired positional
contrasts confirm this trend, highlighting that late-stage gains are
largest for incorrect source responses. While length controls validate
this pattern for medium and long responses, the late gain remains
uncertain in the long-response group
(Appendix [G.3](#A7.SS3 "G.3 Where the Critic Improvement Occurs ‣ Appendix G Additional Experiments ‣ VASPO: Self-Distillation with Privileged Value Estimation")).
Conversely, the self-teacher follows a different trajectory: its
divergence from the baseline actor is high initially, falls through the
middle, and rebounds at the final position
(Figure [2](#S2.F2 "Figure 2 ‣ 2.3 The Positional Divide of Supervision ‣ 2 Preliminaries ‣ VASPO: Self-Distillation with Privileged Value Estimation")).
These complementary signal profiles motivate employing the two readers
for distinct roles in the update.

## 5 Conclusion

We presented VASPO, a PPO framework leveraging shared reference
solutions for continuation-value estimation and token guidance. By
combining privileged critic credit and bounded self-teacher modulation,
VASPO trains actors using solely standard prompts. Empirically, it
achieves top average accuracy across Qwen3 and OLMo3 mathematical and
logical reasoning benchmarks. Analyses show privileged conditioning
trades higher early-prefix error and worse calibration for improved
late-prefix value prediction. Lastly, ablations confirm that full
solution derivations and selective, moderate teacher modulation are
crucial.

## Limitations

Extending VASPO to interactive tasks requires careful consideration of
when newly observed information becomes available to the value
estimator. Specifically, under the current protocol, environmental
feedback obtained at the completion of a response cannot be
retroactively used as privileged context for earlier prefixes of that
same trajectory.

Furthermore, the framework’s efficacy is constrained by evidence quality
and computational overhead. Privileged reference solutions, even when
yielding a verified final answer, may still harbor flawed intermediate
reasoning steps that could introduce noisy supervision. Additionally,
conditioning the readers on full solutions expands the context window
for both the teacher and the critic, thereby increasing training costs.

Finally, VASPO is currently designed for single-turn generation. Its
application to multi-turn dialogue—where conversational history and
available privileged evidence dynamically evolve across successive
turns—remains an open direction for future work.

## Appendix B Related Work

### B.1 RLVR and Value-Based Credit Assignment

Verifiable outcomes provide a scalable training signal for reasoning,
while the policy optimizer determines how that signal is assigned to
sampled tokens. DeepSeekMath introduced GRPO, which compares rewards
within a group of responses to estimate advantages without a learned
critic ([Shao et al., 2024](#bib.bib22)); DeepSeek-R1 further
demonstrated the potential of outcome-based reinforcement learning for
reasoning ([Guo et al., 2025](#bib.bib5)). In outcome-only GRPO, a
response-level advantage is shared across token positions. PPO instead
uses a learned value function to construct prefix-dependent advantages
([Schulman et al., 2017](#bib.bib20)). Process supervision provides
another route to finer-grained feedback by learning from
intermediate-step correctness labels ([Lightman et al.,
2024](#bib.bib12)). Step-potential advantage estimation similarly
derives step-level credit from intermediate confidence and correctness
signals ([Wu et al., 2026a](#bib.bib25)). VASPO retains terminal
verification as the source of rewards and value targets, and uses
training-time evidence to inform the two readers that construct
token-level updates.

Recent actor–critic methods study value estimation for long reasoning
trajectories. VC-PPO pretrains the critic with Monte Carlo returns and
decouples the GAE parameters used for value and policy updates ([Yuan
et al., 2025](#bib.bib32)). VAPO builds on these techniques and adds
length-adaptive advantage estimation to address heterogeneous response
lengths ([Yue et al., 2025](#bib.bib33)). GenAC replaces a scalar value
head with a generative critic that reasons about a prefix before
predicting its value ([Shan et al., 2026](#bib.bib21)). ReDiPPO instead
calibrates value estimates with reference-model guidance and reweights
tokens according to policy–reference discrepancy ([Zhang et al.,
2026c](#bib.bib36)). In OPD, [Oh et al. (2026)](#bib.bib17) derive a
closed-form reverse-KL control-variate baseline to reduce gradient
variance without an additional critic. That baseline belongs to the
distillation objective; VASPO’s learned critic predicts verifier returns
from clean student continuations. VASPO studies the critic’s input
choice: conditioning this return estimate on the evidence already
supplied to a self-teacher.

### B.2 On-Policy Distillation and Self-Teaching

On-policy distillation supplies teacher feedback on the states that the
student actually visits. GKD trains on student-generated sequences and
studies several distribution-matching objectives ([Agarwal et al.,
2024](#bib.bib1)), while MiniLLM uses a reverse-KL objective optimized
through policy gradients ([Gu et al., 2024](#bib.bib4)). More recent
work also considers objectives that relax strict imitation: ExOPD scales
the teacher-derived implicit reward within a KL-constrained formulation
([Yang et al., 2026b](#bib.bib31)). These methods establish
student-generated prefixes as the interface for dense teacher
supervision.

Self-distillation obtains a better-informed teacher by changing its
context rather than requiring a separate, larger model.
Retrieval-augmented generation conditions a model on external evidence
in a similar spirit: Stable-RAG shows that permuting the retrieved clues
can by itself induce hallucinations ([Zhang et al., 2026b](#bib.bib35)),
while compact clue selection reduces such evidence to an informative
subset for efficient reasoning ([Zhang et al., 2026a](#bib.bib34)). This
use of training-only context connects self-teaching to learning using
privileged information and generalized distillation ([Vapnik and
Vashist, 2009](#bib.bib24); [Lopez-Paz et al., 2016](#bib.bib15)). OPSD
conditions a detached self-teacher on worked solutions and matches its
distributions along clean student rollouts ([Zhao et al.,
2026](#bib.bib37)). SDPO constructs self-teaching contexts from rich
environment feedback and successful attempts, allowing the policy to
learn from information revealed during interaction ([Hübotter et al.,
2026](#bib.bib8)). Studies of privileged OP(S)D identify failure modes
for thinking models, instance-specific privileged information, and
unreliable teacher targets at some student prefixes ([Kaur et al.,
2026](#bib.bib9); [Zhu et al., 2026](#bib.bib38); [Liu et al.,
2026a](#bib.bib13)). These findings concern the teacher signal and its
downstream effect on the actor. VASPO uses the privileged information
for sampled-token assessment and additionally tests its effect on
continuation-value estimation. This second role constrains evidence
timing: the shared bank is fixed before rollout, whereas feedback from
the current completed response can inform a retrospective teacher
without being an admissible input to VASPO’s critic for that same
response.

### B.3 Combining Distillation with Verifiable Rewards

Several methods combine dense distillation with outcome optimization
through an additive objective or advantage. MiMo-V2-Flash adds
teacher–student log-probability gaps to outcome-derived advantages in
its multi-teacher distillation pipeline ([Xiao et al.,
2026](#bib.bib27)). SDPG combines a verifier-based policy-gradient
objective with an exact full-vocabulary self-distillation loss and
reference-policy KL regularization ([Liu et al., 2026b](#bib.bib14)).
SAF-OPD studies the relative magnitude and training schedule of the two
signals, using sparsification and bounded compression together with
warm-up and annealing for the external-teacher OPD branch ([Ding et al.,
2026](#bib.bib3)). These designs show that the granularity, scale, and
timing of teacher supervision are separate choices in the fusion
interface.

Other methods select where to apply each signal. Sample-Routed Policy
Optimization (SRPO) routes failed responses with available teacher
information to self-distillation and the remaining responses to GRPO
([Li et al., 2026](#bib.bib11)). Reward-Gated OPD instead retains
trajectories for distillation according to agreement between the
verifier-derived advantage and a sequence-level teacher–student
likelihood gap ([Akhondzadeh et al., 2026](#bib.bib2)). Its verifier
thus controls a distillation gate, rather than contributing an additive
reward term. VASPO uses a learned prefix value to construct its
advantage and applies teacher modulation within that actor–critic
update.

The closest group-relative interfaces use the teacher to refine
verifier-grounded credit. Self-Distilled RLVR (RLSD) preserves the sign
of the outcome advantage while a detached teacher–student evidence ratio
changes token-level update magnitudes ([Yang et al.,
2026a](#bib.bib30)). RLCSD contrasts correct and incorrect privileged
contexts to suppress correctness-independent style shifts in the teacher
signal ([Pan et al., 2026](#bib.bib19)). SSPO applies teacher–student
disagreement as step-level advantage weights on incorrect deep-search
trajectories ([Wu et al., 2026b](#bib.bib26)). Their group-relative
outcome advantages are shared across positions before teacher
modulation; they do not learn a value conditioned on privileged
information for each student prefix. VASPO uses the privileged
information in a learned PPO critic as well as the teacher, so its
outcome-grounded advantages can vary across prefixes before modulation.
The bounded fusion preserves the sign of the raw privileged-critic
advantage
(Section [3.4](#S3.SS4 "3.4 Teacher-Guided PPO Update ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation")).

## Appendix C Critic Pretraining

#### Pretraining Data.

For each task and policy backbone, we use the initial policy checkpoint
to sample eight responses per training prompt. The actor observes only
the standard problem prompt, without the privileged solution or answer.
Each response receives a binary correctness label from the task verifier
described in
Appendix [D.2](#A4.SS2 "D.2 Evaluation Details ‣ Appendix D Additional Experimental Details ‣ VASPO: Self-Distillation with Privileged Value Estimation").
We upsample incorrect response trajectories to obtain an approximately
balanced ratio of correct and incorrect examples. The same sampled
trajectories and return labels are used to pretrain the clean and
privileged critic variants.

#### Pretraining Protocol.

Each critic is initialized from its corresponding policy backbone with a
scalar value head and pretrained for two epochs before RL, following the
value-pretraining protocol of VAPO ([Yue et al., 2025](#bib.bib33)).
Pretraining minimizes the mean squared error between each token-level
prediction and the response’s terminal verifier return. With
$`\gamma=1`$, every valid response-token state has the same binary
target. The clean critic reads the prompt and preceding response tokens;
the privileged critic additionally reads the fixed dataset solution and
answer. Neither critic observes the current token or subsequent response
tokens. PPO and the critic-based reader ablations use the same
initialization, pretraining trajectories, targets, and epoch count; the
input conditioning changes with the ablation. Offline pretraining
initializes the critic, while the per-rollout pre-update in
Appendix [F](#A6 "Appendix F Complete Implementation Details ‣ VASPO: Self-Distillation with Privileged Value Estimation")
adapts it during RL.

#### Pretraining Dynamics.

Figure [6](#A2.F6 "Figure 6 ‣ B.2 On-Policy Distillation and Self-Teaching ‣ Appendix B Related Work ‣ VASPO: Self-Distillation with Privileged Value Estimation")
shows the recorded loss and explained variance under clean, answer, and
solution conditioning. In mathematics, loss decreases overall and
explained variance increases for all three variants. At the last
recorded checkpoint in each task, the answer- and solution-conditioned
critics have lower loss and higher explained variance than the clean
critic.

### D.2 Evaluation Details

#### Training Stage.

For mathematical reasoning, we use math-verify¹¹ 1
[https://github.com/huggingface/Math-Verify](https://github.com/huggingface/Math-Verify)
to compare each generated answer with its reference answer, producing a
binary terminal reward in $`\{0,1\}`$. This supports the non-integer
answers present in the full DeepMath training set. For KK, the task
verifier checks the complete knight/knave assignment against the
reference assignment; a response is correct only when every role is
correct. These verifier outcomes also provide the critic-pretraining
labels and RL return targets.

#### Test Stage.

For all six mathematical benchmarks, we use a two-stage verification
procedure. We first evaluate every predicted answer with math-verify.
Responses judged correct are accepted directly, while those judged
incorrect are sent to CompassVerifier-3B for a second verification pass.
For these responses, the second-stage judgment determines the final
correctness label. KK evaluation uses the complete-assignment verifier
described above.

#### Sampling and Metrics.

Evaluation uses temperature $`0.6`$, top-$`p`$ $`0.95`$, top-$`k`$
$`20`$, and a maximum response length of $`8{,}192`$ tokens for both
backbones. We use $`K=32`$ samples per problem for AIME24, AIME25,
AIME26, and HMMT25, $`K=8`$ for Minerva Math and OlympiadBench, and
$`K=16`$ for KK. For a benchmark with $`N`$ problems, the reported
percentage is

### D.3 Baselines

We compare VASPO with three groups of baselines. Vanilla reports the
initial policy checkpoint without RL. DAPO is the critic-free RLVR
baseline, while PPO uses a clean critic and the same value-pretraining
protocol as VASPO. OPSD ([Zhao et al., 2026](#bib.bib37)) and
RLSD ([Yang et al., 2026a](#bib.bib30)) compare against privileged
self-distillation and its combination with verifiable rewards. External
baselines retain their documented objectives.

For the reader-component comparisons, the variant without the privileged
critic removes the entire privileged critic and its associated PPO/GAE
update path, and trains with the OPSD objective. The variant without
self-teacher modulation retains the privileged critic and PPO update,
while removing both reader components yields PPO with a clean critic.
PPO, Critic-only, and VASPO share critic architecture, initialization,
pretraining, value targets, data order, and optimization settings within
each seed. These three conditions also share normalization, critic
pre-update schedule, rollout correction, reference-policy KL settings,
and actor loss reduction. Each condition generates its own on-policy
responses.

### D.4 Training Details

#### Optimization Settings.

We implement VASPO in verl ([Sheng et al., 2025](#bib.bib23)) and update
all model parameters with AdamW. The global batch size is 128, the PPO
mini-batch size is 32, and the actor and critic learning rates are
$`1\times 10^{-6}`$ and $`5\times 10^{-6}`$, respectively. We set
$`\gamma=\lambda_{\mathrm{GAE}}=1`$ and use PPO clipping
$`\epsilon_{\mathrm{clip}}=0.2`$. VASPO uses full clipped
probability-ratio reweighting with $`\epsilon_{w}=0.2`$ and
token-selection parameters $`\tau=\delta=0.02`$, without advantage
normalization. The self-teacher uses EMA decay $`0.95`$ after each actor
optimizer step.

#### Rollout Settings.

We sample eight responses per prompt at temperature $`1.0`$, top-$`p`$
$`0.95`$, and top-$`k`$ $`20`$. The maximum response length is
$`8{,}192`$ tokens for both backbones. The clean actor prompt limit is
$`2{,}048`$ tokens, including its chat template. Privileged reader
inputs have a separate context budget: the complete solution and answer,
reader wrapper, problem, and response prefix must fit the reader’s
context window. Oversized or invalid privileged inputs are handled
before the common training manifest is frozen, with excluded counts
recorded. Evaluation retains every test problem and logs token-limit
termination and answer-extraction failures. Prompt templates are listed
in
Appendix [D.6](#A4.SS6 "D.6 Prompts ‣ Appendix D Additional Experimental Details ‣ VASPO: Self-Distillation with Privileged Value Estimation").

## Appendix E Additional Method Details

#### Value regression and advantage computation.

The critic regresses to student-rollout returns using
equation [9](#S3.E9 "In PPO clipped value loss. ‣ 3.3 Privileged Value Estimation ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation").
The training driver first evaluates values and constructs return
targets. These initial predictions remain the fixed clipping centers
during the critic pre-update. The driver then re-evaluates values and
recomputes the actor advantages. Under terminal-only rewards and
$`\gamma=\lambda_{\mathrm{GAE}}=1`$, the target is $`G_{i}`$ at every
valid token, and the refreshed advantage is $`G_{i}-v^{z,+}_{i,t}`$ as
in
equation [10](#S3.E10 "In Advantages from refreshed values. ‣ 3.3 Privileged Value Estimation ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation").
Only these recomputed advantages enter token selection and teacher
fusion. Their critic snapshot is $`\phi^{+}`$, with terminal value
$`V^{z}_{\phi^{+}}(h_{T+1},z)=0`$. The privileged information remains
fixed throughout the response, and the critic’s input excludes the
current token and subsequent continuation. When $`z=f(x)`$ is
deterministic, conditioning on privileged information changes the
critic’s representation without adding information beyond the prompt;
the question is whether this explicit representation helps a finite
critic predict student returns.

#### Effect of reweighting.

For $`A^{z}_{t}\neq 0`$,
equation [14](#S3.E14 "In Reweighting the advantage. ‣ 3.4 Teacher-Guided PPO Update ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation")
satisfies

|  |  |  |  |
|----|----|----|----|
|  |
``` math
1-\epsilon_{w}\leq\frac{A^{z,\mathrm{f}}_{t}}{A^{z}_{t}}\leq 1+\epsilon_{w}.
``` |  | (17) |

Selected tokens receive the clipped ratio, while unselected tokens have
unit weight. This bound preserves the sign of the raw privileged-critic
advantage. Changing the critic can still change that advantage relative
to a critic without privileged input.
Algorithm [1](#alg1 "Algorithm 1 ‣ Reweighting the advantage. ‣ 3.4 Teacher-Guided PPO Update ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation")
summarizes the signal flow; the teacher-update schedule and auxiliary
training settings are specified in
Appendix [F](#A6 "Appendix F Complete Implementation Details ‣ VASPO: Self-Distillation with Privileged Value Estimation").

## Appendix F Complete Implementation Details

This section records the experimental realization of the method,
including teacher updates, token selection, loss reduction, and optional
variants.

|  Setting |  Value or procedure |
|----|----|
|  Critic architecture |  Actor backbone with a scalar value head; matched initialization across clean and privileged variants |
|  Critic regression |  Monte Carlo terminal return; PPO clipped value loss |
|  Critic update schedule |  Pre-update once per rollout batch, then re-score values and recompute GAE before fusion |
|  Fusion |  Full clipped probability-ratio reweighting; $`\epsilon_{w}=0.2`$ |
|  Token selection |  Raw $`A^{z}_{t}>0`$ and $`|\tanh(d_{t}/\tau)|>\delta`$; $`\tau=\delta=0.02`$ |
|  Student probability source |  Behavior policy |
|  Advantage normalization |  None before or after fusion |
|  Teacher update |  EMA decay $`\beta_{\mathrm{EMA}}=0.95`$ after each actor optimizer step |
|  Teacher score caching |  Once per rollout batch, before actor updates |
|  Actor loss reduction |  Mean over valid tokens per response, then over responses |
|  Rollout correction |  Token-level importance weighting (launcher default) |

Table 6: Critic, teacher, and policy-update settings for VASPO. Matched
controls retain the applicable settings when a reader is disabled.
Optional implementation variants are described in
Appendix [F](#A6 "Appendix F Complete Implementation Details ‣ VASPO: Self-Distillation with Privileged Value Estimation").

#### Critic update schedule.

The critic is updated before computing the actor advantages for each
rollout batch. We first construct the critic’s return targets and store
its value predictions as fixed clipping centers, run the PPO clipped
value update, and repeat value inference and GAE on the same rollout
batch. Teacher fusion is applied only after this second pass. The
ordinary later critic-update call is skipped, so the schedule changes
when the critic is trained without adding a second update phase. This is
a per-batch operation, distinct from the offline initialization in
Appendix [C](#A3 "Appendix C Critic Pretraining ‣ VASPO: Self-Distillation with Privileged Value Estimation").

#### Teacher parameters and score caching.

The self-teacher uses an exponential moving average of student
parameters, initialized with $`\bar{\theta}_{0}=\theta_{0}`$. After each
actor optimizer step,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\bar{\theta}_{k+1}=\beta_{\mathrm{EMA}}\bar{\theta}_{k}+(1-\beta_{\mathrm{EMA}})\theta_{k+1}.
``` |  | (18) |

The decay is listed in
Table [6](#A6.T6 "Table 6 ‣ Appendix F Complete Implementation Details ‣ VASPO: Self-Distillation with Privileged Value Estimation").
Teacher probabilities are evaluated and cached once per rollout batch,
before the actor update. They remain fixed within that batch even as the
EMA parameters change.

#### Token selection and reweighting.

The implementation computes the detached gap in
equation [11](#S3.E11 "In From teacher scores to token weights. ‣ 3.4 Teacher-Guided PPO Update ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation")
and selects valid response tokens with
equation [13](#S3.E13 "In Token-level mask. ‣ 3.4 Teacher-Guided PPO Update ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation").
Table [6](#A6.T6 "Table 6 ‣ Appendix F Complete Implementation Details ‣ VASPO: Self-Distillation with Privileged Value Estimation")
gives the temperature, threshold, and clipping width. The $`\tanh`$
transform only selects tokens; their weight is the clipped ratio
$`e^{d_{t}}`$ from
equation [12](#S3.E12 "In From teacher scores to token weights. ‣ 3.4 Teacher-Guided PPO Update ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation").
Selected advantages are multiplied directly by this clipped ratio.
Negative and zero raw advantages, and positive advantages below the
signal threshold, retain their GAE values.

#### Behavior versus current student probabilities.

The main formulation uses $`p_{\mathrm{old},t}(y_{t})`$, keeping the
weights, selection mask, and fused advantages fixed during the batch
update. A supported variant replaces this denominator with
$`p_{\theta,t}(y_{t})`$ and recomputes the gap, mask, and fusion at each
actor forward pass. Teacher probabilities remain cached in either case.
The recomputed fusion is still detached, so gradients do not pass
through its denominator. PPO’s update ratio always compares the current
actor with the behavior policy. Recomputing teacher scores during actor
updates is a separate option, disabled in the default configuration.

#### Advantage normalization.

The default uses raw GAE advantages for selection and fusion, with no
whitening before or after fusion. If post-fusion whitening is enabled,
let $`\mathcal{M}`$ contain every valid token position in the rollout
batch:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{A}_{i,t}=\frac{A^{z,\mathrm{f}}_{i,t}-\mu_{\mathcal{M}}}{\sqrt{\sigma^{2}_{\mathcal{M}}+10^{-8}}}.
``` |  | (19) |

The mean and variance include selected and unselected tokens. Both loss
paths use these same statistics, and the selection mask is not
recomputed. Centering can change advantage signs, so
equation [17](#A5.E17 "In Effect of reweighting. ‣ Appendix E Additional Method Details ‣ VASPO: Self-Distillation with Privileged Value Estimation")
describes the fusion before whitening. With raw GAE input, this
normalization option requires the behavior-policy denominator and cached
teacher scores; the current-policy variant uses no post-fusion
whitening.

#### Loss reduction and auxiliary settings.

Let $`B`$ be the number of responses and $`T_{i}`$ their valid-token
counts. Write $`\widehat{A}_{i,t}=A^{z,\mathrm{f}}_{i,t}`$ by default,
or use
equation [19](#A6.E19 "In Advantage normalization. ‣ Appendix F Complete Implementation Details ‣ VASPO: Self-Distillation with Privileged Value Estimation")
when whitening is enabled. The core actor loss averages tokens within
each response and then averages responses:

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\mathcal{L}_{\mathrm{actor}}(\theta)=-\frac{1}{B}\sum_{i=1}^{B}\frac{1}{T_{i}}\sum_{t=1}^{T_{i}}`$ |  | (20) |
|  |  | $`\displaystyle\min\!\left(\rho_{i,t}(\theta)\widehat{A}_{i,t},\rho^{\mathrm{clip}}_{i,t}(\theta)\widehat{A}_{i,t}\right).`$ |  |  |

Selected and unselected contributions share the valid-token denominator
and have equal branch weights. The PPO ratio and its clipping are
defined in
Section [2.1](#S2.SS1 "2.1 Reinforcement Learning with Verifiable Rewards ‣ 2 Preliminaries ‣ VASPO: Self-Distillation with Privileged Value Estimation");
the probability-ratio clip $`\epsilon_{w}`$ instead bounds advantage
reweighting. The launcher additionally applies token-level rollout
importance weights to this surrogate. The reference-policy KL
coefficient is $`0`$, as listed in
Table [5](#A4.T5 "Table 5 ‣ Hyperparameter Record. ‣ D.4 Training Details ‣ Appendix D Additional Experimental Details ‣ VASPO: Self-Distillation with Privileged Value Estimation").
The critic uses the regression loss in
equation [9](#S3.E9 "In PPO clipped value loss. ‣ 3.3 Privileged Value Estimation ‣ 3 Methodology ‣ VASPO: Self-Distillation with Privileged Value Estimation").

## Appendix G Additional Experiments

We trace the positional pattern in
Section [2.3](#S2.SS3 "2.3 The Positional Divide of Supervision ‣ 2 Preliminaries ‣ VASPO: Self-Distillation with Privileged Value Estimation")
from saved responses to independent continuations, then ask which
response groups account for it. The evidence identifies where critic
predictions improve; teacher utility and training interaction require
separate tests.

### G.1 Signal Profiles on Fixed Responses

Figure 8: A pooled trend hides different response groups. Saved-response
critic error reduction (left) and teacher KL (right). Shading shows
pointwise 95% problem-bootstrap intervals; $`n`$ counts problems, which
can occur in both correctness groups. There are 6,659 correct and 1,629
incorrect responses (8,288 total). Positive critic values favor solution
conditioning; teacher KL measures disagreement, not useful guidance.

To separate the pooled trend from its contributing groups, we score
ordinary and solution-conditioned critics and the self-teacher on
identical saved response tokens. The 1,024 problems contribute 8,288
responses, split by correctness; one problem can appear in both groups.
With realized outcome $`R`$, the critic signal is

|     |                                                     |     |      |
|-----|-----------------------------------------------------|-----|------|
|     |
       ``` math
       \Delta_{t}^{V}=(v_{t}^{0}-R)^{2}-(v_{t}^{z}-R)^{2},
       ```                                                  |     | (21) |

and the teacher signal is conditional
$`D_{\mathrm{KL}}(p_{\theta,t}\|q^{z}_{\theta,t})`$. Values are read
before the current token. Tokens are assigned to ten bins using
$`(t-\tfrac{1}{2})/T`$ without rescaling after exclusions.

Figure [8](#A7.F8 "Figure 8 ‣ G.1 Signal Profiles on Fixed Responses ‣ Appendix G Additional Experiments ‣ VASPO: Self-Distillation with Privileged Value Estimation")
reveals two different critic profiles: errors decrease throughout
incorrect responses, whereas correct responses incur an early cost and
benefit only near the end. Teacher KL falls toward the middle and
rebounds at the end in both groups. Thus, the pooled curve hides
outcome-dependent critic behavior, and teacher change is not confined to
the beginning. Since each response supplies only one realized outcome,
we next check critic predictions against independently sampled
continuations.

### G.2 Prediction Quality under Independent Continuations

Figure 9: Prediction accuracy and calibration need not improve together.
Three existing critics evaluated on the same 128 problems, 384 prefixes,

We freeze Qwen3-4B-Instruct-2507 and compare three existing critics

answer and first reference solution. On 128 evaluation problems, we

Figure [9](#A7.F9 "Figure 9 ‣ G.2 Prediction Quality under Independent Continuations ‣ Appendix G Additional Experiments ‣ VASPO: Self-Distillation with Privileged Value Estimation")
shows the highest EV and lowest Brier point estimates for solution

### G.3 Where the Critic Improvement Occurs

Figure 10: Later critic gains depend on the source response.
Clean-minus-solution Brier improvement by source correctness (a) and

Aggregate errors can hide offsetting gains and costs. We therefore

sampled position $`r`$, then form the within-problem contrast

|     |                                                  |     |      |
|-----|--------------------------------------------------|-----|------|
|     |
       ``` math
       C=\frac{\Delta(0.5)+\Delta(0.8)}{2}-\Delta(0.2).

This compares three discrete positions, not continuous trajectory

Figure [10](#A7.F10 "Figure 10 ‣ G.3 Where the Critic Improvement Occurs ‣ Appendix G Additional Experiments ‣ VASPO: Self-Distillation with Privileged Value Estimation")(a,c)
shows an early cost and a late benefit in the pooled group, with an
uncertain middle-position effect. The late gain is much larger for
incorrect source responses; the correct source group’s late interval

relevant distinction is thus where prediction improves within a
response, rather than a uniform gain at every prefix.

uncertain in short ones. Yet the long-response late-gain interval
includes zero: its positive contrast can also reflect the pronounced
early cost. A positive positional contrast therefore does not establish
a significant late gain in every length stratum. Final-answer and
terminal-region exclusions are unavailable because these regions were
not marked.

### G.4 Diagnostic Protocol

#### Samples and models.

The continuation study contains 256 problems (768 prefixes, 6,144
continuations). A separate 128-problem fit split supplies length-tertile
thresholds, computed by linearly interpolated percentiles. Short
responses have $`T\leq 1{,}008`$; medium responses have
$`1{,}008<T\leq 1{,}779.333\ldots`$; longer responses form the long
stratum. The critics are not refitted on this split. The evaluation
split has 101 correct and 27 incorrect source responses, and 34 short,
45 medium, and 49 long responses. Its 3,072 continuation returns contain
2,517 successes and 555 failures. Each scalar-headed Qwen3 critic was
trained on 577,140 balanced examples from the DeepMath training source
for two epochs, at learning rate $`5\times 10^{-6}`$, with 256-step
gradient accumulation, bfloat16, and ZeRO-1 on eight GPUs.

#### Targets and metrics.

The verifier compares the last boxed answer with the ground truth.
Original labels scored the new suffix; rescoring all 3,072 evaluation
continuations after prefix concatenation changes none of them (1,024
checked at each position, none unrecoverable). Separate and joint token
decoding agree, including for the 17 prefixes that already contain boxed
expressions. There were no verifier execution failures. The evaluation
split contains 96 truncated continuations, out of 192 across both
splits. For predictions $`p_{h}`$ and binary outcomes $`y_{hk}`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{Brier}_{h}=(p_{h}-\bar{y}_{h})^{2}+\frac{1}{K_{h}}\sum_{k}(y_{hk}-\bar{y}_{h})^{2}.
``` |  | (23) |

The shared variance term cancels in paired critic differences, so we
plot Brier improvement without a redundant MSE-improvement panel. EV
uses pooled weighted moments,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{EV}=1-\frac{\mathbb{E}_{w}[(y-p)^{2}]-\mathbb{E}_{w}[y-p]^{2}}{\mathbb{E}_{w}[y^{2}]-\mathbb{E}_{w}[y]^{2}},
``` |  | (24) |

with NaN for return variance below $`10^{-12}`$; negative EV is
retained. ECE uses ten equal-width probability bins.

#### Aggregation and uncertainty.

Both diagnostics weight problems equally. Within a problem,
saved-response curves average tokens within a response bin, then
responses; continuation curves average outcomes within a prefix, then
prefixes. The pooled group is recomputed from all records. Intervals use
2,000 whole-problem percentile bootstrap replicates; continuation
comparisons share sampled indices (seed 20261010), recomputing EV and
ECE each time. Intervals are pointwise, without multiplicity correction.
The original fixed-response protocol retrieves the first solution by
exact problem matching, uses the solution-and-answer teacher template in
Appendix [D.6](#A4.SS6 "D.6 Prompts ‣ Appendix D Additional Experimental Details ‣ VASPO: Self-Distillation with Privileged Value Estimation"),
and excludes overlength inputs as complete paired records.
