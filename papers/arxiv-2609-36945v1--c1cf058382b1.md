###### Abstract

We study the learning dynamics of fine-tuning a policy model on
self-generated and reward-weighted rollout data, with particular focus
on a generalized version of classic REINFORCE — referred to as
RE($`S`$)— that updates the rollout distribution once every $`S\geq 1`$
gradient steps. Prior work in bandits and reinforcement learning has
developed rich theory for REINFORCE and policy gradient methods, and
on-policy sampling (i.e., a small value of $`S`$, ideally $`1`$) is
often viewed as crucial to their success; yet in prominent application
like post-training large language models, reward-guided self-training
has proved to be effective even when the rollout distribution is updated
infrequently, but theoretical understanding remains limited for the
learning dynamics and convergence properties of these off-policy
methods. To bridge these gaps, we develop a unified theory for RE($`S`$)
that covers the full spectrum of $`S\geq 1`$: it can be interpreted as a
stage-wise iterative optimization process, where each stage takes $`S`$
gradient steps for minimizing the Kullback–Leibler distance to a fixed
reward-weighted rollout distribution. For multi-arm bandits with softmax
policies, our in-depth analysis and numerical experiments reveal three
key findings: (1) for any fixed $`S`$, RE($`S`$) enjoys global
convergence to the optimal policy as the number of rollout distribution
updates $`B=\lfloor T/S\rfloor\rightarrow\infty`$, where $`T`$ denotes
the total number of gradient steps; (2) we prove tight two-sided bounds
for the convergence rate of RE($`S`$), and show that its suboptimality
gap achieves an asymptotic $`\Theta(1/T)`$ convergence rate, while $`S`$
only affects the length of a burn-in phase; (3) when initialized at a
weak policy with a small optimal-action probability, RE(1) gets trapped
around suboptimal policies for a long period, whereas RE($`S`$) with a
suitable $`S`$ avoids the detour and achieves significantly faster
convergence to the global optimum, highlighting the benefits of
off-policyness in this case.

## 1 Introduction

Multi-armed bandits and reinforcement learning (RL) have a long history
([Lattimore & Szepesvári, 2020](#bib.bib14); [Sutton & Barto,
1998](#bib.bib34)) and have achieved substantial empirical success,
including the recent use of RL in post-training large language models
(LLMs) ([Ouyang et al., 2022](#bib.bib24); [Touvron et al.,
2023](#bib.bib36); [OpenAI, 2024](#bib.bib23); [DeepSeek-AI,
2025](#bib.bib5); [Kimi-Team, 2025](#bib.bib11)). Many algorithms in
these areas can be viewed as fine-tuning a policy model
$`\pi_{{\theta}}`$ on self-generated and reward-weighted data. One
prominent example is the classical REINFORCE algorithm ([Williams,
1992](#bib.bib38)) that, in the bandit setting, estimates the policy
gradient by
$`(1/N)\sum_{i=1}^{N}r_{i}\,\nabla_{{\theta}}\log\pi_{{\theta}}(a_{i})`$,
where $`a_{i}\sim\pi_{{\theta}}`$ is a sampled action and $`r_{i}`$ is
the reward for taking action $`a_{i}`$.

This perspective highlights a gap between two major lines of
methodology, practice, and theory:

\(1\) In the bandit and RL literature, there exists a rich theory for
policy gradient and policy iteration methods, including convergence and
sample-complexity guarantees ([Sutton et al., 1999](#bib.bib35);
[Agarwal et al., 2021](#bib.bib1); [Mei et al., 2020b](#bib.bib20); [Mei
et al., 2023](#bib.bib21); [Lu et al., 2024](#bib.bib17)). Much of this
theory assumes on-policy sampling, where the rollout distribution
matches the current policy under optimization. Methods that account for
(a limited degree of) off-policyness often require explicit algorithmic
modifications, for example through trust-region regularization or
clipping importance-sampling ratios ([Schulman et al.,
2015](#bib.bib29); [Schulman et al., 2017](#bib.bib30); [Espeholt
et al., 2018](#bib.bib7)). In practice, keeping the rollout and training
policies closely aligned is also an important design consideration for
these methods, motivating substantial efforts to support frequent and
efficient synchronization of LLM model weights in RL infrastructure
([Sheng et al., 2024](#bib.bib31); [Hu et al., 2024](#bib.bib10); [Pan
et al., 2025](#bib.bib25)).

\(2\) However, in the broader reward-guided self-training paradigm, it
is also common to update the rollout distribution _infrequently_ while
fine-tuning the policy model on rollout samples weighted or filtered by
their rewards, using standard log-likelihood objectives. Successful
examples in the LLM domain include STaR ([Zelikman et al.,
2022](#bib.bib39)), RAFT ([Dong et al., 2023](#bib.bib6)), ReST
([Gulcehre et al., 2023](#bib.bib9)), ReST$`{}^{\text{EM}}`$ ([Singh
et al., 2024](#bib.bib32)), rejection-sampling fine-tuning in Llama 2
([Touvron et al., 2023](#bib.bib36)), AsymRE ([Arnal et al.,
2026](#bib.bib2)), and more recent industrial practice. Such methods can
be implemented with simple infrastructure: an LLM inference engine
([Kwon et al., 2023](#bib.bib12); [Zheng et al., 2024](#bib.bib41))
generates rollout data and periodically loads an updated policy
checkpoint, while a standard supervised fine-tuning (SFT) engine
performs gradient updates on the reward-weighted or reward-filtered
data. Despite their empirical success, theoretical understanding and
guarantees for these off-policy methods remain limited.

These observations raise intriguing research questions. What are the
connections and differences between these two lines of on-policy versus
off-policy methodology? How does rollout staleness affect policy
learning? What convergence guarantees can be established when the
rollout distribution is synchronized with the trained policy
infrequently? In particular, can off-policyness possibly lead to faster
convergence than on-policy learning?

#### Contributions and outline.

Towards answering these questions, we focus on a simple algorithm termed
RE($`S`$) and formalized in
Algorithm [1](#algorithm1 "In 2 A high-level understanding of RE(S) learning dynamics ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"),
which is a generalized version of vanilla REINFORCE that updates the
rollout distribution once every $`S\geq 1`$ gradient steps. The
parameter $`S`$ denotes the maximum staleness of a rollout sample with
respect to the most updated policy model, and RE(1) reduces to standard
on-policy REINFORCE. We show in
Section [2](#S2 "2 A high-level understanding of RE(S) learning dynamics ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
that RE($`S`$) can be interpreted as a stage-wise iterative optimization
process, where each stage effectively takes $`S`$ gradient steps for
minimizing the Kullback-Leibler (KL) distance to the reward-weighted
rollout distribution. Unlike on-policy REINFORCE — which moves along the
direction of standard policy gradient — our interpretation shows that
RE($`S`$) takes an alternative path towards the optimal policy.

In
Section [3](#S3 "3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"),
we further focus on $`K`$-arm bandits and policies with softmax
parameterization, for in-depth analysis and formal theoretical
guarantees. Our key findings include the following:

        RE($`S`$) enjoys global convergence to the optimal policy as the
        total number of gradient steps $`T\rightarrow\infty`$ regardless of
        $`S`$, as long as the number of rollout distribution updates
        $`B=\lfloor T/S\rfloor`$ also grows unbounded;
2.  2.  Theorems [3.3](#S3.Thmtheorem3 "Theorem 3.3 (Upper Bound). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
        and [3.4](#S3.Thmtheorem4 "Theorem 3.4 (Lower Bound). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"):
        We prove tight two-sided bounds showing that the suboptimality gap
        of RE($`S`$) achieves an asymptotic $`\Theta(1/T)`$ convergence rate

3.  3.  Theorem [3.6](#S3.Thmtheorem6 "Theorem 3.6. ‣ 3.3 Benefits of off-policyness ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"):

        the benefits of off-policyness in this case.

## 2 A high-level understanding of RE(S) learning dynamics

We formalize the problem setting as follows. Consider a multi-arm bandit
with action space $`\mathcal{A}`$. Let $`{\theta}`$ denote the
parameters of a policy, and $`\pi_{{\theta}}`$ denote its output
distribution. Every time an action $`a\in\mathcal{A}`$ is sampled from
the policy distribution $`a\sim\pi_{{\theta}}`$, it receives a
(stochastic) reward $`r\sim P_{R}(a)`$ with expectation
$`\mathbb{E}[r]=\mu(a)\geq 0`$. We assume non-negative reward means
$`\mu`$ throughout this work. The mean reward of a policy $`\pi`$ is
denoted by $`J(\pi)\coloneqq\mathbb{E}_{a\sim\pi}\mu(a)`$.

The RE($`S`$) algorithm is formalized in
Algorithm [1](#algorithm1 "In 2 A high-level understanding of RE(S) learning dynamics ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness").
It is a double-loop process: in the $`b`$-th outer iteration, a total of
$`N\times S`$ action-reward pairs are sampled from the same rollout
distribution $`\pi_{{\theta}_{b,0}}`$; then, the inner loop takes $`S`$
gradient steps of reward-weighted fine-tuning, each consuming $`N`$
rollout samples. It is obvious that the special case $`S=1`$ reduces to
standard on-policy REINFORCE.

Input: initial policy parameters $`{\theta}_{0,0}`$, staleness
$`S\in\mathbb{N}_{+}`$, learning rate $`\eta>0`$.

for _$`b=0,1,\dots,B-1`$_ do

   Sample $`a_{s,i}\sim\pi_{{\theta}_{b,0}}`$ and its reward
$`r_{s,i}\sim P_{R}(a_{s,i})`$, $`0\leq s<S`$, $`1\leq i\leq N`$.

   for _$`s=0,1,\dots,S-1`$_ do

      $`{\theta}_{b,s+1}\leftarrow{\theta}_{b,s}+\frac{\eta}{N}\sum_{i=1}^{N}r_{s,i}\nabla_{{\theta}}\log\pi_{{\theta}}(a_{s,i})|_{{\theta}={\theta}_{b,s}}`$.

   end for

   Set $`{\theta}_{b+1,0}\leftarrow{\theta}_{b,S}`$

end for

Algorithm 1 RE($`S`$), a general version

While standard policy gradient theory says
$`\mathbb{E}_{a\sim\pi_{{\theta}}}[\mu(a)\nabla_{{\theta}}\log\pi_{{\theta}}(a)]=\nabla_{{\theta}}J(\pi_{{\theta}})`$,
such unbiasedness is clearly not true for the gradient estimate in
RE($`S`$) when off-policyness occurs, namely $`S>1`$. Fortunately, we
can show that RE($`S`$) takes an alternative path towards the optimal
policy. Indeed, RE($`S`$) can be viewed as a stage-wise optimization
process, where each stage takes $`S`$ gradient-descent steps for
minimizing the KL distance to the reward-weighted rollout distribution
$`\tilde{\pi}^{\mu}_{b}`$:

|     |     |                                                                                                                                                                                                                                              |     |
| --- | --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     |     | $`\displaystyle\mathbb{E}_{a\sim\pi_{{\theta}_{b,0}},r\sim P_{R}(a)}[r\cdot\nabla_{{\theta}}\log\pi_{{\theta}}(a)]=\mathbb{E}_{a\sim\pi_{{\theta}_{b,0}}}[\mu(a)\cdot\nabla_{{\theta}}\log\pi_{{\theta}}(a)]`$                               |     |
|     |     | $`\displaystyle\qquad=Z_{b}\cdot\int_{a\in\mathcal{A}}\frac{\pi_{{\theta}_{b,0}}(a)\mu(a)}{Z_{b}}\nabla_{{\theta}}\log\pi_{{\theta}}(a)\,\text{d}a=Z_{b}\cdot\mathbb{E}_{a\sim\tilde{\pi}^{\mu}_{b}}\nabla_{{\theta}}\log\pi_{{\theta}}(a)`$ |     |
|     |     | $`\displaystyle\qquad=-Z_{b}\cdot\nabla_{{\theta}}\,\text{D}_{\text{KL}}\Big(\tilde{\pi}^{\mu}_{b}\,\|\,\pi_{{\theta}}\Big),`$                                                                                                               |     |

where $`\tilde{\pi}^{\mu}_{b}`$ and $`Z_{b}`$ are defined by

|     |                                                                                                                                                                                                                                  |     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|     | $`\displaystyle\tilde{\pi}^{\mu}_{b}(a)\coloneqq\frac{\pi_{{\theta}_{b,0}}(a)\mu(a)}{Z_{b}},\quad Z_{b}\coloneqq\int_{a\in\mathcal{A}}\pi_{{\theta}_{b,0}}(a)\mu(a)\,\text{d}a=\mathbb{E}_{a\sim\pi_{{\theta}_{b,0}}}\,\mu(a).`$ |     |

If $`S`$ is sufficiently large, then by the end of the inner loop,
$`\pi_{{\theta}_{b+1,0}}=\pi_{{\theta}_{b,S}}`$ will ideally get close
to $`\tilde{\pi}^{\mu}_{b}`$, which is a higher-reward policy than
$`\pi_{{\theta}_{b,0}}`$. Thus RE($`S`$) could converge to the optimal
policy as the rollout distribution gets updated for
$`B\rightarrow\infty`$ times. In the next section, we formalize this
intuition and provide in-depth convergence analysis in concrete
settings.

````math
### 3.1 Global convergence to the optimal policy

The following theorem guarantees global convergence of RE($`S`$) to the
optimal policy $`{\pi}^{\star}=e_{1}`$, namely probability 1 on the
optimal action and 0 elsewhere.

###### Theorem 3.1.

Suppose that $`{\theta}_{0,0}\in\mathbb{R}^{K}`$ is finite, and the
learning rate $`\eta>0`$ satisfies $`\eta\cdot\mu_{\text{max}}<4`$. Then
for any fixed integer $`S\geq 1`$, RE($`S`$) converges to the optimal
policy asymptotically:

|  |  |  |
|----|----|----|
|  | $`\displaystyle{\pi}_{b,s}\rightarrow e_{1}\quad\text{for all}\quad 0\leq s\leq S\quad\text{as}\quad b\rightarrow\infty.`$ |  |

###### Proof sketch.

The proof combines improvement of the surrogate objective with bounds on
changes in the logits. The step-size condition and smoothness ensure
that $`J_{b}\coloneqq J(\pi_{b,0})`$ is nondecreasing in $`b`$, so it
converges to some $`J_{\infty}\leq\mu(1)`$. The remaining work is to
rule out convergence to a suboptimal action. To prove this by
contradiction, suppose that $`J_{\infty}<\mu(1)`$. For fixed $`S`$,
logit changes during each stage tend to zero. Actions with rewards above
$`J_{\infty}`$ eventually have increasing logits, and those below it
have decreasing logits. The estimate
$`\|g_{b,0}\|_{2}\leq C(J_{\infty}-J_{b})`$ implies
$`\sum_{b}(J_{\infty}-J_{b})=\infty`$, since a finite sum would make all
logits converge to finite values and prevent the optimal action’s
gradient from tending to zero. Keeping $`J_{b}\leq J_{\infty}`$
therefore requires an action $`a`$ with $`\mu(a)<J_{\infty}`$ and
$`\sum_{b}\pi_{b,0}(a)=\infty`$, therefore its logit tends to
$`-\infty`$. Since the optimal logit is bounded below, the optimal
action eventually has greater probability, which implies
$`\sum_{b}\pi_{b,0}(1)=\infty`$ and its logit tends to $`+\infty`$. The
probability of every action with $`\mu(a)<J_{\infty}`$, divided by the
optimal action’s probability, then tends to zero. These actions can no
longer offset the optimal action’s positive contribution to
$`J_{b}-J_{\infty}`$, giving $`J_{b}>J_{\infty}`$, which is a
contradiction. Therefore $`J_{\infty}`$ must be
$`\mu(1)=\mu_{\text{max}}`$, which means convergence to the optimal
policy. See
Appendix [A](#A1 "Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
for the full proof. ∎

### 3.2 Two-sided bounds for convergence rates

We next characterize the convergence rate of RE($`S`$) and its
dependence on $`S`$. Denote the suboptimality gaps of policies by

|  |  |  |
|----|----|----|
|  | $`\displaystyle D(\pi)\coloneqq\mu_{\text{max}}-J(\pi),\qquad d_{b}\coloneqq D(\pi_{b,0}),`$ |  |

and define the surrogate loss function $`L`$ as

|  |  |  |
|----|----|----|
|  | $`\displaystyle L(\pi_{b,s};\pi_{b,0})\coloneqq\mathbb{E}_{a\sim{\pi}_{b,0}}\mu(a)\log\pi_{b,s}(a).`$ |  |

Our analysis critically relies on the following lemma that quantifies
progress within each inner loop.

###### Lemma 3.2 (Progress and suboptimality gaps within an inner loop).

Consider the $`b`$-th outer iteration of
Algorithm [2](#algorithm2 "In Problem setup. ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness").
Suppose that $`\eta\cdot\mu_{\text{max}}<4`$. For every
$`1\leq s\leq S`$, we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\lambda\big(\pi_{b,0}(1)\big)\min\{\eta sd_{b}^{2},d_{b}\}`$ | $`\displaystyle\leq L(\pi_{b,s};\pi_{b,0})-L(\pi_{b,0};\pi_{b,0})`$ |  |  |
|  |  | $`\displaystyle\leq J(\pi_{b,s})-J(\pi_{b,0})\leq A\min\{\eta sd_{b}^{2},d_{b}\},`$ |  | (2) |
|  | $`\displaystyle\text{and}\quad\rho d_{b}`$ | $`\displaystyle\leq D(\pi_{b,s})\leq d_{b},`$ |  | (3) |

where the specific forms of $`\lambda(\cdot)`$, $`\rho`$ and $`A`$ can
be found in Appendix
[B](#A2 "Appendix B Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness").

###### Proof sketch.

We focus on explaining the proof idea of the most important lower bound
in
Eq. ([2](#S3.E2 "In Lemma 3.2 (Progress and suboptimality gaps within an inner loop). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")),
and proofs of the remaining results can be found in
Appendix [B](#A2 "Appendix B Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness").
It is known that for on-policy softmax policy gradient, smoothness and
the non-uniform Łojasiewicz inequality give an
$`\Omega(\eta d_{b}^{2})`$ improvement per step ([Mei et al.,
2020b](#bib.bib20)). For fixed inner loop step $`s`$, when
$`\eta sd_{b}\leq 1`$, a small suboptimality gap $`d_{b}`$ limits how
far the current policy can move over the inner loop. Therefore, the
accumulated progress is $`\Omega(s\eta d_{b}^{2})`$ in this inner loop.
This also explains the on-policy order of progress near convergence. But
when $`\eta sd_{b}>1`$, the gradient can be very different from
on-policy gradient during the inner loop. Nonetheless, the optimal
action gradient component remains at least half of its initial value for
about $`1/(\eta d_{b})`$ steps. Combining this with the on-policy
result, we see that the progress in this inner loop is at least

###### Remark 3.5.

Several previous works studied similar problems but with different
theoretical techniques. [Mei et al. (2020b)](#bib.bib20) lower bound
improvement by a multiple of the squared gap using smoothness and a
non-uniform Łojasiewicz inequality; such a bound is not guaranteed to
hold for every step of an inner loop in the RE($`S`$) algorithm that we
study, since its gradient update $`g=q\odot\mu-J(q)\pi`$ (where $`q`$
denotes the rollout distribution) can vanish. [Liu et al.
(2024)](#bib.bib16) use the nonnegativity of
$`(u(a)-u(a^{\prime}))(e^{\eta u(a)}-e^{\eta u(a^{\prime})})`$, where
$`u=\nabla_{\theta}J`$; for RE($`S`$), the corresponding terms are
$`(u(a)-u(a^{\prime}))(e^{\eta g(a)}-e^{\eta g(a^{\prime})})`$, and
these two factors need not have the same sign. Some works consider
stage-wise algorithms similar to RE($`S`$), where each inner loop uses a
fixed rollout distribution $`q`$: [Arnal et al. (2026)](#bib.bib2)
identify the inner loop convergence limit through a Lyapunov function,
and then iterate this limiting map across outer iterations, while
[Štrupl et al. (2022)](#bib.bib33) use exact weighted-likelihood
maximization, nonnegative action-value variance, and probability ratios
to prove improvement and convergence. For bandits with positive rewards,
both yield the updated rollout distribution $`q^{+}=q\odot\mu/J(q)`$,
but RE($`S`$) with a finite $`S`$ value need not obey this identity.
Adapting their arguments to RE($`S`$) would require additional control
of how incomplete fitting within a stage changes these ratios. Our
proposed analysis instead estimates improvement over a finite-step stage
in terms of the current suboptimality gap, including cases when the gap
approaches zero and when it does not.

### 3.3 Benefits of off-policyness

While the previous theorems present $`\Theta(1/t)`$ asymptotic
convergence rates regardless of the value of $`S`$, there exist other
terms in the bounds that can play a crucial role in the overall speed of
convergence. In the following, we identify settings where, perhaps
surprisingly, RE($`S`$) with a suitably large $`S`$ can achieve much
faster convergence than on-policy RE(1).

Assume $`K\geq 3`$ and consider the following assumptions:

|  |  |  |
|----|----|----|
|  | $`\displaystyle\mu_{\text{max}}=\mu(1)>\mu(2)>\mu(a)\geq\mu_{\text{min}}>0,\quad 3\leq a\leq K;\qquad\Delta=\mu(1)-\mu(2)>0.`$ |  |

Fix weights $`w(a)>0`$ for $`2\leq a\leq K`$ with
$`\sum_{a=2}^{K}w(a)=1`$, and initialize RE($`S`$) with the following
policy $`\pi_{0,0}`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi_{0,0}(1)=x>0,\quad\pi_{0,0}(a)=(1-x)w(a),\quad 2\leq a\leq K.
``` |  | (10) |

Now we consider a family of initial conditions specified by the
optimal-action probability $`x\in(0,1)`$, while fixing other factors
like $`K`$, $`\mu`$, $`w`$, and $`\eta`$ satisfying
$`0<\eta\mu_{\text{max}}<4`$. For any target accuracy
$`0<\epsilon<\Delta/2`$, we define $`T_{\epsilon}(S)`$ as the number of
gradient steps required by RE($`S`$) to achieve it:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
T_{\epsilon}(S):=\inf\{bS:b\geq 0,\ D(\pi_{b,0})\leq\epsilon\}.
``` |  | (11) |

Focusing on asymptotic $`x\rightarrow 0`$, the theorem below
demonstrates provable benefits of off-policyness.

###### Theorem 3.6.

Under the conditions stated above, we have

|     |                                                  |     |
|-----|--------------------------------------------------|-----|
|     |
       ``` math
       T_{\epsilon}(1)=\Omega\!\left(x^{-(K-1)}\right).
       ```                                               |     |

Moreover, there exists an integer $`S_{x}=\Theta(x^{-1})`$, for which

|  |  |  |
|----|----|----|
|  |
``` math
T_{\epsilon}(S_{x})=O\!\left(x^{-1}\log(1/x)\right),\quad\text{and thus}\quad\frac{T_{\epsilon}(S_{x})}{T_{\epsilon}(1)}\longrightarrow 0\quad\text{as}\quad x\rightarrow 0.
``` |  |

The implicit constants in these bounds may depend on
$`K,\mu,w,\eta,\epsilon`$, but not on $`x`$.

We provide an intuitive explanation below. On-policy policy gradient
follows the direction of steepest first-order increase in expected
reward, yet this local improvement might substantially reduce the
optimal action’s probability. Once trapped near a suboptimal vertex of
the probability simplex, the small probability of the optimal action
could suppress its gradient, making recovery very slow. This slow
transient behavior of softmax policy gradient has also been established
theoretically and observed empirically by previous works ([Mei et al.,
2020a](#bib.bib19); [Mei & Osband, 2026](#bib.bib18)). In contrast,
RE($`S`$) fixes the rollout distribution within each stage and takes
gradient steps to reduce the forward KL divergence from the
reward-weighted target to the current policy. Reward weighting assigns
the largest multiplicative weight to the optimal action, so once the KL
divergence is sufficiently small, its probability increases relative to
its value at the start of the stage. Choosing a suitable $`S`$ for
sufficiently accurate fitting therefore ensures progress in the optimal
action’s probability after each inner loop. This property holds for
every full-support policy, including policies near a suboptimal vertex.
Therefore, even if RE($`S`$) has slower progress than on-policy RE(1)
early in training, it can maintain steady progress in increasing the
probability of the optimal action, avoiding the stagnation that may
occur with RE(1) and thus achieving faster convergence eventually.

###### Proof sketch.

For RE(1), probability-ratio identities and conservation of the logit
sum show that the optimal-action probability becomes $`O(x^{K-1})`$
while most probability concentrates on action $`2`$. Controlling the
time spent in this region yields the $`\Omega(x^{-(K-1)})`$ lower bound.
For RE($`S`$), each reward-weighted target increases the log-odds of the
optimal action by at least a fixed positive amount. Its logits differ
from the stage’s initial logits only by reward-dependent shifts, and
standard optimization analysis gives an $`O(1/S)`$ KL fitting error
bound for an $`S`$-step stage, with a constant term independent of
$`x`$. A binary-KL bound shows that an error below a sufficiently small
multiple of $`x`$ preserves a fixed fraction of this log-odds gain. Thus
$`S_{x}=\Theta(x^{-1})`$ suffices to ensure that the optimal-action
probability at the end of a stage remains at least $`x`$ throughout.
Accumulating the fixed log-odds gains takes $`O(\log(1/x))`$ stages,
leading to $`O(x^{-1}\log(1/x))`$ total gradient steps. See
Appendix [C](#A3 "Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
for the complete proof. ∎

## 4 Related work

#### Reward-guided self-training.

Reward-guided self-training has been used to improve LLM reasoning and
alignment by training on model-generated outputs that are weighted or
selected based on task feedback. STaR learns from rationales that yield
correct answers, RAFT selects outputs for training by reward ranking,
and ReST-EM uses binary feedback in an expectation-maximization
procedure ([Zelikman et al., 2022](#bib.bib39); [Dong et al.,
2023](#bib.bib6); [Singh et al., 2024](#bib.bib32)). [Ghosh et al.
(2020)](#bib.bib8) derive a policy-improvement bound for reward-weighted
likelihood fitting that does not require exact optimization. In tabular
settings, reward-weighted regression and zero-baseline AsymRE — both of
which have a stage-wise structure akin to RE($`S`$) — have been shown to
converge globally from any full-support initial policy when the
surrogate objective within each stage is fitted exactly or to
convergence ([Štrupl et al., 2022](#bib.bib33); [Arnal et al.,
2026](#bib.bib2)), but their results do not cover finite-step fitting;
in comparison, our convergence results in this work cover the full range
$`S\geq 1`$. Methods with finite-step inner loops include iw-SFT, which
periodically reweights a fixed curated dataset and yields a
reward-weighted surrogate loss before clipping or smoothing operations
([Qin & Springenberg, 2025](#bib.bib26)). [Russo (2026)](#bib.bib28)
formulates finite-step fitting of success-conditioned targets, but does
not establish convergence of the resulting iterative procedure. All
these works do not establish global convergence or rates measured in
total gradient steps when each stage performs a fixed finite number
$`S`$ of updates.

#### Softmax policy gradient.

Global convergence and $`O(1/T)`$ rates have been established for exact
softmax policy gradient ([Mei et al., 2020b](#bib.bib20); [Liu et al.,
2024](#bib.bib16); [Lu et al., 2024](#bib.bib17)); our results in
Theorems [3.1](#S3.Thmtheorem1 "Theorem 3.1. ‣ 3.1 Global convergence to the optimal policy ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"), [3.3](#S3.Thmtheorem3 "Theorem 3.3 (Upper Bound). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
and [3.4](#S3.Thmtheorem4 "Theorem 3.4 (Lower Bound). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
extend these conclusions to RE($`S`$) with $`S\geq 1`$. Almost-sure
convergence has also been established for stochastic REINFORCE in
bandits and finite-horizon tabular MDPs ([Mei et al., 2023](#bib.bib21);
[Robertson et al., 2025](#bib.bib27)). Lower bounds nevertheless show
slow escape from unfavorable initialization in bandits and exponential
iteration complexity on particular discounted MDPs ([Mei et al.,
2020a](#bib.bib19); [Li et al., 2023](#bib.bib15)). [Mei et al.
(2020a)](#bib.bib19) address this issue by changing the policy
parameterization, while [Mei & Osband (2026)](#bib.bib18) use gradient
gating to accelerate escape from suboptimal corners of the probability
simplex. Our results in
Theorem [3.6](#S3.Thmtheorem6 "Theorem 3.6. ‣ 3.3 Benefits of off-policyness ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
show that an appropriate degree of off-policyness can also reduce this
delay without further algorithmic modifications.

#### Off-policy algorithms.

Global convergence guarantees for dedicated off-policy RL algorithms
allow state-distribution mismatch ([Laroche & Tachet des Combes,
2021](#bib.bib13); [Zhang et al., 2022](#bib.bib40)). They retain
current-policy action weights, directly or through importance-sampling
ratios, whereas RE($`S`$) uses the stale action weights without
importance-sampling correction. FMA-PG provides policy-improvement
guarantees for finite-step surrogate optimization within each inner
loop, while SPMA’s convergence bound includes an additive term for
errors due to approximate fitting ([Vaswani et al., 2022](#bib.bib37);
[Asad et al., 2025](#bib.bib3)). [Dai et al. (2026)](#bib.bib4) prove
global linear convergence of multi-step PPO-Clip with KL regularization
under a bound on the sum of inner step sizes. All these guarantees do
not directly yield global convergence rates for the uncorrected,
unregularized reward-weighted update rule in RE($`S`$) with a fixed
$`S`$ value; our work fills in this gap of the literature.

## 5 Limitations and future work

This work has investigated the learning dynamics of RE($`S`$)— probably
the simplest possible algorithm for fine-tuning on self-generated and
reward-weighted data — with in-depth convergence analysis for multi-arm
bandits and softmax policies. Future work may extend the theoretical
study to broader settings, such as contextual bandits, Markov decision
processes, policies with different parameterizations, or other learning
algorithms. Moreover, our analysis focuses on convergence properties and
considers the infinite-sample limit of gradient dynamics; future work
may investigate sample complexities in finite-sample settings. In terms
of empirical work, it remains open to verify which parts of our results
hold true in realistic scenarios, see if our theoretical results can
inspire better practice of reward-guided self-training, and identify
gaps between theory and practice that require further research.

## Appendix A Proofs for Section [3.1](#S3.SS1 "3.1 Global convergence to the optimal policy ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")

###### Lemma A.1.

Consider the surrogate objective function

|  |  |  |
|----|----|----|
|  |
``` math
L(\pi_{b,s};\pi_{b,0})=\sum_{a\in\mathcal{A}}\pi_{b,0}(a)\mu(a)\log\pi_{b,s}(a).
``` |  |

With $`\pi_{b,0}`$ fixed, the gradient with respect to the logit
parameter $`\theta`$, evaluated at $`\theta=\theta_{b,s}`$, satisfies

|  |  |  |
|----|----|----|
|  | $`\displaystyle g_{b,s}\coloneqq\left.\nabla_{\theta}L(\pi_{\theta};\pi_{b,0})\right|_{\theta=\theta_{b,s}}=\pi_{b,0}\odot\mu-J(\pi_{b,0})\pi_{b,s}.`$ |  |

###### Proof.

Note that

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\left.\nabla_{\theta}L(\pi_{\theta};\pi_{b,0})\right|_{\theta=\theta_{b,s}}`$ | $`\displaystyle=\sum_{a\in\mathcal{A}}\pi_{b,0}(a)\mu(a)\frac{\left.\nabla_{\theta}\pi_{\theta}(a)\right|_{\theta=\theta_{b,s}}}{\pi_{b,s}(a)}`$ |  |
|  |  | $`\displaystyle=\sum_{a\in\mathcal{A}}\pi_{b,0}(a)\mu(a)\frac{\pi_{b,s}(a)e_{a}-\pi_{b,s}(a)\pi_{b,s}}{\pi_{b,s}(a)}`$ |  |
|  |  | $`\displaystyle=\sum_{a\in\mathcal{A}}\pi_{b,0}(a)\mu(a)e_{a}-\sum_{a\in\mathcal{A}}\pi_{b,0}(a)\mu(a)\pi_{b,s}`$ |  |
|  |  | $`\displaystyle=\pi_{b,0}\odot\mu-J(\pi_{b,0})\pi_{b,s}=g_{b,s}.`$ |  |

∎

###### Lemma A.2.

$`\nabla_{\theta}L(\pi_{\theta};\pi_{b,0})`$ has a Lipschitz constant no
greater than $`J(\pi_{b,0})/2`$.

###### Proof.

Define

|     |                                                |     |
|-----|------------------------------------------------|-----|
|     |
       ``` math
       H(\pi)=\operatorname{diag}(\pi)-\pi\pi^{\top}.
       ```                                             |     |

This matrix is positive semidefinite. By Gershgorin’s theorem, its
eigenvalues are bounded above by $`\max_{a}2\pi(a)(1-\pi(a))\leq 1/2`$,
and hence

|     |                             |     |      |
|-----|-----------------------------|-----|------|
|     |
       ``` math
       0\preceq H(\pi)\preceq I/2.
       ```                          |     | (12) |

We also have

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\nabla_{\theta}^{2}L(\pi_{\theta};\pi_{b,0})=-J(\pi_{b,0})H(\pi_{\theta}).
``` |  | (13) |

Thus $`\nabla_{\theta}L(\pi_{\theta};\pi_{b,0})`$ has a Lipschitz
constant no greater than $`J(\pi_{b,0})/2`$. ∎

###### Lemma A.3.

Suppose $`\eta\mu_{\text{max}}<4`$. Consider how the logit of each
action evolves under this assumption. We have

|     |                                     |     |
|-----|-------------------------------------|-----|
|     |
       ``` math
       \|g_{b,s}\|_{2}\leq\|g_{b,0}\|_{2}.
       ```                                  |     |

###### Proof.

Fix $`b`$. Note that the surrogate objective is concave and can be
written as

|  |  |  |
|----|----|----|
|  |
``` math
L(\pi_{\theta};\pi_{b,0})=\sum_{a\in\mathcal{A}}\pi_{b,0}(a)\mu(a)\theta(a)-J(\pi_{b,0})\log\sum_{a\in\mathcal{A}}e^{\theta(a)}.
``` |  |

The Hessian bound from
Eq. ([12](#A1.E12 "In Proof. ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
and
Eq. ([13](#A1.E13 "In Proof. ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
shows that $`\nabla L(\pi_{\theta};\pi_{b,0})`$ has a Lipschitz constant
of at most $`J(\pi_{b,0})/2`$. For $`0\leq s<S`$, by the standard
co-coercivity inequality ([Nesterov, 2013](#bib.bib22)),

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\left\langle\nabla_{\theta}L(\pi_{b,s};\pi_{b,0})-\nabla_{\theta}L(\pi_{b,s+1};\pi_{b,0}),\theta_{b,s+1}-\theta_{b,s}\right\rangle`$ |  |
|  |  | $`\displaystyle\geq\frac{2}{J(\pi_{b,0})}\left\|\nabla_{\theta}L(\pi_{b,s};\pi_{b,0})-\nabla_{\theta}L(\pi_{b,s+1};\pi_{b,0})\right\|_{2}^{2}.`$ |  |

Substituting $`\nabla_{\theta}L(\pi_{b,s};\pi_{b,0})=g_{b,s}`$ and
$`\theta_{b,s+1}-\theta_{b,s}=\eta g_{b,s}`$ gives

|  |  |  |
|----|----|----|
|  |
``` math
\eta\langle g_{b,s}-g_{b,s+1},g_{b,s}\rangle\geq\frac{2}{J(\pi_{b,0})}\|g_{b,s+1}-g_{b,s}\|_{2}^{2}.
``` |  |

Therefore, since $`\eta J(\pi_{b,0})<4`$,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\|g_{b,s+1}\|_{2}^{2}`$ | $`\displaystyle=\|g_{b,s}\|_{2}^{2}+2\langle g_{b,s+1}-g_{b,s},g_{b,s}\rangle+\|g_{b,s+1}-g_{b,s}\|_{2}^{2}`$ |  |
|  |  | $`\displaystyle\leq\|g_{b,s}\|_{2}^{2}-\left(\frac{4}{\eta J(\pi_{b,0})}-1\right)\|g_{b,s+1}-g_{b,s}\|_{2}^{2}`$ |  |
|  |  | $`\displaystyle\leq\|g_{b,s}\|_{2}^{2}.`$ |  |

It follows that

|     |                                     |     |
|-----|-------------------------------------|-----|
|     |
       ``` math
       \|g_{b,s}\|_{2}\leq\|g_{b,0}\|_{2},
       ```                                  |     |

which completes our proof. ∎

#### Proof of Theorem  [3.1](#S3.Thmtheorem1 "Theorem 3.1. ‣ 3.1 Global convergence to the optimal policy ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness").

Using lemma
[A.2](#A1.Thmtheorem2 "Lemma A.2. ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"),
we have

|  |  |  |  |
|----|----|----|----|
|  |
``` math
L(\pi_{b,s+1};\pi_{b,0})-L(\pi_{b,s};\pi_{b,0})\geq\eta\left(1-\frac{\eta J(\pi_{b,0})}{4}\right)\|g_{b,s}\|_{2}^{2}.
``` |  | (14) |

Action $`1`$ is uniquely optimal and rewards are nonnegative, so
$`\mu_{\text{max}}>0`$. Every policy coordinate remains strictly
positive after finitely many updates, and hence
$`J(\pi_{b,0})\geq\mu_{\text{max}}\pi_{b,0}(1)>0`$. The right side is
nonnegative because $`0<J(\pi_{b,0})\leq\mu_{\text{max}}`$ and
$`\eta\mu_{\text{max}}<4`$. For $`0\leq s\leq S`$, using the inequality
$`\log x\leq x-1`$ we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle L(\pi_{b,s};\pi_{b,0})-L(\pi_{b,0};\pi_{b,0})`$ | $`\displaystyle=\sum_{a\in\mathcal{A}}\pi_{b,0}(a)\mu(a)\log\frac{\pi_{b,s}(a)}{\pi_{b,0}(a)}`$ |  | (15) |
|  |  | $`\displaystyle\leq\sum_{a\in\mathcal{A}}\pi_{b,0}(a)\mu(a)\left(\frac{\pi_{b,s}(a)}{\pi_{b,0}(a)}-1\right)`$ |  |  |
|  |  | $`\displaystyle=J(\pi_{b,s})-J(\pi_{b,0}).`$ |  |  |

Hence $`J(\pi_{b,s})\geq J(\pi_{b,0})`$. Taking $`s=S`$ gives
$`J(\pi_{b+1,0})\geq J(\pi_{b,0})`$. Since
$`J(\pi_{b,0})\leq\mu_{\text{max}}`$, there exists
$`J_{\infty}\leq\mu_{\text{max}}`$ such that
$`J(\pi_{b,0})\to J_{\infty}`$. Summing
Eq. ([14](#A1.E14 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
over the updates in the inner loop and using
Eq. ([15](#A1.E15 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
gives

|  |  |  |  |
|----|----|----|----|
|  |
``` math
J(\pi_{b+1,0})-J(\pi_{b,0})\geq\eta\left(1-\frac{\eta\mu_{\text{max}}}{4}\right)\sum_{s=0}^{S-1}\|g_{b,s}\|_{2}^{2}.
``` |  | (16) |

Summing over $`b`$ then we have

|  |  |  |
|----|----|----|
|  |
``` math
\sum_{b=0}^{\infty}\sum_{s=0}^{S-1}\|g_{b,s}\|_{2}^{2}\leq\frac{\mu_{\text{max}}-J_{0}}{\eta(1-\eta\mu_{\text{max}}/4)}<\infty.
``` |  |

In particular, $`g_{b,0}\to 0`$. We have

|     |                                               |     |
|-----|-----------------------------------------------|-----|
|     |
       ``` math
       g_{b,0}(a)=\pi_{b,0}(a)(\mu(a)-J(\pi_{b,0})).
       ```                                            |     |

Thus, if $`\mu(a)\neq J_{\infty}`$, then $`\pi_{b,0}(a)\to 0`$. Define

|     |                                                    |     |
|-----|----------------------------------------------------|-----|
|     |
       ``` math
       \mathcal{M}=\{a\in\mathcal{A}:\mu(a)=J_{\infty}\}.
       ```                                                 |     |

Since the probabilities sum to $`1`$, we have
$`\mathcal{M}\neq\varnothing`$ and

|     |                                                      |     |      |
|-----|------------------------------------------------------|-----|------|
|     |
       ``` math
       \sum_{a\in\mathcal{M}}\pi_{b,0}(a)\longrightarrow 1.
       ```                                                   |     | (17) |

We now prove $`J_{\infty}=\mu(1)`$. Suppose for contradiction that
$`J_{\infty}<\mu(1)`$, and define

|  |  |  |
|----|----|----|
|  |
``` math
\mathcal{M}_{+}=\{a:\mu(a)>J_{\infty}\},\qquad\mathcal{M}_{-}=\{a:\mu(a)<J_{\infty}\}.
``` |  |

Then $`1\in\mathcal{M}_{+}`$. Since $`J(\pi_{b,0})`$ increases
monotonically to $`J_{\infty}`$, we have $`J(\pi_{b,0})\leq J_{\infty}`$
throughout. By lemma
[A.3](#A1.Thmtheorem3 "Lemma A.3. ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"),
we have

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\max_{0\leq s\leq S}\|\theta_{b,s}-\theta_{b,0}\|_{2}\leq\eta S\|g_{b,0}\|_{2}\longrightarrow 0.
``` |  | (18) |

By the definition of $`\pi_{\theta}`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{\pi_{b,s}(a)}{\pi_{b,0}(a)}=\frac{\exp(\theta_{b,s}(a)-\theta_{b,0}(a))}{\sum_{c\in\mathcal{A}}\pi_{b,0}(c)\exp(\theta_{b,s}(c)-\theta_{b,0}(c))}\longrightarrow 1.
``` |  | (19) |

Here the convergence is uniform over the finitely many actions $`a`$ and
steps $`0\leq s\leq S`$. Thus

|  |  |  |
|----|----|----|
|  |
``` math
\frac{g_{b,s}(a)}{\pi_{b,0}(a)}=\mu(a)-J(\pi_{b,0})\frac{\pi_{b,s}(a)}{\pi_{b,0}(a)}\longrightarrow\mu(a)-J_{\infty}.
``` |  |

Since the action set is finite, there exists $`B_{0}`$ such that,
whenever $`b\geq B_{0}`$, the logit of each action in
$`\mathcal{M}_{+}`$ strictly increases at every update of the inner
loop, while the logit of each action in $`\mathcal{M}_{-}`$ strictly
decreases. More precisely,

|  |  |  |  |  |  |  |
|----|----|----|----|----|----|----|
|  | $`\displaystyle\theta_{b+1,0}(a)-\theta_{b,0}(a)`$ | $`\displaystyle\geq\frac{\eta S}{2}(\mu(a)-J_{\infty})\pi_{b,0}(a),`$ |  | $`\displaystyle a\in\mathcal{M}_{+},`$ |  | (20) |
|  | $`\displaystyle\theta_{b+1,0}(a)-\theta_{b,0}(a)`$ | $`\displaystyle\leq-\frac{\eta S}{2}(J_{\infty}-\mu(a))\pi_{b,0}(a),`$ |  | $`\displaystyle a\in\mathcal{M}_{-}.`$ |  |  |

The logit of action $`1`$ is nondecreasing from this point onward, so
$`\theta_{b,0}(1)`$ is bounded below. At the same time,
Eq. ([17](#A1.E17 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
and $`\pi_{b,0}(1)\to 0`$ give

|  |  |  |
|----|----|----|
|  |
``` math
\sum_{a\in\mathcal{M}}\exp(\theta_{b,0}(a)-\theta_{b,0}(1))=\frac{\sum_{a\in\mathcal{M}}\pi_{b,0}(a)}{\pi_{b,0}(1)}\longrightarrow+\infty.
``` |  |

Hence

|     |                                                              |     |      |
|-----|--------------------------------------------------------------|-----|------|
|     |
       ``` math
       \max_{a\in\mathcal{M}}\theta_{b,0}(a)\longrightarrow+\infty.
       ```                                                           |     | (21) |

We now bound the gradient norm in terms of $`J_{\infty}-J(\pi_{b,0})`$.
For notational simplicity, write

|     |                                                  |     |
|-----|--------------------------------------------------|-----|
|     | $`\displaystyle h_{b}\coloneqq\|g_{b,0}\|_{2}.`$ |     |

After the rollout policy is refreshed for the next stage, its initial
gradient satisfies

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle g_{b+1,0}(a)`$ | $`\displaystyle=\pi_{b+1,0}(a)(\mu(a)-J(\pi_{b+1,0}))`$ |  |
|  |  | $`\displaystyle=\frac{\pi_{b+1,0}(a)}{\pi_{b,0}(a)}g_{b,0}(a)-(J(\pi_{b+1,0})-J(\pi_{b,0}))\pi_{b+1,0}(a).`$ |  |

The gradient norm does not increase within the inner loop, so
$`\|\theta_{b+1,0}-\theta_{b,0}\|_{2}\leq\eta Sh_{b}`$. The difference
between the largest and smallest coordinates of a vector is at most
$`\sqrt{2}`$ times its Euclidean norm. The ratio formula
Eq. ([19](#A1.E19 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
for $`\pi_{\theta}`$ therefore gives

|     |                                                                   |     |
|-----|-------------------------------------------------------------------|-----|
|     |
       ``` math
       \frac{\pi_{b+1,0}(a)}{\pi_{b,0}(a)}\geq e^{-\sqrt{2}\eta Sh_{b}}.
       ```                                                                |     |

Combining the reverse triangle inequality with
$`\|\pi_{b+1,0}\|_{2}\leq 1`$ and $`J(\pi_{b+1,0})-J(\pi_{b,0})\geq 0`$
gives

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle h_{b+1}`$ | $`\displaystyle\geq\left(\sum_{a\in\mathcal{A}}\left[\frac{\pi_{b+1,0}(a)}{\pi_{b,0}(a)}g_{b,0}(a)\right]^{2}\right)^{1/2}-(J(\pi_{b+1,0})-J(\pi_{b,0}))\|\pi_{b+1,0}\|_{2}`$ |  |
|  |  | $`\displaystyle\geq e^{-\sqrt{2}\eta Sh_{b}}\left(\sum_{a\in\mathcal{A}}g_{b,0}(a)^{2}\right)^{1/2}-(J(\pi_{b+1,0})-J(\pi_{b,0}))`$ |  |
|  |  | $`\displaystyle=e^{-\sqrt{2}\eta Sh_{b}}h_{b}-(J(\pi_{b+1,0})-J(\pi_{b,0})).`$ |  |

Using $`1-e^{-x}\leq x`$, we obtain

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle h_{b}-h_{b+1}`$ | $`\displaystyle\leq(1-e^{-\sqrt{2}\eta Sh_{b}})h_{b}+(J(\pi_{b+1,0})-J(\pi_{b,0}))`$ |  |
|  |  | $`\displaystyle\leq\sqrt{2}\eta Sh_{b}^{2}+(J(\pi_{b+1,0})-J(\pi_{b,0})).`$ |  |

The lower bound
Eq. ([16](#A1.E16 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
on the increase in the objective gives

|  |  |  |
|----|----|----|
|  |
``` math
\eta\left(1-\frac{\eta\mu_{\text{max}}}{4}\right)h_{b}^{2}\leq J(\pi_{b+1,0})-J(\pi_{b,0}).
``` |  |

Then
$`h_{b}-h_{b+1}\leq(1+\sqrt{2}S/(1-\eta\mu_{\text{max}}/4))(J(\pi_{b+1,0})-J(\pi_{b,0}))`$.
Summing from round $`b`$ to round $`B`$ gives

|  |  |  |
|----|----|----|
|  |
``` math
h_{b}-h_{B+1}\leq(1+\sqrt{2}S/(1-\eta\mu_{\text{max}}/4))(J(\pi_{B+1,0})-J(\pi_{b,0})).
``` |  |

Since $`h_{B+1}\to 0`$ and $`J(\pi_{B+1,0})\to J_{\infty}`$, letting
$`B\to\infty`$ yields

|  |  |  |
|----|----|----|
|  |
``` math
\|g_{b,s}\|_{2}\leq\|g_{b,0}\|_{2}\leq(1+\sqrt{2}S/(1-\eta\mu_{\text{max}}/4))(J_{\infty}-J(\pi_{b,0})),\qquad 0\leq s<S.
``` |  |

If $`\sum_{b}(J_{\infty}-J(\pi_{b,0}))<\infty`$, then

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sum_{b=0}^{\infty}\|\theta_{b+1,0}-\theta_{b,0}\|_{2}`$ | $`\displaystyle\leq\eta\sum_{b=0}^{\infty}\sum_{s=0}^{S-1}\|g_{b,s}\|_{2}`$ |  |
|  |  | $`\displaystyle\leq\eta S(1+\sqrt{2}S/(1-\eta\mu_{\text{max}}/4))\sum_{b=0}^{\infty}(J_{\infty}-J(\pi_{b,0}))<\infty.`$ |  |

Every logit coordinate would then converge to a finite value,
contradicting
Eq. ([21](#A1.E21 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")).
Therefore

|     |                                                       |     |      |
|-----|-------------------------------------------------------|-----|------|
|     |
       ``` math
       \sum_{b=0}^{\infty}(J_{\infty}-J(\pi_{b,0}))=+\infty.
       ```                                                    |     | (22) |

We now use the increasing logits of actions with higher rewards and the
decreasing logits of actions with lower rewards to derive a
contradiction. Note that we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle 0\leq J_{\infty}-J(\pi_{b,0})`$ | $`\displaystyle=\sum_{a\in\mathcal{M}_{-}}(J_{\infty}-\mu(a))\pi_{b,0}(a)-\sum_{a\in\mathcal{M}_{+}}(\mu(a)-J_{\infty})\pi_{b,0}(a)`$ |  |
|  |  | $`\displaystyle\leq\sum_{a\in\mathcal{M}_{-}}(J_{\infty}-\mu(a))\pi_{b,0}(a)`$ |  |

Together with
Eq. ([22](#A1.E22 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")),
this shows that $`\mathcal{M}_{-}\neq\varnothing`$ and that there exists
$`\ell\in\mathcal{M}_{-}`$ such that

|     |                                             |     |
|-----|---------------------------------------------|-----|
|     |
       ``` math
       \sum_{b=0}^{\infty}\pi_{b,0}(\ell)=+\infty.
       ```                                          |     |

Summing the inequality in
Eq. ([20](#A1.E20 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
for action $`\ell`$ gives $`\theta_{b,0}(\ell)\to-\infty`$. Since
$`\theta_{b,0}(1)`$ is bounded below,

|  |  |  |
|----|----|----|
|  |
``` math
\frac{\pi_{b,0}(1)}{\pi_{b,0}(\ell)}=\exp\bigl(\theta_{b,0}(1)-\theta_{b,0}(\ell)\bigr)\longrightarrow+\infty.
``` |  |

Thus, for all sufficiently large $`b`$, we have
$`\pi_{b,0}(1)\geq\pi_{b,0}(\ell)`$, and hence

|     |                                          |     |
|-----|------------------------------------------|-----|
|     |
       ``` math
       \sum_{b=0}^{\infty}\pi_{b,0}(1)=+\infty.
       ```                                       |     |

Applying
Eq. ([20](#A1.E20 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
again gives $`\theta_{b,0}(1)\to+\infty`$. For every
$`a\in\mathcal{M}_{-}`$, $`\theta_{b,0}(a)`$ is nonincreasing from
$`B_{0}`$ onward and is therefore bounded above. Hence

|  |  |  |
|----|----|----|
|  |
``` math
\frac{\pi_{b,0}(a)}{\pi_{b,0}(1)}=\exp\bigl(\theta_{b,0}(a)-\theta_{b,0}(1)\bigr)\longrightarrow 0,\qquad a\in\mathcal{M}_{-}.
``` |  |

Consequently,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle J(\pi_{b,0})-J_{\infty}`$ | $`\displaystyle=\sum_{a\in\mathcal{M}_{+}}(\mu(a)-J_{\infty})\pi_{b,0}(a)-\sum_{a\in\mathcal{M}_{-}}(J_{\infty}-\mu(a))\pi_{b,0}(a)`$ |  |
|  |  | $`\displaystyle\geq\pi_{b,0}(1)\left[\mu(1)-J_{\infty}-\sum_{a\in\mathcal{M}_{-}}(J_{\infty}-\mu(a))\frac{\pi_{b,0}(a)}{\pi_{b,0}(1)}\right]>0`$ |  |

This holds for all sufficiently large $`b`$, contradicting
$`J(\pi_{b,0})\leq J_{\infty}`$. Hence $`J_{\infty}=\mu(1)`$. Since
action $`1`$ is uniquely optimal, $`\mathcal{M}=\{1\}`$, and
Eq. ([17](#A1.E17 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
gives

|  |  |  |
|----|----|----|
|  |
``` math
\pi_{b,0}\longrightarrow e_{1},\qquad J(\pi_{b,0})\longrightarrow\mu(1).
``` |  |

Since $`J(\pi_{b,s})\geq J(\pi_{b,0})`$, we have

|  |  |  |
|----|----|----|
|  |
``` math
0\leq\mu_{\text{max}}-J(\pi_{b,s})\leq\mu_{\text{max}}-J(\pi_{b,0})\rightarrow 0.
``` |  |

And we have the lower bound

|     |                                                          |     |
|-----|----------------------------------------------------------|-----|
|     |
       ``` math
       \mu_{\text{max}}-J(\pi_{b,s})\geq\Delta(1-\pi_{b,s}(1)).
       ```                                                       |     |

Therefore

|  |  |  |
|----|----|----|
|  |
``` math
\max_{0\leq s\leq S}\|\pi_{b,s}-e_{1}\|_{1}\leq\frac{2(\mu_{\text{max}}-J(\pi_{b,0}))}{\Delta}\rightarrow 0.
``` |  |

This completes the proof.

p_{k}(1)\leq\frac{q(1)e^{r_{k}}}{1-q(1)+q(1)e^{r_{k}}},\qquad p_{k}(1)-q(1)\leq q(1)(1-q(1))(e^{r_{k}}-1).

#### Upper bound.

We have

|  |  |  |
|----|----|----|
|  |
``` math
\nabla_{\theta}J(\pi_{\theta})(a)=\pi_{\theta}(a)(\mu(a)-J(\pi_{\theta})),\qquad\|\nabla_{\theta}J(\pi_{\theta})\|_{2}\leq\|\nabla_{\theta}J(\pi_{\theta})\|_{1}\leq 2D(\pi_{\theta}).
``` |  |

Equations ([14](#A1.E14 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
and ([15](#A1.E15 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
imply $`D(p_{k})\leq d`$, hence
$`\|\nabla_{\theta}J(p_{k})\|_{2}\leq 2d`$. Differentiating once more
gives

|  |  |  |
|----|----|----|
|  |
``` math
\nabla_{\theta}^{2}J(\pi_{\theta})=\diag(\nabla_{\theta}J(\pi_{\theta}))-\nabla_{\theta}J(\pi_{\theta})\pi_{\theta}^{\top}-\pi_{\theta}\nabla_{\theta}J(\pi_{\theta})^{\top}.
``` |  |

Because $`|\mu(a)-J(\pi_{\theta})|\leq\mu_{\text{max}}`$, we have
$`\|\nabla_{\theta}J(\pi_{\theta})\|_{2}\leq\|\nabla_{\theta}J(\pi_{\theta})\|_{1}\leq\mu_{\text{max}}`$,
$`\|\diag(\nabla_{\theta}J(\pi_{\theta}))\|_{2}\leq\mu_{\text{max}}`$,
and $`\|\pi_{\theta}\|_{2}\leq 1`$. Therefore
$`\|\nabla_{\theta}^{2}J(\pi_{\theta})\|_{2}\leq 3\mu_{\text{max}}`$.
From Taylor’s theorem and
Eq. ([23](#A2.E23 "In Constants. ‣ B.1 Proof of Lemma ‣ Appendix B Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle J(p_{k+1})-J(p_{k})`$ | $`\displaystyle\leq\eta\nabla_{\theta}J(p_{k})^{\top}g_{k}+\frac{3\mu_{\text{max}}\eta^{2}}{2}\|g_{k}\|_{2}^{2}`$ |  |
|  |  | $`\displaystyle\leq 4\eta d^{2}+6\mu_{\text{max}}\eta^{2}d^{2}=(4+6\eta\mu_{\text{max}})\eta d^{2}.`$ |  |

Summing over $`k<s`$ and using $`0\leq J(p_{s})-J(\pi_{b,0})\leq d`$
proves the upper bound in
Eq. ([2](#S3.E2 "In Lemma 3.2 (Progress and suboptimality gaps within an inner loop). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")).
The middle inequality is
Eq. ([15](#A1.E15 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")).

#### A lower bound on the suboptimality gap.

We prove a bound for any positive policy $`p`$ satisfying
$`L(p;q)\geq L(q;q)`$, and then apply it to $`p_{s}`$. The gap and
reward bounds imply

|  |  |  |
|----|----|----|
|  |
``` math
\Delta\sum_{a>1}q(a)\leq d\leq\mu_{\text{max}}\sum_{a>1}q(a),\qquad H_{q}:=\sum_{a>1}q(a)\mu(a)\geq\mu_{\text{min}}\sum_{a>1}q(a)\geq\frac{\mu_{\text{min}}d}{\mu_{\text{max}}}>0.
``` |  |

The optimal action contributes at most

|  |  |  |
|----|----|----|
|  |
``` math
\mu_{\text{max}}q(1)\log\frac{p(1)}{q(1)}\leq\mu_{\text{max}}(p(1)-q(1))\leq\mu_{\text{max}}(1-q(1))\leq\frac{\mu_{\text{max}}d}{\Delta}.
``` |  |

Jensen’s inequality for the suboptimal terms gives

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sum_{a>1}q(a)\mu(a)\log\frac{p(a)}{q(a)}`$ | $`\displaystyle=H_{q}\sum_{a>1}\frac{q(a)\mu(a)}{H_{q}}\log\frac{p(a)}{q(a)}`$ |  |
|  |  | $`\displaystyle\leq H_{q}\log\left(\sum_{a>1}\frac{q(a)\mu(a)}{H_{q}}\frac{p(a)}{q(a)}\right)=H_{q}\log\frac{\sum_{a>1}\mu(a)p(a)}{H_{q}}.`$ |  |

Since $`D(p)\geq\Delta\sum_{a>1}p(a)`$, we have

|  |  |  |
|----|----|----|
|  |
``` math
\frac{\sum_{a>1}\mu(a)p(a)}{H_{q}}\leq\frac{\mu_{\text{max}}D(p)}{\Delta H_{q}}\leq\frac{\mu_{\text{max}}^{2}}{\mu_{\text{min}}\Delta}\frac{D(p)}{d}.
``` |  |

Consequently,

|  |  |  |
|----|----|----|
|  |
``` math
0\leq L(p;q)-L(q;q)\leq\frac{\mu_{\text{max}}d}{\Delta}+H_{q}\log\!\left(\frac{\mu_{\text{max}}^{2}}{\mu_{\text{min}}\Delta}\frac{D(p)}{d}\right).
``` |  |

Rearranging and using $`H_{q}\geq\mu_{\text{min}}d/\mu_{\text{max}}`$
gives

|  |  |  |
|----|----|----|
|  |
``` math
\log\!\left(\frac{\mu_{\text{max}}^{2}}{\mu_{\text{min}}\Delta}\frac{D(p)}{d}\right)\geq-\frac{\mu_{\text{max}}d}{\Delta H_{q}}\geq-\frac{\mu_{\text{max}}^{2}}{\mu_{\text{min}}\Delta},\qquad D(p)\geq\rho d.
``` |  |

Taking $`p=p_{s}`$ and combining with $`D(p_{s})\leq d`$ proves
Eq. ([3](#S3.E3 "In Lemma 3.2 (Progress and suboptimality gaps within an inner loop). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
in the lemma.

### B.2 Proofs of Theorems [3.3](#S3.Thmtheorem3 "Theorem 3.3 (Upper Bound). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness") and [3.4](#S3.Thmtheorem4 "Theorem 3.4 (Lower Bound). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")

###### Lemma B.1.

Under the assumptions of
Lemma [3.2](#S3.Thmtheorem2 "Lemma 3.2 (Progress and suboptimality gaps within an inner loop). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"),
$`p_{\min}:=\inf_{b\geq 0}\pi_{b,0}(1)>0`$. Set
$`\lambda_{*}=\lambda(p_{\min})`$. For every $`b\geq 0`$ and
$`0\leq s\leq S`$,

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{1}{D(\pi_{b,s})}-\frac{1}{d_{b}}`$ | $`\displaystyle\geq\lambda_{*}\min\left\{\eta s,\frac{1}{d_{b}}\right\},`$ |  | (26) |
|  | $`\displaystyle\frac{1}{D(\pi_{b,s})}-\frac{1}{d_{b}}`$ | $`\displaystyle\leq\min\left\{\frac{A}{\rho}\eta s,\frac{1-\rho}{\rho}\frac{1}{d_{b}}\right\}.`$ |  | (27) |

###### Proof.

Using
Lemma [3.2](#S3.Thmtheorem2 "Lemma 3.2 (Progress and suboptimality gaps within an inner loop). ‣ 3.2 Two-sided bounds for convergence rates ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
and $`D(\pi_{b,s})\leq d_{b}`$ give

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\frac{1}{D(\pi_{b,s})}-\frac{1}{d_{b}}`$ | $`\displaystyle=\frac{J(\pi_{b,s})-J(\pi_{b,0})}{D(\pi_{b,s})d_{b}}\geq\lambda_{*}\min\left\{\eta s,\frac{1}{d_{b}}\right\}.`$ |  |

For the upper bound, let $`\xi=(d_{b}-D(\pi_{b,s}))/d_{b}`$. Then

|  |  |  |
|----|----|----|
|  |
``` math
0\leq\xi\leq A\eta sd_{b},\qquad\xi\leq 1-\rho,\qquad\frac{1}{D(\pi_{b,s})}-\frac{1}{d_{b}}=\frac{\xi}{(1-\xi)d_{b}}.
``` |  |

Bounding the last expression with these two inequalities proves
Eq. ([27](#A2.E27 "In Lemma B.1. ‣ B.2 Proofs of Theorems and ‣ Appendix B Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")).
At $`s=0`$, both sides are zero. ∎

For $`x,y>0`$, define the comparison sequence

|  |  |  |  |
|----|----|----|----|
|  |
``` math
a^{x,y}_{0,0}=d_{0}^{-1},\qquad a^{x,y}_{b,s}=a^{x,y}_{b,0}+\min\{x\eta s,ya^{x,y}_{b,0}\},\qquad a^{x,y}_{b+1,0}=a^{x,y}_{b,S}.
``` |  | (28) |

Set

|  |  |  |  |
|----|----|----|----|
|  |
``` math
b_{x,y}=\begin{cases}0,&\eta Sd_{0}\leq y/x,\\[2.0pt]
\displaystyle\left\lceil\frac{\log(x\eta Sd_{0}/y)}{\log(1+y)}\right\rceil,&\eta Sd_{0}>y/x.\end{cases}
``` |  | (29) |

Define the following function:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{C}_{x,y}(t,S,d_{0})=\begin{cases}\displaystyle d_{0}^{-1}+x\eta t,&\eta Sd_{0}\leq y/x,\\[3.0pt]
\displaystyle\frac{(1+y)^{b}}{d_{0}}+\min\left\{x\eta s,\frac{y(1+y)^{b}}{d_{0}}\right\},&\eta Sd_{0}>y/x,\ b<b_{x,y},\\[3.0pt]
\displaystyle\frac{(1+y)^{b_{x,y}}}{d_{0}}+x\eta(t-Sb_{x,y}),&\eta Sd_{0}>y/x,\ b\geq b_{x,y}.\end{cases}
``` |  | (30) |

Then we have:

###### Lemma B.2.

The map $`a\mapsto a+\min\{x\eta s,ya\}`$ is increasing for every
$`s\geq 0`$. For $`t=bS+s`$ with $`0\leq s<S`$, we have
$`a^{x,y}_{b,s}=\mathcal{C}_{x,y}(t,S,d_{0})`$.

###### Proof.

The map is increasing because $`\min\{x\eta s,ya\}`$ is nondecreasing in
$`a`$. To compute the sequence, first consider the complete-stage
recurrence

|  |  |  |
|----|----|----|
|  |
``` math
a^{x,y}_{b+1,0}=\begin{cases}(1+y)a^{x,y}_{b,0},&a^{x,y}_{b,0}<x\eta S/y,\\
a^{x,y}_{b,0}+x\eta S,&a^{x,y}_{b,0}\geq x\eta S/y.\end{cases}
``` |  |

Since the sequence is increasing, once it reaches $`x\eta S/y`$, every
subsequent stage adds the same amount $`x\eta S`$.

If $`\eta Sd_{0}\leq y/x`$, then
$`a^{x,y}_{0,0}=d_{0}^{-1}\geq x\eta S/y`$. The additive update
therefore applies from the first stage, giving
$`a^{x,y}_{b,0}=d_{0}^{-1}+bx\eta S`$.

If $`\eta Sd_{0}>y/x`$, each complete stage initially multiplies the
current value by $`1+y`$. The first stage index at which the threshold
is reached is the smallest integer $`b`$ satisfying

|     |                                               |     |
|-----|-----------------------------------------------|-----|
|     |
       ``` math
       \frac{(1+y)^{b}}{d_{0}}\geq\frac{x\eta S}{y},
       ```                                            |     |

which is exactly $`b_{x,y}`$ in
Eq. ([29](#A2.E29 "In B.2 Proofs of Theorems and ‣ Appendix B Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")).
Consequently,

|  |  |  |
|----|----|----|
|  |
``` math
a^{x,y}_{b,0}=\begin{cases}\displaystyle\frac{(1+y)^{b}}{d_{0}},&0\leq b<b_{x,y},\\[4.0pt]
\displaystyle\frac{(1+y)^{b_{x,y}}}{d_{0}}+x\eta S(b-b_{x,y}),&b\geq b_{x,y}.\end{cases}
``` |  |

Finally, the definition of $`a^{x,y}_{b,s}`$ adds
$`\min\{x\eta s,ya^{x,y}_{b,0}\}`$ to the stage-start value. Before the
threshold is reached, this minimum remains as written. Once
$`a^{x,y}_{b,0}\geq x\eta S/y`$, it equals $`x\eta s`$ because $`s<S`$.
Substituting the stage-start values above and using $`t=bS+s`$ gives the
three branches of
Eq. ([30](#A2.E30 "In B.2 Proofs of Theorems and ‣ Appendix B Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")).
∎

### B.3 Explicit constants for the convergence rates

###### Lemma B.3.

If $`0<\eta\mu_{\text{max}}\leq 2`$ and $`\pi_{0,0}(1)\geq\pi_{0,0}(a)`$
for every $`a>1`$, then $`\pi_{b,s}(1)\geq\pi_{b,s}(a)`$ for every
$`b\geq 0`$ and $`0\leq s\leq S`$. Consequently, $`p_{\min}\geq 1/K`$.

###### Proof.

Assume inductively that $`q=\pi_{b,0}`$ satisfies $`q(1)\geq q(a)`$ for
all $`a>1`$. Fix $`a>1`$ and write
$`\xi_{s}=\theta_{b,s}(1)-\theta_{b,s}(a)`$. Then
$`\xi_{0}=\log(q(1)/q(a))\geq 0`$, and
$`q(1)\mu_{\text{max}}-q(a)\mu(a)>0`$ because action $`1`$ is uniquely
optimal and $`q(a)>0`$. Whenever $`\xi_{s}\geq 0`$,

|  |  |  |
|----|----|----|
|  |
``` math
0\leq\pi_{b,s}(1)-\pi_{b,s}(a)=\frac{e^{\theta_{b,s}(a)}(e^{\xi_{s}}-1)}{\sum_{j\in\mathcal{A}}e^{\theta_{b,s}(j)}}\leq\frac{e^{\xi_{s}}-1}{e^{\xi_{s}}+1}=\tanh(\xi_{s}/2)\leq\frac{\xi_{s}}{2}.
``` |  |

The update therefore gives

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\xi_{s+1}`$ | $`\displaystyle=\xi_{s}+\eta\big[q(1)\mu_{\text{max}}-q(a)\mu(a)-J(q)(\pi_{b,s}(1)-\pi_{b,s}(a))\big]`$ |  |
|  |  | $`\displaystyle\geq\left(1-\frac{\eta J(q)}{2}\right)\xi_{s}+\eta(q(1)\mu_{\text{max}}-q(a)\mu(a))\geq 0.`$ |  |

The last inequality uses $`\eta J(q)\leq\eta\mu_{\text{max}}\leq 2`$.
Induction over $`s`$ preserves the ordering within the stage. Taking
$`s=S`$ transfers it to the next stage, so induction over $`b`$ proves
the ordering at every iterate. In particular, $`\pi_{b,0}(1)\geq 1/K`$
for every $`b`$. ∎

### C.1 Part 1 of Theorem [3.6](#S3.Thmtheorem6 "Theorem 3.6. ‣ 3.3 Benefits of off-policyness ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"): lower bound for on-policy RE(1)

For $`S=1`$, each stage consists of one gradient step, so $`\pi_{b,0}`$
is reached after exactly $`b`$ steps. We will show that reaching the
target accuracy requires passing through a policy that assigns
probability $`1-O(x^{K-1})`$ to action $`2`$. The following estimate
then bounds how quickly the remaining probability can grow.

###### Lemma C.1.

Fix an action $`j`$ and let $`m_{b}(j)=1-\pi_{b,0}(j)`$. Then we have

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{1}{m_{b+1}(j)}\geq\frac{1}{m_{b}(j)}-2\eta\mu_{\text{max}}.
``` |  | (33) |

Therefore, for integers $`b,n\geq 0`$ such that
$`2\eta\mu_{\text{max}}nm_{b}(j)<1`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi_{b+n,0}(a)\leq m_{b+n}(j)\leq\frac{m_{b}(j)}{1-2\eta\mu_{\text{max}}nm_{b}(j)},\qquad\forall a\neq j.
``` |  | (34) |

###### Proof.

For $`a\neq j`$, we have
$`|g_{b,0}(a)|\leq\mu_{\text{max}}\pi_{b,0}(a)\leq\mu_{\text{max}}m_{b}(j)`$.
Since $`\sum_{a}g_{b,0}(a)=0`$, also
$`|g_{b,0}(j)|\leq\sum_{a\neq j}|g_{b,0}(a)|\leq\mu_{\text{max}}m_{b}(j)`$.
The update of each probability ratio gives

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\frac{m_{b+1}(j)}{1-m_{b+1}(j)}`$ | $`\displaystyle=\sum_{a\neq j}\frac{\pi_{b,0}(a)}{\pi_{b,0}(j)}\exp\!\bigl(\eta(g_{b,0}(a)-g_{b,0}(j))\bigr)`$ |  |
|  |  | $`\displaystyle\leq\frac{m_{b}(j)}{1-m_{b}(j)}\exp(2\eta\mu_{\text{max}}m_{b}(j)).`$ |  |

Policy probability remain positive at finite iterates for each action.
Using $`e^{-v}\geq 1-v`$, we obtain

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\frac{1}{m_{b+1}(j)}-1`$ | $`\displaystyle\geq\left(\frac{1}{m_{b}(j)}-1\right)e^{-2\eta\mu_{\text{max}}m_{b}(j)}`$ |  |
|  |  | $`\displaystyle\geq\left(\frac{1}{m_{b}(j)}-1\right)(1-2\eta\mu_{\text{max}}m_{b}(j)).`$ |  |

Hence
$`1/m_{b+1}(j)\geq 1/m_{b}(j)-2\eta\mu_{\text{max}}(1-m_{b}(j))\geq 1/m_{b}(j)-2\eta\mu_{\text{max}}`$.
Summing this inequality over $`n`$ updates and taking reciprocals when
the resulting lower bound is positive proves
Eq. ([34](#A3.E34 "In Lemma C.1. ‣ C.1 Part 1 of Theorem : lower bound for on-policy RE(1) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")).

###### Proof of the first part of Theorem [3.6](#S3.Thmtheorem6 "Theorem 3.6. ‣ 3.3 Benefits of off-policyness ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness").

For $`S=1`$,
Eqs. ([14](#A1.E14 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
and ([15](#A1.E15 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
imply $`J(\pi_{b+1,0})\geq J(\pi_{b,0})`$. We first use this
monotonicity to obtain a uniformly negative advantage for every action
$`a\geq 3`$. Set

|  |  |  |
|----|----|----|
|  |
``` math
\overline{\mu}:=\max_{3\leq a\leq K}\mu(a),\qquad\kappa:=\frac{\mu(2)-\overline{\mu}}{4}>0.
``` |  |

Consider the separate bandit on actions $`2,\ldots,K`$, initialized at
$`w`$. It has a unique optimal action $`2`$, finite initial logits
$`\log w(a)`$, and $`\eta\mu(2)<4`$.
Theorem [3.1](#S3.Thmtheorem1 "Theorem 3.1. ‣ 3.1 Global convergence to the optimal policy ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"),
applied with $`S=1`$, shows that its mean reward converges to
$`\mu(2)`$. Choose a fixed integer $`b_{0}\geq 1`$ at which this mean
reward is at least $`\overline{\mu}+2\kappa`$.

The full on-policy update has the probability representation

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi_{b+1,0}(a)=\frac{\pi_{b,0}(a)\exp(\eta g_{b,0}(a))}{\sum_{j=1}^{K}\pi_{b,0}(j)\exp(\eta g_{b,0}(j))}.
``` |  | (35) |

When $`x=0`$, action 1 has zero probability and the update reduces to
that of the bandit on actions $`2,\ldots,K`$, initialized at $`w`$. By
the choice of $`b_{0}`$, this reduced bandit has mean reward at least
$`\overline{\mu}+2\kappa`$ after $`b_{0}`$ updates. The update map is
continuous in the policy, including at the boundary of the simplex.
Thus, for sufficiently small $`x>0`$, the mean reward after the same
$`b_{0}`$ updates differs from that of the reduced bandit by less than
$`\kappa`$, giving $`J(\pi_{b_{0},0})\geq\overline{\mu}+\kappa`$. Since
the mean reward is nondecreasing and $`\mu(a)\leq\overline{\mu}`$ for
every $`a\geq 3`$, it follows that

|  |  |  |  |
|----|----|----|----|
|  |
``` math
J(\pi_{b,0})-\mu(a)\geq\kappa,\qquad b\geq b_{0},\quad 3\leq a\leq K.
``` |  | (36) |

Here $`b_{0}`$ is chosen from the reduced bandit and depends not on
$`x`$.

#### Probability concentration on the suboptimal action.

Define the cumulative increase of the optimal logit by

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\ell_{b}=\eta\sum_{k=0}^{b-1}\pi_{k,0}(1)D(\pi_{k,0})=\theta_{b,0}(1)-\theta_{0,0}(1).
``` |  | (37) |

This sequence is nondecreasing, and each one-step increment is in
$`[0,\eta\mu_{\text{max}}]`$. The probability-ratio update and
$`\sum_{a}g_{b,0}(a)=0`$ give the exact identity

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\prod_{a=2}^{K}\frac{\pi_{b,0}(a)}{\pi_{b,0}(1)}=\frac{(1-x)^{K-1}\prod_{a=2}^{K}w(a)}{x^{K-1}}e^{-K\ell_{b}}.
``` |  | (38) |

Indeed, the one-step change in the logarithm of the left-hand side is
$`\eta\sum_{a=2}^{K}(g_{b,0}(a)-g_{b,0}(1))=-K\eta g_{b,0}(1)`$.

Now we define $`b_{\epsilon}=T_{\epsilon}(1)`$. Since

|  |  |  |
|----|----|----|
|  |
``` math
D(\pi_{b_{\epsilon},0})\geq\Delta\bigl(1-\pi_{b_{\epsilon},0}(1)\bigr),
``` |  |

the condition $`\epsilon<\Delta/2`$ implies
$`\pi_{b_{\epsilon},0}(1)>1/2`$. Every factor on the left-hand side of
Eq. ([38](#A3.E38 "In Probability concentration on the suboptimal action. ‣ C.1 Part 1 of Theorem : lower bound for on-policy RE(1) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
is then less than one, so

|  |  |  |
|----|----|----|
|  |
``` math
\ell_{b_{\epsilon}}>\frac{1}{K}\log\frac{(1-x)^{K-1}\prod_{a=2}^{K}w(a)}{x^{K-1}}=\frac{K-1}{K}\log(1/x)+O(1).
``` |  |

On the other hand, $`\ell_{b_{0}}\leq b_{0}\eta\mu_{\text{max}}`$. For
sufficiently small $`x`$, it follows that $`b_{\epsilon}>b_{0}`$ and
$`\ell_{b_{\epsilon}}-\ell_{b_{0}}>1`$. Thus the first crossing index

|     |                                                                 |     |
|-----|-----------------------------------------------------------------|-----|
|     |
       ``` math
       b_{\mathrm{c}}:=\min\{b\geq b_{0}:\ell_{b}-\ell_{b_{0}}\geq 1\}
       ```                                                              |     |

exists and satisfies $`b_{0}<b_{\mathrm{c}}\leq b_{\epsilon}`$. The
one-step bound on $`\ell_{b}`$ gives

|  |  |  |  |
|----|----|----|----|
|  |
``` math
1\leq\ell_{b_{\mathrm{c}}}-\ell_{b_{0}}\leq 1+\eta\mu_{\text{max}},\qquad\ell_{b_{\mathrm{c}}}\leq 1+(b_{0}+1)\eta\mu_{\text{max}}.
``` |  | (39) |

For $`3\leq a\leq K`$ and $`b\geq b_{0}`$,
Eq. ([36](#A3.E36 "In Proof of the first part of Theorem . ‣ C.1 Part 1 of Theorem : lower bound for on-policy RE(1) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
and the nonnegative optimal advantage imply
$`g_{b,0}(1)-g_{b,0}(a)\geq\kappa\pi_{b,0}(a)`$. Using $`e^{v}-1\geq v`$
in the exact ratio update, we obtain

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{\pi_{b+1,0}(1)}{\pi_{b+1,0}(a)}-\frac{\pi_{b,0}(1)}{\pi_{b,0}(a)}`$ | $`\displaystyle=\frac{\pi_{b,0}(1)}{\pi_{b,0}(a)}\left[e^{\eta(g_{b,0}(1)-g_{b,0}(a))}-1\right]`$ |  |  |
|  |  | $`\displaystyle\geq\eta\kappa\pi_{b,0}(1)\geq\frac{\kappa}{\mu_{\text{max}}}(\ell_{b+1}-\ell_{b}).`$ |  | (40) |

Here the last inequality follows from
$`\ell_{b+1}-\ell_{b}=\eta\pi_{b,0}(1)D(\pi_{b,0})\leq\eta\mu_{\text{max}}\pi_{b,0}(1)`$.
Summing from $`b_{0}`$ to $`b_{\mathrm{c}}-1`$ gives

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{\pi_{b_{\mathrm{c}},0}(a)}{\pi_{b_{\mathrm{c}},0}(1)}\leq\frac{\mu_{\text{max}}}{\kappa},\qquad 3\leq a\leq K.
``` |  | (41) |

By
Eq. ([39](#A3.E39 "In Probability concentration on the suboptimal action. ‣ C.1 Part 1 of Theorem : lower bound for on-policy RE(1) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")),
$`\ell_{b_{\mathrm{c}}}`$ has an upper bound independent of $`x`$.
Hence, for sufficiently small $`x`$,
Eq. ([38](#A3.E38 "In Probability concentration on the suboptimal action. ‣ C.1 Part 1 of Theorem : lower bound for on-policy RE(1) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
gives

|  |  |  |
|----|----|----|
|  |
``` math
\prod_{a=2}^{K}\frac{\pi_{b_{\mathrm{c}},0}(a)}{\pi_{b_{\mathrm{c}},0}(1)}\geq c_{1}x^{-(K-1)},
``` |  |

where $`c_{1}>0`$ is independent of $`x`$. By
Eq. ([41](#A3.E41 "In Probability concentration on the suboptimal action. ‣ C.1 Part 1 of Theorem : lower bound for on-policy RE(1) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")),
the product of the factors for actions $`3,\ldots,K`$ is at most
$`(\mu_{\text{max}}/\kappa)^{K-2}`$. The remaining factor therefore
satisfies

|  |  |  |
|----|----|----|
|  |
``` math
\frac{\pi_{b_{\mathrm{c}},0}(2)}{\pi_{b_{\mathrm{c}},0}(1)}\geq\frac{c_{1}x^{-(K-1)}}{(\mu_{\text{max}}/\kappa)^{K-2}}=c_{2}x^{-(K-1)},
``` |  |

where $`c_{2}:=c_{1}(\kappa/\mu_{\text{max}})^{K-2}>0`$ is also
independent of $`x`$. Thus, we further have

|     |                                                  |     |
|-----|--------------------------------------------------|-----|
|     |
       ``` math
       \pi_{b_{\mathrm{c}},0}(1)\leq c_{2}^{-1}x^{K-1}.
       ```                                               |     |

Defining $`C_{1}:=c_{2}^{-1}\max\{1,\mu_{\text{max}}/\kappa\}`$, using
Eq. ([41](#A3.E41 "In Probability concentration on the suboptimal action. ‣ C.1 Part 1 of Theorem : lower bound for on-policy RE(1) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
and summing over $`a\neq 2`$, we obtain

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\pi_{b_{\mathrm{c}},0}(a)`$ | $`\displaystyle\leq C_{1}x^{K-1}\quad(a\neq 2),`$ |  | (42) |
|  | $`\displaystyle m_{b_{\mathrm{c}}}(2)=\sum_{a\neq 2}\pi_{b_{\mathrm{c}},0}(a)`$ | $`\displaystyle\leq(K-1)C_{1}x^{K-1},`$ |  |  |

In particular, $`\pi_{b_{\mathrm{c}},0}(1)<1/2`$ for sufficiently small
$`x`$. On the other hand, by the definition of $`b_{\epsilon}`$ and
$`\epsilon<\Delta/2`$, we have $`\pi_{b_{\epsilon},0}(1)>1/2`$. Since
$`b_{\mathrm{c}}\leq b_{\epsilon}`$, it follows that
$`b_{\mathrm{c}}<b_{\epsilon}`$.

#### The steps required to reach the target.

Note that $`m_{b_{\epsilon}}(2)\geq\pi_{b_{\epsilon},0}(1)>1/2`$. Using
Lemma [C.1](#A3.Thmtheorem1 "Lemma C.1. ‣ C.1 Part 1 of Theorem : lower bound for on-policy RE(1) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"),
summing
Eq. ([33](#A3.E33 "In Lemma C.1. ‣ C.1 Part 1 of Theorem : lower bound for on-policy RE(1) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
from $`b_{\mathrm{c}}`$ to $`b_{\epsilon}-1`$ and using
Eq. ([42](#A3.E42 "In Probability concentration on the suboptimal action. ‣ C.1 Part 1 of Theorem : lower bound for on-policy RE(1) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")),
we obtain

|  |  |  |
|----|----|----|
|  |
``` math
T_{\epsilon}(1)=b_{\epsilon}\geq b_{\epsilon}-b_{\mathrm{c}}\geq\frac{(m_{b_{\mathrm{c}}}(2))^{-1}-2}{2\eta\mu_{\text{max}}}\geq\frac{1}{4\eta\mu_{\text{max}}(K-1)C_{1}}x^{-(K-1)}
``` |  |

for all sufficiently small $`x`$. This proves the first part of
Theorem [3.6](#S3.Thmtheorem6 "Theorem 3.6. ‣ 3.3 Benefits of off-policyness ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness").
∎

### C.2 Part 2 of Theorem [3.6](#S3.Thmtheorem6 "Theorem 3.6. ‣ 3.3 Benefits of off-policyness ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"): upper bound for off-policy RE(S)

We first bound the KL divergence to a fixed reward-weighted rollout
distribution. We then use this bound to show that a sufficiently long
inner loop preserves part of the target’s improvement in the optimal
action log-odds.

###### Lemma C.2.

For a stage beginning at $`q=\pi_{b,0}`$ and any integer $`S\geq 1`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\text{D}_{\text{KL}}(\widehat{\pi}_{q}\|\pi_{b,S})\leq\frac{\|\log\mu\|_{2}^{2}}{2\eta\mu_{\text{min}}(1-\eta\mu_{\text{max}}/4)S},
``` |  | (43) |

where $`\|\log\mu\|_{2}^{2}=\sum_{a=1}^{K}(\log\mu(a))^{2}`$.

###### Proof.

The frozen target is represented by the logits

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\theta^{*}:=\theta_{b,0}+\log\mu,\qquad\|\theta^{*}-\theta_{b,0}\|_{2}^{2}=\|\log\mu\|_{2}^{2}.
``` |  | (44) |

Indeed, $`\pi_{\theta^{*}}=\widehat{\pi}_{q}`$, so $`\theta^{*}`$
maximizes $`L(\pi_{\theta};q)`$ and its gradient vanishes there. Let
$`e_{s}=\theta^{*}-\theta_{b,s}`$ and denote the surrogate gap by

|  |  |  |
|----|----|----|
|  |
``` math
\delta_{s}:=L(\widehat{\pi}_{q};q)-L(\pi_{b,s};q)=J(\pi_{b,0})\text{D}_{\text{KL}}(\widehat{\pi}_{q}\|\pi_{b,s}).
``` |  |

The surrogate is concave with a $`J(\pi_{b,0})/2`$-Lipschitz gradient by
Lemma [A.2](#A1.Thmtheorem2 "Lemma A.2. ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
and
Eq. ([13](#A1.E13 "In Proof. ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")).
Co-coercivity therefore gives
$`\|g_{b,s}\|_{2}^{2}\leq(J(\pi_{b,0})/2)\langle e_{s},g_{b,s}\rangle`$.
Using $`e_{s+1}=e_{s}-\eta g_{b,s}`$ and concavity, we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\|e_{s}\|_{2}^{2}-\|e_{s+1}\|_{2}^{2}`$ | $`\displaystyle=2\eta\langle e_{s},g_{b,s}\rangle-\eta^{2}\|g_{b,s}\|_{2}^{2}`$ |  |
|  |  | $`\displaystyle\geq 2\eta\left(1-\frac{\eta J(\pi_{b,0})}{4}\right)\langle e_{s},g_{b,s}\rangle`$ |  |
|  |  | $`\displaystyle\geq 2\eta\left(1-\frac{\eta J(\pi_{b,0})}{4}\right)\delta_{s}.`$ |  |

By
Eq. ([14](#A1.E14 "In Proof of Theorem . ‣ Appendix A Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")),
$`\delta_{s}`$ is nonincreasing. Summing over the inner loop and using
$`\|e_{S}\|_{2}^{2}\geq 0`$ gives

|  |  |  |
|----|----|----|
|  |
``` math
S\delta_{S}\leq\sum_{s=0}^{S-1}\delta_{s}\leq\frac{\|\log\mu\|_{2}^{2}}{2\eta(1-\eta J(\pi_{b,0})/4)}.
``` |  |

Dividing by $`J(\pi_{b,0})S`$ and using
$`\mu_{\text{min}}\leq J(\pi_{b,0})\leq\mu_{\text{max}}`$ proves the
claim. ∎

###### Lemma C.3.

Let $`\widehat{\pi},p`$ be positive probability vectors,
$`\alpha=\widehat{\pi}(1)`$, and $`0<v\leq 1/2`$. Writing
$`\logit(u):=\log(u/(1-u))`$, we have

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\text{D}_{\text{KL}}(\widehat{\pi}\|p)\leq\frac{1}{8}\min\{\alpha,1-\alpha\}v^{2}\quad\Longrightarrow\quad\logit(p(1))\geq\logit(\alpha)-v.
``` |  | (45) |

###### Proof.

If $`p(1)\geq\alpha`$, the conclusion is immediate. Otherwise, set
$`d=\logit(\alpha)-\logit(p(1))>0`$. Combining all actions other than
action 1 by the log-sum inequality, we obtain

|  |  |  |
|----|----|----|
|  |
``` math
\text{D}_{\text{KL}}(\widehat{\pi}\|p)\geq\alpha\log\frac{\alpha}{p(1)}+(1-\alpha)\log\frac{1-\alpha}{1-p(1)}=f(d),
``` |  |

where $`f(t):=\alpha t+\log(1-\alpha+\alpha e^{-t})`$. Here
$`f(0)=f^{\prime}(0)=0`$, and $`f`$ is strictly increasing for $`t>0`$.
For $`0\leq t\leq v\leq 1/2`$,

|  |  |  |
|----|----|----|
|  |
``` math
f^{\prime\prime}(t)=\frac{\alpha(1-\alpha)e^{-t}}{(1-\alpha+\alpha e^{-t})^{2}}\geq\frac{\alpha(1-\alpha)}{2}\geq\frac{1}{4}\min\{\alpha,1-\alpha\}.
``` |  |

Integrating twice gives $`f(v)\geq\min\{\alpha,1-\alpha\}v^{2}/8`$. If
$`d>v`$, then $`f(d)>f(v)`$, contradicting the assumed KL bound.
Therefore we have $`d\leq v`$. ∎

###### Proof of the second part of Theorem [3.6](#S3.Thmtheorem6 "Theorem 3.6. ‣ 3.3 Benefits of off-policyness ‣ 3 In-depth analysis for bandits and softmax policies ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness").

Set $`h:=1-\epsilon/(\mu_{\text{max}}-\mu_{\text{min}})>1/2`$. When
$`\pi_{b,0}(1)\geq h`$, we have $`D(\pi_{b,0})\leq\epsilon`$. In the
following, assume that $`x`$ is sufficiently small so that

|  |  |  |  |
|----|----|----|----|
|  |
``` math
0<x\leq\frac{\mu_{\text{min}}(1-h)}{\mu_{\text{max}}}=\frac{\mu_{\text{min}}\epsilon}{\mu_{\text{max}}(\mu_{\text{max}}-\mu_{\text{min}})}.
``` |  | (46) |

This is a fixed positive upper bound and implies $`x<h`$.

#### Progress in one stage.

Consider a stage beginning at $`q=\pi_{b,0}`$ with $`x\leq q(1)<h`$, and
let $`\alpha=\widehat{\pi}_{q}(1)`$. Both parts of the target
distribution have mass at least $`x`$:

|  |  |  |
|----|----|----|
|  |
``` math
\alpha=\frac{\mu_{\text{max}}q(1)}{J(\pi_{b,0})}\geq q(1)\geq x,\qquad 1-\alpha\geq\frac{\mu_{\text{min}}(1-q(1))}{\mu_{\text{max}}}>\frac{\mu_{\text{min}}(1-h)}{\mu_{\text{max}}}\geq x.
``` |  |

The target reward-weighted rollout distribution increases the optimal
action’s log-odds by

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\logit(\alpha)-\logit(q(1))`$ | $`\displaystyle=\log\frac{\mu_{\text{max}}(1-q(1))}{\sum_{a>1}q(a)\mu(a)}`$ |  |  |
|  |  | $`\displaystyle\geq\log\frac{\mu_{\text{max}}}{\mu(2)}\geq\frac{\Delta}{\mu_{\text{max}}}.`$ |  | (47) |

To preserve at least half of this lower bound after the inner loop
updates, choose a fixed coefficient

|  |  |  |  |
|----|----|----|----|
|  |
``` math
c_{S}=\frac{16\mu_{\text{max}}^{2}\|\log\mu\|_{2}^{2}}{\eta\mu_{\text{min}}(1-\eta\mu_{\text{max}}/4)\Delta^{2}},\qquad S_{x}:=\left\lceil\frac{c_{S}}{x}\right\rceil.
``` |  | (48) |

Use the same number of gradient steps, $`S_{x}`$, in every inner loop.
For $`v:=\Delta/(2\mu_{\text{max}})\in(0,1/2)`$,
Lemma [C.2](#A3.Thmtheorem2 "Lemma C.2. ‣ C.2 Part 2 of Theorem : upper bound for off-policy RE(S) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
gives

|  |  |  |
|----|----|----|
|  |
``` math
\text{D}_{\text{KL}}(\widehat{\pi}_{q}\|\pi_{b,S_{x}})\leq\frac{x\Delta^{2}}{32\mu_{\text{max}}^{2}}=\frac{xv^{2}}{8}\leq\frac{1}{8}\min\{\alpha,1-\alpha\}v^{2}.
``` |  |

Lemma [C.3](#A3.Thmtheorem3 "Lemma C.3. ‣ C.2 Part 2 of Theorem : upper bound for off-policy RE(S) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness")
and
Eq. ([47](#A3.E47 "In Progress in one stage. ‣ C.2 Part 2 of Theorem : upper bound for off-policy RE(S) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
now yield

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\logit(\pi_{b+1,0}(1))\geq\logit(\alpha)-\frac{\Delta}{2\mu_{\text{max}}}\geq\logit(\pi_{b,0}(1))+\frac{\Delta}{2\mu_{\text{max}}},
``` |  | (49) |

where $`\pi_{b+1,0}=\pi_{b,S_{x}}`$.

#### The number of stages.

Let $`b_{*}:=\inf\{b\geq 0:\pi_{b,0}(1)\geq h\}`$, with $`b_{*}=\infty`$
if the set is empty. Until this threshold is reached,
Eq. ([49](#A3.E49 "In Progress in one stage. ‣ C.2 Part 2 of Theorem : upper bound for off-policy RE(S) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
shows that the optimal action probability increases after each inner
loop and stays at least $`x`$. Induction therefore gives

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\logit(\pi_{b,0}(1))\geq\logit(x)+\frac{b\Delta}{2\mu_{\text{max}}}
``` |  | (50) |

for every integer $`0\leq b\leq b_{*}`$. If $`b_{*}=\infty`$, the bound
holds for all $`b\geq 0`$. Since
Eq. ([46](#A3.E46 "In Proof of the second part of Theorem . ‣ C.2 Part 2 of Theorem : upper bound for off-policy RE(S) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
implies $`x\leq 1-h`$,

|     |                                                               |     |
|-----|---------------------------------------------------------------|-----|
|     |
       ``` math
       \logit(h)-\logit(x)=\log\frac{h(1-x)}{(1-h)x}\leq 2\log(1/x).
       ```                                                            |     |

Define

|  |  |  |
|----|----|----|
|  |
``` math
B_{x}:=\left\lceil\frac{4\mu_{\text{max}}}{\Delta}\log(1/x)\right\rceil.
``` |  |

We claim that $`b_{*}\leq B_{x}`$. Suppose for contradiction that
$`b_{*}>B_{x}`$. Then using
Eq. ([50](#A3.E50 "In The number of stages. ‣ C.2 Part 2 of Theorem : upper bound for off-policy RE(S) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
at $`b=B_{x}`$ we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\logit(\pi_{B_{x},0}(1))`$ | $`\displaystyle\geq\logit(x)+\frac{B_{x}\Delta}{2\mu_{\text{max}}}`$ |  |
|  |  | $`\displaystyle\geq\logit(x)+2\log(1/x)\geq\logit(h).`$ |  |

Since $`\logit`$ is strictly increasing, this implies
$`\pi_{B_{x},0}(1)\geq h`$, contradicting the definition of $`b_{*}`$.
Hence we have $`b_{*}\leq B_{x}`$. At $`b=b_{*}`$,

|  |  |  |
|----|----|----|
|  |
``` math
D(\pi_{b_{*},0})\leq(\mu_{\text{max}}-\mu_{\text{min}})(1-\pi_{b_{*},0}(1))\leq\epsilon.
``` |  |

Thus

|  |  |  |  |
|----|----|----|----|
|  |
``` math
T_{\epsilon}(S_{x})\leq b_{*}S_{x}\leq B_{x}S_{x}=O\!\left(x^{-1}\log(1/x)\right).
``` |  | (51) |

Here $`c_{S}>0`$ is fixed independently of $`x`$, so
$`S_{x}=\Theta(x^{-1})`$. Since $`K\geq 3`$, combining
Eq. ([51](#A3.E51 "In The number of stages. ‣ C.2 Part 2 of Theorem : upper bound for off-policy RE(S) ‣ Appendix C Proofs for Section ‣ Fine-tuning on self-generated and reward-weighted data: Learning dynamics, Convergence rates, and benefits of off-policyness"))
with the first part of the theorem gives

|  |  |  |
|----|----|----|
|  |
``` math
\frac{T_{\epsilon}(S_{x})}{T_{\epsilon}(1)}\leq Cx^{K-2}\log(1/x)\longrightarrow 0\qquad\text{as }x\downarrow 0.
``` |  |

∎
````
