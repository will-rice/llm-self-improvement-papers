###### Abstract

This work studies the challenge of aligning large language models (LLMs)
with offline preference data. We focus on alignment by Reinforcement
Learning from Human Feedback (RLHF) in particular. While popular
preference optimization methods exhibit good empirical performance in
practice, they are not theoretically guaranteed to converge to the
optimal policy and can provably fail when the data coverage is sparse by
classical offline reinforcement learning (RL) results. On the other
hand, a recent line of work has focused on theoretically motivated
preference optimization methods with provable guarantees, but these are
not computationally efficient for large-scale applications like LLM
alignment. To bridge this gap, we propose SPAC, a new offline preference
optimization method with self-play, inspired by the on-average pessimism
technique from the offline RL literature, to be the first provable and
scalable approach to LLM alignment. We both provide theoretical analysis
for its convergence under single-policy concentrability for the general
function approximation setting and demonstrate its competitive empirical
performance for LLM alignment on a 7B Mistral model with Open LLM
Leaderboard evaluations.

## 1 Introduction

Recent advances in large language models (LLMs) have greatly
strengthened their ability at a multitude of high-level, complex
instruction-following tasks, such as coding, summarization, and solving
mathematical problems ([Stiennon et al.,, 2020](#bib.bib66); [Li
et al.,, 2023](#bib.bib45)). However, there still remains the challenge
of ensuring the content generated by LLMs is aligned with human values
and preferences ([Bai et al.,, 2022](#bib.bib6); [Touvron et al.,,
2023](#bib.bib70)), especially in regards to safety, helpfulness, etc.
Specifically, the goal is to make LLMs generate an appropriate response
upon receiving any prompt. To achieve this, Reinforcement Learning from
Human Feedback (RLHF) is predominantly used. Standard RLHF approaches
use human feedback to construct a real-valued reward function that
quantifies the desirability of a prompt-response pair and optimize LLM
parameters so that the model generates in a way maximizing such reward.

In practice, data collection can be slow and costly and is usually done
before the alignment process, so RLHF is commonly formulated as an
offline reinforcement learning (RL) problem in the literature. Through
the lens of offline RL, common RLHF methods ([Christiano et al.,,
2017](#bib.bib19); [Rafailov et al.,, 2024](#bib.bib56); [Bai et al.,,
2022](#bib.bib6)) can be viewed as RL methods that first learn the
empirically best reward function from the offline data and then optimize
on it for a policy. However, despite their great empirical performance,
it is unclear whether these popular alignment methods are guaranteed to
converge to the optimal policy. In fact, by standard offline RL theory
([Zhu et al.,, 2023](#bib.bib93); [Wang et al.,, 2020](#bib.bib76)),
methods that greedily optimize the empirically best reward or value
function can provably fail from converging to the optimal policy when
the data coverage is sparse, which is the case for LLM alignment in
practice. Several works in the alignment literature have also identified
the distribution shift in the training data as a factor for reward
hacking ([Ramé et al.,, 2024](#bib.bib57); [Pan et al.,,
2022](#bib.bib55); [Miao et al.,, 2024](#bib.bib48)).

In response to this issue, a few theoretically motivated preference
optimization methods have been proposed in a recent line of work. These
methods all make use of the pessimism principle from the offline RL
literature ([Jin et al.,, 2021](#bib.bib40); [Li et al.,
2024a,](#bib.bib43) ). In particular, by estimating a pointwise lower
confidence bound for the latent reward function and optimizing the
policy with respect to this reward lower bound, these pessimistic
algorithms are theoretically guaranteed to converge to the optimal
policy even under sparse data coverage, namely, when the offline data
only satisfies single-policy concentrability. Only requiring the offline
data to cover where an optimal policy can visit, this is one of the
weakest data coverage assumption in the offline RL literature. In fact,
it is unlikely that stronger coverage assumptions can be satisfied in
practice, e.g., assuming the data cover where any possible policy can
visit, or even assuming full coverage of the entire state-action space,
which methods based on the empirically best estimator requires to
converge provably. Under this modest data assumption, [Zhu et al.,
(2023)](#bib.bib93) and [Xiong et al., (2023)](#bib.bib82) study the
linear setting, but their algorithms and theoretical guarantees heavily
rely on the linear assumption and are not directly applicable to the
general setting. [Zhan et al., (2024)](#bib.bib92) propose FREEHAND that
handles offline preference optimization for general function
approximation, but the algorithm is computationally hard as the authors
noted. The computational difficulty for finding the confidence bound or
region under general function approximation is well-known; while these
works pioneer the study of provable methods for offline preference
optimization, there remains a considerable gap between them and
large-scale applications like LLM alignment.

In this work, we propose a new approach for offline preference
optimization, named Self-Play with Adversarial Critic (SPAC), that is
not only theoretically guaranteed to converge to the optimal policy
under the single-policy concentrability assumption but also scalable to
general function classes like LLMs at the same time. Our approach is
inspired by [Xie et al., 2021a ()](#bib.bib79); [Cheng et al.,
(2022)](#bib.bib18) from the offline RL literature: we formulate offline
preference optimization as a Stackelberg game, in which there exists a
dueling dynamics between the learner that optimizes policy with respect
to a pessimistic reward estimate and the critic that maintains the
pessimistic reward under the learner’s policy. Specifically, instead of
estimating a pointwise lower bound on the latent reward, our method
maintains an on-average pessimistic reward estimate, i.e., a lower bound
on the reward expectation under the learner’s policy. Such on-average
pessimism is appealing because it allows for this particular Stackelberg
game to be solved by a single-timescale iterative self-play algorithm,
when coupled with a change-of-variable trick similar to the one in
Direct Policy Optimization (DPO) ([Rafailov et al.,, 2024](#bib.bib56)).
In addition, SPAC can be easily implemented on top of an existing RLHF
codebase due to its close connection to DPO. In the following sections,
we not only present the theoretical result showing SPAC converges to the
optimal policy under single-policy concentrability with high
probability, but also put SPAC to test in a 7B LLM alignment experiment
and demonstrate the competitive performance of SPAC against popular
alignment baselines in practice.

In summary, our work makes the following contributions:

1.  (i)
    We propose the first offline preference optimization algorithm that
    both provably converge to a near-optimal policy under only
    single-policy concentrability and is computationally scalable to
    general function approximation at the same time, and provide a
    non-asymptotic analysis on its suboptimality;
2.  (ii)
    We propose a practical implementation of our algorithm, turning our
    double-timescale algorithm into a single-timescale direct preference
    optimization algorithm, which is easy to implement based on existing
    RLHF codebases;
3.  (iii)
    We confirm the competitive performance of SPAC by performing
    alignment on 7B LLM and evaluating the finetuned models on the
    widely-used Open LLM Benchmarks against popular baselines.

### Related Work

##### LLM alignment.

Typically, the process of LLM alignment is comprised of two stages:
supervised fine-tuning (SFT) and RLHF. SFT usually precedes RLHF and
aims to align LLM with a training set containing human demonstration
responses, usually by causal language modeling ([Mishra et al.,,
2021](#bib.bib49); [Wei et al.,, 2021](#bib.bib78)). The standard RLHF
approach ([Christiano et al.,, 2017](#bib.bib19)) involves learning a
reward function from a set of human preference data and optimizes the
LLM with respect to it using RL methods such as PPO ([Schulman et al.,,
2017](#bib.bib62)). Under this pipeline, lightweight reward maximization
methods such as rejection sampling are also used ([Touvron et al.,,
2023](#bib.bib70); [Li et al., 2024b,](#bib.bib44) ; [Gao et al.,,
2024](#bib.bib31)), designed to reduce the computation needed to align
the policy model given a learned reward function. As a popular
alternative, contrastive RLHF methods are also introduced besides the
aforementioned DPO ([Hejna et al.,, 2023](#bib.bib36); [Xu et al.,,
2024](#bib.bib83)), which learn the policy model directly and obviate
the need to learn a separate reward model.

While we consider the offline setting, in which a fixed training set of
preference data is given, there is also a body of literature that
studies the online setting for alignment, in which the model can query
newly-annotated preference data during the training process ([Rosset
et al.,, 2024](#bib.bib59); [Dwaracherla et al.,, 2024](#bib.bib26);
[Calandriello et al.,, 2024](#bib.bib14)). However, the requirement of
fresh annotations at every iteration is costly in practice.

##### Self-play.

Self-play describes the type of approaches that searches for the
solution to a problem by staging the algorithm to play against itself,
usually iteratively. Rooted in game theory ([Brown,, 1951](#bib.bib12);
[Heinrich et al.,, 2015](#bib.bib35)), the concept of self-play has
found many applications in modern machine learning, e.g. AlphaGo Zero
([Silver et al.,, 2016](#bib.bib65)), Generative Adversarial Networks
(GAN) ([Goodfellow et al.,, 2014](#bib.bib33)), multi-agent
reinforcement learning (MARL) ([Bansal et al.,, 2017](#bib.bib8); [Baker
et al.,, 2019](#bib.bib7)), where the problem is innately multiplayer or
can be formulated so. Self-play is also commonly used in adversarial
imitation learning (also known as apprenticeship learning) and inverse
reinforcement learning ([Abbeel and Ng,, 2004](#bib.bib1); [Syed and
Schapire,, 2007](#bib.bib68); [Ho and Ermon,, 2016](#bib.bib39), esp.,),
which closely aligns with this work. The objective here is to maximize
performance in comparison to expert behavior, with the reward function
being adversarially selected with respect to this goal. Recently,
self-play has caught increasing attention in the literature for LLM
alignment, as some game-theoretic formulations of RLHF and thus
self-play methods for them have been proposed, such as Self-Play
Preference Optimization (SPO) ([Swamy et al.,, 2024](#bib.bib67)),
Self-Play fIne-tuNing (SPIN) ([Chen et al.,, 2024](#bib.bib17)), and
Direct Nash Optimization (DNO) ([Rosset et al.,, 2024](#bib.bib59)).

##### Offline RL.

Offline RL has been a well-studied area, both empirically ([Fujimoto
et al.,, 2019](#bib.bib30); [Kumar et al.,, 2020](#bib.bib41); [Levine
et al.,, 2020](#bib.bib42); [Fujimoto and Gu,, 2021](#bib.bib29), e.g.,)
and theoretically. One key algorithmic insight heavily used in offline
RL is the use of adversarial critics or models to establish pessimistic
estimates ([Kumar et al.,, 2020](#bib.bib41); [Xie et al.,
2021a,](#bib.bib79) ; [Cheng et al.,, 2022](#bib.bib18); [Bhardwaj
et al.,, 2023](#bib.bib10), e.g.,), which is also closely related to
this paper. As for the theoretical side, it is extensively studied in
the tabular case ([Shi et al.,, 2022](#bib.bib64); [Xie et al.,
2021b,](#bib.bib81) ; [Yan et al.,, 2023](#bib.bib85)), where the state
and action spaces of the environment are discrete. Notably, a method
with minimax-optimal sample complexity is introduced and analyzed in [Li
et al., 2024a ()](#bib.bib43). Methods with function approximation are
also studied. A population line of research considers linear function
approximation with a known linear feature ([Duan et al.,,
2020](#bib.bib24); [Jin et al.,, 2021](#bib.bib40); [Zanette et al.,,
2021](#bib.bib89)). In efforts to be more realistic, several works study
the setting with general function approximation ([Xie et al.,
2021a,](#bib.bib79) ; [Cheng et al.,, 2022](#bib.bib18); [Yin et al.,
2022b,](#bib.bib88) ; [Zhan et al.,, 2022](#bib.bib91)), including
neural function approximation ([Fan et al.,, 2020](#bib.bib28);
[Nguyen-Tang et al.,, 2021](#bib.bib51)).

##### Preference-based Reinforcement Learning.

We mainly review the works that study the theory of Preference-based
Reinforcement Learning (PbRL) methods. Besides the works for the offline
setting we have mentioned earlier, there are existing results about the
online PbRL setting, e.g., for the tabular case ([Novoseller et al.,,
2020](#bib.bib52); [Xu et al.,, 2020](#bib.bib84)) as well as the linear
and general function approximations ([Pacchiano et al.,,
2021](#bib.bib54); [Chen et al.,, 2022](#bib.bib16)). Related yet
different, dueling bandit is another PbRL setting that has been
well-studied ([Dudík et al.,, 2015](#bib.bib25); [Mehta et al.,,
2023](#bib.bib47); [Saha and Krishnamurthy,, 2022](#bib.bib60)).

## 2 Preliminaries

##### Offline RL

The RLHF portion for LLM alignment is predominantly formulated as
offline RL in the literature, and due to the autoregressive nature of
LLM, such offline RL can be reduced to an offline contextual bandit
([Ouyang et al.,, 2022](#bib.bib53)), which we represent with
$`(\mathcal{X},\mathcal{Y},r^{\star},\rho)`$. The function
$`r^{\star}:\mathcal{X}\times\mathcal{Y}\to\mathbb{R}`$ represents the
latent reward function, which is assumed to be deterministic and
unknown. In particular, $`r(x,y)`$ is the reward of response
$`y\in\mathcal{Y}`$ given prompt $`x\in\mathcal{X}`$, where
$`\mathcal{X}`$ is referred to as the state space and $`\mathcal{Y}`$
the action space. $`\rho`$ denotes the initial state distribution of the
bandit. A policy $`\pi:\mathcal{X}\to\Delta(\mathcal{Y})`$ specifies a
rule for response selection given a prompt, where
$`\pi(\cdot~|~x)\in\Delta(\mathcal{Y})`$ represents the response
selection probability vector for prompt $`x\in\mathcal{X}`$. The value
function of policy $`\pi`$ at $`x`$ is defined as

|     |                                                         |                           |
| --- | ------------------------------------------------------- | ------------------------- | --- |
|     | $`\displaystyle V^{\pi}(x):=\mathbb{E}\_{y\sim\pi(\cdot | x)}\left[r(x,y)\right].`$ |     |

The goal is to find a policy, which would be an LLM for human alignment,
whose response $`y`$ maximizes the reward $`r(x,y)`$ on any prompt
$`x`$. Such a policy is referred to as an optimal policy
$`\pi^{\star}`$, which maximizes the value function for all states
simultaneously.

We evaluate the performance of a policy $`\pi`$ by the suboptimality
metric defined as follow:

|     |                                                                                                          |     |     |
| --- | -------------------------------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle\mathrm{SubOpt}(\pi):=\mathbb{E}_{x\sim\rho}\left[V^{\pi^{\star}}(x)-V^{\pi}(x)\right].`$ |     | (1) |

Suboptimality measures the performance difference between the optimal
policy $`\pi^{\star}`$ and a given policy $`\pi`$. Naturally, one aims
to minimize the suboptimality and find an algorithm whose suboptimality
converges to zero as sample size approaches infinity.

##### Offline preference optimization

Given an offline preference dataset $`\mathcal{D}`$, the standard RLHF
procedure consists of two steps ([Christiano et al.,,
2017](#bib.bib19)): rewarding learning and RL optimization. During
reward learning, the goal is to estimate the latent reward from the
preference dataset $`\mathcal{D}`$. A data point from $`\mathcal{D}`$
includes a prompt $`x`$ and a pair of responses $`(y^{+},y^{-})`$. Here,
$`(y^{+},y^{-})\sim\pi_{\mathrm{ref}}(\cdot~|~x)`$, where
$`\pi_{\mathrm{ref}}`$ is a reference policy after SFT finetuning, and
$`y^{+}`$ is preferred to $`y^{-}`$ given prompt $`x`$, which is denoted
with $`y^{+}\succ y^{-}~|~x`$. Such human preference is commonly assumed
to follow the Bradley-Terry (BT) model ([Bradley and Terry,,
1952](#bib.bib11)) that depends on the latent reward function
$`r^{\star}`$, which satisfies

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\addcontentsline{lla}{section}{\numberline q:BTL}P(y^{+}\succ y^{-}~|~x)=\frac{\exp(r^{\star}(x,y^{+}))}{\exp(r^{\star}(x,y^{+}))+\exp(r^{\star}(x,y^{-}))}.
``` |  | (2) |

This allows one to use maximum-likelihood estimation (MLE) on the the
preference dataset
$`\mathcal{D}=\{(x_{i},y_{i}^{+},y_{i}^{-})\}_{i=1}^{n}`$ to estimate
the reward function. In particular, one can obtain the empirically best
estimated reward function $`\widehat{r}`$ from minimizing the empirical
negative log-likelihood loss over a function class $`\mathcal{F}`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\addcontentsline{lla}{section}{\numberline q:PPO-MLE}\widehat{r}\leftarrow\min_{f\in\mathcal{F}}-\frac{1}{n}\sum_{i=1}^{n}\log\frac{\exp(f(x_{i},y_{i}^{+}))}{\exp(f(x_{i},y_{i}^{+}))+\exp(f(x_{i},y_{i}^{-}))}.
``` |  | (3) |

With $`\widehat{r}`$ learned, the RL optimization step is about finding
a policy that maximizes the following objective:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\addcontentsline{lla}{section}{\numberline q:PPO}\widehat{\pi}\leftarrow\max_{\pi\in\Pi}\mathbb{E}_{x\sim\mathcal{D},y\sim\pi(\cdot|x)}\left[\widehat{r}(x,y)-\alpha D_{\mathrm{KL}}\big(\pi(\cdot~|~x)~||~\pi_{\mathrm{ref}}(\cdot~|~x)\big)\right].
``` |  | (4) |

The KL divergence regularization above is meant to control the deviation
of the output policy from the reference policy $`\pi_{\mathrm{ref}}`$,
where $`\alpha`$ is a hyperparameter. This prevents the RL optimization
from exploiting any misestimation within the learned reward and causing
reward hacking, but at the same time restricts the output policy
$`\widehat{\pi}`$ to the neighborhood of $`\pi_{\mathrm{ref}}`$ and
keeps it from converging to the actual optimal policy.

Besides the standard two-step approach, [Rafailov et al.,
(2024)](#bib.bib56) proposed a popular alternative for RLHF named Direct
Preference Optimization (DPO). It uses the analytical solution of
[Eq. 4](#S2.E4 "In Offline preference optimization ‣ 2 Preliminaries ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
to transform
[Eq. 3](#S2.E3 "In Offline preference optimization ‣ 2 Preliminaries ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
into the following objective:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\addcontentsline{lla}{section}{\numberline q:DPO}\widehat{\pi}\leftarrow\max_{\pi\in\Pi}\mathbb{E}_{x\sim\mathcal{D},y\sim\pi(\cdot|x)}\left[\widehat{r}(x,y)-\alpha D_{\mathrm{KL}}\big(\pi(\cdot~|~x)~||~\pi_{\mathrm{ref}}(\cdot~|~x)\big)\right],
``` |  | (5) |

which effectively combines the RL optimization step with reward
learning.

## 3 Self-Play with Adversarial Critic (SPAC)

Our algorithm is inspired by the philosophy that offline RL can be
formulated as a Stackelberg game ([von Stackelberg et al.,,
2010](#bib.bib75)), which was also studied in [Cheng et al.,
(2022)](#bib.bib18); [Bhardwaj et al., (2023)](#bib.bib10). Slightly
different from the formulation in [Bhardwaj et al., (2023)](#bib.bib10),
where reward samples are available and Bellman error can be computed, we
formulate preference optimization as the following bilevel optimization
problem:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\widehat{\pi}`$ | $`\displaystyle\in\arg\max_{\pi}\mathcal{L}_{\mathcal{D}}(\widehat{f},\pi)`$ |  | (6) |
|  | $`\displaystyle\text{s.t.}\ \widehat{f}`$ | $`\displaystyle\in\arg\min_{f\in\mathcal{F}}\mathcal{L}_{\mathcal{D}}(f,\pi)+\lambda\mathcal{E}_{\mathcal{D}}(f),`$ |  | (7) |

where $`\lambda\geq 0`$ is a hyperparameter, and

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathcal{L}_{\mathcal{D}}(f,\pi):=\frac{1}{n}\sum_{j=1}^{n}f(x_{j},y_{j})-f(x_{j},y_{j}^{\prime}),`$ |  | (8) |

where $`\{x_{j}\}_{j=1}^{n}`$ are prompts from the preference dataset
$`\mathcal{D}`$. For every $`j\in\{1,\cdots,n\}`$, $`y_{j}^{\prime}`$ is
a response generated by the reference policy $`\pi_{\mathrm{ref}}`$ on
$`x_{j}`$, which can be taken from the preference dataset
$`\mathcal{D}`$, and $`y_{j}\sim\pi(\cdot~|~x_{j})`$ is a response newly
generated from $`\pi`$ on $`x_{j}`$. In addition, we define

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathcal{E}_{\mathcal{D}}(f):=-\frac{1}{n}\sum_{i=1}^{n}\log\frac{\exp(f(x_{i},y_{i}^{+}))}{\exp(f(x_{i},y_{i}^{+}))+\exp(f(x_{i},y_{i}^{-}))},`$ |  | (9) |

which is the negative log likelihood of $`f`$ on the samples from
$`\mathcal{D}`$.

In this bilevel optimization formulation,
[Eq. 6](#S3.E6 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
seeks the learner policy $`\pi`$ as the leader in the Stackelberg game
and attempts to find $`\widehat{\pi}`$ under which the value predicted
with the critic $`\widehat{f}`$ is maximized;
[Eq. 7](#S3.E7 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
seeks the critic $`f`$ in function class $`\mathcal{F}`$ as the follower
in the Stackelberg game and attempts to find $`\widehat{f}`$ by
performing an on-average pessimistic policy evaluation relative to
$`\widehat{\pi}`$ while maximizing the log likelihood of $`\widehat{f}`$
with respect to $`\mathcal{D}`$.

However, while there have been existing results that formulate the
alignment problem with bilevel optimization ([Chakraborty et al.,,
2024](#bib.bib15); [Shen et al.,, 2024](#bib.bib63)), bilevel
optimization is computationally difficult to solve in general. Luckily,
this bilevel optimization above can be solved with an iterative
algorithm. Specifically, we propose an iterative algorithm
([Algorithm 1](#alg1 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"))
and replace the policy optimization step in

optimization method in the online RL literature ([Even-Dar et al.,,
2009](#bib.bib27); [Agarwal et al.,, 2021](#bib.bib3); [Cai et al.,,
2020](#bib.bib13); [Geist et al.,, 2019](#bib.bib32)). Note that the
algorithm plays the actor and critic at the same time in a self-play

provably converges to the optimal policy under the weak single-policy
concentrability assumption on the coverage of preference data
$`\mathcal{D}`$.

## 4 Theoretical Guarantees of SPAC

An important advantage of SPAC is that it can be mathematically proved
to converge to the optimal policy under weak assumption on the offline
preference data, which we present in this section. For our theory, we
first make a set of standard assumptions on the latent reward function
and the function class our algorithm uses.

###### Assumption 1 (Realizable, bounded reward).

Assume $`r^{\star}\in\mathcal{F}`$ and there exists $`R>0`$ such that
any $`f\in\mathcal{F}`$ satisfies
$`\left\lVert f\right\rVert_{\infty}\leq R`$.

Recall that $`\mathcal{F}`$ is the implicit reward function class that
is induced from the policy class $`\Pi`$ in
[Algorithm 2](#alg2 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
by
[Eq. 10](#S3.E10 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models").
Note that we assume realizability only for simplicity. Our theory can be
modified to the unrealizable setting by considering the bias-variance
tradeoff between the approximation error and complexity of
$`\mathcal{F}`$. Similarly, we assume that $`\mathcal{F}`$ is finite but
can be exponentially large and use log-cardinality to measure its
statistical complexity. Our theory can also extend to continuous
function classes by replacing the log-cardinality with appropriate
notions of covering number.

###### Assumption 2 (Coverage).

Assume

|  |  |  |
|----|----|----|
|  |
``` math
\mathfrak{C}:=\sqrt{\sup_{f\in\mathcal{F}}\frac{\mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y_{1}\sim\pi^{\star}(\cdot|x),y_{2}\sim\pi_{\mathrm{ref}}(\cdot|x)\end{subarray}}\Big[r^{\star}(x,y_{1})-r^{\star}(x,y_{2})-f(x,y_{1})+f(x,y_{2})\Big]^{2}}{\mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y_{1}\sim\pi_{\mathrm{ref}}(\cdot|x),y_{2}\sim\pi_{\mathrm{ref}}(\cdot|x)\end{subarray}}\Big[\big(r^{\star}(x,y_{1})-r^{\star}(x,y_{2})-f(x,y_{1})+f(x,y_{2})\big)^{2}\Big]}}<\infty
``` |  |

A unique challenge in offline RL is the distribution mismatch between
the sampling distribution of the offline dataset and the visitation
distribution for the policy to be learned. It is desirable that an
algorithm make less assumption on the data coverage and be able to
operate in a broader set of scenarios. There are a few different types
of assumption on the offline data sampling distribution in the offline
RL literature. The strongest assumes full coverage, i.e., the entire
state-action space $`\mathcal{X}\times\mathcal{Y}`$ needs to be covered
([Yin et al.,, 2021](#bib.bib86); [Xie and Jiang,, 2021](#bib.bib80)).
Another strong assumption requires the support of the data sampling
distribution to cover everywhere that any policy can possibly visit
([Antos et al.,, 2006](#bib.bib4); [Munos and Szepesvári,,
2008](#bib.bib50)). However, these assumptions are not possible in
modern machine learning applications with high-dimensional and
continuous spaces, like LLM alignment. In contrast, we consider one of
the weakest assumptions called single-policy concentrability, which only
requires that the data sampling distribution covers the visitation of
the optimal policy over a function space induced by $`\mathcal{F}`$.
Moreover, our characterization for distribution mismatch is tighter than
the standard density ratio for any $`\mathcal{F}`$ or $`\pi^{\star}`$:

|  |  |  |
|----|----|----|
|  | $`\displaystyle\mathfrak{C}\leq\left\lVert\frac{\pi^{\star}}{\pi_{\mathrm{ref}}}\right\rVert_{\infty}:=\sup_{x,y}\frac{\pi^{\star}(y~|~x)}{\pi_{\mathrm{ref}}(y~|~x)}.`$ |  |

An important disadvantage of popular preference optimization methods in
practice is that they have no provable guarantee for finding the optimal
policy unless under full data coverage. This is because these methods
simply take the empirically best reward estimator obtained from MLE and
optimize the policy with respect to it directly. As classical RL theory
suggests ([Rashidinejad et al.,, 2021](#bib.bib58); [Zhu et al.,,
2023](#bib.bib93); [Wang et al.,, 2020](#bib.bib76)), one can always
find a problem instance in which such policy obtained from optimizing
the empirically best value function suffers constant suboptimality with
constant probability. As mentioned in the introduction, this is believed
to be a factor behind the reward hacking phenomenon in the alignment
literature, where policy optimization exploits the parts in the learned
reward function that are ill-estimated because they are not sufficiently
covered in the training data. In LLM alignment, an extra KL
regularization is usually implemented to mitigate this undesirable
phenomenon, by confining the policy model to a trustworthy reference
policy model throughout optimization. However, while this approach gives
acceptable policies in practice, it fundamentally changes the
optimization objective and in general keeps the policy model from
converging to the actual optimal policy.

Finally, the theoretical guarantee of SPAC can be summarized in the
following theorem.

###### Theorem 1.

Assume the $`n`$ samples in $`\mathcal{D}`$ are i.i.d. Suppose
[1](#Thmassumption1 "Assumption 1 (Realizable, bounded reward). ‣ 4 Theoretical Guarantees of SPAC ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
and [2](#Thmassumption2 "Assumption 2 (Coverage). ‣ 4 Theoretical Guarantees of SPAC ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
hold. Let
$`c_{\mathrm{KL}}:=\mathbb{E}_{x\sim\rho}\left[D_{\mathrm{KL}}\big(\pi^{\star}(\cdot|x)~||~\pi_{\mathrm{init}}(\cdot|x)\big)\right]`$
and $`\kappa:=1/(\inf_{z\in[-R,R]}\sigma^{\prime}(z))`$. Choose any
$`\delta\in(0,1)`$. Suppose
$`\eta=\Theta(\sqrt{\frac{R^{2}T}{c_{\mathrm{KL}}}})`$ and
$`\lambda=\Theta(\mathfrak{C}\sqrt{\frac{n}{\kappa^{2}\log(|\Pi|/\delta)}})`$.
Then with probability at least $`1-\delta`$, the output policy
$`\widehat{\pi}`$ of SPAC achieves

|  |  |  |
|----|----|----|
|  | $`\displaystyle\mathrm{SubOpt}(\widehat{\pi})\leq\mathcal{O}\left(\mathfrak{C}\kappa\sqrt{\frac{1}{n}\log\frac{|\Pi|}{\delta}}+R\sqrt{\frac{1}{n}\log\frac{|\Pi|}{\delta}}+R\sqrt{\frac{c_{\mathrm{KL}}}{T}}\right)`$ |  |

for an absolute constant $`C_{0}>0`$.

The suboptimality of SPAC mainly comes from two sources: the statistical
error in learning with $`\mathcal{D}`$
([3](#alg1.l3 "In Algorithm 1 ‣ 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")

[Algorithm 1](#alg1 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"))

[Algorithm 1](#alg1 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")).
We can decompose the suboptimality into four terms as follows:

|  |  |  |  |

|  | $`\displaystyle\mathrm{SubOpt}(\widehat{\pi})`$ | $`\displaystyle=\frac{1}{T}\sum_{t=1}^{T}\Big(\underbrace{\mathbb{E}_{\rho\times\pi^{\star}}\left[r^{\star}(x,y)-f_{t}(x,y)\right]-\mathbb{E}_{\rho\times\pi_{\mathrm{ref}}}\left[r^{\star}(x,y)-f_{t}(x,y)\right]}_{I_{t,1}}`$ |  |
|  |  | $`\displaystyle\quad+\underbrace{\mathbb{E}_{\rho\times\pi^{\star}}[f_{t}(x,y)]-\mathbb{E}_{\rho\times\pi_{t}}[f_{t}(x,y)]}_{I_{t,2}}+\underbrace{\mathbb{E}_{\rho\times\pi_{t}}\left[f_{t}(x,y)\right]-\mathbb{E}_{\rho\times\pi_{\mathrm{ref}}}[f_{t}(x,y)]}_{I_{t,3}}`$ |  |
|  |  | $`\displaystyle\quad-\underbrace{\left(\mathbb{E}_{\rho\times\pi_{t}}\left[r^{\star}(x,y)\right]-\mathbb{E}_{\rho\times\pi_{\mathrm{ref}}}[r^{\star}(x,y)]\right)}_{I_{t,4}}\Big).`$ |  |

The statistical error is associated with $`I_{t,1}`$, $`I_{t,3}`$ and
$`I_{t,4}`$. By a change of measure and the mean value theorem,
$`I_{t,1}`$ can be turned into the total variation distance between the
Bernoulli distributions corresponding to the true BT model induced by
$`r^{\star}`$ and a fictitious BT model induced by $`f_{t}`$. This can
be further bounded by the log likelihood ratio of the two Bernoulli
distributions, resulting in

|  |  |  |
|----|----|----|
|  |
``` math

``` |  |

Furthermore, it can be combined with $`I_{t,1}`$ and $`I_{t,4}`$ to
recover the critic’s optimization objective
$`\mathcal{L}_{\mathcal{D}}(f,\pi_{t})+\lambda\mathcal{E}_{\mathcal{D}}(f)`$,
which can be further bounded by
$`\mathcal{L}_{\mathcal{D}}(r^{\star},\pi_{t})+\lambda\mathcal{E}_{\mathcal{D}}(r^{\star})`$
due to pessimism. Then we can arrive at the final bound on the
statistical error via a concentration argument.

On the other hand, notice the sum of $`I_{t,2}`$ coincides with the

##### Pessimism in offline RL

Pessimism is a common technique in the offline RL literature that is
used to estimate a lower bound for the latent reward or value function.
It is important to estimate an accurate lower bound, particularly for
$`(x,y)`$-pairs with a small number of observations in the offline
dataset, because by concentration, there is a constant probability for
all of these samples to be far from their mean, which can severely throw
off the estimation of a naive RL algorithm. Thus, pessimism is crucial
to the theoretical guarantee for converging to the optimal policy in the
offline setting.

In the offline RL literature, pessimism is widely studied and used in
works that consider the tabular setting ([Rashidinejad et al.,,
2021](#bib.bib58); [Li et al., 2024a,](#bib.bib43) ), in which the lower
confidence bound (LCB) is maintained for every entry of the reward or
value function by subtracting an entrywise penalty from the mean
estimation. The same philosophy can be seen applied in works that study
offline RL under linear function approximation ([Jin et al.,,
2021](#bib.bib40); [Yin et al., 2022a,](#bib.bib87) ), in which an
elliptical confidence region is maintained instead for the reward or
value estimate, and the policy is determined from the worst reward
function from this confidence region in a min-max fashion. These
pessimism methods share a commonality: they construct a pointwise
pessimistic estimate for the entire latent reward function. In fact, the
existing provable preference optimization algorithms ([Zhu et al.,,
2023](#bib.bib93); [Zhan et al.,, 2024](#bib.bib92); [Xiong et al.,,
2023](#bib.bib82)) all follow from this pointwise pessimism approach.
While it is theoretically convenient to obtain a pessimistic estimate
this way, as [Zhan et al., (2024)](#bib.bib92) point out, algorithms
with pointwise pessimism are computationally hard in general, as it is
unclear how to construct a confidence region for a neural network or an
LLM in practice. In contrast, inspired by a different concept called
on-average pessimism from a more recent line of work ([Xie et al.,
2021a,](#bib.bib79) ; [Cheng et al.,, 2022](#bib.bib18); [Bhardwaj
et al.,, 2023](#bib.bib10)), SPAC only needs a reward estimate $`f_{t}`$
whose expectation under the learner’s policy $`\pi`$ is a lower bound,
i.e.,
$`\mathbb{E}_{\rho\times\pi}[f_{t}]\leq\mathbb{E}_{\rho\times\pi}[r^{\star}]`$,
whose computation is scalable to any general function including LLMs.

##### Connections to other alignment methods

SPAC can be seen as a bridge between DPO and SPIN. On the one hand, when
we only run SPAC for one iteration with $`\lambda\to\infty`$, SPAC
reduces to DPO which optimizes the maximum likelihood only with respect
to the preference data $`\mathcal{D}`$. On the other hand, when
$`\lambda`$ is taken to $`0`$, SPAC recovers SPIN and becomes an
adversarial imitation learning algorithm (in this sense, it can also be
viewed as an RLHF extension of [Syed and Schapire, (2007)](#bib.bib68);
[Ho and Ermon, (2016)](#bib.bib39)), which prevents overoptimization of
the reward model. In fact, a similar connection has been discovered in
offline RL and imitation learning ([Cheng et al.,, 2022](#bib.bib18);
[Bhardwaj et al.,, 2023](#bib.bib10)). However, it is important to note
that SPAC enjoys more desirable computational properties as the DPO
trick
([Eq. 10](#S3.E10 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"))
can take care of no-regret policy optimization completely without the
need for extra assumptions.

## 5 Experiments

We demonstrate that SPAC achieves competitive performance over a wide
range of evaluation benchmarks as it substantially improves the initial
SFT model and results in better finetuned models than counterpart LLM
alignment methods, even when the training prompts and testing prompts
follow different distributions.

### 5.1 Experimental Setup

##### Model and Data.

In our experiments, we use mistral-7b-sft-beta as the base model, which
is a finetuned version of Mistral-7B-v0.1 on the Ultrachat200k dataset
([Ding et al.,, 2023](#bib.bib23)) by SFT. For the offline preference
dataset, we use the latest version of UltraFeedback Binarized ([Cui
et al.,, 2023](#bib.bib22)), which is made of a diverse set of 60K
prompt-chosen-rejected triplets. The preferences in this dataset are
annotated based on the quality of the responses with respect to
instruction-following, truthfulness, honesty and helpfulness, judged by
GPT-4.

##### Implementation.

We run SPAC for 3 iterations. We shuffle the samples in UltraFeedback
Binarized and split them into 3 subsets of equal size to be used in each
iteration ([Rosset et al.,, 2024](#bib.bib59); [Tran et al.,,
2023](#bib.bib71)). As the pseudocode of
[Algorithm 2](#alg2 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
lays out, in each iteration $`t\in\{0,1,2\}`$, we use $`\pi_{t}`$ to
generate one response $`y_{j}`$ to every prompt $`x_{j}`$ from the set
of 20K prompts designated to that iteration. We initialize with
$`\pi_{t}`$ and optimize the minimization objective
([3](#alg2.l3 "In Algorithm 2 ‣ 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
of
[Algorithm 2](#alg2 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"))
for two epochs to obtain a new policy model $`\pi_{t+1}`$. More details
about generation and finetuning can be found in
[Appendix A](#A1 "Appendix A Experiment Details ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models").

On the other hand, in theory
([Theorem 1](#Thmtheorem1 "Theorem 1. ‣ 4 Theoretical Guarantees of SPAC ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")),
a huge scaling $`\lambda=\Theta(\mathfrak{C}\sqrt{n})`$ is needed on the
regularization to guarantee convergence. However, such huge numerics can
often lead to numerical instability in optimization. To maintain the
same level of regularization without actually using a huge $`\lambda`$
in practice, we implement a trick on the critic term in the optimization
objective
([3](#alg2.l3 "In Algorithm 2 ‣ 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
of
[Algorithm 2](#alg2 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"))
by smoothing the log density ratio with the log-sigmoid function, which
changes the policy update to:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\pi_{t+1}`$ | $`\displaystyle\leftarrow\arg\min_{\pi\in\Pi}-\frac{1}{n}\sum_{j=1}^{n}\log\sigma\left(\frac{\eta}{2}\log\frac{\pi(y_{j}^{+}|x_{j})}{\pi_{t}(y_{j}^{+}|x_{j})}+\frac{\eta}{2}\log\frac{\pi(y_{j}^{-}|x_{j})}{\pi_{t}(y_{j}^{-}|x_{j})}-\eta\log\frac{\pi(y_{j}|x_{j})}{\pi_{t}(y_{j}|x_{j})}\right)`$ |  |  |
|  |  | $`\displaystyle\qquad\qquad\qquad\qquad-\frac{\lambda}{n}\sum_{i=1}^{n}\log\sigma\left(\eta\log\frac{\pi(y_{i}^{+}|x_{i})}{\pi_{t}(y_{i}^{+}|x_{i})}-\eta\log\frac{\pi(y_{i}^{-}|x_{i})}{\pi_{t}(y_{i}^{-}|x_{i})}\right).`$ |  | (11) |

This technique, which can also be seen used in ([Chen et al.,,
2024](#bib.bib17); [Wang et al.,, 2024](#bib.bib77)) for numerical
stability purposes, would keep the critic term from being too negative
and balance the strength of the critic with that of the regularization,
allowing us to use $`\lambda`$ as small as $`1.0`$ in the experiments.

### 5.2 Results and Analysis

We evaluate the models from every iteration of our SPAC finetuning on
the tasks from Open LLM Leaderboard. Despite a lack of directly
comparable methods, we also finetune with state-of-the-art methods that
do not have guarantees of finding the optimal policy, namely DPO and
SPIN on the same preference dataset and evaluate the resulting models.
In particular, since SPIN is also an iterative algorithm, we run it for
the same number of iterations as SPAC. Furthermore, we treat the chosen
responses in UltraFeedback as demonstrations when running SPIN, for SPIN
takes a supervised dataset made of prompt-response pairs as input. While
this is slightly different from the setting of its original experiments
in [Chen et al., (2024)](#bib.bib17), the responses in UltraFeedback are
generated from LLMs much stronger than our base model and suffice to
serve as demonstrations. We use the training hyperparameters from [Chen
et al., (2024)](#bib.bib17) and finetune SPAC with them too. In
addition, we compare with DPO by finetuning the base model with it for 2
epochs on the entire UltraFeedback dataset. In addition, we evaluate
zephyr-7b-beta ([Tunstall et al.,, 2023](#bib.bib72)), which is an
industry-grade LLM finetuned from mistral-7b-sft-beta using DPO on the
UltraFeedback dataset. We use 42 as random seed in all experiments. The
results are presented in
[Table 1](#S5.T1 "In Evaluation. ‣ 5.1 Experimental Setup ‣ 5 Experiments ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models").

In our experiments, SPAC improves from the initial SFT model by 2.95% on
average across the tasks from Open LLM Leaderboard after the first
iteration. Specifically, SPAC performs better than or on par with DPO in
the first 5 tasks and significantly better on GSM8k. In fact, both SPAC
and SPIN are immediately better than DPO after the first iteration,
despite only using 1/3 of the training data, but DPO noticeably
outperforms SPIN on ARC and HellaSwag. Over the following two
iterations, the performance of SPAC continues to increase over all
tasks, except for a decrease by 0.78% on MMLU at the second iteration
and a decrease by 0.69% on GSM8k at the third iteration. In fact, a
performance decrease on GSM8k is also witnessed in DPO. A reasonable
explanation for this is our training data UltraFeedback does not contain
mathematical reasoning problems, which GSM8k specifically tests, so
finetuning solely on UltraFeedback can cause the LLM to forget its
mathematical reasoning ability from pretraining and SFT. In contrast,
the performance of SPIN starts to waver or decrease after the first
iteration over all six tasks. We conjecture the use of pessimism
controls the model’s overfitting to the training data, so SPAC
experiences less forgetting than other baselines during finetuning. In
the end, we observe the model improvement becomes incremental and the
loss near-zero at the third iteration, implying SPAC is close to
convergence under this set of hyperparameters; SPAC improves the base
SFT model by a total of 4.37% on average, more than other baselines by a
considerable margin.

## 6 Conclusion

In this work, we propose a new offline preference optimization method
named SPAC, which is the first that provably converges to the optimal
policy under single-policy concentrability and has a scalable
implementation for general function approximation at the same time. It
is inspired from a Stackelberg game formulation of the offline RL
problem and can be implemented as a single-timescale iterative self-play
algorithm owing to a change-of-variable trick. We provide a theoretical
analysis showing the suboptimality of SPAC decays at the rate of
$`\widetilde{O}(\sqrt{1/n}+\sqrt{1/T})`$, ignoring logarithmic and
constant factors, under single-policy concentrability. In addition, we
finetune a 7B LLM with SPAC and evaluate the finetuned model on Open LLM
Leaderboard. We demonstrate that SPAC attains competitive empirical
performance compared to state-of-the-art alignment methods.

Bringing

### D.1 Proof of MLE ([Lemma 1](#Thmlemma1 "Lemma 1. ‣ D.1 Proof of MLE () ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"))

In this subsection, we present the additional steps to obtain an upper
bound on $`I_{t,1}`$, which is controlled by the MLE regularization in
the objective of our algorithm. Similar results can be found in
[Bhardwaj et al., (2023)](#bib.bib10) and [Zhan et al.,
(2024)](#bib.bib92), and our lemmas are an adaptation of theirs to our
setting.

###### Lemma 1.

Assume all functions $`f\in\mathcal{F}`$ are uniformly bounded by a
constant $`R>0`$. For any $`0<\delta<1`$, with probability at least
$`1-\delta`$,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{x\sim\rho,y_{1}\sim\pi_{\mathrm{ref}}(\cdot|x),y_{2}\sim\pi_{\mathrm{ref}}(\cdot|x)}\left[\big(r^{\star}(x,y_{1})-r^{\star}(x,y_{2})-f(x,y_{1})+f(x,y_{2})\big)^{2}\right]\lesssim\frac{\kappa^{2}}{n}\log\frac{|\mathcal{F}|}{\delta}
``` |  |

for all $`f\in\mathcal{F}`$ simultaneously.

###### Proof.

By plugging the conclusion of
[Lemma 2](#Thmlemma2 "Lemma 2. ‣ D.1.1 and Its Proof ‣ D.1 Proof of MLE () ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
into
[Lemma 3](#Thmlemma3 "Lemma 3. ‣ D.1.2 and Its Proof ‣ D.1 Proof of MLE () ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"),
we have

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\quad\ \mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y_{1}\sim\pi_{\mathrm{ref}}(\cdot|x)\\
y_{2}\sim\pi_{\mathrm{ref}}(\cdot|x)\end{subarray}}\Big[D_{\mathrm{TV}}\big(P_{f}(\cdot~|~x,y_{1},y_{2}),P(\cdot~|~x,y_{1},y_{2})\big)^{2}\Big]`$ |  |  |
|  |  | $`\displaystyle\lesssim\frac{1}{n}\sum_{i=1}^{n}\log\frac{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P_{f}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}+\frac{1}{n}\log\frac{|\mathcal{F}|}{\delta}`$ |  |  |
|  |  | $`\displaystyle\lesssim\frac{1}{n}\log\frac{|\mathcal{F}|}{\delta}.`$ |  | (29) |

Finally, recall the definitions

|  |  |  |
|----|----|----|
|  |
``` math
P(y^{+}\succ y^{-}~|~x)=\sigma(r^{\star}(x,y^{+})-r^{\star}(x,y^{-}))
``` |  |

and for any $`f\in\mathcal{F}`$,

|     |                                                            |     |
|-----|------------------------------------------------------------|-----|
|     |
       ``` math
       P_{f}(y^{+}\succ y^{-}~|~x)=\sigma(f(x,y^{+})-f(x,y^{-})).
       ```                                                         |     |

With these, we can apply the Mean Value Theorem on the sigmoid function
between $`r^{\star}(x,y_{1})-r^{\star}(x,y_{2})`$ and
$`f(x,y_{1})-f(x,y_{2})`$ to arrive at the advertised bound with an
additional factor of
$`\kappa^{2}=1/(\inf_{z\in[-R,R]}\sigma^{\prime}(z))^{2}`$.
Specifically, we have

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\quad\ \mathbb{E}_{x\sim\rho,y_{1}\sim\pi_{\mathrm{ref}}(\cdot|x),y_{2}\sim\pi_{\mathrm{ref}}(\cdot|x)}\left[\big(r^{\star}(x,y_{1})-r^{\star}(x,y_{2})-f(x,y_{1})+f(x,y_{2})\big)^{2}\right]`$ |  |
|  |  | $`\displaystyle\lesssim\kappa^{2}\mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y_{1}\sim\pi_{\mathrm{ref}}(\cdot|x)\\
y_{2}\sim\pi_{\mathrm{ref}}(\cdot|x)\end{subarray}}\bigg[\Big(\left|P_{f}(y_{1}\succ y_{2}~|~x)-P(y_{1}\succ y_{2}~|~x)\right|+\left|P_{f}(y_{1}\prec y_{2}~|~x)-P(y_{1}\prec y_{2}~|~x)\right|\Big)^{2}\bigg]`$ |  |
|  |  | $`\displaystyle=2\kappa^{2}\mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y_{1}\sim\pi_{\mathrm{ref}}(\cdot|x)\\
y_{2}\sim\pi_{\mathrm{ref}}(\cdot|x)\end{subarray}}\Big[D_{\mathrm{TV}}\big(P_{f}(\cdot~|~x,y_{1},y_{2}),P(\cdot~|~x,y_{1},y_{2})\big)^{2}\Big]`$ |  |
|  |  | $`\displaystyle\lesssim\frac{\kappa^{2}}{n}\log\frac{|\mathcal{F}|}{\delta},`$ |  |

which leads us to the advertised bound. ∎

#### D.1.1 [Lemma 2](#Thmlemma2 "Lemma 2. ‣ D.1.1 and Its Proof ‣ D.1 Proof of MLE () ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models") and Its Proof

###### Lemma 2.

For any $`0<\delta<1`$, with probability at least $`1-\delta`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\sum_{i=1}^{n}\log\frac{P_{f}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}\leq\log\frac{|\mathcal{F}|}{\delta}
``` |  | (30) |

for all $`f\in\mathcal{F}`$ simultaneously.

###### Proof.

This proof follows a standard argument of MLE ([van de Geer,,
2000](#bib.bib73)). For any $`g\in\mathcal{F}`$,

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\quad\ \mathbb{E}\left[\exp\left(\sum_{i=1}^{n}\log\frac{P_{g}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}\right)\right]`$ |  |  |
|  |  | $`\displaystyle\overset{(\mathrm{i})}{=}\prod_{i=1}^{n}\mathbb{E}\left[\exp\left(\log\frac{P_{g}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}\right)\right]`$ |  |  |
|  |  | $`\displaystyle=\prod_{i=1}^{n}\mathbb{E}\left[\frac{P_{g}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}\right]`$ |  |  |
|  |  | $`\displaystyle\overset{(\mathrm{ii})}{=}\prod_{i=1}^{n}\mathbb{E}\Bigg[\mathbb{E}\bigg[\frac{P_{g}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}~|~(x_{i},y_{i}^{+},y_{i}^{-})\bigg]\Bigg]`$ |  |  |
|  |  | $`\displaystyle=\prod_{i=1}^{n}\mathbb{E}\left[P_{g}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})+P_{g}(y_{i}^{+}\prec y_{i}^{-}~|~x_{i})\right]=1.`$ |  | (31) |

Above, (i) the first step is by the independence of the samples in
$`\mathcal{D}`$. (ii) is by the Tower property.

By Markov’s inequality, we can have

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\quad\ \mathbb{P}\left[\sum_{i=1}^{n}\log\frac{P_{g}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}>\log\frac{1}{\delta}\right]`$ |  |  |
|  |  | $`\displaystyle\leq\mathbb{E}\left[\exp\left(\sum_{i=1}^{n}\log\frac{P_{g}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}\right)\right]\exp\left(-\log\frac{1}{\delta}\right)\leq\delta.`$ |  | (32) |

Furthermore, we can invoke the union bound over all $`g\in\mathcal{F}`$
and have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbb{P}\left[\sum_{i=1}^{n}\log\frac{P_{g}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}>\log\frac{|\mathcal{F}|}{\delta}\right]\leq\delta.`$ |  | (33) |

At this point, we have arrived at the advertised bound. ∎

#### D.1.2 [Lemma 3](#Thmlemma3 "Lemma 3. ‣ D.1.2 and Its Proof ‣ D.1 Proof of MLE () ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models") and Its Proof

Note that $`\mathcal{D}`$ can be equivalently written in the form of
$`\mathcal{D}=\{(x_{i},y_{i},y_{i}^{\prime},o_{i})\}_{i=1}^{n}`$, where
$`o_{i}`$ is a binary symbol that indicates whether $`y_{i}`$ is
preferred to $`y_{i}^{\prime}`$ given $`x_{i}`$, i.e., $`o_{i}=+`$ when
$`y_{i}\succ y_{i}^{\prime}~|~x_{i}`$ and $`o_{i}=-`$ otherwise. Using
this set of notation, let us define
$`P(+~|~x,y_{1},y_{2})=P(y_{1}\succ y_{2}~|~x)`$ and
$`P(-~|~x,y_{1},y_{2})=P(y_{1}\prec y_{2}~|~x)`$ and similarly,
$`P_{f}(+~|~x,y_{1},y_{2})=P_{f}(y_{1}\succ y_{2}~|~x)`$ and
$`P_{f}(-~|~x,y_{1},y_{2})=P_{f}(y_{1}\prec y_{2}~|~x)`$. In the
following lemma and its proof, we will make use of this set of notation
for convenience.

###### Lemma 3.

For any $`0<\delta<1`$, with probability at least $`1-\delta`$,

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y_{1}\sim\pi_{\mathrm{ref}}(\cdot|x)\\
y_{2}\sim\pi_{\mathrm{ref}}(\cdot|x)\end{subarray}}\Big[D_{\mathrm{TV}}\big(P_{f}(\cdot~|~x,y_{1},y_{2}),P(\cdot~|~x,y_{1},y_{2})\big)^{2}\Big]\lesssim\frac{1}{n}\left(\sum_{i=1}^{n}\log\frac{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P_{f}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}+\log\frac{|\mathcal{F}|}{\delta}\right)`$ |  |

for all $`f\in\mathcal{F}`$ simultaneously.

###### Proof.

By Lemma 25 of [Agarwal et al., (2020)](#bib.bib2), we have

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\quad\ \mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y_{1}\sim\pi_{\mathrm{ref}}(\cdot|x)\\
y_{2}\sim\pi_{\mathrm{ref}}(\cdot|x)\end{subarray}}\Big[D_{\mathrm{TV}}\big(P_{f}(\cdot~|~x,y_{1},y_{2}),P(\cdot~|~x,y_{1},y_{2})\big)^{2}\Big]`$ |  |  |
|  |  | $`\displaystyle\leq-2\log\mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y\sim\pi_{\mathrm{ref}}(\cdot|x)\\
y^{\prime}\sim\pi_{\mathrm{ref}}(\cdot|x)\\
o\sim P(y\succ y^{\prime}|x)\end{subarray}}\left[\exp\left(-\frac{1}{2}\log\frac{P(o~|~x,y,y^{\prime})}{P_{f}(o~|~x,y,y^{\prime})}\right)\right].`$ |  | (34) |

Now, define
$`\widetilde{\mathcal{D}}=\{(\widetilde{x}_{i},\widetilde{y}_{i},\widetilde{y}_{i}^{\prime},\widetilde{o}_{i})\}`$
be a dataset that is an independent copy of $`\mathcal{D}`$ from the
same sampling distribution. We have

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\quad\ -\log\mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y\sim\pi_{\mathrm{ref}}(\cdot|x)\\
y^{\prime}\sim\pi_{\mathrm{ref}}(\cdot|x)\\
o\sim P(y\succ y^{\prime}|x)\end{subarray}}\left[\exp\left(-\frac{1}{2}\log\frac{P(o~|~x,y,y^{\prime})}{P_{f}(o~|~x,y,y^{\prime})}\right)\right]`$ |  |  |
|  |  | $`\displaystyle=-\frac{1}{n}\sum_{i=1}^{n}\log\mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y\sim\pi_{\mathrm{ref}}(\cdot|x)\\
y^{\prime}\sim\pi_{\mathrm{ref}}(\cdot|x)\\
o\sim P(y\succ y^{\prime}|x)\end{subarray}}\left[\exp\left(-\frac{1}{2}\log\frac{P(o~|~x,y,y^{\prime})}{P_{f}(o~|~x,y,y^{\prime})}\right)\right]`$ |  |  |
|  |  | $`\displaystyle=-\frac{1}{n}\log\mathbb{E}_{\widetilde{\mathcal{D}}}\left[\exp\left(-\frac{1}{2}\sum_{i=1}^{n}\log\frac{P(\widetilde{o}_{i}~|~\widetilde{x}_{i},\widetilde{y}_{i},\widetilde{y}_{i}^{\prime})}{P_{f}(\widetilde{o}_{i}~|~\widetilde{x}_{i},\widetilde{y}_{i},\widetilde{y}_{i}^{\prime})}\right)~|~\mathcal{D}\right],`$ |  | (35) |

in which the last step is by the independence of the samples in
$`\mathcal{D}`$ and $`\widetilde{\mathcal{D}}`$.

Let us temporary define
$`\ell\big(f,(x,y,y^{\prime},o)\big):=-\frac{1}{2}\log\frac{P(o~|~x,y,y^{\prime})}{P_{f}(o~|~x,y,y^{\prime})}`$.
By Lemma 24 of [Agarwal et al., (2020)](#bib.bib2), we have

|  |  |  |
|----|----|----|
|  | $`\displaystyle\mathbb{E}_{\mathcal{D}}\left[\exp\left(\sum_{i=1}^{n}\ell\big(f,(x_{i},y_{i},y_{i}^{\prime},o_{i})\big)-\log\mathbb{E}_{\widetilde{\mathcal{D}}}\left[\exp\left(\sum_{i=1}^{n}\ell\big(f,(\widetilde{x}_{i},\widetilde{y}_{i},\widetilde{y}_{i}^{\prime},\widetilde{o}_{i})\big)\right)~|~\mathcal{D}\right]-\log|\mathcal{F}|\right)\right]\leq 1.`$ |  |

By applying the Chernoff bound and then the union bound for every
$`f\in\mathcal{F}`$ to the inequality above, we have that with
probability at least $`1-\delta`$,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle-\log\mathbb{E}_{\widetilde{\mathcal{D}}}\left[\exp\left(\sum_{i=1}^{n}\ell\big(f,(\widetilde{x}_{i},\widetilde{y}_{i},\widetilde{y}_{i}^{\prime},\widetilde{o}_{i})\big)\right)~|~\mathcal{D}\right]\leq-\sum_{i=1}^{n}\ell\big(f,(x_{i},y_{i},y_{i}^{\prime},o_{i})\big)+2\log\frac{|\mathcal{F}|}{\delta}.`$ |  | (36) |

Finally, bringing
[Eq. 36](#A4.E36 "In Proof. ‣ D.1.2 and Its Proof ‣ D.1 Proof of MLE () ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
into
[Eq. 35](#A4.E35 "In Proof. ‣ D.1.2 and Its Proof ‣ D.1 Proof of MLE () ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
and then back into
[Eq. 34](#A4.E34 "In Proof. ‣ D.1.2 and Its Proof ‣ D.1 Proof of MLE () ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"),
we have that with probability at least $`1-\delta`$,

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\quad\ \mathbb{E}_{\begin{subarray}{c}x\sim\rho\\
y_{1}\sim\pi_{\mathrm{ref}}(\cdot|x)\\
y_{2}\sim\pi_{\mathrm{ref}}(\cdot|x)\end{subarray}}\Big[D_{\mathrm{TV}}\big(P_{f}(\cdot~|~x,y_{1},y_{2}),P(\cdot~|~x,y_{1},y_{2})\big)^{2}\Big]`$ |  |  |
|  |  | $`\displaystyle\leq-\frac{2}{n}\sum_{i=1}^{n}\ell\big(f,(x_{i},y_{i},y_{i}^{\prime},o_{i})\big)+\frac{4}{n}\log\frac{|\mathcal{F}|}{\delta}`$ |  |  |
|  |  | $`\displaystyle=-\frac{1}{n}\sum_{i=1}^{n}\log\frac{P(o_{i}~|~x_{i},y_{i},y_{i}^{\prime})}{P_{f}(o_{i}~|~x_{i},y_{i},y_{i}^{\prime})}+\frac{4}{n}\log\frac{|\mathcal{F}|}{\delta}`$ |  | (37) |
|  |  | $`\displaystyle=-\frac{1}{n}\sum_{i=1}^{n}\log\frac{P(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}{P_{f}(y_{i}^{+}\succ y_{i}^{-}~|~x_{i})}+\frac{4}{n}\log\frac{|\mathcal{F}|}{\delta},`$ |  | (38) |

which is the advertised bound in this lemma. ∎

### D.2 Bounding $`I_{t,2}`$ in [Eq. 18](#A4.E18 "In Proof. ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")

In this subsection, we present the steps to obtain an upper bound on
$`I_{t,2}`$. Note that the sum of $`I_{t,2}`$’s actually coincides with
the definition of regret in online learning ([Hazan et al.,,
2016](#bib.bib34)).

|  |  |  |
|----|----|----|
|  |
``` math
\sum_{t=1}^{T}I_{t,2}=\sum_{t=1}^{T}\mathbb{E}_{x\sim\rho,y\sim\pi^{\star}(\cdot|x)}[f_{t}(x,y)]-\mathbb{E}_{x\sim\rho,y\sim\pi_{t}(\cdot|x)}[f_{t}(x,y)].
``` |  |

Thus, the size of it depends on the no-regret policy optimization update
in
[4](#alg1.l4 "In Algorithm 1 ‣ 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
of
[Algorithm 1](#alg1 "In 3 Self-Play with Adversarial Critic (SPAC) ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"),
and the derivation of its upper bound largely follows from the standard
analysis of policy mirror descent. Similar results can be found in [Xie
et al., 2021a ()](#bib.bib79) (Theorem C.5), and our lemma is a
modification of theirs to accommodate arbitrary initial policy initial
policy our setting.

#### D.2.1 [Lemma 4](#Thmlemma4 "Lemma 4. ‣ D.2.1 and Its Proof ‣ D.2 Bounding 𝐼_{𝑡,2} in ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models") and Its Proof

Define

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\ell_{x}(\pi)`$ | $`\displaystyle:=\eta D_{\mathrm{KL}}\big(\pi(\cdot|x)~||~\pi_{\mathrm{ref}}(\cdot|x)\big)`$ |  |
|  |  | $`\displaystyle=\eta\sum_{y\in\mathcal{Y}}\pi(y~|~x)\log\pi(y~|~x)-\eta\sum_{y\in\mathcal{Y}}\pi(y~|~x)\log\pi_{\mathrm{ref}}(y~|~x).`$ |  |

###### Lemma 4.

For any policy $`\pi:\mathcal{X}\to\Delta(\mathcal{Y})`$ and
$`x\in\mathcal{X}`$,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sum_{t=1}^{T}\big\langle\pi(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi)\leq\sum_{t=1}^{T}\big\langle\pi_{t+1}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi_{1}).`$ |  | (39) |

###### Proof.

We prove this lemma by induction. The base case $`T=0`$ trivially holds
since the KL divergence is always non-negative and is minimized when the
two probability distributions are the same. For the inductive step,
assuming the inductive hypothesis is true for $`T=T^{\prime}`$, we have
that for any $`\pi`$ and $`x\in\mathcal{X}`$,

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\quad\ \sum_{t=1}^{T^{\prime}+1}\big\langle\pi_{t+1}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi_{1})`$ |  |  |
|  |  | $`\displaystyle\overset{(\mathrm{i})}{\leq}\sum_{t=1}^{T^{\prime}+1}\big\langle\pi_{T^{\prime}+2}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi_{T^{\prime}+2})`$ |  |  |
|  |  | $`\displaystyle=\sum_{t=1}^{T^{\prime}}\big\langle\pi_{T^{\prime}+2}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi_{T^{\prime}+2})+\big\langle\pi_{T^{\prime}+2}(\cdot~|~x),f_{T^{\prime}+1}(x,\cdot)\big\rangle`$ |  |  |
|  |  | $`\displaystyle\overset{(\mathrm{ii})}{\leq}\sum_{t=1}^{T^{\prime}}\big\langle\pi_{t+1}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi_{1})+\big\langle\pi_{T^{\prime}+2}(\cdot~|~x),f_{T^{\prime}+1}(x,\cdot)\big\rangle`$ |  |  |
|  |  | $`\displaystyle=\sum_{t=1}^{T}\big\langle\pi(\cdot~|~x),f_{t}(x,\cdot)\rangle-\ell_{x}(\pi),`$ |  | (40) |

which is the advertised bound.

In the series of equalities and inequalities above, (ii) is by the
inductive hypothesis.

(i) can be obtained because $`\pi_{T^{\prime}+2}`$ is the global
maximizer of
$`\sum_{t=1}^{T^{\prime}+1}\big\langle\pi(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi)`$.
This can also be proven inductively following the proof for the Follow
the Regularized Leader (FTRL) algorithm in online learning, with the
analytical solution of the policy from DPO being the base case. ∎

#### D.2.2 [Lemma 5](#Thmlemma5 "Lemma 5. ‣ D.2.2 and Its Proof ‣ D.2 Bounding 𝐼_{𝑡,2} in ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models") and Its Proof

###### Lemma 5.

For any policy $`\pi:\mathcal{X}\to\Delta(\mathcal{Y})`$ and
$`x\in\mathcal{X}`$,

|  |  |  |
|----|----|----|
|  | $`\displaystyle\sum_{t=1}^{T}\big\langle\pi(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle\leq\sum_{t=1}^{T}\big\langle\pi_{t+1}(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi_{1})+\ell_{x}(\pi).`$ |  |

###### Proof.

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\quad\ \sum_{t=1}^{T}\big\langle\pi(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle`$ |  |  |
|  |  | $`\displaystyle=\sum_{t=1}^{T}\big\langle\pi(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi)+\ell_{x}(\pi)-\sum_{t=1}^{T}\big\langle\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle`$ |  |  |
|  |  | $`\displaystyle\leq\sum_{t=1}^{T}\big\langle\pi_{t+1}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi_{1})-\sum_{t=1}^{T}\big\langle\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle+\ell_{x}(\pi)`$ |  |  |
|  |  | $`\displaystyle=\sum_{t=1}^{T}\big\langle\pi_{t+1}(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi_{1})+\ell_{x}(\pi),`$ |  | (41) |

in which the penultimate step is by
[Lemma 4](#Thmlemma4 "Lemma 4. ‣ D.2.1 and Its Proof ‣ D.2 Bounding 𝐼_{𝑡,2} in ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models")
and the last step is by the non-positivity of $`\ell_{x}(\cdot)`$. ∎

#### D.2.3 [Lemma 6](#Thmlemma6 "Lemma 6. ‣ D.2.3 and Its Proof ‣ D.2 Bounding 𝐼_{𝑡,2} in ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models") and Its Proof

###### Lemma 6.

For any policy $`\pi:\mathcal{X}\to\Delta(\mathcal{Y})`$ and
$`x\in\mathcal{X}`$,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sum_{t=1}^{T}\big\langle\pi(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle\leq 2\eta R^{2}T+\frac{1}{\eta}D_{\mathrm{KL}}\big(\pi(\cdot~|~x)~||~\pi_{\mathrm{ref}}(\cdot~|~x)\big).`$ |  | (42) |

###### Proof.

First, let us define

|  |  |  |
|----|----|----|
|  |
``` math
L_{x,t}(\pi):=\sum_{t^{\prime}=1}^{t}\big\langle\pi(\cdot~|~x),f_{t^{\prime}}(x,\cdot)\big\rangle-\ell_{x}(\pi).
``` |  |

Denote the Bregman divergence with respect to $`L_{x,t}(\cdot)`$ with
$`B_{L_{x,t}}(\cdot||\cdot)`$ and similarly denote the Bregman
divergence with respect to $`\ell_{x}(\cdot)`$ with
$`B_{\ell_{x}}(\cdot||\cdot)`$. Notice

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle L_{x,t}(\pi_{t})`$ | $`\displaystyle=L_{x,t}(\pi_{t+1})+\big\langle\pi_{t}(\cdot~|~x)-\pi_{t+1}(\cdot~|~x),\nabla L_{x,t}(\pi)|_{\pi=\pi_{t+1}}\big\rangle+B_{L_{x,t}}(\pi_{t}(\cdot|x)~||~\pi_{t+1}(\cdot|x))`$ |  |  |
|  |  | $`\displaystyle\leq L_{x,t}(\pi_{t+1})+B_{L_{x,t}}(\pi_{t}(\cdot|x)~||~\pi_{t+1}(\cdot|x))`$ |  |  |
|  |  | $`\displaystyle=L_{x,t}(\pi_{t+1})-B_{\ell_{x}}(\pi_{t}(\cdot|x)~||~\pi_{t+1}(\cdot|x))`$ |  | (43) |

in which the first step is by the definition of Bregman divergence, the
second step is because $`\pi_{t+1}`$ is the global maximizer of
$`L_{x,t}(\cdot)`$ as we have mentioned in the proof of
[Lemma 4](#Thmlemma4 "Lemma 4. ‣ D.2.1 and Its Proof ‣ D.2 Bounding 𝐼_{𝑡,2} in ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"),
and the last step is because $`L_{x,t}(\pi)+\ell_{x}(\pi)`$ is linear in
$`\pi`$, which does not change the Bregman divergence.

The above inequalities further give

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle B_{\ell_{x}}(\pi_{t}(\cdot|x)~||~\pi_{t+1}(\cdot|x))`$ | $`\displaystyle\leq L_{x,t}(\pi_{t+1})-L_{x,t}(\pi_{t})`$ |  |  |
|  |  | $`\displaystyle=L_{x,t-1}(\pi_{t+1})-L_{x,t-1}(\pi_{t})+\big\langle\pi_{t+1}(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle`$ |  |  |
|  |  | $`\displaystyle\leq\big\langle\pi_{t+1}(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle,`$ |  | (44) |

in which the last inequality $`\pi_{t}`$ is the global maximizer of
$`L_{x,t-1}(\cdot)`$.

On the other hand, by the Taylor expansion and the mean value theorem,
we can write $`B_{\ell_{x}}`$ above as

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle B_{\ell_{x}}(\pi_{t}(\cdot|x)~||~\pi_{t+1}(\cdot|x))`$ | $`\displaystyle=\frac{1}{2}\|\pi_{t}(\cdot~|~x)-\pi_{t+1}(\cdot~|~x)\|^{2}_{\nabla^{2}_{\pi}\ell_{x}(\pi_{t}^{\prime})},`$ |  | (45) |

where $`\pi_{t}^{\prime}:=\alpha\pi_{t}+(1-\alpha)\pi_{t+1}`$ for some
$`\alpha\in[0,1]`$ and $`\nabla^{2}_{\pi}\ell_{x}(\pi_{t}^{\prime})`$ is
the Hessian of $`\ell_{x}(\pi)`$ with respect to $`\pi`$ at
$`\pi_{t}^{\prime}`$.

Finally, by the generalized Cauchy-Schwarz,

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\quad\ \big\langle\pi_{t+1}(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle`$ |  |  |
|  |  | $`\displaystyle\leq\|\pi_{t}(\cdot~|~x)-\pi_{t+1}(\cdot~|~x)\|_{\nabla^{2}_{\pi}\ell_{x}(\pi_{t}^{\prime})}\|f_{t}(x,\cdot)\|_{(\nabla^{2}_{\pi}\ell_{x})^{-1}(\pi_{t}^{\prime})}`$ |  |  |
|  |  | $`\displaystyle\overset{\mathrm{(i)}}{=}\sqrt{2B_{\ell_{x}}(\pi_{t}(\cdot|x)~||~\pi_{t+1}(\cdot|x))}\|f_{t}(x,\cdot)\|_{(\nabla^{2}_{\pi}\ell_{x})^{-1}(\pi_{t}^{\prime})}`$ |  |  |
|  |  | $`\displaystyle\leq\sqrt{\frac{2}{\eta}B_{\ell_{x}}(\pi_{t}(\cdot|x)~||~\pi_{t+1}(\cdot|x))}\|f_{t}(x,\cdot)\|_{\infty}`$ |  |  |
|  |  | $`\displaystyle\overset{\mathrm{(ii)}}{\leq}\sqrt{\frac{2}{\eta}\big\langle\pi_{t+1}(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle}\|f_{t}(x,\cdot)\|_{\infty}`$ |  |  |
|  |  | $`\displaystyle\overset{\mathrm{(iii)}}{\leq}R\sqrt{\frac{2}{\eta}\big\langle\pi_{t+1}(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle},`$ |  | (46) |

in which (i) is by
[Eq. 45](#A4.E45 "In Proof. ‣ D.2.3 and Its Proof ‣ D.2 Bounding 𝐼_{𝑡,2} in ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"),
(ii) is by
[Eq. 44](#A4.E44 "In Proof. ‣ D.2.3 and Its Proof ‣ D.2 Bounding 𝐼_{𝑡,2} in ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"),
and (iii) is by
[Assumption 1](#Thmassumption1 "Assumption 1 (Realizable, bounded reward). ‣ 4 Theoretical Guarantees of SPAC ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models").

This immediately implies

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\big\langle\pi_{t+1}(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle\leq\frac{2R^{2}}{\eta}.`$ |  | (47) |

By
[Lemma 5](#Thmlemma5 "Lemma 5. ‣ D.2.2 and Its Proof ‣ D.2 Bounding 𝐼_{𝑡,2} in ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models"),
we have

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\quad\ \sum_{t=1}^{T}\big\langle\pi(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle`$ |  |  |
|  |  | $`\displaystyle\leq\sum_{t=1}^{T}\big\langle\pi_{t+1}(\cdot~|~x)-\pi_{t}(\cdot~|~x),f_{t}(x,\cdot)\big\rangle-\ell_{x}(\pi_{1})+\ell_{x}(\pi)`$ |  |  |
|  |  | $`\displaystyle\leq\frac{2R^{2}T}{\eta}+\eta D_{\mathrm{KL}}\big(\pi(\cdot~|~x)~||~\pi_{\mathrm{ref}}(\cdot~|~x)\big),`$ |  | (48) |

where the last step is by
[Eq. 47](#A4.E47 "In Proof. ‣ D.2.3 and Its Proof ‣ D.2 Bounding 𝐼_{𝑡,2} in ‣ Appendix D Proof of ‣ Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models").

At this point, we have arrived at the advertised bound. ∎
````
