###### Abstract

Autonomous AI agents pair a frozen base model with an editable _harness_
of prompts, skills, tool rules, and memory. Recursive self-improvement
(RSI) adapts this harness from experience without weight updates, yet
self-editing without external graders often backfires: reflection and
scalar scores conflate _what an edit newly broke_ with _what remains
unsolved_, causing local regressions, skill forgetting, and memory
bloat. We introduce GUARD (_Grader-free Unsupervised Environment Design
\[UED\] with Adaptive Rule Distillation_), a closed-loop framework for
reference-free continual harness evolution. Our key insight is to
decompose each task into pre-execution self-checks and guide harness
updates via _directional regret_. Each round grades trajectories against
these checks, pinning mastered rules while prioritizing newly broken
behaviors, and selects among parallel candidate edits by critic-free
group-relative fitness. A _Soft-HURT_ gate then promotes an edit only
when gains outweigh regressions, scoping specialized fixes to prevent
over-triggering and guaranteeing non-regression on its gated buffer. At
test time, one frozen harness runs in a single pass. Across benchmarks
on memory, skill evolution, continual task streams, and domain
reasoning, GUARD consistently improves performance without catastrophic
forgetting or memory pollution while substantially cutting deployment
token usage.

## 1 Introduction

Modern language model agents combine a frozen base model with a
surrounding _harness_ of prompts, reusable skills, tool interfaces,
memory, and control logic \[31, 42, 20, 45\]. In practice, this harness
decides whether the same model checks the right state before acting,
calls tools with valid arguments, recovers from failed commands, and
carries useful rules across sessions \[52, 40\]. Much recent progress in
deployed agents comes from _harness engineering_, yet tuning harnesses
by hand scales poorly: engineers can inspect only a small slice of
failed runs, and fixed designs quickly go stale as tools, schemas, and
user workflows change \[5, 49\]. _Recursive self-improvement_ (RSI) aims
to automate this loop by turning past experience into persistent edits
that improve future runs \[54, 38, 44, 26\]. Because frontier models
often sit behind black-box APIs with frozen weights and open-world tasks
rarely provide ground-truth rewards for weight-space reinforcement
learning \[60, 62, 13, 46\], treating the editable harness as a
non-parametric policy around the frozen model offers a practical,
inspectable way to improve agents after deployment \[23, 36\].

gating are turned off, deploying the single frozen harness for standard
single-run evaluation (pass@1 on all primary benchmarks, matching the
base agent’s rollout budget).

Early automated methods search over prompts or agent code offline using
labeled training splits before deployment \[18, 12, 55, 58, 20\]. The
resulting static harnesses struggle when test-time tasks shift. Newer
approaches regularize offline search for out-of-distribution
generalization \[45\], probe per-task harnesses online while saving
reusable lessons \[49\], or append reflections and skills across
episodes \[59, 30, 50, 1\]. Yet continually updating a single persistent
harness across rounds without reference answers or external graders
often degrades performance over time \[5\]. Because every edit changes
subsequent rollouts, free-form reflection and scalar task scores mix two
distinct failure signals: behaviors the latest edit _newly broke_ and
capability gaps the agent _still has not solved_. Mixing these signals
across rounds causes three failure modes: _local overfitting_
(_over-triggering_), where a broad rule written for recent failures
breaks tasks that already worked; _catastrophic forgetting_, where
shifts in workflow, topic, or domain overwrite earlier skills \[5\]; and
_memory pollution_, where unverified additions accumulate stale or
conflicting rules that bloat the prompt. Over multiple rounds,
self-editing can leave an agent worse than its starting point (Figure
1).

Central Question. How can an autonomous agent continually improve its
persistent harness in a reference-free setting without interfering with
or catastrophically forgetting previously learned skills?

We address this challenge by casting harness adaptation around a frozen
model as gradient-free policy optimization in text space, guided by two
ideas from reinforcement learning: curriculum regret from unsupervised
environment design (UED) \[7, 14, 15, 35\] and critic-free
group-relative scoring from Group Relative Policy Optimization (GRPO)
\[37, 3\]. We never update the model weights or train a value critic:
the harness is the only part of the policy that changes (§2). We
implement this approach in GUARD (_Grader-free UED with Adaptive Rule
Distillation_; Figure 2, §4). Before executing a task, GUARD compiles
the task prompt and tool schema into a fixed checklist of atomic binary
checks (§4.1) and grades completed runs with a two-layer (sandbox
execution plus semantic trace) self-reviewer, because checking one
requirement on a finished trace is simpler than satisfying every
constraint during generation. Across rounds, Analyze (§4.2) pins
criteria that stay satisfied and ranks newly broken criteria ahead of
unsolved gaps; Propose (§4.3) samples a parallel group of candidate
edits, scores them against each other on the same tasks, and contrasts
the best and worst candidates to rewrite its proposal prompts; and Gate
(§4.4) promotes the winner only when its gains exceed induced
regressions (_Soft-HURT_), narrowing rules that cause isolated drops
with \[iff\] preconditions and logging rejected edits. At test time,
candidate pooling, self-review, and gating are turned off, and the agent
runs a single pass (pass@1) with its frozen harness.

Three choices separate GUARD from prior harness learners. Reflexion and
GEPA update from free-form reflection or scalar and Pareto scores, so
they cannot tell a new regression from an old gap; GUARD ranks checklist
criteria by paired directional regret. Meta-Harness searches agent code
against raw trace archives, and RRSI rewrites one candidate per round
behind a score-band gate that leaves per-task drops unbounded; GUARD
scores a parallel group of candidates on the same tasks and promotes the
winner only when its gains exceed induced regressions, narrowing rules
with \[iff\] preconditions instead of deleting them. We evaluate GUARD
across four benchmark settings (§5–§6, Appendix C): PAST-Bench \[50\],
EvoHarnessBench \[17\], Drift Gauntlet \[5\], and professional legal and
financial reasoning suites \[2, 16, 27\]. Our contributions are
threefold:

- •
  Trace-grounded checklist self-review and directional regret (Analyze,
  §2–§4.2). We formulate reference-free harness adaptation over a frozen
  model using paired directional regret on pre-execution task
  checklists. We prove that dense checklist grading removes the
  $`1/\epsilon`$ passive-discovery penalty on rare task invariants
  (Theorem 2), that paired priority ranks every fresh regression above
  every non-regressed criterion in the single-rollout binary case and
  pins exactly the mastered criteria (Proposition 1), and that gating
  keeps self-review scores non-decreasing on each round’s gated task
  buffer (Theorem 1).
- •
  GRPO-inspired candidate pooling and contrastive prompt evolution
  without weight updates (Propose, §4.3). Inspired by group-relative
  reinforcement learning \[37, 3\], GUARD samples a parallel group of
  candidate harnesses from one domain-agnostic seed prompt, evaluates
  them on the same task batch, and ranks them by critic-free
  group-standardized fitness (a selection step, not a gradient step)
  while contrasting the best and worst group candidates to rewrite
  proposal prompts across rounds. In a controlled single-model ablation
  at equal budget, parallel two-candidate pooling beats sequential
  single-candidate search and cuts rejected gate rounds by $`64\%`$,
  while deploying a single harness in one pass at test time.
- •
  Soft-HURT promotion gating and continual generalization (Gate, §4.4,
  §6, Appendix C). Pairing Soft-HURT promotion with in-round \[iff
  \<condition\>\] precondition repair yields $`19/19`$ non-regressive
  execution-gated promotions across EvoHarnessBench, Drift Gauntlet, and
  the professional suites. GUARD is the only evaluated method with no
  negative backward or forward transfer on hosted EvoHarnessBench (FWT
  is zero because the gate abstained at later stages) and cuts tokens
  per task by $`54.5\%`$ versus the base agent, incurs no stream-mean
  drop across all $`12`$ block transitions and zero post-block
  forgetting on all four Drift Gauntlet streams, and ties the
  memory-pollution floor on PAST-Bench.

## 2 Background and Problem Formulation

#### Agents, harnesses, and task streams.

We model an autonomous agent $`A=(\pi_{\theta},W_{t,g})`$ as a frozen
language model policy $`\pi_{\theta}`$ paired with an inspectable
_harness state_ $`W_{t,g}`$ at adaptation round $`t\in\{0,1,\dots,T\}`$
($`W_{0,g}`$ empty; subscript $`g`$ omitted when clear) \[20, 45\].
Tasks arrive from groups $`g\in\mathcal{G}`$ indexing roles, task
families, or, when a continual stream hides group labels and drift
boundaries \[5\], the pre-execution (_Turn-0_, before the solver’s first
action) observable tool and schema signature of query
$`q\in\mathcal{Q}_{g}`$. We call $`W_{t,g}`$ a _non-parametric_ policy
component because it is editable text rather than model weights:
conditioning on it steers rollouts
$`\tau\sim\pi_{\theta}(\cdot\mid q,W_{t,g})`$, while $`\theta`$ stays
fixed during both adaptation and testing. In reinforcement-learning
terms, an action is a harness edit, its reward is the gated self-review
fitness $`R_{m}`$ (§4.3), and only $`W`$ is optimized. While this
formulation accommodates general text or code harnesses \[26\], we
instantiate $`W_{t,g}`$ as structured Markdown files, termed a _harness
playbook_, organizing workflow instructions, entity-grouped domain
rules, reusable skills (SKILL.md), persistent memories (MEMORY.md), and
optional pre-submit checks, with specialized exceptions scoped by
explicit \[iff \<condition\>\] preconditions.

#### Reference-free continual evolution and non-regressive RSI.

Let $`V^{\star}(q,\tau)\in[0,100]`$ denote the unobserved task
evaluator, unavailable throughout adaptation. Observing only task
prompts, tool interfaces, execution trajectories, and runtime states in
interaction history $`\mathcal{H}_{t,g}`$, a reference-free harness
_evolver_ $`\mathcal{E}`$ recursively updates the incumbent across
adaptation rounds:

```math
W_{t,g}\;=\;\mathcal{E}\big(W_{t-1,g},\,\mathcal{H}_{t,g}\big),\hskip 18.49988ptt=1,\dots,T\leq T_{\max}. \tag{1}
```

At test time, evolution freezes and each unseen query
$`q\in\mathcal{Q}_{g}`$ executes under the single promoted harness
$`W_{T,g}`$ to maximize
$`\mu_{g}(W_{T,g})=\mathbb{E}_{q\in\mathcal{Q}_{g},\,\tau\sim\pi_{\theta}(\cdot\mid q,W_{T,g})}[V^{\star}(q,\tau)]`$.
Because $`\mathcal{E}`$ updates $`W_{t,g}`$ adaptively from finite
online rollouts without $`V^{\star}`$, continual generalization under
Eq. (1) requires improving $`\mu_{g}`$ without local overfitting on
solved tasks or catastrophic forgetting of mastered behaviors as $`t`$
and task distributions shift \[45, 5\]: scalar round scores mix
edit-induced regressions with unresolved capability gaps and compound
negative transfer across rounds.

#### What reference-free does and does not mean.

Throughout this paper, _reference-free_ (and _grader-free_) is an
operational constraint on the adaptation loop $`\mathcal{E}`$: neither
the solver, the self-reviewer, nor the distiller ever accesses held-out
reference answers, test cases, hidden verifiers $`V^{\star}`$, oracle
skills, or official grading rubrics. It does _not_ mean learning from
zero supervision. Specifically, adaptation draws on four observable
sources of structure: (i) benchmark-authored training task prompt
distributions, (ii) public tool declarations and environment schemas,
(iii) the agent’s own interaction trajectories and observable sandbox
states (with no human expert demonstrations), and (iv) structured
criterion-level judgments from the language-model self-reviewer (§4.1).

## 3 Related Work

Table B.1 (Appendix B.1) compares GUARD with representative
self-improvement methods and environments across the components they
optimize, their closed-loop mechanisms, and their adaptation and context
scalability.

#### Verbal reflection, memories, and playbooks.

Reflexion \[38\], ExpeL \[59\], ReasoningBank \[30\], and AWM \[43\]
store verbal reflections or workflows; MemGPT \[31\], Voyager \[42\],
and WikiSkill \[40\] maintain memories, skill libraries, and append-only
wikis; Dynamic Cheatsheet \[39\] and ACE \[56\] incrementally update
playbooks; and Context Language Models (CLM) \[36\] update model weights
to compact context via Group Relative Policy Optimization (GRPO) \[37\],
whereas Training-Free GRPO \[3\] summarizes group rollouts into an
experience library with frozen weights. GUARD differs in what forms the
group: it scores $`M`$ candidate harnesses on the same task batch rather
than rollouts of one fixed context, contrasts the best and worst
candidates to rewrite proposal prompts, and accepts the winner only
through a regression-aware gate. AutoGuide \[9\], AutoManual \[4\], and
CLIN \[24\] distill conditional guidelines, rule manuals, or causal
memories from experience; GUARD’s \[iff\] rules are likewise
conditional, but enter the harness only through regression-aware ranking
and gating. Because these updates neither isolate edit-induced
regressions nor gate per-task drops, they remain vulnerable to the
plasticity–pollution and plasticity–stability trade-offs measured by
PAST-Bench \[50\], EvoHarnessBench \[17\], and Drift Gauntlet \[5\].
Accepting an update only when prior behavior does not degrade echoes
regression-free model updates \[47\] and gradient-constrained continual
learning \[21\], which rely on labels or gradients that a reference-free
harness loop does not have.

#### Unsupervised environment design and zero-data RL.

UED \[7, 14, 15\] prioritizes high-regret POMDP levels via antagonist
regret (PAIRED \[7\]), maximal Monte Carlo (MaxMC) regret \[14, 15,
32\], or learnability $`p(1-p)`$ \[35\], whereas we transfer regret from
level curation to directional criterion ranking over pre-execution task
checklists \[61\] without an antagonist. Zero-data RL self-play
(Absolute Zero \[60\], Self-Challenging Agents \[62\], R-Zero \[13\],
and Agent0 \[46\]) eliminates human labels via code verifiers or
majority voting, yet requires weight gradients (precluding black-box
APIs), falters on stateful tool mutations, and updates opaque model
weights instead of inspectable conditional rules.

#### Prompt, workflow, and harness optimization.

Prompt optimizers such as DSPy \[18\], TextGrad \[53\], TextReg \[10\],
OPRO \[51\], WizardLM \[48\], Promptbreeder \[8\], EvoPrompt \[11\], and
GEPA \[1\] search instructions via scalar objectives, textual gradients,
or Pareto archives; TextReg \[10\] filters low-recurrence patches under
labeled single-turn supervision, which can suppress valid edge-case
exceptions. Workflow/code optimizers ADAS \[12\], AFlow \[55\], and
Darwin Gödel Machine (DGM) \[58\] mutate code via archives \[19, 28\] or
MCTS against validation ground truth, while AutoHarness \[22\],
Self-Harness \[57\], Meta-Harness \[20\], RRSI \[45\], and Harness²
\[49\] evolve harnesses around frozen weights (alongside MLGym \[29\],
PostTrainBench \[34\], RSIBench-Data \[25\], and RSIGym \[26\]). Among
open-world designs, Harness² probes per-task harnesses online from
$`W_{0}`$ at extra test-time rollout cost, RRSI’s score-band gate leaves
per-task drops unbounded, and persistent harnesses (ReasoningBank, GEPA,
Meta-Harness) suffer severe forgetting under hidden drift \[5\]. GUARD
instead evolves a single persistent harness in a reference-free loop and
deploys it at $`O(1)`$ context in $`T`$ and single-pass (pass@1) test
cost (Appendix B.5).

## 4 GUARD: Regret-Guided Harness Evolution

During adaptation, GUARD instantiates the reference-free evolver
$`\mathcal{E}`$ in Eq. (1) as a four-stage closed loop (Figure 2;
Algorithm 1; constants in Appendix B): pre-execution checklist
derivation and two-layer self-review (§4.1), paired regret ranking
(Analyze, §4.2), contrastive candidate pooling (Propose, §4.3), and
Soft-HURT promotion (Gate, §4.4), with formal guarantees in §4.5. At
test time, this adaptation loop is disabled and each unseen task runs a
single rollout under the frozen harness $`W_{T,g}`$.

### 4.1 Reference-Free Self-Review via Task Checklists

#### Pre-execution task checklist $`\mathcal{C}(q)`$.

Extending IFEval’s verifiable constraint decomposition \[61\] and
checklist-based evaluation \[33, 6, 41\] to multi-turn tool workflows,
the self-reviewer reads _only_ the task prompt, visible tool
declarations, and schema once at Turn 0 (before the solver’s first
action) to derive and cache a fixed checklist $`\mathcal{C}(q)`$ of
atomic binary predicates (_criteria_ $`c\in\mathcal{C}(q)`$; Appendix B)
across two classes: (i) _execution-verifiable_ predicates (clean sandbox
execution, valid entity IDs/columns, idempotent mutations) and (ii)
_semantic_ predicates (honoring every prompt constraint, recipient,
format, and safety rule without applying superseded rules).

#### Two-layer grading and verification asymmetry.

Layer 1 checks execution predicates deterministically on an ephemeral
sandbox copy; Layer 2 grades semantic predicates individually from the
prompt, output, and tool/state trace, returning $`r(\tau,c)\in\{0,1\}`$
and a failure rationale. Over graded predicates
$`\mathcal{C}^{\mathrm{gr}}(\tau)\subseteq\mathcal{C}(q)`$
($`|\mathcal{C}^{\mathrm{gr}}(\tau)|\geq 1`$; unconfigured checks
excluded; an unparseable verdict counts as failed or falls back to
deterministic trace checks), trajectory $`\tau`$ receives criterion
score $`S(\tau)`$ and strict score $`S^{\mathrm{strict}}(\tau)`$:

```math
\displaystyle S(\tau) \displaystyle=100\cdot\frac{1}{|\mathcal{C}^{\mathrm{gr}}(\tau)|}\sum_{c\in\mathcal{C}^{\mathrm{gr}}(\tau)}r(\tau,c), \tag{2}
```

```math
\displaystyle S^{\mathrm{strict}}(\tau) \displaystyle=\begin{cases}0&\text{on a blocking sandbox error,}\\
100&\text{if all graded criteria pass,}\\
S(\tau)/2&\text{otherwise.}\end{cases}
```

Pre-execution decomposition uses _generation–verification asymmetry_:
long-horizon generation couples $`N`$ constraints and suffers
“seen-but-not-carried” omissions, while checking one atomic predicate
after execution requires localized $`O(1)`$ attention grounded by Layer
1 sandbox states. Cross-task $`\Delta_{\mathrm{hurt},t}`$ and Soft-HURT
gating then prevent single-instance overfitting \[23\].

### 4.2 Paired Regret Ranking (Analyze Stage)

###### Definition 1 (Criterion obedience and paired regret).

For trajectories $`\mathcal{T}_{c}(W)`$ grading criterion $`c`$ under
$`W`$ ($`\mathcal{T}_{c}(W_{t-1})=\emptyset`$ skipped), criterion
obedience is

```math
\mathrm{obey}(c;W)\;=\;\frac{1}{|\mathcal{T}_{c}(W)|}\sum_{\tau\in\mathcal{T}_{c}(W)}r(\tau,c)\;\in\;[0,1]. \tag{3}
```

Entering round $`t\geq 1`$ with incumbent $`W_{t-1}`$, comparing the two
most recent incumbents $`W_{t-2}`$ and $`W_{t-1}`$ on the same tasks
gives:

```math
\displaystyle\Delta_{\mathrm{hurt},t}(c) \displaystyle=\max\!\big(0,\;\mathrm{obey}(c;W_{t-2})-\mathrm{obey}(c;W_{t-1})\big), \tag{4}
```

```math
\displaystyle\Delta_{\mathrm{gap},t}(c) \displaystyle=1-\mathrm{obey}(c;W_{t-1}),
```

```math
\displaystyle\mathrm{Priority}_{t}(c) \displaystyle=\Delta_{\mathrm{hurt},t}(c)+\Delta_{\mathrm{gap},t}(c)\;\in\;[0,2],
```

where $`\Delta_{\mathrm{hurt},t}(c)=0`$ if $`t=1`$ or $`c`$ is not
graded under both compared playbooks.

Both terms are non-negative and parameter-free: a regressed criterion
receives its incumbent gap plus its drop, outranking equally obeyed
non-regressed criteria (Proposition 1); with one binary verdict per
criterion after a promotion, $`\mathrm{Priority}_{t}(c)\in\{2,1,0\}`$
separates regressions ($`1\to 0`$), unsolved gaps ($`0\to 0`$), and
mastered checks ($`1\to 1`$ or $`0\to 1`$). In regret terms,
$`\Delta_{\mathrm{gap},t}`$ is the incumbent’s shortfall against an
oracle harness that satisfies every criterion, and
$`\Delta_{\mathrm{hurt},t}`$ is the negative transfer introduced by the
latest promotion.

#### Rejected rounds, diagnostic lists, and trajectory contrasts.

After a rejection ($`W_{t-1}=W_{t-2}`$), execution scoring instead takes
$`\Delta_{\mathrm{hurt},t}`$ from $`W_{t-1}`$ to the rejected winner
$`\widetilde{W}_{t-1}`$ (or its repair
$`\widetilde{W}^{\mathrm{rep}}_{t-1}`$), so the next proposal sees which
criteria the refused edit broke, while $`\Delta_{\mathrm{gap},t}`$ and
pinning stay anchored to the incumbent; critic scoring always compares
consecutive incumbents (§5). The signs of the two terms split criteria
in the regret bundle $`\mathcal{B}_{t,g}`$ into three diagnostic lists,
each sorted by descending $`\mathrm{Priority}_{t}(c)`$ (ties broken by
$`\Delta_{\mathrm{hurt},t}(c)`$): (1) _Regressed_
($`\Delta_{\mathrm{hurt},t}>0`$), asking the proposer to wrap offending
rules in \[iff \<trigger\>\] preconditions instead of discarding
specialized fixes \[10\]; (2) _Unsolved Gap_
($`\Delta_{\mathrm{hurt},t}=0,\Delta_{\mathrm{gap},t}>0`$), targeting
persistent gaps; and (3) _Mastered_ ($`\mathrm{Priority}_{t}=0`$, i.e.,
$`\mathrm{obey}(c;W_{t-1})=1\land\Delta_{\mathrm{hurt},t}=0`$), pinning
obeyed rules against overwriting. These lists serve as diagnostic
annotations, not hand-coded edit operators: the proposer receives them
with the incumbent, trajectory contrasts, and the ledger window, and
writes candidate playbooks end-to-end. Finally, on tasks with differing
scored rollouts, $`\mathcal{B}_{t,g}`$ pairs top and bottom trajectories
$`(\tau^{+},\tau^{-})`$ (ordered by $`S^{\mathrm{strict}}`$, ties by
$`S`$) whenever

```math
\displaystyle\Delta^{\mathrm{strict}}(\tau^{+},\tau^{-})=S^{\mathrm{strict}}(\tau^{+})-S^{\mathrm{strict}}(\tau^{-})>0 \tag{5}
```

```math
\displaystyle\lor \displaystyle\Delta^{\mathrm{cont}}(\tau^{+},\tau^{-})=S(\tau^{+})-S(\tau^{-})\geq\delta_{\mathrm{con}},
```

($`\delta_{\mathrm{con}}=10`$). This condition captures partial
checklist progress even when blocking errors or critical caps flatten
$`S^{\mathrm{strict}}`$.

### 4.3 Group-Relative Candidate Pooling and Contrastive Evolution (Propose Stage)

In reinforcement learning, Group Relative Policy Optimization (GRPO)
\[37\] estimates policy advantage without a value network by sampling a
group of rollouts from a shared state and standardizing their rewards
within the group. Following the training-free group-relative perspective
\[3\], the Propose stage applies this principle to non-parametric
harness optimization without updating model weights: it samples
$`M\geq 2`$ candidate harnesses in parallel from
$`(W_{t-1,g},\mathcal{B}_{t,g})`$, selects the winner by within-group
standardized fitness ($`\arg\max_{m}\hat{A}_{m}`$), and contrasts the
best and worst group candidates ($`\mathsf{ContrastEvolve}`$) to update
the strategy-prompt pool $`\mathcal{P}_{t,g}=\{s_{t,1},\dots,s_{t,M}\}`$
across rounds. Unlike GRPO, GUARD takes no gradient step and uses no
clipping or KL penalty; $`\hat{A}_{m}`$ only ranks candidates and picks
the contrast pair $`(m^{+},m^{-})`$, and the Soft-HURT gate (§4.4) plays
the role of a trust region. What the group buys is credit isolation
without a learned critic: all $`M`$ candidates are scored on the same
$`(W_{t-1,g},\mathcal{B}_{t,g},\mathcal{Q}_{g})`$, so batch-level task
difficulty cancels out.

#### Uniform initialization and scoring.

Round 1 initializes all $`M`$ parallel candidates with the same
domain-agnostic prompt $`s_{0}`$ (SHARED_SEED_PROMPT, Appendix B.4):

```math
\mathcal{P}_{1,g}\;=\;\{s_{1,1},\dots,s_{1,M}\},\qquad s_{1,1}=\dots=s_{1,M}=s_{0}, \tag{6}
```

drawing diversity without operator priors from sampling
$`\widetilde{W}^{(m)}_{1,g}=\mathsf{Distill}(s_{0},\mathcal{B}_{1,g},W_{0,g})`$.
Over $`N_{\mathrm{rep}}\geq 1`$ replicates
$`\{\tau_{q,r}\}_{r=1}^{N_{\mathrm{rep}}}`$ and noise floor
$`\delta_{\mathrm{noise}}\geq 0`$, task scores and helped/hurt sets are

```math
\displaystyle S_{q}(W) \displaystyle=\frac{1}{N_{\mathrm{rep}}}\sum_{r=1}^{N_{\mathrm{rep}}}S(\tau_{q,r}), \tag{7}
```

```math
\displaystyle S^{\mathrm{strict}}_{q}(W) \displaystyle=\frac{1}{N_{\mathrm{rep}}}\sum_{r=1}^{N_{\mathrm{rep}}}S^{\mathrm{strict}}(\tau_{q,r}),
```

```math
\displaystyle\mathcal{Q}^{\pm}(\widetilde{W},W) \displaystyle=\big\{q\in\mathcal{Q}_{g}:\pm\big(S_{q}(\widetilde{W})-S_{q}(W)\big)>\delta_{\mathrm{noise}}\big\},
```

with means $`\bar{S}(W),\bar{S}^{\mathrm{strict}}(W)`$ supplied by
_execution scoring_ ($`M`$ group rollouts/round) or _critic scoring_
(one joint pass over accumulated trajectories on stateful suites). With
$`\mathrm{Perf}_{m}=\bar{S}^{\mathrm{strict}}(\widetilde{W}^{(m)}_{t})+\tfrac{1}{4}\bar{S}(\widetilde{W}^{(m)}_{t})`$
and
$`\mathcal{Q}^{\pm}_{m}=\mathcal{Q}^{\pm}(\widetilde{W}^{(m)}_{t},W_{t-1})`$,
scalar and standardized fitness are

```math
\displaystyle R_{m} \displaystyle=\mathrm{Perf}_{m}-\beta\,|\mathcal{Q}^{-}_{m}|+\gamma\,|\mathcal{Q}^{+}_{m}|,\hskip 18.49988pt\beta>\gamma\geq 0, \tag{8}
```

```math
\displaystyle\hat{A}_{m} \displaystyle=\big(R_{m}-\mu_{R}\big)\big/\sigma_{R},
```

```math
\displaystyle\sigma_{R} \displaystyle=\sqrt{\tfrac{1}{M}\textstyle\sum_{m=1}^{M}(R_{m}-\mu_{R})^{2}}+10^{-6},
```

($`\mu_{R}=\frac{1}{M}\sum_{m}R_{m}`$), where $`\beta>\gamma`$ penalizes
hurts over helps and
$`m^{\star}=\arg\max_{m}\hat{A}_{m}=\arg\max_{m}R_{m}`$ selects
$`\widetilde{W}_{t}=\widetilde{W}^{(m^{\star})}_{t}`$ (with $`M=2`$,
$`\hat{A}_{m}\approx\pm 1`$ whenever $`R_{1}\neq R_{2}`$, so selection
keeps the higher-fitness candidate).

#### Contrastive prompt evolution, deployment, and complexity.

Selecting distinct best and worst candidates in the group,

```math
m^{+}=\arg\max_{m\in\{1,\dots,M\}}R_{m},\qquad m^{-}=\arg\min_{m\neq m^{+}}R_{m} \tag{9}
```

(ties broken by $`\bar{S}`$, $`|\mathcal{Q}^{-}_{m}|`$, candidate index;
mirroring MaxMC spread \[15\]), $`\mathsf{ContrastEvolve}`$ scrubs task
IDs to \<TASK*ID\>, contrasts
$`(s*{t,m^{\pm}},\widetilde{W}^{(m^{\pm})}_{t,g},R_{m^{\pm}},|\mathcal{Q}^{\pm}_{m^{\pm}}|)`$,
and outputs learnings, an exploitation prompt $`s^{+}_{t+1}`$, and a
precondition-narrowing prompt $`s^{-}\_{t+1}`$, updating

```math
\mathcal{P}_{t+1,g}\;=\;\{s^{+}_{t+1}\}^{\lfloor M/2\rfloor}\;\cup\;\{s^{-}_{t+1}\}^{M-\lfloor M/2\rfloor}. \tag{10}
```

At test time, $`\mathcal{P}_{t,g}`$, the self-reviewer, and
$`\mathcal{L}_{g}`$ are discarded: deployment runs a single
($`1\times`$) rollout per task (pass@1 on all primary benchmarks) under
frozen $`W_{T,g}`$. During adaptation, parallel $`M`$-candidate pooling
isolates credit on identical
$`(W_{t-1,g},\mathcal{B}_{t,g},\mathcal{Q}_{g})`$, bootstraps Round-1
contrasts, and reduces single-sample gate rejections (§6.4, Appendix
C.4). Execution scoring costs $`O(TMQ)`$ rollouts with $`O(TQ)`$
parallel rollout depth (or $`O(TQ)`$ online rollouts under critic
scoring), while bounded playbooks $`B_{W}`$, ledger window $`L_{\max}`$,
and capped bundles $`B_{\mathcal{B}}`$ keep proposer and test context
$`O(1)`$ in $`T`$ (Table B.1, Appendix B.5).

#### Soft-HURT promotion gate.

Using per-task scores $`S_{q}`$ and hurt set
$`\mathcal{Q}^{-}(\widetilde{W},W)`$ from (7), the group-averaged
regression penalty beyond $`\delta_{\mathrm{noise}}`$ is

```math
\mathrm{Hurt}(\widetilde{W},W)=\frac{1}{|\mathcal{Q}_{g}|}\sum_{q\in\mathcal{Q}^{-}(\widetilde{W},W)}\big(S_{q}(W)-S_{q}(\widetilde{W})\big), \tag{11}
```

and the Soft-HURT rule promotes a candidate over $`W_{t-1}`$ only when
net gain exceeds induced hurt:

```math
\displaystyle\mathrm{Promote}(\widetilde{W},W_{t-1})\iff \tag{12}
```

```math
\displaystyle\bar{S}(\widetilde{W})-\bar{S}(W_{t-1})>\mathrm{Hurt}(\widetilde{W},W_{t-1}).
```

Parameterized by single-task noise floor
$`\delta_{\mathrm{noise}}\geq 0`$, hurt-task budget $`h_{\max}\geq 0`$,
and trade-off margin $`\mu_{\min}\geq 0`$, Soft-HURT admits
$`\widetilde{W}_{t}`$ when
$`|\mathcal{Q}^{-}(\widetilde{W}_{t},W_{t-1})|\leq h_{\max}`$,
$`|\mathcal{Q}^{+}(\widetilde{W}_{t},W_{t-1})|\geq\mathbb{I}[|\mathcal{Q}^{-}(\widetilde{W}_{t},W_{t-1})|>0]`$,
and

```math
\displaystyle\bar{S}(\widetilde{W}_{t})-\bar{S}(W_{t-1})> \tag{13}
```

```math
\displaystyle\max\!\big(\mathrm{Hurt}(\widetilde{W}_{t},W_{t-1}),\,\mu_{\min}\,\mathbb{I}[|\mathcal{Q}^{-}(\widetilde{W}_{t},W_{t-1})|>0]\big).
```

When $`\widetilde{W}_{t}`$ fails solely due to isolated regressions
($`1\leq|\mathcal{Q}^{-}(\widetilde{W}_{t},W_{t-1})|\leq h_{\mathrm{rep}}`$),
GUARD triggers at most one in-round \[iff\] scope-guard repair
$`\widetilde{W}^{\mathrm{rep}}_{t}`$ and promotes
$`\widetilde{W}^{\mathrm{rep}}_{t}`$ if its re-scored trajectories
satisfy the same Soft-HURT rule ($`\mu_{\min}=0`$ on repaired
candidates; suite parameters in Appendix B). Any other candidate is
rejected, so every promoted update obeys (12).

#### Rejection ledger and stopping.

Rejected gate decisions log deduplicated active entries to
$`\mathcal{L}_{g}`$ (an on-disk JSONL log; candidate-level runners store
gate metrics and scrubbed rule excerpts with read-back cap
$`L_{\max}\in\{12,40\}`$, while the professional-suite runner stores
active criterion-removal excerpts; Appendix B), rendered into
$`\mathcal{B}_{t+1,g}`$ at $`O(1)`$ prompt cost in $`T`$ so refused
edits are not repeated verbatim while \[iff\] refinements remain
eligible. Rejected candidates are never re-executed
($`\Delta_{\mathrm{hurt},t+1}`$ reuses their gate scores), and optional
early stopping is disabled in all reported runs.

### 4.5 Theoretical Guarantees

These results characterize the self-review objective on gated task
buffers; held-out accuracy is evaluated empirically in §6. Proofs of
Theorem 1, Theorem 2, and Proposition 1 appear in Appendix A. For
Theorem 1, fix group $`g\in\mathcal{G}`$ with fixed $`\mathcal{Q}_{g}`$:
conditional on prior history, replicate errors
$`\{S(\tau_{q,r})-\mu_{q}(W)\}_{q\in\mathcal{Q}_{g},\,r\leq N_{\mathrm{rep}}}`$
($`N_{\mathrm{rep}}\geq 1`$ under execution rollouts) are independent
across $`q,r`$ and $`\sigma`$-sub-Gaussian (mean $`\bar{S}(W)`$,
expectation
$`\mu(W)=\frac{1}{|\mathcal{Q}_{g}|}\sum_{q\in\mathcal{Q}_{g}}\mu_{q}(W)`$).
Over $`T_{\max}`$ rounds, at most
$`n_{\mathrm{eval}}=1+T_{\max}(M+\mathbb{I}_{\mathrm{rep}})`$ candidate
harnesses are evaluated per group
($`\mathbb{I}_{\mathrm{rep}}\in\{0,1\}`$ for in-round \[iff\] repair)
against recorded incumbent scores without re-running incumbents; let
$`\Delta_{t}=\bar{S}(W_{t})-\bar{S}(W_{t-1})`$.

###### Theorem 1 (Non-Regressive Gating and Concentration).

Under the gate of (12) and the replicate setup above:

1.  (i)
    No downward drift: $`\Delta_{t}>0`$ if round $`t`$ promotes and
    $`\Delta_{t}=0`$ otherwise, so

    ```math
    \bar{S}(W_{T})=\bar{S}(W_{0})+\sum_{t=1}^{T}\Delta_{t}\;\geq\;\bar{S}(W_{0}). \tag{14}
    ```

2.  (ii)
    Regressions are paid for: on every promoted round, with
    $`\mathcal{Q}^{-}_{t}=\mathcal{Q}^{-}(W_{t},W_{t-1})`$ the tasks
    dropping by more than $`\delta_{\mathrm{noise}}`$,

    ```math
    \sum_{q\in\mathcal{Q}^{-}_{t}}\big(S_{q}(W_{t-1})-S_{q}(W_{t})\big)\;<\;|\mathcal{Q}_{g}|\,\Delta_{t}, \tag{15}
    ```

    and the left-hand side is zero whenever
    $`\mathcal{Q}^{-}_{t}=\emptyset`$ (in particular when
    $`h_{\max}=0`$).

3.  (iii)
    Concentration: for any $`\alpha\in(0,1)`$, with probability at least
    $`1-\alpha`$, simultaneously for every group $`g\in\mathcal{G}`$
    (with $`\log`$ the natural logarithm),

    ```math
    \displaystyle\mu(W_{T}) \displaystyle\geq\mu(W_{0})+\sum_{t=1}^{T}\!\Delta_{t} \tag{16}
    ```

    ```math
    \displaystyle-2\sigma\!\sqrt{\frac{2\log(2n_{\mathrm{eval}}|\mathcal{G}|/\alpha)}{|\mathcal{Q}_{g}|N_{\mathrm{rep}}}}.
    ```

4.  (iv)
    Factored speedup: if group $`g`$ promotes in each round
    independently with probability $`a_{g}`$, per-group gating advances
    a fraction $`\frac{1}{|\mathcal{G}|}\sum_{g}a_{g}`$ of groups per
    round vs. $`\prod_{g}a_{g}`$ under a global gate
    ($`a^{1-|\mathcal{G}|}\times`$ for $`a_{g}=a`$).

The union bound in (iii) covers all $`n_{\mathrm{eval}}`$ evaluated
harnesses per group (paying only $`\log(M+\mathbb{I}_{\mathrm{rep}})`$
inside $`n_{\mathrm{eval}}`$ for within-group selection and repair) and
applies to execution rollouts ($`N_{\mathrm{rep}}\geq 1`$; main-text
suites use $`N_{\mathrm{rep}}=1`$ and Appendix C uses
$`N_{\mathrm{rep}}=2`$) instead of single critic calls. Here $`\mu`$ is
the expected self-review score on $`\mathcal{Q}_{g}`$, and Eq. (16)
serves as an asymptotic sample-complexity scaling law
($`|\mathcal{Q}_{g}|N_{\mathrm{rep}}=\Omega(\sigma^{2}\log(n_{\mathrm{eval}}|\mathcal{G}|/\alpha)/\Delta^{2})`$
samples keep the selection optimism of recorded incumbent scores, at
most twice the deviation term in (16), below a target gain $`\Delta`$)
rather than a non-vacuous finite-sample certificate at our benchmark
task counts. When incumbents are re-scored on growing episode histories
(PAST-Bench) or online task blocks shift across stages (EvoHarnessBench,
Drift Gauntlet), (i)–(ii) hold within each round’s gated task buffer
rather than telescoping unconditionally across distribution shifts,
which motivates pre-execution interface-signature routing and
replay-buffer anchor tasks (§6.3).

###### Theorem 2 (Targeted Repair vs. Passive Discovery).

Consider $`J`$ invariants exercised by $`\mathcal{Q}_{g}`$ and violated
by $`W_{0}`$ (an invariant is a task-independent rule that the playbook
must encode). Compare two observability regimes: a _passive end-task_
learner that observes an invariant only when a coarse task failure
surfaces it with probability $`p_{j}\leq\epsilon`$, versus _dense
pre-execution checklist_ grading where every violated invariant is
captured by a derived criterion evaluated each round. Let
$`T_{\mathrm{passive}}`$ be the rounds until passive surfacing observes
all $`J`$ invariants, $`T_{\mathrm{target}}`$ the rounds until targeted
repair resolves all $`J`$ invariants, and
$`H_{J}=\sum_{\ell=1}^{J}1/\ell`$ ($`H_{0}=0`$).

1.  (i)
    Passive lower bound: if, independently across invariants and rounds,
    invariant $`j`$ surfaces in each round with probability
    $`p_{j}\leq\epsilon`$ for $`\epsilon\in(0,1)`$, then

    ```math
    \displaystyle\mathbb{E}[T_{\mathrm{passive}}] \displaystyle\geq\frac{H_{J}}{-\log(1-\epsilon)}\geq\frac{1-\epsilon}{\epsilon}H_{J} \tag{17}
    ```

    ```math
    \displaystyle=\Omega\!\left(\frac{\log J}{\epsilon}\right)\!,
    ```

    where the $`\Omega((\log J)/\epsilon)`$ asymptotic form holds for
    $`\epsilon\leq 1/2`$.

2.  (ii)
    Targeted upper bound: if in each round (a) every unresolved
    invariant fails a derived criterion
    ($`\mathrm{Priority}_{t}(c)>0`$), (b) the winner addresses at least
    $`\min(b_{\min},u)`$ of the $`u`$ still unresolved invariants, for
    an integer $`b_{\min}\geq 1`$, (c) each is resolved and admitted
    independently with probability $`\geq\rho>0`$, and (d) resolved
    invariants stay resolved, then

    ```math
    \mathbb{E}[T_{\mathrm{target}}]\;\leq\;\frac{J}{\rho\,b_{\min}}+1+\frac{H_{b_{\min}-1}}{\rho}. \tag{18}
    ```

Dense per-criterion grading (assumption (a)) removes the $`1/\epsilon`$
dependence regardless of the specific priority formula: any ranking
assigning positive weight to failing criteria, including
$`1-\mathrm{obey}`$, satisfies (a), and under all-or-nothing candidate
admission with joint bundle pass probability
$`\rho_{\mathrm{bundle}}>0`$,
$`\mathbb{E}[T_{\mathrm{target}}]\leq\lceil J/b_{\min}\rceil/\rho_{\mathrm{bundle}}\leq\frac{J}{\rho_{\mathrm{bundle}}b_{\min}}+\frac{\mathbb{I}[b_{\min}>1]}{\rho_{\mathrm{bundle}}}`$.
What uniquely distinguishes paired priority is regression handling,
formalized next.

###### Proposition 1 (Strict Regression Dominance under Multi-Rollout Grading).

Let obedience (3) average the verdicts of $`K_{\mathrm{gr}}\geq 1`$
graded rollouts, so that it may be fractional. When round $`t-1`$
promoted, write $`o_{c}=\mathrm{obey}(c;W_{t-1})`$ and
$`\delta_{c}=\mathrm{obey}(c;W_{t-2})-o_{c}`$ ($`\delta_{c}:=0`$ if
$`t=1`$ or $`\mathcal{T}_{c}(W_{t-2})=\emptyset`$), so
$`\mathrm{Priority}_{t}(c)=(1-o_{c})+\max(0,\delta_{c})`$ by (4). Let
$`c`$ be a regressed criterion ($`\delta_{c}>0`$) and $`c^{\prime}`$ a
non-regressed one ($`\delta_{c^{\prime}}\leq 0`$).

1.  (i)
    Dominance at equal or higher obedience: if
    $`o_{c^{\prime}}\geq o_{c}`$, then
    $`\mathrm{Priority}_{t}(c)-\mathrm{Priority}_{t}(c^{\prime})\geq\delta_{c}>0`$,
    however small the regression (for example, one additional failing
    rollout).
2.  (ii)
    Exact trade-off:
    $`\mathrm{Priority}_{t}(c)>\mathrm{Priority}_{t}(c^{\prime})`$ if
    and only if $`o_{c}-o_{c^{\prime}}<\delta_{c}`$. In the
    single-rollout binary case ($`K_{\mathrm{gr}}=1`$), a fresh
    regression ($`1\to 0`$, priority $`2`$) therefore outranks every
    non-regressed criterion (priority at most $`1`$).
3.  (iii)
    Exact incumbent pinning set: under (4) in any round (promoted or
    rejected), $`\mathrm{Priority}_{t}(c)=0`$ holds if and only if
    $`\mathrm{obey}(c;W_{t-1})=1`$ and
    $`\Delta_{\mathrm{hurt},t}(c)=0`$; in particular, no regressed
    criterion and no criterion failed by incumbent $`W_{t-1}`$ is ever
    pinned.

Frequency ranking $`1-\mathrm{obey}(c;W_{t-1})`$ satisfies (iii) but
fails (i), tying newly broken criteria with static gaps of equal
obedience; conversely, signed difference
$`\mathrm{obey}(c;W_{t-2})-\mathrm{obey}(c;W_{t-1})`$ satisfies (i) but
fails (iii), assigning $`0`$ to unchanged failures ($`0\to 0`$)
alongside mastered invariants ($`1\to 1`$). Paired priority satisfies
both parameter-free. For $`K_{\mathrm{gr}}\geq 3`$ rollouts (or
$`|\mathcal{T}_{c}|\geq 3`$ tasks), a partial regression ($`1\to 2/3`$,
priority $`2/3`$) scores below a $`0\to 0`$ gap ($`1`$) by (ii), and
tying occurs at $`K_{\mathrm{gr}}=2`$ ($`1\to 0.5`$, priority $`1`$) or
post-rejection when $`\mathrm{obey}(c;W_{t-1})=1`$
($`\Delta_{\mathrm{hurt},t}=1,\Delta_{\mathrm{gap},t}=0`$). This
trade-off is intended: a criterion that the incumbent always fails
outranks one that regressed on a minority of rollouts, while the
Regressed list still surfaces every regression to the proposer (§4.2).

## 5 Experimental Setup

To evaluate continual harness RSI against local overfitting, memory
pollution, and catastrophic forgetting across escalating
non-stationarity, we test GUARD on three primary public benchmarks: (1)
PAST-Bench \[50\] (cross-session memory retention, precision, and SOP
updates), (2) EvoHarnessBench (EnterpriseOps-Gym) \[17\] (stage-wise
continual transfer across evolving Model Context Protocol \[MCP\] tools
and skills), and (3) Drift Gauntlet \[5\] (continual learning without
forgetting across hidden-boundary workflow, topic, domain, and compound
drift), complemented by two rubric-dense professional suites and
controlled component ablations (Analyze, Propose, and Gate) in Appendix
C. All three primary benchmarks compare the unified six-arm suite
(Appendix B.2): No-Evolve ($`W_{0}`$), native memory/skill persistence
(Hermes+ \[50\] / MemToolAgent \[17\]), RRSI \[45\], GEPA \[1\],
Meta-Harness \[20\], and GUARD. To enforce strict reference-free hygiene
on public datasets, our runner strips all held-out evaluator fields
(reference answers, test cases, verifiers, oracle skills, and rubrics),
aborts if any survives, and snapshots initial sandboxes so adaptation
sees only public task inputs and execution states; after adaptation,
every arm freezes its promoted harness $`W_{T}`$ and reports standard
single-rollout (pass@1) held-out accuracy across all three primary
benchmarks ($`N_{\mathrm{rep}}=2`$ frozen DEV trials on the Appendix C
professional suites), with zero test-time candidate pooling,
self-review, or retries.

#### Primary single-model Gemini 4 RSI and applicability to teacher–student knowledge distillation.

Our primary continual-RSI experiments use a single frozen Gemini 4 model
across every role (solver, self-reviewer, distiller, and evolver, with
zero stronger teacher): this powers the EvoHarnessBench Official Hosted
SDK (Table 2), all four hidden-boundary continual streams on Drift
Gauntlet (Table 3), and the controlled dual-axis Propose-stage ablation
(Table C.8), alongside two full 12-family model-identical PAST-Bench
suites (pure claude-opus-5-5 and pure gemini-3.8-flash; §6.1, Appendix
B.2). Complementing this primary single-model regime, we deliberately
include a cross-model teacher–student configuration on PAST-Bench (Table
1), the five-domain local gym (Tables C.5 and C.7), and the Appendix C
professional suites, pairing a frozen gemini-3.8-flash student solver
with a claude-opus-5-5 teacher reviewer and distiller shared identically
across all evolving baselines. Evaluating both regimes serves a
deliberate purpose: the single-model Gemini 4 suites isolate strictly
self-referential continual improvement without external teacher
supervision, while the cross-model suites show that GUARD also applies
to teacher–student knowledge-distillation harness pipelines, distilling
stronger-model reasoning into compact student skills and memories with
low memory pollution and no regressed domain.

#### EvoHarnessBench and Drift Gauntlet protocols.

On EvoHarnessBench, at stage $`v_{k}\in\{\texttt{v1},\dots,v_{V}\}`$,
arms adapt on $`\mathcal{D}_{\text{train}}^{(v_{k})}`$ via execution
scoring (§4.1) and evaluate on
$`\mathcal{D}_{\text{test}}^{(v_{1}\dots v_{k})}`$, forming matrix
$`A_{k,j}`$ ($`k\geq j`$). Following \[17\], we report final _Overall
ACC_, strict _Solved_, _Cohort ACC_ $`A_{V,j}`$, backward transfer
$`\text{BWT}=\sum_{j<V}n_{j}(A_{V,j}-A_{j,j})/\sum_{j<V}n_{j}`$, forward
transfer
$`\text{FWT}=\sum_{k\geq 2}n_{k}(A_{k,k}-A^{\text{pre}}_{k,k})/\sum_{k\geq 2}n_{k}`$
(local gym uses unweighted cohort BWT and stage FWT
$`A_{k,k}-A^{W_{0}}_{k,k}`$), and per-task tokens, calls, and latency
on: (1) the _Official Hosted SDK_ (evolving*tools/calendar, v1–v3,
$`18`$ train / $`43`$ test tasks) under single-model Gemini 4 for all
roles; and (2) the *Full 5-Domain* local gym ($`236`$ test / $`97`$
train tasks, $`16`$ stages across Calendar, Drive, ITSM v1–v4, CSM, HR),
plus a controlled single-model Gemini 4 Propose-stage ablation across
dual-axis ITSM ($`N{=}132`$ test tasks; Appendix C.4). On Drift Gauntlet
\[5\], agents evolve sequentially across $`K\in\{2,3,4\}`$ unannounced
task blocks ($`30`$ online adaptation tasks/block, $`30`$ held-out test
tasks/group, $`12`$ blocks total) under *single-model* Gemini 4 for
every role across four continual drift scenarios spanning BFCL tool
calling, BIRD text-to-SQL, and ScienceWorld interactive environments:
*workflow drift* (BFCL-Miss $`\to`$ BFCL-Base, $`K{=}2`$), *topic drift*
(BIRD-F1 $`\to`$ BIRD-Code $`\to`$ BIRD-TP, $`K{=}3`$), *domain drift*
(ScienceWorld $`\to`$ BFCL-Base $`\to`$ BIRD-F1, $`K{=}3`$), and
*compound drift* (BIRD-Code $`\to`$ BIRD-F1 $`\to`$ BFCL-Miss $`\to`$
BFCL-Base, $`K{=}4`$). From the $`(K{+}1)\times K`$ checkpoint matrix
$`A[t,k]`$ ($`t\in\{0,\dots,K\},k\in\{1,\dots,K\}`$) and seed vector
$`B*{k}=A[0,k]`$, we report \[5\]: *Final Mean*
$`\bar{A}_{K}=\frac{1}{K}\sum_{k=1}^{K}A[K,k]`$, terminal gain
$`\Delta*{K}=\bar{A}*{K}-\bar{B}`$, average gain
$`\bar{\Delta}=\frac{1}{K}\sum*{t=1}^{K}(\bar{A}*{t}-\bar{B})`$,
within-block *plasticity*
$`P=\frac{1}{K}\sum*{k=1}^{K}(A[k,k]-A[k{-}1,k])`$, *pre-block
interference*
$`I=\frac{1}{K-1}\sum*{k=2}^{K}\frac{1}{k-1}\sum*{t=1}^{k-1}(A[t,k]-B*{k})`$,
worst-case *post-block forgetting*
$`F=\frac{1}{K-1}\sum*{k=1}^{K-1}(\min*{t>k}A[t,k]-A[k,k])`$, and
*stability* $`S=(I+F)/2`$. GUARD keys playbook sections to each task’s
pre-execution observable environment/schema signature and renders only
the matching section, whereas baselines keep one global playbook
(lexically retrieved skills for Hermes+); for every arm, held-out
rollouts are memoized per task and rendered playbook (Appendix B). Arms
are compared strictly within each benchmark and model regime.

## 7 Conclusion

Continually adapting an agent’s harness around a frozen backbone model
without external graders requires preventing local overfitting,
catastrophic forgetting, and memory pollution. Drawing on curriculum
regret from UED and group-relative scoring from reinforcement learning
(GRPO), GUARD (_Grader-free UED with Adaptive Rule Distillation_) treats
the text harness as a non-parametric policy component and updates it
from task-derived checklists: Analyze separates edit-induced regressions
($`\Delta_{\mathrm{hurt}}`$) from unresolved gaps
($`\Delta_{\mathrm{gap}}`$) while pinning mastered criteria, Propose
selects among parallel candidate edits via critic-free
group-standardized fitness and contrasts the best and worst candidates
to rewrite proposal prompts, and Gate (_Soft-HURT_) promotes only
net-positive updates with formal non-regression guarantees on the
self-review objective (Theorems 1–2, Proposition 1). At test time, it
deploys a single frozen harness in one pass. Across four benchmark
settings, GUARD improves upon or matches $`W_{0}`$ in held-out accuracy,
achieves $`19/19`$ non-regressive execution-gated promotions, and
sustains monotonic pass@1 gains with zero post-block forgetting under
hidden stream drift while cutting hosted tokens per task by $`54.5\%`$.

## Appendix A Proofs

### A.1 Proof of Theorem 1 (Non-Regressive Gating and Concentration)

###### Proof.

Part (i). If round $`t`$ promotes under the parameterized Soft-HURT gate
(12)–(13), whether directly ($`W_{t}=\widetilde{W}_{t}`$) or after
in-round \[iff\] repair ($`W_{t}=\widetilde{W}^{\mathrm{rep}}_{t}`$ on
its re-scored trajectories), the promoted playbook satisfies

```math
\Delta_{t}\;>\;\mathrm{Hurt}(W_{t},W_{t-1})\;\geq\;0,
```

where $`\mathrm{Hurt}(W_{t},W_{t-1})=0`$ whenever
$`\mathcal{Q}^{-}_{t}=\emptyset`$. If round $`t`$ rejects,
$`W_{t}=W_{t-1}`$ and $`\Delta_{t}=0`$. The incumbent score used by the
gate is the score recorded when the incumbent was itself evaluated, so
the increments telescope and give (14) with non-negative summands. A
band of width $`\delta_{\mathrm{band}}>0`$ relative to the incumbent
instead admits any candidate with
$`\Delta_{t}\geq-\delta_{\mathrm{band}}`$, so $`T`$ consecutive
admissions at $`\Delta_{t}=-\delta_{\mathrm{band}}`$ accumulate a loss
of $`T\delta_{\mathrm{band}}`$; a band relative to the best score so far
bounds the aggregate loss by $`\delta_{\mathrm{band}}`$ but leaves
per-task regressions unbounded.

Part (ii). By (11),

```math
|\mathcal{Q}_{g}|\cdot\mathrm{Hurt}(W_{t},W_{t-1})\;=\;\sum_{q\in\mathcal{Q}^{-}_{t}}\big(S_{q}(W_{t-1})-S_{q}(W_{t})\big),
```

and promotion requires $`\mathrm{Hurt}<\Delta_{t}`$, which is (15);
whenever $`\mathcal{Q}^{-}_{t}=\emptyset`$ (in particular when
$`h_{\max}=0`$), the left-hand side vanishes.

Part (iii). Conditional on everything observed before a candidate
harness evaluation, its $`|\mathcal{Q}_{g}|N_{\mathrm{rep}}`$ errors
$`\{S(\tau_{q,r})-\mu_{q}(W)\}_{q\in\mathcal{Q}_{g},\,r\leq N_{\mathrm{rep}}}`$
are independent across tasks and replicates and $`\sigma`$-sub-Gaussian,
so $`\bar{S}(W)-\mu(W)`$ is
$`\sigma/\sqrt{|\mathcal{Q}_{g}|N_{\mathrm{rep}}}`$-sub-Gaussian and

```math
\Pr\big(|\bar{S}(W)-\mu(W)|>\xi\big)\;\leq\;2\exp\!\left(-\frac{|\mathcal{Q}_{g}|N_{\mathrm{rep}}\,\xi^{2}}{2\sigma^{2}}\right).
```

Over $`T_{\max}`$ rounds, each group evaluates $`W_{0}`$, $`M`$ pool
candidates per round, and at most
$`\mathbb{I}_{\mathrm{rep}}\in\{0,1\}`$ repaired candidate per round,
giving at most
$`n_{\mathrm{eval}}=1+T_{\max}(M+\mathbb{I}_{\mathrm{rep}})`$ harness
evaluations per group and $`n_{\mathrm{eval}}|\mathcal{G}|`$ across all
groups. Choosing
$`\xi=\sigma\sqrt{2\log(2n_{\mathrm{eval}}|\mathcal{G}|/\alpha)/(|\mathcal{Q}_{g}|N_{\mathrm{rep}})}`$
makes each tail probability at most
$`\alpha/(n_{\mathrm{eval}}|\mathcal{G}|)`$. A union bound over the at
most $`n_{\mathrm{eval}}|\mathcal{G}|`$ evaluations gives
$`|\bar{S}-\mu|\leq\xi`$ for all of them with probability at least
$`1-\alpha`$; the union bound remains valid although later candidates
and repairs depend adaptively on earlier noise, because each tail bound
holds conditionally on the past. On this event,

```math
\mu(W_{T})\;\geq\;\bar{S}(W_{T})-\xi\;=\;\bar{S}(W_{0})+\sum_{t=1}^{T}\Delta_{t}-\xi\;\geq\;\mu(W_{0})+\sum_{t=1}^{T}\Delta_{t}-2\xi,
```

which is (16).

Part (iv). With per-group gating, group $`g`$ advances in a round with
probability $`a_{g}`$, so the expected fraction of advancing groups is
$`\frac{1}{|\mathcal{G}|}\sum_{g}a_{g}`$. A single global gate advances
only if every group’s candidate passes, which under independence has
probability $`\prod_{g}a_{g}`$. For equal $`a_{g}=a`$ the ratio is
$`a/a^{|\mathcal{G}|}=a^{1-|\mathcal{G}|}`$ (e.g., $`8\times`$ for
$`|\mathcal{G}|=4`$ and $`a=0.5`$). ∎

### A.2 Proof of Theorem 2 (Targeted Repair vs. Passive Discovery)

###### Proof.

Part (i). The passive learner must observe every invariant, so
$`T_{\mathrm{passive}}\geq\max_{j}G_{j}`$, where
$`G_{j}\sim\mathrm{Geom}(p_{j})`$, supported on $`\{1,2,\dots\}`$, is
the first round in which invariant $`j`$ surfaces and the $`G_{j}`$ are
independent. Because $`p_{j}\leq\epsilon<1`$, each $`G_{j}`$
stochastically dominates $`G^{\prime}_{j}\sim\mathrm{Geom}(\epsilon)`$,
and independence carries the dominance to the maxima. Couple
$`G^{\prime}_{j}=\lceil E_{j}\rceil\geq E_{j}`$ with
$`E_{1},\dots,E_{J}`$ i.i.d. exponential of rate
$`\nu=-\log(1-\epsilon)`$; the coupling is exact since

```math
\Pr\big(\lceil E_{j}\rceil>\ell\big)=e^{-\nu\ell}=(1-\epsilon)^{\ell}.
```

By the Rényi representation of exponential order statistics,
$`\max_{j}E_{j}\stackrel{{\scriptstyle d}}{{=}}\sum_{\ell=1}^{J}X_{\ell}/(\ell\nu)`$
with $`X_{\ell}`$ i.i.d. $`\mathrm{Exp}(1)`$, so for all
$`\epsilon\in(0,1)`$,

```math
\mathbb{E}[T_{\mathrm{passive}}]\;\geq\;\mathbb{E}\big[\max_{j}E_{j}\big]\;=\;\frac{H_{J}}{-\log(1-\epsilon)}\;\geq\;\frac{1-\epsilon}{\epsilon}\,H_{J},
```

using $`-\log(1-\epsilon)\leq\epsilon/(1-\epsilon)`$ on $`(0,1)`$
(giving $`\Omega((\log J)/\epsilon)`$ when $`\epsilon\leq 1/2`$). For
example, $`J=10`$ and $`\epsilon=0.05`$ give
$`\mathbb{E}[T_{\mathrm{passive}}]\geq 57.1`$ rounds.

Part (ii). Let $`u_{t}`$ be the number of invariants still unresolved
after round $`t`$ ($`u_{0}=J`$), and let $`\mathcal{F}_{t}`$ be the
history of the first $`t`$ rounds. By (a) and (d), resolved invariants
never displace unresolved ones in the ranking and stay resolved.

_Phase 1_ ($`u_{t-1}\geq b_{\min}`$). By (b) and (c), on the event
$`\{t_{1}>t-1\}\in\mathcal{F}_{t-1}`$ where
$`t_{1}=\min\{t:u_{t}<b_{\min}\}`$, at least $`b_{\min}`$ unresolved
invariants are targeted and

```math
\mathbb{E}\big[u_{t-1}-u_{t}\,\big|\,\mathcal{F}_{t-1}\big]\;\geq\;\rho\,b_{\min}.
```

The stopping time $`t_{1}`$ is integrable because each active round
resolves at least one invariant with probability at least $`\rho`$.
Defining $`Z_{t}=(J-u_{t})-\rho\,b_{\min}t`$, the stopped process
$`Z_{t\wedge t_{1}}`$ is a bounded-increment submartingale; optional
stopping yields

```math
\rho\,b_{\min}\,\mathbb{E}[t_{1}]\;\leq\;J-\mathbb{E}[u_{t_{1}}]\;\leq\;J.
```

_Phase 2_ ($`u_{t_{1}}<b_{\min}`$). Conditional on
$`\mathcal{F}_{t_{1}}`$, if $`u_{t_{1}}=0`$ (in particular whenever
$`b_{\min}=1`$), zero further rounds are needed; if
$`1\leq u_{t_{1}}\leq b_{\min}-1`$, every remaining invariant is
targeted in every subsequent round and resolved independently with
probability at least $`\rho`$, so the conditional remaining time is
stochastically dominated by the maximum of $`u_{t_{1}}\leq b_{\min}-1`$
independent $`\mathrm{Geom}(\rho)`$ variables. With the coupling of Part
(i) at rate $`\nu^{\prime}=-\log(1-\rho)\geq\rho`$, this maximum is at
most $`1+\max_{j}E^{\prime}_{j}`$, whose conditional expectation is at
most $`1+H_{b_{\min}-1}/\nu^{\prime}\leq 1+H_{b_{\min}-1}/\rho`$.

Taking unconditional expectations and adding the two phases gives (18),
which does not involve $`\epsilon`$. (Under all-or-nothing bundle
admission with joint pass probability $`\rho_{\mathrm{bundle}}>0`$ per
round, each accepted round resolves $`\min(b_{\min},u_{t-1})`$
invariants, requiring at most $`\lceil J/b_{\min}\rceil`$ accepted
bundles of mean waiting time $`1/\rho_{\mathrm{bundle}}`$ each.) ∎

### A.3 Proof of Proposition 1 (Strict Regression Dominance under Multi-Rollout Grading)

###### Proof.

When round $`t-1`$ promoted, (4) gives
$`\Delta_{\mathrm{gap},t}(c)=1-o_{c}`$ and
$`\Delta_{\mathrm{hurt},t}(c)=\max(0,\delta_{c})`$ for any numbers of
rollouts graded under $`W_{t-2}`$ and $`W_{t-1}`$, so
$`\mathrm{Priority}_{t}(c)=(1-o_{c})+\max(0,\delta_{c})`$. For a
regressed criterion $`c`$ ($`\delta_{c}>0`$) and a non-regressed
criterion $`c^{\prime}`$ ($`\delta_{c^{\prime}}\leq 0`$, so
$`\Delta_{\mathrm{hurt},t}(c^{\prime})=0`$),

```math
\mathrm{Priority}_{t}(c)-\mathrm{Priority}_{t}(c^{\prime})\;=\;\big(1-o_{c}+\delta_{c}\big)-\big(1-o_{c^{\prime}}\big)\;=\;\delta_{c}-(o_{c}-o_{c^{\prime}}).
```

Part (i). If $`o_{c^{\prime}}\geq o_{c}`$, the right-hand side is at
least $`\delta_{c}>0`$.

Part (ii). The right-hand side is positive if and only if
$`o_{c}-o_{c^{\prime}}<\delta_{c}`$. In the single-rollout binary case
($`K_{\mathrm{gr}}=1`$), a fresh regression has $`o_{c}=0`$ and
$`\delta_{c}=1`$, so $`\mathrm{Priority}_{t}(c)=2`$, whereas every
non-regressed criterion has
$`\mathrm{Priority}_{t}(c^{\prime})=1-o_{c^{\prime}}\leq 1`$.

Part (iii). In any round (promoted or rejected), both
$`\Delta_{\mathrm{hurt},t}(c)`$ and
$`\Delta_{\mathrm{gap},t}(c)=1-\mathrm{obey}(c;W_{t-1})`$ in (4) are
non-negative, so $`\mathrm{Priority}_{t}(c)=0`$ holds if and only if
$`\mathrm{obey}(c;W_{t-1})=1`$ and $`\Delta_{\mathrm{hurt},t}(c)=0`$.
Because each verdict $`r(\tau,c)`$ is binary,
$`\mathrm{obey}(c;W_{t-1})=1`$ holds exactly when every trajectory in
$`\mathcal{T}_{c}(W_{t-1})`$ obeys $`c`$; hence no criterion failed by
$`W_{t-1}`$ and no regressed criterion
($`\Delta_{\mathrm{hurt},t}(c)>0`$) is ever pinned. ∎

#### Stage-by-stage adaptation time complexity.

Decomposing Algorithm 1 across its stages isolates LLM rollout calls
from local CPU bookkeeping:

1.  1.  _Pre-execution checklist derivation (§4.1):_ Deriving the fixed
        atomic checklist $`\mathcal{C}(q)`$ requires a single pre-execution
        model pass per source task once at $`t=0`$ ($`O(Q)`$ single-pass
        calls total; benchmark field stripping in §5 is $`O(Q)`$ local CPU
        work), cached unchanged across all $`T`$ rounds and $`M`$ parallel
        candidates.
2.  2.  _Solver rollouts (§4.3):_ Multi-turn environment rollouts dominate
        wall-clock adaptation cost. Under _execution scoring_ on a fixed
        task set $`\mathcal{Q}_{g}`$ (Theorem 1), GUARD executes one
        baseline pass under $`W_{0}`$ plus $`M`$ candidate passes per round,
        reusing recorded incumbent scores without re-running incumbents
        (plus at most $`\mathbb{I}_{\mathrm{rep}}\in\{0,1\}`$ conditional
        re-score when in-round \[iff\] repair fires on
        $`1\leq|\mathcal{Q}^{-}_{m^{\star}}|\leq h_{\mathrm{rep}}`$, which
        adds at most one extra $`Q`$-task sweep in that round, i.e.,
        worst-case per-round rollout depth $`2Q`$), totaling
        $`(1+T(M+\mathbb{I}_{\mathrm{rep}}))Q=O(TMQ)`$ rollouts ($`O(TMQH)`$
        environment steps). Because the $`M`$ candidates within round $`t`$
        depend only on $`(W_{t-1,g},\mathcal{B}_{t,g},\mathcal{P}_{t,g})`$,
        they execute in parallel across workers and across the
        $`|\mathcal{G}|`$ groups, yielding $`O(TQ)`$ sequential rollout
        depth. This matches single-candidate RRSI/Hermes+ in asymptotic
        wall-clock depth and matches $`K`$-candidate GEPA/Meta-Harness
        ($`O(TKQ)`$) in total work at $`M=K=2`$. (On stage-expanded
        continual suites such as hosted EvoHarnessBench, where stage $`t`$
        adds $`q`$ tasks under drifted tools and re-scores the incumbent and
        $`M`$ candidates on the cumulative $`tq`$ tasks, total rollouts
        scale as $`\sum_{t=1}^{T}(M+1)tq=O(T^{2}Mq)`$ with $`O(T^{2}q)`$
        sequential depth.) Under _critic scoring_ on stateful cross-session
        benchmarks (PAST-Bench), GUARD executes $`O(TQ)`$ ($`1\times`$)
        online episode rollouts, adding zero environment rollouts over
        Hermes+, RRSI, or Meta-Harness.
3.  3.  _Two-layer self-review (§4.1):_ Layer 1 grades execution-verifiable
        predicates deterministically in the local sandbox ($`O(H)`$ CPU per
        rollout, zero model calls). Layer 2 grades semantic predicates one
        at a time in $`O(C)`$ localized single-pass judgments per rollout,
        adding $`O(TMQC)`$ unbatched single-pass calls under execution
        scoring ($`O(TQC)`$ under critic scoring, with $`C=O(1)`$) without
        multi-turn tool interaction.
4.  4.  _Three closed-loop stages (Analyze, Propose, Gate):_ In Analyze
        (§4.2), computing $`\mathrm{obey}(c;W)`$,
        $`\Delta_{\mathrm{hurt},t}(c)`$, and $`\Delta_{\mathrm{gap},t}(c)`$
        and sorting $`QC`$ criteria by
        $`(\mathbb{I}[\Delta_{\mathrm{hurt},t}>0],\mathrm{Priority}_{t}(c),\Delta_{\mathrm{hurt},t}(c))`$
        takes $`O(QC\log(QC))`$ pure CPU time, and extracting same-task
        $`(\tau^{+},\tau^{-})`$ contrasts takes $`O(QM)`$ CPU time (_zero_
        LLM calls). In Propose (§4.3), compiling $`M`$ candidates via
        $`\mathsf{Distill}`$ and evolving $`(s^{+}_{t+1},s^{-}_{t+1})`$ via
        $`\mathsf{ContrastEvolve}`$ costs $`M+1`$ single-pass distiller
        calls per group and round ($`O(T|\mathcal{G}|M)`$ total), while
        within-group standardized fitness normalization costs
        $`O(T|\mathcal{G}|M)`$ CPU time; because each distiller call reads
        bounded $`(W_{t-1,g},\mathcal{B}_{t,g})`$ and at most $`L_{\max}`$
        active ledger entries, cumulative proposer prefill tokens over $`T`$
        rounds grow _linearly_ in $`T`$ as
        $`O(T|\mathcal{G}|(B_{W}+L_{\max}+B_{\mathcal{B}}))`$, whereas
        raw-trace archive search (Meta-Harness) grows per-round trace
        prefill as $`O(tQH)`$ and cumulative prefill quadratically as
        $`\sum_{t=1}^{T}O(tQH)=O(T^{2}QH)`$. In Gate (§4.4), evaluating Eq.
        (12) and updating $`\mathcal{L}_{g}`$ takes $`O(Q)`$ CPU arithmetic
        (_zero_ LLM calls unless conditional \[iff\] repair triggers).

#### Deployment (test-time) complexity and empirical runtime.

At deployment, $`\mathcal{P}_{t,g}`$, the two-layer self-reviewer, and
$`\mathcal{L}_{g}`$ are discarded: each held-out task
$`q_{\mathrm{test}}`$ runs a single ($`1\times`$) rollout conditioned on
$`W_{T,g}`$, incurring zero Best-of-$`M`$ sampling or reviewer calls and
$`O(B_{W})=O(1)`$ prompt-prefix overhead independent of $`T`$.
Empirically, compact \[iff\]-guarded rules shorten test-time
trajectories instead of slowing them down: on hosted EvoHarnessBench
under unified Gemini 4 ($`43`$ test tasks; Table 2), GUARD’s final
playbook ($`2{,}315`$ characters vs. $`4{,}538`$ in Meta-Harness,
$`5{,}123`$ in GEPA, $`6{,}989`$ in MemToolAgent, and $`10{,}013`$ in
RRSI), combined with two-layer gating (§6.4), reaches $`0/43`$
eight-step budget exhaustions (vs. $`6`$–$`10/43`$ on baselines),
cutting inference tokens per task to $`59{,}651`$ ($`-54.5\%`$ vs.
$`W_{0}`$’s $`131{,}032`$, and $`-24.2\%`$ to $`-30.0\%`$ below evolving
baselines) and keeping 43-task test evaluation wall-clock time
($`167.6\text{ min}`$, $`233.8\text{s}`$/task) within $`6\%`$ of
$`W_{0}`$ ($`158.8\text{ min}`$) and $`2.6\times`$ faster than RRSI
($`439.4\text{ min}`$).

#### Space and active-context complexity.

Memory scales along three distinct tiers: (i) _active deployment prompt
context_ is $`O(B_{W})=O(1)`$ in $`T`$ (and progressive wiki*read loads
only referenced sections on multi-file suites), avoiding the $`O(T)`$
prompt growth and $`0.500`$ memory pollution of uncompacted buffers;
(ii) *active proposer prefill context* is
$`O(B*{W}+L*{\max}+B*{\mathcal{B}})`$ ($`O(1)`$ in $`T`$ under capped
contrasts/rationales, vs. $`O(|\mathcal{Q}_{g}|(C+H))`$ uncapped),
avoiding both the $`O(TQH)`$ raw-trace archive of Meta-Harness and the
$`O(TKQ)`$ instance-Pareto score matrix of GEPA; and (iii) *host working
RAM and disk* hold $`O(QC)`$ cached pre-execution predicates plus
$`O(|\mathcal{G}|MB_{W})`$ active pool strings in RAM, while the
deduplicated on-disk rejection log is windowed to $`L\_{\max}=O(1)`$
active entries whenever read back into model context.
