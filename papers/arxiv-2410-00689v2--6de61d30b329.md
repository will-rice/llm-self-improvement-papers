## 4 Hypothesis: Can memory help improve in-context learning abilities of LLM agents?

Although the context window of LLMS have gotten increasingly larger,
catastrophic forgetting remains an issue as we work towards continual
learning. One way to remedy the limitations of in-context learning, is
store previously seen trajectories in a library. During inference time,
the library can be leveraged to select the most relevant trajectories as
few-shot prompts for the given task.

### 4.2 Experiment 1: Remember what you’ve learned.

1.  1.  Create a 80-20 train-test split
2.  2.  Use the full 80% as in-context examples for the 20% test.
3.  3.  Store the 80% training data in memory. Select the top-K relevant
        examples in the training data to test the 20% test data.
