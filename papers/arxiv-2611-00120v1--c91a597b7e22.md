# DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding

Zhaoyu Chen Affiliation: School of Computer Science and Engineering   
Yongwei Nie Affiliation: South China University of Technology,
Guangzhou, China

###### Abstract

Temporal Video Grounding (TVG) aims to localize the start and end times
of an event described by a language query in a video. The task becomes
particularly challenging when the same video contains multiple repeated,
similar, or opposite events. On these hard examples, all responses
sampled by Group Relative Policy Optimization (GRPO) may miss the target
and receive zero temporal Intersection-over-Union (tIoU). Their
group-relative advantages are then all zero, leaving no useful policy
gradient signal. Further analysis shows that the model is often able to
recognize the queried event but is distracted by other events in the
same video and selects the wrong occurrence. To address this, we propose
DTP-OPSD, a reinforcement learning framework with distractor-aware
temporal-privilege on-policy self-distillation. The student observes the
clean video and generates responses on-policy, while a shared-weight
teacher observes a privileged video in which the target window is marked
by red full-frame borders and same-video distractor windows by blue
full-frame borders. For the distillation loss, the teacher evaluates
student-generated prefixes and provides dense token-level Jensen–Shannon
divergence supervision. This supervision remains informative even when
GRPO provides no policy gradient signal. We suppress distillation when
the teacher does not outperform the student and strengthen it for groups
where the teacher performs better but all student rollouts receive zero
tIoU. We also construct a compact hard-interference training set through
VLM screening and human verification. With only 300 additional
post-training examples, DTP-OPSD achieves the highest mIoU among the
compared open-source 8B models on Charades-TimeLens,
ActivityNet-TimeLens, and QVHighlights-TimeLens, reaching 55.93, 54.77,
and 66.71, respectively. Compared with Pure GRPO trained on the same
data, DTP-OPSD improves all 12 reported metrics, with R1@0.7 gains of
1.28, 1.62, and 1.78 points on the three benchmarks. Code will be
released at
[https://github.com/nian1125/DTP-OPSD](https://github.com/nian1125/DTP-OPSD).

## 1 Introduction

Temporal Video Grounding (TVG) aims to identify the start and end times
of an event described by a language query ([Gao et al.,
2017](#bib.bib1); [Hendricks et al., 2017](#bib.bib2)). It is a
fundamental video-language task that requires joint understanding of the
query semantics and the temporal structure of the video. Earlier methods
localize target moments through proposal matching, boundary regression,
or span prediction ([Zhang et al., 2020](#bib.bib3); [Lei et al.,
2021](#bib.bib4)). More recently, multimodal large language models have
formulated TVG as timestamp generation through a language interface
([Ren et al., 2024](#bib.bib21); [Huang et al., 2024a](#bib.bib6); [Wang
et al., 2025a](#bib.bib23); [Zhang et al., 2026](#bib.bib7)). This
formulation makes TVG more flexible, but accurate localization remains
difficult when a video contains multiple related event occurrences that
provide plausible matches to the query.

Reinforcement learning is now widely used to improve TVG with multimodal
large language models ([Wang et al., 2025b](#bib.bib8); [Chen et al.,
2025](#bib.bib26); [Dong et al., 2026](#bib.bib28)). A predicted
temporal window can be scored directly against the annotated target
using temporal Intersection-over-Union (tIoU). The tIoU score provides a
direct reward, without requiring a learned reward model or extra reward
labels. Group Relative Policy Optimization (GRPO) samples several
responses for the same input and trains the policy using their relative
rewards within the group ([Shao et al., 2024](#bib.bib11); [DeepSeek-AI,
2025](#bib.bib25)). However, GRPO cannot learn from a rollout group when
all sampled responses receive the same reward, because mean centering
assigns every response zero relative advantage. In TVG, a particularly
consequential case is the all-zero group.

A major challenge arises when a video contains multiple events related
to the query. The queried event may occur repeatedly, while other
moments may contain visually or semantically similar actions or opposite
actions involving the same actor and object. These distractors make it
difficult to identify the specific occurrence requested by the query. We
refer to this problem as same-video interference. Under strong
interference, the model may recognize the queried event but still select
the wrong occurrence.

Figure [1](#S1.F1 "Figure 1 ‣ 1 Introduction ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding")
illustrates this failure. In this example, Qwen3-VL-8B ([Bai et al.,
2025](#bib.bib18)) recognizes the queried action but selects an earlier
occurrence, resulting in zero tIoU. With the same model weights, the
privileged view helps distinguish the target from distractors and
recover the correct interval. Dataset-level diagnostics further show
that localization becomes more difficult as the number of valid
same-video distractors increases, while DTP-OPSD remains more robust.
The privileged view also outperforms the clean view on the full
QVHighlights-TimeLens evaluation set. These results suggest that some
failures arise from incorrect occurrence selection under same-video
interference rather than from a failure to recognize the queried action.

![Refer to caption](2611.00120v1/images/motivation.png)

Under strong same-video interference, all sampled responses may select
distractor occurrences and receive zero tIoU, leaving some of the
hardest examples inactive in the current GRPO update.

To reduce wrong-occurrence predictions and provide a learning signal for
all-zero rollout groups, we propose DTP-OPSD, a reinforcement learning
framework with distractor-aware temporal-privilege on-policy
self-distillation. As shown in
Figure [2](#S3.F2 "Figure 2 ‣ 3 Method ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding"),
the student observes the clean video and samples responses on-policy. A
teacher sharing the student’s current weights observes a training-only
privileged view, where the target region is marked in red and the
distractors in blue. For distillation, the teacher evaluates
student-generated prefixes and provides dense token-level Jensen–Shannon
divergence supervision ([Agarwal et al., 2024](#bib.bib13); [Zhao et
al., 2026](#bib.bib14); [Yuan et al., 2026](#bib.bib16)).

Since the privileged teacher is not reliable on every sample, we
introduce an adaptive distillation controller. The controller compares
the mean Student tIoU from the GRPO rollouts with the mean teacher tIoU
from independently generated teacher rollouts under the same sampling
settings. It suppresses distillation when the teacher does not
outperform the student and strengthens it for groups where the teacher
performs better but all student rollout tIoUs are zero. All remaining
groups use the default distillation weight. This design prevents
unreliable teacher supervision while providing stronger guidance when
GRPO receives no reward-driven learning signal.

Effective self-distillation requires hard but teachable examples. We
further construct HI-TVG-300 from the TimeLens-100K training set ([Zhang
et al., 2026](#bib.bib7)), without introducing external videos. VLM
screening and human verification identify examples with strong
same-video interference. A teachability filter then retains examples
where the privileged teacher clearly outperforms the clean-video
student. The resulting dataset contains 300 high-quality, difficult but
teachable training examples. Our contributions are:

- •
  We study a key challenge in reinforcement learning-based TVG.
  Same-video distractors can cause wrong-occurrence predictions and
  all-zero tIoU groups that provide no relative learning signal to GRPO.
- •
  We propose distractor-aware temporal privilege, using red borders to
  mark the target region and blue borders to mark distractor regions.
  This enables on-policy distillation from a shared-weight teacher to a
  clean-video student.
- •
  We design an adaptive distillation controller that suppresses
  distillation when the teacher does not outperform the student and
  strengthens supervision for all-zero student rollout groups when the
  teacher performs better.
- •
  We construct HI-TVG-300, a high-quality hard-interference training
  set, through VLM screening, human verification, and teacher–student
  teachability filtering.

## 2 Related Work

#### Temporal video grounding and reinforcement learning.

Early TVG methods localize moments through proposal matching, boundary
regression, or span prediction ([Gao et al., 2017](#bib.bib1);
[Hendricks et al., 2017](#bib.bib2); [Zhang et al., 2020](#bib.bib3);
[Lei et al., 2021](#bib.bib4)). Video MLLMs later introduced
timestamp-aware representations and grounding instruction tuning for
generative temporal localization ([Ren et al., 2024](#bib.bib21); [Huang
et al., 2024a](#bib.bib6); [Huang et al., 2024b](#bib.bib22); [Wang et
al., 2025a](#bib.bib23); [Zeng et al., 2025](#bib.bib24); [Guo et al.,
2026](#bib.bib32); [Guo et al., 2025](#bib.bib33)). Recent work extends
TVG to multi-moment annotations ([Cao et al., 2025](#bib.bib30); [Xu et
al., 2026](#bib.bib31)). Reinforcement learning with verifiable rewards
has also been applied to multimodal and video reasoning ([Huang et al.,
2026](#bib.bib29); [Feng et al., 2025](#bib.bib9); [Li et al.,
2025](#bib.bib10)), and more recently to temporal video grounding ([Wang
et al., 2025b](#bib.bib8); [Chen et al., 2025](#bib.bib26); [Chen et
al., 2026](#bib.bib27); [Dong et al., 2026](#bib.bib28); [Zhang et al.,
2026](#bib.bib7)). However, group-relative optimization loses its
relative learning signal when all rollout rewards are identical. We
study this failure under same-video interference, where competing
occurrences can produce wrong-occurrence predictions and all-zero tIoU
groups.

#### On-policy distillation and self-distillation.

Knowledge distillation transfers a teacher distribution to a student
([Hinton et al., 2015](#bib.bib12)). On-policy distillation provides
teacher supervision along student-generated trajectories, while
On-Policy Self-Distillation creates a teacher–student capability gap by
conditioning shared model weights on different inputs ([Agarwal et al.,
2024](#bib.bib13); [Zhao et al., 2026](#bib.bib14)). Recent multimodal
self-distillation methods construct privileged views from localized
visual evidence or higher-resolution images ([Yuan et al.,
2026](#bib.bib16); [Zhu et al., 2026](#bib.bib17)). Video-OPD applies
on-policy distillation to temporal video grounding using a fixed
frontier teacher to supervise student-generated trajectories ([Li et
al., 2026](#bib.bib15)). In contrast, DTP-OPSD combines GRPO with
shared-weight self-distillation and constructs query-dependent temporal
privilege by marking the target occurrence and its same-video
distractors. Its adaptive controller suppresses unreliable teacher
supervision and strengthens it for all-zero student groups.

### 3.1 GRPO for TVG and Dead Groups

#### Reward and group-relative optimization.

Following the thinking-free RLVR setting of TimeLens ([Zhang et al.,
2026](#bib.bib7)), our only reward is temporal Intersection-over-Union:

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\operatorname{tIoU}(\hat{\tau},\tau)=\frac{|\hat{\tau}\cap\tau|}{|\hat{\tau}\cup\tau|}.
``` |  | (1) |

Here, $`|\cdot|`$ denotes the duration of an interval. A response that
cannot be parsed into a valid interval receives zero reward. Unlike
Time-R1 ([Wang et al., 2025b](#bib.bib8)), we use no format or
temporal-distance reward, keeping the training reward consistent with
the standard TVG evaluation metric.

For each video-query pair $`(V_{g},q_{g})`$, the rollout policy
$`\pi_{\theta_{\mathrm{old}}}`$ samples $`G`$ responses conditioned on
the clean video and query. Each response is parsed into a predicted
interval $`\hat{\tau}_{g,i}`$, and its tIoU is used as the student
reward $`r_{g,i}^{S}`$. Following TimeLens, we compute the
group-relative advantages by mean centering without standard-deviation
scaling:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\bar{r}_{g}^{S}=\frac{1}{G}\sum_{j=1}^{G}r_{g,j}^{S},\qquad A_{g,i}=r_{g,i}^{S}-\bar{r}_{g}^{S}.
``` |  | (2) |

We use these advantages in the group-relative GRPO objective ([Shao et
al., 2024](#bib.bib11); [Zhang et al., 2026](#bib.bib7)), denoted by
$`\mathcal{L}_{\mathrm{GRPO}}`$. The exact loss, completion-token
normalization, and single-update optimization procedure are provided in
Appendix [A.1](#A1.SS1 "A.1 Training Objective and Update Procedure ‣ Appendix A Implementation and Reproducibility Details ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding").

#### Dead groups under same-video interference.

GRPO obtains a reward-driven learning signal from a rollout group only
when its rewards differ. Under strong same-video interference, a
critical failure mode occurs when every sampled response selects an
incorrect occurrence that does not overlap with the target. In this
case, $`r_{g,i}^{S}=0`$ for all $`i`$, and
Equation [2](#S3.E2 "In Reward and group-relative optimization. ‣ 3.1 GRPO for TVG and Dead Groups ‣ 3 Method ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding")
yields $`A_{g,i}=0`$ for all $`i`$. The group therefore contributes no
reward-driven policy gradient to the current update. We refer to such an
all-zero rollout group as a dead group. Although any constant-reward
group has zero relative advantages, we use the all-zero condition to
identify dead groups because it indicates complete failure to overlap
the target. When the privileged teacher achieves a higher mean tIoU than
the student, DTP-OPSD provides strengthened token-level supervision to
these groups without relying on within-group reward differences.

### 3.2 Distractor-Aware Temporal-Privilege On-Policy Self-Distillation

#### Distractor-aware temporal privilege.

For each training example, we construct an aligned clean video $`V`$ and
a privileged video $`V^{\mathrm{priv}}`$ with identical content and
duration. In $`V^{\mathrm{priv}}`$, frames inside the target window
receive red full-frame borders, while frames inside the verified
same-video distractor windows receive blue full-frame borders. Before
rendering, we expand only the target window to $`1.5`$ times its
duration around its center. The red borders provide a coarse GT-derived
temporal cue rather than displaying the annotated boundaries verbatim.
Red takes priority wherever the target and distractor windows overlap.
The clean video remains unchanged, and $`V^{\mathrm{priv}}`$ is used
only during training.

#### Shared-weight teacher and student.

Following On-Policy Self-Distillation (OPSD) ([Zhao et al.,
2026](#bib.bib14)), the teacher and student are two conditional views of
the same model. They share the current parameters $`\theta`$ and use the
same text prompt, which does not mention the border colors. Their
conditioning differs only in the video input. The resulting capability
gap therefore comes from the privileged temporal evidence rather than
additional parameters or textual hints.

#### On-policy same-prefix distillation.

The student responses sampled for GRPO are reused for distillation. At
each token position, the student and teacher compute their next-token
distributions from the clean and privileged videos, respectively, while
conditioning on the same student-generated prefix $`\hat{y}_{g,i,<t}`$.
We denote these distributions by $`p_{S,g,i}^{t}`$ and
$`p_{T,g,i}^{t}`$. The teacher therefore evaluates the generation states
actually visited by the student, keeping the supervision on-policy.

We align the two distributions using Jensen–Shannon divergence
(JSD) ([Lin, 1991](#bib.bib19)):

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle d_{g,i}^{t}`$ | $`\displaystyle=\operatorname{JSD}\!\left(p_{S,g,i}^{t},\operatorname{sg}\!\left[p_{T,g,i}^{t}\right]\right),`$ |  | (3) |
|  | $`\displaystyle\ell_{g}^{\mathrm{JSD}}`$ | $`\displaystyle=\frac{1}{G}\sum_{i=1}^{G}\frac{1}{T_{g,i}}\sum_{t=1}^{T_{g,i}}d_{g,i}^{t}.`$ |  |  |

Here, $`\operatorname{sg}[\cdot]`$ denotes stop-gradient, and
$`T_{g,i}`$ is the number of valid completion tokens. Gradients
propagate only through the clean-video student branch. This loss does
not vanish merely because all student rollout tIoUs are zero.

### 3.3 Adaptive Distillation Control

#### Teacher competence from independent rollouts.

The privileged view does not guarantee a better teacher prediction for
every input. The teacher may ignore the border information or still
select a distractor, so unreliable teacher supervision should be
suppressed. To estimate teacher competence fairly, the teacher uses the
same model snapshot, text prompt, sampling temperature, and number of
rollouts $`G`$ as the student. The only difference is the video input.
The teacher independently generates $`G`$ responses from the privileged
video using its own autoregressive prefixes. Each response is parsed
using the same rule as the student responses, and an invalid response
receives zero reward. We denote the mean tIoU of these responses by
$`\bar{r}_{g}^{T}`$ and use it as the teacher competence estimate. These
teacher rollouts are used only by the adaptive controller and do not
enter the JSD loss, which remains defined on student-generated prefixes
in
Equation [3](#S3.E3 "In On-policy same-prefix distillation. ‣ 3.2 Distractor-Aware Temporal-Privilege On-Policy Self-Distillation ‣ 3 Method ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding").

#### Adaptive distillation weight.

Let $`\bar{r}_{g}^{S}`$ denote the mean student tIoU defined in
Equation [2](#S3.E2 "In Reward and group-relative optimization. ‣ 3.1 GRPO for TVG and Dead Groups ‣ 3 Method ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding").
The group-level distillation multiplier is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\lambda_{g}^{\mathrm{adapt}}=\begin{cases}0,&\bar{r}_{g}^{T}\leq\bar{r}_{g}^{S},\\[2.0pt]
2,&\bar{r}_{g}^{T}>\bar{r}_{g}^{S}\ \text{and}\ r_{g,i}^{S}=0\ \ \forall i,\\[2.0pt]
1,&\text{otherwise}.\end{cases}
``` |  | (4) |

The first condition removes distillation when the privileged teacher
does not achieve a higher mean tIoU than the student. This includes
groups where both the student and teacher receive only zero tIoU. The
second condition strengthens distillation only when the teacher performs
better and all student rollout tIoUs are zero. When the teacher performs
better, all remaining groups, including student groups with identical
nonzero rewards, retain the default weight.

#### Final objective.

The overall objective combines the standard GRPO loss with
group-adaptive token-level distillation:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}_{\mathrm{total}}=\mathcal{L}_{\mathrm{GRPO}}+\lambda_{\mathrm{JSD}}\frac{1}{|\mathcal{B}|}\sum_{g\in\mathcal{B}}\lambda_{g}^{\mathrm{adapt}}\ell_{g}^{\mathrm{JSD}},
``` |  | (5) |

where $`\mathcal{B}`$ is a minibatch of rollout groups and
$`\lambda_{\mathrm{JSD}}`$ is the global distillation coefficient. The
GRPO coefficient and $`\lambda_{\mathrm{JSD}}`$ are both set to $`1`$ in
our final configuration. The group-level multiplier
$`\lambda_{g}^{\mathrm{adapt}}\in\{0,1,2\}`$ controls the contribution
of JSD for each rollout group. It removes unreliable teacher supervision
and strengthens supervision for all-zero student groups when the teacher
demonstrates better localization.

### 3.4 Construction of HI-TVG-300

Large-scale TVG datasets provide broad training coverage but are not
designed to contain strong same-video interference or reliable
privileged supervision. We therefore derive HI-TVG-300 entirely from the
TimeLens-100K training set ([Zhang et al., 2026](#bib.bib7)). It reuses
selected videos and queries while refining target intervals and adding
verified distractor intervals, without introducing external videos or
queries. As summarized in
Figure [3](#S3.F3 "Figure 3 ‣ 3.4 Construction of HI-TVG-300 ‣ 3 Method ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding"),
we first balance candidate videos across duration ranges and source
datasets. GPT-5.6 then examines each complete video and its annotations
to identify repeated, similar, or opposite event occurrences and propose
refined target intervals. Human annotators verify the target boundaries,
distractor intervals, video quality, and queries. We retain examples
containing at least two valid same-video distractors. Finally, using the
same Qwen3-VL-8B checkpoint and sampling settings, the clean-video
student and privileged teacher independently generate eight responses.
We retain an example when the mean teacher tIoU exceeds $`0.7`$ and the
mean student tIoU is below $`0.3`$. This process produces 300 difficult
but teachable examples with verified same-video interference. Further
construction details, annotation protocols, and dataset statistics are
provided in
Appendix [A.5](#A1.SS5 "A.5 Training Set and Evaluation Protocol ‣ Appendix A Implementation and Reproducibility Details ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding").

![Refer to caption](2611.00120v1/images/data.png)

Figure 3: Construction pipeline of HI-TVG-300, derived entirely from the
TimeLens-100K training set. Candidate videos are balanced by duration
and source, mined for same-video interference, verified by human

## 4 Experiments

We evaluate DTP-OPSD through comparisons with representative TVG methods
and controlled ablations, with additional qualitative examples provided
in
Appendix [C](#A3 "Appendix C Additional Qualitative Example ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding").

### 4.1 Experimental Setup

#### Benchmarks and evaluation metrics.

We evaluate DTP-OPSD on Charades-STA ([Gao et al., 2017](#bib.bib1)),
ActivityNet Captions ([Krishna et al., 2017](#bib.bib5)), and
QVHighlights ([Lei et al., 2021](#bib.bib4)). Following TimeLens ([Zhang
et al., 2026](#bib.bib7)), we use its corrected benchmarks for analysis
and final reporting, referred to as Charades-TimeLens,
ActivityNet-TimeLens, and QVHighlights-TimeLens. We further evaluate on
OMTG-Bench ([Xu et al., 2026](#bib.bib31)) and QV-M² ([Cao et al.,
2025](#bib.bib30)), where a query may correspond to multiple valid
temporal intervals. We report mIoU as the primary metric, together with
R1@0.3, R1@0.5, and R1@0.7. mIoU averages the per-example tIoU, while
R1@$`m`$ measures the percentage of predictions with a tIoU of at least
$`m`$.

#### Implementation details.

We initialize Qwen3-VL-8B from the publicly released TimeLens supervised
checkpoint, denoted by TimeLens-SFT, and post-train it on HI-TVG-300,
which is derived entirely from the TimeLens-100K training set. Videos
are sampled at 2 FPS with a maximum of 448 frames and a visual-token
budget of 14,336. For each input, the student samples $`G=8`$ responses
for GRPO. The teacher independently samples the same number of responses
under identical sampling settings to estimate teacher competence. These
teacher rollouts are not used to compute the JSD loss. We use a global
batch of eight prompt-level rollout groups and a learning rate of
$`1\times 10^{-6}`$. Unless otherwise specified, results from our
post-training experiments and training ablations are reported as the
mean over three independent training runs. The global JSD coefficient is
set to $`\lambda_{\mathrm{JSD}}=1`$, and the reference-policy KL
coefficient is set to $`\beta=0`$. Additional training and
implementation details are provided in
Appendix [A](#A1 "Appendix A Implementation and Reproducibility Details ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding").

### 4.2 Comparison with State-of-the-Art Methods

#### Main results.

## 5 Conclusion

We study same-video interference in TVG, where a model can recognize the
queried event yet select the wrong occurrence. Under strong
interference, all sampled intervals may miss the target, producing an
all-zero tIoU group with no group-relative GRPO signal. DTP-OPSD
addresses this failure by combining GRPO with distractor-aware
temporal-privilege on-policy self-distillation. A shared-weight teacher
uses training-only target and distractor cues to provide token-level JSD
supervision on student-generated prefixes, while an adaptive controller
suppresses supervision when the teacher does not outperform the student
and strengthens it when the teacher performs better but all student
rollout tIoUs are zero. Using only 300 curated examples derived from
TimeLens-100K, DTP-OPSD achieves the highest mIoU among the compared
open-source 8B models on all three TimeLens benchmarks. Compared with
Pure GRPO trained on the same data, it improves all 12 reported metrics,
with R1@0.7 gains of 1.28, 1.62, and 1.78 points. These gains across
datasets and overlap thresholds show that training-only temporal
privilege can complement relative-reward optimization without additional
inputs or parameters during inference.

## Appendix A Implementation and Reproducibility Details

### A.1 Training Objective and Update Procedure

For completion token $`y_{g,i,t}`$, the importance ratio between the
current policy and the rollout snapshot is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\rho_{g,i,t}(\theta)=\frac{\pi_{\theta}(y_{g,i,t}\mid V_{g},q_{g},\hat{y}^{S}_{g,i,<t})}{\pi_{\theta_{\mathrm{old}}}(y_{g,i,t}\mid V_{g},q_{g},\hat{y}^{S}_{g,i,<t})}.
``` |  | (6) |

Using the group-relative advantage $`A_{g,i}`$ from
Equation [2](#S3.E2 "In Reward and group-relative optimization. ‣ 3.1 GRPO for TVG and Dead Groups ‣ 3 Method ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding"),
define

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widetilde{\rho}_{g,i,t}(\theta)=\operatorname{clip}\bigl(\rho_{g,i,t}(\theta),1-\epsilon,1+\epsilon\bigr).
``` |  | (7) |

The GRPO loss is

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathcal{L}_{\mathrm{GRPO}}`$ | $`\displaystyle=-\frac{1}{|\mathcal{B}|}\sum_{g\in\mathcal{B}}\frac{1}{G}\sum_{i=1}^{G}\frac{1}{T_{g,i}}\sum_{t=1}^{T_{g,i}}`$ |  | (8) |
|  |  | $`\displaystyle\min\bigl(\rho_{g,i,t}(\theta)A_{g,i},\widetilde{\rho}_{g,i,t}(\theta)A_{g,i}\bigr).`$ |  |  |

Here, $`\mathcal{B}`$ is a batch of prompt-level rollout groups, $`G=8`$
is the number of student completions per prompt, and $`T_{g,i}`$ is the
number of valid non-padding completion tokens. Prompt tokens are
excluded, while an emitted end-of-sequence token is included. Each
rollout batch is used for a single optimizer update. Therefore,
$`\theta=\theta_{\mathrm{old}}`$ when the gradient is evaluated and the
importance ratio equals one at the update point, making clipping
inactive in our setting.
Equation [8](#A1.E8 "In A.1 Training Objective and Update Procedure ‣ Appendix A Implementation and Reproducibility Details ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding")
consequently produces the same update direction as the corresponding
group-relative policy-gradient objective. We retain the standard GRPO
ratio form to make its relation to the conventional implementation
explicit. The reference-policy KL coefficient is $`\beta=0`$, so no
reference-KL term is added. The GRPO and JSD losses use the same
completion-level and token-level normalization before they are combined
in
Equation [5](#S3.E5 "In Final objective. ‣ 3.3 Adaptive Distillation Control ‣ 3 Method ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding").
Algorithm [1](#alg1 "Algorithm 1 ‣ A.1 Training Objective and Update Procedure ‣ Appendix A Implementation and Reproducibility Details ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding")
summarizes the complete training procedure.

1:  Input: Training set $`\mathcal{D}`$, shared policy $`\pi_{\theta}`$,
rollout size $`G`$, clipping width $`\epsilon`$, and global coefficient
$`\lambda_{\mathrm{JSD}}`$.

2:  Output: Optimized clean-video policy $`\pi_{\theta}`$.

3:  Pre-render each privileged view $`V_{g}^{\mathrm{priv}}`$ by marking
the expanded target interval in red and verified distractors in blue.

4:  for each prompt batch $`\mathcal{B}`$ in one training epoch do

5:   Set the rollout snapshot
$`\pi_{\theta_{\mathrm{old}}}\leftarrow\pi_{\theta}`$.

6:   for each rollout group $`g\in\mathcal{B}`$ do

7:    Sample $`G`$ student responses from
$`\pi_{\theta_{\mathrm{old}}}(\cdot\mid V_{g},q_{g})`$.

8:    Parse their intervals, compute student tIoU rewards, and obtain
the group-relative advantages $`\{A_{g,i}\}_{i=1}^{G}`$.

9:    Independently sample $`G`$ teacher responses from
$`\pi_{\theta_{\mathrm{old}}}(\cdot\mid V_{g}^{\mathrm{priv}},q_{g})`$
and compute $`\bar{r}_{g}^{T}`$ for the controller.

10:    for each student response $`\hat{y}_{g,i}^{S}`$ and valid token
$`t`$ do

11:     Evaluate the student distribution $`p_{S,g,i}^{t}`$ on
$`(V_{g},q_{g},\hat{y}_{g,i,<t}^{S})`$ with gradients.

12:     Evaluate the teacher distribution $`p_{T,g,i}^{t}`$ on
$`(V_{g}^{\mathrm{priv}},q_{g},\hat{y}_{g,i,<t}^{S})`$ with
stop-gradient.

13:    end for

14:    Compute the group-level JSD $`\ell_{g}^{\mathrm{JSD}}`$ and
select $`\lambda_{g}^{\mathrm{adapt}}\in\{0,1,2\}`$ using
Equation [4](#S3.E4 "In Adaptive distillation weight. ‣ 3.3 Adaptive Distillation Control ‣ 3 Method ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding").

15:   end for

16:   Compute $`\mathcal{L}_{\mathrm{GRPO}}`$ using
Equation [8](#A1.E8 "In A.1 Training Objective and Update Procedure ‣ Appendix A Implementation and Reproducibility Details ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding").

17:   Form $`\mathcal{L}_{\mathrm{total}}`$ using
Equation [5](#S3.E5 "In Final objective. ‣ 3.3 Adaptive Distillation Control ‣ 3 Method ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding")
and update $`\theta`$ once.

18:  end for

Distillation

For distillation, the teacher does not provide a separate target
response. Its independently sampled responses are used only to estimate
the teacher reward for the adaptive controller. The teacher distribution
used by JSD is instead evaluated on each student-generated prefix.

Each rollout batch is used for one optimizer update and is not reused
for inner optimization. Pure GRPO and DTP-OPSD follow the same
single-update convention. Teacher distributions are detached, recomputed
after every update, and never cached across updates.

### A.2 Training Protocol

A global batch contains eight prompt groups, each with eight student
completions, giving 64 student completions per update. DTP-OPSD also
samples eight teacher completions per prompt for controller estimation.
Teacher evaluation on student prefixes is a separate forward pass rather
than an additional rollout. The dataloader drops the final incomplete
batch. One epoch over the 300-example set therefore contains 37
optimizer updates, processes 296 examples, and omits four examples from
the shuffled order. Within every paired run, Pure GRPO and DTP-OPSD use
the same order and omit the same examples. Except for the
compute-matched control in
Section [D.2](#A4.SS2 "D.2 Compute-Matched Comparison ‣ Appendix D Stability and Efficiency ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding"),
all methods use one epoch and report the final checkpoint after 37
updates. We do not select an intermediate checkpoint based on benchmark
performance. Following the experimental practice of TimeLens ([Zhang et
al., 2026](#bib.bib7)), we use one shared configuration across the
TimeLens benchmarks. For compactness, detailed sensitivity results are
shown on QVHighlights-TimeLens. The resulting configuration is applied
unchanged to OMTG-Bench and QV-M². Unless otherwise specified, results
from our post-training experiments and training ablations are reported
as the mean over three independent training runs. The same three seeds
are used for paired method comparisons. Corresponding standard
deviations of the primary mIoU results are reported in
Section [D.1](#A4.SS1 "D.1 Stability Across Seeds ‣ Appendix D Stability and Efficiency ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding").

### A.3 Memory-Efficient JSD

At a student-prefix position, let $`p_{S}`$ and $`p_{T}`$ be the
clean-video student and privileged-view teacher distributions. We use
symmetric JSD with equal mixture weights and temperature $`1`$:

|     |                                                           |     |     |
|-----|-----------------------------------------------------------|-----|-----|
|     |
       ``` math
       q=\operatorname{sg}[p_{T}],\qquad m=\frac{1}{2}(p_{S}+q),
       ```                                                        |     | (9) |

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\operatorname{JSD}(p_{S},q)=\frac{1}{2}\operatorname{KL}(p_{S}\|m)+\frac{1}{2}\operatorname{KL}(q\|m).
``` |  | (10) |

The teacher distribution is detached, while the mixture retains its
dependence on $`p_{S}`$. Thus, both terms contribute gradients to the
student, but no gradient flows through the teacher branch.

To reduce memory, let $`\mathcal{K}_{t}`$ contain the 100 tokens with
the highest teacher probability at position $`t`$. For either
distribution $`p`$, we use the deterministic mapping

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Phi_{t}(p)=\left(\{p(v)\}_{v\in\mathcal{K}_{t}},\sum_{v\notin\mathcal{K}_{t}}p(v)\right).
``` |  | (11) |

We compute
$`\operatorname{JSD}(\Phi_{t}(p_{S}),\operatorname{sg}[\Phi_{t}(p_{T})])`$
over the resulting normalized 101-category distributions. The final
category keeps all probability mass outside the teacher top 100, so the
retained tokens are not renormalized in isolation. By the
data-processing inequality, this coarse-grained JSD is a lower bound on
the full-vocabulary JSD and provides a memory-efficient approximation
that preserves both the high-probability tokens and the remaining tail
mass. Tokens merged into the tail category are constrained through their
total probability mass rather than their individual probabilities.

Teacher forward passes use stop-gradient and BF16. Teacher rollout
generation, prefix evaluation, and student optimization are performed
sequentially, and compressed teacher logits are released immediately.
Training uses gradient checkpointing and DeepSpeed ZeRO-2 ([Rajbhandari
et al., 2020](#bib.bib20)) on eight NVIDIA H20 GPUs.

### A.4 Prompt, Reward Parsing, and Video Rendering

The parser extracts the predicted start and end times and computes tIoU
with the ground-truth interval. An unparseable interval, a negative
timestamp, or an end time earlier than the start time receives zero
reward. We use no separate format or temporal-distance reward.

The student and teacher use the same prompt:

> Please find the visual event described by the sentence
> ’{query}’, determining its starting and ending times.
> The format should be: ’The event happens in
> \<start time\> - \<end time\> seconds’.

An expected response is

> The event happens in 12.0 - 18.5 seconds.

The prompt does not name the border colors and requires neither a
\<think\> section nor an \<answer\> tag.

Privileged videos are pre-rendered and cached. Each target interval is
expanded by $`1.5\times`$ about its center and clipped to the valid
video range, so that the displayed cue does not directly coincide with
the annotated boundaries. Frames in this region receive red full-frame
borders, while frames in verified distractor intervals receive blue
borders; red takes priority in overlap regions. Distractor intervals are
not expanded, and the student receives the unchanged video.

### A.5 Training Set and Evaluation Protocol

HI-TVG-300 contains 300 query–video pairs from the TimeLens-100K
training split, without external videos or queries. Each example has at
least two human-verified distractor occurrences from the same video.
Candidates are sampled across source datasets and duration ranges. A VLM
proposes repeated, similar, related, or opposite occurrences, after
which human annotators verify the video, query, target boundaries, and
all distractor intervals.

Using the same Qwen3-VL-8B checkpoint and sampling settings, the clean
student and privileged teacher each generate eight independent
completions during offline filtering. We retain an example when the
teacher mean tIoU is above $`0.7`$ and the student mean tIoU is below
$`0.3`$. Released annotations include the refined target and all
verified distractor intervals.

The human-verified control in
Table [4](#S4.T4 "Table 4 ‣ Effect of training data curation. ‣ 4.3 Ablation Study ‣ 4 Experiments ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding")
is sampled after VLM screening and manual verification but before the
teacher–student teachability filter. It therefore uses refined target
boundaries and verified distractor intervals without filtering examples
according to the privileged-teacher advantage.

All methods in the main comparison are evaluated using the corrected
TimeLens annotations and the same TimeLens evaluation protocol. Results
from our implementation use the same prompt, parser, and tIoU code.
Videos are sampled at 2 FPS with at most 448 frames and a visual-token
budget of 14,336. For QV-M², we evaluate all 323 queries in the official
test split and apply no availability-based query filtering.

For the distractor-count analysis in
Figure [1](#S1.F1 "Figure 1 ‣ 1 Introduction ‣ DTP-OPSD: Reinforcement Learning with Distractor-Aware Temporal-Privilege On-Policy Self-Distillation for Temporal Video Grounding"),
target windows come from the corrected evaluation annotations. Candidate
same-video distractors are screened and manually verified before
examples are grouped by distractor count. These evaluation-side
annotations are used only for analysis and do not affect training or
model selection.

The random control is a fixed 300-example draw from the same
TimeLens-100K pool. For each query, its original TimeLens target
interval is expanded by $`1.5\times`$ and marked in red. Intervals
annotated for other queries associated with the same video are used as
candidate blue cues when available. This row uses neither manual
target-boundary refinement nor human verification of whether the blue
intervals are valid distractors for the current query. It obtains
$`79.75/70.62/54.90`$ for R1@0.3/0.5/0.7 and $`65.53`$ mIoU on
QVHighlights-TimeLens. All rows use DTP-OPSD, which isolates the effect
of successive stages in the data-curation pipeline under a fixed
training method.

## Appendix F Limitations

DTP-OPSD focuses on same-video interference. HI-TVG-300 contains only
300 examples from TimeLens-100K and does not cover every temporal
grounding error, video domain, or annotation style. All tested backbones
also belong to the Qwen3-VL family. The privileged view requires
verified target and distractor intervals, which adds data-preparation
cost. Teachability filtering favors examples with a clear
privileged-teacher advantage and may underrepresent cases in which both
views remain uncertain. Expanding the target cue avoids directly
displaying the annotated boundaries but does not remove all temporal
information leakage. Teacher rollouts and prefix evaluation increase
post-training cost. The method also remains more expensive to train than
Pure GRPO. The controller relies on Monte Carlo estimates from eight
student and eight teacher completions, so its group-level decisions
remain subject to sampling variance. The data ablation changes the
training subset while keeping DTP-OPSD fixed, so it measures the
contribution of the complete curation pipeline rather than independently
isolating every curation stage. The privileged cues, teacher branch, and
adaptive controller are used only during training. The final model
receives clean videos and adds no parameters or computation at
inference.
````
