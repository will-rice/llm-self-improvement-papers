###### Abstract

LLM agents increasingly operate in long-horizon, verifier-rich
environments, but current self-improvement mechanisms often write
episode-derived lessons directly into memory, making local success an
unreliable signal for reusable and safe knowledge. This paper addresses
the core question of when an experience-derived behavioral update should
be admitted into persistent agent state. We propose Falsification-Gated
Self-Evolution (FGSE), a verifier-grounded framework that represents
each candidate lesson as a structured hypothesis with an explicit
precondition, behavior change, expected effect, and verifier. FGSE
applies the hypothesis only in a temporary state, tests it on
target-transfer, falsification, and archived-regression probes, and then
commits, refines, or rejects it according to measured gain and risk.
Across web, app, tool-use, and long-term memory benchmarks, FGSE
achieves strong task performance, including 39.8 WebArena success rate,
78.8 AppWorld average completion, and 0.724/0.487 Pass¹ on
$`\tau`$-Retail/$`\tau`$-Airline, while reducing falsification failures
to 5.0%, regression damage to 1.3%, and harmful committed updates to
3.6%. These results suggest that testing memory updates as hypotheses
supports more reliable long-term adaptation.

## 1 Introduction

Large language model (LLM) agents are increasingly expected to operate
in long-horizon, interactive environments where they must reason, call
tools, update internal context, and recover from mistakes ([Yao et al.,
2023](#bib.bib66)). This capability supports web navigation, app-level
tool use, and user-facing assistance ([Zhou et al., 2024](#bib.bib83);
[Trivedi et al., 2024](#bib.bib46); [Yao et al., 2024](#bib.bib67));
embodied interaction additionally requires grounding language in visual
and gestural context ([Li et al., 2023](#bib.bib25)). Continual
deployment requires agents to solve current tasks and safely learn
reusable behavioral knowledge from experience.

Recent work has made substantial progress toward self-improving agents
through self-feedback and reflection ([Madaan et al.,
2023](#bib.bib32)), verbal reinforcement from past failures ([Shinn
et al., 2023](#bib.bib41)), reusable skill memory ([Wang et al.,
2023](#bib.bib47); [Li et al., 2026b](#bib.bib24)), agentic long-term
memory organization ([Xu et al., 2025](#bib.bib59)), and evolving
symbolic contexts or playbooks ([Zhou et al., 2025](#bib.bib84); [Zhang
et al., 2026f](#bib.bib77)). These methods show that storing lessons,
memories, playbooks, or revised contexts can improve future performance
without necessarily updating model weights. An episode-derived update
may improve tasks that resemble the triggering episode while
overgeneralizing to superficially similar but semantically different
situations, conflicting with previously successful behaviors, or
accumulating as stale persistent memory. Even in verifier-rich
environments, where task success can often be checked after execution,
existing self-evolution mechanisms lack a principled criterion for
assessing an update’s transferability, retention value, and commitment
risk. The central question is how to govern the transition from
temporary experience to persistent agent state under transfer, safety,
and regression constraints.

![Refer to caption](2611.14326v1/teaser.png)

Figure 1: A locally useful episode-derived lesson may overgeneralize or

We study when an experience-derived behavioral update should enter an
LLM agent’s long-term memory. Our approach treats persistent updates as
testable hypotheses. As shown in
Fig. [1](#S1.F1 "Figure 1 ‣ 1 Introduction ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents"),
our approach temporarily applies each candidate update, evaluates its
transfer beyond the source episode, robustness to targeted
counterexamples, and preservation of archived successful behavior, and
then commits, refines, or rejects it.

We make the following contributions: (i) We identify a core failure mode
of self-evolving agents: target improvement alone is an unreliable
signal for persistent memory writing, because many apparently useful
updates encode unsafe shortcuts or overly broad applicability
conditions. (ii) We introduce Falsification-Gated Self-Evolution (FGSE),
a verifier-grounded framework that treats candidate updates as testable
hypotheses and performs structured commit–refine–reject triage before
long-term retention. (iii) Across web, app, tool-use, and long-term
memory settings, FGSE improves task performance while reducing
falsification failures, regression damage, harmful committed updates,
and post-commit violations compared with reflection-, memory-, and
context-evolution baselines.

## 2 Related Work

Interactive language agents and verifier-rich environments. LLM agents
combine reasoning with external actions, from ReAct ([Yao et al.,
2023](#bib.bib66)) to tool use ([Qin et al., 2024](#bib.bib37); [Chen
and Liu, 2026](#bib.bib5); [Xiao et al., 2026b](#bib.bib54)), while
LLM-derived traffic context also augments motion prediction ([Zheng
et al., 2024](#bib.bib79)). This progress has enabled realistic web,
app, and tool-use benchmarks ([Zhou et al., 2024](#bib.bib83); [Trivedi
et al., 2024](#bib.bib46); [Yao et al., 2024](#bib.bib67); [Debenedetti
et al., 2024](#bib.bib8)), where success can often be checked by
executable validators, database states, user goals, or safety
constraints. Healthcare-agent evaluation protocols additionally assess
episode-level state continuity, evidence traceability, and escalation
decisions ([Yao et al., 2026](#bib.bib65)). Complementary work verifies
and repairs synthetic web environments before agent training ([Zhang
et al., 2026a](#bib.bib69)). A YANG-grounded LLM agent supports
multi-vendor OpenROADM management through schema retrieval and
validation of generated configurations ([Xiao et al.,
2026c](#bib.bib55)). Complementary network-diagnosis work uses
multi-head graph attention to jointly address alarm correlation and root
alarm detection in optical transport networks ([Xiao et al.,
2025](#bib.bib53)). Medical-agent security combines risk perception,
evidence constraints, and knowledge-consistency verification ([Hu,
2026](#bib.bib15)). Broader security research studies quantitative
vulnerability assessment ([Shao, 2026b](#bib.bib40)), SHAP-based
explanations for network anomaly detection ([Shao, 2026a](#bib.bib39)),
APT attribution over heterogeneous threat knowledge graphs ([Wang
et al., 2026](#bib.bib49)), and provenance-graph anomaly detection ([Ma
et al., 2026](#bib.bib31)). FGSE builds on verifier-rich settings and
applies verification to candidate behavioral updates before persistent
commitment, testing transfer, falsification, and regression safety.

Memory and context-based self-improvement. Another line improves agents
without updating model weights. Self-Refine ([Madaan et al.,
2023](#bib.bib32)) and Reflexion ([Shinn et al., 2023](#bib.bib41))
revise future behavior through self-feedback or verbal reinforcement,
while Voyager ([Wang et al., 2023](#bib.bib47)) stores reusable
executable skills. Persistent-memory systems such as Generative
Agents ([Park et al., 2023](#bib.bib36)), MemoryBank ([Zhong et al.,
2024](#bib.bib81)), MemGPT ([Packer et al., 2023](#bib.bib34)), and
A-Mem ([Xu et al., 2025](#bib.bib59)) organize memories for retrieval,
reflection, and personalization, with LoCoMo ([Maharana et al.,
2024](#bib.bib33)) and LongMemEval ([Wu et al., 2024](#bib.bib50))
evaluating long-horizon memory utility. Recent context-evolution
methods, including Symbolic Learning ([Zhou et al., 2025](#bib.bib84)),
Lighthouse ([Yang et al., 2025](#bib.bib64)), and ACE ([Zhang et al.,
2026f](#bib.bib77)), further revise prompts, playbooks, critiques, or
contexts from execution feedback. These methods show that textual
updates can improve agents, but they may overgeneralize local lessons,
accumulate stale or conflicting memories, or degrade useful context
during iterative rewriting, echoing concerns about unreliable
self-correction ([Huang et al., 2024](#bib.bib18); [Liu et al.,
2026b](#bib.bib28)) and unsafe misevolution ([Shao et al.,
2026](#bib.bib38)). Adjacent retrieval studies distinguish semantic
relevance from factual consistency in RAG ([Ye et al.,
2026](#bib.bib68)) and show benefits of exemplar diversity under matched
context budgets for multi-turn intent understanding ([Lin et al.,
2026](#bib.bib26)). FGSE treats each lesson as a structured,
verifier-grounded hypothesis and commits it only after falsification and
regression testing.

Capability-level contribution evidence. [Xu et al. (2026c)](#bib.bib60)
propose an observable evidence standard for added planning capabilities,
separating presence, opportunity to act, executed-plan change, and
incremental operational consequence under controlled replay, with
explicit treatment of equivalence, uncertainty, and operating scope.
Their analysis requires capability-specific contribution evidence for
acceptance, beyond aggregate policy gains or proxy diagnostics. For
memory updates, contribution likewise depends on verified behavioral
effects beyond storage or retrieval. FGSE evaluates each update against
the current agent in a temporary state and requires target-transfer
gain, falsification resistance, and regression preservation before
commitment
(Eq. ([8](#S4.E8 "In Commitment gate. ‣ 4.2 Falsification-Gated Self-Evolution ‣ 4 Method ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")));
subsequent activation requires a matching precondition and a violation
record below threshold
(Section [4.3](#S4.SS3 "4.3 Runtime Use and Monitoring ‣ 4 Method ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")).
These conditions link contribution evidence to verification and bounded
activation of memory updates.

Automated agent optimization and self-evolution. Beyond memory writing,
recent work optimizes agent systems by searching over prompts, graph
structures, workflows, or multi-agent state machines ([Yang et al.,
2024](#bib.bib61); [Zhuge et al., 2024](#bib.bib85); [Zhang et al.,
2025a](#bib.bib76); [Hu et al., 2025](#bib.bib16); [Zhang et al.,
2025b](#bib.bib78)), and improves reasoning policies through test-time
reinforcement learning, self-generated curricula, or tool-integrated
co-evolution ([Zuo et al., 2025](#bib.bib86); [Tian et al.,
2025](#bib.bib44); [Huang et al., 2026a](#bib.bib17); [Xia et al.,
2025](#bib.bib51)). In Text-to-SQL, an autonomy-based taxonomy
highlights execution-guided self-correction and modular agent
collaboration ([Su et al., 2027](#bib.bib42)). Continual adaptation also
studies how to preserve knowledge under bounded resources: CoMem ([Zhou
et al., 2026](#bib.bib82)) uses concept-graph memory and feature-space
rehearsal for vision–language adaptation; InduceKV ([Chen et al.,
2026](#bib.bib4)) externalizes multimodal adaptation into budgeted
key–value memories; and Meta-UCF ([Xiao et al., 2026d](#bib.bib56))
generates task-conditioned LoRA updates with a shared hypernetwork.
Compo-ReAlign ([Xiao et al., 2026a](#bib.bib52)) preserves compositional
structure through reversible alignment and sensitivity-constrained
updates, while Affordance-First Decomposition ([Xu et al.,
2026b](#bib.bib58)) separates a stable affordance substrate from
query-routed, conflict-aware adaptation in video–language learning.
These lines address adaptation capacity, retention, and resource
efficiency, alongside cross-domain studies of recoverable model
pruning ([Lu et al., 2026](#bib.bib30)), multi-scale and attention-based
visual processing ([Zhang et al., 2023](#bib.bib70); [Zhang et al.,
2024](#bib.bib71); [Zhang et al., 2026d](#bib.bib74)), activation design
and LLM-guided fusion for forecasting ([Zhang et al.,
2026b](#bib.bib72); [Zhang et al., 2026c](#bib.bib73)), and operational
decision making through semantic evidence for inspection allocation ([He
et al., 2026](#bib.bib13)), causal intervention ranking ([Huang et al.,
2026b](#bib.bib19)), and accuracy–stability trade-offs in
forecasting ([Li et al., 2026a](#bib.bib23)). FGSE addresses a
complementary update-level problem: it falsifies each episode-derived
update before persistent commitment, preserving self-evolution
plasticity while controlling unsafe transfer and regression.

## 3 Preliminary Study

A common self-improvement strategy is to summarize completed episodes
into reflective text or experiential insights and store them in memory
for future decision making ([Shinn et al., 2023](#bib.bib41)). While
such updates can help on similar tasks, they may overgeneralize, disrupt
previously solved behaviors, or encode brittle shortcuts. We
characterize these failure modes in a diagnostic study.

Diagnostic setup. For each completed episode, the base agent generates a
free-form update $`u`$, such as a rule, reminder, or behavioral
correction, which we inject into the memory prompt and compare against
the original agent. For analysis, we evaluate $`u`$ on four case groups:
source replay, near transfer, boundary contrast, and archived success,
corresponding to the original episode neighborhood, intended-pattern
transfer, superficially similar non-trigger cases, and previously solved
tasks. For each group $`\mathcal{C}`$, we measure the average
verifier-score change induced by $`u`$:

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\Delta_{\mathcal{C}}(u)=\frac{1}{|\mathcal{C}|}\sum_{x\in\mathcal{C}}\left[J(\Theta\oplus u,x)-J(\Theta,x)\right],
``` |  | (1) |

where $`\Theta`$ is the original agent state and $`\Theta\oplus u`$
denotes the same agent with the free-form lesson $`u`$ appended to
memory. We report near-transfer gain $`\Delta_{\mathrm{near}}(u)`$,
boundary harm $`[-\Delta_{\mathrm{boundary}}(u)]_{+}`$, and archive harm
$`[-\Delta_{\mathrm{archive}}(u)]_{+}`$. We also annotate each lesson
with a coarse scope-specificity score in $`[0,1]`$, where lower values
indicate broader and less conditional updates.

![Refer to caption](2611.14326v1/preliminary_diagnostics.png)

Figure 2: Exploratory diagnostics for naive episode-derived
self-updates. (a) Many updates combine near-transfer gains with boundary
harm. (b) Broad and underspecified updates produce substantially higher
boundary and archive harm than more specific updates. (c) Sequentially
writing free-form lessons into memory can accumulate errors, especially
when updates are selected only by source-episode improvement. (d) A
post-hoc scope-localization analysis shows that many harmful but useful
updates can be repaired by narrowing their applicability, motivating an
explicit refinement mechanism.

Findings.
Figure [2](#S3.F2 "Figure 2 ‣ 3 Preliminary Study ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
shows that naive memory writing is useful but unreliable. Free-form
lessons often improve near-transfer cases but can cause boundary harm,
indicating that locally valid behaviors may be applied in inappropriate
contexts. This failure is closely tied to scope: broad, underspecified
lessons produce larger boundary and archive degradation than more
specific ones, and sequentially writing them into memory accumulates
errors despite short-term source gains. Post-hoc localization further
shows that some harmful updates contain valid rules with overly broad
applicability; narrowing their scope can retain transfer benefits while
reducing harm. These findings motivate FGSE, which treats
episode-derived lessons as structured, falsifiable hypotheses, tests
them temporarily on target, boundary, and archived cases, and commits or
refines them only when supported by evidence.

## 4 Method

### 4.1 Overview

We propose Falsification-Gated Self-Evolution (FGSE), a
verifier-grounded framework for reliable long-term improvement of
language agents. Given an episode, FGSE converts the observed success or
failure into a structured behavioral hypothesis that specifies its
precondition, behavior change, expected effect, and verifier. The
hypothesis is applied only temporarily and evaluated on target-transfer
probes and falsification probes. It is committed to persistent agent
state only when it improves target cases, survives targeted
falsification, and preserves previously solved behavior. Hypotheses with
localized failures are refined once through precondition narrowing and
reevaluated; hypotheses that still fail are rejected.
Figure [3](#S4.F3 "Figure 3 ‣ 4.1 Overview ‣ 4 Method ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
summarizes the pipeline, with probe construction and refinement details
provided in
Appendix [A.2](#A1.SS2 "A.2 Verifier-Grounded Probe Construction ‣ Appendix A Additional Technical Details ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
and
Appendix [A.3](#A1.SS3 "A.3 Precondition Refinement ‣ Appendix A Additional Technical Details ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents").

### 4.2 Falsification-Gated Self-Evolution

#### Verifier-grounded agent state.

At episode $`t`$, the agent receives a task $`x_{t}`$ and acts under
persistent state

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Theta_{t}=(\mathcal{M}_{t},\pi_{t}),\qquad J_{v}(\Theta,x)=\mathbb{E}_{\tau\sim p_{\Theta}(\cdot\mid x)}\left[v(x,\tau)\right].
``` |  | (2) |

Here, $`\mathcal{M}_{t}`$ is the retrievable memory of committed
evolution units, $`\pi_{t}`$ is the current agent policy,
$`p_{\Theta}(\tau\mid x)`$ is the trajectory distribution induced by
state $`\Theta`$ on task $`x`$, and $`v(x,\tau)\in[0,1]`$ is a
verifier-grounded score. The expectation accounts for stochastic
decoding, tool uncertainty, and multi-step interaction. A completed
episode yields a trajectory $`\tau_{t}`$ and verifier result
$`r_{t}=v_{t}(x_{t},\tau_{t})`$, from which FGSE forms an evidence
packet $`E_{t}=(x_{t},\tau_{t},r_{t},\mathcal{A}_{t})`$ using the audit
archive $`\mathcal{A}_{t}`$.

#### Structured evolution hypothesis.

Each candidate update is represented as

|     |                              |     |     |
|-----|------------------------------|-----|-----|
|     |
       ``` math
       h=(c_{h},b_{h},e_{h},v_{h}).
       ```                           |     | (3) |

The precondition $`c_{h}:\mathcal{Z}\rightarrow[0,1]`$ assigns an
applicability score to an interaction state $`z=(x,\tau_{<\ell})`$. The
behavior transformation $`b_{h}`$ maps the current policy to a modified
policy $`b_{h}[\pi_{\Theta}]`$. The expected-effect checker $`e_{h}`$
specifies the verifier-observable outcome that should hold after
applying the update. The verifier $`v_{h}`$ provides the task-level
score used to evaluate improvement, failure, and regression. The
proposer $`H_{\phi}`$ maps the evidence packet to a schema-constrained
hypothesis, $`h_{t}=H_{\phi}(E_{t})`$. The proposer generates
candidates; the commitment gate determines their retention.

The hypothesis is activated only when its precondition is satisfied:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
g_{h}(z)=\mathbb{I}[c_{h}(z)\geq\gamma_{h}],\qquad\pi_{\Theta_{t}\oplus h}(a\mid z)=(1-\lambda_{h}g_{h}(z))\pi_{\Theta_{t}}(a\mid z)+\lambda_{h}g_{h}(z)b_{h}[\pi_{\Theta_{t}}](a\mid z).
``` |  | (4) |

Here, $`\gamma_{h}`$ is the activation threshold,
$`\lambda_{h}\in[0,1]`$ is the intervention strength, and
$`\Theta_{t}\oplus h`$ denotes temporary application of $`h`$ without
changing persistent memory. The temporary policy remains a valid action
distribution because
Eq. ([4](#S4.E4 "In Structured evolution hypothesis. ‣ 4.2 Falsification-Gated Self-Evolution ‣ 4 Method ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents"))
is a convex combination of two valid policies.

#### Verifier-grounded probes.

For a candidate hypothesis $`h`$, FGSE constructs a target-transfer set
$`\mathcal{T}(h)`$, a falsification set $`\mathcal{F}(h)`$, and a
regression set $`\mathcal{R}(h)`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{P}(h)=\mathcal{T}(h)\cup\mathcal{F}(h)\cup\mathcal{R}(h).
``` |  | (5) |

The target-transfer set contains cases where the hypothesis is expected
to help. The falsification set contains cases designed to expose
overgeneralization. The regression set $`\mathcal{R}(h)`$ contains
archived cases that the current agent already solves and that must not
be degraded. A probe $`x`$ is admitted only when
$`\operatorname{Verifiable}(x,v_{h})=1`$, ensuring that the gate is
based on executable or externally checkable signals. FGSE builds
falsification probes from boundary cases, precondition violations,
regression cases, and decoys; their construction is described in
Appendix [A.2](#A1.SS2 "A.2 Verifier-Grounded Probe Construction ‣ Appendix A Additional Technical Details ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents").

#### Temporary evaluation.

FGSE evaluates $`h`$ by comparing the original state $`\Theta_{t}`$ with
the temporary state $`\Theta_{t}\oplus h`$ on the same probes:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Delta_{h}(x)=J_{v_{h}}(\Theta_{t}\oplus h,x)-J_{v_{h}}(\Theta_{t},x).
``` |  | (6) |

A positive $`\Delta_{h}(x)`$ means that the hypothesis improves
verifier-grounded performance on $`x`$, while a negative value indicates
harm. Empirical estimation under repeated rollouts is given in
Appendix [A.4](#A1.SS4 "A.4 Empirical Estimation Under Stochastic Rollouts ‣ Appendix A Additional Technical Details ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents").

Let $`E_{h}(\Theta,x)\in\{0,1\}`$ denote whether the expected effect
$`e_{h}`$ is satisfied under state $`\Theta`$ on task $`x`$. FGSE
computes

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\widehat{G}(h)`$ | $`\displaystyle=\frac{1}{|\mathcal{T}(h)|}\sum_{x\in\mathcal{T}(h)}\Delta_{h}(x),`$ |  | (7) |
|  | $`\displaystyle\widehat{P}_{\mathrm{fail}}(h)`$ | $`\displaystyle=\frac{1}{|\mathcal{F}(h)|}\sum_{x\in\mathcal{F}(h)}\mathbb{I}\!\left[\Delta_{h}(x)<-\epsilon\vee E_{h}(\Theta_{t}\oplus h,x)=0\right],`$ |  |  |
|  | $`\displaystyle\widehat{D}_{\mathrm{reg}}(h)`$ | $`\displaystyle=\frac{1}{|\mathcal{R}(h)|}\sum_{x\in\mathcal{R}(h)}[-\Delta_{h}(x)]_{+}.`$ |  |  |

Here, $`\epsilon\geq 0`$ is the tolerated verifier-score drop and
$`[\cdot]_{+}=\max(\cdot,0)`$. The three statistics measure useful
transfer, targeted falsification risk, and regression damage.

#### Commitment gate.

The commitment decision is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathsf{Commit}(h)=\mathbb{I}\left[\widehat{G}(h)\geq\eta\wedge\widehat{P}_{\mathrm{fail}}(h)\leq\delta\wedge\widehat{D}_{\mathrm{reg}}(h)\leq\beta\right],
``` |  | (8) |

where $`\eta>0`$ is the minimum target-transfer gain, $`\delta\in[0,1]`$
is the maximum falsification rate, and $`\beta\geq 0`$ is the maximum
regression damage. If $`\widehat{G}(h)\geq\eta`$ but failures are
concentrated outside a separable sub-scope, FGSE performs one
precondition-refinement pass and reevaluates the refined hypothesis. The
refinement objective and separability criterion are given in
Appendix [A.3](#A1.SS3 "A.3 Precondition Refinement ‣ Appendix A Additional Technical Details ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents").
A hypothesis that fails after refinement is rejected.

The persistent state is updated by

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Theta_{t+1}=\begin{cases}\Theta_{t}\oplus h,&\mathsf{Commit}(h)=1,\\
\Theta_{t},&\mathsf{Commit}(h)=0.\end{cases}
``` |  | (9) |

A committed hypothesis is stored together with its precondition,
behavior change, verifier, evaluated probes, verifier outcomes, and
post-commit violation record. Rejected hypotheses are excluded from
retrievable memory.

### 4.3 Runtime Use and Monitoring

During future inference, FGSE retrieves committed hypotheses whose
preconditions match the current interaction state and whose violation
records remain below threshold. Activated hypotheses modify the policy
through the same behavior-transformation interface as
Eq. ([4](#S4.E4 "In Structured evolution hypothesis. ‣ 4.2 Falsification-Gated Self-Evolution ‣ 4 Method ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")).
When multiple hypotheses are active, FGSE combines them by normalized
precondition scores while preserving a nonzero base-policy contribution.
Post-commit violations update a running violation score; hypotheses
exceeding the violation threshold are removed from retrieval. The
retrieval, combination, and monitoring rules are provided in
Appendix [A.5](#A1.SS5 "A.5 Runtime Retrieval, Combination, and Monitoring ‣ Appendix A Additional Technical Details ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents").

0:  Agent state $`\Theta_{t}`$, task $`x_{t}`$, trajectory $`\tau_{t}`$,
verifier result $`r_{t}`$, audit archive $`\mathcal{A}_{t}`$

0:  Updated state $`\Theta_{t+1}`$

1:  Form evidence packet
$`E_{t}=(x_{t},\tau_{t},r_{t},\mathcal{A}_{t})`$.

2:  Propose structured hypothesis $`h=H_{\phi}(E_{t})`$ with fields
$`(c_{h},b_{h},e_{h},v_{h})`$.

3:  Construct $`\mathcal{T}(h)`$, $`\mathcal{F}(h)`$, and
$`\mathcal{R}(h)`$ under verifier constraint
$`\operatorname{Verifiable}(x,v_{h})=1`$.

## 5 Theoretical Analysis

We analyze whether a hypothesis that passes the finite-probe commitment
gate is reliable on the underlying target, falsification, and regression
probe distributions. Fix a round $`t`$ and condition on the
pre-evaluation history, so the current state $`\Theta_{t}`$, evidence
packet, and finite candidate set $`\mathcal{H}_{t}`$ are fixed. If scope
refinement is used, refinement is performed on a development split,
while final commitment uses fresh probes.

For each $`h\in\mathcal{H}_{t}`$, let $`\mathcal{D}_{T}(h)`$,
$`\mathcal{D}_{F}(h)`$, and $`\mathcal{D}_{R}(h)`$ denote the
target-transfer, falsification, and regression probe distributions. We
define

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle G(h)`$ | $`\displaystyle=\mathbb{E}_{x\sim\mathcal{D}_{T}(h)}\left[\Delta_{h}(x)\right],`$ |  | (10) |
|  | $`\displaystyle P_{\mathrm{fail}}(h)`$ | $`\displaystyle=\mathbb{P}_{x\sim\mathcal{D}_{F}(h)}\left[\Delta_{h}(x)<-\epsilon\ \vee\ E_{h}(\Theta_{t}\oplus h,x)=0\right],`$ |  |  |
|  | $`\displaystyle D_{\mathrm{reg}}(h)`$ | $`\displaystyle=\mathbb{E}_{x\sim\mathcal{D}_{R}(h)}\left[[-\Delta_{h}(x)]_{+}\right].`$ |  |  |

These quantities measure useful transfer, falsification risk, and
regression damage, respectively. Let $`\mathrm{LCB}_{T}(h)`$,
$`\mathrm{UCB}_{F}(h)`$, and $`\mathrm{UCB}_{R}(h)`$ be one-sided
confidence bounds for these three quantities, computed from fresh final
probes using empirical-Bernstein bounds for real-valued gains and
Bernoulli-KL bounds for falsification events. Their finite-sample forms
are given in
Appendix [B.2](#A2.SS2 "B.2 Confidence Bounds Used by the Commitment Gate ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents").

###### Theorem 1 (Generalization of the confidence-gated commitment rule).

Suppose that, conditional on the pre-evaluation history, the final
probes for each $`h\in\mathcal{H}_{t}`$ are sampled from
$`\mathcal{D}_{T}(h)`$, $`\mathcal{D}_{F}(h)`$, and
$`\mathcal{D}_{R}(h)`$. Then, with probability at least $`1-\alpha`$,
all $`h\in\mathcal{H}_{t}`$ simultaneously satisfy

|  |  |  |  |
|----|----|----|----|
|  |
``` math
G(h)\geq\mathrm{LCB}_{T}(h),\qquad P_{\mathrm{fail}}(h)\leq\mathrm{UCB}_{F}(h),\qquad D_{\mathrm{reg}}(h)\leq\mathrm{UCB}_{R}(h).
``` |  | (11) |

Consequently, any hypothesis satisfying

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{LCB}_{T}(h)\geq\eta,\qquad\mathrm{UCB}_{F}(h)\leq\delta,\qquad\mathrm{UCB}_{R}(h)\leq\beta
``` |  | (12) |

also satisfies the population constraints

|  |  |  |  |
|----|----|----|----|
|  |
``` math
G(h)\geq\eta,\qquad P_{\mathrm{fail}}(h)\leq\delta,\qquad D_{\mathrm{reg}}(h)\leq\beta.
``` |  | (13) |

#### Proof sketch.

Conditioning on the pre-evaluation history fixes $`\mathcal{H}_{t}`$ and
prevents final probes from being reused for hypothesis construction.
Empirical-Bernstein inequalities control the bounded target-transfer and
regression quantities, while a Bernoulli-KL bound controls falsification
risk. A union bound over hypotheses and statistics gives the
simultaneous high-probability event, under which the confidence-gated
rule implies the corresponding population constraints.

###### Corollary 1 (Probe complexity of safe commitment).

Up to logarithmic factors in $`|\mathcal{H}_{t}|`$, $`1/\alpha`$, and
the number of falsification probes, it suffices to use

|  |  |  |  |
|----|----|----|----|
|  |
``` math
n_{T}=\widetilde{O}\!\left(\frac{1}{\zeta_{T}^{2}}\right),\qquad n_{R}=\widetilde{O}\!\left(\frac{1}{\zeta_{R}^{2}}\right),\qquad n_{F}=\widetilde{O}\!\left(\frac{1}{\mathrm{kl}(\delta_{-}\|\delta)}\right)
``` |  | (14) |

final target, regression, and falsification probes to ensure that any
hypothesis with empirical target margin $`\zeta_{T}`$, empirical
regression margin $`\zeta_{R}`$, and empirical falsification rate at
most $`\delta_{-}<\delta`$ satisfies $`G(h)\geq\eta`$,
$`P_{\mathrm{fail}}(h)\leq\delta`$, and $`D_{\mathrm{reg}}(h)\leq\beta`$
with probability at least $`1-\alpha`$. The exact finite-sample
statement is proved in
Appendix [B.7](#A2.SS7 "B.7 Proof of Corollary ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents").

## 6 Experiments

### 6.1 Experimental Setup

Datasets. We evaluate FGSE on verifier-grounded agentic tasks where
updates can be tested before persistent commitment. The benchmark suite
covers web and browser control with WebArena ([Zhou et al.,
2024](#bib.bib83)) and BrowserGym ([Le Sellier de Chezelles et al.,
2025](#bib.bib22)), app and API interaction with AppWorld ([Trivedi
et al., 2024](#bib.bib46)) and $`\tau`$-bench ([Yao et al.,
2024](#bib.bib67)), adversarial tool-use robustness with
AgentDojo ([Debenedetti et al., 2024](#bib.bib8)), and long-term memory
reliability with LongMemEval ([Wu et al., 2024](#bib.bib50)) and
LoCoMo ([Maharana et al., 2024](#bib.bib33)). We also include
verifier-rich coding and reasoning diagnostics on HumanEval ([Chen
et al., 2021](#bib.bib3)), MBPP ([Austin et al., 2021](#bib.bib2)),

including success rate, task-goal completion, pass rate or
$`\mathrm{pass}^{k}`$, utility and security success, QA accuracy/F1,
pass@1, resolved rate, and exact-match accuracy. To evaluate safe
self-evolution, we additionally report target-transfer gain
$`\widehat{G}`$, falsification failure rate
$`\widehat{P}_{\mathrm{fail}}`$, regression damage
$`\widehat{D}_{\mathrm{reg}}`$, post-commit violation rate, and harmful
update rate.

transfer beyond the triggering case. We therefore evaluate each
candidate before commitment using three temporary statistics:
target-transfer gain $`\widehat{G}(h)`$, falsification failure rate
$`\widehat{P}_{\mathrm{fail}}(h)`$, and regression damage
$`\widehat{D}_{\mathrm{reg}}(h)`$.

Commit–refine–reject decision boundary. To examine the gate, we map each
candidate into a simplex over normalized target gain, falsification
risk, and regression damage. For each candidate $`h`$, we normalize the
three statistics across candidates and project them onto simplex

gain-dominant updates, refining repairable but ambiguous ones, and
rejecting risk-dominant candidates.

## 7 Conclusion

We studied reliable self-evolution for long-horizon LLM agents, focusing
on when episode-derived lessons should enter persistent memory. FGSE
treats each candidate update as a structured, verifier-grounded
hypothesis and commits it only after target-transfer, falsification, and
regression testing. Our results show that safe adaptation requires
evaluating usefulness, boundary failures, and regression on previously
solved behavior alongside source-task improvement. Future work can
extend falsification-gated update control to multimodal agents ([Xu
et al., 2026a](#bib.bib57); [Dong et al., 2026](#bib.bib10); [Liu
et al., 2026a](#bib.bib27); [Zhang et al., 2026e](#bib.bib75); [Kang
et al., 2026](#bib.bib21)), collaborative tool-use systems ([Fan et al.,
2026](#bib.bib12)), and settings where verifiers must be learned or
approximated.

## Appendix A Additional Technical Details

### A.1 Details of the Exploratory Preliminary Study

The preliminary study in
Section [3](#S3 "3 Preliminary Study ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
examines *naive episode-derived memory writing*. The agent directly
summarizes a completed episode into a free-form lesson and writes it
into persistent memory.

#### Episode-derived lessons.

For each completed episode, the base agent observes the task instruction
$`x`$, its interaction trajectory $`\tau`$, and the verifier outcome
$`r`$. It then produces a natural-language lesson

|     |                                       |     |      |
|-----|---------------------------------------|-----|------|
|     |
       ``` math
       u=\mathrm{SummarizeLesson}(x,\tau,r),
       ```                                    |     | (15) |

which may take the form of a rule, reminder, correction, or behavioral
heuristic. The updated agent state is obtained by simply appending $`u`$
to the memory context:

|     |                                            |     |      |
|-----|--------------------------------------------|-----|------|
|     |
       ``` math
       \Theta\oplus u=(\mathcal{M}\cup\{u\},\pi),
       ```                                         |     | (16) |

where $`\mathcal{M}`$ denotes the current memory and $`\pi`$ denotes the
unchanged base policy. This direct memory-writing procedure is a common
self-improvement baseline that exposes unsafe updates.

#### Probe groups.

To analyze the effect of a lesson $`u`$, we evaluate the original agent
$`\Theta`$ and the memory-augmented agent $`\Theta\oplus u`$ on four
groups of diagnostic cases. The *source-replay* group
$`\mathcal{C}_{\mathrm{src}}(u)`$ contains the original episode and
minor perturbations that preserve the same intended solution. The
*near-transfer* group $`\mathcal{C}_{\mathrm{near}}(u)`$ contains tasks
that share the same underlying behavioral pattern but differ in surface
form, entities, or context. The *boundary-contrast* group
$`\mathcal{C}_{\mathrm{bdry}}(u)`$ contains cases that are superficially
similar to the source episode but should not trigger the same lesson.
The *archived-success* group $`\mathcal{C}_{\mathrm{arch}}(u)`$ contains
previously solved cases sampled from the agent’s historical archive. The
first two groups measure whether the lesson captures a useful pattern,
while the latter two groups measure whether it overgeneralizes or
interferes with existing behavior.

#### Verifier-score changes.

For a case $`x`$, we estimate the verifier-grounded performance of an
agent state $`\Theta`$ as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
J(\Theta,x)=\frac{1}{L}\sum_{\ell=1}^{L}v(x,\tau^{(\ell)}),\qquad\tau^{(\ell)}\sim p_{\Theta}(\cdot\mid x),
``` |  | (17) |

where $`v(x,\tau)\in[0,1]`$ is the task verifier and $`L`$ is the number
of repeated rollouts. For deterministic tasks, $`L=1`$ is sufficient.
The effect of lesson $`u`$ on a case group $`\mathcal{C}`$ is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Delta_{\mathcal{C}}(u)=\frac{1}{|\mathcal{C}|}\sum_{x\in\mathcal{C}}\left[J(\Theta\oplus u,x)-J(\Theta,x)\right].
``` |  | (18) |

We report source gain $`\Delta_{\mathrm{src}}(u)`$, near-transfer gain
$`\Delta_{\mathrm{near}}(u)`$, boundary harm

|  |  |  |  |
|----|----|----|----|
|  |
``` math
H_{\mathrm{bdry}}(u)=\left[-\Delta_{\mathcal{C}_{\mathrm{bdry}}}(u)\right]_{+},
``` |  | (19) |

and archive harm

|  |  |  |  |
|----|----|----|----|
|  |
``` math
H_{\mathrm{arch}}(u)=\left[-\Delta_{\mathcal{C}_{\mathrm{arch}}}(u)\right]_{+}.
``` |  | (20) |

A lesson is considered locally useful if it improves near-transfer
cases, but it is considered unsafe if it also induces large boundary or
archive harm.

#### Scope-specificity annotation.

To understand why some useful lessons are harmful, we annotate each
free-form lesson with a coarse scope-specificity score $`s(u)\in[0,1]`$.
A lesson receives a higher score when it contains explicit applicability
conditions, contextual triggers, exception clauses, or task-specific
constraints. It receives a lower score when it is phrased as a broad
heuristic without clear conditions. This analysis-only score tests
whether overgeneralization is associated with underspecified lesson
scope; update selection in the preliminary study proceeds without it.

#### Sequential memory-writing analysis.

To study error accumulation, we simulate sequential memory writing over
a stream of candidate lessons. After writing $`k`$ lessons, the agent
state is

|     |                                                    |     |      |
|-----|----------------------------------------------------|-----|------|
|     |
       ``` math
       \Theta_{k}=\Theta_{0}\oplus\{u_{1},\ldots,u_{k}\},
       ```                                                 |     | (21) |

and its held-out verifier score is measured on a fixed evaluation set
$`\mathcal{E}`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
S_{k}=\frac{1}{|\mathcal{E}|}\sum_{x\in\mathcal{E}}J(\Theta_{k},x).
``` |  | (22) |

We compare three diagnostic memory-writing strategies: writing all
lessons, writing only lessons that improve the source episode, and a
hindsight safe subset. The hindsight subset keeps lessons with high
near-transfer gain and low boundary/archive harm, and is used only as an
oracle diagnostic upper bound. It is not available to the agent during
deployment. This comparison isolates the main observation that source
improvement alone is insufficient for stable long-term self-evolution.

#### Post-hoc scope localization.

For lessons that are useful but harmful, we conduct a post-hoc
localization analysis. Given a lesson $`u`$ with positive near-transfer
gain but high boundary harm, we inspect the boundary failures and
rewrite the lesson into a narrower version $`u^{\prime}`$ by adding an
explicit applicability condition. We then reevaluate $`u^{\prime}`$ on
the same near-transfer and boundary-contrast groups. We summarize the
effect of localization by the transfer-retention ratio

|  |  |  |  |
|----|----|----|----|
|  |
``` math
R_{\mathrm{retain}}(u^{\prime})=\frac{\Delta_{\mathrm{near}}(u^{\prime})}{\Delta_{\mathrm{near}}(u)+\varepsilon},
``` |  | (23) |

and the boundary-harm reduction ratio

|  |  |  |  |
|----|----|----|----|
|  |
``` math
R_{\mathrm{reduce}}(u^{\prime})=\frac{H_{\mathrm{bdry}}(u)-H_{\mathrm{bdry}}(u^{\prime})}{H_{\mathrm{bdry}}(u)+\varepsilon},
``` |  | (24) |

where $`\varepsilon`$ is a small constant for numerical stability. This
separate diagnostic motivates explicit applicability conditions and
refinement of useful but overly broad candidates in the main method.

#### Connection to the method.

The preliminary study supports three design choices. First, testing
episode-derived updates before persistence can expose unsafe free-form
lessons. Second, contrastive and archived cases expose boundary failures
that source or near-transfer cases can miss. Third, scope refinement can
repair some harmful lessons while retaining their useful content. These
observations motivate the structured hypothesis representation,
temporary evaluation, verifier-grounded commitment, and scope refinement
introduced in
Section [4](#S4 "4 Method ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents").

### A.2 Verifier-Grounded Probe Construction

FGSE constructs probes from three candidate sources: archived solved
tasks, verifier-preserving perturbations of the triggering episode, and
language-model-generated candidates filtered by executable verifiers.
The verifier filter is applied before evaluation:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\operatorname{Verifiable}(x,v_{h})=1\quad\Longleftrightarrow\quad v_{h}(x,\tau)\ \text{returns a stable score for every evaluated rollout }\tau.
``` |  | (25) |

Tasks that cannot be checked by $`v_{h}`$ are excluded from the gate.

The falsification set is decomposed as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{F}(h)=\mathcal{F}_{\mathrm{bd}}(h)\cup\mathcal{F}_{\mathrm{pv}}(h)\cup\mathcal{F}_{\mathrm{rg}}(h)\cup\mathcal{F}_{\mathrm{dc}}(h).
``` |  | (26) |

Here, $`\mathcal{F}_{\mathrm{bd}}`$ contains boundary probes near the
activation threshold of $`c_{h}`$, $`\mathcal{F}_{\mathrm{pv}}`$
contains precondition-violation probes that are similar to the claimed
scope but should not activate the rule, $`\mathcal{F}_{\mathrm{rg}}`$
contains regression probes from previously solved cases, and
$`\mathcal{F}_{\mathrm{dc}}`$ contains decoy probes that are
superficially similar to target cases but require different behavior.

For each probe type
$`q\in\{\mathrm{bd},\mathrm{pv},\mathrm{rg},\mathrm{dc}\}`$, FGSE
assigns a risk score

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\rho_{q}(x;h)=\begin{cases}\exp\!\left(-|c_{h}(x)-\gamma_{h}|/\sigma\right),&q=\mathrm{bd},\\[2.0pt]
(1-c_{h}(x))\,\operatorname{sim}(x,h),&q=\mathrm{pv},\\[2.0pt]
\mathbb{I}[J_{v_{h}}(\Theta_{t},x)\geq\zeta]\,\operatorname{sim}(x,h),&q=\mathrm{rg},\\[2.0pt]
\operatorname{sim}(x,h)\,\mathbb{I}[c_{h}(x)<\gamma_{h}],&q=\mathrm{dc}.\end{cases}
``` |  | (27) |

In
Eq. ([27](#A1.E27 "In A.2 Verifier-Grounded Probe Construction ‣ Appendix A Additional Technical Details ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")),
$`\sigma>0`$ controls the width of the boundary region,
$`\operatorname{sim}(x,h)`$ measures semantic or structural similarity
between $`x`$ and the triggering context of $`h`$, and $`\zeta`$ is the
score threshold for considering an archived case solved.

The selected probes are

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{F}_{q}(h)=\operatorname{TopK}_{x\in\mathcal{X}_{q}}\left\{\rho_{q}(x;h):\operatorname{Verifiable}(x,v_{h})=1\right\},
``` |  | (28) |

where $`\mathcal{X}_{q}`$ is the candidate pool for probe type $`q`$.
Boundary probes test whether the hypothesis changes behavior too
aggressively near its activation threshold. Precondition-violation
probes test whether the rule fires outside its intended condition.
Regression probes measure damage to cases already solved by
$`\Theta_{t}`$. Decoy probes test whether superficial similarity causes
the wrong behavior change.

The target-transfer set $`\mathcal{T}(h)`$ is selected from verifiable
candidates satisfying $`c_{h}(x)\geq\gamma_{h}`$. FGSE prioritizes
candidates that match the precondition while differing from the
triggering task in surface form, tool trace, or problem instance. This
tests transfer beyond memorization of the original episode.

### A.3 Precondition Refinement

Refinement is used when a hypothesis improves target probes but fails on
falsification probes that can be separated by a more precise
precondition. FGSE forms the safe and falsifying sets

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathcal{P}_{h}^{+}`$ | $`\displaystyle=\{x\in\mathcal{T}(h)\cup\mathcal{F}(h):\Delta_{h}(x)\geq 0,\ E_{h}(\Theta_{t}\oplus h,x)=1\},`$ |  |  |
|  | $`\displaystyle\mathcal{P}_{h}^{-}`$ | $`\displaystyle=\{x\in\mathcal{F}(h):\Delta_{h}(x)<-\epsilon\ \vee\ E_{h}(\Theta_{t}\oplus h,x)=0\}.`$ |  | (29) |

The refined precondition is obtained by

|  |  |  |  |
|----|----|----|----|
|  |
``` math
c_{h}^{\prime}=\arg\min_{c\in\mathfrak{C}}\left[\Omega(c)+\lambda_{+}\sum_{x\in\mathcal{P}_{h}^{+}}\ell(1,c(x))+\lambda_{-}\sum_{x\in\mathcal{P}_{h}^{-}}\ell(0,c(x))\right].
``` |  | (30) |

Here, $`\mathfrak{C}`$ is the precondition class, $`\Omega(c)`$
penalizes overly complex conditions, $`\ell`$ is binary cross-entropy,
and $`\lambda_{+},\lambda_{-}\geq 0`$ weight safe and falsifying probes.

FGSE triggers refinement only when the following separability score is
below a threshold:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\operatorname{Sep}(h)=\min_{c\in\mathfrak{C}}\left[\frac{1}{|\mathcal{P}_{h}^{+}|}\sum_{x\in\mathcal{P}_{h}^{+}}\mathbb{I}[c(x)<\gamma_{h}]+\frac{1}{|\mathcal{P}_{h}^{-}|}\sum_{x\in\mathcal{P}_{h}^{-}}\mathbb{I}[c(x)\geq\gamma_{h}]\right]\leq\alpha_{\mathrm{sep}}.
``` |  | (31) |

A refined hypothesis is
$`h^{\prime}=(c_{h}^{\prime},b_{h},e_{h},v_{h})`$. FGSE performs one
refinement pass. The refined hypothesis is then evaluated by the same
equations used in the main method. If it fails the gate after
refinement, it is rejected.

### A.4 Empirical Estimation Under Stochastic Rollouts

The verifier-grounded score in
Eq. ([2](#S4.E2 "In Verifier-grounded agent state. ‣ 4.2 Falsification-Gated Self-Evolution ‣ 4 Method ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents"))
is estimated with repeated rollouts:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{J}_{v}(\Theta,x)=\frac{1}{n}\sum_{j=1}^{n}v(x,\tau^{(j)}),\qquad\tau^{(j)}\sim p_{\Theta}(\cdot\mid x).
``` |  | (32) |

The empirical update effect is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{\Delta}_{h}(x)=\widehat{J}_{v_{h}}(\Theta_{t}\oplus h,x)-\widehat{J}_{v_{h}}(\Theta_{t},x).
``` |  | (33) |

In experiments with deterministic verifiers and deterministic decoding,
$`n=1`$ is sufficient. With stochastic decoding or nondeterministic tool
responses, FGSE uses paired random seeds for $`\Theta_{t}`$ and
$`\Theta_{t}\oplus h`$ when the environment supports seed control. This
reduces variance in $`\widehat{\Delta}_{h}(x)`$ because both states are
evaluated under matched rollout conditions.

For finite probe budgets, FGSE reports the conservative falsification
score

|  |  |  |  |
|----|----|----|----|
|  |
``` math
S_{\mathrm{fail}}(h)=\widehat{P}_{\mathrm{fail}}(h)+\kappa|\mathcal{F}(h)|^{-1/2},
``` |  | (34) |

where $`\kappa\geq 0`$ controls the penalty for small falsification
sets. This score is used for analysis and ablations. The main gate in
Eq. ([8](#S4.E8 "In Commitment gate. ‣ 4.2 Falsification-Gated Self-Evolution ‣ 4 Method ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents"))
uses the empirical falsification rate
$`\widehat{P}_{\mathrm{fail}}(h)`$.

### A.5 Runtime Retrieval, Combination, and Monitoring

At inference time, FGSE retrieves committed hypotheses whose
preconditions match the current interaction state
$`z=(x,\tau_{<\ell})`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{H}_{t}(z)=\{h\in\mathcal{M}_{t}:c_{h}(z)\geq\gamma_{h},\ u_{t}(h)\leq u_{\max}\},
``` |  | (35) |

where $`u_{t}(h)`$ is the post-commit violation score and $`u_{\max}`$
is the maximum allowed violation level.

When $`\mathcal{H}_{t}(z)`$ is nonempty, FGSE assigns normalized weights

|  |  |  |  |
|----|----|----|----|
|  |
``` math
w_{h}(z)=\frac{\exp(c_{h}(z)/\rho)}{\sum_{h^{\prime}\in\mathcal{H}_{t}(z)}\exp(c_{h^{\prime}}(z)/\rho)},\qquad h\in\mathcal{H}_{t}(z),
``` |  | (36) |

where $`\rho>0`$ is the temperature. The runtime policy is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi_{t}^{\mathrm{FGSE}}(a\mid z)=(1-\lambda(z))\pi_{\Theta_{t}}(a\mid z)+\lambda(z)\sum_{h\in\mathcal{H}_{t}(z)}w_{h}(z)b_{h}[\pi_{\Theta_{t}}](a\mid z),
``` |  | (37) |

where $`\lambda(z)\in[0,1]`$ is the total intervention strength. This
form preserves a nonzero base-policy contribution even when several
hypotheses are active.

After a committed hypothesis is activated, FGSE records whether its
expected effect is violated:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
V_{t}(h,x_{t})=\mathbb{I}\left[E_{h}(\Theta_{t},x_{t})=0\vee J_{v_{h}}(\Theta_{t},x_{t})<\zeta_{h}\right],
``` |  | (38) |

where $`\zeta_{h}`$ is the minimum acceptable verifier score associated
with hypothesis $`h`$. The violation score is updated by

|     |                                                         |     |      |
|-----|---------------------------------------------------------|-----|------|
|     |
       ``` math
       u_{t+1}(h)=\rho_{u}u_{t}(h)+(1-\rho_{u})V_{t}(h,x_{t}),
       ```                                                      |     | (39) |

where $`\rho_{u}\in[0,1)`$ controls the memory of previous violations.
If $`u_{t+1}(h)>u_{\max}`$, the hypothesis is removed from the active
retrieval set. Removed hypotheses remain in the audit archive and are
not used for future action selection.

### A.6 Audit Record

Each committed hypothesis is stored with an audit record

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\operatorname{Record}(h)=\left(h,\mathcal{T}(h),\mathcal{F}(h),\mathcal{R}(h),\{\Delta_{h}(x)\}_{x\in\mathcal{P}(h)},\widehat{G}(h),\widehat{P}_{\mathrm{fail}}(h),\widehat{D}_{\mathrm{reg}}(h),u_{t}(h)\right).
``` |  | (40) |

The audit record supports post-hoc inspection of why a rule was
committed, which probes were used to falsify it, and whether the rule
later accumulated violations.

### A.7 Detailed Algorithm with Refinement

0:  State $`\Theta_{t}`$, evidence packet $`E_{t}`$, audit archive
$`\mathcal{A}_{t}`$, thresholds
$`(\eta,\delta,\beta,\alpha_{\mathrm{sep}})`$

0:  Updated state $`\Theta_{t+1}`$

1:  Propose $`h=(c_{h},b_{h},e_{h},v_{h})=H_{\phi}(E_{t})`$.

2:  Build $`\mathcal{T}(h)`$, $`\mathcal{F}(h)`$, and
$`\mathcal{R}(h)`$.

3:  Evaluate $`\widehat{G}(h)`$, $`\widehat{P}_{\mathrm{fail}}(h)`$, and
$`\widehat{D}_{\mathrm{reg}}(h)`$.

4:  if $`\widehat{G}(h)\geq\eta`$ and
$`\widehat{P}_{\mathrm{fail}}(h)\leq\delta`$ and
$`\widehat{D}_{\mathrm{reg}}(h)\leq\beta`$ then

5:   Commit $`h`$ and set $`\Theta_{t+1}=\Theta_{t}\oplus h`$.

6:  else if $`\widehat{G}(h)\geq\eta`$ and
$`\operatorname{Sep}(h)\leq\alpha_{\mathrm{sep}}`$ then

7:   Compute $`c_{h}^{\prime}`$ by
Eq. ([30](#A1.E30 "In A.3 Precondition Refinement ‣ Appendix A Additional Technical Details ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents"))
and set $`h^{\prime}=(c_{h}^{\prime},b_{h},e_{h},v_{h})`$.

8:   Rebuild probes for $`h^{\prime}`$ and reevaluate the gate.

9:   if $`h^{\prime}`$ satisfies
Eq. ([8](#S4.E8 "In Commitment gate. ‣ 4.2 Falsification-Gated Self-Evolution ‣ 4 Method ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents"))
then

10:    Commit $`h^{\prime}`$ and set
$`\Theta_{t+1}=\Theta_{t}\oplus h^{\prime}`$.

11:   else

12:    Reject $`h^{\prime}`$ and set $`\Theta_{t+1}=\Theta_{t}`$.

13:   end if

14:  else

15:   Reject $`h`$ and set $`\Theta_{t+1}=\Theta_{t}`$.

16:  end if

#### Practical representation of hypotheses.

In implementation, each hypothesis is stored as a schema-constrained
JSON object. The precondition field is a natural-language predicate
together with a scoring function implemented by a lightweight LLM
classifier or rule-based matcher. The behavior field specifies a bounded
prompt/tool-policy patch. The expected-effect field specifies a
verifier-observable condition, and the verifier field points to the
benchmark validator or executable checker. Audits of synthetic
healthcare workflows also expose escalation errors under conflicting
evidence and brittle routing rules under unseen paraphrases \[[Zheng
et al., 2026](#bib.bib80)\].

## Appendix B Proofs for the Commitment Gate Generalization

### B.1 Conditional Setup

We prove
Theorem [1](#Thmtheorem1 "Theorem 1 (Generalization of the confidence-gated commitment rule). ‣ 5 Theoretical Analysis ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
and
Corollary [1](#Thmcorollary1 "Corollary 1 (Probe complexity of safe commitment). ‣ Proof sketch. ‣ 5 Theoretical Analysis ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents").
Fix a round $`t`$. Let $`\mathcal{F}_{t}`$ denote the sigma-field
containing the current agent state $`\Theta_{t}`$, the evidence packet,
the audit archive, the proposal and refinement randomness before final
evaluation, and the finite candidate set $`\mathcal{H}_{t}`$. Throughout
the proof, we condition on $`\mathcal{F}_{t}`$. Thus, the candidate set
is fixed before the final evaluation probes are sampled.

For each $`h\in\mathcal{H}_{t}`$, define the target-transfer random
variable

|     |                                                         |     |      |
|-----|---------------------------------------------------------|-----|------|
|     |
       ``` math
       X^{T}_{h}=\Delta_{h}(x),\qquad x\sim\mathcal{D}_{T}(h).
       ```                                                      |     | (41) |

Because verifier scores lie in $`[0,1]`$, we have

|     |                     |     |      |
|-----|---------------------|-----|------|
|     |
       ``` math
       X^{T}_{h}\in[-1,1].
       ```                  |     | (42) |

The population and empirical target-transfer gains are

|  |  |  |  |
|----|----|----|----|
|  |
``` math
G(h)=\mathbb{E}[X^{T}_{h}],\qquad\widehat{G}(h)=\frac{1}{n_{T}}\sum_{i=1}^{n_{T}}X^{T}_{h,i}.
``` |  | (43) |

The empirical target-transfer variance is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{V}_{T}(h)=\frac{1}{n_{T}}\sum_{i=1}^{n_{T}}\left(X^{T}_{h,i}-\widehat{G}(h)\right)^{2}.
``` |  | (44) |

For falsification probes, define the Bernoulli random variable

|  |  |  |  |
|----|----|----|----|
|  |
``` math
X^{F}_{h}=\mathbb{I}\left[\Delta_{h}(x)<-\epsilon\ \vee\ E_{h}(\Theta_{t}\oplus h,x)=0\right],\qquad x\sim\mathcal{D}_{F}(h).
``` |  | (45) |

Then

|     |                      |     |      |
|-----|----------------------|-----|------|
|     |
       ``` math
       X^{F}_{h}\in\{0,1\}.
       ```                   |     | (46) |

The population falsification risk and empirical failure rate are

|  |  |  |  |
|----|----|----|----|
|  |
``` math
P_{\mathrm{fail}}(h)=\mathbb{E}[X^{F}_{h}],\qquad\widehat{P}_{\mathrm{fail}}(h)=\frac{1}{n_{F}}\sum_{i=1}^{n_{F}}X^{F}_{h,i}.
``` |  | (47) |

For regression probes, define

|     |                                                                |     |      |
|-----|----------------------------------------------------------------|-----|------|
|     |
       ``` math
       X^{R}_{h}=[-\Delta_{h}(x)]_{+},\qquad x\sim\mathcal{D}_{R}(h).
       ```                                                             |     | (48) |

Since $`\Delta_{h}(x)\in[-1,1]`$, we have

|     |                    |     |      |
|-----|--------------------|-----|------|
|     |
       ``` math
       X^{R}_{h}\in[0,1].
       ```                 |     | (49) |

The population and empirical regression damages are

|  |  |  |  |
|----|----|----|----|
|  |
``` math
D_{\mathrm{reg}}(h)=\mathbb{E}[X^{R}_{h}],\qquad\widehat{D}_{\mathrm{reg}}(h)=\frac{1}{n_{R}}\sum_{i=1}^{n_{R}}X^{R}_{h,i}.
``` |  | (50) |

The empirical regression variance is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{V}_{R}(h)=\frac{1}{n_{R}}\sum_{i=1}^{n_{R}}\left(X^{R}_{h,i}-\widehat{D}_{\mathrm{reg}}(h)\right)^{2}.
``` |  | (51) |

The analysis treats the randomness in $`X^{T}_{h}`$, $`X^{F}_{h}`$, and
$`X^{R}_{h}`$ as including both probe sampling and any rollout
randomness used to estimate verifier outcomes. The only properties
needed are boundedness and conditional independence of the final
evaluation samples for each fixed $`h`$.

### B.2 Confidence Bounds Used by the Commitment Gate

Let $`n_{T},n_{F},n_{R}`$ be the numbers of final target, falsification,
and regression probes. Let $`\alpha_{T},\alpha_{F},\alpha_{R}>0`$
satisfy

|     |                                          |     |      |
|-----|------------------------------------------|-----|------|
|     |
       ``` math
       \alpha_{T}+\alpha_{F}+\alpha_{R}=\alpha.
       ```                                       |     | (52) |

Define the logarithmic factors

|  |  |  |  |
|----|----|----|----|
|  |
``` math
L_{T}=\log\frac{2|\mathcal{H}_{t}|}{\alpha_{T}},\qquad L_{R}=\log\frac{2|\mathcal{H}_{t}|}{\alpha_{R}},\qquad L_{F}=\log\frac{(n_{F}+1)|\mathcal{H}_{t}|}{\alpha_{F}}.
``` |  | (53) |

The empirical-Bernstein slacks are

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\varepsilon_{T}(h)=\sqrt{\frac{2\widehat{V}_{T}(h)L_{T}}{n_{T}}}+\frac{14L_{T}}{3(n_{T}-1)},\qquad\varepsilon_{R}(h)=\sqrt{\frac{2\widehat{V}_{R}(h)L_{R}}{n_{R}}}+\frac{7L_{R}}{3(n_{R}-1)}.
``` |  | (54) |

The target lower confidence bound and regression upper confidence bound
are

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{LCB}_{T}(h)=\widehat{G}(h)-\varepsilon_{T}(h),\qquad\mathrm{UCB}_{R}(h)=\widehat{D}_{\mathrm{reg}}(h)+\varepsilon_{R}(h).
``` |  | (55) |

For $`p,q\in[0,1]`$, define the binary KL divergence

|     |                                                              |     |      |
|-----|--------------------------------------------------------------|-----|------|
|     |
       ``` math
       \mathrm{kl}(p\|q)=p\log\frac{p}{q}+(1-p)\log\frac{1-p}{1-q},
       ```                                                           |     | (56) |

with the standard continuous extension at the boundary. The KL upper
confidence bound for falsification risk is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{UCB}_{F}(h)=\sup\left\{q\in[\widehat{P}_{\mathrm{fail}}(h),1]:\mathrm{kl}\left(\widehat{P}_{\mathrm{fail}}(h)\|q\right)\leq\frac{L_{F}}{n_{F}}\right\}.
``` |  | (57) |

### B.3 Concentration Tools

We use two concentration results. The first controls bounded real-valued
random variables using empirical variance.

###### Lemma 1 (One-sided empirical Bernstein inequality).

Let $`Y_{1},\ldots,Y_{n}`$ be independent random variables taking values
in an interval of length $`\mathfrak{b}`$. Let

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mu=\mathbb{E}[Y_{1}],\qquad\widehat{\mu}=\frac{1}{n}\sum_{i=1}^{n}Y_{i},
``` |  | (58) |

and

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{V}=\frac{1}{n}\sum_{i=1}^{n}(Y_{i}-\widehat{\mu})^{2}.
``` |  | (59) |

For any $`\rho\in(0,1)`$ and $`n\geq 2`$, with probability at least
$`1-\rho`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mu-\widehat{\mu}\leq\sqrt{\frac{2\widehat{V}\log(2/\rho)}{n}}+\frac{7\mathfrak{b}\log(2/\rho)}{3(n-1)}.
``` |  | (60) |

The same inequality also holds with $`\widehat{\mu}-\mu`$ on the
left-hand side.

###### Proof.

This is the standard one-sided form of the empirical Bernstein
inequality for bounded random variables. The lower-tail statement
follows by applying the same result to $`-Y_{i}`$, whose range length
remains $`\mathfrak{b}`$. ∎

The second result gives a KL confidence bound for Bernoulli variables.

###### Lemma 2 (Bernoulli KL confidence bound).

Let $`B_{1},\ldots,B_{n}`$ be i.i.d. Bernoulli random variables with
mean $`p`$, and let

|     |                                             |     |      |
|-----|---------------------------------------------|-----|------|
|     |
       ``` math
       \widehat{p}=\frac{1}{n}\sum_{i=1}^{n}B_{i}.
       ```                                          |     | (61) |

Then, for any $`u>0`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{P}\left(\mathrm{kl}(\widehat{p}\|p)\geq u\right)\leq(n+1)\exp(-nu).
``` |  | (62) |

###### Proof.

For each $`k\in\{0,1,\ldots,n\}`$, let

|     |                    |     |      |
|-----|--------------------|-----|------|
|     |
       ``` math
       q_{k}=\frac{k}{n}.
       ```                 |     | (63) |

The event $`\widehat{p}=q_{k}`$ has probability

|     |                                                             |     |      |
|-----|-------------------------------------------------------------|-----|------|
|     |
       ``` math
       \mathbb{P}(\widehat{p}=q_{k})=\binom{n}{k}p^{k}(1-p)^{n-k}.
       ```                                                          |     | (64) |

Using the type-counting bound

|     |                                             |     |      |
|-----|---------------------------------------------|-----|------|
|     |
       ``` math
       \binom{n}{k}\leq\exp\left(nH(q_{k})\right),
       ```                                          |     | (65) |

where

|     |                               |     |      |
|-----|-------------------------------|-----|------|
|     |
       ``` math
       H(q)=-q\log q-(1-q)\log(1-q),
       ```                            |     | (66) |

we obtain

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathbb{P}(\widehat{p}=q_{k})`$ | $`\displaystyle=\binom{n}{k}p^{nq_{k}}(1-p)^{n(1-q_{k})}`$ |  | (67) |
|  |  | $`\displaystyle\leq\exp\left(nH(q_{k})+nq_{k}\log p+n(1-q_{k})\log(1-p)\right)`$ |  |  |
|  |  | $`\displaystyle=\exp\left(-n\left[q_{k}\log\frac{q_{k}}{p}+(1-q_{k})\log\frac{1-q_{k}}{1-p}\right]\right)`$ |  |  |
|  |  | $`\displaystyle=\exp\left(-n\mathrm{kl}(q_{k}\|p)\right).`$ |  |  |

Therefore,

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathbb{P}\left(\mathrm{kl}(\widehat{p}\|p)\geq u\right)`$ | $`\displaystyle=\sum_{k:\mathrm{kl}(q_{k}\|p)\geq u}\mathbb{P}(\widehat{p}=q_{k})`$ |  | (68) |
|  |  | $`\displaystyle\leq\sum_{k:\mathrm{kl}(q_{k}\|p)\geq u}\exp\left(-n\mathrm{kl}(q_{k}\|p)\right)`$ |  |  |
|  |  | $`\displaystyle\leq\sum_{k=0}^{n}\exp(-nu)`$ |  |  |
|  |  | $`\displaystyle=(n+1)\exp(-nu).`$ |  |  |

This proves the claim. ∎

### B.4 Uniform Confidence Event

We now prove that the three confidence bounds hold simultaneously for
all hypotheses in $`\mathcal{H}_{t}`$.

###### Lemma 3 (Uniform confidence event).

With probability at least $`1-\alpha`$, every $`h\in\mathcal{H}_{t}`$
simultaneously satisfies

|  |  |  |  |
|----|----|----|----|
|  |
``` math
G(h)\geq\mathrm{LCB}_{T}(h),\qquad P_{\mathrm{fail}}(h)\leq\mathrm{UCB}_{F}(h),\qquad D_{\mathrm{reg}}(h)\leq\mathrm{UCB}_{R}(h).
``` |  | (69) |

###### Proof.

We prove the target, regression, and falsification bounds separately and
then apply a union bound.

First consider target-transfer gain. For a fixed $`h`$, apply
Lemma [1](#Thmlemma1 "Lemma 1 (One-sided empirical Bernstein inequality). ‣ B.3 Concentration Tools ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
to $`X^{T}_{h}`$. Its range length is

|     |                     |     |      |
|-----|---------------------|-----|------|
|     |
       ``` math
       \mathfrak{b}_{T}=2.
       ```                  |     | (70) |

Set

|     |                                                |     |      |
|-----|------------------------------------------------|-----|------|
|     |
       ``` math
       \rho_{T}=\frac{\alpha_{T}}{|\mathcal{H}_{t}|}.
       ```                                             |     | (71) |

Then

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\log\frac{2}{\rho_{T}}=\log\frac{2|\mathcal{H}_{t}|}{\alpha_{T}}=L_{T}.
``` |  | (72) |

For this fixed $`h`$,
Lemma [1](#Thmlemma1 "Lemma 1 (One-sided empirical Bernstein inequality). ‣ B.3 Concentration Tools ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
gives

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle G(h)-\widehat{G}(h)`$ | $`\displaystyle\geq-\left[\sqrt{\frac{2\widehat{V}_{T}(h)L_{T}}{n_{T}}}+\frac{7\mathfrak{b}_{T}L_{T}}{3(n_{T}-1)}\right]`$ |  | (73) |
|  |  | $`\displaystyle=-\left[\sqrt{\frac{2\widehat{V}_{T}(h)L_{T}}{n_{T}}}+\frac{14L_{T}}{3(n_{T}-1)}\right]`$ |  |  |
|  |  | $`\displaystyle=-\varepsilon_{T}(h).`$ |  |  |

Thus,

|     |                                                                |     |      |
|-----|----------------------------------------------------------------|-----|------|
|     |
       ``` math
       G(h)\geq\widehat{G}(h)-\varepsilon_{T}(h)=\mathrm{LCB}_{T}(h).
       ```                                                             |     | (74) |

A union bound over $`h\in\mathcal{H}_{t}`$ gives

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{P}\left(\forall h\in\mathcal{H}_{t}:G(h)\geq\mathrm{LCB}_{T}(h)\right)\geq 1-\alpha_{T}.
``` |  | (75) |

Next consider regression damage. For a fixed $`h`$, apply
Lemma [1](#Thmlemma1 "Lemma 1 (One-sided empirical Bernstein inequality). ‣ B.3 Concentration Tools ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
to $`X^{R}_{h}`$. Its range length is

|     |                     |     |      |
|-----|---------------------|-----|------|
|     |
       ``` math
       \mathfrak{b}_{R}=1.
       ```                  |     | (76) |

Set

|     |                                                |     |      |
|-----|------------------------------------------------|-----|------|
|     |
       ``` math
       \rho_{R}=\frac{\alpha_{R}}{|\mathcal{H}_{t}|}.
       ```                                             |     | (77) |

Then

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\log\frac{2}{\rho_{R}}=\log\frac{2|\mathcal{H}_{t}|}{\alpha_{R}}=L_{R}.
``` |  | (78) |

For this fixed $`h`$,
Lemma [1](#Thmlemma1 "Lemma 1 (One-sided empirical Bernstein inequality). ‣ B.3 Concentration Tools ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
gives

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle D_{\mathrm{reg}}(h)-\widehat{D}_{\mathrm{reg}}(h)`$ | $`\displaystyle\leq\sqrt{\frac{2\widehat{V}_{R}(h)L_{R}}{n_{R}}}+\frac{7\mathfrak{b}_{R}L_{R}}{3(n_{R}-1)}`$ |  | (79) |
|  |  | $`\displaystyle=\sqrt{\frac{2\widehat{V}_{R}(h)L_{R}}{n_{R}}}+\frac{7L_{R}}{3(n_{R}-1)}`$ |  |  |
|  |  | $`\displaystyle=\varepsilon_{R}(h).`$ |  |  |

Therefore,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
D_{\mathrm{reg}}(h)\leq\widehat{D}_{\mathrm{reg}}(h)+\varepsilon_{R}(h)=\mathrm{UCB}_{R}(h).
``` |  | (80) |

A union bound over $`h\in\mathcal{H}_{t}`$ gives

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{P}\left(\forall h\in\mathcal{H}_{t}:D_{\mathrm{reg}}(h)\leq\mathrm{UCB}_{R}(h)\right)\geq 1-\alpha_{R}.
``` |  | (81) |

Finally consider falsification risk. For a fixed $`h`$, apply
Lemma [2](#Thmlemma2 "Lemma 2 (Bernoulli KL confidence bound). ‣ B.3 Concentration Tools ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
to $`X^{F}_{h}`$. Let

|     |                            |     |      |
|-----|----------------------------|-----|------|
|     |
       ``` math
       u_{F}=\frac{L_{F}}{n_{F}}.
       ```                         |     | (82) |

Then

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathbb{P}\left(\mathrm{kl}\left(\widehat{P}_{\mathrm{fail}}(h)\|P_{\mathrm{fail}}(h)\right)>\frac{L_{F}}{n_{F}}\right)`$ | $`\displaystyle\leq(n_{F}+1)\exp(-L_{F})`$ |  | (83) |
|  |  | $`\displaystyle=(n_{F}+1)\exp\left(-\log\frac{(n_{F}+1)|\mathcal{H}_{t}|}{\alpha_{F}}\right)`$ |  |  |
|  |  | $`\displaystyle=\frac{\alpha_{F}}{|\mathcal{H}_{t}|}.`$ |  |  |

A union bound over $`h\in\mathcal{H}_{t}`$ yields

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{P}\left(\forall h\in\mathcal{H}_{t}:\mathrm{kl}\left(\widehat{P}_{\mathrm{fail}}(h)\|P_{\mathrm{fail}}(h)\right)\leq\frac{L_{F}}{n_{F}}\right)\geq 1-\alpha_{F}.
``` |  | (84) |

On the event in
Eq. ([84](#A2.E84 "In Proof. ‣ B.4 Uniform Confidence Event ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")),
we prove that $`P_{\mathrm{fail}}(h)\leq\mathrm{UCB}_{F}(h)`$ for every
$`h`$. Fix $`h`$. If
$`P_{\mathrm{fail}}(h)\leq\widehat{P}_{\mathrm{fail}}(h)`$, then

|  |  |  |  |
|----|----|----|----|
|  |
``` math
P_{\mathrm{fail}}(h)\leq\widehat{P}_{\mathrm{fail}}(h)\leq\mathrm{UCB}_{F}(h),
``` |  | (85) |

because $`q=\widehat{P}_{\mathrm{fail}}(h)`$ is feasible in the
definition of $`\mathrm{UCB}_{F}(h)`$. If
$`P_{\mathrm{fail}}(h)>\widehat{P}_{\mathrm{fail}}(h)`$, then
$`q=P_{\mathrm{fail}}(h)`$ lies in
$`[\widehat{P}_{\mathrm{fail}}(h),1]`$, and the KL event gives

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{kl}\left(\widehat{P}_{\mathrm{fail}}(h)\|P_{\mathrm{fail}}(h)\right)\leq\frac{L_{F}}{n_{F}}.
``` |  | (86) |

Thus $`P_{\mathrm{fail}}(h)`$ is feasible in the supremum defining
$`\mathrm{UCB}_{F}(h)`$, which implies

|     |                                              |     |      |
|-----|----------------------------------------------|-----|------|
|     |
       ``` math
       P_{\mathrm{fail}}(h)\leq\mathrm{UCB}_{F}(h).
       ```                                           |     | (87) |

Combining the two cases gives

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\forall h\in\mathcal{H}_{t}:P_{\mathrm{fail}}(h)\leq\mathrm{UCB}_{F}(h).
``` |  | (88) |

Let $`\mathcal{E}_{T}`$, $`\mathcal{E}_{F}`$, and $`\mathcal{E}_{R}`$
denote the target, falsification, and regression confidence events.
Combining
Eq. ([75](#A2.E75 "In Proof. ‣ B.4 Uniform Confidence Event ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")),
Eq. ([81](#A2.E81 "In Proof. ‣ B.4 Uniform Confidence Event ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")),
and
Eq. ([84](#A2.E84 "In Proof. ‣ B.4 Uniform Confidence Event ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")),
we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathbb{P}(\mathcal{E}_{T}\cap\mathcal{E}_{F}\cap\mathcal{E}_{R})`$ | $`\displaystyle=1-\mathbb{P}(\mathcal{E}_{T}^{c}\cup\mathcal{E}_{F}^{c}\cup\mathcal{E}_{R}^{c})`$ |  | (89) |
|  |  | $`\displaystyle\geq 1-\mathbb{P}(\mathcal{E}_{T}^{c})-\mathbb{P}(\mathcal{E}_{F}^{c})-\mathbb{P}(\mathcal{E}_{R}^{c})`$ |  |  |
|  |  | $`\displaystyle\geq 1-\alpha_{T}-\alpha_{F}-\alpha_{R}`$ |  |  |
|  |  | $`\displaystyle=1-\alpha.`$ |  |  |

On this event, all three bounds in
Eq. ([69](#A2.E69 "In Lemma 3 (Uniform confidence event). ‣ B.4 Uniform Confidence Event ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents"))
hold simultaneously for every $`h\in\mathcal{H}_{t}`$. This proves the
lemma. ∎

### B.7 Proof of Corollary [2](#Thmcorollary2 "Corollary 2 (Exact probe complexity). ‣ B.6 Exact Probe Complexity Statement ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")

###### Proof.

We first control the target-transfer confidence radius. Since
$`X^{T}_{h}\in[-1,1]`$, its empirical variance satisfies

|     |                           |     |       |
|-----|---------------------------|-----|-------|
|     |
       ``` math
       \widehat{V}_{T}(h)\leq 1.
       ```                        |     | (101) |

Therefore,

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\varepsilon_{T}(h)`$ | $`\displaystyle=\sqrt{\frac{2\widehat{V}_{T}(h)L_{T}}{n_{T}}}+\frac{14L_{T}}{3(n_{T}-1)}`$ |  | (102) |
|  |  | $`\displaystyle\leq\sqrt{\frac{2L_{T}}{n_{T}}}+\frac{14L_{T}}{3(n_{T}-1)}.`$ |  |  |

If

|     |                                        |     |       |
|-----|----------------------------------------|-----|-------|
|     |
       ``` math
       n_{T}\geq\frac{8L_{T}}{\zeta_{T}^{2}},
       ```                                     |     | (103) |

then

|     |                                                     |     |       |
|-----|-----------------------------------------------------|-----|-------|
|     |
       ``` math
       \sqrt{\frac{2L_{T}}{n_{T}}}\leq\frac{\zeta_{T}}{2}.
       ```                                                  |     | (104) |

If

|     |                                        |     |       |
|-----|----------------------------------------|-----|-------|
|     |
       ``` math
       n_{T}-1\geq\frac{28L_{T}}{3\zeta_{T}},
       ```                                     |     | (105) |

then

|-----|----------------------------------------------------|-----|-------|

       \frac{14L_{T}}{3(n_{T}-1)}\leq\frac{\zeta_{T}}{2}.

we get

|     |                                  |     |       |
|-----|----------------------------------|-----|-------|
|     |
       ``` math
       \varepsilon_{T}(h)\leq\zeta_{T}.
       ```                               |     | (107) |

We next control the regression confidence radius. Since
$`X^{R}_{h}\in[0,1]`$, its empirical variance satisfies

|     |                                    |     |       |
|-----|------------------------------------|-----|-------|

``` |  | (115) |

       ```                                     |     | (116) |

|  |  |  |  |
|----|----|----|----|
|  |

|     |                                |     |       |
|-----|--------------------------------|-----|-------|
|     |
       ``` math
       \mathrm{UCB}_{F}(h)\leq\delta.
       ```                             |     | (120) |

Eq. ([107](#A2.E107 "In Proof. ‣ B.7 Proof of Corollary ‣ Appendix B Proofs for the Commitment Gate Generalization ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")),

### B.8 Remarks on Adaptivity and Scope Refinement

The proof requires that the final evaluation probes are not reused to
construct or refine the hypothesis being certified. This condition
prevents adaptive overfitting to the finite falsification set. In
practice, this can be implemented in two equivalent ways. The first is
sample splitting: use a development split for scope refinement and a
fresh evaluation split for final commitment. The second is to define
$`\mathcal{H}_{t}`$ as the enlarged finite set containing all hypotheses
that can be produced by proposal and refinement before final evaluation;
the same proof then applies with $`|\mathcal{H}_{t}|`$ replaced by the
size of this enlarged set.

The theorem certifies reliability with respect to the probe-generation
distributions $`\mathcal{D}_{T}(h)`$, $`\mathcal{D}_{F}(h)`$, and
$`\mathcal{D}_{R}(h)`$. If these distributions differ from the
deployment distribution, an additional distribution-shift term is
needed. For example, if the deployment falsification distribution is
within total variation distance $`\rho`$ of $`\mathcal{D}_{F}(h)`$, then
the certified falsification risk increases by at most $`\rho`$. The
commitment gate controls statistical generalization from finite probes
to the specified probe distributions, while the quality of the probe
generator determines how well those distributions cover deployment-time
boundary cases.

## Appendix C Additional Experimental Details

### C.1 Benchmark Details

#### Web and browser-control tasks.

For WebArena \[[Zhou et al., 2024](#bib.bib83)\] and BrowserGym \[[Le
Sellier de Chezelles et al., 2025](#bib.bib22)\], we follow the official
environment setup and success validators. Each task provides a
natural-language instruction, an initial browser state, and an
environment-specific completion condition. We use these validators as
the verifier $`v_{h}`$ whenever possible. For FGSE, target-transfer
probes are constructed from tasks sharing the same high-level
interaction pattern, while falsification probes are selected from tasks
with similar surface forms but different completion conditions,
websites, forms, or required constraints. Regression probes are drawn
from previously solved held-out tasks and are never used to propose the
candidate hypothesis.

#### Tool-use and app-interaction tasks.

For AppWorld \[[Trivedi et al., 2024](#bib.bib46)\], we evaluate on the
official Normal and Challenge splits and report task-goal completion
using the benchmark-provided database-state evaluator. For
$`\tau`$-bench \[[Yao et al., 2024](#bib.bib67)\], we evaluate both
retail and airline domains and use the official database-state
comparison and $`\mathrm{pass}^{k}`$ reliability protocol. In both
benchmarks, a hypothesis may modify the agent’s tool-use policy,
retrieval memory, or instruction-level strategy, but the available
tools, API schemas, and domain policies are fixed across all methods.
Holding tool access fixed isolates the effect of the update mechanism.

#### Security and adversarial tool-output tasks.

AgentDojo \[[Debenedetti et al., 2024](#bib.bib8)\] is used to evaluate
whether self-evolution increases susceptibility to prompt injection or
malicious tool outputs. We report utility success on benign tasks,
security success under attacks, and the joint utility-security score.
For FGSE, falsification probes include decoy tool outputs, conflicting
instructions, and previously solved benign cases. A candidate update is
rejected if it improves utility but increases attack success or violates
a high-priority system or user constraint.

#### Long-term memory tasks.

For LongMemEval \[[Wu et al., 2024](#bib.bib50)\] and LoCoMo \[[Maharana
et al., 2024](#bib.bib33)\], we evaluate whether committed hypotheses
improve memory use without corrupting persistent user or task state. We
report the official QA accuracy or F1 metrics, temporal reasoning
accuracy, knowledge-update accuracy, and abstention accuracy when
available. We also measure memory pollution rate, defined as the
fraction of committed updates that are later contradicted by held-out
evidence or cause a regression on archived successful examples.

#### Code and mathematical reasoning diagnostics.

We use HumanEval \[[Chen et al., 2021](#bib.bib3)\], MBPP \[[Austin
et al., 2021](#bib.bib2)\], and SWE-bench Verified \[[Chowdhury et al.,
2024](#bib.bib6)\] as verifier-rich coding environments because unit
tests provide executable feedback. SWE-bench Verified is a
human-validated subset of the original SWE-bench \[[Jimenez et al.,
2024](#bib.bib20)\], released by OpenAI in collaboration with the
SWE-bench authors \[[Chowdhury et al., 2024](#bib.bib6)\]. We report
pass@1 on HumanEval and MBPP and resolved rate on SWE-bench Verified.
For mathematical reasoning, we use GSM8K \[[Cobbe et al.,
2021](#bib.bib7)\] and MATH \[[Hendrycks et al., 2021](#bib.bib14)\],
reporting exact-match solve rate after answer normalization. These
datasets are used primarily for controlled analysis of update quality
because their verifiers allow clean construction of target, boundary,
and regression probes.

### C.2 Evaluation Metrics

Let $`\mathcal{D}`$ denote a held-out evaluation set and let
$`v(x,\tau)\in[0,1]`$ be the benchmark-specific verifier score. The
standard task success rate is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{SR}=\frac{1}{|\mathcal{D}|}\sum_{x\in\mathcal{D}}v(x,\tau_{x}).
``` |  | (123) |

For binary task validators, this reduces to the fraction of solved
tasks. For benchmarks with official non-binary scores, we use the
official normalized score.

For each committed or rejected hypothesis $`h`$, we compute the three
FGSE-specific statistics:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{G}(h)=\frac{1}{|\mathcal{T}(h)|}\sum_{x\in\mathcal{T}(h)}\left[J_{v_{h}}(\Theta\oplus h,x)-J_{v_{h}}(\Theta,x)\right],
``` |  | (124) |

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{P}_{\mathrm{fail}}(h)=\frac{1}{|\mathcal{F}(h)|}\sum_{x\in\mathcal{F}(h)}\mathbb{I}\left[J_{v_{h}}(\Theta\oplus h,x)-J_{v_{h}}(\Theta,x)<-\epsilon\;\vee\;E_{h}(\Theta\oplus h,x)=0\right],
``` |  | (125) |

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{D}_{\mathrm{reg}}(h)=\frac{1}{|\mathcal{R}(h)|}\sum_{x\in\mathcal{R}(h)}\left[J_{v_{h}}(\Theta,x)-J_{v_{h}}(\Theta\oplus h,x)\right]_{+}.
``` |  | (126) |

We also report:

- •
  Harmful update rate: the fraction of committed updates that cause
  held-out regression larger than $`\epsilon`$.
- •
  Accepted-update precision: the fraction of committed updates that
  yield positive held-out target-transfer gain without measurable
  regression.
- •
  Falsification hit rate: the fraction of rejected or refined updates
  for which at least one falsification probe exposes a failure.
- •
  Post-commit violation rate: the fraction of future activations where a
  committed hypothesis violates its expected-effect checker.
- •
  Cost: total LLM calls, verifier calls, wall-clock time, and token
  usage per committed update.

### C.3 Fair Comparison Protocol

All controlled comparisons follow the same protocol \[[Yang et al.,
2026b](#bib.bib63)\]:

1.  1.
    Same backbone: every method uses the same base LLM and the same
    ReAct-style executor unless the method intrinsically requires a
    different executor.
2.  2.
    Same tools: all methods receive identical tool schemas, browser
    actions, API access, and environment observations.
3.  3.
    Same memory budget: methods with persistent memory are allowed the
    same maximum number of stored units and the same retrieval
    top-$`k`$.
4.  4.
    Same update budget: methods that propose self-updates receive the
    same number of completed training episodes and the same maximum
    number of update attempts.
5.  5.
    No test leakage: hypotheses, reflections, playbooks, workflows, and
    memory entries are constructed only from training or development
    episodes. Test tasks are used only for final evaluation.
6.  6.
    Same verifier access: if a verifier is available during development,
    all methods may use it under the same budget. During final
    evaluation, verifier outputs are used only for scoring.

For workflow-search or architecture-search methods such as
AFlow \[[Zhang et al., 2025a](#bib.bib76)\], ADAS \[[Hu et al.,
2025](#bib.bib16)\], GPTSwarm \[[Zhuge et al., 2024](#bib.bib85)\], and
MetaAgent \[[Zhang et al., 2025b](#bib.bib78)\], we report a
controlled-budget version when code and prompts are available. Methods
requiring a substantially larger search budget, extra training data,
reinforcement learning, or model fine-tuning are reported in a separate
native-setting table, outside the controlled FGSE comparisons.

### C.4 Baseline Implementation Details

#### Direct and ReAct.

The direct baseline uses the base LLM without persistent memory or
post-episode updates. The ReAct baseline \[[Yao et al.,
2023](#bib.bib66)\] uses the same action space and tool interface as
FGSE but does not modify its persistent state after each episode.

#### Self-Refine and Reflexion.

Self-Refine \[[Madaan et al., 2023](#bib.bib32)\] performs
within-episode critique and revision under the same maximum number of
refinement calls as FGSE’s hypothesis proposal calls. Reflexion \[[Shinn
et al., 2023](#bib.bib41)\] writes natural-language reflections after
failed or low-scoring episodes and retrieves them in future tasks.
Reflexion commits reflections without requiring structured
preconditions, falsification probes, or regression tests.

#### Voyager-style skill memory.

The Voyager-style baseline \[[Wang et al., 2023](#bib.bib47)\] stores
reusable skills or lessons from successful episodes and retrieves them
for related future tasks. For non-Minecraft benchmarks, we adapt the
skill library into a text-based rule or tool-use strategy library while
keeping the same retrieval budget as FGSE.

#### Memory and context-evolution methods.

A-Mem \[[Xu et al., 2025](#bib.bib59)\] is implemented as an agentic
memory organization baseline that dynamically indexes, links, and
updates memories. ACE \[[Zhang et al., 2026f](#bib.bib77)\] is
implemented as an evolving playbook baseline that incrementally revises
persistent context using execution feedback. Both methods are evaluated
with the same memory capacity and retrieval top-$`k`$ as FGSE.

#### Workflow and agent-design optimization methods.

AFlow \[[Zhang et al., 2025a](#bib.bib76)\], ADAS \[[Hu et al.,
2025](#bib.bib16)\], GPTSwarm \[[Zhuge et al., 2024](#bib.bib85)\], and
MetaAgent \[[Zhang et al., 2025b](#bib.bib78)\] provide comparisons at
the agentic-workflow level, complementing update-level memory methods.
Because these methods may search over a larger design space than FGSE,
we distinguish controlled-budget and native-budget results.

### C.6 Ablation Studies

We conduct the following ablations:

- •
  No falsification: commit every proposed hypothesis that improves the
  source episode.
- •
  Random probes: replace targeted falsification probes with randomly
  sampled held-out tasks.
- •
  LLM-judge gate: replace executable or environment verifiers with an
  LLM-only judgment.
- •
  No regression archive: remove $`\mathcal{R}(h)`$ from the commitment
  rule.
- •
  No scope narrowing: reject all hypotheses that fail falsification
  without allowing precondition refinement.
- •
  Free-form memory: store unstructured natural-language lessons instead
  of structured $`(c_{h},b_{h},e_{h},v_{h})`$ hypotheses.
- •
  Probe-budget sweep: vary the number of falsification probes to measure
  the trade-off between update safety and computation.

These ablations isolate whether FGSE’s gains come from verifier
grounding, targeted counterexample construction, regression protection,
structured update representation, or scope refinement.

### D.2 Update-Selection and Falsification Analysis

#### Plasticity–safety Pareto frontier

Effective self-evolution combines useful agent improvements with
protection against harmful or regressive memory updates. We examine the
*plasticity–safety Pareto frontier* for update selection and compare
FGSE’s position with alternative strategies.

We sweep a broad range of update-selection configurations and compare
representative strategies, including FGSE, FGSE w/o Refine, Target-Only,
LLM-Judge Gate, Conservative Gate, Exhaustive Verifier, Random Keep, and
No Persistent Update. For each configuration $`c`$, we measure: (i)
*update gain* $`\Delta_{\mathrm{upd}}(c)`$, defined as the average
improvement after applying the selected update; (ii) *harmful update
rate* $`H(c)`$, i.e., the fraction of committed updates that later
induce safety violations or incorrect behavior on held-out probes; (iii)
*regression damage* $`R(c)`$, i.e., the average degradation on archived
successful behaviors; and (iv) *verifier cost* $`C(c)`$, measured as the
average number of verifier calls per candidate update.
Figure [6](#A4.F6 "Figure 6 ‣ Plasticity–safety Pareto frontier ‣ D.2 Update-Selection and Falsification Analysis ‣ Appendix D Additional Experimental Results ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
visualizes the resulting trade-off. The left panel plots
$`\Delta_{\mathrm{upd}}`$ against $`H`$, while the right panel plots
$`\Delta_{\mathrm{upd}}`$ against $`R`$. Each point corresponds to one
configuration, point size encodes verifier cost, and the black dashed
curve marks the empirical Pareto frontier.

Figure 6: Plasticity–safety Pareto analysis of update-selection
strategies. Each point is one configuration obtained by sweeping
verifier budgets and acceptance thresholds. The $`x`$-axis is update
gain $`\Delta_{\mathrm{upd}}`$, and the $`y`$-axis is either harmful
update rate $`H`$ (left) or regression damage $`R`$ (right). Point size
indicates verifier cost $`C`$ (average verifier calls per candidate
update), and color denotes the update-selection strategy. The black
dashed line shows the empirical Pareto frontier, where larger gain and
smaller harm are jointly preferred. FGSE occupies the most favorable
lower-right region over a wide range of medium verifier budgets, showing
that it improves plasticity without incurring the safety cost typically
associated with aggressive update policies.

Figure [6](#A4.F6 "Figure 6 ‣ Plasticity–safety Pareto frontier ‣ D.2 Update-Selection and Falsification Analysis ‣ Appendix D Additional Experimental Results ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
reveals a clear plasticity–safety frontier. First, FGSE traces the
dominant lower-right boundary in both panels over a broad range of
medium-cost configurations, achieving substantially larger update gain
at similar or lower harm than competing strategies. In the
harmful-update panel, frontier configurations of FGSE achieve roughly
$`9\%`$–$`12\%`$ update gain while keeping the harmful update rate
within $`2.5\%`$–$`4.5\%`$, typically with only $`20`$–$`40`$ verifier
calls per candidate update. At comparable gain levels, Target-Only and
LLM-Judge Gate incur much larger harmful update rates, often exceeding
$`8\%`$–$`15\%`$, indicating that target improvement alone is an
unreliable proxy for safe transfer.

Second, a purely conservative policy is also suboptimal. Conservative
Gate combines low harm with much smaller update gain in the lower-left
region. This shows that effective self-improvement also requires
sufficient plasticity to capture reusable behavioral rules. Conversely,
Exhaustive Verifier pushes harm slightly lower than FGSE in a few
settings, but does so at much higher verifier cost and with little or no
gain advantage, indicating that aggressive verification yields
diminishing returns.

Third, the comparison between FGSE and FGSE w/o Refine highlights the
functional role of scope refinement. Without refinement, many
configurations move upward in both panels: they retain some gain but
suffer higher harmful update rates and larger regression damage. This
suggests that a substantial fraction of risky updates retain utility and
become safe only after narrowing their applicability conditions.
Overall, the Pareto analysis supports FGSE’s better trade-off between
*plasticity* and *safety*, placing it in a more favorable region of the
update-selection design space.

#### Targeted probes versus random probes.

FGSE uses *targeted* falsification: the verifier constructs probes
likely to expose scope overreach, missing preconditions, archived
regressions, and decoy-induced shortcut behavior. We compare targeted
probe scheduling with budget-matched baselines to evaluate its
efficiency in discovering harmful updates.

Let $`\mathcal{H}_{\mathrm{bad}}`$ denote the set of candidate updates
that are in fact unsafe or regressive under held-out evaluation. Given a
probe budget $`K`$, we define the *bad-update detection rate* as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
D(K)=\frac{1}{|\mathcal{H}_{\mathrm{bad}}|}\sum_{h\in\mathcal{H}_{\mathrm{bad}}}\mathbb{1}\!\left[\tau_{h}\leq K\right],
``` |  | (127) |

where $`\tau_{h}`$ is the number of probes required to expose update
$`h`$ under a given scheduling policy. Thus, $`D(K)`$ measures the
fraction of unsafe updates discovered within the first $`K`$ probes.

To account for the severity of detected updates, we also report *harmful
update avoided*,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
A(K)=\frac{\sum_{h\in\mathcal{H}_{\mathrm{bad}}}w_{h}\,\mathbb{1}\!\left[\tau_{h}\leq K\right]}{\sum_{h\in\mathcal{H}_{\mathrm{bad}}}w_{h}},
``` |  | (128) |

where $`w_{h}`$ is the downstream harm weight of update $`h`$, estimated
from its induced violation severity and regression impact. Hence,
$`A(K)`$ measures how much total harmful mass would be prevented if all
detected bad updates were rejected before commitment.

We compare five probe-selection policies under the same verifier budget:
Targeted (the full FGSE probe scheduler), Stratified Random (random
selection balanced across probe sources), Pure Random (uniform sampling
from the entire probe pool), Boundary-Only (target only
applicability-boundary probes), and Regression-Only (target only
archived-regression probes).
Figure [7](#A4.F7 "Figure 7 ‣ Targeted probes versus random probes. ‣ D.2 Update-Selection and Falsification Analysis ‣ Appendix D Additional Experimental Results ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
plots the resulting falsification discovery curves.

Figure 7: Falsification discovery curves under different probe-selection
policies. The $`x`$-axis is the probe budget $`K`$. The left panel shows
bad-update detection rate $`D(K)`$, and the right panel shows harmful
update avoided $`A(K)`$. Solid lines denote the mean across repeated
trials, and shaded bands denote $`95\%`$ confidence intervals. The gray
vertical band marks the practically relevant low-budget regime
($`8\leq K\leq 16`$). Targeted probing consistently dominates random
baselines, especially in the low-budget regime, showing that
hypothesis-aware falsification is substantially more
information-efficient than unguided random testing.

Figure [7](#A4.F7 "Figure 7 ‣ Targeted probes versus random probes. ‣ D.2 Update-Selection and Falsification Analysis ‣ Appendix D Additional Experimental Results ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
shows that targeted probing is markedly more informative than random
testing at every budget. The gap is largest in the practically relevant
low-budget regime, where verifier calls are scarce. At around $`K=8`$,
the Targeted policy already detects roughly twice as many bad updates as
Pure Random, and the improvement is even larger in terms of harmful
update avoided. This indicates that targeted probing discovers *more*
harmful updates early and prioritizes those with larger downstream
damage.

A second observation is that Boundary-Only and Regression-Only each
improve over pure random sampling in the regimes where their probe
families are most relevant, but both eventually saturate below the full
targeted strategy. This suggests that harmful updates are heterogeneous:
some arise from overly broad applicability conditions, whereas others
only become visible through archived-regression or decoy-style
counterfactual tests. Therefore, a single probe family is insufficient;
the gain of FGSE comes from selecting probes conditionally on the
specific hypothesis under test.

Finally, the larger gap in $`A(K)`$ than in $`D(K)`$ is itself
informative. It shows that targeted probing tends to surface the *most
dangerous* updates first while increasing discovery count. This property
is crucial for practical self-evolution, where only a small verifier
budget is available and preventing a few highly harmful commitments is
more important than marginally increasing average detection at very
large budgets.

#### Stability under stochastic rollouts.

We evaluate each candidate hypothesis under multiple stochastic rollouts
to assess the reproducibility of its benefit across seeds.

For a hypothesis $`h`$ and evaluation set $`\mathcal{X}_{h}`$, we define
its seed-specific update effect as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Delta_{h}^{(s)}=\frac{1}{|\mathcal{X}_{h}|}\sum_{x\in\mathcal{X}_{h}}\Big(R(\pi\oplus h;x,s)-R(\pi;x,s)\Big),
``` |  | (129) |

where $`s`$ is the rollout seed controlling stochastic decoding, action
tie-breaking, and environment perturbations. Thus, $`\Delta_{h}^{(s)}`$
measures the marginal effect of applying hypothesis $`h`$ under seed
$`s`$.

To quantify stability, we further compute the mean seed effect

|     |                                                             |     |       |
|-----|-------------------------------------------------------------|-----|-------|
|     |
       ``` math
       \bar{\Delta}_{h}=\frac{1}{S}\sum_{s=1}^{S}\Delta_{h}^{(s)},
       ```                                                          |     | (130) |

and the sign-consistency score

|  |  |  |  |
|----|----|----|----|
|  |
``` math
C(h)=\frac{1}{S}\sum_{s=1}^{S}\mathbb{1}\!\left[\operatorname{sign}\!\big(\Delta_{h}^{(s)}\big)=\operatorname{sign}\!\big(\bar{\Delta}_{h}\big)\right],
``` |  | (131) |

which measures the fraction of seeds whose update effect agrees in sign
with the mean effect. A stable and genuinely useful update should
exhibit both a positive $`\bar{\Delta}_{h}`$ and high sign consistency.

Figure [8](#A4.F8 "Figure 8 ‣ Stability under stochastic rollouts. ‣ D.2 Update-Selection and Falsification Analysis ‣ Appendix D Additional Experimental Results ‣ When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents")
visualizes the seed-level effect distributions for representative
hypotheses from the Commit, Refine, and Reject groups. Each row shows
the distribution of $`\Delta_{h}^{(s)}`$ over seeds for one hypothesis,
using a raincloud plot. This visualization shows the robustness of
observed gains across stochastic rollouts.

Figure 8: Stability of hypothesis effects under stochastic rollouts.
Each row corresponds to one hypothesis and shows the distribution of
seed-specific update effects $`\Delta_{h}^{(s)}`$ across repeated
rollouts. Rows are grouped by the final FGSE decision. Dots denote

shows a clear separation between update classes. Committed hypotheses
are tightly concentrated on the positive side, with small seed variance
and high sign consistency. In our diagnostic run, the median committed
hypothesis has $`\bar{\Delta}_{h}\approx 0.10`$ and median sign

rules whose scope still requires tightening. In contrast, rejected
hypotheses are typically centered near zero or slightly negative, and
many of them flip sign across seeds, showing that their apparent gains
are unstable and largely attributable to stochastic variation.

The effects of accepted updates persist across seeds. Hypothesis
identity dominates rollout randomness as a source of variation. FGSE
preferentially commits hypotheses whose benefit persists across
stochastic executions.

### D.3 Mechanistic Analysis of Long-Term Self-Evolution

#### Trajectory-level behavioral changes.

Aligned interpretability in autonomous driving ties language to
intermediate perception, prediction, and planning outputs \[[Ding
et al., 2025](#bib.bib9)\]. We compare baseline and FGSE execution
trajectories to identify the dominant behavioral edits underlying
performance improvements.

Let $`\tau^{\mathrm{B}}=(a_{1},\dots,a_{T})`$ and
$`\tau^{\mathrm{F}}=(a^{\prime}_{1},\dots,a^{\prime}_{T^{\prime}})`$
denote the baseline and FGSE trajectories for the same task. We first
align the two traces at the action-type level and group all trajectory
edits into four interpretable behavior families: *tool order*, *memory
retrieval*, *constraint checking*, and *final answer formatting*. For
each family $`e\in\mathcal{E}`$, we compute its weighted edit mass

|  |  |  |  |
|----|----|----|----|
|  |
``` math
m_{e}(\tau^{\mathrm{B}},\tau^{\mathrm{F}})=\sum_{o\in\mathcal{O}_{e}}w(o),
``` |  | (132) |

where $`\mathcal{O}_{e}`$ is the set of aligned edit operations assigned
to family $`e`$, and $`w(o)`$ denotes the causal weight of operation
$`o`$ estimated from its contribution to final task improvement. We then
define the dominant edit family as

|  |  |  |  |
|----|----|----|----|
|  |
``` math

panels. It reaches its strongest regime at a moderate memory size. In
this diagnostic run, FGSE attains around $`70\%\!\sim\!72\%`$ task

compared with All-Commit, FGSE achieves a clearly better quality–cost

far fewer retained hypotheses and noticeably smaller retrieval cost.

bottleneck for gains from persistent memory.

moderate memory size, the marginal gain of additional committed
hypotheses becomes very small, while retrieval cost continues to
increase. These results support controllable long-term memory growth
through commitment filtered by utility, falsification, and regression
preservation.

## Appendix E Broader Impacts

FGSE may improve the reliability of long-horizon language agents by
reducing unsafe memory updates, overgeneralized behavioral rules, and
regressions on previously solved tasks. Potential positive impacts
include safer agent adaptation in web, app, and tool-use settings where
persistent memory is used. However, more reliable self-evolving agents
may also increase the capability of automated systems that can perform
harmful or unauthorized actions if deployed without access control,
monitoring, and domain-specific safety constraints \[[Yang et al.,
2026a](#bib.bib62), [Fan et al., 2023](#bib.bib11)\]. Financial-agent
audits likewise identify source-manipulation risks and motivate
model-independent halts and hard loss limits \[[Wang and Saxena,
2026](#bib.bib48)\]. FGSE mitigates some of these risks through
verifier-grounded falsification, regression testing, audit records, and
post-commit monitoring. These mechanisms complement deployment-level
safety controls.

## Appendix F LLM Usage

This paper studies self-evolving LLM agents. In the experiments, frozen
LLM backbones are used as ReAct-style executors that generate
````
