###### Abstract

Large language model (LLM) agents can autonomously run neuroimaging
analyses from research questions to reported findings. Existing agentic
systems use tools to check that code runs and reported values match its
output, but rely on LLM judgment to decide which results warrant
scientific reporting. We show that LLM judges endorse site-confounded
findings even when the confound is presented as evidence. We present
CONFIRM, a framework that separates running an analysis from deciding
which findings to report. CONFIRM encodes each hypothesis as a
machine-readable, pre-specified analysis plan that fixes the claim and
its pass criteria before computing results. It then filters results
through five deterministic gates (search history and multiplicity,
confounds, power, analytic stability, and replication) under three
configurable reporting standards, from least to most demanding: Screen,
Replicate, and Full. Failed claims receive diagnoses that guide
follow-up analyses. To evaluate reporting decisions at the claim level,
we introduce NeuroClaimBench, comprising 489 executable neuroimaging
claims with frozen data, including literature-supported findings and 150
controls designed to violate individual methodological requirements. On
NeuroClaimBench, CONFIRM falsely supports at most 3% of controls,
compared with 23–38% for the baselines, while recovering up to 61% of
literature-supported claims. When auditing an existing agent, CONFIRM
reduces false support on controls from 23% to 0% while retaining the
agent’s literature-supported claims. Its diagnostic feedback also
produces more supported revisions than Self-Refine with fewer LLM calls.
Together, CONFIRM and NeuroClaimBench show that basing reporting
decisions on pre-specified analysis plans and deterministic gates is
essential for trustworthy autonomous scientific discovery.

## 1 Introduction

Large language model (LLM) agents are increasingly deployed to automate
scientific discovery: given a research hypothesis, an agent selects
datasets, formulates an analysis, executes code, and summarizes the
findings ([Boiko et al., 2023](#bib.bib6)). In neuroimaging, agents have
recently begun to automate this entire process ([Wang et al.,
2026](#bib.bib1); [Zhong et al., 2026](#bib.bib2); [Han et al.,
2026](#bib.bib3); [Xie et al., 2026](#bib.bib4)). For example, when
testing whether hippocampal volume decreases in Alzheimer’s disease, an
agent can autonomously compare patients with dementia against
cognitively normal controls in ADNI ([Weiner and others,
2010](#bib.bib18)) and report the resulting group difference. To date,
verification frameworks for these workflows focus almost entirely on
checking that scripts run without error and that reported values match
their outputs.

However, computational correctness does not guarantee scientific
validity. A correctly computed result may still come from an
underpowered cohort, an unadjusted confound, or a comparison selected
after inspecting the results. These problems are common in neuroimaging:
reliable brain-wide associations often require thousands of
participants ([Marek and others, 2022](#bib.bib7)), independent analysis
pipelines frequently reach different conclusions from the same raw
data ([Botvinik-Nezer and others, 2020](#bib.bib8)), and small cohorts
routinely inflate effect sizes that fail to replicate ([Button et al.,
2013](#bib.bib9); [Poldrack et al., 2017](#bib.bib10)).

Current systems entrust the decision to report a finding to the LLM
itself, which acts as an _LLM judge_. LLMs can report values unsupported
by their tools ([Ji et al., 2023](#bib.bib16)), misjudge the
applicability of statistical tests ([Zhu et al., 2024](#bib.bib34)), and
endorse site-confounded results even when shown evidence of the confound
(Section [5.1](#S5.SS1 "5.1 CONFIRM Rejects Designed Controls While Recovering Literature-Supported Claims ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")).
In these cases, the compared groups come mostly from different scan
sites, so site differences can appear as group effects. Fixed
heuristics, such as filtering for $`p<0.05`$, offer little protection
because significance thresholds accept effects caused by confounds just
as readily as genuine effects. Spurious findings distort downstream
meta-analyses and power calculations, and direct follow-up studies
toward effects that fail to replicate.

We introduce CONFIRM, a framework that separates running an analysis
from deciding whether its finding warrants scientific reporting. We call
this decision process _claim governance_. The LLM first translates a
hypothesis into a _pre-specified analysis plan_ that fixes the estimand
(the effect being tested), covariates (variables included to adjust for
other influences), cohorts, search family (every test the agent may run
for the question), and pass criteria. Deterministic gates are fixed
rules that evaluate five properties: search history and multiplicity
(whether the result survives correction for every test run), measured
confounds, statistical power (the probability of detecting a specified
effect), analytic stability (whether at least 60% of reasonable
alternative analyses agree), and independent replication. The Screen,
Replicate, and Full reporting standards specify which gates a claim must
pass. CONFIRM runs as a standalone agent or audits an existing agent in
_retrofit mode_. Failed-gate diagnoses guide follow-up analyses under
the pre-specified analysis plan.

Existing benchmarks assess program execution or agreement with reference
code ([Chen and others, 2025](#bib.bib35)). We introduce
NeuroClaimBench: 489 executable neuroimaging claims that can be tested
directly on the available imaging data. Each claim, analysis plan, and
data partition is fixed before evaluation. Claims are scored against
literature-grounded labels and 150 designed controls that violate
individual methodological requirements. On NeuroClaimBench, CONFIRM
falsely supports at most 3% of designed controls, compared with 23–38%
for the baselines, while recovering up to 61% of literature-supported
claims.

Our contributions are:

- •
  The reporting gap in agentic science. We show that LLM judges and
  fixed heuristics accept 23–38% of designed controls, which
  deliberately violate methodological requirements. They accept
  site-confounded findings even when shown evidence of the confound.
- •
  CONFIRM, an agentic framework for scientific reporting. We combine
  LLM-based analysis planning and follow-up with deterministic execution
  and reporting gates. CONFIRM runs as a standalone agent or audits an
  existing agent.
- •
  NeuroClaimBench. We provide frozen neuroimaging claims, literature
  reference labels, and designed negative controls for evaluating
  scientific reporting decisions.

## 2 Related Work

#### Agentic neuroimaging and iterative refinement.

LLMs can plan and execute end-to-end scientific workflows ([Boiko et
al., 2023](#bib.bib6)). Neuroimaging agents have focused on pipeline
reproducibility ([Wang et al., 2026](#bib.bib1)), preprocessing and
disease prediction ([Zhong et al., 2026](#bib.bib2)), predictive
accuracy ([Han et al., 2026](#bib.bib3)), or robustness against
hallucinated inputs ([Xie et al., 2026](#bib.bib4)), while VERITAS uses
fixed rules to assign evidence labels to hypotheses derived from
images ([Stoffl et al., 2026](#bib.bib5)). None of these systems
determines whether a neuroimaging claim warrants scientific reporting,
so
Section [5.1](#S5.SS1 "5.1 CONFIRM Rejects Designed Controls While Recovering Literature-Supported Claims ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")
evaluates adaptations of the two closest frameworks. In general agent
architectures, Self-Refine repeatedly critiques and revises its
generated responses ([Madaan and others, 2023](#bib.bib17)), but it
neither diagnoses specific methodological failures nor delegates
reporting decisions to deterministic code.

#### LLM judges.

LLMs are frequently used as evaluators, but their judgments show
position bias (sensitivity to response order), verbosity bias (favoring
longer responses), and self-enhancement bias (favoring their own
outputs) ([Zheng and others, 2023](#bib.bib38)). Scientific agents
increasingly rely on LLM critics to decide what to report ([Wang et al.,
2026](#bib.bib1)). CONFIRM assigns this reporting decision to code: the
model proposes analysis plans and follow-up candidates, while
deterministic gates decide which findings may be reported.

#### Governance layers and agent benchmarks.

POPPER formulates sequential falsification experiments to evaluate
free-form hypotheses with Type-I error control ([Huang et al.,
2025](#bib.bib37)). CONFIRM fixes an observational analysis plan before
computation and uses pre-specified criteria to decide which findings may
be reported. It runs on its own or audits an existing agent. EviBound
requires machine-checkable artifacts before an agent reports completed
work ([Chen, 2025](#bib.bib36)) to verify task execution.
ScienceAgentBench scores program code against references ([Chen and
others, 2025](#bib.bib35)). NeuroClaimBench evaluates which scientific
claims the completed analyses support.

#### Statistical safeguards for neuroimaging.

Techniques such as false discovery rate control ([Benjamini and
Hochberg, 1995](#bib.bib15)), multiverse analysis ([Steegen et al.,
2016](#bib.bib12); [Carp, 2012](#bib.bib11)), and ComBat
harmonization ([Johnson et al., 2007](#bib.bib13); [Fortin and others,
2018](#bib.bib14)) each target specific threats to validity. CONFIRM
combines these safeguards into an automated reporting rule for
scientific agents.

## 3 CONFIRM: Frozen Claim Governance

CONFIRM is a framework that determines whether an autonomous analysis
agent may report a statistical claim as supported. To eliminate
confirmation bias and selective reporting, CONFIRM separates three
stages: specifying a claim, computing its results with deterministic
code, and deciding whether to report it
(Figure [1](#S3.F1 "Figure 1 ‣ 3 CONFIRM: Frozen Claim Governance ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")).

The framework operates in two modes. In _standalone mode_, it governs
the agent during execution and evaluates claims before any final report
can be generated. In _retrofit mode_, it audits an existing agent’s
claim and record of the analysis after execution. The original analysis
plan must have been fixed and timestamped before results were observed.
Both modes apply the same analysis plan format, verification gates, and
reporting standards.

Figure 1: CONFIRM separates running an analysis from deciding whether
its finding may be reported. The LLM turns a question into an analysis
plan that is frozen before any statistic is computed. Code runs the
analysis, and five gates check the result. The reporting standard,
chosen before results are seen, sets which gates must pass, and only
Full can report a claim as confirmed. If a required gate fails, the
claim is withheld, and the LLM may propose revised analyses that keep
the original question. These are tested first on the discovery and
replication cohorts and then on holdout data.

````math
The analysis plan $`C`$ is checked against a schema that specifies its
required fields and format. Before any outcome data are read, the plan
is fixed and assigned a cryptographic hash, an identifier computed from
its contents. The plan is then locked, so the agent cannot alter the
outcome variable, covariates, multiplicity penalties, or replication
criteria after inspecting results.

Once the plan is frozen, deterministic scripts fit the models and
generate an analysis record $`E(C)`$ containing effect estimates,
multiverse analyses (repeated fits under pre-specified alternative
analysis choices), power calculations, replication statistics, and
checks of the study design. The LLM agent receives $`E(C)`$ solely to
draft natural-language summaries. An automated consistency check
validates all numbers and labels in the draft against $`E(C)`$,
discarding any value that differs from the analysis record.

### 3.2 Deterministic Verification Gates and Reporting Standards

CONFIRM subjects every claim to five deterministic checks, termed
*gates*. Each gate targets a specific failure mode in empirical
neuroimaging
(Table [1](#S3.T1 "Table 1 ‣ 3.2 Deterministic Verification Gates and Reporting Standards ‣ 3 CONFIRM: Frozen Claim Governance ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")).
Formally, the gates evaluate the analysis plan and execution record,
mapping $`(C,E)`$ to a vector of pass/fail results,
$`\mathbf{g}(C,E)\in\{0,1\}^{5}`$. All gate thresholds $`\mathcal{G}`$
are fixed in $`C`$ before execution and cannot be changed after results
are observed.

|  What can go wrong |  Gate |  Passes when (default) |  Designed control |
|----|----|----|----|
|  Many tests were tried and only the best one is reported |  Search history and multiplicity |  The effect stays significant after correcting for every test tried ($`\alpha=0.05`$). |  Broad-search |
|  A site or scanner difference creates an apparent effect |  Measured confounds |  No measured site, scanner, field-strength, or software variable differs between the groups while being left out of the analysis. |  Site-confounded |
|  The sample is too small to trust the result |  Power |  The planned design can detect a modest reference effect, by default $`d=0.3`$, with at least 80% power. |  Underpowered |
|  The result depends on arbitrary analysis choices |  Analytic stability |  At least 60% of reasonable alternative analyses give a consistent result ([Steegen et al., 2016](#bib.bib12)). |  – |
|  The effect does not appear again in new data |  Independent replication |  The effect has the same direction and $`p<0.05`$ in every replication dataset. |  Nonreplicating |

For statistical power, the gate computes prospective power: the
probability of detecting a reference effect size
$`\delta_{\mathrm{ref}}`$ chosen before results are observed. When
literature values are unavailable, CONFIRM defaults to
$`\delta_{\mathrm{ref}}=0.3`$ (Cohen’s $`d`$). No benchmark claim in our
evaluation had a reference effect size established in the literature, so
all benchmark power gates use this default, and

A claim is designated confirmed if and only if its frozen analysis
passes all five gates ($`\mathbf{g}=\mathbf{1}`$) on the designated
discovery and replication cohorts. This label denotes support under the
Full reporting standard. The claim is withheld if any gate fails or
required diagnostic metadata are missing. Withheld claims receive an
explanatory diagnostic label according to the following priority order:
fragile (multiplicity, confound, or stability failure), under_powered
(power failure), or non_replicated (replication failure).

Because gate checks are deterministic and computed once, CONFIRM
supports three reporting standards, each adding requirements to the
previous one. CONFIRM-Screen requires only the multiplicity and confound
gates and reports *discovery support*. CONFIRM-Replicate adds the
independent replication gate and reports *replicated support*.
CONFIRM-Full, the default, enforces all five gates and is the only
standard that can report a claim as confirmed.

### 3.3 Bounded, Failure-Directed Follow-Up Search

When a parent analysis plan $`C_{0}`$ fails, CONFIRM uses the failed
gates to guide a bounded search for follow-up analyses. The parent
retains its withheld verdict, and each follow-up receives a separate
evaluation.

A deterministic diagnostic routine first identifies the failed gates and
the fields that must stay fixed. The search then runs for at most $`R`$
rounds, and each round $`r\in\{1,\dots,R\}`$ has three steps. First, the
LLM agent receives $`C_{0}`$, the failure diagnostic, the available
dataset variables, and the history of failed candidates from earlier
rounds, and it proposes up to $`K`$ candidate analysis plans
$`\{C_{r,1},\dots,C_{r,K}\}`$. Second, a strict validator rejects any
candidate that alters the core scientific question, the primary
predictor or contrast, the hypothesized direction, the underlying
datasets, or the gate thresholds, or that removes a previously included
covariate. Third, surviving candidates are executed only on the parent’s
discovery and replication cohorts (the *search data*). To penalize
iterative exploration, candidate $`k`$ in round $`r`$ is evaluated
against a cumulative multiplicity penalty

|  |  |  |  |
|----|----|----|----|
|  |
``` math
M_{\mathrm{eff}}(C_{r,k},r)=\max\left\{M_{\mathrm{declared}}(C_{r,k}),\,M_{0}+H_{r}\right\},
``` |  | (3) |

where $`H_{r}`$ is the cumulative count of unique hypotheses evaluated
through round $`r`$. Any candidate that provisionally passes is
re-checked against the final hypothesis count $`H_{R}`$ at the end of
the search.

Candidates surviving this follow-up protocol receive *exploratory
support* on the search data. Support for the frozen follow-up plan is
assessed on additional data: designated holdout and external cohorts are
kept out of candidate generation and follow-up search. They are used
only after the candidate plan and its final count of tests are fixed.
Appendix [A](#A1 "Appendix A Gate and Follow-Up Implementation Details ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")
specifies how failed gates guide revisions, when search stops, and how
candidates are validated.

## 4 NeuroClaimBench: A Claim-Level Benchmark

Existing benchmarks for AI analysis agents typically evaluate *code
execution*: whether a model writes code that runs to completion.
NeuroClaimBench evaluates *reporting decisions*: whether a system agrees
with literature-grounded references and withholds claims that violate
the specified methodological requirements.

Benchmark cases are defined independently of the outputs of the systems
being evaluated. Each benchmark item pairs a natural-language research
question with a frozen, executable analysis plan, its designated data
partitions, and an adjudicated reference label where one exists.

### 4.1 Benchmark Construction and Evidence Partitions

We assessed each candidate item before execution, without access to its
results. We checked that the research question matched the analysis plan
and datasets, and that the specified estimand was statistically
identifiable, meaning that it could be uniquely determined from the
planned model and available data.

Out of 544 candidate items, 55 ambiguous or non-executable items were
excluded. The remaining 489 executable claims comprise 279 scientific
claims drawn from neuroimaging cohorts, 60 external-transfer claims that
evaluate generalization to other imaging consortia, and 150 designed
negative controls, which are claims with deliberate methodological flaws
and a known negative label. The counts for each category appear in
Appendix
Table [6](#A2.T6 "Table 6 ‣ B.2 Source Corpus ‣ Appendix B Benchmark Construction Details ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging").
The benchmark spans structural MRI (sMRI), resting-state functional
connectivity (rs-fMRI), and positron emission tomography (PET), covering
healthy populations, attention-deficit/hyperactivity disorder (ADHD),
autism spectrum disorder (ASD), Alzheimer’s disease/aging, and
psychosis. Each analysis plan designates discovery, replication, and
holdout partitions with no participants shared between them.

#### Designed negative controls.

New scientific claims often lack a known reference answer. We therefore
constructed 150 designed negative controls whose methodological flaws
require withholding the claim. Each follows a standard neuroimaging
study design with one deliberate flaw that violates a reporting
requirement.

The controls represent five distinct failure modes:

1.  1.
    Site-confounded: Comparison groups are sampled from different
    acquisition sites in unbalanced ratios, mixing the apparent group
    effect with scanner differences.
2.  2.
    Broad-search: Many tests are run, and a significant result is
    selected for reporting without correction for the number of tests.
3.  3.
    Random-label: Group diagnostic labels are randomly permuted,
    ensuring that any detected effect represents sample noise.
4.  4.
    Underpowered: Sample sizes are severely restricted, so the design
    lacks 80% power to detect the reference effect.
5.  5.
    Nonreplicating: An effect observed in the discovery cohort fails to
    replicate ($`p\geq 0.05`$ or the opposite sign) in an independent
    cohort.

### 4.2 Literature Reference Labels and Adjudication

Literature reference labels were established for 96 scientific and
external-transfer claims through agreement among LLM assessors and
expert review. Two independent LLMs (GPT-5.5 and Gemini 3.5 Flash)
evaluated fixed sets of PubMed evidence for each contrast. An
independent arbitrator (Claude Opus 4.8) cast the deciding vote, and
neuroimaging experts reviewed and finalized all resulting labels. This
process yielded 47 *strict* labels (requiring agreement between the
arbitrator and at least one assessor, followed by expert consensus) and
49 *provisional* labels with weaker agreement among assessors
(Appendix [B.4](#A2.SS4 "B.4 Reference Construction and Coverage ‣ Appendix B Benchmark Construction Details ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")).
The 150 designed controls and 22 random-label controls in the
external-transfer split have a *withhold* reference label. The remaining
221 executable claims lack direct literature evidence for their exact
contrast and are excluded when calculating the metrics.

### 4.3 Evaluation Subsets and Performance Metrics

Evaluation uses three subsets. The literature set ($`N=70`$) contains
scientific claims with adjudicated literature labels, 51 supported and
19 unsupported, covering both scalar brain measures (e.g., hippocampal
volume) and brain-wide patterns. Because baseline methods (except direct
LLM judges) have no decision rule for claims about patterns across many
brain regions, head-to-head comparisons use the common scalar set
($`N=46`$) of single-measure claims, with 31 supported and 15
unsupported. The control set ($`N=150`$) contains all designed negative
controls, all of which should be rejected. If a baseline method fails to
run or returns no verdict for an item, the item counts as withheld.

System performance is summarized with two metrics. Recovery
($`\uparrow`$) is the proportion of literature-supported claims that a
method accepts. False support ($`\downarrow`$) is the proportion of
claims with a negative reference label that a method accepts, reported
separately for designed controls and literature-unsupported claims.

## 5 Experiments

We ask three questions. Does CONFIRM eliminate methodologically flawed
findings without sacrificing literature-supported claims
(Section [5.1](#S5.SS1 "5.1 CONFIRM Rejects Designed Controls While Recovering Literature-Supported Claims ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging"))?
Do CONFIRM’s deterministic failure diagnoses guide agents toward
revisions supported on search and holdout data
(Section [5.2](#S5.SS2 "5.2 Deterministic Failure Diagnoses Guide Effective Follow-Up ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging"))?
Can CONFIRM be integrated into existing autonomous agents to audit and
improve their reliability
(Section [5.3](#S5.SS3 "5.3 Retrofitting CONFIRM Onto Existing Autonomous Agents ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging"))?

checks appear in
Appendix [C](#A3 "Appendix C Experimental Details and Additional Results ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging").

### 5.1 CONFIRM Rejects Designed Controls While Recovering Literature-Supported Claims

We compare CONFIRM against four reporting policies: *VERITAS-adapted*
(fixed heuristic) ([Stoffl et al., 2026](#bib.bib5)),
*NeuroClaw-adapted* (LLM critic panel) ([Wang et al., 2026](#bib.bib1)),
a *direct LLM judge* (prompted on summary statistics and metadata), and
a *significance filter* (reporting any directional $`p<0.05`$ across
datasets). We adapt VERITAS and NeuroClaw to evaluate frozen claims
using their original decision rules and persona prompts, respectively.
VERITAS-adapted reimplements VERITAS’s fixed rule for assigning evidence
labels with its default smallest effect of interest ($`d=0.5`$,
$`r=0.3`$), $`\alpha=0.05`$, and its power formula. NeuroClaw-adapted
uses GPT-5.5 with NeuroClaw’s original prompts for three roles:
biostatistician, clinical neuroscientist, and methodology expert. It
applies NeuroClaw’s panel rule, including the methodology expert’s veto,
and reports a claim only when all three roles support it. No threshold,
prompt, or aggregation rule was tuned on NeuroClaimBench
(Appendix [C.1](#A3.SS1 "C.1 Comparison Protocol ‣ Appendix C Experimental Details and Additional Results ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")).
All methods receive the same evidence as CONFIRM: the discovery and
replication effects, results from the alternative analyses, power, the
declared search family, and each measured site or scanner variable’s
association with the predictor. No method sees a reference label, gate
state, or CONFIRM verdict.

### 5.2 Deterministic Failure Diagnoses Guide Effective Follow-Up

Run autonomously, CONFIRM formulated and executed 289 analysis plans.
CONFIRM-Full withheld 74% of them, citing the exact failed gates. When
evaluated on holdout partitions, 25% of initially confirmed claims
passed the Full reporting standard again, compared with 3% of withheld
claims. The replication gate alone passed for 63% and 15%, respectively
(Appendix [C.3](#A3.SS3 "C.3 Holdout Support for Standalone Verdicts ‣ Appendix C Experimental Details and Additional Results ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")).
The 215 withheld claims are the starting point for the follow-up search
below.

CONFIRM uses failed-gate diagnoses to guide follow-up analysis. We gave
each withheld claim to GPT-5.5 and asked it to propose revised analysis
plans within a fixed search budget ($`R=3`$ rounds, $`K=5`$ candidates
per round), enforcing cumulative multiplicity corrections and schema
validation. We compared three kinds of feedback. With failure-blind
retry, the LLM receives only a binary notification of failure. With
Self-Refine ([Madaan and others, 2023](#bib.bib17)), the LLM is prompted
to critique and revise its failed analysis on its own. With CONFIRM
diagnosis, the LLM receives deterministic diagnostic output identifying
the failed gates and the fields it must keep unchanged.

Across three independent evaluation runs
(Table [3](#S5.T3 "Table 3 ‣ 5.1 CONFIRM Rejects Designed Controls While Recovering Literature-Supported Claims ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")
reports a representative run), CONFIRM diagnosis produced more revisions
supported on the search data (70 supported revisions vs. $`\leq 54`$ for
alternatives). It also used fewer total LLM calls and reached
approximately twice the holdout support rate of failure-blind retry or
Self-Refine. For designed controls, a high-budget follow-up search
($`R=10`$, $`K=10`$) evaluated 10,716 candidates, and none passed even
provisionally (Appendix

### 5.3 Retrofitting CONFIRM Onto Existing Autonomous Agents

We also used CONFIRM to audit claims after NeuroClaw-adapted completed
its analyses. NeuroClaw-adapted alone accepts 23% of designed controls.
Requiring its claims to pass CONFIRM-Full eliminates all false support
on controls (0%) while retaining every literature-supported claim the
agent originally supported
(Figure [5](#S5.F5 "Figure 5 ‣ 5.2 Deterministic Failure Diagnoses Guide Effective Follow-Up ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")).
CONFIRM’s diagnoses also improve the agent’s own revisions. When
NeuroClaw-adapted revises its withheld claims, CONFIRM’s diagnosis
raises the share of drafts the agent reports from 28.6% to 37.5%,
against 35.4% with self-critique, while using fewer LLM calls. It also
raises the share of drafts supported on holdout data from 5.7% to 8.9%,
against 6.4% with self-critique
(Figure [6](#S5.F6.fig1 "Figure 6 ‣ 5.2 Deterministic Failure Diagnoses Guide Effective Follow-Up ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging"),

## 6 Discussion

#### Auditable reporting decisions.

LLM judges apply available evidence inconsistently, while fixed
heuristics omit relevant checks. The frozen analysis plan and execution
record make the reporting criteria and their outcomes available for
inspection. Users can trace a withheld claim to its failed checks, and
agents can use those diagnoses to plan follow-up analyses. The same
records support external audits across agents.

#### Reporting standards for exploration and confirmation.

The reporting standards let researchers match requirements to the
study’s purpose. CONFIRM-Screen supports exploratory analysis and
screening many claims, CONFIRM-Replicate supports multi-cohort studies
with limited statistical power, and CONFIRM-Full suits confirmatory
studies that must pass all five gates. The standard is selected before
results are observed. Stored gate outcomes also let readers apply
stricter standards without rerunning models.

#### Generalization across scientific fields.

Applying CONFIRM in another field requires translating its
methodological requirements into executable gates, such as checks for
batch effects in genomics, selection bias in epidemiology, or invalid
instrumental variables in econometrics. The same benchmark design can be
used in those fields: construct negative controls that violate the
relevant requirements and measure how often agents support them.

## 7 Conclusion

LLM agents that run neuroimaging analyses still leave the decision to
report a finding to LLM judgment, and LLM judges endorse site-confounded
findings even when the confound is shown to them. CONFIRM takes this
decision away from the LLM. The LLM writes a pre-specified analysis
plan, code runs it, and five deterministic gates decide whether the
finding may be reported under a reporting standard chosen before results
are seen. Every verdict records which gates passed and which failed, so
a withheld claim can be traced to its cause.

On NeuroClaimBench, CONFIRM falsely supports at most 3% of designed
controls, compared with 23–38% for the baselines, and CONFIRM-Full
supports none. It recovers up to 61% of literature-supported claims, and
87% of the literature-supported claims that CONFIRM-Full withholds fail
to replicate in the independent cohort. Its diagnoses tell the LLM which
gate failed and which parts of the analysis plan a revision must
preserve. With them, the LLM finds more revisions supported on the
search data than with failure-blind retry or Self-Refine, reaches about
twice their holdout support rate, and uses fewer LLM calls. Used to
audit an existing agent, CONFIRM lowers false support on designed
controls from 23% to 0% and keeps every literature-supported claim the
agent supported.

These results show that an agent can propose and run analyses freely,
while criteria fixed before results are observed determine which
findings it may report. The same separation carries over to other fields
wherever methodological requirements can be written as executable
checks, and designed controls like those in NeuroClaimBench measure how
often an agent reports findings that violate them.

Analysis plans may specify stricter thresholds.

#### Search history and multiplicity.

The effective family size is the number of tests used for multiplicity
correction. It is the largest count among the declared tests, the tests
documented during claim selection, and the outcomes or regional features
tested during execution. Scalar claims must reach
$`p\leq\alpha/M_{\mathrm{eff}}`$ in the declared direction, and
brain-wide claims use Benjamini–Hochberg-adjusted $`q`$-values across
the regional family ([Benjamini and Hochberg, 1995](#bib.bib15)). A
search whose selection history is unknown, or whose selection used the
full data, receives unverifiable_search_provenance.

#### Measured confounds.

The gate audits four measured confounds: site, scanner, field strength,
and processing-software version. For each available variable that varies
within the data, it tests association with the predictor at
$`\alpha=0.05`$, using a chi-square test for a group predictor, a
one-way ANOVA for a continuous predictor against a categorical variable,
and a Pearson correlation between continuous variables. It stores the
test statistic, $`p`$-value, and number of levels. Omitting an
associated variable from the declared covariates yields
confound_incomplete.

#### Statistical power.

The power gate asks whether the planned design can detect a reference
effect $`\delta_{\mathrm{ref}}`$ at the minimum power set in the
analysis plan. Designs below the threshold receive under_powered.
Table [2](#S5.T2 "Table 2 ‣ 5.1 CONFIRM Rejects Designed Controls While Recovering Literature-Supported Claims ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")
varies $`\delta_{\mathrm{ref}}`$ from 0.1 to 0.5. Although the share of
scalar claims passing the power gate ranges from 17% to 99%,
CONFIRM-Full remains at 41% recovery, 11% literature false support, and
no false support on controls for values from 0.2 to 0.4. Recovery
changes only at $`d=0.1`$, falling to 14% with no false support.

#### Analytic stability.

Let $`\mathcal{F}`$ denote the pre-specified analysis variants, or
*forks*, that differ in covariates, outlier handling, and model form.
The default grid combines inclusion or omission of total intracranial
volume and of site, three outlier rules (none, removal at $`|z|>3`$, and
winsorization, which caps extreme values), and ordinary least squares or
a robust model, giving $`|\mathcal{F}|=24`$ forks. The grid is fixed
before execution and shared across claims unless an analysis plan
declares another. A scalar fork is consistent when it retains the
required direction and multiplicity threshold, and CONFIRM requires

|  |  |  |  |
|----|----|----|----|
|  |
``` math
S(C)=\frac{1}{|\mathcal{F}|}\sum_{f\in\mathcal{F}}I_{f}\geq\rho,
``` |  | (4) |

where $`I_{f}=1`$ only for a directionally consistent, significant fork
and $`\rho`$ is fixed in the analysis plan. Forks that fail to run or
cannot estimate the specified effect remain in the denominator.
Brain-wide claims must retain their regional pattern across six forks,
which combine full or minimal covariates with the three outlier rules
under ordinary least squares. A brain-wide fork is consistent when at
least half of the regions significant in the primary fit remain
significant in the locked direction.

#### Independent replication.

The model specified by the fixed analysis plan is fitted again in every
designated replication cohort. Scalar claims must replicate with the
required direction and independent significance. Brain-wide analysis
plans additionally fix thresholds for regional overlap,
replicated-region fraction, and pattern correlation. ComBat
harmonization is applied only when the analysis plan requires
it ([Johnson et al., 2007](#bib.bib13); [Fortin and others,
2018](#bib.bib14)).

|----|----|----|

|  fragile |  Search history or multiplicity requirements, measured-confound checks, or analytic stability fail. |  unverifiable_search_provenance; confound_incomplete; failed stability. |

### A.2 Failure Diagnosis and Candidate Validation

A deterministic routine maps the parent analysis plan, its analysis
record, and its failed gates to a structured diagnosis,

|  |  |  |
|----|----|----|
|  |
``` math
d_{0}=\operatorname{Diagnose}(C_{0},E(C_{0}),\mathbf{g}(C_{0},E(C_{0}))).
``` |  |

The diagnosis records the primary failure, its supporting evidence, the
fields that must be preserved, and the types of revision allowed. It
distinguishes errors in the analysis plan, evidence failures, design
limits, search-history failures, and confound failures.

In round $`r`$, the LLM receives $`C_{0}`$, $`d_{0}`$, the list of
variables available in the search data, and a structured summary of the
failures from round $`r-1`$. Each candidate $`C_{r,k}`$ records its
parent, round, question, executable analysis plan, and a rationale
connecting it to the parent. Permitted changes are refinements of the
outcome within the same modality, subgroups available in the search
data, justified measured confounds, and brain-wide patterns related to
the parent claim.

The validator compares each candidate analysis plan with its parent. It
rejects any change to the predictor or contrast, direction, datasets,
required gates, or existing covariates, as well as unrelated modalities,
invalid inclusion rules, unsupported numeric claims, non-executable
fields, and rewrites that change only wording. An added confound must be
available in every search-data cohort and have a scientific
justification. The agent receives invalid proposals and the rules they
violated, with a limit on the number of repair attempts. Evaluation
proceeds with candidates that satisfy the schema and validation rules.

### A.3 Stopping Rules, Candidate Status, and Holdout Evaluation

Candidates that provisionally pass on the search data are re-checked
using the final count of tests. A candidate that no longer passes may
return to the next round for revision. The search stops after $`R`$
rounds, when no valid candidate is generated, when generation fails, or
when no failed candidate remains.

Some candidates repair the parent’s failure directly, for example by
adding an omitted confound. Others introduce new outcomes, subgroups, or
brain-wide patterns. Both kinds must pass every gate and receive
exploratory support on the search data.

After the search-data evaluation, each surviving candidate and its final
effective family size are frozen. A mapping fixed independently of
outcomes assigns compatible analysis plans to designated internal
holdout and external cohorts.

## Appendix B Benchmark Construction Details

### B.1 Cohorts, Modalities, and Eligibility

NeuroClaimBench draws on 544 source items spanning structural MRI,
resting-state functional connectivity, and PET. Structural MRI for
Alzheimer’s disease and aging uses ADNI ([Weiner and others,
2010](#bib.bib18)) and OASIS3 ([LaMontagne and others,
2019](#bib.bib19)), with NACC for external transfer ([Beekly et al.,
2007](#bib.bib20)). Normative and neurodevelopmental
functional-connectivity analysis plans use UK Biobank ([Miller and
others, 2016](#bib.bib21); [Alfaro-Almagro and others,
2018](#bib.bib22)), HCP-family cohorts ([Van Essen et al.,
2013](#bib.bib23); [Bookheimer and others, 2019](#bib.bib24)),
ABCD ([Casey and others, 2018](#bib.bib25)), ABIDE ([Di Martino and
others, 2014](#bib.bib26); [Di Martino and others, 2017](#bib.bib27)),
and ADHD-200 ([Bellec et al., 2017](#bib.bib28)), and functional MRI for
Alzheimer’s disease and aging also uses ADNI and OASIS3. Psychosis
analysis plans use COBRE ([Aine and others, 2017](#bib.bib29)),
FBIRN ([Keator and others, 2016](#bib.bib30)), ChineseSZ,
BSNIP2 ([National Institute of Mental Health Data Archive,
2015](#bib.bib31); [Clementz and others, 2022](#bib.bib32)), Olin, and
Johns Hopkins data, with CNP for external transfer ([Poldrack and
others, 2016](#bib.bib33)).

Each claim is tied to its cohort pair. An analysis plan is executable
only when every named cohort contains its outcome, predictor,
covariates, and group definition, and the model can estimate the
specified effect. Low-power designs remain eligible for evaluation by
the power gate. Differences in scanner, site, and processing remain part
of the replication challenge.

Each benchmark case records three fields: the split (scientific,
external-transfer, or designed control), the reference label (support,
withhold, or unresolved), and the observed outcome (confirmed, withheld,
error, or not evaluated). Literature evidence, model agreement, the
source of the question, and reference strength are recorded for
sensitivity analyses.

Each claim records its question, analysis plan, dataset roles, and
evidence sources, with hashes identifying the frozen question, plan, and
data partitions. Controls also record their assignments, selected rows,
generation parameters, and random seeds. Items with matching executable
plans and scientific content are merged, but distinct random assignments
remain separate tests.

### B.3 Outcome-Blind Eligibility Assessment

Corrections that aligned an analysis plan with its question kept the
question’s predictor, contrast, population, outcome, modality, and
direction, and could also add measured confounds as covariates. Before
execution, deterministic checks verify the groups, outcomes, required
columns, design rank, and residual degrees of freedom. Gemini 3.5 Flash

ambiguous, which remain unresolved and excluded from all reported
metrics. Designed controls were validated deterministically. The prompts

### B.4 Reference Construction and Coverage

GPT-5.5 and Gemini 3.5 Flash assessed fixed sets of PubMed evidence, and
Claude Opus 4.8 served as the independent arbitrator. Every cited PMID
or DOI had to appear in the fixed evidence set, and the cited study had
to match the claim’s population, contrast, imaging modality, outcome,
and direction. Of the 96 score-eligible literature references, 44 had
agreement among all three models, 15 had arbitrator-plus-assessor
agreement, and 37 had assessor-only agreement. The 47 strict references
comprise 39 all-three and 8 arbitrator-plus-assessor cases, and the 49
provisional references comprise 5, 7, and 37 cases of these three types.
Neuroimaging experts reviewed and finalized all literature labels.

The 150 controls in the control set and 22 random-label controls in the
external-transfer split receive negative labels from their design. They
are separate from the strict literature references. Evidence was
insufficient for 276 source items, including 221 executable unresolved

### C.1 Comparison Protocol

The three reporting standards use the same analysis plans, gate
thresholds, and gate results. They differ in the gates required for
support, with CONFIRM-Full requiring all five. Because the significance
filter has no decision rule for brain-wide claims, comparisons that
include it use the common scalar set. Removing one gate at a time
measures its contribution to the verdict.

The direct LLM judge receives the frozen claim and the evidence with
reference labels excluded in a single GPT-5.5 call, whereas
NeuroClaw-adapted makes three calls per claim. The judge applies no
aggregation rule for brain-wide claims. The significance filter requires
an unadjusted $`p<0.05`$ in the locked direction in discovery and in
every replication cohort, with no multiplicity, confound, power, or
stability requirement. In follow-up search, failure-blind retry receives
only the prior failure, whereas Self-Refine ([Madaan and others,
2023](#bib.bib17)) adds a critique call before each refinement, which
increases the number of LLM calls for the same search budget.

The 150 designed controls comprise 42 site-confounded, 42 broad-search,
42 random-label, 21 underpowered, and 3 nonreplicating cases.
Site-confounded controls account for 74% of the controls that
VERITAS-adapted supports, 95% for the direct judge, 98% for the
significance filter, and 97% for NeuroClaw-adapted. VERITAS-adapted also
accepts 24% of broad-search controls, because it relies on discovery
evidence alone. CONFIRM-Full rejects every control in all five families.

### C.4 Diagnosis Feedback for an Existing Agent

NeuroClaw-adapted writes questions and analysis plans, CONFIRM evaluates
the 280 executable drafts, and the 200 withheld claims are revised using
one of two types of feedback with the same budget: self-critique, in
which the agent critiques its supported or withheld verdict, or
CONFIRM’s gate diagnosis
(Table [11](#A3.T11 "Table 11 ‣ C.4 Diagnosis Feedback for an Existing Agent ‣ Appendix C Experimental Details and Additional Results ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")).
Diagnosis finds supported follow-ups for more withheld claims than
self-critique while using fewer calls, because self-critique adds a

### C.5 Worked Example: Revising One Withheld Claim

Figure [4](#S5.F4 "Figure 4 ‣ 5.2 Deterministic Failure Diagnoses Guide Effective Follow-Up ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging")
traces one withheld claim through the follow-up search of
Section [5.2](#S5.SS2 "5.2 Deterministic Failure Diagnoses Guide Effective Follow-Up ‣ 5 Experiments ‣ CONFIRM: Governing Scientific Reporting for Trustworthy Agentic Neuroimaging").

#### Step 1: the original claim and its verdict.

The claim states that, among cognitively normal OASIS3 participants,
older age is associated with larger ventricular volume. The analysis
plan adjusts for sex, estimated total intracranial volume (eTIV), and
site, and it replicates the claim in a separate OASIS3 partition
reserved for replication. CONFIRM withholds the claim at the
measured-confound gate. OASIS3 scans were processed with four versions
of FreeSurfer, and the version used is associated with participant age.
Because the analysis omits the software version, software changes could
account for part of the apparent age effect. CONFIRM therefore labels
the claim fragile.

#### Step 2: the diagnosis given to the LLM.

CONFIRM identifies the omitted measured confound and lists the fields
that each revision must preserve: the scientific question, the outcome
family, the expected direction, the datasets, and every gate threshold.

#### Step 3: the LLM’s proposals.

Guided by this diagnosis, the LLM proposes three revisions. Proposal (a)
adds the FreeSurfer version as a covariate, directly repairing the
diagnosed failure. Proposal (b) adds the software version and restricts
the sample to participants aged 65 or older. Proposal (c) adds the
software version and tests a six-region structural pattern instead of
ventricular volume alone.

#### Step 4: validation.

Before execution, the deterministic validator compares each proposal
with the parent analysis plan. Proposals (a) and (c) preserve every
required field and pass validation. Proposal (b) is rejected without
being run, because the age cutoff is not among the subgroups offered to
the LLM.

#### Step 5: evaluation on the search data.

The two valid proposals run on the same discovery and replication data
as the parent and must pass every gate. Each result is corrected for
every analysis tried during the search, and both (a) and (c) pass every
gate after this correction. Their support remains exploratory at this
stage, because the search used the same data.

#### Step 6: evaluation on holdout data.

Finally, (a) and (c) are tested on holdout data never used during the
search, and both are supported there. The parent claim, which omits the
software version, is not supported on the same holdout data.

## Appendix D Scope and Limitations

NeuroClaimBench covers a finite set of executable claims that represents
some target populations more than others. Its reference labels come from
expert review of the retrieved evidence, its designed controls target
specific gates, and it covers three imaging modalities.

The gates assess the recorded analyses and measured confounds under
fixed thresholds. Passing them does not establish biological truth.
````
