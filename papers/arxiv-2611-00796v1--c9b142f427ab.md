###### Abstract

Post training for large reasoning models remains insufficient on
challenging problems, whose correct trajectories are hard to sample.
Though prior works address this difficulty by integrating supervised
fine tuning on expert trajectories with reinforcement learning, such
external experts are not always available. Existing self improvement
methods instead use reference solutions to create a privileged
self-teacher. Yet privileged teacher correctness does not imply student
reachability. Solution conditioning shifts the teacher distribution
toward actions unlikely under the unprivileged student, producing
seemingly ”correct” trajectories that are unreachable or even mal-formed
learning targets. Accordingly, we identify reachability alignment as the
key to self constructed supervision and propose Self-Steered Reasoner
(SSR). SSR realizes this principle through student support projection,
which transforms the privileged teacher distribution into a directional
signal only over reasoning actions locally reachable under the unguided
student. Verification then retains correct trajectories sampled from
this reachable space. To further boost the sampling efficiency, an
iterative refinement framework is adopted, using diagnostic guidance
based on current trajectories. On problems with pass@64 = 0 even after
extensive RL, SSR recovers correct and learnable trajectories for 74.6%
without parameter updates. Fine tuning on these trajectories followed by
resumed reinforcement learning improves aggregate accuracy by 4.9
percentage points on AIME25/26 and HMMT26. These results show that
privileged guidance becomes effective self-improvement data when aligned
with the reasoning actions the student can reach.

## 1 Introduction

Training large reasoning models on verifiable tasks has driven
substantial gains in mathematical and scientific problem
solving ([OpenAI, 2024](#bib.bib35); [DeepSeek-AI, 2025](#bib.bib33);
[Shao et al., 2025](#bib.bib6)). Yet reinforcement learning remains
ineffective on the hardest problems when correct trajectories are rarely
sampled ([Chen et al., 2026a](#bib.bib1); [Li et al.,
2025b](#bib.bib36); [Chen et al., 2026b](#bib.bib2)). Prior work show
that supervised or off-policy expert guidance can complement
reinforcement learning on such questions  ([Ma et al., 2025](#bib.bib5);
[Zhang et al., 2025](#bib.bib9); [Yan et al., 2025](#bib.bib3)). Their
supervision, however, is supplied by stronger models or external expert
trajectories, which may be unavailable when training frontier reasoning
models. This motivates a self contained setting in which the model must
improve using only the problem and its reference solution.

Prior self improvement methods instead use reference solutions to
construct supervision. Offline methods condition generation on solutions
to synthesize rationales ([Zelikman et al., 2022](#bib.bib26); [Mendes
et al., 2026](#bib.bib29); [Zhang et al., 2026a](#bib.bib27); [Zhang et
al., 2026c](#bib.bib28)), while online privileged self distillation
methods construct a teacher with access to complete solutions for token
level supervision ([Zhao et al., 2026](#bib.bib7); [Jiang et al.,
2026](#bib.bib37)). In either case, reference conditioning gives the
same model the intended outcome, making trajectories that appears to
have a correct outcome easier to produce. Yet privileged teacher’s
outcome correctness does not imply student reachability. The teacher may
exploit the final answer and intermediate results to construct reasoning
actions that are unlikely or even illegal(e.g. referencing a
non-existing hint) under the unprivileged student. Its trajectory can
therefore be correct under privileged conditioning while remaining
unreachable or even malformed as a learning target. Directly imitating
the teacher will transfers such behavior to the student. Explicit answer
leakage, shortcut hacking, and post hoc rationalization are visible
consequences therefore.

![Refer to caption](2611.00796v1/plot1_icon_unified.png)

Figure 1: RLVR can extend the model’s ability in its comfort zone, but
it meets obstacles when coming to anxiety zone where correct
trajectories are hard to sample. Privileged-teacher can provide aid
signals on anxiety zone, but it can also select actions outside the
student’s reachable region, producing unlearnable traces. Directly
imitating these actions can corrupt the student’s reasoning
ability(e.g., learning to hallucinate a non-existent hint). By
projecting privileged preferences into the consensus region, SSR retains
the learnable steering signals within the privileged preferences,
effectively expands the student’s learning boundary.

We identify this correctness reachability mismatch as the central
obstacle to self improvement and propose Self-Steered Reasoner (SSR).
The core principle is to align the privileged teacher with what the
student can reach. At each decoding prefix, student-support projection
restricts the guided teacher to actions that remain plausible under the
unguided student, while preserving the teacher’s relative preferences
among those actions. The student defines the reachable action set, and
the teacher supplies a direction within it. The joint-decoding mechanism
drives the student into a more plausible trajectory. Verification
subsequently retains correct completed trajectories. This separation
turns a privileged solution from an imitation target into guidance for
searching the student’s reachable reasoning space.

To further boost the search efficiency, SSR places projected decoding
inside an iterative refinement framework. Each round constructs a
diagnostic steer from the current failed trajectory and the reference
solution. The steer records the error and an abstract corrective
direction while excluding the final answer and unseen numerical values.
Guided and unguided next-token distributions are then compared along the
failed trajectory, and their KL disagreement selects an informative
intervention frontier. SSR retains the preceding prefix and regenerates
only the suffix through projection. An incorrect continuation enters the
next round with a new diagnosis and intervention point.

Our experiments show that student support projection effectively reduces
hallucination on privileged information and general hindsight bias. The
complete SSR framework recovers verified correct trajectories for 147 of
the 197 problems where the plateaued Qwen3-8B model achieves
pass@64$`=0`$, or 74.6%, without parameter updates. Fine-tuning on the
resulting trajectories followed by resumed RL improves aggregate
accuracy by 4.9 percentage points on Qwen3-8B and 5.2 points on
Qwen3-4B-Instruct. Ablation experiments further shows that
student-support projection substantially reduces hindsight anchoring
effect and hint leakage. Our contributions are as follows.

- •
  We identify the correctness reachability mismatch in privileged self
  distillation and formulate reachability alignment as the key
  requirement for self constructed reasoning supervision.
- •
  We introduce student-support projection and instantiate it in SSR
  through diagnostic steering, divergence-guided intervention, projected
  continuation, verification, and iterative refinement.
- •
  We isolate the effect of projection under fixed guidance and show that
  the complete framework recovers verified trajectories for 74.6% of the
  empirically unsolved set, producing supervision that enables resumed
  RL to move beyond the parent plateau.

## 2 Method

We introduce Self-Steered Reasoner (SSR), a self distillation framework
for constructing supervision on problems where a plateaued reasoning
policy receives no positive RL signal. The core operation is student
support projection, which restricts a privileged teacher to reasoning
actions locally reachable under the unguided student. SSR places this
operator inside an iterative refinement procedure that diagnoses the
current failure, selects an informative intervention point, and
regenerates only the remaining suffix.

![Refer to caption](2611.00796v1/ssr_pipeline.png)

Figure 2: Overview of the SSR framework. 1. Given a very hard question
Q, we sample failed rollouts from the student model. The failed rollout
is then summarized and diagnosed against the reference solution to
produce a self-steer. The self-steer describes the error and provide
fixing directions while avoiding directly offering the answer. 2. The
self-steer is then used to construct the privileged self-teacher. The
KL-divergence between teacher and student is calculated on the failed
rollout to determine the proper intervention point. Everything after
that point is discarded. 3. After the intervention point, for every
decoding prefix, the student first calculate its support-set by
retaining every token with a student possibility above a certain
threshold $`\delta`$. The teacher then rewights these tokens and choose
the next token. For each new trajectory generated, it will be stored for
further training if correct, and send back to a new round of refinement
if incorrect. After the iterative refinement succeeds, the saved
positive trajectory can be used to improve the student model.

### 2.1 Post-Plateau Self-Improvement

Let $`p_{\theta_{0}}`$ denote a reasoning policy after RL training has
reached a performance plateau. Each verifiable problem $`x`$ is paired
with a reference solution $`g_{x}`$, and $`R(x,y)\in\{0,1\}`$ evaluates
whether a generated trajectory $`y`$ is correct. We define the
empirically unsolved set under a rollout budget $`K`$ as

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\mathcal{H}_{\theta_{0}}^{K}=\left\{x\;\middle|\;\max_{1\leq k\leq K}R(x,y_{k})=0,\quad y_{k}\sim p_{\theta_{0}}(\cdot\mid x)\right\}.
``` |  | (1) |

These problems provide no positive reward under the specified sampling
budget. Our goal is to construct verified trajectories for them using
the frozen policy and their reference solutions. Conditioning the policy
on $`g_{x}`$ creates a privileged self-teacher that can produce correct
trajectories more readily. The additional context can also shift
probability toward actions that are locally implausible under the
unprivileged policy. We seek trajectories that combine verified
correctness with local student reachability.

### 2.2 Student-Support Projection

Let $`s`$ denote the problem and the reasoning prefix generated so far.
We define the student’s local action set using a probability floor
$`\delta`$

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{V}_{\theta_{0},\delta}(s)=\left\{v\;\middle|\;p_{\theta_{0}}(v\mid s)>\delta\right\}.
``` |  | (2) |

Throughout the paper, student support refers to this thresholded local
set.

Let $`q_{d}(v\mid s)`$ denote the next-token distribution of the same
frozen model when additionally conditioned on a filtered diagnostic
steer $`d`$. Direct sampling from $`q_{d}`$ retains its corrective
preferences together with actions that may lie outside the student’s
local support. We define student-support projection as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Pi_{\theta_{0},\delta}[q_{d}](v\mid s)=\frac{q_{d}(v\mid s)\mathbf{1}\left[p_{\theta_{0}}(v\mid s)>\delta\right]}{\sum_{u}q_{d}(u\mid s)\mathbf{1}\left[p_{\theta_{0}}(u\mid s)>\delta\right]}.
``` |  | (3) |

The student determines the admissible action set, while the guided
teacher preserves its relative preferences among the remaining actions.
We apply
 equation [3](#S2.E3 "In 2.2 Student-Support Projection ‣ 2 Method ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation")
autoregressively and use $`\delta=0.02`$ in all experiments. The choice
of this hyperparameter is presented in the appendix.

#### Projection interpretation.

For any prefix where the denominator in
 equation [3](#S2.E3 "In 2.2 Student-Support Projection ‣ 2 Method ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation")
is nonzero, the projected distribution is the KL projection of $`q_{d}`$
onto distributions supported by $`\mathcal{V}_{\theta_{0},\delta}(s)`$

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Pi_{\theta_{0},\delta}[q_{d}](\cdot\mid s)=\arg\min_{r:\operatorname{supp}(r)\subseteq\mathcal{V}_{\theta_{0},\delta}(s)}D_{\mathrm{KL}}\left(r(\cdot\mid s)\middle\|q_{d}(\cdot\mid s)\right).
``` |  | (4) |

The proof is given in
Appendix [A](#A1 "Appendix A Student-Support Projection as a Constrained KL Projection ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation").
Projection enforces local reachability, and the verifier evaluates
sequence-level correctness.

### 2.3 Iterative Projected Refinement

A projected decoder still needs a correction direction and an
intervention point. One correction can also expose an error that was
hidden by the original failure. SSR therefore applies student-support
projection through iterative refinement. Each round constructs a
diagnostic steer, selects an intervention point from guided and unguided
disagreement, regenerates the suffix, and verifies the completed
trajectory.

#### Diagnostic steer.

At round $`r`$, let $`\tau^{(r-1)}`$ be the current failed trajectory.
The frozen model first summarizes the trajectory into
$`\bar{\tau}^{(r-1)}`$ and then produces a raw steer from the problem,
the summary, and the reference solution. The steer identifies the
previous error and proposes an abstract corrective direction. We screen
the raw steer with an LLM judge implemented by the same frozen model.
Also, we search for the exact outcome answer string to ensure that the
final answer is never directly revealed. A steer that fails either check
is discarded. Only the retained steer $`d^{(r)}`$ is passed to the
continuation process. The prompts used for diagnosis and problem solving
are provided in
Appendix [B](#A2 "Appendix B Prompt Templates and Steer Validation ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation").

#### Divergence-guided intervention.

For each position $`t`$ in the current trajectory, we compare the guided
teacher and the unguided student at the same prefix

|  |  |  |  |
|----|----|----|----|
|  |
``` math
S_{r}(t)=D_{\mathrm{KL}}\left(q_{d^{(r)}}\left(\cdot\mid x,\tau_{\leq t}^{(r-1)}\right)\middle\|p_{\theta_{0}}\left(\cdot\mid x,\tau_{\leq t}^{(r-1)}\right)\right).
``` |  | (5) |

Large disagreement marks a prefix where the diagnostic steer strongly
changes the model’s next action. We rank all positions by $`S_{r}(t)`$
and sample the intervention point uniformly from the ten highest-scoring
positions. The prefix through the selected point is retained.

#### Projected continuation and verification.

Starting from the selected intervention point, every continuation token
is sampled from
 equation [3](#S2.E3 "In 2.2 Student-Support Projection ‣ 2 Method ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation").
The guided teacher redirects probability within the student’s local
action set, and the retained prefix preserves reasoning already present
in the failed trajectory. If masking leaves no teacher probability mass
at a decoding step, we sample that step from the unguided student and
resume projected decoding immediately afterward.

The verifier evaluates each completed continuation. Correct trajectories
are added to the self-constructed training set while incorrect
trajectory becomes the target of the next round. This process continues
until the trajectory is verified or the iteration budget is exhausted.
The verified trajectories are used for targeted supervised fine-tuning
of the plateau checkpoint. Reinforcement learning then resumes with the
original RL recipe.

### 2.4 Measuring Privileged Dependence

Following [Peng et al. (2026)](#bib.bib31), we evaluate privileged
dependence from three complementary perspectives. Lexical anchoring
measures explicit overlap between a generated trajectory and privileged
target content not already present in the question. Probabilistic
anchoring measures how much the trajectory increases the model
probability of directly reciting the reference solution, capturing
implicit dependence without literal copying. Average leakage counts
case-insensitive literal matches to predefined shortcut phrases. Lower
values indicate less privileged dependence for these metrics. Exact
definitions are provided in
Appendix [G](#A7 "Appendix G Measuring Privileged Dependence ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation"),
with the complete leakage pattern list and matching rules in
Appendix [G.1](#A7.SS1 "G.1 Regex-Based Average Leakage ‣ Appendix G Measuring Privileged Dependence ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation").

### 3.1 Setup

#### Models and plateau checkpoints.

We use Qwen3-8B ([Yang et al., 2025](#bib.bib34)) as the primary model
and Qwen3-4B-Instruct-2507 as a smaller instruction-tuned model. Both
models first undergo 100 steps of RLVR. We select the first checkpoint
after training reward and evaluation performance show no significant
improvement for 30 consecutive steps. Every post-plateau intervention
starts from the corresponding checkpoint. Training details are provided
in
Appendix [F.2](#A6.SS2 "F.2 Resumed Reinforcement Learning ‣ Appendix F Training Configuration ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation").

#### Hard sets.

We use Int-Hard ([Yang et al., 2026b](#bib.bib8)), a collection of
challenging problems sampled from widely used open-source datasets. For
each training problem, we sample 64 trajectories from the plateau
checkpoint and retain the problem when none is verified correct. This
yields 197 hard problems for Qwen3-8B and 628 for
Qwen3-4B-Instruct-2507. By construction, the corresponding checkpoint
has pass@64$`=0`$ on each set under the same sampling configuration.

#### Search protocol.

Each problem begins with an initial pool of 64 failed trajectories. SSR
starts 16 independent lineages by sampling 16 trajectories from this
pool. For each lineage, the selected failure is summarized and
diagnosed, one intervention point is sampled uniformly from the ten
positions with the largest guided-versus-unguided KL disagreement, and
one student-support projected continuation is generated from the
retained prefix. If the continuation remains incorrect, it becomes the
failed trajectory for the next round. We run at most four rounds, with
one successor per unresolved lineage and early termination after
verification. The complete procedure therefore uses at most 64 projected
continuations per problem.

#### Training data.

For methods that construct explicit trajectories, SFT uses four verified
traces for each problem covered by that method. If fewer than four
distinct positive traces are available, we sample from the available
positives with replacement. On the Qwen3-8B hard set, Answer-conditioned
generation, Hinted Decode, and DAIL provide four positive traces for all
197 problems, yielding 788 SFT examples per method. DASD is an
exception, where all generated trajectories fall into repetition, so we
randomly sampled 4 trajectories instead. SSR recovers positive traces
for 147 problems and contributes $`147\times 4=588`$ examples(for those
problems that less than 4 positive trajectories are constructed, their
positive trajectories are duplicated). These explicit-trajectory methods
use the same SFT and resumed-RL hyperparameters;
Appendix [F.1](#A6.SS1 "F.1 Supervised Fine-Tuning ‣ Appendix F Training Configuration ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation")
reports the SFT configuration.

#### Baselines.

We compare SSR with five post-plateau baselines and continued RLVR.
Answer-conditioned generation places the reference solution in the
generation context. Hinted Decode ([Zhang et al., 2026a](#bib.bib27))
combines answer-conditioned generation with a distribution discriminant
at decoding time. DAIL ([Mendes et al., 2026](#bib.bib29)) performs
token-level distribution-aligned imitation. DASD ([Zhang et al.,
2026c](#bib.bib28)) selects teacher tokens according to student
confidence. OPSD ([Zhao et al., 2026](#bib.bib7)) uses an online
reference-conditioned self-teacher. Vanilla RLVR continues RL directly
from the plateau checkpoint. The offline baselines use their constructed
supervision for SFT followed by resumed RL, while OPSD follows its
online self-distillation objective without a separate SFT stage.

#### Evaluation.

We evaluate on AIME2025, AIME2026, and HMMT February 2026. For both
model sizes, per-benchmark accuracy is avg@8, computed from eight
samples per problem. Aggregate accuracy is the unweighted mean over the
three benchmarks, and aggregate Pass@8 uses the same sampling budget.
Table [3](#S3 "3 Experiments ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation")
reports the checkpoint with the highest aggregate accuracy for each
method. The reported $`\Delta`$ is measured against Vanilla RLVR under
the same selection protocol.

### 3.2 Breaking the RL Plateau

Table [3](#S3 "3 Experiments ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation")
reports peak post-plateau performance. On Qwen3-8B, SSR reaches 66.8
aggregate accuracy, improving over continued Vanilla RLVR by 4.9
percentage points. The gain appears on all three benchmarks. Pass@8 also
rises from 78.9 to 80.1, indicating broader problem coverage together
with more reliable correct reasoning across repeated samples.

Among the baselines, OPSD achieves the strongest peak at 64.1 aggregate
accuracy, although its performance declines quickly with continued
training. Answer-conditioned generation and Hinted Decode reach 62.0 and
62.8, respectively, while DAIL and DASD remain below the continued RLVR
reference. SSR therefore provides the largest peak improvement among the
evaluated post-plateau interventions.

The result also transfers to Qwen3-4B-Instruct-2507. SSR improves
aggregate accuracy from 52.2 to 57.4 and obtains the best result on
AIME2025, AIME2026, and HMMT February 2026. OPSD reaches 53.0, while the
other self-distillation baselines remain below Vanilla RLVR.

### 3.3 Controlled Effect of Student-Support Projection

We isolate student-support projection using the first-round instances
for all 197 Qwen3-8B hard problems. For each problem, the raw and
projected decoders receive the same 16 selected failures, trajectory
summaries, filtered steers, intervention points, and retained prefixes.
They differ only in the continuation distribution. Raw guided decoding
samples directly from the steer-conditioned teacher, while projected
decoding renormalizes that distribution over the unguided student’s
local support.

We report Mean@16, the average fraction of the 16 continuations per
problem that are verified correct, and Pass@16, the fraction of problems
with at least one verified continuation.
Table [3.3](#S3.SS3 "3.3 Controlled Effect of Student-Support Projection ‣ 3 Experiments ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation")
shows that raw guided decoding reaches 68.6% Mean@16 and 92.9% Pass@16.
Projected decoding reaches 5.7% Mean@16 and recovers 63 of the 197
problems, or 32.0%, in this single-round comparison. The support
constraint also sharply reduces privileged dependence. Lexical anchoring
falls from 76.46% to 41.97%, probabilistic anchoring from 10.94% to
4.25%, and average leakage from 25.44 to 0.02 matches per rollout.

On the 60 problems solved by both decoders, mean probabilistic anchoring
decreases from 8.41% to 5.58%, and the median decreases from 5.20% to
3.36%. Thus, even before iterative refinement, projection produces
verified positive trajectories with substantially lower privileged
dependence.

### 3.4 Iterative Refinement Extends Recovery

We next compare two ways to allocate 64 projected continuations per
problem. Full SSR follows 16 initial lineages for up to four refinement
rounds. The single-correction allocation instead applies one projected
correction to each of the 64 trajectories in the initial failure pool.

Figure [3](#S3.F3 "Figure 3 ‣ 3.5 Privileged Dependence of Constructed Trajectories ‣ 3 Experiments ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation")
shows that iterative recovery grows from 30.5% after the first round to
52.8%, 59.4%, and 74.6% after the next three rounds. The
single-correction allocation reaches 51.8% under the same budget.
Iterative refinement therefore recovers 147 problems, compared with 102
when every initial failure receives one correction. Direct sampling from
the plateau checkpoint solves none of the 197 problems in 64 rollouts
and one problem in 128 rollouts.

### 3.5 Privileged Dependence of Constructed Trajectories

We evaluate the 147 hard problems for which full SSR recovers at least
one verified trajectory. For each problem, every method contributes four
traces. For Answer-conditioned generation, Hinted Decode, DAIL, and SSR,
these are the verified positive traces used for SFT. When SSR yields
fewer than four distinct positives, we sample its available verified
traces with replacement. For DASD, we select four generated outputs at
random and report only leakage because the outputs are incomplete for
trajectory-level anchoring. Each method therefore contributes 588
outputs to the analysis.

SSR records the lowest value on all three metrics. Lexical anchoring is

fewer explicit shortcut traces and less latent dependence on the
privileged target.

### 3.6 Search Design Ablations

We keep student-support projected decoding and the 16-continuation
first-round protocol fixed while varying intervention placement,
guidance construction, and prefix retention. Uniform intervention
samples a trajectory position without using KL disagreement.
Masked-reference guidance replaces the diagnostic steer with the
reference solution after removing its final answer. Regenerate from
start discards the retained prefix and generates from the problem using
diagnostic guidance.

|  Condition |  Search design | Verified | Coverage |
|----|----|----|----|
|  Full design |  KL-guided intervention, diagnostic steer, retained prefix | 166 | 60 |
|  Uniform intervention |  Uniformly sampled intervention, diagnostic steer, retained prefix | 72 | 38 |
|  Masked-reference guidance |  KL-guided intervention, masked reference solution, retained prefix | 56 | 27 |
|  Regenerate from start |  Diagnostic steer with no retained trajectory prefix | 17 | 7 |

Table 4: Search-design ablations. All variants use student-support
projected decoding and 16 continuations per problem.

The full design produces 166 verified trajectories across 60 problems.
Uniform intervention reduces these figures to 72 trajectories across 38
problems. Masked-reference guidance reaches 27 problems, and
regeneration from the start reaches seven. KL disagreement therefore
identifies more productive intervention points, diagnostic guidance
supplies an error-specific correction, and prefix retention preserves
useful reasoning before the intervention.

## 4 Related Work

#### Interleaved supervised and reinforcement learning.

ReLIFT ([Ma et al., 2025](#bib.bib5)) and CHORD ([Zhang et al.,
2025](#bib.bib9)) show that supervised expert trajectories can
complement reinforcement learning on hard questions that the current
policy rarely solves through exploration alone. ReLIFT interleaves
targeted fine tuning with RL, while CHORD integrates off policy expert
supervision into on policy optimization. These works motivate our post
plateau SFT followed by resumed RL setting, but obtain their supervision
from stronger models or external experts. SSR addresses the
complementary data construction problem of producing such supervision
using only the plateaued student and reference solutions.

#### Online and offline self distillation.

Offline methods such as STaR ([Zelikman et al., 2022](#bib.bib26)),
DAIL ([Mendes et al., 2026](#bib.bib29)), Hinted Decode ([Zhang et al.,
2026a](#bib.bib27)), and DASD ([Zhang et al., 2026c](#bib.bib28))
construct or transform solution conditioned trajectories, while online
methods including OPSD ([Zhao et al., 2026](#bib.bib7)) distill token
level signals from privileged teachers during training. Although these
methods improve trajectory quality or teacher student alignment, the
teacher still observes the intended solution or privileged feedback.
They therefore remain vulnerable to shortcut hacking, including explicit
answer leakage and implicit post hoc rationalization through actions
that are individually plausible to the student. RLSD ([Yang et al.,
2026a](#bib.bib30)) resolve the problem by using the privileged signal
only for advantage curation, such approach make it unable to learn on
problems hard to sample. Structural skeleton-guided reasoning  ([Peng et
al., 2026](#bib.bib31)) studies the hacking behavior through lexical and
probabilistic anchoring. SSR instead restricts what privileged guidance
can contribute by converting it into diagnostic steering and projecting
the guided distribution onto the student’s local support before
retaining verified trajectories.

#### Guided exploration on hard problems.

POPE ([Qu et al., 2026](#bib.bib4)), ExPO ([Zhou et al.,
2025](#bib.bib32)), and NuRL ([Chen et al., 2026a](#bib.bib1)) use
privileged prefixes, self explanations, or hints to improve exploration
on problems that otherwise yield no positive reward. These approaches
are orthogonal to SSR. They alter the problem context to a simple form
from which the policy should explore, whereas SSR determines how to
construct verified and student reachable trajectories under a given
problem context. After a hint reduces the original task to a more
tractable subproblem, SSR can still diagnose and refine a failed
rollout. The two directions can therefore be composed rather than viewed
as competing alternatives.

## 5 Conclusion

We introduced Self-Steered Reasoner (SSR), a reachability aligned self
distillation framework for reasoning models at an RL plateau. Its
central insight is that privileged teacher correctness does not imply
student reachability. Rather than distilling the raw privileged
distribution, SSR projects teacher guidance onto the student’s local
support and verifies the resulting continuations. Diagnostic guidance,
KL guided intervention, and iterative refinement turn this projection
into a search process that progressively repairs hard reasoning
trajectories.

On the plateau hard set, SSR recovers verified trajectories for 74.6% of
problems that ordinary policy sampling fails to solve, before any
parameter update. The resulting data exhibits markedly lower privileged
dependence than competing self distillation methods and enables resumed
RL to move beyond the parent plateau. These results connect inference
time search and post training improvement through a common property. The
constructed supervision is not only correct, but also reachable by the
student.

The broader lesson is that privileged knowledge should steer reasoning
without dictating actions outside the student’s reasoning space.
Reachability alignment transforms reference solutions from answer aware
targets into directions the student can follow. By projecting the
teacher before distillation, SSR turns privileged knowledge into
supervision that the student can absorb and continue improving from.

## Appendix A Student-Support Projection as a Constrained KL Projection

At a fixed decoding prefix $`s`$, let $`\mathcal{V}`$ denote the token
vocabulary, $`p_{\theta_{0}}(\cdot\mid s)`$ the frozen student
distribution, and $`q_{d}(\cdot\mid s)`$ the steer-conditioned teacher
distribution. For a threshold $`\delta`$, define the local student
support

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{V}_{\theta_{0},\delta}(s)=\{v\in\mathcal{V}:p_{\theta_{0}}(v\mid s)>\delta\}.
``` |  | (6) |

Let $`\mathcal{Q}_{\theta_{0},\delta}(s)`$ denote the family of
probability distributions whose support is contained in
$`\mathcal{V}_{\theta_{0},\delta}(s)`$.

The teacher probability mass retained by the support constraint is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
Z_{d}(s)=\sum_{v\in\mathcal{V}_{\theta_{0},\delta}(s)}q_{d}(v\mid s).
``` |  | (7) |

When $`Z_{d}(s)>0`$, student-support projection renormalizes this mass
to obtain

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{q}_{d}(v\mid s)=\frac{q_{d}(v\mid s)\mathbf{1}[v\in\mathcal{V}_{\theta_{0},\delta}(s)]}{Z_{d}(s)}.
``` |  | (8) |

This projected distribution is the unique solution to

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{q}_{d}(\cdot\mid s)=\arg\min_{r\in\mathcal{Q}_{\theta_{0},\delta}(s)}D_{\mathrm{KL}}\left(r(\cdot\mid s)\,\middle\|\,q_{d}(\cdot\mid s)\right).
``` |  | (9) |

#### Proof.

Consider any $`r\in\mathcal{Q}_{\theta_{0},\delta}(s)`$ with finite
$`D_{\mathrm{KL}}(r\|q_{d})`$. On the support of $`r`$, we have
$`q_{d}(v\mid s)=Z_{d}(s)\widehat{q}_{d}(v\mid s)`$. Hence

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle D_{\mathrm{KL}}(r\|q_{d})`$ | $`\displaystyle=\sum_{v:r(v\mid s)>0}r(v\mid s)\log\frac{r(v\mid s)}{Z_{d}(s)\widehat{q}_{d}(v\mid s)}`$ |  |
|  |  | $`\displaystyle=D_{\mathrm{KL}}(r\|\widehat{q}_{d})-\log Z_{d}(s).`$ |  |

The KL term is nonnegative and vanishes exactly when
$`r=\widehat{q}_{d}`$. Since $`\widehat{q}_{d}`$ is feasible, it attains
the minimum value $`-\log Z_{d}(s)`$. Feasible distributions with
infinite divergence cannot improve this value, establishing uniqueness.

The projection preserves the teacher’s relative preferences among
admissible tokens while restricting each projected step to the student’s
local support. If $`Z_{d}(s)=0`$, the implementation samples one token
from the unguided student and resumes projection at the next prefix.
Completed trajectories are then evaluated by the verifier.

## Appendix C Additional Experimental Protocols

### C.1 SSR Trajectory Construction

For each hard problem, the plateau checkpoint provides an initial pool
of 64 failed trajectories. Round 1 randomly selects 16 of these 64
trajectories. Each selected trajectory is summarized and diagnosed
independently, and one intervention point is sampled from the ten
positions with the highest guided-versus-unguided KL disagreement. A
student-support projected continuation is then generated.

Rounds 2–4 preserve these trajectories as separate lineages. Each
unresolved lineage produces exactly one successor in the next round,
while a verified lineage terminates. Thus each initial Round-1
trajectory has at most one successor per later round, and the complete
search uses at most 64 projected continuations per problem.

### C.2 Student-Support Threshold Selection

We select the student-support threshold $`\delta`$ using a separate
diagnostic sweep on the 197 Qwen3-8B hard problems. This sweep uses
masked-reference guidance(using the reference solution with the final
answer value removed as the privileged information) and regenerates the
trajectory from the beginning. It is designed only to expose the
trade-off controlled by $`\delta`$ and does not use the full SSR search
procedure.

For each threshold, we generate one trajectory per problem. We evaluate
the degree of leakage with the same metrics in
sec. [G](#A7 "Appendix G Measuring Privileged Dependence ‣ Steer, Don’t Tell: Breaking ReasoningPlateaus with Reachability-AlignedSelf-Distillation")
and the passrate of these trajectories.

| $`\delta`$ | Verified correct $`\uparrow`$ | Prob. anchoring $`\downarrow`$ | Lex. anchoring $`\downarrow`$ | Avg. leakage $`\downarrow`$ |
|----|----|----|----|----|
| $`0.1`$ | $`6/197`$   $`(3.05\%)`$ | $`4.77\%`$ | $`59.56\%`$ | $`0.041`$ |
| $`\mathbf{0.02}`$ | $`31/197`$   $`(15.74\%)`$ | $`5.41\%`$ | $`62.69\%`$ | $`0.159`$ |
| $`0.01`$ | $`46/197`$   $`(23.35\%)`$ | $`6.06\%`$ | $`64.03\%`$ | $`0.328`$ |
| $`0.001`$ | $`119/197`$   $`(60.41\%)`$ | $`14.02\%`$ | $`71.33\%`$ | $`2.015`$ |

Table 5: Selection of the student-support threshold. The passrate,
degree of anchoring and leakage of different threshold values. Higher
verified correctness is better, while lower anchoring and leakage are
better.

Relaxing the support threshold increases the probability of sampling a
verified trajectory, but also increases privileged dependence. The
strict setting $`\delta=0.1`$ retains little leakage but verifies only
six problems. At the other extreme, $`\delta=0.001`$ verifies 119
problems, while probabilistic anchoring rises to $`14.02\%`$ and average
leakage exceeds two matches per trajectory. We select $`\delta=0.02`$ as
the intermediate operating point. It verifies 31 problems while keeping
probabilistic anchoring at $`5.41\%`$ and average leakage at $`0.159`$.
Lowering the threshold further to $`0.01`$ adds 15 verified problems,
but more than doubles average leakage and increases both anchoring
measures. We therefore use $`\delta=0.02`$ throughout the main
experiments.

### C.4 Iterative and Repeated Round-1 Search

Iterative refinement uses the 16 Round-1 trajectories as separate
lineages and applies one correction to each unresolved lineage in Rounds

trajectories in the initial failed pool. The two procedures therefore
use the same 64-continuation budget, with different allocation across
lineages.

### C.6 Search-Design Ablations

All ablations use student-support projected decoding and the Round-1
pass@16 budget. Uniform intervention replaces KL-guided placement with a
uniformly sampled trajectory position. Masked-reference guidance
replaces the diagnostic steer with a masked reference solution.
Regenerate-from-start discards the retained prefix and regenerates from
the beginning with diagnostic guidance.

The nominal budget is $`197\times 16=3152`$ trajectory samples per
condition. The effective number of valid rollouts may be smaller under
the evaluation protocol; the final ablation table reports the
corresponding effective count.

## Appendix D Additional Related Work

#### Partial reasoning and self-distillation.

TRSD ([Silvestri and Cetin, 2026](#bib.bib10)) distills teacher behavior
conditioned on truncated reasoning prefixes, targeting efficient
reasoning from partial chains. SSR instead constructs a new continuation
from a failed prefix and constrains every regenerated token to the
student’s local support.

#### Privileged and online self-distillation.

STV ([Wu and Raghunathan, 2026](#bib.bib11)), GATES, HDPO, TRACE, GEAR,
and related methods use privileged supervision, verification, or
selective distillation to improve reasoning trajectories ([Stein et al.,
2026](#bib.bib17); [Ding, 2026](#bib.bib18); [Wang et al.,
2026](#bib.bib20); [Li et al., 2026](#bib.bib21)). Their training
signals are built around teacher information or teacher-guided
selection. SSR uses the same model family to diagnose failures and
constructs the training trajectory under the student’s own local
support, while explicitly measuring and reducing privileged leakage.
AR-OPD ([Zhang, 2026](#bib.bib19)) is closely related in viewing
privileged targets through the lens of local compatibility, but
transfers a compatible residual rather than enforcing compatibility
during autoregressive generation. However, it still suffers from the
hacking patterns of the teachers.

#### Reasoning degradation and self-training.

Marco-o1 v2 ([Yin et al., 2025](#bib.bib15)) studies mismatched
reasoning patterns in distillation, while HSIR and self-training
analyses document failure modes such as data imbalance, overthinking,
and reward hacking  ([Zhong et al., 2026](#bib.bib12); [Shafayat et al.,
2025](#bib.bib14)). These works motivate scrutiny of self-generated
reasoning quality. SSR adds an explicit reachability constraint and
privileged-dependence measurement to trajectory construction.

#### Self-improvement beyond token-level trajectory imitation.

CODI ([Shen et al., 2025](#bib.bib24)) performs self-distillation in
continuous representations, START ([Li et al., 2025a](#bib.bib23)) uses
tools and rejection sampling, and influence-calibration and
feedback-alignment methods study how supervision should affect
self-training ([Lan et al., 2026](#bib.bib25); [Kara and Ersoy,
2026](#bib.bib22)). These directions target representation learning,
tool use, feedback alignment, or teacher influence rather than the
token-level construction of reachability-aligned positive trajectories.

#### Test-time training and hybrid SFT-RL.

TEMPO ([Zhang et al., 2026b](#bib.bib13)) studies test-time training
through alternating policy and critic refinement. ReLIFT, CHORD, and
LUFFY establish the value of hybrid or interleaved supervised learning
and RL  ([Ma et al., 2025](#bib.bib5); [Zhang et al., 2025](#bib.bib9);
[Yan et al., 2025](#bib.bib3)); SSR addresses the complementary
data-construction problem by supplying verified trajectories for
plateaued problems. POPE, ExPO, and NuRL provide hints or guided
exploration during RL  ([Qu et al., 2026](#bib.bib4); [Zhou et al.,
2025](#bib.bib32); [Chen et al., 2026a](#bib.bib1)). They are orthogonal
to SSR: once guidance reduces a hard problem to a solvable subproblem,
SSR can construct a reachability-aligned positive trajectory for that
subproblem.

#### Broader context.

TEMPO and related test-time training work study why self-training loops
stall, while surveys of reinforced reasoning provide a broader view of
RL-based post-training and self-improvement ([Xu et al.,
2025](#bib.bib16)). SSR focuses on the data-construction bottleneck at
the plateau, with compatibility enforced locally during decoding.

## Appendix G Measuring Privileged Dependence

We use the lexical and probabilistic anchoring measures of [Peng et al.
(2026)](#bib.bib31). Let $`Q`$ denote the problem, $`A`$ the privileged
target, and $`R`$ the generated reasoning trajectory. Lexical anchoring
measures IDF-weighted recall of target content not already present in
$`Q`$:

|     |                                                           |     |      |
|-----|-----------------------------------------------------------|-----|------|
|     |
       ``` math
       \mathcal{C}_{Q}(A)=\mathcal{C}(A)\setminus\mathcal{C}(Q),
       ```                                                        |     | (10) |

|  |  |  |  |
|----|----|----|----|
|  |
``` math
A_{\mathrm{lex}}(Q,A,R)=\frac{\sum_{w\in\mathcal{C}_{Q}(A)}\operatorname{idf}(w)\min\!\left(\operatorname{tf}_{R}(w),\operatorname{tf}_{A}(w)\right)}{\sum_{w\in\mathcal{C}_{Q}(A)}\operatorname{idf}(w)\operatorname{tf}_{A}(w)}.
``` |  | (11) |

We use the gold answer as $`A`$ for lexical anchoring.

For probabilistic anchoring, let

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\ell_{\theta}(A\mid C)=\frac{1}{|A|}\log_{2}p_{\theta}(A\mid C).
``` |  | (12) |

Following [Peng et al. (2026)](#bib.bib31),

|  |  |  |  |
|----|----|----|----|
|  |
``` math
A_{\mathrm{prob}}(Q,A,R)=\operatorname{clip}_{[0,1]}\left(\frac{\ell_{\theta}(A\mid Q,R)-\ell_{\theta}(A\mid Q)}{-\ell_{\theta}(A\mid Q)}\right).
``` |  | (13) |

Here $`A`$ is the unmasked reference solution. Both anchoring scores are
reported as percentages, with lower values indicating less privileged
dependence.
````
