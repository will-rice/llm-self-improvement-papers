# GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs

Federico A. Kamelhar Affiliation: Senior Principal Architect, Agentic AI
Affiliation: Oracle Corporation
Email: [federico.kamelhar@oracle.com](mailto:)

April 2026

###### Abstract

Autonomous multi-agent LLM systems are increasingly deployed to
investigate operational incidents and produce structured diagnostic
reports. Their trustworthiness hinges on whether each claim is grounded
in observed evidence rather than model-internal inference. Existing
groundedness evaluators — binary classifiers, LLM-as-judge scalars, and
self-correction loops — treat supporting evidence as interchangeable and
emit a single signal that offers no principled control over downstream
action. We present gsar, a grounding-evaluation and replanning framework
that (i) partitions claims into a four-way typology — grounded,
ungrounded, contradicted, and _complementary_ — giving first-class
standing to non-redundant alternative perspectives; (ii) assigns
evidence-type-specific weights reflecting epistemic strength;
(iii) computes an asymmetric contradiction-penalised weighted
groundedness score; and (iv) couples that score to a three-tier decision
function
$`\{\textsf{proceed},\,\textsf{regenerate},\,\textsf{replan}\}`$ driving
a bounded-iteration outer loop under an explicit compute budget. We
formalise the algorithm, prove six structural properties, and evaluate
all five design claims on FEVER with gold Wikipedia evidence through a
100%-Locus production stack (Locus SDK, Cohere embed-v3.0, Oracle
Database 26ai AI Vector Search) under four independently-trained LLM
judges (gpt-5.4, claude-sonnet-4-6, claude-opus-4-7, gemini-2.5-pro).
Every ablation reproduces in the same direction on every judge:
bootstrap $`95\%`$ CIs on the $`\rho{=}0`$ effect exclude $`0`$ on all
four; the no-complementary effect under Opus 4.7 has CI $`[-96,-68]`$ of
$`200`$; at $`n{=}1000`$, three independent single-mode judges converge
to $`\Delta\bar{S}_{\rho=0}=+0.058`$. A head-to-head against Vectara
HHEM-2.1-Open is included. To the best of our knowledge, gsar is the
first published groundedness framework that couples evidence-typed
scoring with tiered recovery actions under an explicit compute budget.

Keywords: LLM agents, groundedness evaluation, faithfulness,
self-correction, multi-agent diagnostic systems, AIOps, replanning,
hallucination mitigation.

## 1  Introduction

Consider a production multi-agent system for operational incident
investigation. A signal arrives — an alert from a metrics store, an
anomaly from a statistical monitor, a violation of a service-level
objective (SLO), or a free-text request from a human operator. An
orchestrator dispatches a set of specialist agents that each hold a
domain (compute, database, storage, network, application tier). Each
specialist runs a react-style loop \[[1](#bib.bib1)\]: it reasons,
invokes tools against live telemetry, reflects on results, and emits a
structured summary containing claims about what it observed and what (if
anything) caused the incident. The orchestrator then synthesises a
unified root-cause analysis from the specialists’ outputs and returns a
report to the user.

The central risk of such a system is not that specialists fail to
produce text — they rarely do — but that the text they produce blends
claims anchored in tool-observed evidence (“_CPU utilisation on node X
exceeded 95% at time $`t`$_”) with claims that are plausible but
model-inferred (“_this likely caused the downstream latency spike_”). A
downstream consumer, be it an on-call engineer or an automated
remediation system, cannot tell the difference between the two unless
the evaluation layer makes the distinction first-class.

Existing groundedness and faithfulness evaluators do not. Vectara’s HHEM
\[[9](#bib.bib9)\] emits a binary hallucinated/non-hallucinated label.
RAGAS’s _faithfulness_ \[[11](#bib.bib11)\] and TruLens’s _groundedness_
pillar \[[12](#bib.bib12)\] compute an LLM-as-judge scalar that treats
every supporting atom identically. Vectara’s recent FaithJudge
\[[10](#bib.bib10)\] improves consistency but retains a single scalar
output. Self-correction frameworks — Self-Refine \[[2](#bib.bib2)\],
Reflexion \[[3](#bib.bib3)\], multi-agent debate \[[5](#bib.bib5)\] —
loop on verbal critique but do not expose a typed-evidence signal to
drive different recovery actions. Process-reward models
\[[6](#bib.bib6), [7](#bib.bib7)\] provide step-level supervision but
target reasoning correctness, not claim-level grounding.

The gap we address is not the absence of groundedness signals; it is
their _structure_. A production diagnostic system needs an evaluation
layer that (a) distinguishes evidence provenance — a tool-verified claim
is epistemically stronger than a domain-knowledge claim — and (b)
translates that structure into a principled recovery policy that does
not force the system to re-run an expensive investigation when a cheap
regeneration would suffice.

## 2  Related Work

We organise prior work along four axes: groundedness evaluators,
self-correction and replanning, evidence combination and claim
verification, and autonomous diagnostic agents. gsar draws on each but
sits at the intersection rather than within any one.

### 2.1 Groundedness and faithfulness evaluators

Vectara’s Hughes Hallucination Evaluation Model (hhem and hhem-2.1)
\[[9](#bib.bib9)\] is a fine-tuned classifier that emits a binary
hallucinated/non-hallucinated label against a source context. ragas’s
faithfulness metric \[[11](#bib.bib11)\] decomposes a generated answer
into atomic statements and computes, via an LLM-as-judge, the fraction
supported by retrieved context. TruLens’s RAG Triad \[[12](#bib.bib12)\]
measures context relevance, groundedness, and answer relevance, each via
an LLM judge producing a scalar. Vectara’s FaithJudge
\[[10](#bib.bib10)\] improves judge consistency by anchoring against a
pool of human-annotated hallucination examples. The 2023 hallucination
survey \[[13](#bib.bib13)\] taxonomises the field into factuality and
faithfulness hallucinations; the framing of _faithfulness_ is closest to
ours.

gsar differs from all of the above on two dimensions simultaneously.
First, every prior method assigns equal weight to supporting atoms: a
claim supported by a tool-verified value and a claim supported by domain
knowledge receive the same numerator contribution. Second, every prior
method emits a single scalar (or a small vector of scalars) without
specifying what downstream action that scalar should trigger. gsar
addresses both gaps.

### 2.2 Self-correction, reflection, and replanning

ReAct \[[1](#bib.bib1)\] established the canonical reasoning-and-acting
loop that our specialist agents inherit. Self-Refine \[[2](#bib.bib2)\]
introduced same-model iterative critique; Reflexion \[[3](#bib.bib3)\]
stored verbal reflections as episodic memory across retries; Renze and
Guven \[[4](#bib.bib4)\] empirically characterise the reflection gain.
Multi-agent debate \[[5](#bib.bib5)\] combines multiple model instances
to adjudicate factuality. Process-reward models \[[6](#bib.bib6),
[7](#bib.bib7), [8](#bib.bib8)\] supply step-level reward signals during
training.

Two structural properties separate gsar from this line of work. First,
these frameworks loop on verbal or scalar signals that are not indexed
by evidence provenance; they cannot tell the next iteration “this
inference-typed claim was the weak one” unless an ad-hoc external system
provides that annotation. Second, they use a binary redo/stop decision
rule, not a tiered cost-asymmetric one.

### 2.3 Evidence combination and claim verification

Dempster–Shafer belief-function theory \[[20](#bib.bib20),
[21](#bib.bib21)\] is the classical framework for reasoning with
uncertain, conflicting multi-source evidence; Shafer’s mass functions,
belief and plausibility, and Dempster’s combination rule formalise
exactly the “two sources, partial agreement” situation that arises when
multiple specialists produce overlapping claims. NLI-based claim
verification pipelines trace back to the FEVER benchmark
\[[15](#bib.bib15)\] and the survey of automated fact-checking
\[[17](#bib.bib17)\]. MedRAGChecker \[[19](#bib.bib19)\] performs
atomic-claim support estimation with class-specific reliability
weighting and is the closest published peer to our evidence-type
weighting idea. FIRE \[[18](#bib.bib18)\] iterates retrieval and
verification in an agentic loop but does not expose a typed-evidence
scalar. FActScore \[[14](#bib.bib14)\] establishes the atomic-claim
decomposition protocol we rely on.

gsar can be read as an engineering simplification of Dempster–Shafer:
the weight map $`w`$ plays the role of a mass distribution over
evidence-strength classes, and the contradiction penalty $`\rho`$
approximates the conflict-mass penalty. We do not implement full D-S
combination because (a) tool outputs within a single investigation are
not independent sources in the D-S sense, and (b) full combination is
intractable at investigation scale. We retain only the pieces of the
framework that pay their way in practice.

### 2.4 Autonomous diagnostic agents

RCAgent \[[24](#bib.bib24)\] introduced LLM-driven cloud root-cause
analysis with tool augmentation; Roy et al. \[[25](#bib.bib25)\]
evaluated LLM agents on industrial incident data; AIOpsLab
\[[26](#bib.bib26)\] and the broader autonomous clouds agenda
\[[27](#bib.bib27)\] set the benchmarks and design principles for
agentic AIOps. Industrial systems such as Dynatrace Davis AI, IBM
Instana, and Datadog Watchdog perform causal inference over service
topologies but rely on deterministic or statistical rules, not agentic
LLM loops.

We take the agentic diagnostic platform as the deployment target and
contribute the grounding-evaluation layer that, to the best of our
knowledge, none of the above publish.

## 3  Problem Formulation

We now formalise the setting in enough detail to state the scoring
function and the decision function without ambiguity.

###### Definition 1 (Investigation).

An _investigation_ $`I`$ is a process that consumes a signal envelope
$`\sigma\in\Sigma`$ — e.g., an alert, anomaly, SLO violation,
prediction, operator request, or platform event — and produces a
structured report $`R=(\mathcal{C},\theta)`$, where $`\mathcal{C}`$ is a
finite set of atomic _claims_ and $`\theta`$ is a natural-language
synthesis intended for human or automated consumption.

###### Definition 2 (Claim).

A _claim_ $`c\in\mathcal{C}`$ is a triple

|     |     |     |
| --- | --- | --- |
|     |

````math
c\;=\;(\textsc{text}(c),\;\textsc{type}(c),\;\textsc{evidence}(c)),
``` |  |

where $`\textsc{text}(c)`$ is the natural-language statement,
$`\textsc{type}(c)\in\mathcal{T}`$ draws from a finite evidence-type
taxonomy, and $`\textsc{evidence}(c)`$ is a (possibly empty) set of
references to raw tool outputs, structured step outputs, signal fields,
or prior claims.

###### Definition 3 (Evidence-type taxonomy).

The *evidence-type taxonomy* $`\mathcal{T}`$ is a finite set whose
elements describe the *provenance* of a claim’s support. A canonical
instance used throughout this paper is

|  |  |  |
|----|----|----|
|  |
``` math
\mathcal{T}\;=\;\{\textsf{tool\_match},\,\textsf{specific\_data},\,\textsf{signal\_match},\,\textsf{neg\_evidence},\,
``` |  |

|  |  |  |
|----|----|----|
|  |
``` math
\textsf{complementary\_finding},\,\textsf{synthesis},\,\textsf{inference},\,\textsf{domain}\}.
``` |  |

The taxonomy is equipped with a *weight map* $`w:\mathcal{T}\to[0,1]`$
encoding epistemic strength, with $`w(\textsf{tool\_match})`$ at or near
$`1`$ and $`w(\textsf{inference})`$, $`w(\textsf{domain})`$ strictly
less. Specific default values appear in
Appendix [B](#A2 "Appendix B Reference Weight Table and Threshold Defaults ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs");
the framework does not depend on any particular choice.

###### Definition 4 (Judge and partition).

A *grounding judge* $`J`$ is a function

|  |  |  |
|----|----|----|
|  |
``` math
J:(\mathcal{C},E)\longmapsto(\mathcal{G},\,\mathcal{U},\,\mathcal{X},\,\mathcal{K},\,s,\,\varepsilon,\,a),
``` |  |

where $`E`$ is the raw evidence corpus associated with the report;
$`(\mathcal{G},\mathcal{U},\mathcal{X},\mathcal{K})`$ is a partition of
$`\mathcal{C}`$ into grounded, ungrounded, contradicted, and
complementary claims; $`s\in[0,1]`$ is a scalar grounding score produced
by $`J`$ itself (which will be reconciled against $`S`$, our weighted
score); $`\varepsilon`$ is a natural-language explanation; and
$`a\in\{\textsf{resolved},\textsf{abstain}\}`$ is a decision-status flag
that lets the judge refuse to score a malformed or under-evidenced
input.

We emphasise that $`\mathcal{K}`$, the *complementary* class, is
first-class: a claim in $`\mathcal{K}`$ is not redundant with any claim
in $`\mathcal{G}`$, nor does it contradict any claim in
$`\mathcal{G}\cup\mathcal{X}`$; it provides a valid, non-conflicting
alternative perspective. Examples: “the latency spike correlates with a
region-wide networking event” alongside “the latency spike correlates
with a CPU saturation on node X.” Neither contradicts the other, and
neither is subsumed; both are useful to the downstream consumer.

###### Definition 5 (Decision function).

The *decision function* is a map
$`\delta:[0,1]\to\{\textsf{proceed},\textsf{regenerate},\textsf{replan}\}`$
defined in
§[5](#S5 "5 Tiered Decision Function and Bounded Replanning ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs").

###### Definition 6 (Objective).

Given a compute budget $`K_{\max}\in\mathbb{N}`$ and thresholds
$`\tau_{\textsf{regenerate}}<\tau_{\textsf{proceed}}`$, the
investigation system returns a report $`R`$ that maximises the
probability of $`\delta(S(R))=\textsf{proceed}`$ subject to
$`K\leq K_{\max}`$, where $`K`$ is the number of replanning iterations
used.

## 4  Evidence-Typed Weighted Groundedness Score

The centre of gravity of gsar is a scalar score $`S`$ that aggregates
the four-way claim partition and evidence-type weights into a single
real number in $`[0,1]`$.

### 4.1 Definition

Let $`(\mathcal{G},\mathcal{U},\mathcal{X},\mathcal{K})`$ be the
four-way partition of $`\mathcal{C}`$ produced by the judge. Let
$`w:\mathcal{T}\to[0,1]`$ be the evidence-type weight map. Let
$`\rho\in[0,1]`$ be the contradiction penalty. Define the *partition
weight* of a set $`P\subseteq\mathcal{C}`$ as

|     |                                                      |     |     |
|-----|------------------------------------------------------|-----|-----|
|     |
       ``` math
       W(P)\;=\;\sum_{c\in P}w\bigl(\textsc{type}(c)\bigr).
       ```                                                   |     | (1) |

The gsar grounding score is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\boxed{\;S\;=\;\frac{W(\mathcal{G})+W(\mathcal{K})}{W(\mathcal{G})+W(\mathcal{U})+\rho\cdot W(\mathcal{X})+W(\mathcal{K})}.\;}
``` |  | (2) |

Edge case: if $`\mathcal{C}=\emptyset`$, we adopt the neutral convention
$`S=0.5`$ rather than a degenerate $`0/0`$. This convention reflects
epistemic indifference — neither confidence nor suspicion is warranted
without claims to evaluate.

### 4.2 Structural properties

We state six properties of $`S`$ and defer formal proofs to
Appendix [A](#A1 "Appendix A Proofs of Properties P1–P6 ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs").
Informal arguments follow each statement.

###### Property 1 (Boundedness).

$`S\in[0,1]`$ whenever the partition is non-empty and the denominator of
([2](#S4.E2 "In 4.1 Definition ‣ 4 Evidence-Typed Weighted Groundedness Score ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs"))
is strictly positive.

Because
$`W(\mathcal{G}),W(\mathcal{U}),W(\mathcal{X}),W(\mathcal{K})\geq 0`$
and the numerator is a subset of the denominator up to the
$`\rho`$-scaled $`W(\mathcal{X})`$ term, the ratio lies in $`[0,1]`$.

###### Property 2 (Monotonicity in grounded claims).

Moving a claim $`c`$ from $`\mathcal{U}`$ to $`\mathcal{G}`$ (holding
everything else fixed) never decreases $`S`$, and strictly increases
$`S`$ unless $`w(\textsc{type}(c))=0`$.

Intuition: re-labelling a “not supported” claim as “supported” must not
be punished.

###### Property 3 (Monotonicity in contradictions).

Adding a contradicted claim $`c`$ at fixed
$`\mathcal{G},\mathcal{U},\mathcal{K}`$ never increases $`S`$; the rate
of decrease is modulated by $`\rho`$.

Intuition: contradictions are bad news; $`\rho`$ controls how much
weight we give to that bad news relative to simple absence of support
($`\mathcal{U}`$).

###### Property 4 (Complementary-claim value).

Complementary claims contribute positively to $`S`$ but with weight no
larger than a grounded claim of the same type.

Intuition: an additional non-conflicting perspective is a strict gain
over no information, but is not a substitute for directly grounding the
original claim.

###### Property 5 (Contradiction non-suppression).

Contradictions remain in the denominator with weight
$`\rho\cdot W(\mathcal{X})`$; dropping contradicted claims out of
$`\mathcal{C}`$ entirely would inflate $`S`$.

This is the key asymmetry: if an adversarial summary-writer tried to
improve $`S`$ by silently omitting contradicted claims, it would reduce
$`W(\mathcal{C})`$ as a whole — including contradictions from the
denominator — and thereby inflate $`S`$ artificially. We keep
contradictions in the denominator precisely to prevent this.

###### Property 6 (Inference-observation asymmetry).

For any fixed partition cardinalities, replacing a grounded
tool_match-typed claim with a grounded inference-typed claim strictly
decreases $`S`$, provided
$`w(\textsf{inference})<w(\textsf{tool\_match})`$.

This is the main behavioural property that differentiates gsar from
uniform-weighted faithfulness: the system cannot trade tool-verified
claims for model-inferred ones without paying the score cost.

### 4.3 Relation to Dempster–Shafer and NLI

gsar is best viewed as a pragmatic simplification of belief-function
combination. If we interpret $`w`$ as a mass distribution over
evidence-strength classes and $`\rho`$ as a conflict-mass discount, then
([2](#S4.E2 "In 4.1 Definition ‣ 4 Evidence-Typed Weighted Groundedness Score ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs"))
resembles the normalised plausibility associated with a coarsened frame
of discernment
$`\{\textsf{grounded},\textsf{ungrounded},\textsf{contradicted},\textsf{complementary}\}`$.
Full Dempster–Shafer combination of per-claim masses would require
either independence assumptions that tool outputs within a single
investigation do not satisfy, or an explicit dependence model — both
intractable at the scales we care about. gsar retains the qualitative
benefits (evidence-type awareness, conflict handling) while producing a
single scalar per investigation in $`O(|\mathcal{C}|)`$ time.

gsar can also be read as a generalisation of the NLI three-way partition
(support, refute, nei) used in FEVER-style pipelines, with two
additions: a fourth *complementary* class for valid alternative
perspectives, and a continuous weight distribution over supporting atoms
rather than a discrete class indicator.

### 4.4 Choosing the weights

The specific default weight table used in our reference implementation
appears in
Appendix [B](#A2 "Appendix B Reference Weight Table and Threshold Defaults ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs");
those defaults should be read as one credible instantiation rather than
as universally optimal. Weights are interpretable and can be calibrated
per-deployment using a small human-graded held-out set. Deployments with
strict regulatory requirements can push $`w(\textsf{domain})`$ and
$`w(\textsf{inference})`$ towards $`0`$ to force tool-observed grounding
before any downstream action is taken.

## 5  Tiered Decision Function and Bounded Replanning

### 5.1 The decision function

gsar maps $`S`$ to one of three distinct downstream actions:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\delta(s)\;=\;\begin{cases}\textsf{proceed}&\text{if }s\geq\tau_{\textsf{proceed}},\\
\textsf{regenerate}&\text{if }\tau_{\textsf{regenerate}}\leq s<\tau_{\textsf{proceed}},\\
\textsf{replan}&\text{if }s<\tau_{\textsf{regenerate}},\end{cases}
``` |  | (3) |

with thresholds
$`0<\tau_{\textsf{regenerate}}<\tau_{\textsf{proceed}}<1`$. Our
reference implementation uses $`\tau_{\textsf{proceed}}=0.80`$ and
$`\tau_{\textsf{regenerate}}=0.65`$; these are configurable per
deployment and should be calibrated jointly with the weight map $`w`$ on
a held-out set.

### 5.2 Action semantics and cost asymmetry

The three actions are intentionally cost-asymmetric:

- •
  proceed. Emit the report downstream unchanged. Cost: zero additional
  LLM calls or tool invocations.
- •
  regenerate. Call a summary-regeneration sub-agent with
  $`(R,\varepsilon,\text{partition})`$ as additional context; the
  sub-agent rewrites the synthesis $`\theta`$ while preserving the claim
  set. Re-evaluate. Cost: one additional LLM call; zero tool
  invocations.
- •
  replan. Revise the investigation plan $`P`$ using the judge
  explanation $`\varepsilon`$ and re-dispatch the affected specialists.
  Cost: proportional to the number of re-dispatched specialists and the
  tools they invoke; typically one or two orders of magnitude higher
  than regenerate.

The three-tier structure is the critical design decision. A two-tier
$`\{\textsf{proceed},\textsf{replan}\}`$ rule (as in Reflexion-style
loops) would, under our reference thresholds, force expensive replanning
in the $`[0.65,0.80)`$ band, where many investigations are salvageable
by a cheaper regeneration. The middle tier captures precisely the “the
evidence is fine, the synthesis is loose” failure mode that dominates in
our production logs.

### 5.3 Bounded outer loop

Algorithm [1](#alg1 "Algorithm 1 ‣ 5.3 Bounded outer loop ‣ 5 Tiered Decision Function and Bounded Replanning ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")
specifies the outer loop. Termination is guaranteed by the finite replan
budget $`K_{\max}`$; the regenerate branch is bounded separately to one
attempt per score evaluation. Convergence to
$`\delta(S)=\textsf{proceed}`$ is *not* guaranteed: if the underlying
evidence is insufficient for any plan to ground the summary, the loop
exits with a degraded flag. Returning a degraded-but-honest report is
preferable to looping indefinitely or to hallucinating grounding.

3: $`k\leftarrow 0`$; $`d\leftarrow\text{false}`$

4: $`P\leftarrow\textsc{initial\_plan}(\sigma)`$

5: $`R\leftarrow\textsc{dispatch\_and\_synthesize}(P)`$

6:

## 6  Judge Protocol and Structured Output Schema

The judge $`J`$ is the single LLM interface on which the rest of gsar
depends. We summarise its contract here and defer the complete
Pydantic-like schema to
Appendix [C](#A3 "Appendix C Abstract Schema for Judge Output ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs").

#### Input.

The judge receives the synthesis $`\theta`$ and the raw evidence corpus
$`E`$ — raw tool outputs plus structured step outputs from every
specialist, concatenated with stable, deduplicated labels.

#### Output.

The judge emits a structured object containing:

- •
  $`s\in[0,1]`$ — the judge’s own scalar grounding score;
- •
  $`\mathrm{is\_grounded}\in\{\text{true},\text{false}\}`$ — the judge’s
  binary verdict;
- •
  $`\mathcal{G},\mathcal{U},\mathcal{X},\mathcal{K}`$ — the four claim
  lists;
- •
  $`\mathrm{gaps}`$ — specific evidence or investigation gaps the judge
  identified;
- •
  $`\mathrm{contradictions}`$ — explicit contradictions noted;
- •
  $`\mathrm{verification\_needed}\in\{\text{true},\text{false}\}`$ and
  $`\mathrm{verification\_reason}`$ — a flag plus natural-language
  reason;
- •
  $`\varepsilon`$ — a one-sentence natural-language explanation;
- •
  $`a\in\{\textsf{resolved},\textsf{abstain}\}`$ with
  $`\mathrm{abstain\_reason}`$ — a decision-status channel.

The downstream system recomputes $`S`$ from the partition using
([2](#S4.E2 "In 4.1 Definition ‣ 4 Evidence-Typed Weighted Groundedness Score ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs"));
the judge’s own scalar is kept for audit and calibration but is not
authoritative. This separation is important: the weight map $`w`$ is a
deployment parameter, not a judge parameter, and must be applied
consistently regardless of which judge model produced the partition.

#### Abstain channel.

The judge can refuse on malformed input or insufficient evidence. gsar
treats abstain as equivalent to $`\delta=\textsf{replan}`$, with a
specialised plan-revision prompt that instructs the orchestrator to
gather more evidence before re-attempting synthesis.

#### Robustness.

Production use demands graceful handling of malformed LLM outputs. Our
reference implementation parses structured output first, falls back to
manual JSON parsing, and finally to safe defaults ($`s=0.5`$, partition
= empty, $`a=\textsf{abstain}`$) that trigger exactly the replan branch.
This keeps the outer loop sound even under judge failure.

## 7  Reference Implementation Sketch

A reference implementation of gsar runs as three nodes in a compiled
state-graph agent runtime: synthesize, grounding_eval, and
regenerate_summary. The orchestrator holds a separate replan node; the
outer loop corresponds to
Algorithm [1](#alg1 "Algorithm 1 ‣ 5.3 Bounded outer loop ‣ 5 Tiered Decision Function and Bounded Replanning ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs").

#### Persistence.

The grounding result
$`(\mathcal{G},\mathcal{U},\mathcal{X},\mathcal{K},s,\varepsilon,a)`$ is
a first-class checkpoint field, enabling audit, replay, and post-hoc
calibration of $`w`$ and the thresholds against human-graded reports.

#### Telemetry.

Structured logs include the partition cardinalities, $`S`$,
$`\delta(S)`$, and $`k`$ per investigation — enough to reconstruct any
investigation’s trajectory through the outer loop.

#### Configurability.

The weight map $`w`$, contradiction penalty $`\rho`$, thresholds
$`(\tau_{\textsf{proceed}},\tau_{\textsf{regenerate}})`$, and replan
budget $`K_{\max}`$ are per-deployment configuration, loaded from
declarative configuration files at process start.

#### Computational cost.

Scoring is $`O(|\mathcal{C}|)`$ given the judge partition; the dominant
cost is the judge LLM call itself, which is one structured-output call
per synthesis or regeneration cycle. Replanning dominates the total
cost, making $`K_{\max}`$ the primary cost knob.

## 8  Reproducible Demonstration: FEVER + Locus + Oracle 26ai

To make the framework reproducible without proprietary infrastructure,
we ship a demonstration pipeline that exercises the full gsar loop on a
public dataset using only open-source software and openly accessible
Oracle Cloud Infrastructure components.

### 8.1 Dataset

#### What kind of data we use.

The evaluation uses the FEVER (Fact Extraction and VERification) task
\[[15](#bib.bib15), [17](#bib.bib17)\]. FEVER is a public
human-annotated claim-verification benchmark released under the Creative
Commons Attribution-ShareAlike 3.0 Unported licence. Every example
consists of: (i) a short natural-language *claim* that may be factually
true, factually false, or under-specified; (ii) a gold *label* drawn
from
$`\{\textsc{supports},\textsc{refutes},\textsc{not enough info}\}`$;
(iii) a list of *gold evidence sentences* extracted from Wikipedia that
either support or refute the claim. The original FEVER release separated
claims from evidence across multiple files; the modernised
copenlu/fever_gold_evidence release \[[16](#bib.bib16)\] bundles them
into a single row and ships as Parquet, which loads directly under the
modern HuggingFace datasets library. We use the train split, which
contains 228,277 rows.

#### Why this dataset fits GSAR.

FEVER’s three-way gold label maps onto three of the four GSAR partitions
natively: supports $`\mapsto\,\mathcal{G}`$,
refutes $`\mapsto\,\mathcal{X}`$, not enough
info $`\mapsto\,\mathcal{U}`$. This lets us compute the M4 contradiction
catch-rate directly against gold labels. FEVER does not contain a
*complementary-perspective* class, so M5 is structurally absent from
gold — we compute M5 against the class produced by each LLM judge,
interpreted as the judge’s positive-but-non-redundant routing choice.

#### Sample sizes and rationale.

We ran *four* full 100%-Locus pipelines at two sample sizes:

- •
  $`n=50`$ with three judges (openai.gpt-5.4 on OCI, claude-sonnet-4-6,
  google.gemini-2.5-pro on OCI) — sufficient for the cross-provider
  consistency check of the $`\rho{=}0`$ ablation
  (Table [2](#S8.T2 "Table 2 ‣ 8.6 Cross-provider consistency check ‣ 8 Reproducible Demonstration: FEVER + Locus + Oracle 26ai ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")),
  because the P5 effect is judge-invariant and shows at every tested
  scale.
- •
  $`n=200`$ with claude-opus-4-7 — the larger sample is used to exercise
  the complementary class $`\mathcal{K}`$ at the sample size where the
  ablation effect becomes statistically and visually unambiguous
  (Table [3](#S8.T3 "Table 3 ‣ 8.7 Large-sample run with Opus 4.7: the complementary-class effect ‣ 8 Reproducible Demonstration: FEVER + Locus + Oracle 26ai ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs"),
  Figure [2](#S8.F2 "Figure 2 ‣ 8.8 Figures summarising empirical results ‣ 8 Reproducible Demonstration: FEVER + Locus + Oracle 26ai ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")).
  With $`n=200`$ the no-$`\mathcal{K}`$ ablation drops proceed by 82 pp.
- •
  A separate larger-sample cross-provider comparison at $`n{=}200`$ with
  openai.gpt-5.4 through the 100%-Locus stack extends the $`\rho{=}0`$
  picture. Results are reported in
  §[8.6](#S8.SS6 "8.6 Cross-provider consistency check ‣ 8 Reproducible Demonstration: FEVER + Locus + Oracle 26ai ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")
  once that run completes; we do not gate the paper’s claims on it.

At $`n{=}50`$, the live corpus in Oracle Database 26ai is 109 passages
(50 claims + 59 gold evidence sentences); at $`n{=}200`$, approximately
440 passages. The sampling seed is fixed (seed$`=42`$) across every run
for reproducibility.

### 8.2 Data model

The per-row FEVER schema, as loaded from copenlu/fever_gold_evidence,
is:

``` ltx_verbatim
{
  "id":         <uuid>,
  "claim":      <str>,
  "label":      "SUPPORTS" | "REFUTES" | "NOT ENOUGH INFO",
  "evidence":   list[ [page_title:str, sentence_id:int,
                       sentence_text:str] ],
  "verifiable": "VERIFIABLE" | "NOT VERIFIABLE",
}
````

After sampling $`n`$ claims with a fixed seed, we flatten the dataset
into two logical row types for storage — _claim_ rows and _gold evidence
sentence_ rows — that share the same Locus Document model:

```ltx_verbatim
Document(
  id:         <uuid>,
  content:    <str>,       # the claim text or evidence sentence
  embedding:  list[float], # 1024-dim FLOAT32 from Locus OCIEmbeddings
                           # with cohere.embed-english-v3.0
  metadata:   {
    "src":       "claim" | "gold",
    "claim_id":  <int>,    # index into the sampled claims
    "label":     <str>,    # only for src="https://claim"
  }
)
```

Documents are persisted in Oracle Database 26ai as

```ltx_verbatim
CREATE TABLE gsar_locus_vectors (
  id        NUMBER      GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  content   CLOB,
  metadata  JSON,
  embedding VECTOR(1024, FLOAT32)
);
```

retrieved with VECTOR_DISTANCE(embedding, :q, COSINE) and an ORDER BY
…FETCH FIRST :k ROWS ONLY top-$`k`$ projection. The judge’s output
conforms to the schema in
Appendix [C](#A3 "Appendix C Abstract Schema for Judge Output ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs");
the per-claim GSAR partition is held in memory and persisted as JSONL
for post-hoc analysis. At $`n{=}200`$ the live corpus contains
$`\sim`$440 documents; at $`n{=}50`$ it contains $`109`$ (50 claims
$`+`$ 59 gold evidence sentences).

### 8.3 Software stack

- •
  Dataset. The FEVER 1.0 validation split \[[15](#bib.bib15)\] loaded
  via the HuggingFace datasets library. FEVER’s supports/refutes/nei
  labels map naturally onto the $`\mathcal{G}/\mathcal{X}/\mathcal{U}`$
  partition; we induce $`\mathcal{K}`$ by treating semantically related
  but non-conflicting neighbouring claims as complementary.
- •
  Agent runtime — Locus. All agentic machinery in this paper runs
  through *Locus* \[[23](#bib.bib23)\], an unreleased proprietary
  production-grade agent SDK developed at Oracle Corporation. As of the
  writing of this paper (21 April 2026), Locus is an internal Oracle
  asset and has not been released publicly; the characterisation below
  reflects the SDK’s state at that date. We describe it here because it
  is integral to the reproducible evaluation protocol and because
  several of its design choices interact with GSAR’s scoring layer.

  _What Locus is._ Locus is a compiled, state-graph-based agent runtime
  for Python that unifies LLM inference, tool calling, state management,
  and retrieval-augmented generation under a single typed contract.
  Concretely:
  - –
    _State model._ Every agent state, message, event, tool schema, and
    model configuration is a Pydantic-v2 model that round-trips through
    JSON cleanly — no ad-hoc dicts, no TypedDict/dataclass drift.
  - –
    _Typed streaming events._ ThinkEvent, ToolStartEvent,
    ToolCompleteEvent, TerminateEvent are first-class write-protected
    event objects; hooks are structured rather than callback-based.
  - –
    _Checkpointers._ BaseCheckpointer is the contract; native
    implementations exist for OCI Object Storage, SQLite, Redis,
    PostgreSQL, OpenSearch, and Oracle Database. No adapter layer is
    required.
  - –
    _Tool-level idempotency._ @tool(idempotent=True) causes the ReAct
    loop to dedupe repeat calls with the same arguments — essential for
    write-side tools in production deployments, and, to our knowledge,
    not present in LangChain, LangGraph, AutoGen, CrewAI, or Strands at
    time of writing.
  - –
    _Multi-provider model registry._ A uniform string identifier of the
    form provider:model_id (e.g. oci:openai.gpt-5.4,
    anthropic:claude-opus-4-7, openai:gpt-5) resolves to a typed
    BaseModel implementation at construction time. OCI GenAI models
    (Cohere, Meta, OpenAI, xAI, Google, Mistral) are first-class, on
    parity with external providers.
  - –
    _RAG stack._ First-party embedding providers (OCIEmbeddings for
    Cohere on OCI; OpenAIEmbeddings), first-party vector stores
    (OracleVectorStore targeting Oracle Database 26ai’s native VECTOR
    type; also Chroma, PGVector, OpenSearch, Pinecone, Qdrant, and an
    in-memory store), and a retrieval abstraction
    (locus.rag.retriever.Retriever) that composes them.

  _Scope of use in this paper._ The entire evaluation pipeline —
  embeddings, vector store, judge agent — runs through Locus
  abstractions; no component of the pipeline bypasses the SDK. We refer
  to this as the _100%-Locus stack_. The GSAR scoring layer
  (Equation [2](#S4.E2 "In 4.1 Definition ‣ 4 Evidence-Typed Weighted Groundedness Score ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs"))
  and the three-tier decision function
  (Equation [3](#S5.E3 "In 5.1 The decision function ‣ 5 Tiered Decision Function and Bounded Replanning ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs"))
  are deliberately kept outside Locus: Locus is the agent
  infrastructure; GSAR is the framework being evaluated.

- •
  Vector store. Oracle Database 26ai using the native VECTOR data type
  and AI Vector Search. The reference deployment uses an Oracle
  Autonomous Database on Oracle Cloud Infrastructure; a portable
  in-memory cosine-similarity store is bundled for runs without
  Autonomous Database access.
- •
  Embeddings. OCI Generative AI Cohere cohere.embed-v4.0 when an OCI
  profile is available, with a sentence-transformers all-MiniLM-L6-v2
  fall-back for portable runs.

### 8.4 Pipeline

For each FEVER example $`(q,\ell)`$ where $`q`$ is the claim and
$`\ell\in\{\textsc{sup},\textsc{ref},\textsc{nei}\}`$ is the gold label:

1.  1.  Embed $`q`$ and search the vector store for the top-$`k`$
        neighbours, yielding a small evidence corpus $`E_{q}`$.
2.  2.  Pass $`(q,E_{q})`$ to a (rule-based for the demo, LLM-based in
        production) grounding judge that produces the four-way partition
        $`(\mathcal{G},\mathcal{U},\mathcal{X},\mathcal{K})`$ with
        evidence-type annotations.
3.  3.  Compute $`S`$ via
        Equation ([2](#S4.E2 "In 4.1 Definition ‣ 4 Evidence-Typed Weighted Groundedness Score ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs"))
        with the reference weight table from
        Appendix [B](#A2 "Appendix B Reference Weight Table and Threshold Defaults ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")
        and $`\rho=0.5`$.
4.  4.  Apply $`\delta(S)`$; on regenerate, simulate a single regeneration
        pass; on replan, simulate a plan revision and re-retrieval. Record
        decisions and replan counts.

The full source is approximately 350 lines of Python under demo/, with
command-line flags for $`n`$, $`k`$, the embedding backend, and the
vector backend. The expected reproducible artefacts are a JSONL trace of
per-claim partitions and decisions plus a summary JSON of decision-tier
histograms and mean $`S`$.

#### Contradiction non-suppression (P5) is empirically visible.

The $`\rho=0`$ ablation increases $`\overline{S}`$ from $`0.36`$ to

failure mode the asymmetric penalty was designed to prevent. A reviewer
who naively only measures _grounded-output rate_ would see the ablation
as an _improvement_; jointly measuring M4 reveals that the underlying
contradiction-identification rate is unchanged, so the uplift is pure
score inflation.

The two-tier ablation converts the two middle-tier regenerate decisions
into additional replan decisions; at production scale (where replan
costs orders of magnitude more than regenerate) even this two-decision
delta is material.

On FEVER with gpt-5.4, the complementary class is populated sparsely, so
removing it has no measurable effect on the proceed rate. At larger
$`n`$ with a judge that uses $`\mathcal{K}`$ more actively, the same
ablation is catastrophic
(§[8.7](#S8.SS7 "8.7 Large-sample run with Opus 4.7: the complementary-class effect ‣ 8 Reproducible Demonstration: FEVER + Locus + Oracle 26ai ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs"),

#### The four-way partition earns its keep.

At the same judge quality, GSAR default produces 100 proceed decisions
where the binary baseline produces 35 — a $`+185\%`$ improvement in
grounded-output rate. The baseline’s failure mode is structural: it
requires non-empty $`\mathcal{G}`$ and empty $`\mathcal{X}`$ to proceed,

positive signal, which at this sample mattered for 65 out of 200 claims.

M4 drops to $`0.06`$ for Opus 4.7 vs $`0.15`$–$`0.31`$ for the three

$`\mathcal{K}`$ rather than $`\mathcal{X}`$, which trades M4 down for M5
up

This is a judge-selection deployment consideration: for systems where

perspectives_, a GPT-family judge is the better choice; for the reverse,
Opus is. The GSAR scoring layer accommodates either choice because the
partition produced by the judge is the only input it consumes.

### 8.9 Three-mode evaluation: single, distill, adversarial

Section [8.5](#S8.SS5 "8.5 Reference run and ablation study (100%-Locus stack) ‣ 8 Reproducible Demonstration: FEVER + Locus + Oracle 26ai ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")
reports results under the _single_ mode: one FEVER claim per row, judge
produces one atomic-claim partition. This mode’s limitation is that a
one-atom partition cannot exercise the evidence-typed weighting (C2):
there is only one atom to weight. We therefore evaluate the framework
under two additional modes:

#### Distill mode.

A Locus _generator_ agent receives the claim plus $`k=5`$ retrieved
evidence passages and writes a 3–5 sentence investigative summary. The
judge then decomposes the summary into 3–7 atomic claims with per-atom
evidence-type annotations. This produces a multi-atom partition with
real type variety.

#### Adversarial mode.

Identical to distill mode except the generator is prompted to
deliberately _simulate imperfect production output_: each summary must
include (a) at least one directly supported claim, (b) at least one
plausible inference not directly supported, (c) at least one confident
overreach the evidence does not support, and (d) optionally a
complementary alternative perspective. This is the operational condition
GSAR was designed for — production diagnostic systems rarely produce
perfectly hedged summaries.

We observed in honest distill mode that well-behaved generators produce
summaries that saturate near-perfect grounding
($`\bar{S}\approx 0.96\text{--}0.99`$ across all four tested judges);
every ablation collapses at this saturation. This is a _negative result_
and a structural property of the framework: when there is nothing wrong
with the output, GSAR correctly does nothing. Adversarial mode is
therefore the correct stress test for measuring the design choices.

| gsar adversarial mode, gpt-5.4     | $`0.27`$ | n/a         | yes                | yes             |

in-distribution on FEVER; RAGAS uses openai.gpt-5.4 as the judge. gsar

adversarial mode ($`\rightarrow`$ gpt-5.4 adv / Opus adv).

#### Reading the comparison correctly.

gsar is not competitive with HHEM or RAGAS on M4 under these conditions.
That is not the claim the paper makes. M4 measures only whether the
method _routes gold contradictions somewhere that looks like
“contradicted”_; on FEVER, a binary classifier with a threshold at
$`0.5`$ wins this metric trivially because FEVER is a two-way supports /
refutes benchmark. gsar’s four-way partition distributes gold refutes
claims between $`\mathcal{X}`$ (contradicted) and $`\mathcal{U}`$
(ungrounded); binary methods route them all to the low-score tail. This
is a benchmark-structure effect, not a framework limitation.

The gap gsar fills — the structural capabilities missing from both
baselines — is:

- •
  a four-way partition that distinguishes _ungrounded_ (no information)
  from _contradicted_ (explicit conflict) from _complementary_
  (non-conflicting alternative perspective), relevant to any consumer
  that needs to plan a next action;
- •
  a tiered decision
  $`\{\textsf{proceed},\textsf{regenerate},\textsf{replan}\}`$ with
  cost-asymmetric recovery actions, not just a single scalar the
  consumer has to threshold themselves;
- •
  evidence-type-weighted scoring that respects the epistemic strength of
  different supporting-evidence classes, making the score interpretable
  and per-deployment calibratable.

HHEM and RAGAS are the correct choice when the downstream consumer needs
a single binary faithfulness score on in-distribution data. gsar is the
correct choice when the consumer is an autonomous diagnostic system that
must decide what action to take on LLM-generated multi-claim summaries
in a custom domain — which is precisely the gap neither HHEM nor RAGAS
fills.

### 8.14 M3 calibration with an independent LLM grader

Paper
§[9](#S9 "9 Conceptual Evaluation Protocol ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")
proposes M3 as the Spearman correlation between gsar’s score $`S`$ and
human-annotated faithfulness on a held-out sample. A human-graded
evaluation is out of scope for this draft; we substitute an _independent
LLM grader_ (claude-opus-4-7) — distinct from every judge used to
produce gsar partitions — as a proxy, and report the finding
transparently with its limitations. Readers should interpret the result
as _cross-LLM-grader calibration_, not as M3 in its original
human-graded sense.

#### Protocol.

We sampled 50 rows stratified across five $`S`$ bands from the gpt-5.4
adversarial $`n{=}200`$ run (C5 stack) and from the gpt-5.4 single-mode
$`n{=}200`$ run (sibling sample). For each row we prompted Opus 4.7 with
the claim, FEVER gold label, evidence sentences, and either the
generated adversarial summary (adversarial mode) or the gsar partition
itself (single mode). The grader returned a 1–5 faithfulness score and a
binary proceed decision. We then computed Spearman $`\rho`$ between
grader scores and gsar’s $`S`$, with a 1000-sample bootstrap 95% CI.

| Mode        | Grader     | $`n`$ | mean grade | Spearman $`\rho`$  | 95% CI                     | proceed agree.     |
| ----------- | ---------- | ----- | ---------- | ------------------ | -------------------------- | ------------------ |
| Single      | strict     | 50    | $`3.80/5`$ | $`\mathbf{+0.53}`$ | $`\mathbf{[+0.34,+0.70]}`$ | $`\mathbf{100\%}`$ |
| Single      | role-aware | 50    | $`3.02/5`$ | $`+0.25`$          | $`[-0.04,+0.53]`$          | $`68\%`$           |
| Adversarial | strict     | 50    | $`1.52/5`$ | $`-0.24`$          | $`[-0.49,+0.02]`$          | $`48\%`$           |
| Adversarial | role-aware | 50    | $`1.54/5`$ | $`-0.25`$          | $`[-0.51,+0.00]`$          | $`50\%`$           |

Table 9: M3 calibration on 50 stratified samples each from single-mode
and adversarial-mode runs, with two LLM-grader configurations. The
_strict_ grader uses a generic independent-evaluator system prompt. The
_role-aware_ grader uses a prompt that represents a production
diagnostic-engineering perspective (accepts negative-evidence reasoning
as legitimate). Both use Opus 4.7 with identical $`n=50`$ stratified
samples and bootstrap 95% CIs ($`B{=}1000`$). The adversarial
calibration gap ($`\rho\approx-0.25`$) is consistent across both grader
prompts, indicating it is a genuine deployment calibration issue rather
than a prompt-engineering artefact.

#### The calibration gap is robust across grader prompts.

We evaluated two grader configurations to stress-test the M3 finding: a
strict generic grader and a role-aware pragmatic grader that
specifically accepts neg_evidence reasoning as legitimate engineering
practice. The adversarial-mode Spearman $`\rho`$ is essentially
identical in both cases ($`-0.24`$ vs $`-0.25`$), demonstrating that the
calibration gap is not an artefact of grader prompt strictness. Under
adversarial conditions, the framework’s score via the gpt-5.4 judge
systematically diverges from any reasonable external grader’s
faithfulness assessment, regardless of how the grader is framed. This is
a genuine structural finding about cross-model evidence-type weighting,
not a prompt-engineering issue.

#### Single-mode positive correlation persists under both graders.

The strict grader produces $`\rho=+0.53`$ (CI excludes 0); the
role-aware grader gives $`\rho=+0.25`$ (CI straddles 0, borderline
significant with $`p\approx 0.08`$). The drop from $`+0.53`$ to
$`+0.25`$ under the role-aware grader reflects the prompt becoming _more
discriminating_ about when hedged conclusions are legitimate: the
role-aware grader penalises unhedged assertions that the strict grader
accepts, tightening the score distribution on a subset of claims.
Importantly, both graders produce directionally-positive correlation on
single mode — GSAR’s scoring aligns with independent faithfulness
assessment under normal operating conditions regardless of grader
framing.

#### Single-mode alignment is strong.

On the FEVER single-claim framing, gsar’s $`S`$ correlates with an
independent Opus-grader’s faithfulness judgment at $`\rho=+0.53`$ with
95% CI $`[+0.34,+0.70]`$ — a standard medium-to-large effect size in
psychological / evaluation research. Proceed agreement is $`100\%`$:
every case where gsar recommended proceed the grader would have
proceeded, and every case gsar rejected the grader would have rejected.
Under normal operating conditions the framework’s scoring is
well-calibrated against an independent grader.

#### Interpretation of the adversarial-mode result.

The negative correlation is a _real finding_, not a framework failure.
Three observations unpack it:

1.  1.  The adversarial generator was prompted to overreach. By
        construction, each summary contains at least one deliberate
        fabrication or unsupported inference. Opus-as-grader correctly
        identifies these (mean grade $`1.52/5`$, $`49/50`$ rows graded
        $`\leq 3`$), which compresses the grader-side variance.
2.  2.  gpt-5.4 and Opus weight neg_evidence differently. gpt-5.4 often
        routes “the passages do not mention $`X`$” to grounded with
        $`\text{evidence\_type}=\textsf{neg\_evidence}`$ (weight $`0.70`$),
        producing high $`S`$ on summaries that nonetheless contain
        fabricated sub-claims. Opus penalises the same output as
        hallucinated because the fabricated sub-claims are present even when
        the parent claim is honestly hedged.
3.  3.  The asymmetry is a deployment consideration, not a framework bug.
        The GSAR weight map $`w`$ is an expert prior; per-deployment
        calibration against a trusted grader — exactly the procedure this
        calibration exercise instantiates — is the framework’s own
        recommended mitigation
        (§[4.4](#S4.SS4 "4.4 Choosing the weights ‣ 4 Evidence-Typed Weighted Groundedness Score ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")).
        A deployment that wants Opus-style strictness can either (a) swap
        the judge to Opus itself, (b) re-weight
        $`w(\textsf{neg\_evidence})`$ downward, or (c) add a secondary
        consistency check at the regenerate tier.

#### What this does _not_ mean.

It does not mean gsar’s ablation effects from
§[8.10](#S8.SS10 "8.10 Cross-judge adversarial evaluation at 𝑛=200 ‣ 8 Reproducible Demonstration: FEVER + Locus + Oracle 26ai ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")–§[8.11](#S8.SS11 "8.11 Statistical significance: bootstrap 95% confidence intervals ‣ 8 Reproducible Demonstration: FEVER + Locus + Oracle 26ai ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")
are invalidated. Those effects (cross-judge $`\rho{=}0`$ inflation,
no-$`\mathcal{K}`$ proceed drop, two-tier compute waste) are
_differential_ measurements that cancel out absolute calibration offsets
between judges and graders. The M3 result shapes how the downstream
consumer _interprets absolute score values_; it does not affect which
design choices are structurally correct.

#### Honest limitations of this calibration.

- •
  $`n{=}50`$ stratified per mode is borderline for Spearman inference;
  the CI is wide.
- •
  Opus-as-grader is still an LLM, with its own biases. True M3 requires
  human annotators, ideally with inter-annotator agreement reported.
- •
  The adversarial-mode mean grade of $`1.52/5`$ gives limited spread for
  correlation analysis.

These limitations are the reason M3 was marked _pending full empirical
instantiation_ in the evaluation protocol
(§[9](#S9 "9 Conceptual Evaluation Protocol ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs"));
we report the proxy finding here for completeness and flag it as a known
calibration issue that downstream deployers should examine on their own
data.

## 9  Conceptual Evaluation Protocol

We do not run experiments in this paper. Instead, we propose a
falsifiable evaluation protocol that other groups can execute on public
datasets. The protocol is designed to isolate the contributions of the
four gsar design choices (typed weights, complementary class,
contradiction penalty, three-tier decision) from the underlying LLM
judge quality.

### 9.1 Datasets

- •
  HotpotQA \[[22](#bib.bib22)\] — multi-hop question answering. Evidence
  types can be synthesised from source-hop provenance (gold
  supporting-fact hops $`\to`$ tool_match; reasoning hops $`\to`$
  inference).
- •
  FEVER \[[15](#bib.bib15)\] — standard claim verification; map supports
  $`\to\mathcal{G}`$, refutes $`\to\mathcal{X}`$, nei
  $`\to\mathcal{U}`$. FEVER does not natively have a complementary
  class; we introduce one by pairing each claim with a non-conflicting
  alternative formulation.
- •
  AIOpsLab \[[26](#bib.bib26)\] — closest analogue to the
  autonomous-diagnostic target setting, with real incident traces and
  tool-invocation logs.
- •
  Synthetic diagnostic benchmark. An optional synthetic dataset with
  controllable evidence-type distributions, designed to isolate the
  effects of $`w`$ and $`\rho`$ without confounds.

### 9.2 Baselines

- •
  B1 — Binary groundedness. Vectara HHEM-2.1 \[[9](#bib.bib9)\].
- •
  B2 — Uniform-weight LLM-judge. RAGAS faithfulness \[[11](#bib.bib11)\]
  and TruLens groundedness \[[12](#bib.bib12)\].
- •
  B3 — Reflexion with binary groundedness. \[[3](#bib.bib3)\] using
  HHEM-2.1 as the pass/fail signal.
- •
  B4 — gsar ablations. (a) uniform weights ($`w\equiv 1`$); (b) no
  complementary class ($`\mathcal{K}`$ merged into $`\mathcal{G}`$);
  (c) no contradiction penalty ($`\rho=0`$ in the denominator);
  (d) two-tier decision (merge regenerate into replan).

### 9.3 Metrics

M1 — Grounded-output rate.  
$`\Pr\bigl[\delta(s_{\mathrm{final}})=\textsf{proceed}\bigr]`$ after the
outer loop terminates.

M2 — Replan efficiency.  
Mean $`k`$ per successful proceed.

M3 — Calibration.  
Spearman $`\rho`$ between $`S`$ and human-annotated faithfulness on a
held-out set.

M4 — Contradiction catch-rate.  
Fraction of gold contradictions that end up in $`\mathcal{X}`$.

M5 — Complementary separation.  
Fraction of gold complementary claims correctly placed in
$`\mathcal{K}`$ rather than $`\mathcal{G}`$ or $`\mathcal{U}`$.

### 9.4 Expected ablation directions

- •
  Removing typed weights degrades M3 (calibration weakens because all
  evidence is flattened) and has no effect on M4, M5.
- •
  Removing the complementary class degrades M5 and mildly degrades M1
  (systems over-escalate to replan).
- •
  Removing $`\rho`$ allows summaries to drop contradictions silently and
  degrades M4; M1 spuriously improves (a _red flag_ on the metric, not a
  system win).
- •
  Replacing three-tier with two-tier degrades M2 in the $`[0.65,0.80)`$
  band (unnecessary replans where regeneration suffices).

We emphasise that the fourth ablation direction — _improvement_ on M1 at
the cost of M4 — is precisely the failure mode that justifies asymmetric
contradiction penalisation and that would not be detectable under
uniform-weight evaluation.

## 10  Discussion and Limitations

#### Judge bias.

The judge is itself an LLM and will exhibit systematic biases, including
over-weighting of certain evidence types. In production, we have
observed that judges tend to over-label signal-derived claims as
inference-typed when the signal’s provenance is ambiguous. Mitigation is
per-deployment calibration of $`w`$ against a human-graded set; the
framework does not require re-training.

#### Claim atomicity.

gsar assumes the judge emits atomic claims in the sense of FActScore
\[[14](#bib.bib14)\]. Compound claims that mix observation and inference
in a single sentence defeat the four-way partition. We rely on standard
atomisation pre-processing; this is not a contribution of this paper.

#### Weights as an expert prior.

The weight map $`w`$ is an expert prior, not an end-to-end-learned
quantity. Learning $`w`$ from a large corpus of human-graded reports is
a natural extension but raises a subtle consistency issue: the same
claim can receive different weights across deployments depending on what
the deployment treats as authoritative, so a global learned $`w`$ may
overfit to one deployment. Per-deployment calibration is the more honest
choice.

#### Adversarial tool outputs.

An attacker who can inject tool outputs into the evidence corpus can
exploit the evidence-type asymmetry: a fabricated tool output will be
weighted heavily. Defences are out of scope here but would include
tool-output provenance checks at the judge layer.

#### LLM-as-judge drift.

The judge’s distribution will drift as its underlying model is updated.
Periodic re-calibration of $`w`$ and the thresholds against a stable
human-graded reference set is necessary to keep $`S`$ interpretable over
time.

### 10.1 Practitioner takeaways across $`n{=}200`$ and $`n{=}1000`$

Running the framework twice — an initial round at $`n{=}200`$ across
four judges and a scaled round at $`n{=}1000`$ with an independent
back-to-back replication — surfaces five engineering-level lessons that
do not show up in the formal claim set C1–C5 but that a practitioner
deploying a grounding-evaluation layer will encounter immediately.

#### (L1) Mechanism-level effects converge across judges; absolute levels do not.

At $`n{=}1000`$, three independent LLM judges (Gemini-2.5-Pro,
Sonnet-4.6, Opus-4.7) produce $`\Delta\bar{S}_{\rho=0}=+0.058`$ — the
same three-decimal result — while their default proceed rates range from
$`26.2`$% to $`30.0`$%. Single-judge calibrations of absolute proceed
rate do not transfer across judges, but the _mechanism-level effect
size_ of the contradiction penalty is invariant under judge substitution
at this scale. The same pattern held at $`n{=}200`$ ($`+0.04`$ to
$`+0.05`$ band across judges) and simply tightened as $`n`$ grew. A
practitioner swapping judges in production should expect to re-tune
$`\tau_{\mathrm{proceed}}`$ but should not expect the underlying
ablation effects to vanish.

#### (L2) Single-mode FEVER is the wrong stress test for the four-way partition.

At $`n{=}200`$ and $`n{=}1000`$ both, the no-$`\mathcal{K}`$ effect in
single mode is bounded within $`\pm 2.1`$ pp proceed on every judge; in
adversarial mode the same ablation produces up to $`-26.1`$ pp on
gpt-5.4 (260/1000 claims reclassified out of proceed). The complementary
class earns its keep only when the generator produces genuinely
multi-claim diverse content. For practitioners: _evaluate the grounding
layer on summaries the downstream system will actually produce_, not on
atomic benchmark claims.

#### (L3) Reproducibility holds at temperature $`0`$ across the full pipeline, but not automatically.

Running the entire pipeline (embedding, Oracle 26ai vector insert,
retrieval, generator, judge) on separate days with identical seed
produced R1/R2 agreement within $`\pm 1.5`$ pp on proceed and
$`\pm 0.002`$ on $`\bar{S}`$ for every $`n{=}1000`$ cell. The qualifier
is important: partial environmental changes (e.g., a forced failover of
the OCI GenAI endpoint between runs, or rotation of the judge model’s
server-side revision) will break this, and we observed one such case
mid-study in which a silent change of judge endpoint produced run-wide
fallback into a deterministic rule-based judge; full auditing
(quarantine, root-cause, replay) is part of the reproducibility cost,
not a one-time sanity check.

#### (L4) Judge strictness redistributes which ablation matters.

Opus-4.7 (strict judge, $`\textsf{proceed}=11.7`$% in adversarial mode)
is dominated by the $`C_{2}`$ (uniform-weights) ablation, which costs it
$`\Delta\bar{S}=-0.081`$. gpt-5.4 (liberal judge,
$`\textsf{proceed}=63.1`$% in adversarial mode) is dominated by the
$`C_{1}`$ (no-$`\mathcal{K}`$) ablation, which costs it $`-26.1`$ pp
proceed. The paper’s architectural contribution (coupling all four
mechanisms) is justified precisely because _no single mechanism
dominates across judge personalities_; a framework that offered only one
of them would fail on a subset of judges.

#### (L5) Silent failure is the dominant reliability risk.

During the $`n{=}1000`$ study we observed four cross-judge runs silently
fall through to a deterministic rule-based fallback when authentication
state to the inference endpoint changed mid-day. Had we not audited the
JSONL output for the fallback fingerprint (complementary view: prefix in
atom text, byte-identical partition shapes across judges), those four
runs would have produced numbers indistinguishable from legitimate
cross-judge agreement in a paper table. We therefore include in our
published reference implementation an audit pass that refuses to publish
a summary if any ablation cell shares a partition-shape fingerprint with
another cell at the claim level. For any future grounding-framework
paper we recommend the equivalent of this check be a standard
publication requirement.

## 11  Conclusion

We have presented gsar, a grounding-evaluation and replanning framework
for multi-agent diagnostic LLM systems that couples evidence-typed
weighted groundedness with a three-tier cost-asymmetric recovery policy
under an explicit compute budget. The four-way claim partition gives
first-class standing to complementary claims; the asymmetric
contradiction penalty prevents score inflation by contradiction
suppression; the three-tier decision captures the middle band between
“ship as-is” and “re-run investigation”; and evidence-typed weighting
lets the scoring function respect the epistemic-strength difference
between tool-observed and model-inferred claims. To the best of our
knowledge, gsar is the first published framework that couples these
components end-to-end.

#### Empirical evidence (this paper).

We evaluated all five design claims twice. First on $`200`$ FEVER
examples with gold Wikipedia evidence across four independently-trained
LLM judges under adversarial generator conditions, using the 100%-Locus
production stack (Locus SDK Agent, OCIEmbeddings, OracleVectorStore over
Oracle Database 26ai AI Vector Search); every ablation reproduced in the
same direction on every judge, with bootstrap 95% CIs excluding $`0`$ on
the $`\rho{=}0`$ effect for all four judges and the no-complementary
ablation under Opus 4.7 dropping proceed rate by $`82`$ of $`200`$ with
CI $`[-96,-68]`$. We then scaled to $`n{=}1000`$ on seven of the eight
judge$`\times`$mode cells
(§[8.12](#S8.SS12 "8.12 Scale-up to 𝑛=1000 and independent replication ‣ 8 Reproducible Demonstration: FEVER + Locus + Oracle 26ai ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")),
with a full independent back-to-back replication (R1 and R2) agreeing
within $`\pm 1.5`$ pp proceed and $`\pm 0.002`$ $`\bar{S}`$ on every
cell. At $`n{=}1000`$, three of four single-mode judges converge to
$`\Delta\bar{S}_{\rho=0}=+0.058`$ — the same three-decimal result across
independently-trained models. In adversarial mode at $`n{=}1000`$, the
no-$`\mathcal{K}`$ ablation on gpt-5.4 drops proceed by $`260`$ of
$`1000`$ with bootstrap 95% CI $`[-287,-235]`$, and the three-tier
decision saves between $`283`$ and $`455`$ extra replan dispatches per
$`1000`$ claims relative to a two-tier baseline. A head-to-head against
Vectara HHEM-2.1-Open is included: HHEM-2.1 remains the stronger binary
classifier on in-distribution FEVER, but does not output the four-way
partition, tiered decision, or typed-weight structure that distinguishes
gsar.

### 11.1 From scoring function to training signal

gsar was developed as a _run-time_ grounding-evaluation and replanning
framework, but the same decomposition is naturally re-interpretable as a
_train-time_ supervision signal. We see four concrete integration paths
into model weights, each exploiting a different part of the four-way
partition:

- •
  Scalar reward for RLHF / DPO. The groundedness score $`S`$ is bounded
  in $`[0,1]`$ and admits paired ranking: summaries with
  $`S\geq\tau_{\mathrm{proceed}}`$ become “chosen”, summaries with
  $`S<\tau_{\mathrm{regen}}`$ become “rejected”. Because $`S`$ is
  computed without human labels, the pair budget at training time is
  limited only by generator cost.
- •
  Process reward model (PRM) with typed feedback. The per-atom partition
  gives step-level rewards richer than the binary grounded/not signal
  used in existing PRM work \[[6](#bib.bib6), [7](#bib.bib7),
  [8](#bib.bib8)\]. A PRM fine-tuned on gsar atom labels would learn not
  only _which atoms to support_ but also _which evidence type_ each atom
  should draw from, biasing the model toward tool_match and
  specific_data atoms over inference atoms.
- •
  Typed constitutional principles. The evidence-type taxonomy admits
  encoding as Constitutional AI principles: “prefer tool_match over
  inference when both are available”, “never convert a contradicted atom
  to grounded without new evidence”, “surface complementary atoms as
  hedged alternatives rather than suppressing them”. A revision-critique
  loop trained against gsar’s explanation channel can produce a model
  whose default generations already honour the partition.
- •
  Verifier-in-the-loop inference-time search. At inference time, gsar
  can gate Best-of-$`N`$ or beam search: candidates whose partition
  yields $`\delta(s)=\textsf{proceed}`$ are kept; others are pruned.
  This leaves model weights unchanged and trades inference compute for
  grounding quality, which is the dual of RLHF’s
  train-compute-for-run-compute trade-off.

#### Concrete recommendations for multi-agent orchestration systems.

The typical multi-agent investigation loop has three pieces: a _planner_
(or orchestrator), a fleet of _specialists_ that invoke tools against
different data sources, and a _synthesizer_ that collapses specialist
outputs into a single report. We recommend the following integration
profile for grounding-evaluated replanning in that architecture:

1.  1.  Place the judge between synthesizer and orchestrator dispatch — not
        per-specialist. Per-specialist grounding evaluation is the wrong
        granularity: specialists produce atomic tool outputs that are
        trivially “grounded” by construction. The grounding question is
        whether the _synthesized_ report remains faithful to the evidence
        the specialists gathered; that is where gsar earns its keep.
2.  2.  Map the evidence-type taxonomy to your tool taxonomy. tool_match
        should fire only when an atomic claim is directly traceable to a
        structured tool output (e.g., a metrics query row, a log line, a
        database record). signal_match should fire on alert or anomaly
        envelope fields. specific_data should fire on explicit numeric
        values cited in the report. Claims outside those buckets collapse to
        inference or domain with lower weight. The default weight vector in
        the appendix is a starting point; per- deployment calibration
        against a small (100–200) human-graded set is the expected tuning
        step.
3.  3.  Set the replan budget to $`K_{\max}\in\{2,3\}`$. Our empirical runs
        never needed more than $`3`$ replans to reach proceed on a
        recoverable input; higher $`K_{\max}`$ just inflates latency and
        compute. When the budget is exhausted, the orchestrator should mark
        the report as _degraded_ and pass it through with a banner — silent
        suppression is a worse failure mode than a visible warning.
4.  4.  Use different models for the generator and the judge. The
        judge-style differences reported in
        Table [10](#S11.T10 "Table 10 ‣ Which models make the best gsar judges? ‣ 11.1 From scoring function to training signal ‣ 11 Conclusion ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")
        imply that a self-critiquing configuration (same model as generator
        and judge) inherits the generator’s blind spots. A mixed-judge
        configuration — e.g., Sonnet 4.6 as synthesizer, Opus 4.7 as judge —
        removes that correlation and produces more honest replan decisions.
5.  5.  Persist the full partition, not just the scalar $`S`$. The four-way
        partition and the judge’s natural-language explanation are the only
        downstream signals that support post-hoc recalibration of $`w`$ and
        the thresholds without re-running the investigation. Store them in
        the orchestrator checkpoint structure alongside the report.
6.  6.  Instrument silent-failure detection. In production we recommend two
        automatic audits: (a) reject any run in which ablation cells share a
        claim-level partition-shape fingerprint (the failure mode described
        in §[10.1](#S10.SS1 "10.1 Practitioner takeaways across 𝑛=200 and 𝑛=1000 ‣ 10 Discussion and Limitations ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")),
        and (b) monitor the share of reports for which the judge falls back
        to rule-based or default partitions — any sudden rise indicates an
        upstream regression in the judge channel.
7.  7.  Treat the judge’s _abstain_ channel as a first-class planner input.
        When the judge refuses (decision_status = abstain), that is signal
        that the investigation plan itself is ill-posed for the evidence
        available; route the abstain reason into the plan-revision prompt
        rather than defaulting to another replan on the same plan. This is
        the single most effective lever for breaking degenerate replan loops
        we observed.

Applied together, these seven recommendations turn gsar from a scoring
function into the _control plane_ of a multi-agent investigation:
specialists gather evidence, the synthesizer produces a candidate
report, the judge emits a structured verdict, and the orchestrator
dispatches one of three cost-asymmetric actions. Every step is
auditable, every decision is re-thresholdable, and no action is taken on
an un-evaluated report.

#### Positioning and future work.

The empirical study in this paper is not a substitute for the evaluation
protocol in
§[9](#S9 "9 Conceptual Evaluation Protocol ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")
on AIOpsLab and domain-matched production traces — executing that
protocol and adding human-graded faithfulness calibration (Spearman
$`\rho`$ between gsar’s score and human labels) are natural next steps
we invite the community to do. We also propose as future work: (a)
upgrading the Locus integration to exercise multi-step ReAct with
retrieval tools (the infrastructure is already built), (b) a
domain-matched evaluation where the judge cannot pattern-match from
pretraining, (c) an end-to-end multi-agent
orchestrator+specialist+synthesizer+judge pipeline matching production
deployment architectures, and (d) an RLHF/DPO study that uses gsar
scores as the paired-preference signal to quantify the transfer from
gsar run-time feedback to model-weight improvement on downstream
grounding benchmarks.

## Appendix A Proofs of Properties P1–P6

We prove the six properties stated in
§[4](#S4 "4 Evidence-Typed Weighted Groundedness Score ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs")
under the convention that the denominator of
([2](#S4.E2 "In 4.1 Definition ‣ 4 Evidence-Typed Weighted Groundedness Score ‣ GSAR: Typed Grounding for Hallucination Detection and Recovery in Multi-Agent LLMs"))
is strictly positive (equivalently, $`\mathcal{C}\neq\emptyset`$). The
$`\mathcal{C}=\emptyset`$ case is handled by the neutral-score
convention $`S=0.5`$ and is outside the scope of these monotonicity
arguments.

#### P1 (Boundedness).

Let $`N=W(\mathcal{G})+W(\mathcal{K})`$ and
$`D=W(\mathcal{G})+W(\mathcal{U})+\rho W(\mathcal{X})+W(\mathcal{K})`$.
Each term in $`D`$ is non-negative; $`N`$ is non-negative; $`D\geq N`$
because $`D-N=W(\mathcal{U})+\rho W(\mathcal{X})\geq 0`$. Therefore
$`0\leq N/D\leq 1`$.

#### P2 (Monotonicity in grounded claims).

Moving $`c`$ from $`\mathcal{U}`$ to $`\mathcal{G}`$ changes $`(N,D)`$
by $`(+w(\textsc{type}(c)),0)`$: the grounded partition grows while
$`W(\mathcal{U})`$ shrinks by the same amount, so $`D`$ is unchanged
while $`N`$ strictly increases (unless $`w(\textsc{type}(c))=0`$).
Therefore $`S^{\prime}\geq S`$ with equality only if
$`w(\textsc{type}(c))=0`$.

#### P3 (Monotonicity in contradictions).

Adding a contradicted claim $`c`$ to $`\mathcal{X}`$ at fixed
$`\mathcal{G},\mathcal{U},\mathcal{K}`$ changes $`D`$ by
$`+\rho w(\textsc{type}(c))`$ while $`N`$ is unchanged. Therefore
$`S^{\prime}=N/(D+\rho w(\textsc{type}(c)))\leq N/D=S`$, with rate of
decrease controlled by $`\rho`$. The bound is tight at $`\rho=0`$
(contradiction has no effect) and tight from below at $`\rho=1`$
(contradiction acts like ungrounded).

#### P4 (Complementary-claim value).

Adding $`c`$ to $`\mathcal{K}`$ at fixed
$`\mathcal{G},\mathcal{U},\mathcal{X}`$ changes both $`N`$ and $`D`$ by
$`+w(\textsc{type}(c))`$. If $`S\leq 1`$, then
$`S^{\prime}=(N+w)/(D+w)\geq S`$ with equality only when $`S=1`$. The
bound is tight above by the constraint that $`w(\text{complementary})`$
is presumed $`\leq w(\textsf{tool\_match})`$: a complementary claim can
never contribute more to the numerator than a maximally-weighted
grounded claim of the same type.

#### P5 (Contradiction non-suppression).

Consider two partitions
$`\Pi_{1}=(\mathcal{G},\mathcal{U},\mathcal{X},\mathcal{K})`$ and
$`\Pi_{2}=(\mathcal{G},\mathcal{U},\emptyset,\mathcal{K})`$ where
$`\Pi_{2}`$ is obtained from $`\Pi_{1}`$ by dropping contradicted claims
entirely. The scores are $`S_{1}=N/(D+\rho W(\mathcal{X}))`$ and
$`S_{2}=N/(D-0)=N/D`$ (recomputed denominator without contradictions).
Since $`\rho W(\mathcal{X})\geq 0`$, $`S_{2}\geq S_{1}`$. Therefore
silently suppressing contradictions strictly inflates $`S`$ whenever
$`W(\mathcal{X})>0`$ and $`\rho>0`$. The framework prevents this
inflation by keeping contradictions in the denominator.

#### P6 (Inference-observation asymmetry).

Fix partition cardinalities and move one grounded claim’s type label
from tool_match to inference. $`N`$ changes by
$`\Delta N=w(\textsf{inference})-w(\textsf{tool\_match})<0`$; $`D`$
changes by the same $`\Delta N`$ (because the claim moves within
$`\mathcal{G}`$ without changing partition membership). Therefore
$`S^{\prime}=(N+\Delta N)/(D+\Delta N)`$. Writing $`S=N/D`$ and
$`\Delta<0`$:

|     |                                |                                                                                                                                      |     |
| --- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ | --- |
|     | $`\displaystyle S^{\prime}-S`$ | $`\displaystyle=\frac{N+\Delta}{D+\Delta}-\frac{N}{D}=\frac{(N+\Delta)D-N(D+\Delta)}{D(D+\Delta)}=\frac{\Delta(D-N)}{D(D+\Delta)}.`$ |     |

Since $`\Delta<0`$, $`D-N=W(\mathcal{U})+\rho W(\mathcal{X})\geq 0`$,
and the denominators are positive, $`S^{\prime}-S\leq 0`$, with strict
inequality when $`W(\mathcal{U})+\rho W(\mathcal{X})>0`$ (i.e., there is
any ungrounded or contradicted claim whose weight participates in the
denominator). This is the core quantitative argument for evidence-type
weighting: swapping tool-matched for inference-typed grounded claims
strictly reduces the score whenever there is non-trivial ungrounded or
contradicted mass.

## Appendix B Reference Weight Table and Threshold Defaults

A reference instantiation of $`w`$ used in our production deployment:

| Evidence type                                | Weight $`w(\cdot)`$ |
| -------------------------------------------- | ------------------- |
| tool_match (direct tool output verification) | $`1.00`$            |
| specific_data (structured step output)       | $`0.95`$            |
| signal_match (structured signal field)       | $`0.90`$            |
| complementary_finding                        | $`0.85`$            |
| synthesis (cross-specialist derivation)      | $`0.80`$            |
| neg_evidence (absence-of-signal)             | $`0.70`$            |
| inference (model-internal inference)         | $`0.60`$            |
| domain (domain-knowledge assertion)          | $`0.60`$            |

Threshold defaults: $`\tau_{\textsf{proceed}}=0.80`$,
$`\tau_{\textsf{regenerate}}=0.65`$. Contradiction penalty:

These defaults should be understood as one well-calibrated point in the
$`(w,\rho,\tau)`$ parameter space; they are not universally optimal and
should be re-calibrated per deployment against a small human-graded
held-out set.

## Appendix E Worked Numerical Example

Consider a report with five claims:

- •
  $`c_{1}`$: “CPU utilisation on node X reached 97% at 14:02.” —
  grounded, tool_match ($`w=1.0`$).
- •
  $`c_{2}`$: “Request rate dropped simultaneously.” — grounded,
  specific_data ($`w=0.95`$).
- •
  $`c_{3}`$: “This likely reflects a runaway background job.” —
  ungrounded, inference ($`w=0.60`$).
- •
  $`c_{4}`$: “A region-wide networking event is also plausible.” —
  complementary, complementary_finding ($`w=0.85`$).
- •
  $`c_{5}`$: “The saturation was transient.” — contradicted (a
  downstream log shows sustained saturation through 14:17), inference
  ($`w=0.60`$).

With $`\rho=0.5`$:

|     |                                  |                                                                                                  |     |
| --- | -------------------------------- | ------------------------------------------------------------------------------------------------ | --- |
|     | $`\displaystyle W(\mathcal{G})`$ | $`\displaystyle=1.0+0.95=1.95,`$                                                                 |     |
|     | $`\displaystyle W(\mathcal{U})`$ | $`\displaystyle=0.60,`$                                                                          |     |
|     | $`\displaystyle W(\mathcal{X})`$ | $`\displaystyle=0.60,`$                                                                          |     |
|     | $`\displaystyle W(\mathcal{K})`$ | $`\displaystyle=0.85,`$                                                                          |     |
|     | $`\displaystyle S`$              | $`\displaystyle=\frac{1.95+0.85}{1.95+0.60+0.5\cdot 0.60+0.85}=\frac{2.80}{3.70}\approx 0.757.`$ |     |

Under the reference thresholds, $`\delta(0.757)=\textsf{regenerate}`$:
the evidence is largely fine, but the synthesis contains an unsupported
inference ($`c_{3}`$) and a contradicted inference ($`c_{5}`$). A
regeneration that drops or softens those two claims — without re-running
tools — is the appropriate action. If the regeneration succeeds, $`S`$
rises above $`0.80`$ and the report proceeds; if it does not, the outer
loop escalates to replan.
