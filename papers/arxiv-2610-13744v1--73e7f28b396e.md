# A Privileged Teacher That Only Scores Cannot Search: Critique-Conditioned On-Policy Self-Distillation for Reasoning

###### Abstract

On-policy self-distillation promises to replace the sparse outcome
signal of verifiable-reward RL with dense token-level credit: a teacher
conditioned on the reference solution scores the student’s own rollout,
and the resulting distributional shift is distilled back into the
policy. We investigate whether this scoring signal actually contains
corrective credit. Using gold error spans in student rollouts, we test
the two signals consumed by self-distillation objectives, the
full-distribution KL and the token log-ratio, for two properties:
whether they localize errors and whether they push probability away from
erroneous student tokens. They exhibit neither of these properties nor
can they reliably distinguish correct from incorrect rollouts within the
same problem. We argue that this failure is structural: locating an
error in a reasoning trace is itself a search problem, while a scoring
teacher is never explicitly asked to perform that search. The same
model, with the same privileged information, localizes errors
substantially better when allowed to generate a critique. This forms the
motivation for _critique-conditioned self-distillation_: first generate
a critique of the current rollout, then condition the scoring teacher on
that critique. The resulting signal localizes errors, is corrective
within error spans, and shifts probability toward tokens that initiate
backtracking such as “Wait”, “But”, and “Actually”. We further show that
the critique is useful both at test time, where resuming a wrong rollout
with the critique in context converts math problems the model cannot
solve by sampling, and in cold-start GRPO, where it provides an
advantage signal on prompts for which verifiable rewards alone provide
none.

## 1 Introduction

Reinforcement learning with verifiable rewards (RLVR) provides a
reliable but sparse learning signal: a reasoning rollout is correct or
incorrect, but the verifier does not identify which intermediate
decisions caused the outcome. In group-based objectives, the limitation
is sharper when all sampled rollouts for a problem fail, since the
relative advantage can vanish entirely. These all-wrong groups are
precisely where additional supervision is most useful, yet outcome-based
RL provides little guidance about how the reasoning should change.

On-policy self-distillation (OPSD) offers a natural way to obtain denser
supervision (Zhao et al., 2026a; Hübotter et al., 2026; Yang et al.,
2026). The model generates a rollout as a student and then scores the
same rollout as a teacher with privileged information, such as a
reference solution. The discrepancy between the student and teacher
distributions provides a signal at every token, even when the final
answer is wrong. But density alone does not imply credit assignment. For
the signal to be corrective, it should be larger where the reasoning
goes wrong and should push probability away from the student’s erroneous
choices.

We test these properties directly on annotated error spans in logic and
competition-mathematics rollouts. Across tasks and teacher scales,
reference-conditioned scoring fails both tests: its distributional shift
is only weakly concentrated at errors, its token-level signal does not
reliably suppress erroneous student tokens, and even when aggregated
over the full trajectory it does not distinguish correct from incorrect
rollouts of the same problem. The limitation is therefore not in how a
particular loss consumes the signal. Scoring itself exposes little
information about where the reasoning failed.

We argue that locating an error is itself a reasoning problem. A scoring
teacher is given the reference but is never explicitly asked to compare
it against the rollout and search for the mistake. When the same model
is instead allowed to generate a critique, it can localize and explain
the error. This motivates _critique-conditioned self-distillation_:
first generate a localized critique of the student’s rollout, then
condition the scoring teacher on that critique. Generation performs the
search, and scoring converts the error it finds into a dense token-level
signal.

Our contributions are threefold. We show that the privileged teacher’s
signal is neither localized nor corrective at gold error spans, and is
not predictive of rollout correctness even at the whole-trace level
(§5). We show that the failure lies in scoring, not in the information.
The same model, given the same reference, localizes errors when it
generates a critique (§6). Finally, we introduce _critique-conditioned
self-distillation_, which uses generated critiques as privileged context
for dense token-level supervision, and provide initial results using
this signal for test-time inference and training (§8, Appendix A).

## 2 Related Work

Privileged self-distillation. Our work sits between privileged
self-distillation and error-localization methods. On-policy
self-distillation uses a teacher conditioned on privileged information
to provide dense token-level supervision over the student’s own rollout
(Zhao et al., 2026a; Hübotter et al., 2026; Yang et al., 2026; Pan
et al., 2026). Recent work has identified several failure modes of this
setup, including context-induced bias and weak or stylistic
distributional shifts (Harne et al., 2026; Kaur et al., 2026; Pan
et al., 2026). We differ by measuring the resulting signal directly at
gold error spans and asking whether it carries corrective credit.

Locating errors is a reasoning problem. A separate line of work shows
that locating reasoning errors can itself require generation or explicit
reasoning, motivating generative verifiers, process supervision, and
critique-based reward models (Tyen et al., 2024; Zhang et al., 2025a;
Ankner et al., 2024; Khalifa et al., 2025). Extended related work
appears in Appendix C.

## 3 Preliminaries

### 3.1 Group-relative RL and the all-wrong group

For a prompt $`x`$ the policy $`\pi_{\theta}`$ samples a group of $`G`$
rollouts $`y^{1},\dots,y^{G}`$, a verifier scores each one
$`r_{i}\in\{0,1\}`$, and every token of rollout $`i`$ receives the
group-normalised advantage $`A_{i}=(r_{i}-\bar{r})/\sigma_{r}`$ (Shao
et al., 2024). The signal is one bit per rollout, and it vanishes
entirely when the group is unanimous: if all $`G`$ rollouts are wrong,
$`A_{i}=0`$ for every $`i`$ and the group contributes no gradient. These
_all-wrong_ groups are the problems at the frontier of the model’s
competence—the ones it cannot yet solve once in $`G`$ tries—and they are
the reason verifiable-reward RL tends to sharpen what the base model can
already do rather than extend it (Yue et al., 2025).

### 3.2 On-policy self-distillation

Let $`P_{S}(\cdot\mid x,y_{<t})`$ denote the student’s next-token
distribution at a prefix of its own rollout, and let
$`P_{T}(\cdot\mid x,r,y_{<t})`$ denote the same network evaluated at
that prefix with privileged information $`r`$—here, the reference
solution—in context. Because the teacher evaluates a rollout it did not
generate, we call this _scoring_. Scoring yields a dense signal: at each
position, the discrepancy between $`P_{T}`$ and $`P_{S}`$ is interpreted
as token-level credit.

Two forms of that discrepancy are in use. OPSD distils the full
distribution,

```math
\mathcal{L}_{\mathrm{KL}}=\sum_{t}\mathrm{KL}\!\big(P_{T}(\cdot\mid x,r,y_{<t})\,\big\|\,P_{S}(\cdot\mid x,y_{<t})\big), \tag{1}
```

so its per-token signal is the KL divergence at each position (Zhao
et al., 2026a; Hübotter et al., 2026; Kaur et al., 2026). RLSD (Yang
et al., 2026) instead scores the token the student wrote,

```math
\Delta_{t}=\log P_{T}(y_{t}\mid x,r,y_{<t})-\log P_{S}(y_{t}\mid x,y_{<t}), \tag{2}
```

and uses $`\Delta_{t}`$ to modulate the group advantage token by token.
The verifier therefore determines the update direction, while the
privileged teacher modulates its magnitude. RLCSD (Pan et al., 2026)
keeps this form but replaces the reference by sibling rollouts from the
same group, contrasting a correct sibling $`y^{+}`$ against a wrong one
$`y^{-}`$,
$`e_{t}=\log P_{T}(y_{t}\mid x,y^{+},y_{<t})-\log P_{T}(y_{t}\mid x,y^{-},y_{<t})`$,
thereby removing shifts induced by privileged context alone. Neither
construction resolves the all-wrong regime: there is no correct sibling,
and group-relative advantage vanishes. We therefore focus on
reference-conditioned scoring and ask a more basic question: does
$`P_{T}(\cdot\mid x,r,y_{<t})`$ expose useful credit at the positions
where the student’s reasoning goes wrong?

### 3.3 A general form of the probe

Fix a rollout $`y`$ and let $`b`$ denote privileged context prepended to
the teacher prompt. Scoring the same rollout with and without $`b`$
gives two per-token signals:

```math
\displaystyle\mathrm{KL}_{t}(b) \displaystyle=\mathrm{KL}\!\big(P_{T}(\cdot\mid x,b,y_{<t})\,\big\|\,P_{T}(\cdot\mid x,y_{<t})\big), \tag{3}
```

```math
\displaystyle\Delta_{t}(b) \displaystyle=\log P_{T}(y_{t}\mid x,b,y_{<t})-\log P_{T}(y_{t}\mid x,y_{<t}). \tag{4}
```

When $`b=r`$, these recover the two OPSD readouts of Eqs. 1 and 2, since
the unprivileged teacher is the student.

The two signals probe different properties of the same scoring pass.
$`\mathrm{KL}_{t}(b)`$ measures how strongly the privileged context
changes the teacher’s distribution at position $`t`$. If that context
identifies where the rollout fails, this shift should concentrate at the
error spans, so we call it the _localization_ signal. $`\Delta_{t}(b)`$
measures how the context changes the probability of the token the
student actually wrote. At an erroneous token, a corrective signal
should reduce that probability, so we call $`\Delta_{t}`$ the
_correction_ signal and read negative values as corrective. We evaluate
both signals at gold error spans in §4.

To isolate the information carried by privileged context, we pair each
context $`b`$ with a matched placebo $`\tilde{b}`$ and report the
content signals $`\mathrm{KL}_{t}(b)-\mathrm{KL}_{t}(\tilde{b})`$ and
$`\Delta_{t}(b)-\Delta_{t}(\tilde{b})`$. This controls for
distributional shifts caused by the presence of a solution-shaped
preamble alone. For the reference condition, $`b=r`$ and
$`\tilde{b}=r^{\prime}`$ is a matched-length reference from another
problem. For the critique condition, $`b=c(y)`$ and
$`\tilde{b}=c(y^{\prime})`$ is a critique of another problem’s rollout.

The critique is generated from the problem, reference, and student
rollout as $`c(y)=\{(q_{j},\rho_{j})\}_{j}`$, where $`q_{j}`$ is a
verbatim quote of an erroneous sentence and $`\rho_{j}`$ explains the
error. _Critique-conditioned self-distillation_ then replaces the
reference in OPSD with $`c(y)`$: generation performs the search for the
error, and scoring converts the resulting critique into a dense signal
over the rollout. We ablate the quote and explanation separately in §7.

## 4 Setup

### 4.1 Models, data, and labels

#### Models and tasks.

We conduct the token credit signal analysis on the Qwen3-1.7B (Yang
et al., 2025), Olmo-3-7B-Think and Olmo-3-32B-Think (Olmo et al., 2026)
rollouts. In each case the teacher is the same model with privileged
context, the on-policy self-distillation setting. For Qwen3-1.7B we also
run Qwen3-8B as a scale-control teacher. The tasks are Knights & Knaves
logic puzzles (Xie et al., 2025a; Xie et al., 2025b) (K&K, 4–8 people)
and DeepMath (He et al., 2025b) at two difficulty bands (L5-7, L7-10).

#### Rollouts, references, and gold error spans.

We study wrong rollouts: verifier-incorrect, not truncated, and ending
in a boxed answer. We keep the verifier-correct rollouts of the same
problems for the correctness test in §5. The privileged reference is a
verified step-by-step derivation for K&K and the dataset’s reference
solution plus answer for DeepMath. We obtain gold error spans from a
grader model that reads the problem, the rollout and the reference and
flags each error as a verbatim quote of one sentence plus a reason. The
grader is a DeepSeek model (DeepSeek-AI et al., 2026a; DeepSeek-AI
et al., 2026b) for the Qwen rollouts and claude-sonnet-5 (Anthropic, 2026) for the Olmo-3 rollouts. We then have gpt-5.2 (OpenAI, 2025a) and
claude-sonnet-5 judge every flag independently, and we count a flag as
gold when both accept it. To measure how lenient the judges are, we
replace a quarter of the flags sent to each judge with position-matched
control sentences carrying the same reason and report their acceptance
rate with each study (Appendix D). We also perform the same signal
analysis on human-annotated error spans from ProcessBench (Appendix J).

#### Critics.

We use three critics to write the critiques $`c(y)`$ of §3.3. All use
the same prompt: the rollout is presented sentence-numbered, each error
is a verbatim quote plus a reason, and recall is favoured over precision
(Appendix D.1). All receive the same reference $`r`$ that the teacher
receives in the reference condition. We use gpt-5.2 as the oracle
critic. We also test whether the student can identify its own errors by
having Qwen3-1.7B critique its own rollouts. We call this the
self-critique. To assess whether a larger critic is more effective, we
have Qwen3-8B perform the critiques as well. Appendix B shows an oracle
critique and a self-critique of the same rollout on each task. Because
critic and teacher see the same information, the comparison in §6 is
between generating and scoring, not between amounts of information. The
Olmo-3 models each critique their own rollouts (Table 1, Appendix I).

### 4.2 The error-span Z readout

Per-token signals vary substantially across positions and rollouts, so
we normalise each rollout against its own clean regions, following
baseline-normalisation conventions in event-related neurophysiology
(Mercier et al., 2022). For each rollout, we measure the signal in a
short window immediately after the first gold error span and compare it
with length-matched windows after clean spans in the prefix. We use the
first error only because the reasoning after it is often wrong in ways
the gold spans do not mark. If $`\bar{s}_{W}`$ denotes the mean signal
in window $`W`$, we define

```math
Z_{r}=\frac{\bar{s}_{W_{\mathrm{err}}}-\operatorname{mean}_{k}\bar{s}_{W_{k}}}{\operatorname{sd}_{k}\bar{s}_{W_{k}}},
```

which we call the _error-span Z_. It measures how far the signal at the
error departs from the rollout’s own baseline, in units comparable
across signals, teachers, and tasks.

A positive localization score means that the teacher’s distribution
changes more at the error than at clean regions while a negative
correction score means that privileged context lowers the probability of
the student’s erroneous token. For localization, we log-transform the
window-mean KL before computing $`Z_{r}`$ to reduce the effect of its
heavy tail. We report the mean $`Z_{r}`$ across rollouts, calibrated by
subtracting the score obtained when a random clean sentence from the
same rollout is treated as the error. Thus, a signal with no
error-specific content is centered at zero. Window sizes and other
implementation details are given in Appendix D.

## 5 The Privileged Signal Is Empty Where It Matters

We report the localization and correction signals of §3.3 at the
positions of the student’s rollouts known to be wrong. Figure 1 shows
both signals around the gold error sentences (blue), aligned to sentence
onset and to sentence end and averaged over all error sentences of all
rollouts, against the same average over the clean sentences that precede
the first error (orange). Table 1 reports the error-span Z of §4.2. A
privileged teacher provides usable token-level credit at an error if its
error-span Z is positive for localization and negative for correction.
We apply the same criterion to the reference here and to the critique in
§7.

#### Not localized at the errors.

On K&K, error and control traces are nearly indistinguishable for both
localization and correction. On DeepMath, the reference induces a small
error-specific shift, most visible near the sentence boundary, but the
effect is much weaker than under critique conditioning (Figure 3). Thus,
the reference does affect the teacher’s distribution, but not
selectively at the student’s errors.

Table 1 shows the same comparison at the rollout level. Across students,
tasks, and both signals, reference-conditioned scores remain close to
the rollout’s clean baseline, and no setting satisfies the corrective
criterion. When the reference signal does depart from zero, it can even
point in the wrong direction: on L7-10, the Qwen teacher assigns _more_
probability to the student’s erroneous token when conditioned on the
reference. Increasing teacher capacity does not rescue the signal.
Re-scoring the same Qwen rollouts with the 8B teacher leaves the
reference-conditioned scores similarly small, while critique-conditioned
signals become stronger across settings (Appendix E).

#### Not even informative about correctness.

A diffuse signal could still be useful even if it does not localize
errors, but at minimum it should recover the verifier’s one bit: whether
the rollout is correct. We therefore test whether the localization or
correction signal averaged over all tokens of a rollout ranks correct
rollouts above incorrect siblings of the same problem. Across all three
tasks and both teacher scales, neither reference-conditioned signal does
so reliably: all twelve within-problem AUC confidence intervals include
chance. Pooled across problems, some cells move away from chance
(Figure 2), but the same deviations appear under content-free controls,
indicating that they largely reflect problem-level factors such as
length and difficulty. A trained probe over richer trace-level summaries
does no better than the content-free controls (Appendix G). The
reference-conditioned signal is therefore not only poorly localized.
Even aggregated over the full trajectory, it carries little information
about whether the reasoning is correct.

## 6 Dense Feedback Is a Search Problem

Why does the reference as privileged context induce so little signal at
the error? We posit that locating where a rollout goes wrong, and why,
is itself a reasoning problem: the reference and rollout must be
compared until the discrepancy is found. A scoring pass is never asked
to perform that search. It only produces a next-token distribution with
the reference in context. If the failure is one of scoring rather than
of information, the same model should recover the errors when allowed to
generate. We test this directly by asking critics of different scales to
read the problem, reference, and rollout and produce a list of errors,
each with a verbatim quote and an explanation (§3.3). The quote makes
the prediction directly localizable against the gold error spans and
later provides an anchor for critique-conditioned teacher scoring.

Table 2 confirms this prediction. The strongest critic localizes a gold
error on well over half of the rollouts across tasks, while smaller
critics succeed less often but preserve the same ordering with scale.
Their main failures are practical rather than conceptual: they often
paraphrase instead of quoting the rollout or violate the required output
format. The key result is that the same reference that yields little
error-specific signal under scoring produces explicit error locations
under generation. This suggests that search is the missing computation.
The next section asks whether these generated critiques can in turn be
converted back into a dense signal by scoring.

## 7 Critique-Conditioned Self-Distillation Delivers

We replace the reference in the teacher’s context with a generated
critique and score the student’s rollout exactly as before, using a
critique from another problem as the placebo. Figure 3 repeats Figure 1
with the critique in place of the reference. The teacher, alignment, and
estimand are the same. Under critique conditioning, the previously
overlapping error and control traces separate. The teacher’s
distribution shifts after the flagged error sentence, and its
probability on the student’s continuation decreases there rather than
elsewhere. This pattern holds across tasks.

Table 1 confirms the same result at the rollout level. With oracle
critiques, every setting satisfies the corrective criterion of §5 on
both signals: errors are localized relative to clean regions, and
probability is pulled away from the student’s erroneous continuation, at
several times the magnitude of the reference-conditioned signal. The
critic sees only the reference that the scoring teacher already has. The
critique therefore carries the same information in a form the scoring
pass can use. Self-generated critiques preserve the same effect at
reduced magnitude: with Qwen3-1.7B critiquing its own rollouts,
localization is positive and correction is negative on all three tasks,
and the effect strengthens with model scale. The weaker self-critique
signal still trains. In the training runs of Appendix A, the
self-critique arm recovers most of the oracle-critique arm’s gain over
GRPO (Table 6). Larger scoring teachers likewise amplify the
critique-conditioned signal while leaving the reference-conditioned
signal near baseline (Appendix E). Critique conditioning also recovers
the trace-level correctness signal absent under the reference
(Figure 2). The same pattern holds on human-labelled error steps: on
ProcessBench (Zheng et al., 2025), with each solution scored by the
Qwen2.5 model that wrote it, the reference is neither localized nor
corrective, while a critique localizes the labelled step for both
generators and corrects once the tokens it quotes are excluded
(Appendix J).

#### Correction resolves into self-correction language.

The correction signal in Table 1 shows that critique conditioning moves
probability mass away from the student’s continuation, but not where
that mass goes. We therefore inspect high-content tokens in the
post-error window and bucket the teacher’s argmax prediction by
destination. Under reference conditioning, error windows show no excess
of self-correction markers such as _Wait_, _But_, or _However_ while
under critique conditioning, the reconsideration bucket rises to two to
three times the control rate on every task (Table 4). Thus, the
probability mass released from the student’s erroneous continuation is
redirected toward self-correction language only when the teacher is told
what is wrong, not merely shown the correct solution.

#### Delivery decomposes into pointing and correcting.

A critique contains two separable components: a quote that points to the
erroneous step, and a reason that explains why it is wrong. Table 4
ablates each in turn. Localization is carried primarily by the quote:
removing the reason leaves it largely unchanged, while removing the
quote weakens it across tasks. Correction depends on the reason: without
it, the corrective shift shrinks substantially and, with the larger
teacher, can disappear or even reverse. The two components therefore
play distinct roles in delivery: the quote tells the scoring teacher
_where_ to react, while the reason tells it _how_ to change the
student’s distribution.

## 8 Using the Signal at Test Time

We test whether the critique is useful at inference. We take wrong
rollouts of Olmo-3-32B-Think on L7-10, 55 rollouts from 39 problems, 19
of which the model does not solve in eight samples. The model critiques
each rollout with the reference solution in context, the self-critique
setting of Table 1. We cut the rollout at the first sentence the
critique flags and let the model continue from the cut, eight samples
per rollout. The critique item is placed at the cut together with the
cue “Wait, I should correct this reasoning.” The control cuts at a fixed
depth and places the cue alone. Table 5 reports sample accuracy. With
the critique in context the model solves the problems it never solved by
sampling about twice as often as the control. The critic had the
reference in context, so the gain measures what a privileged critique
delivers at inference, not unaided self-correction. We also train with
the signal (Appendix A). On four Knights & Knaves puzzles
Olmo-3-7B-Think never solves by sampling, the critique-conditioned arm
solves two puzzles that the GRPO control never solves (Appendix A.1). On
a 320-puzzle training set, the critique-conditioned term raises
out-of-distribution accuracy over GRPO and over reference-conditioned
self-distillation, and the student as its own critic recovers most of
the oracle critic’s gain (Appendix A.2).

## 9 Conclusion and Limitations

We show that reference-conditioned self-distillation provides dense
supervision but not reliable corrective credit: its signal does not
localize student errors and is not informative about rollout
correctness. The same teacher can recover those errors when allowed to
generate a critique, suggesting that credit assignment requires an
explicit search over the reasoning trace. Critique-conditioned
self-distillation separates that search from scoring, using generation
to identify the error and a scoring pass to turn it into dense
token-level supervision. Limitations. Our study has three main
limitations. First, our training evidence is small in scale, a
320-puzzle set and 100 steps (Appendix A.2), and we have not run
critique-conditioned self-distillation at full RL scale. Second,
critique conditioning adds a generation pass over the wrong rollouts of
each batch. In our runs this costs 6% of step time with the student as
critic and about a fifth with an API critic (Appendix A.3). Third, every
critique in this paper, in the signal analysis, at test time and in
training, is written with the reference solution in context. Our results
show that a critique conveys privileged information in a form the
scoring teacher can use, not that the model corrects itself unaided.

## Appendix B Critique Examples

We show one wrong Qwen3-1.7B rollout per task with its gold error
sentence, the gpt-5.2 critique and the student’s own critique. Both
critics received the same prompt (Appendix D.1) and the same reference.
The gold error sentence is in italics in the rollout excerpt.

#### Knights & Knaves.

Problem. A very special island is inhabited only by knights and knaves.
Knights always tell the truth, and knaves always lie. You meet 6
inhabitants on this island: Yara, Liam, Peter, Sophia, Noah, and Bob.
Yara says: “Peter is a knave if and only if Liam is a knight.” Liam
says: “It is not the case that Yara is a knave if and only if Yara is a
knight.” Peter says: “Bob is a knight.” Sophia says: “Liam is a knight.”
Noah says: “It is not the case that Liam is a knave.” Bob says: “Noah is
a knave.”

Reference answer. Yara is a knight, Liam is a knight, Peter is a knave,
Sophia is a knight, Noah is a knight, Bob is a knave.

Student’s answer. Yara is a knight, Liam is a knave, Peter is a knight,
Sophia is a knave, Noah is a knave, Bob is a knight.

Rollout excerpt. \[…\] if Yara is a knight ($`Y`$ is true), then the
statement “Yara is a knave if and only if Yara is a knight” would be
“False $`\leftrightarrow`$ True”, which is False. Similarly, if Yara is
a knave ($`Y`$ is false), then the statement is “True
$`\leftrightarrow`$ False”, which is also False. Therefore, the
statement is always false. _Therefore, Liam’s statement is false._
Therefore, if Liam is a knight, he would be making a false statement,
which is impossible. Therefore, Liam must be a knave. Wait, that seems
important. \[…\]

Gold error. Liam’s statement is the negation of the inner biconditional,
and since that inner biconditional is always false, Liam’s statement is
actually true.

Oracle critique (gpt-5.2). ERROR 1: “Therefore, the statement is always
false.” – The biconditional “Yara is a knave iff Yara is a knight” is
always false, so its negation (Liam’s statement) is always true, not
false.  
ERROR 2: “Therefore, Liam must be a knave.” – Since Liam’s statement is
necessarily true, Liam must be a knight, not a knave.  
ERROR 3: “Since we just determined that Liam is a knave,” – This
propagates the earlier incorrect classification of Liam, making
subsequent deductions unreliable.

Self-critique (Qwen3-1.7B). ERROR 1: “Liam is a knave” – Liam’s
statement is a contradiction (always false), so he must be a knave. This
is correct, but the final answer contradicts this conclusion.  
ERROR 2: “Noah is a knave” – Noah’s statement is “Liam is a knight,”
which is false because Liam is a knave. Therefore, Noah is a knave. This
is correct.  
ERROR 3: “Bob is a knight” – Bob’s statement “Noah is a knave” is true,
so Bob is a knight. This is correct.  
ERROR 4: “Peter is a knight” – Peter’s statement “Bob is a knight” is
true, so Peter is a knight. This is correct.  
ERROR 5: “Yara is a knight” – Yara’s statement is true, so she is a
knight. This is correct.  
Final Answer (boxed): Yara is a knight, Liam is a knight, Peter is a
knave, Sophia is a knight, Noah is a knight, Bob is a knave.

The oracle quotes the sentence before the gold error and the conclusion
drawn from it, and each reason says which way to correct it. The
self-critique quotes fragments of the final answer, endorses the
student’s reasoning, and then writes the reference answer as its own
final answer. Its quotes carry no location and its reasons carry no
correction before that last line.

#### DeepMath L5-7.

Problem. Find the residue of the function
$`\sin\left(\frac{1}{z}\right)`$ at its poles.

Reference answer. 1.  Student’s answer. 0.

Rollout excerpt. \[…\] So, this is an infinite series, and there are
infinitely many terms with positive powers of $`1/z`$. Therefore, the
Laurent series has an infinite number of terms with negative powers of
$`z`$, which means that $`z=0`$ is an essential singularity, not a pole.
But wait, the question says “at its poles”. _But if there are no poles,
then the residue would be… Well, if there are no poles, then the residue
is zero?_ But maybe I need to check if there are any poles. But since
$`\sin(1/z)`$ has an essential singularity at $`z=0`$, there are no
poles. So, the residue at the pole… but there are no poles. Therefore,
the residue is zero? \[…\]

Gold errors. Three sentences are gold. The first is the italic one above
(a residue can exist at an essential singularity and is the coefficient
of the $`z^{-1}`$ term, which is nonzero here). The other two are “Since
there are no poles, the Laurent expansion does not have any
$`(z-a)^{-1}`$ term, so the coefficient is zero” and “if a function has
an essential singularity at a point, then the residue is not defined in
the usual sense.”

Oracle critique (gpt-5.2). ERROR 1: “then the residue would be… Well, if
there are no poles, then the residue is zero?” – Lack of poles does not
imply the residue is zero; residue is defined at isolated singularities
(including essential ones) via the $`z^{-1}`$ coefficient.  
ERROR 2: “if a function has an essential singularity at a point, then
the residue is not defined in the usual sense.” – False: the residue is
still defined for essential singularities as the coefficient of
$`z^{-1}`$ in the Laurent series.  
ERROR 3: “Since there are no poles, the Laurent expansion does not have
any $`(z-a)^{-1}`$ term” – Incorrect:
$`\sin(1/z)=1/z-1/(6z^{3})+\cdots`$ does contain a $`z^{-1}`$ term, so
residue at $`0`$ is $`1`$.

Self-critique (Qwen3-1.7B). ERROR 1: “the residue of the function
$`\sin\left(\frac{1}{z}\right)`$ at its poles is $`\boxed{0}`$” – The
student incorrectly concludes that the residue is zero because there are
no poles, but the residue is defined only for isolated singularities,
not for the absence of poles. The function has an essential singularity
at $`z=0`$, and the residue at that singularity is 1, not zero.  
ERROR 2: “the student’s final answer is known to be WRONG: the solution
below contains at least one mistake” – The student’s final answer is
wrong because the residue of $`\sin\left(\frac{1}{z}\right)`$ at its
essential singularity (not poles) is 1, not 0.  
\[ERROR 3 to ERROR 5 repeat these two items.\]

The oracle’s three quotes are the three gold error sentences, and each
reason states the correct fact. The self-critique quotes the final
answer and a line of its own prompt, neither of which is a step of the
derivation, so it does not localize. Its reason is right: the residue at
the essential singularity is 1. This is the division of labour of
Table 4. The quote carries the location and the reason carries the
direction, and here the self-critique has the second without the first.

## Appendix C Extended Related Work

Self-distillation with a privileged teacher. On-policy self-distillation
\[Zhao et al., 2026a, Hübotter et al., 2026\] produces a per-token
signal in place of the single bit that verifiable-reward RL provides:
the same model scores the student’s own rollout with the reference
solution in its context. The line has grown by varying pieces of that
recipe. RLSD keeps the reference fixed and turns the log-ratio into a
token-level advantage weight \[Yang et al., 2026\]. RLCSD contrasts a
correct hint against a wrong one to suppress the style drift a hint
alone induces \[Pan et al., 2026\], and Zhao et al. \[2026b\] replace
the full solution with a more structured trace. Carried over to thinking
models, the recipe degrades performance rather than helping \[Kaur
et al., 2026\], and Rebellious Student reverses the signal on rollouts
the student already gets right, to encourage exploration rather than
correction \[Kim et al., 2026\]. Closest to our premise, Li et al.
\[2026b\] show that a teacher conditioned only on the final answer
produces no signal at the intermediate positions where guidance is
needed, and condition it on a successful peer rollout instead. All of
these variants take the scored signal as given and change how it is
consumed or what the teacher is conditioned on. We ask whether the
scored signal carries any credit at the error, and find that a full
reference solution does not. Cross-model distillation selects the
teacher’s tokens by mismatch, importance, learnability, position, or
evidence \[Yu et al., 2026, Xu et al., 2026, Wang et al., 2026, Liu
et al., 2026, Xiao et al., 2026\], and Li et al. \[2026a\] find instead
that the high-overlap tokens carry the signal. Those methods assume a
signal to select. A cross-model teacher’s gap reflects a real capability
difference; a privileged teacher differs from the student only by
context, and at the errors we find no signal to select.

Failure modes of the privileged teacher. Three papers report that the
privileged teacher misbehaves. Harne et al. \[2026\] show that the
teacher is biased by the privileged information it is given, and ask
whether self-distillation alone teaches anything. Kaur et al. \[2026\]
show that the same information degrades performance on thinking models.
Pan et al. \[2026\] find that the distributional gap concentrates on
style tokens rather than task-bearing ones. None of them anchors the
diagnosis to the place where the student’s reasoning goes wrong. We
measure the signal itself against gold error spans on the student’s own
rollouts, and find that scoring fails to localize the error while
generating does.

Locating an error is a reasoning problem. Tyen et al. \[2024\] show that
language models cannot find their reasoning errors but can correct them
given the error location, and Huang et al. \[2024\] and Kamoi et al.
\[2024\] show that intrinsic self-correction without an external signal
does not improve reasoning. Verifiers do better when they reason before
they judge. Generative verifiers \[Zhang et al., 2025a\],
critique-out-loud reward models \[Ankner et al., 2024\], and reward
models trained as reasoners \[Chen et al., 2026a\] all take this route,
and process reward models that think locate erroneous steps better than
discriminative scorers with a fraction of the labels \[Khalifa et al.,
2025\]. ProcessBench reports that trained step scorers underperform
prompted critics \[Zheng et al., 2025\], and Chen et al. \[2026b\] find
that verification is a capability separate from generation. Generation’s
advantage is not universal. Tyen et al. \[2024\] also show that a
trained classifier can localize mistakes without generating, and Stechly
et al. \[2023\] find a critique’s content irrelevant to the benefit of
iterative prompting in planning. Our claim is correspondingly narrow.
The token-level likelihoods of a teacher scoring a forced trace do not
localize the error, while the same model generating a critique does.

Process supervision and critics. Process supervision identifies the
error when the step-level labels are created. Labels come from humans
\[Uesato et al., 2022, Lightman et al., 2023\], from automatic rollouts
\[Wang et al., 2024\], or from an LLM judge, and the automatically
estimated labels generalize worse than the judged or human ones \[Zhang
et al., 2025b\]. The generative verifiers and critique-out-loud models
above, together with critics trained to critique rather than imitate
\[Wang et al., 2025\], put the search into generation, which is the
readout we use. Such critics are scored against human-annotated
step-level error benchmarks \[Tyen et al., 2024, Zheng et al., 2025, He
et al., 2025a\], which we revisit in Appendix J. Critique-conditioned
self-distillation combines both ideas: a generated critique, delivered
through the scoring teacher, becomes a per-token signal for on-policy
self-distillation, with the critic and the teacher the same model.

## Appendix D Setup Details

#### Rollouts and targets.

Every rollout in the paper is sampled from the student itself, on the
training distribution. A rollout is a _target_ if the verifier scores it
wrong, it is not truncated, and it ends in a boxed answer;
verifier-correct rollouts of the same problems are kept as a control
stratum for §5. K&K targets are drawn only from puzzles whose English
rendering is decidable as worded, about half of the pool, because on the
remainder a “wrong” rollout is often a legitimate alternative reading.
Rollouts are sampled with the training parameters, temperature 1.0,
top-p 0.95, top-k 20, eight rollouts per prompt, with a 16,384-token
budget for Qwen3-1.7B and a 32,768-token budget for the Olmo-3 models,
whose thinking traces are longer.

#### Gold error spans.

A grader model reads the problem, the rollout, and the reference, and
lists the places where the reasoning goes wrong, earliest first, each as
a verbatim quote of one sentence with a reason, a severity, and a
confidence (§D.2). The grader is deepseek-reasoner for the original Qwen
sample, deepseek-v4-flash for the problems added in the scale-up, and
claude-sonnet-5 for the two Olmo-3 studies. Each flagged sentence is
then judged independently by gpt-5.2 and by claude-sonnet-5, which see
the problem, the reference, and the rollout with the sentence marked and
the grader’s reason attached (§D.3). A quarter of the flags sent to each
jury are replaced by position-matched control sentences carrying the
same reason, which measures the jury’s leniency; the control acceptance
rate is reported with each study. A flag is _strict_ gold if both juries
accept it and _lenient_ gold if the claude jury accepts it. Error-span Z
uses the first strict gold sentence of each rollout; the curves of
Figs. 1 and 3 use every strict gold sentence; the critique gate of
Table 2 uses the lenient tier. In the Olmo-3 studies the claude jury
shares its model with the grader, so gpt-5.2 is the only fully
independent judge there.

#### Placebos.

Every conditioning block is scored against a placebo of the same shape,
and all reported signals are block minus placebo. The placebo for the
reference is a different problem’s reference of matched length, assigned
by one fixed derangement of the problems that every arm shares. The
placebo for a critique is the critique written for a different problem’s
rollout, assigned by the same derangement. The undifferenced arms are
reported as negative controls in Table 9.

#### Error-span Z windows and statistics.

The error window is the 20 tokens immediately after the first gold error
sentence ends. Control windows have the same shape and sit after the
ends of clean sentences before the first error. We use the 12 nearest
control windows, non-overlapping, with a 60-token guard band around the
error sentence. On the localization signal we take the log of each
window mean before Z-scoring; the correction signal is already a signed
log-probability difference and is used as is. The dataset-level
statistic is the mean of $`Z_{r}`$ over rollouts, winsorized at the 5th
and 95th percentiles, with a 95% bootstrap interval clustered by problem
(2,000 resamples). The null subtracted from every cell relabels a
control sentence of the same rollout as the error and recomputes
$`Z_{r}`$; the reported value is $`Z-Z_{\mathrm{null}}`$. Bold in
Table 1 marks cells whose 95% interval excludes zero.

#### Which reference each model sees.

The scoring teacher’s reference is a step-by-step derivation verified
against the ground truth for K&K and the dataset’s reference solution
with its final answer for DeepMath. The oracle critic receives the same
reference as the teacher. The open-weights critics on the scale-up
sample receive the K&K derivations and, for DeepMath, a clean derivation
generated and verified against the ground-truth answer, because the
dataset solutions are raw chains of thought that weaker critics mistake
for a second student solution; the 60 rollouts without a verified
derivation are dropped from those arms.

### D.1 Critique prompt

The critic receives the problem, the student’s rollout with sentence
tags, the reference solution, and the instructions below. The rollout is
presented before the reference to prevent the critic from quoting the
reference. The same prompt is used for every critic.

```ltx_verbatim
Problem: {problem}

You are grading a student’s solution to this problem.

The student’s final answer is known to be WRONG: the solution below
contains at least one mistake.

=== Student Solution Begin ===
[S0] <sentence 0> [S1] <sentence 1> ...
=== Student Solution End ===

For reference, here is a correct solution:

=== Reference Solution Begin ===
{reference}
=== Reference Solution End ===

Coverage matters more than precision here: if you are unsure where the
reasoning FIRST goes wrong, list EACH plausible location as its own
ERROR line (up to 5), earliest first -- it is better to list several
candidate locations than to miss the true one.

Write a CONCISE critique of the student’s reasoning, at most 120 words
total. Use EXACTLY this format, one line per error, earliest error
first, at most 5 errors, and nothing else:

ERROR 1: "<short quote, at most 10 words, copied word-for-word from the
student’s solution at the point the error occurs>" -- <one short
sentence: what is wrong there>
ERROR 2: ...

If the reasoning contains no errors, output the single line: NO ERRORS

Rules: each quote must be copied exactly, character for character, from
the Student Solution above (never from the reference, never a
paraphrase), and must be at most 10 words. Point at the sentence where
the reasoning first goes wrong, not merely the final answer line. Only
report NEW errors: once the reasoning is broken, list a later step only
if it introduces a NEW, independent error. Report only errors you are
CERTAIN about.

IMPORTANT REMINDER: every quote must be copied word-for-word from
between "=== Student Solution Begin ===" and "=== Student Solution End
===" above -- NEVER from the Reference Solution, which is correct and is
not being graded.
The student’s sentences are tagged [S0], [S1], ... to help you keep
track of position. Do NOT include any [S#] tag inside your quotes --
quote only the sentence text itself.
```

### D.2 Gold-span grader prompt

The grader sees the problem, the rollout, and the reference (arm _ref_),
with the same known-wrong line as the critic, followed by:

```ltx_verbatim
List the places where the student’s REASONING goes wrong, in order of
occurrence, starting with the FIRST error. Report ONLY errors you are
CERTAIN about -- one certain error is worth more than several doubtful
ones. List at most 8. Your final answer must use EXACTLY this format and
nothing else, beginning with the line "ERROR 1:" (or the single line
"NO ERRORS" if you find none):

ERROR 1:
QUOTE: "<one sentence copied word-for-word from the student’s solution,
at the point where the error occurs>"
REASON: <one short sentence explaining what is wrong there>
SEVERITY: <integer 1-5: how much this error contributes to a wrong final
answer; 5 = directly causes it, 1 = minor slip>
CONFIDENCE: <integer 0-100: how certain you are that this is a genuine
error>

ERROR 2:
...

Rules: each QUOTE must be copied exactly, character for character, from
the Student Solution above -- not from the reference, and not your own
paraphrase. Point to the sentence in the student’s reasoning where
things go wrong, not merely the final answer line. ERROR 1 must be the
EARLIEST point where the reasoning actually goes wrong. Only report NEW
errors: once the reasoning is broken, do not list every later step that
merely inherits an earlier mistake -- list a later step only if it
introduces a NEW, independent error. Do not include errors you are not
sure about.
```

### D.3 Jury prompt

Each grader flag is judged independently by two models. The judge sees
the problem, the reference, and the rollout with the flagged sentence
marked between \<\<\< and \>\>\>; a quarter of the flags are replaced by
position-matched control sentences with the grader’s reason attached
unchanged.

```ltx_verbatim
Above is a problem, a correct reference solution, and a student’s
solution in which one sentence has been marked between <<< and >>>. A
grader claims the student’s reasoning goes wrong AT THAT SENTENCE, for
this reason:

GRADER’S CLAIM: {reason}

Judge the claim on the student’s actual reasoning. Answer YES only if a
genuine reasoning error is committed at (or within a sentence or two of)
the marked sentence -- i.e. the marked step is wrong given what the
student derived so far, not merely downstream of an earlier mistake, and
not a legitimate alternative reading. Answer NO otherwise.

Reply in EXACTLY this format:
VERDICT: <YES or NO>
CONFIDENCE: <integer 0-100>
WHY: <one short sentence>
```

## Appendix J Validation on Human-Annotated Error Spans

Our main analysis uses error spans labelled by an LLM jury. To validate
the result on human annotations, we repeat the analysis on ProcessBench
\[Zheng et al., 2025\], which provides human-labelled first-error steps
for solutions generated by Qwen2.5-7B-Instruct and
Qwen2.5-Math-7B-Instruct. We score each solution with the model that
generated it and compare reference conditioning against an oracle
critique from gpt-5 \[OpenAI, 2025b\], generated without access to the
human label. Table 17 reproduces the main pattern of Table 1: the
reference is neither localized nor corrective, while critique
conditioning localizes the error for both models. Correction is clear
for Qwen2.5-7B-Instruct and initially weak for Qwen2.5-Math-7B-Instruct;
consistent with §7, removing tokens quoted by the critique makes the
signal corrective for both. More generally, correction appears when the
critique points inside the human-labelled error span and disappears when
it points elsewhere. Thus, human annotations reproduce the same picture:
reference-conditioned scoring remains flat, while critique-conditioned
scoring reacts where the critique identifies the error.
