###### Abstract.

Weight-space programming (WSP) shows that language models can reason
about and rewrite neural network weights; recursive self-improvement
(RSI) motivates feedback-driven improvement. Models guiding experiments
receive concrete feedback: completed assays reveal prediction errors and
inform what to test next. We introduce WeightLoop, a framework that
turns experimental feedback into persistent updates to deployed
predictors. GPT-6 Astra inspects a task specification and the model
implementation, then writes a bounded, reusable parameter-editing
program. As new measurements arrive, the program identifies prediction
discrepancies, validates candidate edits using observed outcomes, and
writes the selected changes back to the original model. The editor
remains fixed while the predictor evolves, enabling repeated updates
without further LLM calls or gradient retraining while preserving the
original inference interface. In offline replay, targeted edits improve
mean ranking utility in seven of eight endpoint–budget settings (all
eight versus random edits) and mean final discovery across three
sequential tasks. WeightLoop connects WSP with an RSI-inspired
improvement loop, making experimental evidence a direct driver of model
change and subsequent decisions.

###### Key words and phrases:

Scientific recommendation, model editing, experimental feedback,
weight-space programming

## 1. Introduction

An experiment does more than test a prediction: it produces evidence
that can change the next decision. In experimental decision-making
[Settles (2009)](#bib.bib20); [King et al. (2009)](#bib.bib21); [Roohani
et al. (2025)](#bib.bib22), a predictor ranks candidate interventions,
but their effects become known only after measurement. Historical data
provide reusable knowledge, yet a new objective may have only a few
dozen functional measurements. These results can expose task-specific
errors in an otherwise useful model. The challenge is therefore not only
to evaluate predictions, but to incorporate evidence into the deployed
predictor so subsequent decisions reflect what has been learned.
Cellular perturbation research [Cui et al. (2024)](#bib.bib16); [Roohani
et al. (2023)](#bib.bib17) and virtual cells [Bunne et al.
(2024)](#bib.bib5) provide a demanding example.

#### From model editing to weight-space programming

Model-editing research studies targeted corrections to neural parameters
[Sinitsin et al. (2020)](#bib.bib3); [Mitchell et al.
(2022)](#bib.bib4); [De Cao et al. (2021)](#bib.bib12); [Meng et al.
(2022)](#bib.bib13); [Meng et al. (2023)](#bib.bib14). Takehi et al.
introduced weight-space programming (WSP), demonstrating language models
interpreting and rewriting weights according to natural-language
objectives in specified settings [Takehi et al. (2026)](#bib.bib1). This
opens a possibility: can an LLM program how a deployed model should
change when experimental evidence arrives? Beyond producing one
parameter correction, such a program could connect successive
measurements to the model’s future behavior.

#### Where the improvement loop lives

Recursive self-improvement (RSI) motivates systems such as STOP, whose
improvement program revises itself [Zelikman et al. (2024)](#bib.bib2).
In WeightLoop, the sequence is concrete: the LLM writes an editor once;
each returned assay batch lets that editor revise the predictor; the
revised predictor recommends the next batch. The editor code and LLM
remain fixed during this loop. New measured outcomes determine the
parameter changes, without another LLM call or gradient retraining. The
scientific predictor is the object of this improvement loop.

#### The WeightLoop workflow

Given a task objective and model, GPT-6 Astra [OpenAI
(2026)](#bib.bib23) identifies task-relevant mutable parameters and
writes a bounded editing program. When feedback arrives, the program
evaluates discrepancies between predictions and measurements, constructs
candidate changes, and selects a validated update. Changes are written
into the checkpoint, which reloads through its original inference
interface. The updated predictor guides the next decision, and the
process repeats as measurements arrive (Figure
[1](#S1.F1 "Figure 1 ‣ The WeightLoop workflow ‣ 1. Introduction ‣ WeightLoop: Weight-Space Programming with Experimental Feedback")).
Feedback therefore changes the model itself, beyond adjusting one
recommendation list.

We study two complementary settings: single-round ranking and sequential
discovery. Cellular growth, migration, autophagy, and LDL-uptake
measurements supply concrete feedback across objectives. Here, biology
supplies measurable outcomes for testing a reusable editing workflow.
Neural, linear, and tree-based predictors offer different parameter
structures for the same workflow. Recorded measurements enable offline
replay to test whether updates improve subsequent decisions and remain
usable after checkpoint writeback and reload. Together, these
experiments demonstrate how WSP can turn returned measurements into an
ongoing source of model improvement.

## 2. WeightLoop

### 2.1. Fixed editor, updating predictor

GPT-6 Astra [OpenAI (2026)](#bib.bib23) constructs the editor from the
task objective, model implementation, parameter structure, and available
feedback. It produces an executable editor specifying mutable
parameters, candidate updates, validation rules, and model saving. The
editor uses measured support to update the predictor through repeated
numerical execution, with no additional LLM calls. For original
parameters $`\theta_{0}`$, editor $`\mathcal{E}_{\mathcal{I}}`$, and
accumulated support $`S_{t}=\{(g_{i},x_{i},y_{i})\}`$ recording
identities, inputs, and measured outcomes,

|     |     |     |     |
| --- | --- | --- | --- |
| (1) |     |

````math
\Delta_{t}=\mathcal{E}_{\mathcal{I}}(\theta_{0},S_{t}),\qquad\theta_{t}=\theta_{0}+\Delta_{t},\qquad A_{t+1}=\mathcal{D}(f_{\theta_{t}}),
``` |  |

where $`\mathcal{D}`$ applies the remaining candidates, budget, and
decision rule; $`\Delta_{t,j}=0`$ outside $`\mathcal{I}`$. Updates are
constructed on support-training records, selected on support-validation
records, then reconstructed on all support. No qualifying improvement
gives $`\Delta_{t}=0`$. Each update starts from $`\theta_{0}`$, so
patches do not compound. Only observed outcomes enter support; outcomes
of unmeasured candidates and the permanent test set are excluded.

#### A concrete program-design choice

The neural editor exposes the functional output weights as its update
interface. The model code separates a reusable molecular encoder from a
linear functional readout: changing one readout weight alters that
feature’s contribution while preserving both the representation and the
RNA auxiliary branches. This structure also makes a candidate change
exactly computable from cached activations, so the editor can test
individual connections without backpropagation. Its diagnostic asks
whether weakening a connection improves the ordering of measured genes;
its validation combines a pairwise ranking loss with top-budget utility.
For coefficient and leaf-value updates, the implemented objective is
instead residual prediction error. Thus the program construction ties
the mutable interface and validation criterion to the model structure
and task objective. Once those choices are encoded, measurements
determine the affected coordinates and accepted parameter values on each
execution.

### 2.2. Neural output-weight editing

A ReLU MLP encodes static GO [The Gene Ontology Consortium
(2023)](#bib.bib15), scGPT [Cui et al. (2024)](#bib.bib16), and MAP-KG
features, with availability indicators, as
$`h_{\phi}(x_{g})\in\mathbb{R}^{128}`$. Its original fit used functional
labels and historical RNA auxiliary supervision; candidate-specific
perturbation RNA is not an inference input. The functional prediction in
assay units is

|     |     |                                                           |     |
|-----|-----|-----------------------------------------------------------|-----|
| (2) |     |
             ``` math
             f_{\theta}(g)=s_{y}\{w^{\top}h_{\phi}(x_{g})+b\}+\mu_{y}.
             ```                                                        |     |

Only the 128 entries of $`w`$ are editable. The encoder, bias, input
transform, original 25-label output scaler $`(\mu_{y},s_{y})`$, RNA
head, and source parameters remain fixed; the edit reweights the
existing representation.

#### Diagnose, select, and write

Feedback consists of newly measured gene effects. If a hidden feature
gives high scores to genes with weak measured effects, attenuating its
output connection can reduce ranking errors. The editor tests this
possibility against the observed measurements. Using the original
25-label output scaler, let $`p_{i}=(f_{\theta}(g_{i})-\mu_{y})/s_{y}`$
and $`\tilde{y}_{i}=(y_{i}-\mu_{y})/s_{y}`$. Let
$`a_{ij}=|\tilde{y}_{i}-\tilde{y}_{j}|`$ and
$`s_{ij}=\operatorname{sgn}(\tilde{y}_{i}-\tilde{y}_{j})`$. The support
loss is

|  |  |  |  |
|----|----|----|----|
| (3) |  |
``` math
\mathcal{L}(p,\tilde{y})=\frac{\sum_{i<j}a_{ij}\log\{1+\exp[-s_{ij}(p_{i}-p_{j})]\}}{\sum_{i<j}a_{ij}}.
``` |  |

The logistic comparison follows learning-to-rank formulations [Burges et
al. (2005)](#bib.bib6). We cache $`h_{i}`$ and probe each connection by
halving $`w_{j}`$, which changes standardized predictions by exactly
$`-0.5w_{j}h_{ij}`$. Its diagnostic gain is the resulting decrease in
$`\mathcal{L}`$. The top positive gains above $`10^{-12}`$ determine at
most $`k`$ coordinates $`S_{k}`$ for six update settings:
$`k\in\{4,8,16\}`$ and $`\alpha\in\{0.25,0.5\}`$,

|     |     |                                                       |     |
|-----|-----|-------------------------------------------------------|-----|
| (4) |     |
             ``` math
             w^{\prime}_{j}=w_{j}(1-\alpha\mathbf{1}[j\in S_{k}]).
             ```                                                    |     |

Equal-label pairs have zero weight; an all-tied set has zero loss.
Diagnostic and update ties follow fixed orders. Three identity-based
support folds select the lowest mean validation loss subject to
non-decreasing mean validation utility ($`\mathrm{BU}@10`$ for
single-round ranking). Each fold diagnoses coordinates using only its
training genes. The accepted update is rebuilt on all feedback and
written to the model’s output-weight vector. Its effect is
gene-specific: $`\delta f(g)=s_{y}\sum_{j}\delta w_{j}h_{j}(x_{g})`$, so
it can change ordering while preserving the learned representation.

Matched controls permute the same diagnostic update across coordinates.
For a given support set and update setting, they preserve the number and
norm of changes and receive the same six-setting validation opportunity.
Single-round ranking uses three fixed permutations; sequential discovery
uses one and may acquire different subsequent support.

### 2.3. Coefficient and leaf-value editing

With standardized feedback $`\tilde{y}_{i}`$ and original prediction
$`p_{0i}`$, define residuals $`r_{i}=\tilde{y}_{i}-p_{0i}`$. Ridge
[Hoerl and Kennard (1970)](#bib.bib18) adds
$`\delta w=(X_{c}^{\top}X_{c}+\lambda I)^{-1}X_{c}^{\top}r_{c}`$ and
$`\delta b=\bar{r}-\bar{x}^{\top}\delta w`$, where centering uses the
fitting support, $`\lambda=m\gamma`$, and $`\gamma\in\{0.1,1,10,100\}`$.
XGBoost [Chen and Guestrin (2016)](#bib.bib19) retains all 300 tree
structures and revises each supported prediction leaf by
$`v^{\prime}_{\ell}=v_{\ell}+\alpha\sum_{i\in\ell}r_{i}/[300(n_{\ell}+5)]`$,
with $`\alpha\in\{0.1,0.25,0.5\}`$. Here $`m`$ is the support size;
$`n_{\ell}`$ counts support records reaching leaf $`\ell`$. Unsupported
leaves remain unchanged. Three-fold support MSE selects these updates;
no improvement retains the original model. These supervised analytical
operators change coefficients or native leaf values while retaining
input/output transforms and inference code.

## 3. Evaluation and Results

We evaluate single-round ranking and sequential discovery using public
functional screens. Editor design used DepMap experiments; the resulting
rules were fixed for HL60 and sequential evaluation. Each prediction or
batch choice precedes access to its evaluation outcomes. Tables present
the complete endpoint–budget grid under matched feedback budgets.

### 3.1. Single-round ranking

The single-round experiment asks whether one feedback update improves
subsequent ranking. It covers HepG2/Jurkat negative Chronos effects from
DepMap 24Q4 [Broad DepMap (2024)](#bib.bib11); [Dempster et al.
(2021)](#bib.bib7), HL60 proliferation, and serum-gradient migration
inhibition [Belliveau et al. (2023)](#bib.bib8). Five gene partitions
and two seeds per endpoint give 40 initial $`n=25`$ models. Feedback is
the 75 genes in the corresponding $`n=100`$ training set but outside the
initial 25; query genes are excluded from both. All six arms share the
query pool. The existing $`n=100`$ reference and initial models were
each fitted for 1600 updates; editing maintains the $`n=25`$ model using
the additional measurements.

For budget $`B=20,50`$, let $`d_{r}`$ be $`1/\log_{2}(r+1)`$ normalized
over all $`B`$ positions. We report

|  |  |  |  |
|----|----|----|----|
| (5) |  |
``` math
U_{B}=\sum_{r=1}^{B}d_{r}y_{\pi_{r}},\qquad\mathrm{BU}_{B}=\frac{U_{B}-\bar{y}}{U_{B}^{\mathrm{oracle}}-\bar{y}}.
``` |  |

where zero is the same-pool random expectation and one the oracle.
Paired summaries average seeds within each gene partition of a study.

Edited utility exceeds Random in all eight settings and improves over
Original in seven (Table
[1](#S2.T1 "Table 1 ‣ 2.3. Coefficient and leaf-value editing ‣ 2. WeightLoop ‣ WeightLoop: Weight-Space Programming with Experimental Feedback")).
HepG2 improves in all five paired folds at both budgets, connecting the
mean gains to consistent within-task improvements.

### 3.2. Sequential discovery

Sequential discovery reuses 15 initial 25-label models for LC3/NBR1
autophagic flux [Shoemaker et al. (2019)](#bib.bib9) and reduced LDL
uptake in HuH7 cells with lipoprotein-rich medium [Emmer et al.
(2021)](#bib.bib10): three endpoints, five gene folds, and one seed.
Unchanged, targeted-edit, and permuted-edit policies each acquire five
batches of 20 genes. Each batch is chosen before its measurements become
available. Later edits use only that policy’s acquired feedback; the
initial 25 labels influence $`\theta_{0}`$ but do not reenter $`S_{t}`$.
Each patch is reconstructed from $`\theta_{0}`$, with a validation guard
at $`B=\min(5,n_{\mathrm{validation}}-1)`$.

For acquired set $`A_{K}`$ from candidate pool $`C`$, discovery is
$`D_{K}=(\sum_{g\in A_{K}}y_{g}-K\bar{y}_{C})/(\sum_{g\in\mathrm{Top}_{K}(C)}y_{g}-K\bar{y}_{C})`$.
Its oracle normalization changes with $`K`$, so policies are compared at
the same acquisition count. Permanent-set predictions are evaluated
after all 45 trajectories finish, separately from discovery in the
queried pool.

Edited selection improves mean $`D_{100}`$ over both controls in all
three tasks, with 4/5, 4/5, and 3/5 positive paired folds (Table
[2](#S3.T2 "Table 2 ‣ 3.2. Sequential discovery ‣ 3. Evaluation and Results ‣ WeightLoop: Weight-Space Programming with Experimental Feedback")).
Identical first batches locate these differences in later
feedback-driven selections. Permanent-set $`\mathrm{BU}@50`$ increases
by 0.0254, 0.0098, and 0.0096 (Figure
[2](#S1.F2 "Figure 2 ‣ The WeightLoop workflow ‣ 1. Introduction ‣ WeightLoop: Weight-Space Programming with Experimental Feedback")e).
Of 75 targeted updates, 56 change weights, at most 16 each; the final
update serves only permanent-set prediction.

The paired panels connect these aggregate improvements to actual model
updates. Discovery measures the value of genes selected for assay,
whereas permanent-set utility measures ranking of genes that never
supplied feedback. Their joint mean improvement links the selection loop
to predictions beyond the acquired set. The edit-count panel makes the
mechanism visible: individual feedback batches can retain the original
model or select different numbers of coordinates. Thus the fixed program
translates changing evidence into adaptive model states, rather than
applying the same perturbation after every batch.

#### Persistent model updates

In a deployed predictor with 3,604,535 network parameters, the HepG2
update changes only 16 weights (0.00044%) and reproduces all 914 edited
predictions exactly after native checkpoint reload. These are 16 of the
128 functional output weights; the network count includes the encoder
and RNA head. Both remain unchanged, as do the separately stored source
adapters. Reordered queries also reproduce all saved scores, and a
single-gene inference check passes with the original input/output
transforms. The update therefore persists in the predictor and serves
subsequent queries through the original inference interface.

## 4. Conclusion

WeightLoop converts experimental feedback into persistent model updates.
A fixed, LLM-constructed editor selects parameter changes from observed
measurements, and the updated predictor guides the next decision.
Ranking, sequential acquisition, and multiple parameter interfaces
demonstrate how WSP connects accumulating scientific evidence to future
experimental choices through the original prediction interface.

## Ethical Considerations

The study uses public functional-screen measurements, with no new
human-subject experiments or personal data collection. Recommendations
guide research assays; biological efficacy requires validation in the
intended setting. Retaining the original model makes parameter updates
reversible and supports traceable deployment.
````
