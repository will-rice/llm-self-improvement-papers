# Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning

Haozhe Chi Affiliation: Peking University    Song Jin
Affiliation: Renmin University of China    Yang Jin Affiliation: Peking
University    Yadong Mu Affiliation: Peking University

###### Abstract

Long-video embedding requires capturing sparse query-relevant evidence
under a limited visual-token budget. Uniform sampling can miss brief
events in videos spanning minutes or hours, whereas encoding more frames
in a single context increases memory and computation. We introduce
Query-Aware Streaming Latent Reasoning (QASLR), a post-training
framework that accumulates evidence across clips while keeping the
embedding size fixed. QASLR selects a bounded set of frames, restores
their temporal order, and processes them clip by clip with a
vision-language backbone. A compact set of persistent think tokens
cross-attends to each clip’s features, while an embed token reads out a
normalized representation after every update. This design integrates
evidence across multiple backbone calls without requiring all selected
frames to share a single context. Training combines final contrastive
learning, step-wise contrastive supervision, and final-embedding
self-distillation. Intermediate supervision trains partial-video
readouts for retrieval, while self-distillation regularizes them toward
the final representation. Query-aware selection produces
query-conditioned representations for candidate-set scoring and
reranking, whereas query-independent selection enables reusable corpus
indexing. Under the full training recipe, HourVideo retrieval Hit@1
increases from 54.2 to 70.7 and from 57.4 to 72.8 for 2B and 8B
Qwen3-VL-Embedding backbones, respectively. Gains extend to the
evaluated moment-retrieval and video-QA tasks, and the streaming head
transfers to a second Qwen-family embedding backbone. These results
support streaming latent aggregation as an effective approach to
integrating long-video evidence into fixed-dimensional representations.

## 1 Introduction

Multimodal embedding models provide a common representation interface
for retrieving, organizing, and comparing text, images, and
videos ([Radford et al., 2021](#bib.bib40); [Jia et al.,
2021](#bib.bib23); [Girdhar et al., 2023](#bib.bib14); [Meng et al.,
2026](#bib.bib38)). Their fixed-dimensional outputs are attractive for
large collections because candidate representations can be indexed once
and searched efficiently ([Johnson et al., 2021](#bib.bib28); [Karpukhin
et al., 2020](#bib.bib29)). Extending this interface to long videos is
difficult, however, because the visual input grows with duration whereas
the model’s visual-token budget remains bounded ([Zhang et al.,
2025a](#bib.bib58); [Shen et al., 2025](#bib.bib42)). A video may span
tens of minutes, while the evidence that determines its relevance to a
query may occupy only a few seconds ([Chandrasegaran et al.,
2024](#bib.bib6); [Wu et al., 2024](#bib.bib49)). Consequently, the
quality of a long-video embedding depends not only on semantic
alignment, but also on whether the model observes the relevant evidence
and retains it while processing the rest of the sequence.

Existing pipelines usually address the input constraint by sampling a
fixed number of frames. Uniform sampling provides broad temporal
coverage at low cost, but can miss brief relevant events when a fixed
frame budget is spread across a longer video ([Yu et al.,
2023](#bib.bib52); [Tang et al., 2025](#bib.bib44)). Query-aware
selection concentrates a limited budget on semantically relevant
frames ([Wang et al., 2025b](#bib.bib47); [Tang et al.,
2025](#bib.bib44)), but it does not by itself solve the representation
problem. Selected frames may be temporally fragmented, and encoding all
of them in one context couples the frame budget to the backbone’s memory
cost. Moreover, query-aware selection changes the retrieval setting:
because the selected frames depend on the query, the resulting video
representation cannot generally be reused as a single query-independent
corpus embedding. A practical system must therefore distinguish
query-independent indexing from query-conditioned candidate scoring, as
in embedding-and-reranking pipelines ([Li et al., 2026](#bib.bib35)).

A second issue concerns how selected evidence is aggregated.
Video-retrieval encoders have explored joint spatiotemporal encoding and
pooling of frame-level representations ([Bain et al., 2021](#bib.bib4);
[Xu et al., 2021](#bib.bib51); [Luo et al., 2022](#bib.bib36)), while
memory-augmented video models explicitly retain information across
observations ([Song et al., 2024](#bib.bib43); [He et al.,
2024](#bib.bib18)). These developments motivate studying how a compact
streaming state can be trained to produce useful retrieval embeddings
throughout a video. This issue is particularly important when relevant
observations are distributed across time or when the number of selected
frames still exceeds the context that can be processed economically in
one forward pass. We therefore study long-video evidence accumulation
through a bounded latent state, building on latent bottlenecks and
recurrent memory architectures ([Jaegle et al., 2021](#bib.bib21);
[Bulatov et al., 2022](#bib.bib5); [Hutchins et al., 2022](#bib.bib20)).

We propose Query-Aware Streaming Latent Reasoning (QASLR), a
post-training framework for long-video embeddings. As shown in
Figure [1](#S1.F1 "Figure 1 ‣ 1 Introduction ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning"),
QASLR processes selected frames as chronologically ordered clips, using
learnable think tokens to accumulate clip-level evidence in a persistent
latent memory. An embed token reads out a fixed-dimensional
representation after each step. Query-independent frame selection
enables reusable video indexing, whereas query-aware selection produces
query-conditioned representations for a bounded candidate set, such as
candidates returned by a first-stage retriever.

Training combines a final contrastive loss with step-wise
supervision ([Lee et al., 2015](#bib.bib32)) and self-distillation
toward the final embedding ([Zhang et al., 2019](#bib.bib54)), aligning
both intermediate and complete representations with their targets.
Following MMEB and MMEB-V2 ([Jiang et al., 2025](#bib.bib26); [Meng et
al., 2026](#bib.bib38)), a unified query–positive interface supports
retrieval, moment retrieval, classification, and multiple-choice video
question answering (QA). Interleaved sub-batching groups compatible
input formats during mixed-task training and is evaluated separately
from streaming aggregation.

The full QASLR training recipe improves both 2B and 8B
Qwen3-VL-Embedding backbones ([Li et al., 2026](#bib.bib35)), increasing
HourVideo retrieval Hit@1 from 54.2 to 70.7 and from 57.4 to 72.8,
respectively, relative to the original checkpoints. Gains extend to the
evaluated moment-retrieval and video-QA tasks, while experiments on
RzenEmbed ([Jian et al., 2025](#bib.bib24)) demonstrate applicability to
a second Qwen-family embedding backbone.

Our contributions are threefold:

- •
  We introduce QASLR, a streaming framework that decouples temporal
  coverage from representation size for long-video embedding. A
  persistent latent memory incrementally integrates temporally ordered
  clips and emits a fixed-dimensional embedding without placing all
  selected frames in one backbone context.
- •
  We design a streaming post-training objective that combines final
  contrastive learning, step-wise contrastive supervision, and
  final-embedding self-distillation. This objective directly supervises
  intermediate representations through the same query–positive interface
  used across retrieval, classification, and video QA.
- •
  We evaluate QASLR on nine long-video tasks using 2B and 8B
  Qwen3-VL-Embedding models and demonstrate within-family transfer to
  RzenEmbed 7B. The full QASLR recipe improves every reported task over
  the original checkpoints.

## 2 Related Work

### 2.1 Multimodal Embeddings and Long-Video Processing

Contrastive learning supports shared image–text and multimodal
representations ([Radford et al., 2021](#bib.bib40); [Jia et al.,
2021](#bib.bib23); [Zhai et al., 2023](#bib.bib53); [Girdhar et al.,
2023](#bib.bib14)), with temporal encoders and aggregation extending
this approach to video ([Bain et al., 2021](#bib.bib4); [Xu et al.,
2021](#bib.bib51); [Luo et al., 2022](#bib.bib36)). Instruction-guided
retrieval and VLM-based embeddings unify diverse retrieval tasks ([Wei
et al., 2024](#bib.bib48); [Jiang et al., 2024](#bib.bib25); [Jiang et
al., 2025](#bib.bib26); [Zhang et al., 2025b](#bib.bib57)), with recent
models supporting video and document inputs ([Meng et al.,
2026](#bib.bib38); [Jian et al., 2025](#bib.bib24); [Li et al.,
2026](#bib.bib35)). Long-video benchmarks highlight challenges in
temporal coverage and reasoning ([Fu et al., 2025](#bib.bib12); [Zhou et
al., 2025](#bib.bib59); [Wang et al., 2025a](#bib.bib46)). Existing
approaches extend context ([Zhang et al., 2025a](#bib.bib58)), compress
visual tokens ([Shen et al., 2025](#bib.bib42)), aggregate clip
descriptions ([Zhang et al., 2024a](#bib.bib56)), select query-relevant
frames ([Yu et al., 2023](#bib.bib52); [Wang et al., 2025b](#bib.bib47);
[Tang et al., 2025](#bib.bib44)), or allocate frame-wise
resolution ([Jin et al., 2026](#bib.bib27)). Temporally grounded
datasets provide localized language–video supervision ([Krishna et al.,
2017](#bib.bib31); [Gao et al., 2017](#bib.bib13); [Lei et al.,
2021](#bib.bib33)). Complementing input selection and compression, QASLR
accumulates selected clip evidence into a fixed-dimensional embedding.

### 2.2 Streaming Latent Reasoning and Adaptive Computation

Latent-query architectures compress inputs through
cross-attention ([Jaegle et al., 2021](#bib.bib21); [Jaegle et al.,
2022](#bib.bib22); [Alayrac et al., 2022](#bib.bib1); [Li et al.,
2023](#bib.bib34)), while recurrence and memory tokens carry information
across sequence blocks ([Dai et al., 2019](#bib.bib10); [Bulatov et al.,
2022](#bib.bib5); [Hutchins et al., 2022](#bib.bib20)). Video models
similarly retain historical information ([Song et al.,
2024](#bib.bib43); [He et al., 2024](#bib.bib18)) and support streaming
interaction ([Chen et al., 2024](#bib.bib8); [Zhang et al.,
2024b](#bib.bib55)). Related approaches introduce computation before
prediction through pause tokens ([Goyal et al., 2024](#bib.bib15)),
continuous hidden states ([Hao et al., 2025](#bib.bib17)), or explicit
reasoning traces for embeddings ([Cui et al., 2026](#bib.bib9)).
Building on these ideas, QASLR updates persistent latent memory across
clips and contrastively supervises intermediate embedding readouts.
Early-exit methods adapt computation using intermediate
predictions ([Xin et al., 2020](#bib.bib50); [Elbayad et al.,
2020](#bib.bib11); [Schuster et al., 2022](#bib.bib41)). QASLR’s
optional exit instead controls the number of observed clips.

Figure 2: QASLR architecture, training objectives, and optional

## 3 Method

### 3.1 Overview and Retrieval Settings

Figure [2](#S2.F2 "Figure 2 ‣ 2.2 Streaming Latent Reasoning and Adaptive Computation ‣ 2 Related Work ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning")
summarizes QASLR. A fixed set of think tokens accumulates clip evidence,
and an embed token reads the latent state after each update. Streaming
refers to aggregation over preselected clips, not necessarily online
frame selection from an unseen video.

Following unified multimodal embedding frameworks ([Wei et al.,
2024](#bib.bib48); [Jiang et al., 2025](#bib.bib26); [Meng et al.,
2026](#bib.bib38)), we formulate all tasks as query–positive pairs
$`(A_{i},B_{i})`$. The query $`A_{i}`$ may contain text, an image–text
input, or a video–question input, while $`B_{i}`$ may be a video,
temporal window, class label, or answer. Non-video and short-video
inputs retain the original embedding pathway. Long videos use the
proposed streaming pathway.

QASLR supports two retrieval settings, distinguishing reusable dense
representations ([Karpukhin et al., 2020](#bib.bib29)) from
pair-conditioned scoring ([Li et al., 2026](#bib.bib35)). In the
_indexable setting_, frame selection is query-independent, and each
candidate video produces one reusable embedding $`\mathbf{v}_{j}`$. In
the _query-conditioned setting_, frame selection and video encoding
depend on query $`A_{i}`$, producing $`\mathbf{v}_{ij}`$. The similarity
score is

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
s_{ij}=\begin{cases}\mathbf{q}_{i}^{\top}\mathbf{v}_{j}/\tau,&\text{indexable},\\[2.0pt]
\mathbf{q}_{i}^{\top}\mathbf{v}_{ij}/\tau,&\text{query-conditioned},\end{cases}
``` |  | (1) |

where $`\mathbf{q}_{i}`$ is the normalized query embedding and $`\tau`$
is the contrastive temperature. Query-conditioned scoring is restricted
to a bounded candidate set, such as the output of a first-stage
retriever. Every candidate for a given query is selected and encoded
using the same conditioning procedure.

### 3.2 Streaming Video Encoding

Query-guided frame selection has been explored for video QA ([Yu et al.,
2023](#bib.bib52); [Tang et al., 2025](#bib.bib44)). QASLR treats
selection as an input stage: for a long video $`V`$ and optional
conditioning input $`c`$, the selector returns an ordered sequence of at
most $`K_{\max}`$ indices:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{I}(V,c)=(k_{1},\ldots,k_{K_{V}}),\qquad k_{1}<\cdots<k_{K_{V}},\qquad K_{V}\leq K_{\max}.
``` |  | (2) |

The selected frames are restored to chronological order and divided into
clips:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
X(V,c)=[C_{1},\ldots,C_{T}],\qquad T=\left\lceil\frac{K_{V}}{L}\right\rceil,
``` |  | (3) |

where $`L`$ is the number of frames per clip. We use $`K_{\max}=128`$,
with $`L=16`$ at full budget and fewer frames per clip for shorter
inputs. Padding in the final clip is excluded by the attention mask.
Ground-truth labels and temporal boundaries are not provided to the
frame selector during evaluation.

At step $`t`$, the vision-language backbone $`F_{\theta}`$, instantiated
from Qwen3-VL-Embedding ([Li et al., 2026](#bib.bib35)) built on
Qwen3-VL ([Bai et al., 2025](#bib.bib3)), encodes the current clip
together with the task instruction and optional conditioning input:

|     |                                                                 |     |     |
|-----|-----------------------------------------------------------------|-----|-----|
|     |
       ``` math
       U_{t}=F_{\theta}(C_{t},c)\in\mathbb{R}^{B\times S_{t}\times D},
       ```                                                              |     | (4) |

where $`B`$, $`S_{t}`$, and $`D`$ denote the batch size, valid sequence
length, and backbone hidden dimension.

To bound the input size of the streaming head, the valid hidden states
are compressed into at most $`M`$ evidence tokens:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
E_{t}=\operatorname{Compress}(U_{t})\in\mathbb{R}^{B\times M\times D}.
``` |  | (5) |

The compression operator uses cosine similarity to compress valid hidden
states after masking. We use $`M=256`$ and $`N=32`$ think tokens by
default. Evidence banks with fewer than $`M`$ states are padded and
masked in cross-attention. Clips may share a backbone forward pass, but
their evidence banks and latent states remain independent.

### 3.3 Streaming Latent Memory and Embedding Readout

Motivated by compact latent bottlenecks ([Jaegle et al.,
2021](#bib.bib21)) and recurrent memory tokens ([Bulatov et al.,
2022](#bib.bib5)), QASLR maintains $`N`$ learnable think tokens as a
persistent latent memory:

|     |                                         |     |     |
|-----|-----------------------------------------|-----|-----|
|     |
       ``` math
       H_{0}\in\mathbb{R}^{B\times N\times D}.
       ```                                      |     | (6) |

The memory is initialized once for each video and is not reset between
clips. At streaming step $`t`$, the previous memory attends to the
current clip evidence using multi-head attention ([Vaswani et al.,
2017](#bib.bib45)) and layer normalization ([Ba et al.,
2016](#bib.bib2)):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widetilde{H}_{t}=\operatorname{LN}\left[H_{t-1}+\operatorname{MHA}\left(\operatorname{LN}(H_{t-1}),\operatorname{LN}(E_{t}),\operatorname{LN}(E_{t})\right)\right],
``` |  | (7) |

|  |  |  |  |
|----|----|----|----|
|  |
``` math
H_{t}=\operatorname{LN}\left[\widetilde{H}_{t}+\operatorname{FFN}(\widetilde{H}_{t})\right].
``` |  | (8) |

The recurrent update allows the model to integrate new visual evidence
while retaining information from earlier clips. Because the number of
think tokens remains fixed, the size of the persistent state does not
grow with video duration.

After each update, a learnable embed token $`e`$ reads the current
memory through query-based attention pooling, as in Perceiver
IO ([Jaegle et al., 2022](#bib.bib22)):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
r_{t}=\operatorname{MHA}(e,H_{t},H_{t}),\qquad\mathbf{z}_{t}=\frac{Wr_{t}}{\|Wr_{t}\|_{2}},
``` |  | (9) |

where $`W`$ projects the readout into the shared $`d`$-dimensional
embedding space. The streaming pathway returns

|     |                                                |     |      |
|-----|------------------------------------------------|-----|------|
|     |
       ``` math
       Z(V,c)=(\mathbf{z}_{1},\ldots,\mathbf{z}_{T}),
       ```                                             |     | (10) |

and uses $`\mathbf{z}_{T}`$ as the final video representation.
Intermediate embeddings expose the representation after each observed
clip and are used by the auxiliary training objectives below.

### 3.4 Training Objective

For a batch of $`B`$ query–positive pairs, let $`\mathbf{a}_{i}`$ denote
the final query-side embedding and $`\mathbf{b}_{ij}`$ the
representation of candidate $`B_{j}`$ when scored against $`A_{i}`$. In
the indexable setting, $`\mathbf{b}_{ij}=\mathbf{b}_{j}`$. In the
query-conditioned setting, each candidate is encoded under $`A_{i}`$.
The final loss uses an InfoNCE-style contrastive objective ([van den
Oord et al., 2018](#bib.bib39); [Radford et al., 2021](#bib.bib40)):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}_{\mathrm{final}}=\operatorname{CE}(\widetilde{S},y),\qquad s_{ij}=\frac{\mathbf{a}_{i}^{\top}\mathbf{b}_{ij}}{\tau},\qquad y_{i}=i.
``` |  | (11) |

Query-independent embeddings can be gathered across workers to enlarge
the negative pool ([Chen et al., 2020](#bib.bib7)). Query-conditioned
scores instead require each candidate to be encoded under the current
query. Embeddings conditioned on another query are not interchangeable.
Valid co-positives from the same video are masked from the denominator,
while the paired target remains the sole positive ([Khosla et al.,
2020](#bib.bib30); [Jian et al., 2025](#bib.bib24)).

Here, $`\widetilde{S}`$ equals $`S`$ with excluded co-positive logits
set to $`-\infty`$. Following deep supervision ([Lee et al.,
2015](#bib.bib32)), we also train intermediate embeddings. Let
$`\mathcal{B}_{t}`$ contain pairs with valid step-$`t`$ readouts on all
streaming sides. Non-streaming embeddings are reused. The step-wise loss
is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}_{\mathrm{step}}=\frac{\sum_{t}|\mathcal{B}_{t}|\operatorname{CE}(\widetilde{S}^{(t)},y^{(t)})}{\sum_{t}|\mathcal{B}_{t}|},\qquad s_{ij}^{(t)}=\frac{\left(\mathbf{a}_{i}^{(t)}\right)^{\top}\mathbf{b}_{ij}^{(t)}}{\tau}.
``` |  | (12) |

At each step, invalid pairs and padded readouts are excluded, targets
are reindexed within $`\mathcal{B}_{t}`$, and the same co-positive mask
is applied. Text-to-video retrieval reuses text embeddings. Video QA
reuses answer embeddings.

To regularize the streaming trajectory, we adapt knowledge
distillation ([Hinton et al., 2015](#bib.bib19)) and
self-distillation ([Zhang et al., 2019](#bib.bib54)) by using the final
embedding as a stop-gradient teacher:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}_{\mathrm{distill}}=\frac{1}{Z}\sum_{i\in\mathcal{S}}\sum_{t=1}^{T_{i}-1}\left[1-\left(\mathbf{z}_{i}^{(t)}\right)^{\top}\operatorname{sg}\left(\mathbf{z}_{i}^{(T_{i})}\right)\right],
``` |  | (13) |

where $`\mathcal{S}`$ contains the streamed inputs, $`T_{i}`$ is the
number of valid steps, and $`Z=\sum_{i\in\mathcal{S}}(T_{i}-1)`$. When
$`Z=0`$, we define $`\mathcal{L}_{\mathrm{distill}}=0`$. Unlike the
moving-average target network in BYOL ([Grill et al.,
2020](#bib.bib16)), the teacher here is the detached final-step
embedding from the same forward trajectory.

The complete objective is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}=\mathcal{L}_{\mathrm{final}}+\lambda_{\mathrm{step}}\mathcal{L}_{\mathrm{step}}+\lambda_{\mathrm{distill}}\mathcal{L}_{\mathrm{distill}}.
``` |  | (14) |

Mixed-task training combines retrieval, moment retrieval,
classification, and video QA through the same query–positive interface.
Interleaved sub-batching groups examples with compatible task and input
formats. Their losses are weighted by the corresponding sub-batch sizes,
and gradients are accumulated before one optimizer update.

Only the streaming head is trainable in the QASLR experiments. The
backbone is frozen. The appendix describes data processing,
computational complexity, and the optional early-exit mechanism.

## 4 Experiments

### 4.1 Experimental Setup

#### Tasks and metrics.

We evaluated nine long-video embedding tasks spanning classification,
video retrieval, moment retrieval, and multiple-choice QA. These
comprised HourVideo ([Chandrasegaran et al., 2024](#bib.bib6))
classification, retrieval, and moment retrieval, LVBench ([Wang et al.,
2025a](#bib.bib46)) retrieval and QA, LongVideoBench ([Wu et al.,
2024](#bib.bib49)) moment retrieval, MovieChat QA ([Song et al.,
2024](#bib.bib43)), EgoSchema ([Mangalam et al., 2023](#bib.bib37)), and
TimeScope ([Zohar et al., 2025](#bib.bib60)). We report Hit@1/Hit@5 for
classification and retrieval, except LongVideoBench moment retrieval
(Hit@1 only), and accuracy for QA. All reported gains are in percentage
points.

#### Models and training.

We compared original Qwen3-VL-Embedding ([Li et al., 2026](#bib.bib35))
checkpoints, single-round post-training, and QASLR at 2B and 8B scales.
Both post-training methods used the same training data. QASLR selected
at most 128 frames, using 16-frame clips at full budget and shorter
clips for fewer frames. Training combined final contrastive learning,
step-wise contrastive supervision, and final-embedding
self-distillation. Only the streaming head was trainable in QASLR. The
backbone remained frozen.

#### Mixed-task data processing.

All examples used a common query–positive format. Retrieval paired a
query with a video or candidate moment, whereas QA paired a
video–question input with its answer text. Selected frames were stored
as indices and decoded from source videos on demand. Interleaved
sub-batching grouped compatible task and input formats, with its effects
examined in
Section [4.4](#S4.SS4 "4.4 Effect of Interleaved Sub-Batching ‣ 4 Experiments ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning").

The original checkpoints establish performance before long-video
post-training. Single-round post-training uses the mixed-task data
without recurrent latent aggregation.

### 4.2 Main Results on Qwen3-VL-Embedding

In
Table [1](#S4.T1 "Table 1 ‣ Comparison protocol. ‣ 4.1 Experimental Setup ‣ 4 Experiments ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning"),
QASLR achieved the highest Hit@1 on all five retrieval-style tasks at
both scales. Mean Hit@1 increased from 45.8 to 53.5 at 2B and from 47.2
to 54.8 at 8B, compared with single-round averages of 46.9 and 48.0. The
similar gains over the original checkpoints show that improvement was
not limited to one model scale.

#### Video retrieval and classification.

The largest gains occurred on full-video retrieval. QASLR achieved
70.7/92.5 HourVideo Hit@1/Hit@5 at 2B and 72.8/95.8 at 8B, exceeding the
original checkpoints by 16.5 and 15.4 Hit@1 points, respectively.
Relative to single-round post-training, the corresponding Hit@1 gains
were 15.7 and 15.0 points. HourVideo Hit@5 also improved by 15.4 and 8.3
points over the original checkpoints, showing gains in both top-one and
top-five retrieval. On LVBench retrieval, Hit@1 improved by 10.3 and 9.2
points over the original checkpoints, while Hit@5 remained near 98.
Thus, the LVBench gains primarily reflect better top-ranked ordering
rather than expanded top-five coverage. HourVideo classification
improved more moderately, from 51.1 to 54.2 at 2B and from 52.2 to 57.3
at 8B.

#### Moment retrieval.

HourVideo moment-retrieval Hit@1 increased from 24.3 to 30.1 at 2B and
from 24.9 to 27.7 at 8B, with Hit@5 also improving at both scales.
LongVideoBench Hit@1 rose from 34.2 to 37.0 and from 33.2 to 38.8,
respectively. The larger HourVideo gain at 2B and larger LongVideoBench
gain at 8B indicate task-dependent effects of model scale.

#### Video question answering.

QASLR improved all four QA tasks over both baselines in
Table [1](#S4.T1 "Table 1 ‣ Comparison protocol. ‣ 4.1 Experimental Setup ‣ 4 Experiments ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning").
Mean accuracy increased from 48.3 to 50.6 at 2B and from 61.2 to 66.3 at
8B relative to the original checkpoints. The 8B gains were 4.6 points on
MovieChat, 5.8 on LVBench, 4.3 on EgoSchema, and 5.6 on TimeScope.
Improvements at 2B ranged from 1.1 to 3.7 points. Single-round
post-training achieved mean QA accuracies of 48.9 and 62.0, so the
additional gains with QASLR were larger at 8B. These results concern the
complete recipe. Comparison with sub-batched single-round training
reveals a less uniform QA advantage, as discussed below.

### 4.3 Generalization to Another VLM Embedding Backbone

Figure [3](#S4.F3 "Figure 3 ‣ Comparison protocol. ‣ 4.1 Experimental Setup ‣ 4 Experiments ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning")
compares the original RzenEmbed 7B checkpoint, single-round
post-training, and QASLR. This Qwen2-VL-based backbone provides a test
beyond Qwen3-VL-Embedding using the same training formulation. QASLR
exceeded both baselines on all seven displayed tasks, with gains of
3.4–6.0 points over the original checkpoint. Improvements span
classification, retrieval, moment retrieval, and QA, rather than a
single task family. Relative to single-round post-training, QASLR raised
EgoSchema accuracy from 61.1 to 66.3 and LongVideoBench moment-retrieval
Hit@1 from 32.3 to 35.7. Because both backbones belong to the Qwen
family, this experiment supports within-family transfer, not
generalization across unrelated architectures.

### 4.4 Effect of Interleaved Sub-Batching

Table [2](#S4.T2 "Table 2 ‣ Comparison protocol. ‣ 4.1 Experimental Setup ‣ 4 Experiments ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning")
shows that the sub-batching configuration, including a larger effective
batch, improved QASLR’s mean retrieval Hit@1 from 54.5 to 61.1 at 2B and
from 55.7 to 63.0 at 8B. HourVideo retrieval gains were 15.3 and 13.6
points, respectively. LVBench retrieval improved by 2.4 and 4.9 Hit@1
points, while LongVideoBench moment retrieval improved by 2.2 and 3.2
points. At 2B, MovieChat and LVBench QA fell below the original
checkpoint without sub-batching, reaching 47.0 and 36.8. Sub-batching
recovered them to 55.2 and 42.3. At 8B, QA gains ranged from 2.3 points
on EgoSchema to 7.1 on MovieChat. Sub-batching therefore benefited both
retrieval and QA within the QASLR configuration.

However, sub-batching also improved single-round post-training: mean
retrieval Hit@1 increased from 52.2 to 56.8 at 2B and from 53.8 to 59.9
at 8B. With sub-batching, QASLR retained higher Hit@1 on all three
retrieval tasks at both scales. Mean scores were 61.1 versus 56.8 at 2B
and 63.0 versus 59.9 at 8B. At the task level, HourVideo Hit@1 gains
over this baseline were 4.6 points at 2B and 5.5 at 8B. The
corresponding margins were 8.2 and 1.5 points on LVBench, and 0.3 and
2.1 on LongVideoBench, showing task- and scale-dependent differences. QA
results were mixed: single-round post-training scored higher on three of
four tasks at 2B and on MovieChat at 8B. These comparisons show
substantial gains from the batching configuration, while QASLR’s
advantage over the sub-batched baseline is consistent for retrieval but
task-dependent for QA.

## 5 Conclusion

We introduced QASLR, a post-training framework that represents long
videos through a fixed-size latent memory updated over temporally
ordered clips. The full training recipe improved retrieval, moment
retrieval, classification, and multiple-choice QA relative to the
original checkpoints at both the 2B and 8B scales. The streaming head
also transferred to a second Qwen-family embedding model. QASLR stores
frame indices rather than duplicated images and preserves the downstream
embedding interface. Its query-aware path produces query-conditioned
representations and is therefore intended for bounded candidate sets or
second-stage reranking. Query-independent selection remains necessary
when each video must be indexed once and reused across queries.
Sub-batching benefits both single-round and streaming models, although
improvements in QA remain task-dependent. Future work could assess
generalization beyond Qwen-family backbones and evaluate whether
adaptive stopping can reduce inference cost while preserving task
performance.

## Appendix A Appendix

This appendix describes the training configuration, evaluation data,
component comparisons, and theoretical properties of QASLR.

### A.1 Detailed Algorithm

Table [3](#A1.T3 "Table 3 ‣ A.1 Detailed Algorithm ‣ Appendix A Appendix ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning")
summarizes the QASLR training pathway. Each example is represented
through a query–positive interface, and selected frame indices are
decoded on demand. Streaming memory is initialized once for each input
and retained across its clips.

|  Input: training pairs $`\{(q_{i},p_{i})\}_{i=1}^{P}`$, selected frame indices, VLM backbone $`F_{\theta}`$, streaming head $`G_{\phi}`$, temperature $`\tau`$, loss weights $`\lambda_{\mathrm{step}},\lambda_{\mathrm{distill}}`$. |
|----|
|  1. Sample a mini-batch of query-positive pairs. If interleaved sub-batching is enabled, group examples with similar task and input format into homogeneous sub-batches. |
|  2. For each streaming video item, decode selected frame indices from the original video and restore chronological order. |
|  3. Split selected frames into clips $`[C_{1},\ldots,C_{T}]`$. |
|  4. For each clip $`C_{t}`$, encode $`U_{t}=F_{\theta}(C_{t},c)`$, where $`c`$ is the permitted conditioning input, omitted for query-independent video encoding. |
|  5. Compress valid hidden states into a fixed-size evidence bank $`E_{t}`$. |
|  6. Initialize think-token memory $`H_{0}`$ and update it sequentially: $`H_{t}=\mathrm{Update}_{\phi}(H_{t-1},E_{t})`$. |
|  7. Read out step embeddings $`z_{t}=\mathrm{Readout}_{\phi}(H_{t})`$. |
|  8. Compute the masked final contrastive loss and enabled auxiliary embedding losses; train the optional gate separately after embedding training. |
|  9. Update the streaming-head parameters while keeping the pretrained backbone frozen. |

Table 3: QASLR post-training procedure for unified query–positive pairs.
Selected frame indices are decoded on demand and restored to
chronological order before clip-wise backbone encoding. A bounded
evidence bank updates the persistent think-token memory, which is
initialized once per video and read out after every clip. The
optimization combines final contrastive learning with the enabled
auxiliary objectives. Interleaved sub-batching groups compatible task
and input formats before parameter updates. The gate objective applies
only when training the optional early-exit module; it is not required
for fixed-length streaming inference.

#### State isolation and padding.

Each video trajectory has an independent memory state. Packing clips
into a backbone batch does not permit attention or memory sharing
between different inputs. Padded evidence tokens and unavailable
readouts are masked. Non-streaming inputs retain their original
embedding pathway.

#### Inference.

Fixed-length inference returns the final valid readout. Optional early
exit returns an intermediate readout when the stopping rule is
satisfied. Early-exit use in local-clip QA is discussed separately in
Section [A.10](#A1.SS10 "A.10 Early Exit and Computational Cost ‣ Appendix A Appendix ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning").

### A.2 Implementation Details

#### Backbone input and output.

The image processor uses a pixel-area range of 4,096–1,310,720, with
height and width aligned to multiples of 32. The output embedding
dimensions are 2,048 for Qwen3-VL-Embedding 2B and 4,096 for
Qwen3-VL-Embedding 8B.

#### Streaming configuration.

The main QASLR configuration selects at most 128 frames and uses 32
think tokens and at most 256 evidence tokens per clip. At the full frame
budget, 16 frames per clip give eight streaming updates. For inputs with
fewer selected frames, the number of frames per clip is reduced. Only
valid frames and readouts contribute to attention and auxiliary losses.
Compression uses cosine similarity between valid hidden-state
representations to construct the evidence bank.

#### Trainable modules.

Only the streaming latent reasoning head is updated in QASLR, while
pretrained backbone parameters remain frozen. The trainable parameter
counts are approximately 200 million for the 2B configuration and 600
million for the 8B configuration. These counts refer to the trainable
head rather than the total model size.

#### Optimization.

Post-training uses AdamW with a learning rate of $`10^{-4}`$ and
approximately three to five epochs, depending on the configuration.
Training runs on NVIDIA H100 GPUs, with a per-GPU batch size of 4 or 8
and a global effective batch size of 256 or 512 across configurations.
The step-wise contrastive and self-distillation weights are
$`\lambda_{\mathrm{step}}=0.1`$ and $`\lambda_{\mathrm{distill}}=0.01`$,
respectively. The reported experimental results are averaged over three
random seeds.

#### Interleaved sub-batching.

Compatible examples are grouped by task and input format. Negative
candidates are shared across sub-batches and GPUs, and the effective
batch size increases in the sub-batching configuration. The sub-batching
configuration therefore changes both the effective optimization batch
size and the negative pool. For query-conditioned scoring, shared
candidates retain the query-conditioning requirement defined in the main
objective.

#### Frame storage.

Selected frames are recorded as indices with optional timestamps and
decoded from the original videos when needed. This avoids storing
duplicated image copies for every query–video annotation. Frame indices
and timestamps provide references to the original video without
duplicating the selected images.

### A.3 Additional Experimental Details

#### Post-training data.

Post-training primarily uses LLaVA-Video-178K, supplemented with 10,000
ActivityNet videos.

#### Benchmark annotations and task construction.

QA annotations are taken from the corresponding original benchmark
datasets. The four QA results in the main comparison are MovieChat,
LVBench, EgoSchema, and TimeScope. Classification, video retrieval, and
moment retrieval use sampled and filtered subsets of the source
datasets. Their sizes vary by dataset and task, from tens to thousands
of examples. GPT-4o assists annotation by constructing pairs of visual
frames from video segments and textual questions. We will publicly
release the complete evaluation sets for all reported tasks to support
reproducibility and future research on long-video understanding.

#### Candidate sets.

These evaluations use bounded candidate sets. Video-retrieval questions
generally have 4 or 8 candidates, and moment-retrieval questions
generally have 8 or 16 candidate segments, depending on video length.
Classification uses 4–8 categories, depending on the dataset. QA
questions generally contain four answer options. Retrieval scores
measure ranking within these task-specific candidate sets. The
candidate-count distribution also affects Hit@5: with four candidates
and a valid positive, top-five retrieval necessarily includes that
positive.

#### QA scoring.

The video–question input is embedded on the query side, and the original
answer options are embedded on the candidate side. The selected answer
is the option with the highest embedding similarity. No additional QA
prompt is introduced beyond this input construction.

#### Metrics and averaging.

Retrieval-style tasks report Hit@1/Hit@5 where available, and QA reports
accuracy. LongVideoBench moment retrieval reports Hit@1. Results are
averaged over three random seeds. Task averages include only the tasks
specified in the relevant table and do not weight by the number of
examples.

### A.7 Frame Budget and Streaming Depth

The full-budget configuration uses $`K=128`$ frames, $`L=16`$ frames per
clip, and eight memory updates. For inputs with fewer selected frames,
QASLR reduces the number of frames per clip. Frame budget and clip size
determine different aspects of processing: $`K`$ controls the
observations supplied to the backbone, while $`L`$ controls per-call
context length.

For fixed $`K`$, changing $`L`$ also changes the number of updates
$`T=\lceil K/L\rceil`$. At fixed $`L`$, increasing $`K`$ changes both
temporal coverage and total computation. These dependencies distinguish
the storage occupied by the persistent memory from the cost of obtaining
and encoding its evidence.

Consistent with the main objective, each query retains its paired target

#### Final and intermediate effects.

Adding step-wise supervision alone increases final HourVideo Hit@1 from
67.9 to 69.8; distillation alone increases it to 70.1; using both

improve partial-video readouts as well as the final embedding in this
comparison.

#### Partial evidence and distillation.

An early clip may not yet contain the evidence needed for the paired
target. Step-wise supervision therefore encourages a useful
partial-video representation, rather than certifying that the answer is
already observable. The final teacher also sees evidence unavailable at
earlier steps. Alignment to that teacher is a training regularizer, not
access to unseen frames at inference. Neither a high checkpoint accuracy
nor a low average distillation loss guarantees correctness on every
query or every candidate.

### A.9 Frame Selection and Evidence Coverage

Q-Frame selects text-relevant frames within the input budget, and QASLR
restores their chronological order before aggregation. The selector
determines the available observations; the persistent memory combines
their evidence across clips. Events omitted by selection remain outside
the information available to the streaming head.

### A.10 Early Exit and Computational Cost

#### Optional early exit.

For local-clip QA, the optional stopping rule returns an intermediate
readout at the first eligible step $`t\geq t_{\min}`$ satisfying
$`p_{t}\geq\eta`$. If no eligible step meets the threshold, processing
continues to the final readout. The fixed-length retrieval results use
the complete sequence. The theoretical analysis below characterizes
agreement with full-step predictions under its stated calibration
assumption.

#### Warm-cache latency.

Table [4](#A1.T4 "Table 4 ‣ Indexing and two-stage scoring. ‣ A.4 Evaluation Modes and Query Conditioning ‣ Appendix A Appendix ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning")
reports per-query latency on NVIDIA H100 hardware with a warm cache. The
two-stage single-round and QASLR configurations take 1.26 s and 1.72 s,
respectively. QASLR improves HourVideo Hit@1 by 4.6 points in this
comparison, with a latency increase of 0.46 s, approximately 36.5%. The
uniform-selection rows compare configurations that additionally differ
in sub-batching.

#### Cost decomposition.

For a shortlist $`\mathcal{C}_{R}(q)`$ containing at most $`R`$
candidates, online processing comprises query encoding, search,
candidate processing, and ranking:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle C_{\mathrm{online}}(q)`$ | $`\displaystyle=C_{\mathrm{query}}(q)+C_{\mathrm{search}}(q)+C_{\mathrm{rank}}(q)`$ |  |  |
|  |  | $`\displaystyle\quad+\sum_{j\in\mathcal{C}_{R}(q)}\left[C_{\mathrm{select}}(q,j)+C_{\mathrm{decode}}(q,j)+C_{\mathrm{encode}}(q,j)+C_{\mathrm{head}}(q,j)\right].`$ |  | (15) |

This decomposition defines the full online workload separately from the
warm-cache measurements above. Query-independent corpus encoding and
index construction contribute offline costs, amortized as
$`C_{\mathrm{offline}}/Q`$ over $`Q`$ queries. Cached media can reduce
repeated decoding, whereas query-conditioned video encoding remains
specific to each query–candidate pair.

### A.12 Complexity Analysis

Let $`K`$ be the selected-frame count, $`L`$ the clip size,
$`T=\lceil K/L\rceil`$ the number of steps, and $`D`$ the backbone
hidden dimension. The head uses $`N`$ think tokens, at most $`M`$
evidence tokens, and an output dimension $`d`$. Let
$`C_{\mathrm{vlm}}(L)`$ denote one clip-encoding cost. For the
cross-attention, fixed-width-ratio feed-forward network, and readout
defined in
Section [3](#S3 "3 Method ‣ Enhancing Long-Video VLM Embeddings with Query-Aware Streaming Latent Reasoning"),
the per-step head cost is

|     |                                                      |     |      |
|-----|------------------------------------------------------|-----|------|
|     |
       ``` math
       C_{\mathrm{head}}=O\!\left(NMD+(N+M)D^{2}+Dd\right).
       ```                                                   |     | (16) |

The terms account for attention mixing, token projections and
feed-forward transformations, and the output projection, respectively.
This expression does not assume an additional latent self-attention
layer. For full-step inference,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
C_{\mathrm{full}}=C_{\mathrm{fixed}}+T\left[C_{\mathrm{vlm}}(L)+C_{\mathrm{head}}\right],
``` |  | (17) |

where $`C_{\mathrm{fixed}}`$ includes any up-front selection or
preprocessing cost. In query-conditioned retrieval, clip encoding and
aggregation are repeated for each query–candidate pair; first-stage
retrieval and query encoding are additional costs.

The persistent memory occupies $`O(ND)`$ values per example. Excluding
model parameters and backbone activations, a conventional single-step
attention implementation requires working space of order

|     |                              |     |      |
|-----|------------------------------|-----|------|
|     |
       ``` math
       O\!\left((N+M)D+NM+d\right).
       ```                           |     | (18) |

These are inference-state bounds, not bounds on training peak memory.
Backpropagation through the streaming head may retain activations across
steps even when the backbone is frozen; checkpointing or recomputation
changes that trade-off.

If the model exits after $`\widehat{T}\leq T`$ steps, then, for fixed
per-step cost and negligible gate overhead,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{E}[C_{\mathrm{exit}}]=C_{\mathrm{fixed}}+\mathbb{E}[\widehat{T}]\left[C_{\mathrm{vlm}}(L)+C_{\mathrm{head}}\right].
``` |  | (19) |

When fixed costs are negligible, the remaining cost ratio is
approximately $`\mathbb{E}[\widehat{T}]/T`$, and the saved fraction is
$`1-\mathbb{E}[\widehat{T}]/T`$. Up-front frame selection and decoding
can reduce end-to-end savings relative to this approximation.

### A.13 Theoretical Analysis

The following conditional results describe perturbation stability and
agreement with full-step retrieval. They do not establish that
optimization attains the stated assumptions or that QASLR is optimal.

#### Assumption 1: regular memory update and readout.

Let $`H_{t}=U_{\phi}(H_{t-1},E_{t})`$. On the states under
consideration, assume

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\|U_{\phi}(H,E)-U_{\phi}(H^{\prime},E^{\prime})\|_{F}\leq\rho\|H-H^{\prime}\|_{F}+\beta\|E-E^{\prime}\|_{F},
``` |  | (20) |

with $`\rho,\beta\geq 0`$, and assume the normalized readout is
$`L_{R}`$-Lipschitz. For normalization, this requires the
pre-normalization readout norm to remain bounded away from zero, in
addition to regularity of the preceding operations.

#### Proposition 1: propagation of evidence perturbations.

Consider two executions with the same initial memory and
$`\|E_{t}-\widetilde{E}_{t}\|_{F}\leq\epsilon`$ at every step. Under
Assumption 1,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\|H_{T}-\widetilde{H}_{T}\|_{F}\leq\beta\epsilon\sum_{k=0}^{T-1}\rho^{k},\qquad\|z_{T}-\widetilde{z}_{T}\|_{2}\leq L_{R}\beta\epsilon\sum_{k=0}^{T-1}\rho^{k}.
``` |  | (21) |

#### Proof.

Writing $`\delta_{t}=\|H_{t}-\widetilde{H}_{t}\|_{F}`$ gives
$`\delta_{t}\leq\rho\delta_{t-1}+\beta\epsilon`$. Unrolling from
$`\delta_{0}=0`$ yields the memory bound; applying readout Lipschitz
continuity yields the embedding bound. $`\square`$

If $`\rho<1`$, the memory bound is at most $`\beta\epsilon/(1-\rho)`$,
uniformly in $`T`$. If $`\rho=1`$, it grows linearly, and if $`\rho>1`$,
it can grow geometrically. The architecture alone does not verify a
contractive update.

#### Scope of step-wise supervision.

The step-wise contrastive objective directly evaluates intermediate
retrieval scores, whereas the final-only objective directly evaluates
only the terminal readout. This distinction motivates intermediate
supervision, but does not prove it is necessary for early exit. Nor does
minimizing contrastive loss alone establish a prescribed distance to an
ideal intermediate embedding. Both shared parameters and other auxiliary
objectives can influence intermediate states without a step-wise
contrastive term.

#### Proposition 2: ranking preservation under an embedding-distance bound.

For a fixed normalized query $`q`$, let $`p`$ be the positive candidate
and $`n`$ index negatives. Define

|     |                                                         |     |      |
|-----|---------------------------------------------------------|-----|------|
|     |
       ``` math
       \gamma_{t}=q^{\top}z_{t}^{p}-\max_{n}q^{\top}z_{t}^{n}.
       ```                                                      |     | (22) |

Suppose $`\gamma_{T}\geq m>0`$ and every candidate satisfies
$`\|z_{t}-z_{T}\|_{2}\leq\epsilon`$. If $`2\epsilon<m`$, the step-$`t`$
representation preserves the correct full-step top-1 decision.

#### Proof.

Cauchy–Schwarz gives $`\left|q^{\top}(z_{t}-z_{T})\right|\leq\epsilon`$.
The positive score can decrease by at most $`\epsilon`$, and the largest
negative score can increase by at most $`\epsilon`$. Hence

|     |                                                       |     |      |
|-----|-------------------------------------------------------|-----|------|
|     |
       ``` math
       \gamma_{t}\geq\gamma_{T}-2\epsilon\geq m-2\epsilon>0.
       ```                                                    |     | (23) |

$`\square`$

For normalized embeddings,
$`\|z_{t}-z_{T}\|_{2}^{2}=2(1-z_{t}^{\top}z_{T})`$, linking the
distillation objective to embedding distance. However, a small average
distillation loss does not guarantee the uniform bound required for
every candidate. The proposition assumes a fixed query and does not
directly cover a simultaneously changing query-side embedding.

#### Assumption 2: calibration conditional on the stopping history.

Let $`\mathcal{F}_{t}`$ contain the information available to the
stopping rule through step $`t`$, including the query, observed states,
and previous gate outputs. Let $`A_{t}`$ denote agreement between the
step-$`t`$ and full-step retrieval decisions. Assume the gate output
$`p_{t}`$ is measurable with respect to $`\mathcal{F}_{t}`$ and
satisfies

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\left|p_{t}-\Pr(A_{t}\mid\mathcal{F}_{t})\right|\leq\epsilon_{g}
``` |  | (24) |

almost surely at every eligible step, with $`\epsilon_{g}\geq 0`$ and
$`0\leq\eta\leq 1`$. This history-conditional assumption is stronger
than a small average calibration error.

#### Proposition 3: disagreement risk at a threshold-based stopping time.

Let $`\widehat{T}`$ be the first step $`t\geq t_{\min}`$ with
$`p_{t}\geq\eta`$, or $`T`$ if no earlier exit occurs. Under Assumption
2,

|     |                                                                |     |      |
|-----|----------------------------------------------------------------|-----|------|
|     |
       ``` math
       \Pr(A_{\widehat{T}}^{\,c})\leq\min\{1,\,1-\eta+\epsilon_{g}\}.
       ```                                                             |     | (25) |

#### Proof.

For $`t<T`$, the event $`\{\widehat{T}=t\}`$ belongs to
$`\mathcal{F}_{t}`$. On this event, calibration and the threshold imply
$`\Pr(A_{t}^{c}\mid\mathcal{F}_{t})\leq 1-\eta+\epsilon_{g}`$. Since
$`A_{T}`$ holds by definition,

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\Pr(A_{\widehat{T}}^{\,c})`$ | $`\displaystyle=\sum_{t<T}\mathbb{E}\!\left[\mathbf{1}_{\{\widehat{T}=t\}}\Pr(A_{t}^{c}\mid\mathcal{F}_{t})\right]`$ |  | (26) |
|  |  | $`\displaystyle\leq(1-\eta+\epsilon_{g})\Pr(\widehat{T}<T)\leq 1-\eta+\epsilon_{g}.`$ |  | (27) |

A probability is also at most one. $`\square`$

This is an agreement bound, not a guarantee of correctness against
ground truth. It is conditional on Assumption 2, which is not verified
by the reported experiments. A larger threshold delays or prevents exit
for a fixed gate-output trajectory, but does not by itself prove
improved task accuracy.

#### Storage cost of index-only annotations.

Suppose a video has $`R`$ query annotations, each selecting $`K`$ frames
of size $`H\times W`$ with $`c`$ channels. If each raw pixel-channel
value occupies $`s`$ bytes and each index occupies $`b`$ bytes,
uncompressed frame copies require $`RKHWcs`$ bytes. Index lists require
$`RKb`$ bytes, giving an additional-annotation storage ratio of

|     |                 |     |      |
|-----|-----------------|-----|------|
|     |
       ``` math
       \frac{HWcs}{b}.
       ```              |     | (28) |

Both approaches retain the original video. Compressed image formats,
metadata, and caching alter the practical ratio; this comparison
concerns duplicated annotation storage, not total dataset size or
decoding latency.

### A.14 Limitations

QASLR depends on frame selection: its latent memory cannot recover
evidence that is absent from the selected observations. The query-aware
pathway produces query-conditioned representations for bounded candidate
scoring. Reusable corpus indexing instead requires query-independent
selection and encoding.

The comparisons with sub-batched single-round training show consistent
retrieval gains but task-dependent QA gains. Test-time order and memory
perturbations measure sensitivity to altered inputs and state updates,
rather than identifying the internal reasoning process. Transfer is
evaluated within the Qwen family.

Warm-cache latency depends on selection, decoding, candidate count, and
hardware. Fixed memory size bounds the persistent state, but does not
imply a proportional reduction in total computation. The seed-averaged
scores describe empirical differences without establishing statistical
significance. Early-exit bounds concern agreement with full-step
predictions under the stated assumptions, rather than unconditional
ground-truth accuracy.
````
