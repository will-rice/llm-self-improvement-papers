# On the Convergence of Self-Improving Online LLM Alignment

Xudong Wu Affiliation: The University of Hong Kong, Hong Kong SAR   
Pangpang Liu Affiliation: Yale University, New Haven, CT, USA    Vaneet
Aggarwal Affiliation: Purdue University, West Lafayette, IN, USA   
Jiayu Chen Affiliation: The University of Hong Kong, Hong Kong SAR

###### Abstract

The Self-Improving Alignment (SAIL) algorithm addresses distribution
shift by reducing a bilevel formulation of the problem to an efficient,
single-level method. Empirically, SAIL has demonstrated strong
performance on this task. However, a formal analysis of its convergence
properties has been lacking. We identify a key theoretical challenge:
the standard SAIL objective function is not guaranteed to be strongly
concave due to unfavorable properties of its Hessian. To address this
limitation, we propose a regularized objective, SAIL-RevKL, which
incorporates a reverse Kullback-Leibler (KL) divergence penalty to
improve the optimization landscape. Our central theoretical contribution
is to prove that this regularized objective satisfies the
Polyak-Lojasiewicz (PL) condition within a bounded parameter space. We
establish global convergence guarantees, achieving a near-linear sample
complexity. We further validate the effectiveness and stability of
SAIL-RevKL through empirical evaluations, demonstrating that it
outperforms the vanilla SAIL on both MuJoCo benchmarks and LLM alignment
tasks.

## 1 Introduction

Large language models (LLMs) are increasingly deployed in settings where
alignment with human preferences is critical \[[Bai et al.,
2022](#bib.bib23)\]. Reinforcement Learning from Human Feedback (RLHF)
has emerged as a practical route to alignment \[[Agarwal et al.,
2020](#bib.bib20), [Rafailov et al., 2024](#bib.bib11), [Ziegler et al.,
2020](#bib.bib22)\]. However, the prevailing pipelines are predominantly
offline, optimizing on a fixed preference dataset produced by an
supervised fine-tuning(SFT) model, which makes the resulting performance
sensitive to coverage gaps and data quality \[[Tang et al.,
2024](#bib.bib15)\]. To mitigate these limitations, recent work explores
online RLHF that iterates between generating on-policy responses and
collecting preferences \[[Lee et al., 2024](#bib.bib16), [Park et al.,
2022](#bib.bib25)\]. Among online approaches, SAIL reduces a bilevel
alignment formulation to a computationally efficient single-level
surrogate and reports strong empirical gains \[[Ding et al.,
2024](#bib.bib3)\]. Yet, existing online pipelines are largely heuristic
and do not analytically control the distributional shift induced by
iterative data collection \[[Chakraborty et al., 2024](#bib.bib17),
[Shen et al., 2024](#bib.bib18)\], which has been linked to suboptimal
performance in practice \[[Sharma et al., 2024](#bib.bib19)\].

A growing line of work argues that the coupling between reward learning
and policy updates is fundamentally bilevel and should be modeled as
such \[[Chakraborty et al., 2024](#bib.bib17)\]. As a follow-up, [Ding
et al. \[2024\]](#bib.bib3) reduces the bilevel alignment objective to a
tractable single-level surrogate and reports strong empirical gains, yet
it lacks formal convergence guarantees. Related theoretical analyses in
bilevel/RLHF-style problems exist \[[Yang et al., 2025](#bib.bib21),
[Chakraborty et al., 2024](#bib.bib17), [Gaur et al., 2025](#bib.bib31),
e.g.,\], yet they either focus on tabular/idealized settings, rely on
assumptions not directly applicable to LLM alignment, or do not provide
global non-asymptotic guarantees for policy updates in the online,
policy-dependent regime we study.

#### Our contributions.

We revisit SAIL through the lens of first-order optimization. We
identify a key obstacle: the standard SAIL objective may fail to be
strongly concave due to unfavorable curvature of its Hessian, which
hinders global guarantees. We therefore introduce a reverse KL (RevKL)
regularization that restores benign geometry on a bounded parameter set
and prove that the resulting objective satisfies a Polyak–Łojasiewicz
(PL) condition. Building on this structure, we analyze a projected
stochastic gradient ascent scheme and establish non-asymptotic
convergence guarantees for the RevKL-regularized SAIL surrogate under
explicit structural assumptions:

- •
  Geometry of SAIL. We show the unregularized objective admits only
  local strong concavity under a curvature threshold; augmenting with a
  reverse–KL penalty yields global strong concavity/PL on a bounded
  domain, clarifying when SAIL becomes a well-conditioned first-order
  problem.
- •
  Global convergence in the strongly concave regime. Leveraging the
  PL/strong-concavity geometry induced by RevKL, we obtain global linear
  convergence of the regularized objective gap on the stated bounded
  feasible set, yielding sample complexity
  $`\tilde{\mathcal{O}}(\varepsilon^{-1}\log(\varepsilon^{-1}))`$ to
  reach accuracy $`\varepsilon`$ with practical choices of stepsize and
  batch size.
- •
  Empirical Evaluation. We conduct empirical evaluations on both
  continuous-control benchmarks and LLM alignment tasks. In addition to
  practical LoRA-based fine-tuning experiments, we include
  last-layer-only experiments that provide the closest empirical
  counterpart to the log-linear policy class used in the theory.

## 2 RELATED WORK

#### Online RLHF.

A large body of work studies preference-based alignment within the RLHF
pipeline; many recent methods are offline, optimizing over fixed
preference datasets, e.g., DPO and its refinements \[[Rafailov et al.,
2024](#bib.bib11), [Zhao et al., 2023](#bib.bib14), [Azar et al.,
2023](#bib.bib24)\]. However, offline pipelines can be sensitive to data
quality and distribution shift \[[Tang et al., 2024](#bib.bib15)\]. To
address this, online RLHF collects on-policy feedback and updates the
policy iteratively \[[Christiano et al., 2023](#bib.bib13), [Lee et al.,
2024](#bib.bib16)\]. Among online approaches, SAIL reduces a bilevel
alignment formulation to a tractable single-level surrogate and
demonstrates strong empirical performance \[[Ding et al.,
2024](#bib.bib3)\].

Most existing pipelines are heuristic and lack a unified mathematical
treatment; more critically, the issue of distributional shift in online,
iterative RLHF is largely unaddressed \[[Chakraborty et al.,
2024](#bib.bib17), [Shen et al., 2024](#bib.bib18)\], which has been
linked to sub–optimal performance in practice \[[Sharma et al.,
2024](#bib.bib19)\].

#### Bilevel RLHF.

Motivated by the current shortcomings of online RL, [Chakraborty et al.
\[2024\]](#bib.bib17) formulate online RLHF as a bilevel optimization
problem that explicitly captures the coupling between reward learning
and policy updates, thereby modeling statistical dependencies often
ignored in prior work and implicated in distribution shift. However, the
bilevel structure introduces substantial computational burden due to
nested optimization and second–order sensitivity. A follow-up study
reduces the bilevel alignment objective to a tractable single-level
surrogate, reporting strong empirical gains but lacking formal
convergence guarantees \[[Ding et al., 2024](#bib.bib3)\].

Recently, [Gaur et al. \[2025\]](#bib.bib31) provided the first sample
complexity analysis for general bilevel RLHF-style problems with
non-convex lower levels, establishing a theoretical benchmark of
$`\tilde{\mathcal{O}}(\epsilon^{-3})`$. However, their contribution has
two notable limitations in the context of our work. First, as they
primarily focus on local convergence, they do not establish global
convergence bounds for the policy updates in the online,
policy-dependent regime considered here (mainly because there is no
PL/convexity assumption on upper level). Second, their general framework
does not account for the special structure of the SAIL surrogate \[[Ding
et al., 2024](#bib.bib3)\], which simplifies the bilevel problem into a
tractable single-level objective.

## 3 PRELIMINARIES

#### Notations:

$`\|\cdot\|`$ denotes the Euclidean norm. We use $`\sigma`$ to denote
the sigmoid (standard logistic) function.

For any two probability distributions $`P`$ and $`Q`$ defined on
$`\mathcal{Z}`$, the Kullback-Leibler (KL) divergence is \[[Villani,
2009](#bib.bib12)\]

|     |     |     |
| --- | --- | --- |
|     |

````math
D_{\mathrm{KL}}(P\,\|\,Q)=\sum_{z\in\mathcal{Z}}P(z)\,\log\!\frac{P(z)}{Q(z)}\,.
``` |  |

#### Projected (Stochastic) Gradient and Gradient Mapping.

Let $`\Theta\subset\mathbb{R}^{d}`$ be nonempty, closed, and convex, and
let $`\Pi_{\Theta}(\cdot)`$ denote the Euclidean projection onto
$`\Theta`$:

|     |                                                          |     |
|-----|----------------------------------------------------------|-----|
|     |
       ``` math
       \Pi_{\Theta}(z)\;:=\;\arg\min_{u\in\Theta}\;\|u-z\|_{2}.
       ```                                                       |     |

The normal cone of $`\Theta`$ at $`x\in\Theta`$ is

|  |  |  |
|----|----|----|
|  |
``` math
N_{\Theta}(x)\;:=\;\{\,v\in\mathbb{R}^{d}:\ \langle v,\,y-x\rangle\leq 0\;\text{ for all }y\in\Theta\,\}.
``` |  |

Given a stepsize $`\eta>0`$, the gradient mapping is

|  |  |  |
|----|----|----|
|  |
``` math
G_{\eta}(\theta)\;:=\;\frac{1}{\eta}\big(\Pi_{\Theta}(\theta+\eta\nabla J_{\gamma}(\theta))-\theta\big).
``` |  |

When $`\Theta=\mathbb{R}^{d}`$,
$`G_{\eta}(\theta)=\nabla J_{\gamma}(\theta)`$.

## 4 PROBLEM SETUP AND PROPOSED ALGORITHM

### 4.1 Problem Setup

We make the following assumptions for the rest of the paper.

Let $`\theta_{0}`$ denote the fixed parameter of the SFT policy, i.e.,
$`\pi_{\mathrm{SFT}}=\pi_{\theta_{0}}`$. We initialize the projected
optimization at $`\theta_{0}`$.

###### Assumption 1 (Log-linear policy class).

Let $`\psi:S\times A\to\mathbb{R}^{d}`$ be a known $`d`$-dimensional
feature mapping with $`\max_{s,a}\|\psi(s,a)\|_{2}\leq 1`$. Assume a
bounded policy parameter set
$`\Theta:=\{\theta\in\mathbb{R}^{d}:\|\theta-\theta_{0}\|_{2}\leq B_{\theta}\}`$
We consider the following class of log-linear policies:

|  |  |  |
|----|----|----|
|  |
``` math
\Pi=\left\{\pi_{\theta}:\pi_{\theta}(a\mid s)=\frac{\exp\left(\theta^{\top}\psi(s,a)\right)}{\sum_{a^{\prime}\in\mathcal{A}}\exp\left(\theta^{\top}\psi(s,a^{\prime})\right)}\right\}.
``` |  |

###### Remark 1 (Practical and Theoretical Justification).

This is a standard assumption in the theoretical analysis of RL
\[[Agarwal et al., 2021](#bib.bib10), [Modi et al., 2020](#bib.bib9)\],
RLHF \[[Zhu et al., 2023](#bib.bib8)\], and DPO \[[Nika et al.,
2024](#bib.bib7)\].

It is also deeply grounded in the architectural reality and practical
alignment paradigms of LLMs.

First, the bounded feature space is an intrinsic property of Transformer
architectures. Components such as Layer Normalization and Softmax
naturally constrain the range of feature representations during the
forward pass.

Second, the log-linear policy assumption mathematically aligns with the
widely adopted linear probing paradigm (i.e., updating only the final
linear head while freezing the pre-trained backbone). We adopt this
setting to prioritize robustness during alignment. Full fine-tuning can
induce “feature distortion” modifying robust pre-trained features to
overfit in-distribution data, which degrades performance under
distribution shifts \[[Kumar et al., 2022](#bib.bib38)\]. Extensive
empirical evidence demonstrates that this simple last-layer retraining
strategy yields highly stable alignment and can match or outperform full
fine-tuning under distribution shifts, but with profoundly lower
computational complexity \[[Kirichenko et al., 2023](#bib.bib39),
[LaBonte et al., 2023](#bib.bib40)\].

###### Assumption 2 (Fisher information lower bound).

Let $`\rho`$ be the initial state distribution and let
$`\nu_{\pi_{\theta},\rho}`$ denote the (discounted or undiscounted)
state–action visitation distribution induced by policy $`\pi_{\theta}`$
and $`\rho`$. Define the Fisher matrix

|  |  |  |
|----|----|----|
|  |
``` math
F_{\rho}(\theta):=\mathbb{E}_{(s,a)\sim\nu_{\pi_{\theta},\rho}}\!\big[\,\nabla_{\theta}\log\pi_{\theta}(a\mid s)\,\nabla_{\theta}\log\pi_{\theta}(a\mid s)^{\top}\big].
``` |  |

There exists a constant $`\mu_{F}>0`$ such that, for all
$`\theta\in\Theta`$,

|     |                                    |     |
|-----|------------------------------------|-----|
|     |
       ``` math
       F_{\rho}(\theta)\succeq\mu_{F}\,I.
       ```                                 |     |

###### Remark 2.

This assumption is commonly used in reinforcement learning, see \[[Liu
et al., 2020](#bib.bib4), [Mondal and Aggarwal, 2024](#bib.bib2),
[Ganesh et al., 2025](#bib.bib1)\]. It is a cornerstone for our
analysis, as it provides the foundation for proving the strict positive
definiteness of the ordered-pair Fisher information matrix in Lemma
[1](#Thmlemma1 "Lemma 1 (Strict positive definiteness of 𝑆⁢𝑆^⊤ under Assumption 2). ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment").

SAIL admits a bilevel formulation in which the reward is fitted from
preferences generated by the current policy and the policy is then
updated under a KL-regularized objective \[[Ding et al.,
2024](#bib.bib3)\]:

|  |  |  |  |
|----|----|----|----|
|  | (upper) | $`\displaystyle\min_{r}\;-\,\mathbb{E}_{\begin{subarray}{c}\mathbf{x}\sim\mathcal{P},\;\mathbf{y}_{i}\sim\pi_{r}^{*}(\cdot\mid\mathbf{x}),\\
(\mathbf{y}_{w}\succ\mathbf{y}_{l})\sim p_{*}\end{subarray}}`$ |  |
|  |  | $`\displaystyle\Big[\,\log\sigma\big(r(\mathbf{x},\mathbf{y}_{w})-r(\mathbf{x},\mathbf{y}_{l})\big)\,\Big]`$ |  |
|  | (lower) | $`\displaystyle\text{s.t.}\;\;\pi_{r}^{*}:=\arg\max_{\pi}\;\mathbb{E}_{\mathbf{x}\sim\mathcal{P}}\Big[\,\mathbb{E}_{\mathbf{y}\sim\pi(\cdot\mid\mathbf{x})}\big[\,r(\mathbf{y},\mathbf{x})-`$ |  |
|  |  | $`\displaystyle\beta\,D_{\mathrm{KL}}\!\big(\pi(\cdot\mid\mathbf{x})\,\|\,\pi_{\mathrm{SFT}}(\cdot\mid\mathbf{x})\big)\,\big]\Big].`$ |  |

Due to the special structure of the equivalence between the reward
function and the LLM policy see \[[Rafailov et al., 2024](#bib.bib11)\],
we get the closed-form solution of the inner objective as

|  |  |  |
|----|----|----|
|  | $`\displaystyle r(\mathbf{x},\mathbf{y})=\beta\log\frac{\pi_{r}^{*}(\mathbf{y}\mid\mathbf{x})}{\pi_{\mathrm{SFT}}(\mathbf{y}\mid\mathbf{x})}+\beta\log Z(\mathbf{x}).`$ |  |

The above problem becomes an optimization over the space of
$`\pi_{r}^{*}`$, which we solve via parametrization as \[[Rafailov et
al., 2024](#bib.bib11), [Ding et al., 2024](#bib.bib3)\]

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\max_{\theta}\;J(\theta)`$ | $`\displaystyle=\mathbb{E}_{\begin{subarray}{c}\mathbf{x}\sim\mathcal{P},\;\mathbf{y}_{i}\sim\pi_{\theta}(\cdot\mid\mathbf{x}),\\
(\mathbf{y}_{w}\succ\mathbf{y}_{l})\sim p_{*}\end{subarray}}\![\log\sigma\!\Big(\beta\log\frac{\pi_{\theta}(\mathbf{y}_{w}\mid\mathbf{x})}{\pi_{\mathrm{SFT}}(\mathbf{y}_{w}\mid\mathbf{x})}-`$ |  |
|  |  | $`\displaystyle\beta\log\frac{\pi_{\theta}(\mathbf{y}_{l}\mid\mathbf{x})}{\pi_{\mathrm{SFT}}(\mathbf{y}_{l}\mid\mathbf{x})}\Big)].`$ |  |

The Performance Difference Lemma is a standard tool for establishing
global performance bounds \[[Ding et al., 2024](#bib.bib3)\]. It states

|  |  |  |
|----|----|----|
|  |
``` math
J_{r}(\pi^{\prime})-J_{r}(\pi)=\frac{1}{1-\gamma}\,\mathbb{E}_{\,s\sim d^{\pi^{\prime}},\,a\sim\pi^{\prime}}\big[\,A_{r}^{\pi}(s,a)\,\big],
``` |  |

which critically assumes that the reward $`r`$ and the evaluation
measure are independent of the policy parameter used inside the
advantage $`A_{r}^{\pi}`$. This independence is crucial; once the reward
or evaluation metric itself depends on the policy, the lemma no longer
applies.

Consequently, we analyze the *geometry* of $`J`$ directly; in
particular, we study the regime where
$`-\nabla^{2}J(\theta)\succeq\mu I`$ (local strong concavity/PL) and
show that the unregularized objective only enjoys this property within a
small neighborhood of $`\theta_{0}`$.

For completeness, Appendix
[A.7](#A1.SS7 "A.7 Stationarity Under General Policy Parameterizations ‣ Appendix A Proofs for Theorems ‣ On the Convergence of Self-Improving Online LLM Alignment")
shows that the original SAIL objective, corresponding to $`\gamma=0`$,
also admits a standard first-order stationarity guarantee under general
differentiable policy parameterizations. Under Assumptions
[3](#Thmassumption3 "Assumption 3 (L-smoothness). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
and
[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment"),
projected stochastic ascent reaches an $`\varepsilon`$-stationary point
with sample complexity $`\mathcal{O}(\varepsilon^{-2})`$; this auxiliary
result does not imply global optimality.

###### Theorem 1 (Local Strong Concavity and Polyak–Łojasiewicz Condition for SAIL).

Under Assumptions
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
and
[2](#Thmassumption2 "Assumption 2 (Fisher information lower bound). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
define

|     |                                                    |     |
|-----|----------------------------------------------------|-----|
|     |
       ``` math
       f(x):=-e^{2x}+\log\!\left(2+e^{2x}+e^{-2x}\right).
       ```                                                 |     |

Let $`x_{\star}>0`$ denote the unique positive root of $`f(x)=0`$¹¹ 1
Numerically, $`x_{\star}\approx 0.174`$. For $`0<B\leq B_{\theta}`$,
define the local parameter region centered at the initial parameter
$`\theta_{0}`$ as

|  |  |  |
|----|----|----|
|  |
``` math
\Theta_{\mathrm{loc}}(B):=\left\{\theta\in\mathbb{R}^{d}:\|\theta-\theta_{0}\|_{2}\leq B\right\}.
``` |  |

If

|     |                      |     |
|-----|----------------------|-----|
|     |
       ``` math
       0<\beta B<x_{\star},
       ```                   |     |

then, for every $`\theta\in\Theta_{\mathrm{loc}}(B)`$,

|     |                                               |     |
|-----|-----------------------------------------------|-----|
|     |
       ``` math
       -\nabla^{2}J(\theta)\succeq\mu I,\qquad\mu>0.
       ```                                            |     |

Consequently, $`J`$ satisfies the Polyak–Łojasiewicz inequality on
$`\Theta_{\mathrm{loc}}(B)`$:

|  |  |  |
|----|----|----|
|  |
``` math
\|\nabla J(\theta)\|_{2}^{2}\geq 2\mu\left(J(\theta_{B}^{\star})-J(\theta)\right),\qquad\forall\theta\in\Theta_{\mathrm{loc}}(B),
``` |  |

where

|  |  |  |
|----|----|----|
|  |
``` math
\theta_{B}^{\star}:=\operatorname*{arg\,max}_{\theta\in\Theta_{\mathrm{loc}}(B)}J(\theta).
``` |  |

###### Remark 3 (Motivation for Regularization).

Theorem
[1](#Thmtheorem1 "Theorem 1 (Local Strong Concavity and Polyak–Łojasiewicz Condition for SAIL). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
reveals a critical limitation of the original SAIL objective
$`J(\theta)`$. While it possesses desirable strong concavity and the
resulting Polyak-Lojasiewicz (PL) condition, this property is guaranteed
only within a local neighborhood $`\|\theta-\theta_{0}\|_{2}\leq B`$
whose radius $`B`$ is constrained by the hyperparameter $`\beta`$
(specifically, $`\beta B<x_{\star}`$).

To establish a global convergence guarantee for the regularized
surrogate over the stated bounded feasible set, it is imperative to
reshape the optimization landscape. The introduction of the reverse-KL
regularizer in Section
[4.2](#S4.SS2 "4.2 Regularized Objective ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
achieves this by adding Fisher-type positive curvature. With an
appropriate $`\gamma`$, the regularized objective $`J_{\gamma}(\theta)`$
satisfies the PL condition on the feasible set considered in our
analysis.

#### Proof Sketch for Theorem [1](#Thmtheorem1 "Theorem 1 (Local Strong Concavity and Polyak–Łojasiewicz Condition for SAIL). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")

The proof analyzes the geometry of the original SAIL objective
$`J(\theta)`$ to understand its limitations. Our key technical
contribution is a novel decomposition of its negative Hessian,
$`-\nabla^{2}J(\theta)`$, into four functionally distinct terms, which
can be expressed conceptually as:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle-\nabla^{2}J(\theta)=2\mathbb{E}\big[`$ | $`\displaystyle\underbrace{-SS^{\top}F_{\theta}}_{\text{(a) Score Curvature}}\underbrace{-2S(\nabla_{\theta}F_{\theta})^{\top}}_{\text{(b) Cross-term}}`$ |  |
|  |  | $`\displaystyle\underbrace{-HF_{\theta}}_{\text{(c) Fisher-Hessian}}\underbrace{-\nabla^{2}_{\theta}F_{\theta}}_{\text{(d) Sigmoid Curvature}}\big]`$ |  |

where the expectation is taken over the data distribution. Here,
$`S:=\nabla_{\theta}\log(\pi_{\theta}(y_{w}|x)\pi_{\theta}(y_{l}|x))`$
is the score vector for the response pair,
$`H:=\nabla_{\theta}^{2}\log(\pi_{\theta}(y_{w}|x)\pi_{\theta}(y_{l}|x))`$
is the corresponding Hessian of the log-policy, and
$`F_{\theta}:=\log\sigma(\beta(\theta-\theta_{0})^{\top}z)`$ is the
log-sigmoid term from the objective, with $`z`$ representing the feature
difference $`\psi(x,y_{w})-\psi(x,y_{l})`$. By carefully bounding each
term under Assumptions
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
and
[2](#Thmassumption2 "Assumption 2 (Fisher information lower bound). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
we demonstrate that the complex matrix condition for strong concavity
(i.e., $`-\nabla^{2}J(\theta)\succeq\mu I`$) reduces to a simple scalar
condition.

The analysis reveals that the positive definiteness is governed by a
critical trade-off. While some terms, such as the Sigmoid Curvature (d),
contribute positively, the term related to the Fisher-Hessian identity
(c) acts as a negative contributor to the positive definiteness of
$`-\nabla^{2}J(\theta)`$. Crucially, the magnitude of this negative
contribution is controlled by the scalar coefficient $`F_{\theta}`$,
which grows with the parameter distance $`x=\beta B`$. As parameters
move further from the initialization $`\theta_{0}`$, this negative
effect begins to dominate, eventually causing the entire matrix to lose
its positive definiteness. This entire failure mechanism is captured
precisely by the sign of the function
$`f(x)=-e^{2x}+\log(2+e^{2x}+e^{-2x})`$. This result allows us to
pinpoint the root cause of the optimization challenge: strong concavity
is only guaranteed in a local region where $`f(x)>0`$, thus motivating
the need for regularization. The full derivation is detailed in Appendix
[A.1](#A1.SS1 "A.1 Proof for Theorem ‣ Appendix A Proofs for Theorems ‣ On the Convergence of Self-Improving Online LLM Alignment").

### 4.2 Regularized Objective

Fix a reference policy $`\pi_{\mathrm{ref}}`$, we add $`J`$ with a
reverse–KL penalty:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle J_{\gamma}(\theta)\;`$ | $`\displaystyle:=\;J(\theta)\;-\;\gamma\,\mathbb{E}_{x}\!\Big[D_{\mathrm{KL}}\!\big(\pi_{\mathrm{ref}}(\cdot\mid x)\,\|\,\pi_{\theta}(\cdot\mid x)\big)\Big]`$ |  |

where $`\gamma>0`$.

###### Remark 4 (On the Choice of Reference Policy).

The reference policy $`\pi_{\mathrm{ref}}`$ in the RevKL regularizer
serves as a fixed anchor to prevent the learned policy $`\pi_{\theta}`$
from deviating excessively from a known, stable distribution. In
practice, a natural choice for $`\pi_{\mathrm{ref}}`$ is the initial
Supervised Fine-Tuning (SFT) policy, $`\pi_{\mathrm{SFT}}`$, which
ensures that the aligned model retains the general capabilities acquired
during pre-training and fine-tuning. Alternatively, in an iterative
online learning setting, $`\pi_{\mathrm{ref}}`$ could be set to the
policy from a previous iteration, $`\pi_{t-1}`$, to regularize the
magnitude of a single update step. Our theoretical analysis holds for
any fixed, valid reference policy.

###### Theorem 2 (Strong Concavity and Polyak-Lojasiewicz Condition for SAIL RevKL).

Under Assumptions
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
and
[2](#Thmassumption2 "Assumption 2 (Fisher information lower bound). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
the regularized objective $`J_{\gamma}`$ is strongly concave on the
algorithmic feasible set

|  |  |  |
|----|----|----|
|  |
``` math
\Theta=\{\theta\in\mathbb{R}^{d}:\|\theta-\theta_{0}\|_{2}\leq B_{\theta}\}.
``` |  |

Let

|  |  |  |
|----|----|----|
|  |
``` math
\gamma>4\log(\sigma(2\beta B_{\theta}))+\frac{4\sigma(2\beta B_{\theta})\beta}{\varepsilon}+4\log(\sigma(-2\beta B_{\theta})).
``` |  |

Then, for all $`\theta\in\Theta`$,

|     |                                                        |     |
|-----|--------------------------------------------------------|-----|
|     |
       ``` math
       -\nabla^{2}J_{\gamma}(\theta)\succeq\mu I,\qquad\mu>0.
       ```                                                     |     |

Consequently,

|  |  |  |
|----|----|----|
|  |
``` math
\|\nabla J_{\gamma}(\theta)\|^{2}\geq 2\mu\bigl(J_{\gamma}(\theta^{\ast})-J_{\gamma}(\theta)\bigr),\qquad\theta^{\ast}=\arg\max_{\theta\in\Theta}J_{\gamma}(\theta).
``` |  |

###### Remark 5 (Local Region and Algorithmic Feasible Set).

The set $`\Theta`$ is the bounded feasible set enforced by the projected
algorithm, whereas $`\Theta_{\mathrm{loc}}(B)`$ is used only to describe
the local geometry of the unregularized SAIL objective. Since both sets
are centered at $`\theta_{0}`$, we have
$`\Theta_{\mathrm{loc}}(B)\subseteq\Theta`$ whenever
$`B\leq B_{\theta}`$. Theorem
[2](#Thmtheorem2 "Theorem 2 (Strong Concavity and Polyak-Lojasiewicz Condition for SAIL RevKL). ‣ 4.2 Regularized Objective ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
establishes the PL geometry of the regularized surrogate on the full
feasible set $`\Theta`$.

#### Proof Sketch for Theorem [2](#Thmtheorem2 "Theorem 2 (Strong Concavity and Polyak-Lojasiewicz Condition for SAIL RevKL). ‣ 4.2 Regularized Objective ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")

Theorem
[1](#Thmtheorem1 "Theorem 1 (Local Strong Concavity and Polyak–Łojasiewicz Condition for SAIL). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
reveals that the original SAIL objective $`J(\theta)`$ lacks global
strong concavity. To address this, we introduce the regularized
objective
$`J_{\gamma}(\theta)=J(\theta)-\gamma\mathbb{E}_{x}[D_{KL}(\pi_{ref}||\pi_{\theta})]`$.
The key technical insight of our work lies in the analysis of its
negative Hessian:

|  |  |  |
|----|----|----|
|  |
``` math
-\nabla^{2}J_{\gamma}(\theta)=(-\nabla^{2}J(\theta))+\gamma\nabla_{\theta}^{2}\Big(\mathbb{E}_{x}\big[D_{\mathrm{KL}}(\pi_{\mathrm{ref}}\|\pi_{\theta})\big]\Big)
``` |  |

Here, the first term, $`-\nabla^{2}J(\theta)`$, is the problematic
Hessian from Theorem
[1](#Thmtheorem1 "Theorem 1 (Local Strong Concavity and Polyak–Łojasiewicz Condition for SAIL). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
which is only locally positive definite. The second term is the Hessian
of our RevKL regularizer.

The crucial observation is that the Hessian of the RevKL penalty,
$`\nabla_{\theta}^{2}\Big(\mathbb{E}_{x}\big[D_{\mathrm{KL}}(\pi_{\mathrm{ref}}\|\pi_{\theta})\big]\Big)`$,
is precisely the Fisher Information Matrix. While this term contributed
negatively within the structure of $`-\nabla^{2}J(\theta)`$, our
regularizer adds it back as a purely positive definite term, scaled by
$`\gamma`$. This allows us to directly control the strength of this
positive curvature. By choosing a $`\gamma`$ large enough to overwhelm
the internal negative effects for all parameters in the feasible set, we
effectively expand the region of strong concavity to cover the entire
domain, thus restoring the global PL condition. The full derivation is
in Appendix
[A.2](#A1.SS2 "A.2 Proof for Theorem ‣ Appendix A Proofs for Theorems ‣ On the Convergence of Self-Improving Online LLM Alignment").

### 4.3 Algorithm

To ensure that the policy parameter $`\theta`$ remains within the
bounded set
$`\Theta:=\{\theta\in\mathbb{R}^{d}:\|\theta-\theta_{0}\|_{2}\leq B_{\theta}\}.`$
as required by Assumption
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
we employ a projected gradient ascent scheme. This is a standard method
for constrained optimization where the iterates are projected back onto
the feasible set after each gradient step \[[Boyd and Vandenberghe,
2004](#bib.bib5)\].

1: Initial parameters $`\theta_{0}`$, stepsize $`\eta\leq 1/L_{eff}`$,
batch size $`B_{s}`$, KL weight $`\gamma\geq 0`$, parameter bound
$`B_{\theta}`$.

2: The parameter set in Assumption
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
is
$`\Theta:=\{\theta\in\mathbb{R}^{d}:\|\theta-\theta_{0}\|_{2}\leq B_{\theta}\}`$..

3: for $`t=0`$ to $`T-1`$ do

4:   Sample $`x_{i}\sim\mathbb{P}`$ and
$`y^{j}_{i}\sim\pi_{\theta_{t}}(\cdot\mid x_{i})`$.$`y^{j}_{i}`$ are
labeled as $`y_{w}`$ and $`y_{l}`$ according to preference annotations.

5:   Compute loss:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\hat{\mathcal{L}}_{\mathrm{pair}}(\theta_{t})=\frac{1}{B_{s}}\sum_{i=1}^{B_{s}}\log\sigma\biggl(`$ | $`\displaystyle\beta\log\frac{\pi_{\theta_{t}}(y_{w}\mid x_{i})}{\pi_{\mathrm{SFT}}(y_{w}\mid x_{i})}`$ |  |
|  |  | $`\displaystyle-\beta\log\frac{\pi_{\theta_{t}}(y_{l}\mid x_{i})}{\pi_{\mathrm{SFT}}(y_{l}\mid x_{i})}\biggr)`$ |  |

6:   Compute reverse KL penalty:
$`\displaystyle\mathrm{KL}_{i}=D_{\mathrm{KL}}\!\big(\pi_{\mathrm{ref}}(\cdot\mid x_{i})\,\|\,\pi_{\theta_{t}}(\cdot\mid x_{i})\big)`$

7:   Compute loss with reverse KL penalty:
$`\displaystyle\hat{\mathcal{L}}_{\gamma}(\theta_{t})=\hat{\mathcal{L}}_{\mathrm{pair}}(\theta_{t})-\frac{\gamma}{B_{s}}\sum_{i=1}^{B_{s}}\mathrm{KL}_{i}`$

8:   Compute gradient:
$`\hat{g_{t}}=\nabla_{\theta}\hat{\mathcal{L}}_{\gamma}(\theta_{t})`$

9:   Gradient ascent update:
$`\theta^{\prime}_{t+1}=\theta_{t}+\eta\hat{g_{t}}`$

10:   $`\theta_{t+1}=\Pi_{\Theta}(\theta^{\prime}_{t+1})`$

11: end for

12: return $`\theta_{T}`$

Algorithm 1 SAIL RevKL with Projection

###### Remark 6.

The Euclidean projection operator $`\Pi_{\Theta}`$ onto the L2-ball
$`\Theta`$ is defined as:

|  |  |  |
|----|----|----|
|  |
``` math
\Pi_{\Theta}(v)=\theta_{0}+\min\left(1,\frac{B_{\theta}}{\|v-\theta_{0}\|_{2}}\right)(v-\theta_{0}).
``` |  |

Hence, it ensures that the parameter constraint

|     |                                               |     |
|-----|-----------------------------------------------|-----|
|     |
       ``` math
       \|\theta_{t}-\theta_{0}\|_{2}\leq B_{\theta}.
       ```                                            |     |

is satisfied at every iteration $`t`$ by construction.

Our algorithm describes the gradient computation using the compact
notation
$`\hat{g}_{t}=\nabla_{\theta}\mathcal{L}_{\gamma}(\theta_{t})`$. Due to
the linearity of the gradient operator, this computation is
mathematically equivalent to averaging the gradients from individual
samples: $`\hat{g}_{t}=\frac{1}{B_{s}}\sum_{i=1}^{B_{s}}g_{t}^{(i)}`$,
where
$`g_{t}^{(i)}=\log\sigma\!(\beta\log\frac{\pi_{\theta_{t}}(y_{w}\mid x_{i})}{\pi_{\mathrm{SFT}}(y_{w}\mid x_{i})}-\beta\log\frac{\pi_{\theta_{t}}(y_{l}\mid x_{i})}{\pi_{\mathrm{SFT}}(y_{l}\mid x_{i})})-\gamma\cdot\mathrm{KL}_{i}`$.

This equivalence allows our theoretical framework, based on the
per-sample gradient properties defined in Assumption
[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment"),
to apply directly. Consequently, the mini-batch gradient $`\hat{g}_{t}`$
used in our algorithm is guaranteed by Lemma
[6](#Thmlemma6 "Lemma 6. ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment")
to have its variance reduced by the factor of the batch size $`B_{s}`$.

## 5 THEORETICAL RESULTS

### 5.1 Convergence Analysis

We adopt the following standard assumptions on the regularized objective
and on the stochastic gradient estimator.

###### Assumption 3 (L-smoothness).

The objective function $`J_{\gamma}(\theta)`$ is $`L`$-smooth with
respect to $`\theta`$, i.e., there exists a constant $`L>0`$ such that:

|  |  |  |
|----|----|----|
|  |
``` math
\|\nabla J_{\gamma}(\theta)-\nabla J_{\gamma}(\theta^{\prime})\|\leq L\|\theta-\theta^{\prime}\|\quad\text{for all }\theta,\theta^{\prime}.
``` |  |

###### Remark 7.

While Lemma
[7](#Thmlemma7 "Lemma 7 (L-smoothness of the Objective Function). ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment")
shows that L-smoothness can be formally derived from Assumption
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
the resulting smoothness constant is too large to establish a meaningful
global convergence rate. Therefore, for our main theoretical results, we
directly assume a sufficiently small L-smoothness constant as stated in
Assumption
[3](#Thmassumption3 "Assumption 3 (L-smoothness). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment").

###### Assumption 4 (Unbiased Stochastic Gradients).

Let
$`g_{t}^{(i)}:=\nabla_{\theta}\mathcal{L}_{\gamma}^{(i)}(\theta_{t})`$
denote the stochastic gradient computed from the $`i`$-th sample in the
mini-batch at iteration $`t`$. We assume each stochastic gradient
$`g_{t}^{(i)}`$ is an unbiased estimator of the true gradient
$`\nabla J_{\gamma}(\theta_{t})`$, and its variance is bounded:

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}[g_{t}^{(i)}]=\nabla J_{\gamma}(\theta_{t}),\quad\mathbb{E}[\|g_{t}^{(i)}-\nabla J_{\gamma}(\theta_{t})\|^{2}]\leq\sigma_{g}^{2}.
``` |  |

###### Remark 8.

Assumption
[3](#Thmassumption3 "Assumption 3 (L-smoothness). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")-[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")

variance-reduced variants \[[Agarwal et al., 2021](#bib.bib10), [Papini
et al., 2018](#bib.bib26), [Xu et al., 2019](#bib.bib27), [Xu et al.,
2021](#bib.bib28), [Liu et al., 2020](#bib.bib4)\]. A similar form of
Assumption
[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
also appears in the bilevel-optimization literature \[[Gaur et al.,
2025](#bib.bib31), [Kwon et al., 2024](#bib.bib29), [Chen et al.,
2025](#bib.bib30)\].

Under Assumptions
[3](#Thmassumption3 "Assumption 3 (L-smoothness). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")–[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")

artificially constrain the optimization to a strictly limited local
region to satisfy the PL condition, which could introduce a significant,
unquantifiable, and potentially unbounded parametrization error if the
true global optimum $`\theta^{*}`$ lies outside this region. In
contrast, our RevKL objective effectively trades this unquantifiable
structural error for a mathematically bounded regularization bias ,
while unlocking the full feasible set for global exploration.

Empirically, the coefficient sweep in Section
[6](#S6 "6 EXPERIMENTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
indicates that moderate values of $`\gamma`$ can improve optimization
stability, while overly strong regularization may degrade performance.
Thus, $`\gamma`$ controls a trade-off between curvature stabilization
and regularization bias.

The full proof is detailed in Appendix
[A.6](#A1.SS6 "A.6 Proof for Theorem ‣ Appendix A Proofs for Theorems ‣ On the Convergence of Self-Improving Online LLM Alignment").

### 6.1 Continuous Control Experiments

We evaluate SAIL-RevKL on challenging continuous control benchmarks,
including the Walker locomotion tasks from the DeepMind Control Suite
\[[Tassa et al., 2018](#bib.bib34)\] and the Door Open manipulation task
from Meta-World \[[Yu et al., 2020](#bib.bib32)\]. We compare our
approach against two strong baselines. The first is PEBBLE \[[Lee et
al., 2021](#bib.bib35)\], a widely recognized algorithm for
preference-based reinforcement learning. The second is a critical
ablation of our method: the unregularized SAIL algorithm, which is
equivalent to setting the regularization weight $`\gamma=0`$ in our
framework. Learning curves are reported in Figures
[1](#S5.F1 "Figure 1 ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment").
Across all tasks, SAIL-RevKL demonstrates consistently improved learning
stability and final performance.

To quantify the practical significance of these improvements beyond raw
return values, Table
[2](#S5.T2 "Table 2 ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
reports effect sizes measured by Cohen’s $`d`$, which captures the
magnitude of performance differences normalized by variability across
random seeds.Following standard statistical conventions \[[Cohen,
1988](#bib.bib33)\], values of Cohen’s $`d`$ around 0.2, 0.5, and 0.8
correspond to small, medium, and large effects, respectively.

### 6.2 Large Language Model Experiments

Table
[3](#S5.T3 "Table 3 ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
details the performance on the PKU-SafeRLHF dataset [Ji et al.
\[2025\]](#bib.bib37), which specifically assesses the model’s ability
to balance helpfulness and harmlessness. In contrast, Table
[4](#S5.T4 "Table 4 ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
reports results on UltraFeedback [Cui et al. \[2023\]](#bib.bib36), a
benchmark designed to evaluate general instruction-following and
response quality. Across both datasets and all backbones, the results
consistently demonstrate that incorporating the reverse-KL (RevKL)
penalty significantly improves pairwise win rates compared to both DPO
and the vanilla SAIL method.

To evaluate these results, we adopt the LLM-as-a-Judge framework
\[[Zheng et al., 2023](#bib.bib41)\] using GPT-4\[[Achiam et al.,
2023](#bib.bib42)\] to calculate: (i) Pairwise winrate, the preference
rate against the chosen response; (ii) Tie rate, the frequency of
comparable quality; and (iii) Mean GPT score difference, the mean
difference between the GPT score assigned to the evaluated response and
that assigned to the reference response.

#### Last-layer-only Large Language Model Experiments.

The main LLM experiments above use LoRA fine-tuning and therefore should
not be interpreted as direct empirical instantiations of Assumption
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment").
Instead, they show that the stabilizing effect of RevKL can transfer to
practical nonlinear fine-tuning regimes.

To directly validate the theoretical log-linear regime, we further
evaluate a last-layer-only (LLO) setting, where all backbone parameters
are frozen and only the final linear layer is trained. In this setting,
the trainable score is linear in the updated parameters and hence most
closely matches the log-linear policy class analyzed in our theory.

As shown in Table
[5](#S5.T5 "Table 5 ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment"),
SAIL-RevKL improves the win rate over vanilla SAIL across all three
backbones for moderate values of $`\gamma`$. The best coefficient is
scale-dependent: Qwen-0.5B peaks at $`\gamma=10^{-2}`$, whereas
Phi-3-3.8B and LLaMA-3-8B obtain the highest win rates at
$`\gamma=10^{-1}`$. These results provide theory-matched evidence that
the RevKL term improves the optimization behavior of SAIL in the regime
covered by our main analysis, while the LoRA results in Tables
[3](#S5.T3 "Table 3 ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
and
[4](#S5.T4 "Table 4 ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
demonstrate empirical transfer beyond this controlled setting.

## 7 CONCLUSION

We study online LLM alignment through the bilevel RL approach in \[[Ding
et al., 2024](#bib.bib3)\] and provide the first convergence guarantees
for its single-level surrogate. We show that the unregularized objective
may lack favorable curvature; adding a reverse–KL penalty yields strong
concavity and a Polyak–Łojasiewicz geometry on a bounded parameter set.
Under these conditions, we obtain nonasymptotic guarantees for projected
stochastic ascent, comprising a global linear convergence of the reverse
KL regularized SAIL objective throughout the feasible region. These
results clarify when SAIL becomes a well-conditioned first-order problem
and offer concrete guidance for setting the KL weight, stepsize, and
batch size.

## Appendix A Proofs for Theorems

### A.1 Proof for Theorem [1](#Thmtheorem1 "Theorem 1 (Local Strong Concavity and Polyak–Łojasiewicz Condition for SAIL). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")

###### Proof.

The SAIL objective \[[Ding et al., 2024](#bib.bib3)\] is

|  |  |  |
|----|----|----|
|  |
``` math
\max_{\theta}J(\theta)=\mathbb{E}_{\begin{subarray}{c}\mathbf{x}\sim\mathcal{P},\ \mathbf{y}_{i}\sim\pi_{\theta}(\cdot\mid\mathbf{x}),\\
(y_{w}\succ y_{l})\sim p_{*}\end{subarray}}\left[\log\sigma\!\left(\beta\log\frac{\pi_{\theta}(y_{w}\mid\mathbf{x})}{\pi_{\mathrm{SFT}}(y_{w}\mid\mathbf{x})}-\beta\log\frac{\pi_{\theta}(y_{l}\mid\mathbf{x})}{\pi_{\mathrm{SFT}}(y_{l}\mid\mathbf{x})}\right)\right]
``` |  |

Denote

|  |  |  |
|----|----|----|
|  |
``` math
F_{\theta}(x,\mathbf{y}_{w},\mathbf{y}_{l}):=\log\sigma\bigl(\beta\log\tfrac{\pi_{\theta}(\mathbf{y}_{w}\mid x)}{\pi_{\rm SFT}(\mathbf{y}_{w}\mid x)}-\beta\log\tfrac{\pi_{\theta}(\mathbf{y}_{l}\mid x)}{\pi_{\rm SFT}(\mathbf{y}_{l}\mid x)}\bigr)
``` |  |

Define the normalization constant

|  |  |  |
|----|----|----|
|  |
``` math
Z(\theta,x)\;:=\;\mathbb{E}_{(y_{w},y_{l})\sim\pi_{\theta}(\cdot\mid x)\otimes\pi_{\theta}(\cdot\mid x)}\big[P^{*}(y_{w}>y_{l}\mid x)\big].
``` |  |

When ties are possible (e.g., $`y_{w}=y_{l}`$), we adopt *randomized
tie-breaking* and simply interpret the given external preference as
splitting the tie mass evenly between the two directions. Concretely,
for all $`a,b`$ and fixed $`x`$ we read

|  |  |  |
|----|----|----|
|  |
``` math
P^{*}(a>b\mid x)\ \leftarrow\ P^{*}(a>b\mid x)\;+\;\tfrac{1}{2}\,P^{*}(a=b\mid x),\qquad P^{*}(b>a\mid x)\ \leftarrow\ P^{*}(b>a\mid x)\;+\;\tfrac{1}{2}\,P^{*}(a=b\mid x),
``` |  |

so that

|     |                                      |     |
|-----|--------------------------------------|-----|
|     |
       ``` math
       P^{*}(a>b\mid x)+P^{*}(b>a\mid x)=1.
       ```                                   |     |

By exchange symmetry of the base pair measure
$`\pi_{\theta}(y_{w}\mid x)\pi_{\theta}(y_{l}\mid x)=\pi_{\theta}(y_{l}\mid x)\pi_{\theta}(y_{w}\mid x)`$,
we pair $`(a,b)`$ with $`(b,a)`$ to get

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle 2Z(\theta,x)`$ | $`\displaystyle=\sum_{a,b}\pi_{\theta}(a\mid x)\pi_{\theta}(b\mid x)\,P^{*}(a>b\mid x)+\sum_{a,b}\pi_{\theta}(b\mid x)\pi_{\theta}(a\mid x)\,P^{*}(b>a\mid x)`$ |  |
|  |  | $`\displaystyle=\sum_{a,b}\pi_{\theta}(a\mid x)\pi_{\theta}(b\mid x)\big(P^{*}(a>b\mid x)+P^{*}(b>a\mid x)\big)=\sum_{a,b}\pi_{\theta}(a\mid x)\pi_{\theta}(b\mid x)=1.`$ |  |

hence

|     |                               |     |
|-----|-------------------------------|-----|
|     |
       ``` math
       \,Z(\theta,x)=\tfrac{1}{2}\,.
       ```                            |     |

Therefore the ordered-pair sampling distribution is the *normalized*
weight:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\;\Pi_{\theta}^{\text{order}}(y_{w},y_{l}\mid x)`$ | $`\displaystyle=\frac{\pi_{\theta}(y_{w}\mid x)\pi_{\theta}(y_{l}\mid x)\,P^{*}(y_{w}>y_{l}\mid x)}{Z(\theta,x)}`$ |  |
|  |  | $`\displaystyle=2\,P^{*}(y_{w}>y_{l}\mid x)\,\pi_{\theta}(y_{w}\mid x)\pi_{\theta}(y_{l}\mid x)\;`$ |  |
|  |  | $`\displaystyle:=2\,P^{*}(y_{w}>y_{l}\mid x)\,\Pi_{\theta}(y_{w},y_{l}\mid x).\;`$ |  |

In particular, since $`P^{*}`$ is $`\theta`$-independent,

|  |  |  |
|----|----|----|
|  |
``` math
\nabla_{\theta}\log\Pi_{\theta}^{\text{order}}(y_{w},y_{l}\mid x)=\nabla_{\theta}\log\pi_{\theta}(y_{w}\mid x)+\nabla_{\theta}\log\pi_{\theta}(y_{l}\mid x).
``` |  |

Since the policy $`\Pi_{\theta}`$ is related to $`\theta`$, from \[[Ding
et al., 2024](#bib.bib3)\], we have:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla_{\theta}J(\theta)`$ | $`\displaystyle=2\nabla_{\theta}\sum_{x,y_{w},y_{l}}\pi_{\theta}(y_{w}\mid\mathbf{x})\pi_{\theta}(y_{l}\mid\mathbf{x})P^{*}(y_{w}>y_{l})\left[\log\sigma\left(\beta\log\frac{\pi_{\theta}(y_{w}\mid\mathbf{x})}{\pi_{\mathrm{SFT}}(y_{w}\mid\mathbf{x})}-\beta\log\frac{\pi_{\theta}(y_{l}\mid\mathbf{x})}{\pi_{\mathrm{SFT}}(y_{l}\mid\mathbf{x})}\right)\right]`$ |  |
|  |  | $`\displaystyle=2\nabla_{\theta}\sum_{x,y_{w},y_{l}}\Pi_{\theta}(y_{w},y_{l}\mid\mathbf{x})P^{*}(y_{w}>y_{l})\left[F_{\theta}(x,y_{w},y_{l})\right]`$ |  |
|  |  | $`\displaystyle=2\sum_{x,y_{w},y_{l}}P^{*}(y_{w}>y_{l})\nabla_{\theta}\Pi_{\theta}(y_{w},y_{l}\mid\mathbf{x})\left[F_{\theta}(x,y_{w},y_{l})\right]`$ |  |
|  |  | $`\displaystyle=2\sum_{x,\mathbf{y}_{w},\mathbf{y}_{l}}P^{*}(y_{w}>y_{l})\big(\underbrace{\nabla_{\theta}\Pi_{\theta}(\mathbf{y}_{w},\mathbf{y}_{l}\mid\mathbf{x})\left[F_{\theta}(x,\mathbf{y}_{w},\mathbf{y}_{l})\right]}_{T_{1}}+\underbrace{\Pi_{\theta}(\mathbf{y}_{w},\mathbf{y}_{l}\mid\mathbf{x})\left[\nabla_{\theta}F_{\theta}(x,\mathbf{y}_{w},\mathbf{y}_{l})\right]}_{T_{2}}\big)`$ |  |

hence, the second order derivative is

|  |  |  |
|----|----|----|
|  |
``` math
\nabla^{2}J(\theta)=2\sum_{x,\mathbf{y}_{w},\mathbf{y}_{l}}P^{*}(y_{w}>y_{l})\bigl[\nabla^{2}\Pi_{\theta}\,F_{\theta}+\nabla\Pi_{\theta}\,(\nabla J_{\theta})^{\!\top}+\nabla J_{\theta}\,(\nabla\Pi_{\theta})^{\!\top}+\Pi_{\theta}\,\nabla^{2}F_{\theta}\bigr].
``` |  |

Under the log-linear policy Assumption from Assumption
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
we can express the ratio of the policy $`\pi_{\theta}`$ to a pre-trained
reference policy, $`\pi_{\text{SFT}}`$. We define the reference policy
as being parameterized by a fixed vector $`\theta_{0}`$, such that
$`\pi_{\text{SFT}}(y|x)=\pi_{\theta_{0}}(y|x)`$. The derivation of the
ratio is as follows:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\frac{\pi_{\theta}(y|x)}{\pi_{\text{SFT}}(y|x)}`$ | $`\displaystyle=\frac{\exp(\theta^{\top}\psi(x,y))/\sum_{y^{\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,y^{\prime}))}{\exp(\theta_{0}^{\top}\psi(x,y))/\sum_{y^{\prime}\in\mathcal{A}}\exp(\theta_{0}^{\top}\psi(x,y^{\prime}))}`$ |  |
|  |  | $`\displaystyle=\left(\frac{\sum_{y^{\prime}\in\mathcal{A}}\exp(\theta_{0}^{\top}\psi(x,y^{\prime}))}{\sum_{y^{\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,y^{\prime}))}\right)\frac{\exp(\theta^{\top}\psi(x,y))}{\exp(\theta_{0}^{\top}\psi(x,y))}`$ |  |
|  |  | $`\displaystyle:=\frac{Z_{\theta_{0}}(x)}{Z_{\theta}(x)}\frac{\exp(\theta^{\top}\psi(x,y))}{\exp(\theta_{0}^{\top}\psi(x,y))},\text{where }Z_{\theta}(x):=\sum_{y^{\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,y^{\prime})).`$ |  |

Taking the natural logarithm of the ratio allows for a convenient linear
decomposition of its terms:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\log\frac{\pi_{\theta}(y|x)}{\pi_{\text{SFT}}(y|x)}`$ | $`\displaystyle=\log\left(\exp(\theta^{\top}\psi(x,y)-\theta_{0}^{\top}\psi(x,y))\right)+\log\left(\frac{Z_{\theta_{0}}(x)}{Z_{\theta}(x)}\right)`$ |  |
|  |  | $`\displaystyle=(\theta-\theta_{0})^{\top}\psi(x,y)+\log Z_{\theta_{0}}(x)-\log Z_{\theta}(x).`$ |  |

Hence

|  |  |  |
|----|----|----|
|  |
``` math
\log\frac{\pi_{\theta}(y_{w}\mid x)}{\pi_{\rm SFT}(y_{w}\mid x)}-\log\frac{\pi_{\theta}(y_{l}\mid x)}{\pi_{\rm SFT}(y_{l}\mid x)}=(\theta-\theta_{0})^{\top}\bigl(\psi(x,y_{w})-\psi(x,y_{l})\bigr)=(\theta-\theta_{0})^{\top}z,
``` |  |

We have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle F_{\theta}(x,\mathbf{y}_{w},\mathbf{y}_{l})`$ | $`\displaystyle:=\log\sigma\bigl(\beta\log\tfrac{\pi_{\theta}(\mathbf{y}_{w}\mid x)}{\pi_{\rm SFT}(\mathbf{y}_{w}\mid x)}-\beta\log\tfrac{\pi_{\theta}(\mathbf{y}_{l}\mid x)}{\pi_{\rm SFT}(\mathbf{y}_{l}\mid x)}\bigr)`$ |  |
|  |  | $`\displaystyle=\log\sigma(\beta(\theta-\theta_{0})^{\top}z)`$ |  |

We apply the chain rule. Let $`u=\beta(\theta-\theta_{0})^{\top}z`$.

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla_{\theta}F_{\theta}(x,y_{w},y_{l})`$ | $`\displaystyle=\nabla_{\theta}\log\sigma(\beta(\theta-\theta_{0})^{\top}z)`$ |  |
|  |  | $`\displaystyle=\frac{d}{du}\log\sigma(u)\cdot\nabla_{\theta}u`$ |  |
|  |  | $`\displaystyle=\left(1-\sigma(u)\right)\cdot\nabla_{\theta}(\beta(\theta-\theta_{0})^{\top}z)`$ |  |
|  |  | $`\displaystyle=\left(1-\sigma(\beta(\theta-\theta_{0})^{\top}z)\right)\cdot(\beta z)`$ |  |
|  |  | $`\displaystyle=\beta\left[1-\sigma(\beta(\theta-\theta_{0})^{\top}z)\right]z.`$ |  |

To find the Hessian, we differentiate the first-order derivative with
respect to $`\theta`$.

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla^{2}_{\theta}F_{\theta}`$ | $`\displaystyle=\nabla_{\theta}\left(\beta\left[1-\sigma(\beta(\theta-\theta_{0})^{\top}z)\right]z\right)^{\top}`$ |  |
|  |  | $`\displaystyle=\nabla_{\theta}\left(\beta z^{\top}-\beta\sigma(\beta(\theta-\theta_{0})^{\top}z)z^{\top}\right)`$ |  |
|  |  | $`\displaystyle=-\beta\cdot\nabla_{\theta}\left(\sigma(\beta(\theta-\theta_{0})^{\top}z)z^{\top}\right)`$ |  |
|  |  | $`\displaystyle=-\beta\cdot\left(\nabla_{\theta}\sigma(\beta(\theta-\theta_{0})^{\top}z)\right)z^{\top}.`$ |  |

Now, we compute the gradient of the sigmoid term using the chain rule.

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla_{\theta}\sigma(\beta(\theta-\theta_{0})^{\top}z)`$ | $`\displaystyle=\sigma(\beta(\theta-\theta_{0})^{\top}z)\left[1-\sigma(\beta(\theta-\theta_{0})^{\top}z)\right]\cdot\nabla_{\theta}(\beta(\theta-\theta_{0})^{\top}z)`$ |  |
|  |  | $`\displaystyle=\beta\cdot\sigma(\beta(\theta-\theta_{0})^{\top}z)\left[1-\sigma(\beta(\theta-\theta_{0})^{\top}z)\right]z.`$ |  |

Finally, we substitute this back:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla^{2}_{\theta}F_{\theta}`$ | $`\displaystyle=-\beta\cdot\left(\beta\cdot\sigma(\beta(\theta-\theta_{0})^{\top}z)\left[1-\sigma(\beta(\theta-\theta_{0})^{\top}z)\right]z\right)z^{\top}`$ |  |
|  |  | $`\displaystyle=-\beta^{2}\sigma(\beta(\theta-\theta_{0})^{\top}z)\left[1-\sigma(\beta(\theta-\theta_{0})^{\top}z)\right]zz^{\top}.`$ |  |

Since

|  |  |  |
|----|----|----|
|  |
``` math
\nabla_{\theta}\Pi_{\theta}=\Pi_{\theta}S,\quad\nabla_{\theta}^{2}\Pi_{\theta}=\Pi_{\theta}(SS^{\top}+H).
``` |  |

Define

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle S`$ | $`\displaystyle:=\nabla_{\theta}\log\Pi_{\theta}(y_{w},y_{l}\mid x)`$ |  |
|  |  | $`\displaystyle=\nabla_{\theta}\log\left(\pi_{\theta}(y_{w}\mid x)\,\pi_{\theta}(y_{l}\mid x)\right)`$ |  |
|  |  | $`\displaystyle=\nabla_{\theta}\log\pi_{\theta}(y_{w}\mid x)\,+\nabla_{\theta}\log\pi_{\theta}(y_{l}\mid x),`$ |  |

and

|     |                                                           |     |
|-----|-----------------------------------------------------------|-----|
|     | $`\displaystyle H:=\nabla_{\theta}^{2}\log\Pi_{\theta}.`$ |     |

Then rewrite the expression of second order derivative as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla_{\theta}^{2}J`$ | $`\displaystyle=2\sum_{x,\mathbf{y}_{w},\mathbf{y}_{l}}P^{*}(y_{w}>y_{l})\Pi_{\theta}\Bigl[(\underbrace{SS^{\top}+H}_{\nabla_{\theta}^{2}\Pi_{\theta}/\Pi_{\theta}})F_{\theta}+2S(\nabla_{\theta}F_{\theta})^{\top}+\nabla_{\theta}^{2}F_{\theta}\Bigr]`$ |  |
|  |  | $`\displaystyle=2\mathbb{E}_{\Pi_{\theta}}\Bigl[P^{*}(y_{w}>y_{l})\big((\underbrace{SS^{\top}+H}_{\nabla_{\theta}^{2}\Pi_{\theta}/\Pi_{\theta}})F_{\theta}+2S(\nabla_{\theta}F_{\theta})^{\top}+\nabla_{\theta}^{2}F_{\theta}\big)\Bigr]`$ |  |
|  |  | $`\displaystyle=2\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}\Bigl[(\underbrace{SS^{\top}+H}_{\nabla_{\theta}^{2}\Pi_{\theta}/\Pi_{\theta}})F_{\theta}+2S(\nabla_{\theta}F_{\theta})^{\top}+\nabla_{\theta}^{2}F_{\theta}\Bigr].`$ |  |

which can be rearranged (factoring out $`\Pi_{\theta}`$ and omitting
expectation notation) as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla_{\theta}^{2}J`$ | $`\displaystyle=2\underbrace{\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[SS^{\top}F_{\theta}]}_{(a)}+2\underbrace{\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}\Bigl[2S\cdot\beta[1-\sigma(\beta(\theta-\theta_{0})^{\top}z)]z\Bigr]}_{(b)}+2\underbrace{\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[HF_{\theta}]}_{(c)}`$ |  |
|  |  | $`\displaystyle+2\underbrace{\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}\Bigl[-\beta^{2}\sigma(\beta(\theta-\theta_{0})^{\top}z)[1-\sigma(\beta(\theta-\theta_{0})^{\top}z)]zz^{\top}\Bigr]}_{(d)}.`$ |  |

To analyze the local convexity, we examine the lower bound of
$`-\nabla^{2}J(\theta)`$.

We derive all necessary bounds directly.

- •
  Bounding $`z`$: By definition, $`z=\psi(x,y_{w})-\psi(x,y_{l})`$. From
  Assumption
  [1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
  we have $`||\psi(s,a)||_{2}\leq 1`$. Using the triangle inequality, we
  get:

  |     |                                                                    |     |
  |-----|--------------------------------------------------------------------|-----|
  |     |
         ``` math
         ||z||_{2}\leq||\psi(x,y_{w})||_{2}+||\psi(x,y_{l})||_{2}\leq 1+1=2
         ```                                                                 |     |
- •
  Bounding $`(\theta-\theta_{0})^{\top}z`$: The term $`M`$ is defined as
  an upper bound for $`|(\theta-\theta_{0})^{\top}z|`$. Using the bound
  on $`||\theta-\theta_{0}||_{2}\leq B`$ from Assumption
  [1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
  and our derived bound for $`z`$:

  |  |  |  |
  |----|----|----|
  |  |
  ``` math
  |(\theta-\theta_{0})^{\top}z|\leq||\theta-\theta_{0}||_{2}||z||_{2}\leq B\cdot 2=2B
  ``` |  |

  Thus, we can set $`M=2B`$.
- •
  Bounding $`S`$:

  First, let’s derive the expression for
  $`\nabla_{\theta}\log\pi_{\theta}(y|x)`$. Recall the log-linear policy
  class from Assumption
  [1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"):

  |  |  |  |
  |----|----|----|
  |  |
  ``` math
  \pi_{\theta}(y|x)=\frac{\exp(\theta^{\top}\psi(x,y))}{\sum_{y^{\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,y^{\prime}))}
  ``` |  |

  Taking the logarithm gives:

  |  |  |  |
  |----|----|----|
  |  |
  ``` math
  \log\pi_{\theta}(y|x)=\theta^{\top}\psi(x,y)-\log\sum_{y^{\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,y^{\prime}))
  ``` |  |

  Now, we take the gradient with respect to $`\theta`$. Using the chain
  rule for the second term (the log-sum-exp term), we get:

  |  |  |  |  |
  |----|----|----|----|
  |  | $`\displaystyle\nabla_{\theta}\log\pi_{\theta}(y|x)`$ | $`\displaystyle=\nabla_{\theta}(\theta^{\top}\psi(x,y))-\nabla_{\theta}\left(\log\sum_{y^{\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,y^{\prime}))\right)`$ |  |
  |  |  | $`\displaystyle=\psi(x,y)-\frac{1}{\sum_{y^{\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,y^{\prime}))}\cdot\sum_{y^{\prime\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,y^{\prime\prime}))\psi(x,y^{\prime\prime})`$ |  |
  |  |  | $`\displaystyle=\psi(x,y)-\sum_{y^{\prime\prime}\in\mathcal{A}}\left(\frac{\exp(\theta^{\top}\psi(x,y^{\prime\prime}))}{\sum_{y^{\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,y^{\prime}))}\right)\psi(x,y^{\prime\prime})`$ |  |
  |  |  | $`\displaystyle=\psi(x,y)-\sum_{y^{\prime\prime}\in\mathcal{A}}\pi_{\theta}(y^{\prime\prime}|x)\psi(x,y^{\prime\prime})`$ |  |
  |  |  | $`\displaystyle=\psi(x,y)-\mathbb{E}_{y^{\prime}\sim\pi_{\theta}(\cdot|x)}[\psi(x,y^{\prime})].`$ |  |

  To bound this, we first apply the triangle inequality to its
  definition:

  |  |  |  |  |
  |----|----|----|----|
  |  | $`\displaystyle\left\|\nabla_{\theta}\log\pi_{\theta}(y|x)\right\|_{2}`$ | $`\displaystyle=\left\|\psi(x,y)-\mathbb{E}_{y^{\prime}\sim\pi_{\theta}(\cdot|x)}[\psi(x,y^{\prime})]\right\|_{2}`$ |  |
  |  |  | $`\displaystyle\leq\left\|\psi(x,y)\right\|_{2}+\left\|\mathbb{E}_{y^{\prime}\sim\pi_{\theta}(\cdot|x)}[\psi(x,y^{\prime})]\right\|_{2}.`$ |  |

  We bound the two terms on the right-hand side separately. The first
  term is bounded directly by Assumption
  [1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
  which states that $`\max_{x,y}\|\psi(x,y)\|_{2}\leq 1`$.

  For the second term, we apply Jensen’s inequality for norms, which is
  applicable as the L2 norm is a convex function:

  |  |  |  |  |
  |----|----|----|----|
  |  | $`\displaystyle\left\|\mathbb{E}_{y^{\prime}\sim\pi_{\theta}(\cdot|x)}[\psi(x,y^{\prime})]\right\|_{2}`$ | $`\displaystyle=\left\|\sum_{y^{\prime}\in\mathcal{A}}\pi_{\theta}(y^{\prime}|x)\psi(x,y^{\prime})\right\|_{2}`$ |  |
  |  |  | $`\displaystyle\leq\sum_{y^{\prime}\in\mathcal{A}}\pi_{\theta}(y^{\prime}|x)\left\|\psi(x,y^{\prime})\right\|_{2}\quad\text{(by Jensen's inequality)}`$ |  |
  |  |  | $`\displaystyle\leq\sum_{y^{\prime}\in\mathcal{A}}\pi_{\theta}(y^{\prime}|x)\cdot 1\quad\text{(by Assumption\penalty\ \ref{assump:Log-linear})}`$ |  |
  |  |  | $`\displaystyle=1.\quad\text{(since $\sum_{y^{\prime}\in\mathcal{A}}\pi_{\theta}(y^{\prime}|x)=1$)}`$ |  |

  Substituting these two bounds back, we obtain the final bound:

  |     |                                                                    |     |
  |-----|--------------------------------------------------------------------|-----|
  |     |
         ``` math
         \left\|\nabla_{\theta}\log\pi_{\theta}(y|x)\right\|_{2}\leq 1+1=2.
         ```                                                                 |     |

  For the total score
  $`S=\nabla_{\theta}\log\pi_{\theta}(y_{w}|x)+\nabla_{\theta}\log\pi_{\theta}(y_{l}|x)`$,
  we can use the triangle inequality and our bound for a single score:

  |  |  |  |
  |----|----|----|
  |  |
  ``` math
  \|S\|_{2}\leq\|\nabla_{\theta}\log\pi_{\theta}(y_{w}|x)\|_{2}+\|\nabla_{\theta}\log\pi_{\theta}(y_{l}|x)\|_{2}\leq 2+2=4.
  ``` |  |
- •
  Bounding $`H`$: The Hessian is the second-order gradient of the
  log-policy,
  $`H:=\nabla_{\theta}^{2}\log\Pi_{\theta}(y_{w},y_{l}\mid x)`$, which
  is equivalent to the gradient of the score, $`H=\nabla_{\theta}S`$.

  The Hessian can be shown in

  |  |  |  |  |
  |----|----|----|----|
  |  | $`\displaystyle H`$ | $`\displaystyle:=\nabla_{\theta}^{2}\log\Pi_{\theta}(y_{w},y_{l}\mid x)`$ |  |
  |  |  | $`\displaystyle=\nabla_{\theta}^{2}\log\pi_{\theta}(y_{w},\mid x)+\nabla_{\theta}^{2}\log\pi_{\theta}(y_{l},\mid x)`$ |  |

  In the general case, it can be shown to be the negative of the
  covariance matrix of the features under the policy $`\pi_{\theta}`$:

  |  |  |  |  |
  |----|----|----|----|
  |  | $`\displaystyle\nabla_{\theta}^{2}\log\pi_{\theta}(y\mid x)`$ | $`\displaystyle=\nabla_{\theta}(\nabla_{\theta}\log\pi_{\theta}(y\mid x))`$ |  |
  |  |  | $`\displaystyle=\nabla_{\theta}(\psi(x,y)-\mathbb{E}_{y^{\prime}\sim\pi_{\theta}(\cdot|x)}[\psi(x,y^{\prime})])`$ |  |

  Since $`\psi(x,y)`$ does not depend on $`\theta`$, its gradient is
  zero. It is therefore determined solely by the gradient of the
  expectation term:

  |  |  |  |  |
  |----|----|----|----|
  |  | $`\displaystyle\nabla_{\theta}^{2}\log\pi_{\theta}(y,\mid x)`$ | $`\displaystyle=-\nabla_{\theta}\left(\mathbb{E}_{y^{\prime}\sim\pi_{\theta}(\cdot|x)}[\psi(x,y^{\prime})]\right)`$ |  |
  |  |  | $`\displaystyle=-\nabla_{\theta}\left(\sum_{y^{\prime}\in\mathcal{A}}\pi_{\theta}(y^{\prime}|x)\psi(x,y^{\prime})\right)`$ |  |
  |  |  | $`\displaystyle=-\sum_{y^{\prime}\in\mathcal{A}}\left(\nabla_{\theta}\pi_{\theta}(y^{\prime}|x)\right)\psi(x,y^{\prime})^{\top}`$ |  |
  |  |  | $`\displaystyle=-\sum_{y^{\prime}\in\mathcal{A}}\pi_{\theta}(y^{\prime}|x)\left(\nabla_{\theta}\log\pi_{\theta}(y^{\prime}|x)\right)\psi(x,y^{\prime})^{\top}`$ |  |
  |  |  | $`\displaystyle=-\mathbb{E}_{y^{\prime}\sim\pi_{\theta}}\left[(\nabla_{\theta}\log\pi_{\theta}(y^{\prime}|x))\psi(x,y^{\prime})^{\top}\right]`$ |  |
  |  |  | $`\displaystyle=-\mathbb{E}_{y^{\prime}\sim\pi_{\theta}}\left[\left(\psi(x,y^{\prime})-\mathbb{E}_{y^{\prime\prime}\sim\pi_{\theta}}[\psi(x,y^{\prime\prime})]\right)\psi(x,y^{\prime})^{\top}\right]`$ |  |
  |  |  | $`\displaystyle=-\left(\mathbb{E}_{y^{\prime}}[\psi(y^{\prime})\psi(y^{\prime})^{\top}]-\mathbb{E}_{y^{\prime}}\left[\mathbb{E}_{y^{\prime\prime}}[\psi(y^{\prime\prime})]\psi(y^{\prime})^{\top}\right]\right)`$ |  |
  |  |  | $`\displaystyle=-\left(\mathbb{E}[\psi\psi^{\top}]-\mathbb{E}[\psi]\mathbb{E}[\psi]^{\top}\right).`$ |  |

  To obtain the final result in last step, we observe that the inner
  expectation $`\mathbb{E}_{y^{\prime\prime}}[\psi(y^{\prime\prime})]`$
  is a constant vector with respect to the outer expectation over
  $`y^{\prime}`$. It can thus be factored out, yielding
  $`\mathbb{E}_{y^{\prime}}[\mathbb{E}_{y^{\prime\prime}}[\psi]\psi(y^{\prime})^{\top}]=\mathbb{E}_{y^{\prime\prime}}[\psi]\cdot\mathbb{E}_{y^{\prime}}[\psi(y^{\prime})^{\top}]=\mathbb{E}[\psi]\mathbb{E}[\psi]^{\top}`$.
  The result is the negative of the covariance matrix of the features
  $`\psi`$ under the policy $`\pi_{\theta}`$.

  Using Jensen’s inequality, the property of the spectral norm
  $`\|\mathbf{v}\mathbf{v}^{\top}\|_{2}=\|\mathbf{v}\|_{2}^{2}`$ and
  Assumption
  [1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
  which states that $`\max_{s,a}\|\psi(s,a)\|_{2}\leq 1`$, we can bound
  the Hessian $`H`$.

  Now, we bound the two terms separately:

  |  |  |  |  |
  |----|----|----|----|
  |  | $`\displaystyle\left\|\mathbb{E}[\psi\psi^{\top}]\right\|_{2}`$ | $`\displaystyle\leq\mathbb{E}\left[\left\|\psi\psi^{\top}\right\|_{2}\right]\quad\text{(by Jensen's inequality)}`$ |  |
  |  |  | $`\displaystyle=\mathbb{E}\left[\|\psi\|_{2}^{2}\right]`$ |  |
  |  |  | $`\displaystyle\leq\mathbb{E}[1]=1.\quad\text{(by Assumption\penalty\ \ref{assump:Log-linear})}`$ |  |

  |  |  |  |  |
  |----|----|----|----|
  |  | $`\displaystyle\left\|\mathbb{E}[\psi]\mathbb{E}[\psi]^{\top}\right\|_{2}`$ | $`\displaystyle=\left\|\mathbb{E}[\psi]\right\|_{2}^{2}`$ |  |
  |  |  | $`\displaystyle\leq\mathbb{E}[\|\psi\|^{2}_{2}]\quad\text{(by Jensen's inequality)}`$ |  |
  |  |  | $`\displaystyle\leq\mathbb{E}[1]=1.\quad\text{(by Assumption\penalty\ \ref{assump:Log-linear})}`$ |  |

  Substituting these two results back:

  |     |                         |     |
  |-----|-------------------------|-----|
  |     |
         ``` math
         \|H\|_{2}\leq 2(1+1)=4.
         ```                      |     |

### A.2 Proof for Theorem [2](#Thmtheorem2 "Theorem 2 (Strong Concavity and Polyak-Lojasiewicz Condition for SAIL RevKL). ‣ 4.2 Regularized Objective ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")

###### Proof.

Fix a reference policy $`\pi_{\mathrm{ref}}`$, we add $`J`$ with a
reverse–KL penalty:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle J_{\gamma}(\theta)\;`$ | $`\displaystyle:=\;J(\theta)\;-\;\gamma\,\mathbb{E}_{x}\!\Big[D_{\mathrm{KL}}\!\big(\pi_{\mathrm{ref}}(\cdot\mid x)\,\|\,\pi_{\theta}(\cdot\mid x)\big)\Big],\qquad\gamma>0.`$ |  | (A.1) |
|  |  | $`\displaystyle=\mathbb{E}_{\begin{subarray}{c}\mathbf{x}\sim\mathcal{P},\ \mathbf{y}_{i}\sim\pi_{\theta}(\cdot\mid\mathbf{x}),\\
(y_{w}\succ y_{l})\sim p_{*}\end{subarray}}\left[\log\sigma\!\left(\beta\log\frac{\pi_{\theta}(y_{w}\mid\mathbf{x})}{\pi_{\mathrm{SFT}}(y_{w}\mid\mathbf{x})}-\beta\log\frac{\pi_{\theta}(y_{l}\mid\mathbf{x})}{\pi_{\mathrm{SFT}}(y_{l}\mid\mathbf{x})}\right)\right]`$ |  |  |
|  |  | $`\displaystyle-\;\gamma\,\mathbb{E}_{x}\!\Big[D_{\mathrm{KL}}\!\big(\pi_{\mathrm{ref}}(\cdot\mid x)\,\|\,\pi_{\theta}(\cdot\mid x)\big)\Big],\qquad\gamma>0.`$ |  |  |

For log–linear policies:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle D_{\text{KL}}`$ | $`\displaystyle(\pi_{\text{ref}}(\cdot|x)\parallel\pi_{\theta}(\cdot|x))`$ |  |
|  |  | $`\displaystyle=\sum_{a\in\mathcal{A}}\pi_{\text{ref}}(a|x)\log\left(\frac{\pi_{\text{ref}}(a|x)}{\pi_{\theta}(a|x)}\right)`$ |  |
|  |  | $`\displaystyle=\sum_{a\in\mathcal{A}}\pi_{\text{ref}}(a|x)\left[\log\pi_{\text{ref}}(a|x)-\log\pi_{\theta}(a|x)\right]`$ |  |
|  |  | $`\displaystyle=\sum_{a\in\mathcal{A}}\pi_{\text{ref}}(a|x)\left[(\theta_{\text{ref}}^{\top}\psi(x,a)-A_{x}(\theta_{\text{ref}}))-(\theta^{\top}\psi(x,a)-A_{x}(\theta))\right]`$ |  |
|  |  | $`\displaystyle=\sum_{a\in\mathcal{A}}\pi_{\text{ref}}(a|x)\left[(\theta_{\text{ref}}-\theta)^{\top}\psi(x,a)+A_{x}(\theta)-A_{x}(\theta_{\text{ref}})\right]`$ |  |
|  |  | $`\displaystyle=\sum_{a\in\mathcal{A}}\pi_{\text{ref}}(a|x)(\theta_{\text{ref}}-\theta)^{\top}\psi(x,a)+\sum_{a\in\mathcal{A}}\pi_{\text{ref}}(a|x)A_{x}(\theta)-\sum_{a\in\mathcal{A}}\pi_{\text{ref}}(a|x)A_{x}(\theta_{\text{ref}})`$ |  |
|  |  | $`\displaystyle=(\theta_{\text{ref}}-\theta)^{\top}\sum_{a\in\mathcal{A}}\pi_{\text{ref}}(a|x)\psi(x,a)+A_{x}(\theta)\sum_{a\in\mathcal{A}}\pi_{\text{ref}}(a|x)-A_{x}(\theta_{\text{ref}})\sum_{a\in\mathcal{A}}\pi_{\text{ref}}(a|x)`$ |  |
|  |  | $`\displaystyle=(\theta_{\text{ref}}-\theta)^{\top}\mathbb{E}_{a\sim\pi_{\text{ref}}}[\psi(x,a)]+A_{x}(\theta)\cdot 1-A_{x}(\theta_{\text{ref}})\cdot 1`$ |  |
|  |  | $`\displaystyle=A_{x}(\theta)-A_{x}(\theta_{\text{ref}})+(\theta_{\text{ref}}-\theta)^{\top}\mu_{\text{ref}}(x),\quad\mu_{\mathrm{ref}}(x):=\mathbb{E}_{\pi_{\mathrm{ref}}}[\psi(x,\cdot)]`$ |  |
|  |  | $`\displaystyle=A_{x}(\theta)-A_{x}(\theta_{\text{ref}})-(\theta-\theta_{\text{ref}})^{\top}\mu_{\text{ref}}(x),\quad\mu_{\mathrm{ref}}(x):=\mathbb{E}_{\pi_{\mathrm{ref}}}[\psi(x,\cdot)].`$ |  |

Dropping $`\theta`$–independent constants, the working form of
([A.1](#A1.E1 "In Proof. ‣ A.2 Proof for Theorem ‣ Appendix A Proofs for Theorems ‣ On the Convergence of Self-Improving Online LLM Alignment"))
is

|  |  |  |
|----|----|----|
|  |
``` math
J_{\gamma}(\theta)\;\equiv\;J(\theta)\;-\;\gamma\,\mathbb{E}_{x}\!\big[\,A_{x}(\theta)-\theta^{\top}\mu_{\mathrm{ref}}(x)\,\big].
``` |  |

Using $`\nabla_{\theta}A_{x}(\theta)=\mu_{\theta}(x)`$ and that
$`\mu_{\mathrm{ref}}(x)`$ does not depend on $`\theta`$,

|  |  |  |
|----|----|----|
|  |
``` math
\nabla_{\theta}\Big(\mathbb{E}_{x}\big[D_{\mathrm{KL}}(\pi_{\mathrm{ref}}\|\pi_{\theta})\big]\Big)=\mathbb{E}_{x}\!\big[\mu_{\theta}(x)-\mu_{\mathrm{ref}}(x)\big].
``` |  |

Hence, the gradient of the new objective is

|  |  |  |
|----|----|----|
|  |
``` math
\nabla_{\theta}J_{\gamma}(\theta)=\nabla_{\theta}J(\theta)\;-\;\gamma\,\mathbb{E}_{x}\!\big[\mu_{\theta}(x)-\mu_{\mathrm{ref}}(x)\big].
``` |  |

Differentiating and using
$`\nabla_{\theta}\mu_{\theta}(x)=C_{x}(\theta)`$,

|  |  |  |
|----|----|----|
|  |
``` math
\nabla_{\theta}^{2}\Big(\mathbb{E}_{x}\big[D_{\mathrm{KL}}(\pi_{\mathrm{ref}}\|\pi_{\theta})\big]\Big)=\mathbb{E}_{x}\!\big[C_{x}(\theta)\big]\ \succeq\ 0.
``` |  |

Therefore, the Hessian and negative Hessian of the regularized objective
are

|  |  |  |
|----|----|----|
|  |
``` math
\nabla_{\theta}^{2}J_{\gamma}(\theta)=\nabla_{\theta}^{2}J(\theta)\;-\;\gamma\,\mathbb{E}_{x}[C_{x}(\theta)],\qquad-\nabla_{\theta}^{2}J_{\gamma}(\theta)=-\nabla_{\theta}^{2}J(\theta)\;+\;\gamma\,\mathbb{E}_{x}[C_{x}(\theta)].
``` |  |

By lemma
[4](#Thmlemma4 "Lemma 4 (Relation between Fisher Matrix and second order of reverse KL term). ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment"),
$`\mathbb{E}_{x}[C_{x}(\theta)]=-\tfrac{1}{2}\,\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H]`$.

To establish the PL condition, we will show that the Hessian of the
objective function is negative definite, i.e.,
$`-\nabla^{2}J_{\gamma}(\theta)\geq\mu I`$ for some constant $`\mu>0`$.

We add a reverse-KL regularizer to the SAIL objective leading to the new
Hessian:

|  |  |  |
|----|----|----|
|  |
``` math
-\nabla^{2}J_{\gamma}(\theta)=-\nabla^{2}J(\theta)+\gamma\mathbb{E}_{x}[C_{x}(\theta)]=-\nabla^{2}J(\theta)-\frac{\gamma}{2}\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H].
``` |  |

Here, we have used the identity that the Hessian of the regularizer is
the Fisher Information Matrix, $`C_{x}(\theta)=\text{Cov}(\psi)=-H/2`$.

We have:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle-\nabla^{2}J_{\gamma}(\theta)`$ | $`\displaystyle=2[-(a)-(b)-(c)-(d)]-\frac{\gamma}{2}\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H]`$ |  |
|  |  | $`\displaystyle\succeq 2[-\log(\sigma(2\beta B))\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[SS^{\top}]-\beta\sigma(2\beta B)\!\left(\frac{1}{\varepsilon}\,\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[SS^{\top}]\;+\;\varepsilon\,\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[zz^{\top}]\right)`$ |  |
|  |  | $`\displaystyle\log(\sigma(-2\beta B))\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H]+\beta^{2}\sigma(2\beta B)\sigma(-2\beta B)\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[zz^{\top}]]-\frac{\gamma}{2}\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H]`$ |  |
|  |  | $`\displaystyle\succeq 2\big(-\log(\sigma(2\beta B))-\frac{\beta\sigma(2\beta B)}{\varepsilon}\big)\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[SS^{\top}]-`$ |  |
|  |  | $`\displaystyle+2\big(\beta^{2}\sigma(2\beta B)\sigma(-2\beta B)-\beta\sigma(2\beta B)\varepsilon\big)\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[zz^{\top}]`$ |  |
|  |  | $`\displaystyle+\big(2\log(\sigma(-2\beta B))-\frac{\gamma}{2}\big)\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H].`$ |  |

Under Lemma
[3](#Thmlemma3 "Lemma 3 (Fisher–Hessian identity under 𝜃–independent normalization). ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment"),
we have
$`\mathbb{E}[SS^{\top}]=-\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H]`$
and $`\mathbb{E}[SS^{\top}]\succeq 0`$. Hence,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle-\nabla^{2}J_{\gamma}(\theta)`$ | $`\displaystyle=-2(a)-2(b)-2(c)-2(d)-\frac{\gamma}{2}\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H]`$ |  |
|  |  | $`\displaystyle\succeq\big(-2\log(\sigma(2\beta B))-\frac{2\sigma(2\beta B)\beta}{\varepsilon}-2\log(\sigma(-2\beta B))+\frac{\gamma}{2}\big)\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[SS^{\top}]`$ |  |
|  |  | $`\displaystyle+\big(2\beta^{2}\sigma(2\beta B)\sigma(-2\beta B)-2\sigma(2\beta B)\beta\varepsilon\big)\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[zz^{\top}].`$ |  |

We can take

|     |                                                        |     |
|-----|--------------------------------------------------------|-----|
|     | $`\displaystyle\varepsilon\leq\beta\sigma(-2\beta B)`$ |     |

and choose

|  |  |  |
|----|----|----|
|  | $`\displaystyle\gamma>4\log(\sigma(2\beta B))+\frac{4\sigma(2\beta B)\beta}{\varepsilon}+4\log(\sigma(-2\beta B))`$ |  |

Under this choice, we can drop the positive semi-definite
$`\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[zz^{\top}]`$ term and lemma
[1](#Thmlemma1 "Lemma 1 (Strict positive definiteness of 𝑆⁢𝑆^⊤ under Assumption 2). ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment")
gives
$`\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[SS^{\top}]\succeq\lambda I`$,
we obtain:

|  |  |  |
|----|----|----|
|  |
``` math
-\nabla^{2}J_{\gamma}(\theta)\ \succeq\ \big(-2\log(\sigma(2\beta B))-\frac{2\sigma(2\beta B)\beta}{\varepsilon}-2\log(\sigma(-2\beta B))+\frac{\gamma}{2}\big)\lambda I.
``` |  |

This yields an explicit PL constant

|  |  |  |
|----|----|----|
|  |
``` math
\ \mu\ \geq\ \big(-2\log(\sigma(2\beta B))-\frac{2\sigma(2\beta B)\beta}{\varepsilon}-2\log(\sigma(-2\beta B))+\frac{\gamma}{2}\big)\lambda
``` |  |

Choose

|     |                                                     |     |
|-----|-----------------------------------------------------|-----|
|     | $`\displaystyle\varepsilon=\beta\sigma(-2\beta B)`$ |     |

This yields a specific PL constant

|  |  |  |
|----|----|----|
|  |
``` math
\ \mu\ \geq\ \big(-2\log(\sigma(2\beta B))-2\frac{\sigma(2\beta B)}{\sigma(-2\beta B)}-2\log(\sigma(-2\beta B))+\frac{\gamma}{2}\big)\lambda
``` |  |

|  |  |  |
|----|----|----|

``` math
\frac{\sigma(x)}{\sigma(-x)}=\frac{\dfrac{e^{x}}{1+e^{x}}}{\dfrac{1}{1+e^{x}}}=e^{x}.
``` |  |

PL constant is

|  |  |  |

### A.3 Proof for Theorem [3](#Thmtheorem3 "Theorem 3. ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")

###### Proof.

By the L-smoothness of $`J_{\gamma}(\theta)`$, for the intermediate
update step $`\theta^{\prime}_{t+1}=\theta_{t}+\eta\hat{g}_{t}`$, we
have:

|  |  |  |
|----|----|----|
|  |
``` math
J_{\gamma}(\theta^{\prime}_{t+1})\geq J_{\gamma}(\theta_{t})+\eta\langle\nabla J_{\gamma}(\theta_{t}),\hat{g}_{t}\rangle-\frac{L\eta^{2}}{2}||\hat{g}_{t}||^{2}
``` |  |

By Lemma
[8](#Thmlemma8 "Lemma 8 (One-step progress with projection). ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment"),
we have:

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}[J_{\gamma}(\theta_{t+1})]\geq\mathbb{E}[J_{\gamma}(\theta_{t})]+\Bigl(\frac{1}{2\eta}-\frac{L}{2}\Bigr)\mathbb{E}\|\Delta_{t}\|^{2}-\frac{\eta}{2}\,\mathbb{E}\|\nabla J_{\gamma}(\theta_{t})-\hat{g}_{t}\|^{2},\qquad\Delta_{t}=\Pi_{\Theta}(\theta^{\prime}_{t+1})-\theta_{t}
``` |  |

By Lemma
[6](#Thmlemma6 "Lemma 6. ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment"),
the gradient $`\hat{g}_{t}`$ is an unbiased estimator of the true
gradient $`\nabla J_{\gamma}(\theta_{t})`$. This implies:

|     |                                                        |     |
|-----|--------------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{E}[\hat{g}_{t}]=\nabla J_{\gamma}(\theta_{t}),
       ```                                                     |     |

and consequently:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbb{E}[\|\hat{g}_{t}-\nabla J_{\gamma}(\theta_{t})\|^{2}]`$ | $`\displaystyle\leq\frac{\sigma_{g}^{2}}{B_{s}}.`$ |  |

Furthermore, we can bound the expected squared norm of the stochastic
gradient. By the definition of variance and Lemma
[6](#Thmlemma6 "Lemma 6. ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment"),
we have:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbb{E}[\|\hat{g}_{t}-\nabla J_{\gamma}(\theta_{t})\|^{2}]`$ | $`\displaystyle\leq\frac{\sigma_{g}^{2}}{B_{s}}.`$ |  |

The cross-term vanishes because
$`\mathbb{E}[\hat{g}_{t}-\nabla J_{\gamma}(\theta_{t})]=0`$.

Substituting back, we get:

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}[J_{\gamma}(\theta_{t+1})]\geq\mathbb{E}[J_{\gamma}(\theta_{t})]+\Bigl(\frac{1}{2\eta}-\frac{L}{2}\Bigr)\mathbb{E}\|\Delta_{t}\|^{2}-\frac{\eta}{2}\,\frac{\sigma_{g}^{2}}{B_{s}}
``` |  |

Rearranging terms to isolate the gradient norm:

|  |  |  |
|----|----|----|
|  |
``` math
\Bigl(\frac{1}{2\eta}-\frac{L}{2}\Bigr)\mathbb{E}\|\Delta_{t}\|^{2}\leq\mathbb{E}[J_{\gamma}(\theta_{t+1})]-\mathbb{E}[J_{\gamma}(\theta_{t})]+\frac{\eta}{2}\,\frac{\sigma_{g}^{2}}{B_{s}}.
``` |  |

Summing both sides of the inequality from $`t=0`$ to $`T-1`$, we obtain:

|  |  |  |
|----|----|----|
|  |
``` math
\left(\frac{1}{2\eta}-\frac{L}{2}\right)\sum_{t=0}^{T-1}\mathbb{E}\,\|\Delta_{t}\|^{2}\;\leq\;\mathbb{E}[J_{\gamma}(\theta_{T})]-\mathbb{E}[J_{\gamma}(\theta_{0})]+\frac{\eta T}{2}\,\frac{\sigma_{g}^{2}}{B_{s}}.
``` |  |

Rearranging terms, and noting that
$`J_{\gamma}(\theta_{T})-J_{\gamma}(\theta_{0})`$ is bounded by a
constant related to the initial and final function values:

|  |  |  |
|----|----|----|
|  |
``` math
\frac{1}{T}\sum_{t=0}^{T-1}\mathbb{E}\,\|\Delta_{t}\|^{2}\;\leq\;\frac{2\left(\mathbb{E}[J_{\gamma}(\theta_{T})]-\mathbb{E}[J_{\gamma}(\theta_{0})\right)]}{(1/\eta-L)\,T}+\frac{\eta^{2}\sigma_{g}^{2}}{(1-\eta L)\,B_{s}},\qquad\eta<1/L.
``` |  |

By definition and the gradient $`\hat{g}_{t}`$ is an unbiased estimator
of the true gradient $`\nabla J_{\gamma}(\theta_{t})`$. Therefore
$`\mathbb{E}[G_{\eta}(\theta_{t})]=\frac{1}{\eta}\,\mathbb{E}[\Delta_{t}]`$,
we have:

|  |  |  |
|----|----|----|
|  |
``` math
\frac{1}{T}\sum_{t=0}^{T-1}\mathbb{E}\,\|G_{\eta}(\theta_{t})\|^{2}\;\leq\;\frac{2\left(\mathbb{E}[J_{\gamma}(\theta_{T})]-J_{\gamma}(\theta_{0})\right)}{(1-\eta L)\,\eta\,T}+\frac{\sigma_{g}^{2}}{(1-\eta L)\,B_{s}},\qquad\eta<1/L.
``` |  |

### A.4 Proof for Theorem [6](#Thmtheorem6 "Theorem 6 (Global convergence under strong concavity). ‣ A.4 Proof for Theorem ‣ Appendix A Proofs for Theorems ‣ On the Convergence of Self-Improving Online LLM Alignment")

###### Theorem 6 (Global convergence under strong concavity).

Under Assumptions
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
[2](#Thmassumption2 "Assumption 2 (Fisher information lower bound). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),

[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment"),

$`\Theta`$, and let $`\{\theta_{t}\}`$ be generated by Algorithm
[1](#alg1 "Algorithm 1 ‣ 4.3 Algorithm ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
with a stepsize $`\eta\in(0,2\mu/L)`$. Then, for all $`t\geq 0`$,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}\big[\|\theta_{t}-\theta^{*}\|^{2}\big]\leq\rho(\eta)^{t}\|\theta_{0}-\theta^{*}\|^{2}\;+\;\frac{\eta^{2}\sigma_{g}^{2}}{B_{s}(2\eta\mu-\eta^{2}L^{2})}.
``` |  |

Where $`\rho(\eta):=1-2\eta\mu+\eta^{2}L^{2}.`$

###### Proof.

By nonexpansiveness of projection and Lemma
[9](#Thmlemma9 "Lemma 9 (Projection fixed point / KKT equivalence). ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment"),

|  |  |  |
|----|----|----|
|  |
``` math
\|\theta_{t+1}-\theta^{*}\|^{2}\;\leq\;\big\|\theta_{t}+\eta\hat{g}_{t}-\big(\theta^{*}+\eta\nabla J_{\gamma}(\theta^{*})\big)\big\|^{2}.
``` |  |

Write $`\hat{g}_{t}=\nabla J_{\gamma}(\theta_{t})+\xi_{t}`$ with
$`\mathbb{E}[\xi_{t}|\theta_{t}]=0`$ and
$`\mathbb{E}[\|\xi_{t}\|^{2}|\theta_{t}]\leq\frac{\sigma_{g}^{2}}{B_{s}}`$
under Assumption
[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
and Lemma
[6](#Thmlemma6 "Lemma 6. ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment"),
take conditional expectation, and expand:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbb{E}\!\left[\|\theta_{t+1}-\theta^{*}\|^{2}\mid\theta_{t}\right]`$ | $`\displaystyle\leq\big\|\theta_{t}-\theta^{*}+\eta\big(\nabla J_{\gamma}(\theta_{t})-\nabla J_{\gamma}(\theta^{*})\big)\big\|^{2}+\eta^{2}\frac{\sigma_{g}^{2}}{B_{s}}`$ |  |
|  |  | $`\displaystyle=\|\theta_{t}-\theta^{*}\|^{2}+2\eta\!\left\langle\theta_{t}-\theta^{*},\,\nabla J_{\gamma}(\theta_{t})-\nabla J_{\gamma}(\theta^{*})\right\rangle+\eta^{2}\|\nabla J_{\gamma}(\theta_{t})-\nabla J_{\gamma}(\theta^{*})\|^{2}+\eta^{2}\frac{\sigma_{g}^{2}}{B_{s}}`$ |  |
|  |  | $`\displaystyle\leq\Big(1-2\eta\mu+\eta^{2}L^{2}\Big)\,\|\theta_{t}-\theta^{*}\|^{2}+\eta^{2}\frac{\sigma_{g}^{2}}{B_{s}}.`$ |  |

Here we used $`L`$-smoothness,
$`\|\nabla J_{\gamma}(\theta_{t})-\nabla J_{\gamma}(\theta^{*})\|\leq L\|\theta_{t}-\theta^{*}\|`$,
and $`\mu`$-strong concavity
$`\langle\theta_{t}-\theta^{*},\,\nabla J_{\gamma}(\theta_{t})-\nabla J_{\gamma}(\theta^{*})\rangle\leq-\mu\|\theta_{t}-\theta^{*}\|^{2}`$.

Taking total expectation and unrolling the recursion yields the
geometric term plus the steady-state bound
$`\eta^{2}\sigma^{2}/(1-\rho(\eta))`$, i.e.,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}\big[\|\theta_{t}-\theta^{*}\|^{2}\big]\leq\rho(\eta)^{t}\|\theta_{0}-\theta^{*}\|^{2}\;+\;\frac{\eta^{2}\sigma_{g}^{2}}{B_{s}(2\eta\mu-\eta^{2}L^{2})}\,,\qquad\eta<\frac{2\mu}{L}.
``` |  |

|  |  |  |

### A.6 Proof for Theorem [5](#Thmtheorem5 "Theorem 5 (End-to-End Suboptimality Gap for SAIL-RevKL). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")

###### Proof.

By Theorem
[2](#Thmtheorem2 "Theorem 2 (Strong Concavity and Polyak-Lojasiewicz Condition for SAIL RevKL). ‣ 4.2 Regularized Objective ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
$`J_{\gamma}(\theta)`$ is $`\mu_{\gamma}`$-strongly concave on
$`\Theta`$. A key property of strongly concave functions is that for any
$`\theta_{1},\theta_{2}\in\Theta`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\langle\nabla J_{\gamma}(\theta_{1})-\nabla J_{\gamma}(\theta_{2}),\theta_{1}-\theta_{2}\rangle\leq-\mu_{\gamma}||\theta_{1}-\theta_{2}||_{2}^{2}
``` |  | (A.4) |

Let us set $`\theta_{1}=\theta^{*}_{\gamma}`$ and
$`\theta_{2}=\theta^{*}`$. Substituting these yields:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\langle\nabla J_{\gamma}(\theta^{*}_{\gamma})-\nabla J_{\gamma}(\theta^{*}),\theta^{*}_{\gamma}-\theta^{*}\rangle\leq-\mu_{\gamma}||\theta^{*}_{\gamma}-\theta^{*}||_{2}^{2}
``` |  | (A.5) |

From the first-order optimality condition for the maximizer
$`\theta^{*}_{\gamma}`$ over the convex set $`\Theta`$, we have
$`\langle\nabla J_{\gamma}(\theta^{*}_{\gamma}),\theta^{*}-\theta^{*}_{\gamma}\rangle\leq 0`$,
which implies
$`\langle\nabla J_{\gamma}(\theta^{*}_{\gamma}),\theta^{*}_{\gamma}-\theta^{*}\rangle\geq 0`$.
We can thus drop this non-negative term, and the inequality still holds:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle-\langle\nabla J_{\gamma}(\theta^{*}),\theta^{*}_{\gamma}-\theta^{*}\rangle`$ | $`\displaystyle\leq-\mu_{\gamma}||\theta^{*}_{\gamma}-\theta^{*}||_{2}^{2}`$ |  |
|  | $`\displaystyle\text{i.e}\penalty\ \penalty\ \penalty\ \langle\nabla J_{\gamma}(\theta^{*}),\theta^{*}_{\gamma}-\theta^{*}\rangle`$ | $`\displaystyle\geq\mu_{\gamma}||\theta^{*}_{\gamma}-\theta^{*}||_{2}^{2}`$ |  |

We now expand the gradient term
$`\nabla J_{\gamma}(\theta^{*})=\nabla J(\theta^{*})-\gamma\nabla R(\theta^{*})`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\langle\nabla J(\theta^{*})-\gamma\nabla R(\theta^{*}),\theta^{*}_{\gamma}-\theta^{*}\rangle\geq\mu_{\gamma}||\theta^{*}_{\gamma}-\theta^{*}||_{2}^{2}
``` |  | (A.6) |

Rearranging the terms on the left-hand side gives:

|  |  |  |
|----|----|----|
|  |
``` math
\langle\nabla J(\theta^{*}),\theta^{*}_{\gamma}-\theta^{*}\rangle-\gamma\langle\nabla R(\theta^{*}),\theta^{*}_{\gamma}-\theta^{*}\rangle\geq\mu_{\gamma}||\theta^{*}_{\gamma}-\theta^{*}||_{2}^{2}
``` |  |

From the first-order optimality condition for $`\theta^{*}`$, we know
that
$`\langle\nabla J(\theta^{*}),\theta^{*}_{\gamma}-\theta^{*}\rangle\leq 0`$.
Dropping this non-positive term from the left-hand side maintains the
inequality:

|  |  |  |
|----|----|----|
|  |
``` math
-\gamma\langle\nabla R(\theta^{*}),\theta^{*}_{\gamma}-\theta^{*}\rangle\geq\mu_{\gamma}||\theta^{*}_{\gamma}-\theta^{*}||_{2}^{2}
``` |  |

By applying the Cauchy-Schwarz inequality to the inner product and using
Assumption (c), $`||\nabla R(\theta^{*})||_{2}\leq G_{KL}`$, we get:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mu_{\gamma}||\theta^{*}_{\gamma}-\theta^{*}||_{2}^{2}`$ | $`\displaystyle\leq-\gamma\langle\nabla R(\theta^{*}),\theta^{*}_{\gamma}-\theta^{*}\rangle`$ |  |
|  |  | $`\displaystyle\leq\gamma||\nabla R(\theta^{*})||_{2}\cdot||\theta^{*}_{\gamma}-\theta^{*}||_{2}`$ |  |
|  |  | $`\displaystyle\leq\gamma G_{KL}||\theta^{*}_{\gamma}-\theta^{*}||_{2}`$ |  |

Assuming $`\theta^{*}\neq\theta^{*}_{\gamma}`$, we can divide both sides
by $`||\theta^{*}_{\gamma}-\theta^{*}||_{2}`$ to obtain a bound on the
parameter distance:

|  |  |  |
|----|----|----|
|  |
``` math
||\theta^{*}_{\gamma}-\theta^{*}||_{2}\leq\frac{\gamma G_{KL}}{\mu_{\gamma}}
``` |  |

By Assumption
[3](#Thmassumption3 "Assumption 3 (L-smoothness). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment"),
the original objective $`J(\theta)`$ is $`L_{J}`$-smooth. A direct
consequence of L-smoothness and the optimality of $`\theta^{*}`$ is the
quadratic upper bound on the suboptimality gap:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
J(\theta^{*})-J(\theta)\leq\frac{L_{J}}{2}||\theta-\theta^{*}||_{2}^{2},\quad\forall\theta\in\Theta
``` |  | (A.7) |

Setting $`\theta=\theta^{*}_{\gamma}`$, we get:

|  |  |  |
|----|----|----|
|  |
``` math
J(\theta^{*})-J(\theta^{*}_{\gamma})\leq\frac{L_{J}}{2}||\theta^{*}_{\gamma}-\theta^{*}||_{2}^{2}
``` |  |

Finally, we substitute the parameter distance bound into the above
inequality:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle J(\theta^{*})-J(\theta^{*}_{\gamma})`$ | $`\displaystyle\leq\frac{L_{J}}{2}\left(\frac{\gamma G_{KL}}{\mu_{\gamma}}\right)^{2}`$ |  |
|  |  | $`\displaystyle=\frac{L_{J}G_{KL}^{2}}{2\mu_{\gamma}^{2}}\cdot\gamma^{2}`$ |  |

∎

### A.7 Stationarity Under General Policy Parameterizations

The global PL analysis in the main text uses the log-linear policy
structure. Here, we record a standard first-order result that does not
require Assumptions
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
and
[2](#Thmassumption2 "Assumption 2 (Fisher information lower bound). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment").
We use the same projected stochastic-gradient update with the RevKL term
removed, equivalently with $`\gamma=0`$.

###### Proposition 1 (First-Order Stationarity for General Policy Parameterizations).

Suppose Assumptions
[3](#Thmassumption3 "Assumption 3 (L-smoothness). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
and
[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
hold with $`\gamma=0`$, so that $`J_{\gamma}=J`$. Consider

|     |                                                                  |     |
|-----|------------------------------------------------------------------|-----|
|     |
       ``` math
       \theta_{t+1}=\Pi_{\Theta}\bigl(\theta_{t}+\eta\hat{g}_{t}\bigr),
       ```                                                               |     |

where $`\hat{g}_{t}`$ is the mini-batch stochastic-gradient estimator
defined in Assumption
[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment").
If

|     |                         |     |
|-----|-------------------------|-----|
|     |
       ``` math
       0<\eta\leq\frac{1}{2L},
       ```                      |     |

then

|  |  |  |
|----|----|----|
|  |
``` math
\frac{1}{T}\sum_{t=0}^{T-1}\mathbb{E}\|G_{\eta}(\theta_{t})\|^{2}\leq\frac{8\log 2}{\eta T}+\frac{6\sigma_{g}^{2}}{B_{s}}.
``` |  |

Consequently, choosing

|  |  |  |
|----|----|----|
|  |
``` math
T\geq\frac{16\log 2}{\eta\varepsilon},\qquad B_{s}\geq\frac{12\sigma_{g}^{2}}{\varepsilon}
``` |  |

gives

|  |  |  |
|----|----|----|
|  |
``` math
\min_{0\leq t<T}\mathbb{E}\|G_{\eta}(\theta_{t})\|^{2}\leq\varepsilon.
``` |  |

For any fixed stepsize $`\eta\in(0,1/(2L)]`$, the resulting sample
complexity is

|     |                                       |     |
|-----|---------------------------------------|-----|
|     |
       ``` math
       B_{s}T=\mathcal{O}(\varepsilon^{-2}).
       ```                                    |     |

###### Proof.

Let

|     |                                      |     |
|-----|--------------------------------------|-----|
|     |
       ``` math
       \Delta_{t}:=\theta_{t+1}-\theta_{t}.
       ```                                   |     |

Since $`\gamma=0`$, Assumption
[3](#Thmassumption3 "Assumption 3 (L-smoothness). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
gives

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle J(\theta_{t+1})\geq\;`$ | $`\displaystyle J(\theta_{t})+\left\langle\nabla J(\theta_{t}),\Delta_{t}\right\rangle-\frac{L}{2}\|\Delta_{t}\|^{2}.`$ |  | (A.8) |

By the optimality condition of the Euclidean projection

|     |                                                                  |     |
|-----|------------------------------------------------------------------|-----|
|     |
       ``` math
       \theta_{t+1}=\Pi_{\Theta}\bigl(\theta_{t}+\eta\hat{g}_{t}\bigr),
       ```                                                               |     |

we have

|  |  |  |
|----|----|----|
|  |
``` math
\left\langle\hat{g}_{t},\Delta_{t}\right\rangle\geq\frac{1}{\eta}\|\Delta_{t}\|^{2}.
``` |  |

Writing

|  |  |  |
|----|----|----|
|  |
``` math
\nabla J(\theta_{t})=\hat{g}_{t}+\bigl(\nabla J(\theta_{t})-\hat{g}_{t}\bigr)
``` |  |

in
([A.8](#A1.E8 "In Proof. ‣ A.7 Stationarity Under General Policy Parameterizations ‣ Appendix A Proofs for Theorems ‣ On the Convergence of Self-Improving Online LLM Alignment"))
yields

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle J(\theta_{t+1})\geq\;`$ | $`\displaystyle J(\theta_{t})+\left(\frac{1}{\eta}-\frac{L}{2}\right)\|\Delta_{t}\|^{2}`$ |  |
|  |  | $`\displaystyle+\left\langle\nabla J(\theta_{t})-\hat{g}_{t},\Delta_{t}\right\rangle.`$ |  |

Young’s inequality gives

|  |  |  |
|----|----|----|
|  |
``` math
\left\langle\nabla J(\theta_{t})-\hat{g}_{t},\Delta_{t}\right\rangle\geq-\frac{\eta}{2}\|\nabla J(\theta_{t})-\hat{g}_{t}\|^{2}-\frac{1}{2\eta}\|\Delta_{t}\|^{2}.
``` |  |

Therefore,

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle J(\theta_{t+1})\geq\;`$ | $`\displaystyle J(\theta_{t})+\frac{1-\eta L}{2\eta}\|\Delta_{t}\|^{2}`$ |  |  |
|  |  | $`\displaystyle-\frac{\eta}{2}\|\nabla J(\theta_{t})-\hat{g}_{t}\|^{2}.`$ |  | (A.9) |

By Assumption
[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
and the mini-batch variance bound,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}\|\nabla J(\theta_{t})-\hat{g}_{t}\|^{2}\leq\frac{\sigma_{g}^{2}}{B_{s}}.
``` |  |

Taking expectations in
([A.9](#A1.E9 "In Proof. ‣ A.7 Stationarity Under General Policy Parameterizations ‣ Appendix A Proofs for Theorems ‣ On the Convergence of Self-Improving Online LLM Alignment"))
and summing over $`t=0,\ldots,T-1`$ gives

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{1}{T}\sum_{t=0}^{T-1}\frac{\mathbb{E}\|\Delta_{t}\|^{2}}{\eta^{2}}\leq\;`$ | $`\displaystyle\frac{2\bigl(\mathbb{E}[J(\theta_{T})]-J(\theta_{0})\bigr)}{(1-\eta L)\eta T}`$ |  |  |
|  |  | $`\displaystyle+\frac{\sigma_{g}^{2}}{(1-\eta L)B_{s}}.`$ |  | (A.10) |

By the non-expansiveness of Euclidean projection,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\eta\|G_{\eta}(\theta_{t})\|={}`$ | $`\displaystyle\left\|\Pi_{\Theta}\bigl(\theta_{t}+\eta\nabla J(\theta_{t})\bigr)-\theta_{t}\right\|`$ |  |
|  | $`\displaystyle\leq\;`$ | $`\displaystyle\left\|\Pi_{\Theta}\bigl(\theta_{t}+\eta\nabla J(\theta_{t})\bigr)-\Pi_{\Theta}\bigl(\theta_{t}+\eta\hat{g}_{t}\bigr)\right\|+\|\Delta_{t}\|`$ |  |
|  | $`\displaystyle\leq\;`$ | $`\displaystyle\eta\|\nabla J(\theta_{t})-\hat{g}_{t}\|+\|\Delta_{t}\|.`$ |  |

Hence,

|  |  |  |
|----|----|----|
|  |
``` math
\|G_{\eta}(\theta_{t})\|^{2}\leq 2\|\nabla J(\theta_{t})-\hat{g}_{t}\|^{2}+\frac{2}{\eta^{2}}\|\Delta_{t}\|^{2}.
``` |  |

Combining this inequality with
([A.10](#A1.E10 "In Proof. ‣ A.7 Stationarity Under General Policy Parameterizations ‣ Appendix A Proofs for Theorems ‣ On the Convergence of Self-Improving Online LLM Alignment"))
yields

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\frac{1}{T}\sum_{t=0}^{T-1}\mathbb{E}\|G_{\eta}(\theta_{t})\|^{2}\leq\;`$ | $`\displaystyle\frac{4\bigl(\mathbb{E}[J(\theta_{T})]-J(\theta_{0})\bigr)}{(1-\eta L)\eta T}`$ |  |  |
|  |  | $`\displaystyle+\frac{2(2-\eta L)\sigma_{g}^{2}}{(1-\eta L)B_{s}}.`$ |  | (A.11) |

Since $`\log\sigma(z)\leq 0`$ for all $`z`$,

|     |                                                      |     |
|-----|------------------------------------------------------|-----|
|     |
       ``` math
       J(\theta)\leq 0\qquad\text{for all }\theta\in\Theta.
       ```                                                   |     |

Moreover, $`\pi_{\theta_{0}}=\pi_{\mathrm{SFT}}`$, so both log-policy
ratios in the SAIL objective vanish at $`\theta_{0}`$. Consequently,

|     |                                      |     |
|-----|--------------------------------------|-----|
|     |
       ``` math
       J(\theta_{0})=\log\sigma(0)=-\log 2,
       ```                                   |     |

and therefore

|     |                                                    |     |
|-----|----------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{E}[J(\theta_{T})]-J(\theta_{0})\leq\log 2.
       ```                                                 |     |

Finally, $`\eta\leq 1/(2L)`$ implies $`1-\eta L\geq 1/2`$. Applying
these inequalities to
([A.11](#A1.E11 "In Proof. ‣ A.7 Stationarity Under General Policy Parameterizations ‣ Appendix A Proofs for Theorems ‣ On the Convergence of Self-Improving Online LLM Alignment"))
gives

|  |  |  |
|----|----|----|
|  |
``` math
\frac{1}{T}\sum_{t=0}^{T-1}\mathbb{E}\|G_{\eta}(\theta_{t})\|^{2}\leq\frac{8\log 2}{\eta T}+\frac{6\sigma_{g}^{2}}{B_{s}}.
``` |  |

The stated choices of $`T`$ and $`B_{s}`$ make each term on the
right-hand side at most $`\varepsilon/2`$, proving the result. ∎

###### Lemma 2 (Hessian of the Log-Partition Function).

Let $`\pi_{\theta}(a|x)`$ be a log-linear (softmax) policy defined as:

|  |  |  |
|----|----|----|
|  |
``` math
\pi_{\theta}(a|x)=\frac{\exp(\theta^{\top}\psi(x,a))}{\sum_{a^{\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,a^{\prime}))}
``` |  |

The log-partition function is
$`A_{x}(\theta):=\log\sum_{a^{\prime}\in\mathcal{A}}\exp(\theta^{\top}\psi(x,a^{\prime}))`$.
Then, the Hessian of $`A_{x}(\theta)`$ with respect to $`\theta`$ is the
covariance matrix of the features $`\psi(x,a)`$ under the policy
distribution $`\pi_{\theta}(\cdot|x)`$:

|  |  |  |
|----|----|----|
|  |
``` math
\nabla^{2}_{\theta}A_{x}(\theta)=\mathrm{Cov}_{a\sim\pi_{\theta}(\cdot|x)}[\psi(x,a)].
``` |  |

###### Proof.

First, we compute the gradient of the log-partition function,
$`\nabla_{\theta}A_{x}(\theta)`$, by applying the chain rule:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla_{\theta}A_{x}(\theta)`$ | $`\displaystyle=\nabla_{\theta}\log\left(\sum_{a^{\prime}}\exp(\theta^{\top}\psi(x,a^{\prime}))\right)`$ |  |
|  |  | $`\displaystyle=\frac{1}{\sum_{a^{\prime}}\exp(\theta^{\top}\psi(x,a^{\prime}))}\cdot\nabla_{\theta}\left(\sum_{a^{\prime\prime}}\exp(\theta^{\top}\psi(x,a^{\prime\prime}))\right)`$ |  |
|  |  | $`\displaystyle=\frac{1}{\sum_{a^{\prime}}\exp(\theta^{\top}\psi(x,a^{\prime}))}\cdot\left(\sum_{a^{\prime\prime}}\exp(\theta^{\top}\psi(x,a^{\prime\prime}))\cdot\psi(x,a^{\prime\prime})\right)`$ |  |
|  |  | $`\displaystyle=\sum_{a^{\prime\prime}}\frac{\exp(\theta^{\top}\psi(x,a^{\prime\prime}))}{\sum_{a^{\prime}}\exp(\theta^{\top}\psi(x,a^{\prime}))}\cdot\psi(x,a^{\prime\prime})`$ |  |
|  |  | $`\displaystyle=\sum_{a^{\prime\prime}}\pi_{\theta}(a^{\prime\prime}|x)\cdot\psi(x,a^{\prime\prime})`$ |  |
|  |  | $`\displaystyle=\mathbb{E}_{a\sim\pi_{\theta}(\cdot|x)}[\psi(x,a)].`$ |  |

Next, we differentiate the gradient to find the Hessian,
$`\nabla^{2}_{\theta}A_{x}(\theta)`$.

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla^{2}_{\theta}A_{x}(\theta)`$ | $`\displaystyle=\nabla_{\theta}\left(\sum_{a}\pi_{\theta}(a|x)\psi(x,a)\right)`$ |  |
|  |  | $`\displaystyle=\sum_{a}(\nabla_{\theta}\pi_{\theta}(a|x))\psi(x,a)^{\top}.`$ |  |

Using the log-derivative trick,
$`\nabla_{\theta}\pi_{\theta}(a|x)=\pi_{\theta}(a|x)\nabla_{\theta}\log\pi_{\theta}(a|x)`$.
The score function, $`\nabla_{\theta}\log\pi_{\theta}(a|x)`$, is given
by:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla_{\theta}\log\pi_{\theta}(a|x)`$ | $`\displaystyle=\nabla_{\theta}\left(\theta^{\top}\psi(x,a)-\log\sum_{a^{\prime}}\exp(\theta^{\top}\psi(x,a^{\prime}))\right)`$ |  |
|  |  | $`\displaystyle=\psi(x,a)-\nabla_{\theta}A_{x}(\theta).`$ |  |

Substituting this back into the Hessian expression:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla^{2}_{\theta}A_{x}(\theta)`$ | $`\displaystyle=\sum_{a}\pi_{\theta}(a|x)\left(\psi(x,a)-\mathbb{E}[\psi]\right)\psi(x,a)^{\top}`$ |  |
|  |  | $`\displaystyle=\sum_{a}\pi_{\theta}(a|x)\psi(x,a)\psi(x,a)^{\top}-\left(\sum_{a}\pi_{\theta}(a|x)\psi(x,a)\right)\mathbb{E}[\psi]^{\top}`$ |  |
|  |  | $`\displaystyle=\mathbb{E}[\psi\psi^{\top}]-\mathbb{E}[\psi]\mathbb{E}[\psi]^{\top}`$ |  |
|  |  | $`\displaystyle=\mathrm{Cov}_{a\sim\pi_{\theta}(\cdot|x)}[\psi(x,a)].`$ |  |

Since a covariance matrix is always positive semi-definite, it follows
that

|     |                                            |     |
|-----|--------------------------------------------|-----|
|     |
       ``` math
       \nabla^{2}_{\theta}A_{x}(\theta)\succeq 0.
       ```                                         |     |

Hence,

|  |  |  |
|----|----|----|
|  | $`\displaystyle\nabla^{2}_{\theta}\log\pi_{\theta}(a|x)=-\mathrm{Cov}_{a\sim\pi_{\theta}(\cdot|x)}[\psi(x,a)]`$ |  |

∎

###### Lemma 3 (Fisher–Hessian identity under $`\theta`$–independent normalization).

Under assumption
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment")
and let
$`C_{x}(\theta):=\mathrm{Cov}_{a\sim\pi_{\theta}(\cdot\mid x)}[\psi(x,a)]`$.

Define the ordered-pair distribution

|  |  |  |
|----|----|----|
|  |
``` math
\Pi_{\theta}^{\mathrm{order}}(y_{w},y_{l}\mid x)=2P^{*}(y_{w}>y_{l}\mid x)\,\Pi_{\theta}(y_{w},y_{l}\mid x),\qquad\Pi_{\theta}(y_{w},y_{l}\mid x):=\pi_{\theta}(y_{w}\mid x)\pi_{\theta}(y_{l}\mid x).
``` |  |

Let $`S:=\nabla_{\theta}\log\Pi_{\theta}(y_{w},y_{l}\mid x)`$ and
$`H:=\nabla_{\theta}^{2}\log\Pi_{\theta}(y_{w},y_{l}\mid x)`$.

Then,

|  |  |  |
|----|----|----|
|  |
``` math
\ \mathbb{E}_{(y_{w},y_{l})\sim\Pi_{\theta}^{\mathrm{order}}(\cdot\mid x)}[\,SS^{\top}\,]=-\,\mathbb{E}_{(y_{w},y_{l})\sim\Pi_{\theta}^{\mathrm{order}}(\cdot\mid x)}[\,H\,]\ .
``` |  |

The same equality holds after averaging over $`x`$.

###### Proof.

Use the pointwise identity

|  |  |  |
|----|----|----|
|  |
``` math
H=\nabla_{\theta}^{2}\log\Pi_{\theta}=\frac{\nabla_{\theta}^{2}\Pi_{\theta}}{\Pi_{\theta}}-SS^{\top},
``` |  |

which gives

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[SS^{\top}]=-\,\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H]+\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}\!\left[\frac{\nabla_{\theta}^{2}\Pi_{\theta}}{\Pi_{\theta}}\right].
``` |  |

Since $`\Pi_{\theta}^{\mathrm{order}}\propto P^{*}\Pi_{\theta}`$ and
$`P\!`$ is $`\theta`$–independent,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}\!\left[\frac{\nabla_{\theta}^{2}\Pi_{\theta}}{\Pi_{\theta}}\right]`$ | $`\displaystyle=2\sum_{y_{w},y_{l}}P^{*}(y_{w}>y_{l}\mid x)\,\Pi_{\theta}(y_{w},y_{l}\mid x)\cdot\frac{\nabla_{\theta}^{2}\Pi_{\theta}(y_{w},y_{l}\mid x)}{\Pi_{\theta}(y_{w},y_{l}\mid x)}`$ |  |
|  |  | $`\displaystyle=2\sum_{y_{w},y_{l}}P^{*}(y_{w}>y_{l}\mid x)\,\nabla_{\theta}^{2}\Pi_{\theta}(y_{w},y_{l}\mid x)`$ |  |
|  |  | $`\displaystyle=2\,\nabla_{\theta}^{2}\!\left(\sum_{y_{w},y_{l}}P^{*}(y_{w}>y_{l}\mid x)\,\Pi_{\theta}(y_{w},y_{l}\mid x)\right)`$ |  |
|  |  | $`\displaystyle=2\,\nabla_{\theta}^{2}\,\mathbb{E}_{(y_{w},y_{l})\sim\Pi_{\theta}(\cdot\mid x)}\!\big[P^{*}(y_{w}>y_{l}\mid x)\big]`$ |  |
|  |  | $`\displaystyle=2\nabla_{\theta}^{2}\frac{1}{2}.`$ |  |

Therefore the last term vanishes and the stated equality follows. ∎

``` |  |

Let $`S:=\nabla_{\theta}\log\Pi_{\theta}(y_{w},y_{l}\mid x)`$ and
$`H:=\nabla_{\theta}^{2}\log\Pi_{\theta}(y_{w},y_{l}\mid x)`$.

Then

|  |  |  |
|----|----|----|
|  |
``` math
\ \mathbb{E}_{(y_{w},y_{l})\sim\Pi_{\theta}^{\mathrm{order}}(\cdot\mid x)}[\,H\,]\;=\;-\,2\,C_{x}(\theta)\,\qquad\text{and hence}\qquad\ \mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[\,H\,]\;=\;-\,2\,\mathbb{E}_{x}[C_{x}(\theta)]\,.
``` |  |

Equivalently, using Lemma
[3](#Thmlemma3 "Lemma 3 (Fisher–Hessian identity under 𝜃–independent normalization). ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment"),
$`\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[SS^{\top}]=2\,\mathbb{E}_{x}[C_{x}(\theta)]`$.

###### Proof.

For the log–linear policy, by lemma
[2](#Thmlemma2 "Lemma 2 (Hessian of the Log-Partition Function). ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment")

|  |  |  |
|----|----|----|
|  |
``` math
\nabla_{\theta}^{2}\log\pi_{\theta}(y\mid x)=-\,\mathrm{Cov}_{a\sim\pi_{\theta}(\cdot\mid x)}[\psi(x,a)]=-\,C_{x}(\theta).
``` |  |

Because
$`\log\Pi_{\theta}(y_{w},y_{l}\mid x)=\log\pi_{\theta}(y_{w}\mid x)+\log\pi_{\theta}(y_{l}\mid x)`$,
we have

|  |  |  |
|----|----|----|
|  |
``` math
H=\nabla_{\theta}^{2}\log\pi_{\theta}(y_{w}\mid x)+\nabla_{\theta}^{2}\log\pi_{\theta}(y_{l}\mid x)=-\,C_{x}(\theta)-\,C_{x}(\theta)=-\,2\,C_{x}(\theta).
``` |  |

Crucially, the right-hand side depends only on $`x`$ and $`\theta`$, not
on $`(y_{w},y_{l})`$. Therefore, taking expectation with respect to the
ordered-pair distribution (which is normalized,
$`\sum_{y_{w},y_{l}}\Pi_{\theta}^{\mathrm{order}}(\cdot\mid x)=1`$),

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{(y_{w},y_{l})\sim\Pi_{\theta}^{\mathrm{order}}(\cdot\mid x)}[\,H\,]=\sum_{y_{w},y_{l}}\Pi_{\theta}^{\mathrm{order}}(y_{w},y_{l}\mid x)\,(-2\,C_{x}(\theta))=-\,2\,C_{x}(\theta).
``` |  |

Averaging further over $`x`$ gives
$`\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H]=-2\,\mathbb{E}_{x}[C_{x}(\theta)]`$.
Finally, by Lemma
[3](#Thmlemma3 "Lemma 3 (Fisher–Hessian identity under 𝜃–independent normalization). ‣ Appendix B Supporting Lemmas ‣ On the Convergence of Self-Improving Online LLM Alignment"),
$`\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[SS^{\top}]=-\mathbb{E}_{\Pi_{\theta}^{\mathrm{order}}}[H]=2\,\mathbb{E}_{x}[C_{x}(\theta)]`$.
∎

###### Lemma 5 (Scalar lower bound times a PSD random matrix).

Let $`M(\omega)\succeq 0`$ be a random positive semi-definite matrix and
$`g(\omega)`$ a real random variable. If $`g(\omega)\geq m`$ almost
surely, then

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}[\,g(\omega)M(\omega)\,]\ \succeq\ m\,\mathbb{E}[\,M(\omega)\,].
``` |  |

###### Proof.

For any fixed vector $`v`$,
$`v^{\top}\!\big(\mathbb{E}[gM]-m\mathbb{E}[M]\big)v=\mathbb{E}\!\big[(g-m)\,v^{\top}Mv\big]\geq 0`$
because $`g-m\geq 0`$ and $`v^{\top}Mv\geq 0`$. Hence
$`\mathbb{E}[gM]-m\mathbb{E}[M]\succeq 0`$. ∎

###### Lemma 6.

Under Assumptions
[3](#Thmassumption3 "Assumption 3 (L-smoothness). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment")
and
[4](#Thmassumption4 "Assumption 4 (Unbiased Stochastic Gradients). ‣ 5.1 Convergence Analysis ‣ 5 THEORETICAL RESULTS ‣ On the Convergence of Self-Improving Online LLM Alignment"),
let $`\hat{g}_{t}=\frac{1}{B_{s}}\sum_{i=1}^{B}g_{t}^{(i)}`$ denote the
mini-batch estimator at iteration $`t`$. Then we have

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}[\hat{g}_{t}]=\nabla J_{\gamma}(\theta_{t}),\quad\mathbb{E}\|\hat{g}_{t}-\nabla J_{\gamma}(\theta_{t})\|^{2}\leq\frac{\sigma_{g}^{2}}{B_{s}}.
``` |  |

###### Proof.

Since each $`g_{t}^{(i)}`$ is an independent unbiased estimator of
$`\nabla J_{\gamma}(\theta_{t})`$, we have

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}[\hat{g}_{t}]=\mathbb{E}\left[\frac{1}{B_{s}}\sum_{i=1}^{B_{s}}g_{t}^{(i)}\right]=\frac{1}{B_{s}}\sum_{i=1}^{B_{s}}\mathbb{E}[g_{t}^{(i)}]=\nabla J_{\gamma}(\theta_{t}).
``` |  |

Therefore, $`\hat{g}_{t}`$ is unbiased.

Next, we compute its variance:

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}\|\hat{g}_{t}-\nabla J_{\gamma}(\theta_{t})\|^{2}=\mathbb{E}\left\|\frac{1}{B_{s}}\sum_{i=1}^{B_{s}}(g_{t}^{(i)}-\nabla J_{\gamma}(\theta_{t}))\right\|^{2}.
``` |  |

By independence and identical distribution of $`g_{t}^{(i)}`$,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}\|\hat{g}_{t}-\nabla J_{\gamma}(\theta_{t})\|^{2}=\frac{1}{B_{s}^{2}}\sum_{i=1}^{B_{s}}\mathbb{E}\|g_{t}^{(i)}-\nabla J_{\gamma}(\theta_{t})\|^{2}\leq\frac{1}{B_{s}^{2}}\cdot B_{s}\sigma_{g}^{2}=\frac{\sigma_{g}^{2}}{B_{s}}.
``` |  |

∎

###### Lemma 7 (L-smoothness of the Objective Function).

Under Assumption
[1](#Thmassumption1 "Assumption 1 (Log-linear policy class). ‣ 4.1 Problem Setup ‣ 4 PROBLEM SETUP AND PROPOSED ALGORITHM ‣ On the Convergence of Self-Improving Online LLM Alignment"),
the objective function $`J_{\gamma}(\theta)`$ is L-smooth on the
parameter set
$`\Theta=\{\theta\in\mathbb{R}^{d}:||\theta-\theta_{0}||_{2}\leq B\}`$.
That is, there exists a finite constant $`L>0`$ such that its Hessian is
uniformly bounded:

|  |  |  |
|----|----|----|
|  |
``` math
||\nabla^{2}J_{\gamma}(\theta)||\leq L,\quad\forall\theta\in\Theta.
``` |  |

###### Proof.

To establish L-smoothness, we prove that the spectral norm of the
Hessian, $`||\nabla^{2}J_{\gamma}(\theta)||`$, is bounded by a finite
constant for all $`\theta\in\Theta`$.

The Hessian of the regularized objective is
$`\nabla^{2}J_{\gamma}(\theta)=\nabla^{2}J(\theta)-\gamma\mathbb{E}_{x}[C_{x}(\theta)]`$.The
full expression for $`\nabla^{2}J(\theta)`$ is given by:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\nabla^{2}J(\theta)=2\mathbb{E}_{\Pi_{\theta}^{order}}`$ | $`\displaystyle[SS^{\top}F_{\theta}]+2\mathbb{E}_{\Pi_{\theta}^{order}}[2S\cdot\beta(1-\sigma(\beta(\theta-\theta_{0})^{\top}z))z^{\top}]`$ |  |
|  |  | $`\displaystyle+2\mathbb{E}_{\Pi_{\theta}^{order}}[HF_{\theta}]+2\mathbb{E}_{\Pi_{\theta}^{order}}[-\beta^{2}\sigma(\beta(\theta-\theta_{0})^{\top}z)(1-\sigma(\beta(\theta-\theta_{0})^{\top}z))zz^{\top}].`$ |  |

The Hessian of the regularizer is
$`\nabla^{2}(\mathbb{E}_{x}[D_{KL}(\pi_{ref}||\pi_{\theta})])=\mathbb{E}_{x}[C_{x}(\theta)]`$.

We bound the norm of each component using the bounds derived from
Assumption 1. By the triangle inequality:

|  |  |  |
|----|----|----|
|  |
``` math
||\nabla^{2}J_{\gamma}(\theta)||\leq||\nabla^{2}J(\theta)||+\gamma||\mathbb{E}_{x}[C_{x}(\theta)]||.
``` |  |

First, we recall the established bounds on intermediate terms for
$`\theta\in\Theta`$:

- •
  $`||z||_{2}\leq 2`$
- •
  $`||S||_{2}\leq 4`$
- •
  $`||H||_{2}\leq 4`$
- •
  $`|F_{\theta}|=|\log\sigma(\beta(\theta-\theta_{0})^{\top}z)|\leq\log(1+e^{2\beta B})`$
- •
  $`||\nabla_{\theta}F_{\theta}||_{2}=||\beta(1-\sigma(\beta(\theta-\theta_{0})^{\top}z))z||_{2}\leq 2\beta`$
- •
  $`||\nabla_{\theta}^{2}F_{\theta}||_{2}=||-\beta^{2}\sigma(\beta(\theta-\theta_{0})(1-\sigma(\beta(\theta-\theta_{0}))zz^{\top}||_{2}\leq\beta^{2}\cdot\frac{1}{4}\cdot||z||_{2}^{2}\leq\beta^{2}`$

Using these bounds, we can bound the norm of each term in
$`\nabla^{2}J(\theta)`$:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle||\nabla^{2}J(\theta)||`$ | $`\displaystyle\leq 2||\mathbb{E}[SS^{\top}F_{\theta}]||+2||\mathbb{E}[2S(\nabla_{\theta}F_{\theta})^{\top}]||+2||\mathbb{E}[HF_{\theta}]||+2||\mathbb{E}[\nabla_{\theta}^{2}F_{\theta}]||`$ |  |
|  |  | $`\displaystyle\leq 2\mathbb{E}[||S||_{2}^{2}|F_{\theta}|]+4\mathbb{E}[||S||_{2}||\nabla_{\theta}F_{\theta}||_{2}]+2\mathbb{E}[||H||_{2}|F_{\theta}|]+2\mathbb{E}[||\nabla_{\theta}^{2}F_{\theta}||_{2}]`$ |  |
|  |  | $`\displaystyle\leq 2\cdot(4^{2}\cdot\log(1+e^{2\beta B}))+4\cdot(4\cdot 2\beta)+2\cdot(4\cdot\log(1+e^{2\beta B}))+2\beta^{2}`$ |  |
|  |  | $`\displaystyle=32\log(1+e^{2\beta B})+32\beta+8\log(1+e^{2\beta B})+2\beta^{2}`$ |  |
|  |  | $`\displaystyle=40\log(1+e^{2\beta B})+32\beta+2\beta^{2}.`$ |  |

For the regularizer term, we proceed by first establishing a pointwise
bound on the operator norm of $`C_{x}(\theta)`$ for any given $`x`$, and
then extending this bound to the expectation.

The matrix $`C_{x}(\theta)=\nabla_{\theta}^{2}A_{x}(\theta)`$ is the
covariance matrix of the features $`\psi(x,a)`$ and
$`\|\nabla_{\theta}^{2}A_{x}(\theta)\|_{\mathrm{op}}\leq 1`$

This allows us to move the norm inside the expectation:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\gamma||\mathbb{E}_{x}[C_{x}(\theta)]||`$ | $`\displaystyle\leq\gamma\mathbb{E}_{x}[||C_{x}(\theta)||]`$ |  |
|  |  | $`\displaystyle\leq\gamma\mathbb{E}_{x}[1]`$ |  |
|  |  | $`\displaystyle=\gamma.`$ |  |

Combining these results yields a final upper bound:

|  |  |  |
|----|----|----|
|  |
``` math
||\nabla^{2}J_{\gamma}(\theta)||\leq 40\log(1+e^{2\beta B})+32\beta+2\beta^{2}+\gamma.
``` |  |

Since $`\beta`$, $`B`$, and $`\gamma`$ are finite constants, we have
found a finite upper bound
$`L:=40\log(1+e^{2\beta B})+32\beta+2\beta^{2}+\gamma`$. This concludes
the proof that $`J_{\gamma}(\theta)`$ is L-smooth. ∎

###### Lemma 8 (One-step progress with projection).

Let $`J_{\gamma}:\mathbb{R}^{d}\to\mathbb{R}`$ be $`L`$-smooth and let
$`\Theta\subseteq\mathbb{R}^{d}`$ be closed and convex. Consider the
projected update

|  |  |  |
|----|----|----|
|  |
``` math
\theta^{\prime}_{t+1}\coloneqq\theta_{t}+\eta\hat{g}_{t},\qquad\theta_{t+1}\coloneqq\Pi_{\Theta}(\theta^{\prime}_{t+1}),\qquad g_{t}\coloneqq\nabla J_{\gamma}(\theta_{t}),\qquad\Delta_{t}\coloneqq\theta_{t+1}-\theta_{t},
``` |  |

where $`\Pi_{\Theta}`$ denotes the Euclidean projection and
$`\hat{g}_{t}`$ is a stochastic gradient. Then the following bound holds
for any $`\eta>0`$:

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}[J_{\gamma}(\theta_{t+1})]\geq\mathbb{E}[J_{\gamma}(\theta_{t})]+\Bigl(\frac{1}{2\eta}-\frac{L}{2}\Bigr)\mathbb{E}\|\Delta_{t}\|^{2}-\frac{\eta}{2}\,\mathbb{E}\|g_{t}-\hat{g}_{t}\|^{2}.
``` |  |

And we have
$`\mathbb{E}\|\Delta_{t}\|^{2}\leq\eta^{2}\mathbb{E}\|\hat{g}_{t}\|^{2}`$.

###### Proof.

$`L`$-smoothness yields, for any $`x,y`$,
$`J_{\gamma}(y)\geq J_{\gamma}(x)+\langle\nabla J_{\gamma}(x),y-x\rangle-\tfrac{L}{2}\|y-x\|^{2}`$.
With $`x=\theta_{t}`$ and $`y=\theta_{t+1}`$ and taking expectation,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}[J_{\gamma}(\theta_{t+1})]\;\geq\;\mathbb{E}[J_{\gamma}(\theta_{t})]+\mathbb{E}\!\left[\langle g_{t},\Delta_{t}\rangle\right]-\frac{L}{2}\,\mathbb{E}\!\left[\|\Delta_{t}\|^{2}\right].
``` |  |

Decompose the inner product:

|  |  |  |
|----|----|----|
|  |
``` math
\langle g_{t},\Delta_{t}\rangle=\langle\hat{g}_{t},\Delta_{t}\rangle+\langle g_{t}-\hat{g}_{t},\Delta_{t}\rangle.
``` |  |

By firm non-expansiveness of the Euclidean projection,
$`\langle\Pi(a)-\Pi(b),\,a-b\rangle\geq\|\Pi(a)-\Pi(b)\|^{2}`$ for all
$`a,b`$. With $`a=\theta_{t}+\eta\hat{g}_{t}`$ and $`b=\theta_{t}`$,

|  |  |  |
|----|----|----|
|  |
``` math
\langle\hat{g}_{t},\Delta_{t}\rangle=\frac{1}{\eta}\,\big\langle\theta_{t+1}-\theta_{t},\;(\theta_{t}+\eta\hat{g}_{t})-\theta_{t}\big\rangle\;\geq\;\frac{1}{\eta}\,\|\Delta_{t}\|^{2}.
``` |  |

For the error term, by Cauchy–Schwarz and Young’s inequality
$`ab\leq\tfrac{a^{2}}{2\eta}+\tfrac{\eta}{2}b^{2}`$,

|  |  |  |
|----|----|----|
|  |
``` math
\langle g_{t}-\hat{g}_{t},\Delta_{t}\rangle\geq-\|g_{t}-\hat{g}_{t}\|\,\|\Delta_{t}\|\geq-\frac{1}{2\eta}\|\Delta_{t}\|^{2}-\frac{\eta}{2}\|g_{t}-\hat{g}_{t}\|^{2},
``` |  |

Combining above gives

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}[J_{\gamma}(\theta_{t+1})]\geq\mathbb{E}[J_{\gamma}(\theta_{t})]+\Bigl(\frac{1}{2\eta}-\frac{L}{2}\Bigr)\mathbb{E}\|\Delta_{t}\|^{2}-\frac{\eta}{2}\,\mathbb{E}\|g_{t}-\hat{g}_{t}\|^{2}.
``` |  |

∎

###### Lemma 9 (Projection fixed point / KKT equivalence).

Consider Problem $`\max_{\theta\in\Theta}J_{\gamma}(\theta)`$, where
$`J_{\gamma}`$ is L-smooth, and $`\Theta`$ is closed, convex and
nonempty. Then $`\theta^{*}`$ satisfies the first-order optimality
condition $`\nabla J_{\gamma}(\theta^{*})\in N_{\Theta}(\theta^{*})`$,
if and only if for any $`\eta>0`$,

|  |  |  |
|----|----|----|
|  |
``` math
\theta^{*}\;=\;\Pi_{\Theta}\!\big(\theta^{*}+\eta\,\nabla J_{\gamma}(\theta^{*})\big).
``` |  |

Equivalently, $`G_{\eta}(\theta^{*})=0`$.

###### Remark 12.

See \[[Wright and Recht, 2022](#bib.bib6)\] Prop. 7.8.

###### Proof.

*“if” part.* Suppose $`G_{\eta}(x^{*})=0`$. This means

|  |  |  |
|----|----|----|
|  |
``` math
\theta^{*}\;=\;\Pi_{\Theta}\!\big(\theta^{*}+\eta\,\nabla J_{\gamma}(\theta^{*})\big)\;=\;\arg\min_{\theta\in\Theta}\;\frac{1}{2}\Bigl\|\,\theta-\bigl(\theta^{*}+\eta\,\nabla J_{\gamma}(\theta^{*})\bigr)\Bigr\|_{2}^{2}.
``` |  |

Applying the first-order optimality condition to the above projection
problem yields

|  |  |  |
|----|----|----|
|  |
``` math
N_{\mathcal{X}}(x^{*})\;\ni\;\nabla\!\left[\frac{1}{2}\Bigl\|\,\theta-\bigl(\theta^{*}+\eta\,\nabla J_{\gamma}(\theta^{*})\bigr)\Bigr\|_{2}^{2}\right]_{\,\theta=\theta^{*}}\;=\;\eta\,\nabla J_{\gamma}(\theta^{*}),
``` |  |

which is exactly
$`\nabla J_{\gamma}(\theta^{*})\in N_{\Theta}(\theta^{*})`$.

*“only if” part.* Suppose
$`\nabla J_{\gamma}(\theta^{*})\in N_{\Theta}(\theta^{*})`$. By the
definition of the normal cone, for all $`\theta\in\Theta`$,

|  |  |  |
|----|----|----|
|  |
``` math
0\;\geq\;\eta\,\langle\nabla J_{\gamma}(\theta^{*}),\,\theta-\theta^{*}\rangle\;=\;\Bigl\langle\theta-\bigl(\theta^{*}+\eta\,\nabla J_{\gamma}(\theta^{*})\bigr),\;\theta-\theta^{*}\Bigr\rangle.
``` |  |

By the minimum principle (characterization) of Euclidean projection,

|  |  |  |
|----|----|----|
|  |
``` math
\langle\Pi_{\Theta}(z)-z,\;y-\Pi_{\Theta}(z)\rangle\;\geq\;0,\quad\forall\,y\in\mathcal{X},
``` |  |

with $`z=\theta^{*}+\eta\,\nabla J_{\gamma}(\theta^{*})`$, the above
inequality implies

|  |  |  |
|----|----|----|
|  |
``` math
\theta^{*}\;=\;\Pi_{\Theta}(z)\;=\;\Pi_{\Theta}\!\Bigl(\theta^{*}+\eta\,\nabla J_{\gamma}(\theta^{*})\Bigr).
``` |  |

∎
````
