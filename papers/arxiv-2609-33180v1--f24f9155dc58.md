# Which Self-Improvements Should We Trust? Reliable Self-Improvement When Agents Reuse Their Benchmarks

Xiaojing Sun Affiliation: Purdue University    Yuhan Zeng
Affiliation: Purdue University    Zihua She Affiliation: Purdue
University    Xiao Wang Affiliation: Purdue University

###### Abstract

As recursive self-improvement (RSI) rapidly advances, reliable
evaluation becomes critical for guiding adaptive search. RSI typically
relies on finite evaluation resources, such as fixed benchmarks, to
determine which modifications are retained and what is proposed next.
However, when these finite resources are repeatedly reused, new
candidates are proposed based on feedback from the same evaluation set,
so the search trajectory can adaptively overfit and empirical
improvement may not reflect genuine population improvement on the
underlying task distribution. Some existing methods account for multiple
comparisons but assume that candidates are chosen independently of the
evaluation set, and therefore do not control this adaptive dependence.
To address this, we propose Reuse (Risk-controlled Evaluation Under
Sequential Evolution), a certified evaluation and promotion framework
that allows a fixed evaluation set to support repeated adaptive
decisions while providing statistical guarantees. Specifically, for a
user-specified error level $`\alpha`$, with probability at least
$`1-\alpha`$, every promoted modification is a genuine population
improvement on the underlying task distribution. Reuse achieves this by
strictly limiting the evaluation feedback returned to the search process
and accounting for possible promotion histories within the error budget.
We develop a detailed statistical theory for RSI evaluation in this
setting, including simultaneous error control, valid lower bounds on
cumulative improvement, and a characterization of the fundamental limits
of adaptive evaluation reuse. In live self-improvement experiments,
Reuse commits substantially fewer false promotions than evaluation
frameworks from current RSI systems and error-controlled baselines,
reducing the proportion of promotions that are false from up to 20.7% to
0%, while achieving final true population performance comparable to the
best baselines.

## 1 Introduction

Recent progress in recursive self-improvement (RSI) has significantly
advanced the capabilities of self-improving AI systems. For instance,
agents now rewrite their own tools ([Zhang et al., 2026](#bib.bib9);
[Robeyns et al., 2025](#bib.bib10)), evolve production-ready algorithms
([Novikov et al., 2025](#bib.bib15)), and automate complex workflows
like model alignment and post-training ([Chen et al.,
2026b](#bib.bib13); [Rank et al., 2026](#bib.bib11)). As agents become
more capable at proposing and executing changes ([Zelikman et al.,
2024](#bib.bib40); [Hu et al., 2025](#bib.bib42); [Lu et al.,
2024](#bib.bib43); [Wang et al., 2026b](#bib.bib16)), evaluation becomes
increasingly critical ([Manheim and Garrabrant, 2018](#bib.bib52);
[Skalse et al., 2022](#bib.bib53); [Gao et al., 2023](#bib.bib54); [Guo
et al., 2026](#bib.bib44)). The evaluation feedback dictates which
candidate modifications are retained, expanded, or used to generate
future proposals. Ideally, this feedback would favor only changes that
improve performance on the underlying task distribution ([Hastie et al.,
2009](#bib.bib55); [Recht et al., 2019](#bib.bib23)). In practice,
current RSI systems employ diverse search strategies but typically
obtain this feedback by repeatedly querying a finite set of fixed
benchmarks ([Wang et al., 2026c](#bib.bib36)).

This creates a fundamental statistical challenge. When RSI systems rely
on a finite set of benchmarks to guide adaptive search, the search
trajectory becomes increasingly tuned to the evaluation signal ([Shawn,
2026](#bib.bib3)), and empirical improvement may reflect adaptation to
these benchmark tasks rather than genuine improvement ([Wang et al.,
2026c](#bib.bib36); [Chen et al., 2026b](#bib.bib13)). False promotions
in this setting arise from three main sources.

- •
  Within-round selection. Selecting the best of several candidates
  within a round favors candidates whose advantage on the evaluation set
  is overstated by chance ([Cawley and Talbot, 2010](#bib.bib56);
  [Efron, 2011](#bib.bib34); [Xu et al., 2026](#bib.bib5)).
- •
  Repeated testing. Testing across many rounds increases the probability
  that at least one test makes an error ([Dunn, 1961](#bib.bib57);
  [Holm, 1979](#bib.bib47)).
- •
  Adaptive dependence. Later candidates are adapted to earlier
  evaluation outcomes ([Dwork et al., 2015b](#bib.bib18); [Hardt and
  Ullman, 2014](#bib.bib45); [Blum and Hardt, 2015](#bib.bib17)).

The first two would arise even if every round used fresh evaluation
data, and standard multiple comparison corrections handle them by
accounting for the number of tests ([Dunn, 1961](#bib.bib57); [Holm,
1979](#bib.bib47); [Bretz et al., 2009](#bib.bib48); [Tian and Ramdas,
2021](#bib.bib33)). The third source arises from benchmark reuse. When
later candidates are generated based on earlier outcomes on the
evaluation set and then tested on that same set, the candidates
themselves become functions of the evaluation set. This adaptive
dependence violates the assumption of standard statistical tests that
candidates are chosen independently of the evaluation set ([Kriegeskorte
et al., 2009](#bib.bib58); [Berk et al., 2013](#bib.bib50); [Dwork et
al., 2015a](#bib.bib19)). Consequently, a candidate may be promoted
because it overfits the specific evaluation set, rather than because it
genuinely improves on the underlying task distribution. Recent work
attempts to bring statistical error control into self-improvement loops
and iterative evaluation ([Shawn, 2026](#bib.bib3); [Wu et al.,
2025](#bib.bib2); [Sengupta, 2026](#bib.bib4); [Guo et al.,
2026](#bib.bib44); [Bertran et al., 2026](#bib.bib6)). However, none of
these methods account for all three sources of false promotion
simultaneously. In particular, their statistical guarantees rely on each
candidate being independent of the data on which it is evaluated, and
restricting feedback alone does not account for the information revealed
by the promotion decisions themselves. Because they do not address the
adaptive dependence created by reusing the same evaluation set, they
cannot guarantee that every promoted modification is a genuine
population improvement.

In this paper, we propose Reuse (Risk-controlled Evaluation Under
Sequential Evolution), a certified evaluation and promotion framework
for adaptive self-improvement that controls all three sources jointly.
Reuse allows a fixed evaluation set to be reused throughout an adaptive
search while preserving valid evidence of population improvement. In
each round, candidate modifications are evaluated against the current
system, but the search process receives only the promotion decision
rather than evaluation scores or task-level outcomes
([Figure 1](#S1.F1 "In 1 Introduction ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")).
Later candidates may still adapt to earlier decisions, but they can
depend on the evaluation set only through this decision history. For
each possible history, the candidates are determined without reference
to the evaluation set, so the corresponding comparison is a valid test.
Reuse therefore turns the dependence on the evaluation set into a
multiple comparison problem over all possible decision histories, and
controls it together with the first two sources within a global error
budget. As a result, for a user-specified level $`\alpha`$, with
probability at least $`1-\alpha`$, every promoted modification over the
entire self-improvement process is a genuine population improvement on
the underlying task distribution.

Our main contributions are:

- •
  We propose Reuse, a certified evaluation and promotion framework for
  adaptive self-improvement that jointly addresses the statistical
  challenges of within-round selection, repeated testing, and adaptive
  dependence under finite evaluation resources. For a user-specified
  error level $`\alpha`$, with probability at least $`1-\alpha`$, every
  promoted modification is a genuine population improvement on the
  underlying task distribution.
- •
  We develop statistical theory for evaluation under benchmark reuse,
  including simultaneous error control over the entire process, valid
  lower bounds on cumulative improvement, the minimum detectable
  improvement, and the fundamental limits of adaptive evaluation reuse.
- •
  We evaluate Reuse in live self-improvement experiments against
  evaluation frameworks from current RSI systems and error-controlled
  baselines. Reuse commits substantially fewer false promotions than
  competing methods, reducing the proportion of promotions that are
  false from up to 20.7% to 0%, while achieving final true population
  performance within 0.04 percentage points of the best baselines,
  demonstrating that its rigorous statistical guarantees do not
  compromise overall progress.

## 2 Methodology and Theoretical Guarantees

In this section, we formalize the adaptive self-improvement setting,
present Reuse, and establish its statistical guarantees. More
comprehensive theoretical results and complete proofs are given in
[Appendix A](#A1 "Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").

### 2.1 Setting and objective

A system $`A\in\mathcal{A}`$ denotes the complete agent or AI system
evaluated at a given round. A modification may change its prompt, code,
tools, training procedure, or model parameters. Let $`Q`$ denote the
underlying population distribution on which system performance is
measured. For an evaluation draw $`W\sim Q`$, the score of system $`A`$
is $`s(A,W)\in[0,1]`$. Any randomness used in the evaluation is included
in $`W`$. The population performance of $`A`$ is

|     |     |     |
| --- | --- | --- |
|     |

       ``` math
       V(A)=\mathbb{E}_{W\sim Q}[s(A,W)],\qquad\Delta(B,A)=V(B)-V(A),
       ```                                                             |     |

where $`\Delta(B,A)`$ is the population improvement of candidate $`B`$
over system $`A`$.

The self-improvement process starts from $`A_{0}`$. At round $`t`$, the
current system is $`A_{t-1}`$ and the proposer generates $`K`$
candidates $`B_{t,1},\ldots,B_{t,K}.`$ The promotion decision is
$`y_{t}\in\{0,1,\ldots,K\}`$. If $`y_{t}=k>0`$, candidate $`B_{t,k}`$
becomes the new system. If $`y_{t}=0`$, all candidates are rejected and
the incumbent is retained. We write
$`p_{t}=\sum_{s=1}^{t}\mathbf{1}\{y_{s}\neq 0\}`$ for the number of
promotions through round $`t`$.

Promotion decisions are based on a fixed evaluation set

|     |     |     |
| --- | --- | --- |
|     |

````math
S=(W_{1},\ldots,W_{n}),\qquad W_{i}\overset{\mathrm{i.i.d.}}{\sim}Q,
``` |  |

drawn before the process begins and repeatedly reused across rounds. For
any pair of systems $`(B,A)`$, define the paired differences

|     |                                   |     |
|-----|-----------------------------------|-----|
|     |
       ``` math
       Z_{i}(B,A)=s(B,W_{i})-s(A,W_{i}),
       ```                                |     |

which are i.i.d. with mean $`\Delta(B,A)`$. The proposer receives
information from $`S`$ only through previous promotion decisions. It may
otherwise adapt using its own randomness $`R`$, development data $`D`$,
and those decisions. We formalize this setting with two assumptions.

###### Assumption 1 (Independent evaluation set).

The evaluation set $`S`$ is independent of the tuple $`(R,D,A_{0})`$
consisting of the proposer’s randomness, the development data, and the
initial system.

###### Assumption 2 (Decision-only feedback).

Write $`\xi=(R,D,A_{0})`$. For every round $`t\geq 1`$ and candidate
index $`k\leq K`$, there is a map $`f_{t,k}`$ such that
$`B_{t,k}=f_{t,k}(\xi,y_{1:t-1})`$. Moreover, the map
$`(\xi,w)\mapsto s(A_{0},w)`$ and, for every $`t\geq 1`$, $`k\leq K`$,
and fixed history $`h\in\{0,1,\ldots,K\}^{t-1}`$, the map
$`(\xi,w)\mapsto s(f_{t,k}(\xi,h),w)`$ are jointly measurable.

[Assumption 1](#Thmassumption1 "Assumption 1 (Independent evaluation set). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
requires that the evaluation set $`S`$ be drawn independently of
everything that shapes the search from the start, which is exactly what
a benchmark is meant to be, a fresh sample from the target task
distribution that plays no role in development.
[Assumption 2](#Thmassumption2 "Assumption 2 (Decision-only feedback). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
requires that $`S`$ influence the search only through the promotion
decisions, while the proposer is otherwise unrestricted and can freely
use any language model or development pipeline.

Together, the two assumptions ensure that candidate generation depends
on $`S`$ only through the decision history. Once $`\xi`$ is fixed, every
possible decision history determines the incumbent and the next
candidates without reference to $`S`$, and by
[Assumption 1](#Thmassumption1 "Assumption 1 (Independent evaluation set). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
$`S`$ remains an i.i.d. sample from $`Q`$. Every comparison determined
in this way is therefore a valid test, and each comparison actually made
during the search is one of them. This turns the adaptive dependence
created by benchmark reuse into a multiple comparison problem over all
possible decision histories, which the allocation in
[Section 2.2](#S2.SS2 "2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
explicitly controls. The measurability condition is technical and holds
for essentially any practical proposer, for example whenever systems are
prompts, programs, or configurations.

For a practical improvement threshold $`\gamma\geq 0`$, a promotion is
false if $`\Delta(A_{t},A_{t-1})\leq\gamma.`$ Our goal is to control all
promotions simultaneously:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{P}\!\left(\Delta(A_{t},A_{t-1})>\gamma\text{ for every }t\text{ with }y_{t}\neq 0\right)\geq 1-\alpha.
``` |  | (1) |

### 2.2 Reuse

To achieve the guarantee in
([1](#S2.E1 "Equation 1 ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")),
Reuse tests each candidate against the current system using paired
evaluation and allocates a single error budget across all candidate
comparisons that may arise during the adaptive search. At each round,
the proposer generates candidates using development data and previous
promotion decisions, and receives only the evaluation framework’s
promotion decision.
[Figure 1](#S1.F1 "In 1 Introduction ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
illustrates this process. We first consider pass/fail benchmarks with
$`\gamma=0`$, where $`s(A,W)\in\{0,1\}`$. The same framework extends
naturally to bounded scores $`s(A,W)\in[0,1]`$, where the detailed
construction is given in
[Section A.1](#A1.SS1 "A.1 A paired lower confidence bound for bounded scores ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").

For a fixed candidate $`B`$ and incumbent $`A`$, let $`n_{+}`$ be the
number of evaluation tasks on which $`B`$ succeeds and $`A`$ fails, let
$`n_{-}`$ be the number on which $`A`$ succeeds and $`B`$ fails, and let
$`M=n_{+}+n_{-}`$ be the number of tasks on which the two systems have
different outcomes. We test whether the candidate genuinely improves on
the incumbent:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
H_{0}:\Delta(B,A)\leq 0\qquad\text{versus}\qquad H_{1}:\Delta(B,A)>0.
``` |  | (2) |

Under $`H_{0}`$, conditional on a task where the two systems disagree,
the probability that $`B`$ wins is at most $`1/2`$. Conditional on
$`M`$, this gives the exact one-sided paired sign-test $`p`$-value

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi(n_{+},M)=\mathbb{P}\!\left(\mathrm{Bin}(M,\tfrac{1}{2})\geq n_{+}\right),\qquad\pi(0,0)=1.
``` |  | (3) |

A small value of $`\pi(n_{+},M)`$ provides evidence in favor of
$`\Delta(B,A)>0`$, and its finite-sample validity is established in
[Lemma A2](#A1.Thmlemma2 "Lemma A2 (Validity of the exact paired test). ‣ A.2 Validity of the exact paired sign test ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").

A single hypothesis test controls the error for one fixed
candidate–incumbent comparison. In the self-improvement loop, however,
many comparisons are made on the same evaluation set, and later
candidates depend on earlier promotion decisions. To control false
promotions over the entire run, Reuse allocates the global error budget
$`\alpha\in(0,1)`$ across all comparisons that can arise under all
possible decision histories.

Suppose $`p`$ promotions have occurred before round $`t`$. The $`p`$
promotion rounds can be chosen in $`\binom{t-1}{p}`$ ways, and each
promotion can select one of $`K`$ candidates. Hence there are
$`\tbinom{t-1}{p}\,K^{p}`$ possible decision histories with $`p`$
previous promotions. Under
[Assumption 2](#Thmassumption2 "Assumption 2 (Decision-only feedback). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),
once $`(R,D,A_{0})`$ are fixed, each such history determines the
incumbent and the $`K`$ candidates at round $`t`$. Let
$`(w_{t})_{t\geq 1}`$ and $`(v_{p})_{p\geq 0}`$ be nonnegative weights
satisfying $`\sum_{t\geq 1}w_{t}\leq 1`$ and
$`\sum_{p\geq 0}v_{p}\leq 1.`$ These weights distribute the overall
error budget across the round index and the number of previous
promotions. At round $`t`$ after $`p`$ promotions, each candidate
comparison is assigned the error budget

|     |                                                               |     |     |
|-----|---------------------------------------------------------------|-----|-----|
|     |
       ``` math
       \delta_{t,p}=\frac{\alpha w_{t}v_{p}}{\binom{t-1}{p}K^{p+1}}.
       ```                                                            |     | (4) |

This explicit allocation addresses all three sources of false promotion
mentioned in
[Section 1](#S1 "1 Introduction ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
simultaneously. The weights over rounds $`t`$ control repeated testing,
the additional factor $`K`$ in the denominator accounts for within-round
selection, and the $`\binom{t-1}{p}K^{p}`$ term handles adaptive
dependence by covering all possible histories. Throughout the paper we
use $`w_{t}=1/[t(t+1)]`$ and $`v_{p}=1/[(p+1)(p+2)].`$

To also quantify cumulative improvement, we divide $`\delta_{t,p}`$ into
two parts. For a fixed $`\rho\in(0,1)`$, a fraction $`\rho\delta_{t,p}`$
is used for the sign test, and the remaining $`(1-\rho)\delta_{t,p}`$ is
used to construct a lower confidence bound $`\ell`$ on the candidate’s
population improvemetn
([Lemma A3](#A1.Thmlemma3 "Lemma A3 (Lower confidence bound for pass/fail evaluation). ‣ A.3 A lower confidence bound for pass/fail evaluation ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")).
When a candidate is promoted, Reuse adds $`\max\{\ell,0\}`$ to a running
certificate $`C_{t}`$, initialized at $`C_{0}=0`$. The certificate is
kept for auditing and is not returned to the proposer during the search.

For candidate $`k`$ at round $`t`$, define its empirical improvement
over the incumbent as

|     |                                                              |     |
|-----|--------------------------------------------------------------|-----|
|     |
       ``` math
       \bar{Z}_{k}=\frac{1}{n}\sum_{i=1}^{n}Z_{i}(B_{t,k},A_{t-1}).
       ```                                                           |     |

If multiple candidates pass the promotion test, Reuse promotes the one
with the largest $`\bar{Z}_{k}`$. The complete procedure is given in
[Algorithm 1](#alg1 "In 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").

1: $`p\leftarrow p_{t-1}`$ and $`\delta\leftarrow\delta_{t,p}`$

2: for $`k=1,\ldots,K`$ do

3:   Compute $`(n_{+,k},n_{-,k})`$ and $`\bar{Z}_{k}`$ for $`B_{t,k}`$
against $`A_{t-1}`$

4:
  $`\mathrm{pass}_{k}\leftarrow\left[\pi(n_{+,k},n_{+,k}+n_{-,k})\leq\rho\delta\right]`$

5: end for

6: if at least one candidate passes then

7:   $`k^{\star}\leftarrow\arg\max_{k:\mathrm{pass}_{k}}\bar{Z}_{k}`$

8:   Compute a lower confidence bound $`\ell`$ for
$`\Delta(B_{t,k^{\star}},A_{t-1})`$ at error level $`(1-\rho)\delta`$

9:   $`y_{t}\leftarrow k^{\star}`$

10:   $`C_{t}\leftarrow C_{t-1}+\max\{\ell,0\}`$

11: else

12:   $`y_{t}\leftarrow 0`$, $`C_{t}\leftarrow C_{t-1}`$

13: end if

Conditional on $`(R,D,A_{0})`$, each fixed-history comparison has
probability at most $`\delta_{t,p}`$ of either an erroneous promotion
decision or an invalid lower confidence bound. A union bound over all
rounds, all possible histories, and all candidate comparisons gives

|  |  |  |
|----|----|----|
|  |
``` math
\sum_{t\geq 1}\sum_{p=0}^{t-1}\binom{t-1}{p}K^{p}\cdot K\delta_{t,p}=\alpha\sum_{t\geq 1}w_{t}\sum_{p=0}^{t-1}v_{p}\leq\alpha.
``` |  |

This gives the following main result.

###### Theorem 1 (Simultaneous validity and cumulative progress).

Consider pass/fail evaluation, with $`s(A,W)\in\{0,1\}`$ and
$`\gamma=0`$. Suppose
[Assumptions 1](#Thmassumption1 "Assumption 1 (Independent evaluation set). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
and [2](#Thmassumption2 "Assumption 2 (Decision-only feedback). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
hold, and Reuse is run as in
[Algorithm 1](#alg1 "In 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
with the allocation
([4](#S2.E4 "Equation 4 ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")).
Then, for every adaptive proposer satisfying these assumptions, with
probability at least $`1-\alpha`$, $`\Delta(A_{t},A_{t-1})>0`$ for every
$`t`$ with $`y_{t}\neq 0`$. On the same event, the running certificate
satisfies $`V(A_{t})-V(A_{0})\geq C_{t}`$ for every $`t\geq 1`$.

The cumulative bound follows by summing the valid stepwise contributions
$`\max\{\ell,0\}`$ over promotions, since the corresponding population
improvement telescope to $`V(A_{t})-V(A_{0})`$.

Development data may also be used to select a single candidate before
$`S`$ is queried. If only that candidate is tested on $`S`$,
[Theorem 1](#Thmtheorem1 "Theorem 1 (Simultaneous validity and cumulative progress). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
applies with $`K=1`$ in
([4](#S2.E4 "Equation 4 ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")),
since there is no within-round candidate selection on the evaluation
set.

We now establish how large a true improvement must be for reliable
detection. We let $`\mathcal{L}_{t,p}=\ln({2}/{\delta_{t,p}})`$ and let
$`d=\mathbb{P}\!\left(Z_{i}(B,A)\neq 0\right)`$ denote the probability
that the candidate and incumbent have different outcomes on a random
task. The following result gives the corresponding minimum detectable
population improvement.

###### Proposition 1 (Minimum detectable improvement).

Consider pass/fail evaluation with $`\gamma=0`$ and $`\rho=1/2`$ at a
fixed decision history node. Suppose the candidate and incumbent pairs
are fixed independently of $`S`$ and each has disagreement probability
$`d\in(0,1]`$. Define

|     |                                                                  |     |
|-----|------------------------------------------------------------------|-----|
|     |
       ``` math
       \Delta_{\min}(n,t,p,K,d)=\sqrt{\frac{2d\,\mathcal{L}_{t,p}}{n}}.
       ```                                                               |     |

Under the regularity conditions in
[Section A.6](#A1.SS6 "A.6 Power and the minimum detectable improvement ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),
for any fixed $`\eta\in(0,1)`$, a candidate with
$`\Delta(B,A)\geq(1+\eta)\Delta_{\min}`$ passes the promotion test with
probability tending to one, whereas if all $`K`$ candidates satisfy
$`\Delta(B_{t,k},A_{t-1})\leq(1-\eta)\Delta_{\min}`$, the probability of
any promotion tends to zero.

The quantity $`\Delta_{\min}`$ represents the smallest population
improvement that we can reliably detect. The formula shows that a larger
evaluation set $`n`$ in the denominator decreases this detection
threshold. At the same time the term $`\mathcal{L}_{t,p}`$ in the
numerator depends on the per-round error level $`\delta_{t,p}`$. To
maintain our global guarantee we must allocate smaller error budgets
$`\delta_{t,p}`$ as the round count $`t`$ and promotion count $`p`$
increase. This decrease in $`\delta_{t,p}`$ causes $`\mathcal{L}_{t,p}`$
to grow which makes larger true improvements necessary for reliable
detection at later stages. This behavior directly reflects our
statistical intuition. By demanding stronger evidence as the search
proceeds we prevent random noise from accumulating into false promotions
over a long trajectory.

This dependence on the adaptive history is not solely an artifact of our
particular allocation. In
[Section A.7](#A1.SS7 "A.7 Lower bound for threshold-based promotion rules ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
we show that for a class of threshold rules a comparable first order
growth in the promotion threshold is necessary to prevent an adaptive
proposer from eventually inducing a false promotion.

## 3 Experiments

In this section, we evaluate Reuse against existing methods in live
self-improvement loops, where an LLM-based proposer generates
modifications and a finite evaluation set is repeatedly reused. Our
experiments address two key questions: First, how often do current RSI
promotion schemes accept false improvements? Second, can Reuse prevent
these false promotions without sacrificing true population improvement?

### 3.1 Experimental setup

We consider the agent tasked with machine learning classification.
Specifically, we use the Covertype dataset ([Blackard,
1998](#bib.bib35))¹¹ 1
[https://archive.ics.uci.edu/dataset/31/covertype](https://archive.ics.uci.edu/dataset/31/covertype)
for the binary classification of cover type 2 against the remaining six
classes. A fixed random split yields a training set $`D_{\mathrm{tr}}`$
of 50,000 examples for fitting candidates, a development set
$`D_{\mathrm{dev}}`$ of 20,000 examples for proposer feedback, and an
evaluation pool $`\mathcal{E}`$ of 60,000 examples, from which each run
draws an evaluation set $`S`$ of size $`n\in\{2{,}000,10{,}000\}`$ that
is reused throughout the search. Together, $`D_{\mathrm{tr}}`$ and
$`D_{\mathrm{dev}}`$ form $`D`$ of
[Section 2.1](#S2.SS1 "2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").
Since the underlying task distribution is unknown, we measure population
improvement on a disjoint held-out set $`H`$ of 50,000 examples. Each
run lasts $`T=200`$ rounds. At every round, Qwen2.5-7B-Instruct ([Yang
et al., 2024](#bib.bib29)) proposes up to $`K=8`$ modifications of a
scikit-learn pipeline ([Pedregosa et al., 2011](#bib.bib37)) based on
the prompt templates detailed in
[Section B.2](#A2.SS2 "B.2 Proposer and prompt templates ‣ Appendix B Experimental Details ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").
Each modification changes at most two components among the model family,
feature subset, pre-processing, and hyperparameters. All methods start
from the same gradient-boosting configuration, share the proposer,
candidate space, and training data, and see the same evaluation set
within a seed. We run 30 seeds at each evaluation-set size, and
[Appendix B](#A2 "Appendix B Experimental Details ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
gives the full protocol.

We compare Reuse with several evaluation frameworks that reflect how
current RSI systems use their benchmarks. Empirical best-of-$`K`$ edits
the incumbent and promotes the candidate with the largest positive gain
on $`S`$ ([Chen et al., 2026b](#bib.bib13)). SICA-style follows the
archive-based search of SICA ([Robeyns et al., 2025](#bib.bib10)),
DGM-style follows the parent selection of DGM ([Zhang et al.,
2026](#bib.bib9)), and Elite and Niche-elite use population-based search
inspired by AlphaEvolve ([Novikov et al., 2025](#bib.bib15)). We also
evaluate baselines that add statistical control to the same loop.
PACE-style applies a one-sided McNemar test ([Dietterich,
1998](#bib.bib38)) to each candidate at level $`\alpha=0.05`$, a
fixed-sample analogue of the per-decision error control in PACE ([Shawn,
2026](#bib.bib3)). Bonferroni-style applies the same test at level
$`0.05/(TK)`$, splitting the error budget evenly over all potential
comparisons of a run, as in the union-bound allocation of SGM ([Wu et
al., 2025](#bib.bib2)).

To measure true improvement, we estimate the population improvement of
each promoted modification by its paired improvement on the held-out set
$`H`$, which no method ever accesses, and call a promotion false when
this improvement is at most zero. For each method we report the final
population improvement of the deployed system over the starting system
$`A_{0}`$, the mean number of promotions per run, and the total number
of false promotions across runs. We also report the optimism gap of the
final system, defined as its improvement over $`A_{0}`$ measured on
$`S`$ minus its population improvement, which measures how much the
reused evaluation set overstates the final improvement.

## 4 Related Work

##### Recursive self-improvement and statistical control.

The idea of a system that improves itself with guarantees dates back to
the Gödel machine ([Schmidhuber, 2007](#bib.bib39)). Language models
have turned this into practical search loops that rewrite prompts, agent
scaffolds, algorithms, and entire pipelines ([Zelikman et al.,
2024](#bib.bib40); [Fernando et al., 2024](#bib.bib41); [Robeyns et al.,
2025](#bib.bib10); [Zhang et al., 2026](#bib.bib9); [Novikov et al.,
2025](#bib.bib15); [Chen et al., 2026b](#bib.bib13); [Chen et al.,
2026a](#bib.bib12)). However, evaluating these systems by repeatedly
querying fixed benchmarks often leads to false promotions and degraded
deployment performance ([Wang et al., 2026c](#bib.bib36); [Shawn,
2026](#bib.bib3); [Guo et al., 2026](#bib.bib44); [Wang et al.,
2026a](#bib.bib8)). To address this, recent works gate self-modification
with statistical tests, utilizing global error budgets ([Wu et al.,
2025](#bib.bib2); [Sengupta, 2026](#bib.bib4)), sequential testing
([Shawn, 2026](#bib.bib3)), or sealed audits ([Guo et al.,
2026](#bib.bib44); [Mittal and Gupta, 2026](#bib.bib7)). Yet, these
approaches typically treat candidates as independent of the test data or
restrict feedback without accounting for the information revealed by the
promotion decisions themselves. Reuse overcomes this by combining
decision-only feedback with an explicit error allocation over all
possible decision histories, thereby controlling adaptive dependence on
a reused evaluation set over the entire run.

##### Adaptive data analysis and holdout reuse.

The risk of reusing a holdout set adaptively is a central topic in
adaptive data analysis. Mechanisms based on differential privacy and
description length allow a holdout set to answer adaptively chosen
queries ([Dwork et al., 2015b](#bib.bib18); [Dwork et al.,
2015a](#bib.bib19)), and the Ladder mechanism maintains a leaderboard by
releasing scores only upon significant improvement ([Blum and Hardt,
2015](#bib.bib17)). Information-theoretic arguments bound the bias of
adaptive analysis ([Russo and Zou, 2016](#bib.bib20); [Xu and Raginsky,
2017](#bib.bib21); [Bassily et al., 2016](#bib.bib46)), though empirical
benchmark reuse often shows less overfitting than worst-case theory
predicts ([Recht et al., 2019](#bib.bib23); [Roelofs et al.,
2019](#bib.bib22); [Bertran et al., 2026](#bib.bib6)). Reuse explicitly
counts decision histories, turning the information bound into exact
finite-sample tests for each promotion.

##### Multiple testing and sequential inference.

Controlling the family-wise error over many hypotheses encompasses
classical ([Holm, 1979](#bib.bib47)), weighted ([Bretz et al.,
2009](#bib.bib48)), and sequential anytime-valid procedures ([Lan and
DeMets, 1983](#bib.bib49); [Javanmard and Montanari, 2018](#bib.bib32);
[Howard et al., 2021](#bib.bib27); [Ramdas et al., 2023](#bib.bib28);
[Waudby-Smith and Ramdas, 2024](#bib.bib26)). Similarly, selective
inference adjusts tests for data-driven selection biases ([Berk et al.,
2013](#bib.bib50); [Fithian et al., 2014](#bib.bib51); [Efron,
2011](#bib.bib34); [Jamieson and Jain, 2018](#bib.bib31)). However,
these frameworks generally assume that hypotheses are fixed in advance,
arrive with fresh data, or are selected by characterizable
distributions. In a self-improvement loop, hypotheses are instead
generated by an arbitrary proposer adapting to earlier outcomes on the
same data. Reuse bridges this gap by allocating an error budget over all
possible decision histories, ensuring each test is valid in finite
samples ([Clopper and Pearson, 1934](#bib.bib1); [Maurer and Pontil,
2009](#bib.bib24)).

## 5 Discussion

Self-improving systems increasingly decide what to keep by querying the
same evaluation set over long trajectories. We showed that this reuse
creates a source of error that multiple comparison corrections do not
address, because later candidates depend on earlier outcomes on the
evaluation set. Reuse controls this by returning only promotion
decisions and allocating an error budget over all decision histories,
which yields a simultaneous guarantee that every promoted modification
is a true population improvement. In live self-improvement experiments,
Reuse made much fewer false promotion than other frameworks without
sacrificing true population performance. Reuse achieves this reliability
while placing no restrictions on the underlying proposer or agent
architecture. While our experiments demonstrate the framework on a
machine learning classification task, extending it to larger agentic
settings like coding and model post-training is a natural next step. The
decision-only feedback currently provides strict statistical guarantees,
but future work could accommodate richer signals including rounded
scores, privatized summaries, or periodically refreshed evaluation sets
by explicitly accounting for their information transcripts. Furthermore,
expanding the framework to simultaneously control for secondary metrics
like safety and cost offers a promising path toward generating the
auditable and provable records of capability gains increasingly required
by frontier AI safety frameworks ([OpenAI, 2025](#bib.bib14)).

## Appendix A Proofs and Additional Theory

### A.1 A paired lower confidence bound for bounded scores

We first give a lower confidence bound for the mean of bounded paired
differences. This result is used for non-binary scores and as one
component of the certificate for pass/fail evaluation.

Let $`z_{1},\ldots,z_{n}\in[-1,1]`$. Write

|  |  |  |
|----|----|----|
|  |
``` math
\bar{z}=\frac{1}{n}\sum_{i=1}^{n}z_{i},\qquad\overline{z^{2}}=\frac{1}{n}\sum_{i=1}^{n}z_{i}^{2}.
``` |  |

Here $`\mathrm{kl}(a\,\|\,b)=a\ln(a/b)+(1-a)\ln((1-a)/(1-b))`$ is the
Bernoulli relative entropy, with the usual continuous extensions at the
endpoints. All logarithms are natural. For $`L>0`$, define

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\hat{s}^{+}(z;L)=\max\left\{q\in[\overline{z^{2}},1]:n\,\mathrm{kl}(\overline{z^{2}}\,\|\,q)\leq L\right\},
``` |  | (5) |

and

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\varepsilon(v,L)=\frac{2L}{3n}+\sqrt{\left(\frac{2L}{3n}\right)^{2}+\frac{2vL}{n}}.
``` |  | (6) |

We use the lower bound

|     |                                                            |     |     |
|-----|------------------------------------------------------------|-----|-----|
|     |
       ``` math
       \mathrm{lcb}(z;L)=\bar{z}-\varepsilon(\hat{s}^{+}(z;L),L).
       ```                                                         |     | (7) |

The quantity $`\hat{s}^{+}(z;L)`$ is an upper confidence bound for
$`\mathbb{E}Z^{2}`$, which in turn upper bounds $`\mathrm{Var}(Z)`$. The
second term in
([7](#A1.E7 "Equation 7 ‣ A.1 A paired lower confidence bound for bounded scores ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"))
is a Bernstein deviation evaluated at this data-dependent variance
proxy.

###### Lemma A1 (Paired lower confidence bound).

Let $`Z_{1},\ldots,Z_{n}`$ be i.i.d. random variables in $`[-1,1]`$ with
mean $`\mu`$. For $`\delta\in(0,1)`$ and $`L=\ln(2/\delta)`$,

|     |                                                                 |     |
|-----|-----------------------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}\!\left(\mu<\mathrm{lcb}(Z_{1:n};L)\right)\leq\delta.
       ```                                                              |     |

###### Proof.

Let

|     |                                                                   |     |
|-----|-------------------------------------------------------------------|-----|
|     |
       ``` math
       m=\mathbb{E}Z_{1}^{2},\qquad\sigma^{2}=\mathrm{Var}(Z_{1})\leq m.
       ```                                                                |     |

Since $`Z_{i}^{2}\in[0,1]`$ are i.i.d. with mean $`m`$, applying the
Chernoff–Hoeffding bound to $`1-Z_{i}^{2}`$ ([Hoeffding,
1963](#bib.bib25)) gives

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\!\left(\overline{Z^{2}}\leq a\right)\leq\exp\{-n\mathrm{kl}(a\,\|\,m)\},\qquad 0\leq a<m.
``` |  |

For $`a=0`$ and $`m<1`$, the same bound follows from
$`\mathbb{P}(Z_{i}^{2}=0)\leq 1-m`$ and independence. If $`m=1`$, then
$`Z_{i}^{2}=1`$ almost surely, so the probability is zero for every
$`a<1`$, consistent with the convention $`\exp(-\infty)=0`$. By the
definition of $`\hat{s}^{+}`$,

|     |                                                |     |
|-----|------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(\hat{s}^{+}<m)\leq e^{-L}=\delta/2.
       ```                                             |     |

Next, the centered variables satisfy $`Z_{i}-\mu\leq 2`$. Bernstein’s
inequality ([Hoeffding, 1963](#bib.bib25)), with range parameter
$`b=2`$, gives, for every $`\epsilon>0`$,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}(\bar{Z}-\mu\geq\epsilon)\leq\exp\!\left\{-\frac{n\epsilon^{2}}{2\sigma^{2}+\frac{4}{3}\epsilon}\right\}.
``` |  |

If $`\sigma^{2}=0`$, the left-hand side is zero and the inequality
remains valid. The positive solution of

|     |                                                             |     |
|-----|-------------------------------------------------------------|-----|
|     |
       ``` math
       n\epsilon^{2}=L\left(2\sigma^{2}+\frac{4}{3}\epsilon\right)
       ```                                                          |     |

is $`\varepsilon(\sigma^{2},L)`$. Hence

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\!\left(\bar{Z}-\mu\geq\varepsilon(\sigma^{2},L)\right)\leq e^{-L}=\delta/2.
``` |  |

The function $`\varepsilon(v,L)`$ is increasing in $`v`$. On the event
$`\{\hat{s}^{+}\geq m\}`$,

|  |  |  |
|----|----|----|
|  |
``` math
\varepsilon(\hat{s}^{+},L)\geq\varepsilon(m,L)\geq\varepsilon(\sigma^{2},L).
``` |  |

Therefore

|  |  |  |
|----|----|----|
|  |
``` math
\left\{\mu<\mathrm{lcb}(Z_{1:n};L)\right\}\subseteq\{\hat{s}^{+}<m\}\cup\left\{\bar{Z}-\mu>\varepsilon(\sigma^{2},L)\right\}.
``` |  |

The two probabilities sum to at most $`\delta`$. ∎

### A.2 Validity of the exact paired sign test

For pass/fail evaluation,

|     |                      |     |
|-----|----------------------|-----|
|     |
       ``` math
       Z_{i}\in\{-1,0,+1\}.
       ```                   |     |

Let

|  |  |  |
|----|----|----|
|  |
``` math
q_{+}=\mathbb{P}(Z_{i}=+1),\qquad q_{-}=\mathbb{P}(Z_{i}=-1),\qquad d=q_{+}+q_{-}.
``` |  |

The population gain is

|     |                                  |     |
|-----|----------------------------------|-----|
|     |
       ``` math
       \mu=\mathbb{E}Z_{i}=q_{+}-q_{-}.
       ```                               |     |

Recall that $`n_{+}`$ and $`n_{-}`$ denote the number of candidate wins
and losses and

|     |                |     |
|-----|----------------|-----|
|     |
       ``` math
       M=n_{+}+n_{-}.
       ```             |     |

The paired sign-test $`p`$-value is

|  |  |  |
|----|----|----|
|  |
``` math
\pi(n_{+},M)=\mathbb{P}\!\left(\mathrm{Bin}(M,\tfrac{1}{2})\geq n_{+}\right),\qquad\pi(0,0)=1.
``` |  |

###### Lemma A2 (Validity of the exact paired test).

Let $`Z_{1},\ldots,Z_{n}`$ be i.i.d. in $`\{-1,0,+1\}`$ with mean
$`\mu\leq 0`$. For any $`\delta^{\prime}\in(0,1)`$,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\!\left(\pi(n_{+},M)\leq\delta^{\prime}\right)\leq\delta^{\prime}.
``` |  |

The same inequality holds conditionally on every value of $`M`$.

###### Proof.

If $`d=0`$, then $`M=0`$ almost surely and $`\pi(0,0)=1`$. The test
never rejects.

Assume $`d>0`$ and define

|     |                                                         |     |
|-----|---------------------------------------------------------|-----|
|     |
       ``` math
       q=\frac{q_{+}}{d}=\mathbb{P}(Z_{i}=+1\mid Z_{i}\neq 0).
       ```                                                      |     |

By independence, $`(n_{+},n_{-},n-M)`$ has the multinomial distribution
with cell probabilities $`(q_{+},q_{-},1-d)`$. For
$`0\leq k\leq m\leq n`$, its probability mass factors as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbb{P}(M=m,n_{+}=k)`$ | $`\displaystyle=\binom{n}{m}\binom{m}{k}q_{+}^{k}q_{-}^{m-k}(1-d)^{n-m}`$ |  |
|  |  | $`\displaystyle=\mathbb{P}(M=m)\binom{m}{k}q^{k}(1-q)^{m-k}.`$ |  |

Thus, for every $`m`$ with $`\mathbb{P}(M=m)>0`$,
$`n_{+}\mid M=m\sim\mathrm{Bin}(m,q)`$. The null hypothesis
$`\mu\leq 0`$ is equivalent to $`q\leq 1/2`$.

Fix such an $`m`$. Under the null, $`\mathrm{Bin}(m,q)`$ is
stochastically dominated by $`\mathrm{Bin}(m,1/2)`$, so the rejection
probability of the upper-tail sign test is maximized over $`q\leq 1/2`$
at $`q=1/2`$. Indeed, if there is a rejection threshold, let $`k_{0}`$
be the smallest integer in $`\{0,\ldots,m\}`$ with
$`\pi(k_{0},m)\leq\delta^{\prime}`$. Monotonicity of $`\pi(k,m)`$ in
$`k`$ then gives

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbb{P}\!\left(\pi(n_{+},M)\leq\delta^{\prime}\mid M=m\right)`$ | $`\displaystyle=\mathbb{P}\!\left(n_{+}\geq k_{0}\mid M=m\right)`$ |  |
|  |  | $`\displaystyle\leq\mathbb{P}\!\left(\mathrm{Bin}(m,\tfrac{1}{2})\geq k_{0}\right)=\pi(k_{0},m)\leq\delta^{\prime}.`$ |  |

If there is no rejection threshold, the rejection probability is zero.
For $`m=0`$ it is also zero. Averaging over $`M`$ proves the
unconditional claim. ∎

### A.3 A lower confidence bound for pass/fail evaluation

For $`d>0`$, define

|     |                    |     |
|-----|--------------------|-----|
|     |
       ``` math
       q=\frac{q_{+}}{d}.
       ```                 |     |

Then

|     |                                                      |     |     |
|-----|------------------------------------------------------|-----|-----|
|     |
       ``` math
       \mu=q_{+}-q_{-}=(2q-1)d,\qquad\mathbb{E}Z_{i}^{2}=d.
       ```                                                   |     | (8) |

For $`k`$ successes in $`m`$ Bernoulli trials, let
$`\underline{\theta}(k;m,a)`$ denote the one-sided Clopper–Pearson lower
confidence limit at error level $`a\in(0,1)`$ ([Clopper and Pearson,
1934](#bib.bib1)). For $`1\leq k\leq m`$, it is the $`a`$-quantile of
$`\mathrm{Beta}(k,m-k+1)`$, and we set $`\underline{\theta}(0;m,a)=0`$.

Given an error level $`\delta_{c}\in(0,1)`$, define

|  |  |  |
|----|----|----|
|  |
``` math
q_{\mathrm{lo}}=\underline{\theta}(n_{+};M,\delta_{c}/4),\qquad d_{\mathrm{lo}}=\underline{\theta}(M;n,\delta_{c}/4),
``` |  |

and

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\ell^{\mathrm{sgn}}=\begin{cases}(2q_{\mathrm{lo}}-1)d_{\mathrm{lo}},&q_{\mathrm{lo}}>1/2,\\[5.69054pt]
-\infty,&q_{\mathrm{lo}}\leq 1/2.\end{cases}
``` |  | (9) |

We combine this exact bound with the bounded-score lower confidence
bound from
[Lemma A1](#A1.Thmlemma1 "Lemma A1 (Paired lower confidence bound). ‣ A.1 A paired lower confidence bound for bounded scores ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\ell^{\star}(Z_{1:n};\delta_{c})=\max\left\{\mathrm{lcb}\left(Z_{1:n};\ln\frac{4}{\delta_{c}}\right),\ell^{\mathrm{sgn}}\right\}.
``` |  | (10) |

###### Lemma A3 (Lower confidence bound for pass/fail evaluation).

For i.i.d. $`Z_{1},\ldots,Z_{n}\in\{-1,0,+1\}`$ with mean $`\mu`$,

|     |                                                              |     |
|-----|--------------------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(\mu<\ell^{\mathrm{sgn}})\leq\frac{\delta_{c}}{2},
       ```                                                           |     |

and

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\!\left(\mu<\ell^{\star}(Z_{1:n};\delta_{c})\right)\leq\delta_{c}.
``` |  |

###### Proof.

If $`d=0`$, then $`M=n_{+}=0`$ almost surely, so $`q_{\mathrm{lo}}=0`$
and $`\ell^{\mathrm{sgn}}=-\infty`$. The first claim is immediate, and
the second follows from
[Lemma A1](#A1.Thmlemma1 "Lemma A1 (Paired lower confidence bound). ‣ A.1 A paired lower confidence bound for bounded scores ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").
Assume henceforth that $`d>0`$.

By the conditional-count calculation in the proof of
[Lemma A2](#A1.Thmlemma2 "Lemma A2 (Validity of the exact paired test). ‣ A.2 Validity of the exact paired sign test ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),
the conditional law of $`n_{+}`$ given $`M=m`$ is $`\mathrm{Bin}(m,q)`$
whenever $`\mathbb{P}(M=m)>0`$. Applying the one-sided Clopper–Pearson
coverage property conditionally and then averaging over $`M`$ gives

|     |                                                |     |
|-----|------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(q<q_{\mathrm{lo}})\leq\delta_{c}/4.
       ```                                             |     |

Separately, the indicators $`\mathbf{1}\{Z_{i}\neq 0\}`$ are i.i.d.
Bernoulli variables with success probability $`d`$, so
$`M\sim\mathrm{Bin}(n,d)`$. Applying the same coverage property directly
to this count gives

|     |                                                |     |
|-----|------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(d<d_{\mathrm{lo}})\leq\delta_{c}/4.
       ```                                             |     |

Therefore, with probability at least $`1-\delta_{c}/2`$,

|     |                                                     |     |
|-----|-----------------------------------------------------|-----|
|     |
       ``` math
       q\geq q_{\mathrm{lo}},\qquad d\geq d_{\mathrm{lo}}.
       ```                                                  |     |

On this event, when $`q_{\mathrm{lo}}>1/2`$,

|  |  |  |
|----|----|----|
|  |
``` math
\mu=(2q-1)d\geq(2q_{\mathrm{lo}}-1)d_{\mathrm{lo}}=\ell^{\mathrm{sgn}}.
``` |  |

When $`q_{\mathrm{lo}}\leq 1/2`$, the bound equals $`-\infty`$ and the
inequality holds automatically. Hence

|     |                                                      |     |
|-----|------------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(\mu<\ell^{\mathrm{sgn}})\leq\delta_{c}/2.
       ```                                                   |     |

By
[Lemma A1](#A1.Thmlemma1 "Lemma A1 (Paired lower confidence bound). ‣ A.1 A paired lower confidence bound for bounded scores ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\left(\mu<\mathrm{lcb}\left(Z_{1:n};\ln\frac{4}{\delta_{c}}\right)\right)\leq\delta_{c}/2.
``` |  |

A union bound over the two lower confidence bounds gives

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\!\left(\mu<\ell^{\star}(Z_{1:n};\delta_{c})\right)\leq\delta_{c}.
``` |  |

∎

###### Remark A1 (Running cumulative bound).

The sign test may establish that $`\mu>0`$ even when the numerical lower
confidence bound $`\ell^{\star}`$ is non-positive. For the pass/fail
test with $`\gamma=0`$, Reuse therefore adds

|     |                        |     |
|-----|------------------------|-----|
|     |
       ``` math
       \max\{\ell^{\star},0\}
       ```                     |     |

to the running bound $`C_{t}`$. On the event of
[Theorem 1](#Thmtheorem1 "Theorem 1 (Simultaneous validity and cumulative progress). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),
both

|     |                         |     |
|-----|-------------------------|-----|
|     |
       ``` math
       \Delta(A_{t},A_{t-1})>0
       ```                      |     |

and

|     |                                       |     |
|-----|---------------------------------------|-----|
|     |
       ``` math
       \Delta(A_{t},A_{t-1})\geq\ell^{\star}
       ```                                    |     |

hold. Hence

|     |                                                  |     |
|-----|--------------------------------------------------|-----|
|     |
       ``` math
       \Delta(A_{t},A_{t-1})\geq\max\{\ell^{\star},0\}.
       ```                                               |     |

This keeps $`C_{t}`$ nondecreasing while preserving its lower-bound
interpretation. For the bounded-score extension, promotion requires
$`\ell>\gamma\geq 0`$, and the contribution is $`\ell`$ itself.

### A.4 Proof of the main guarantee

We prove
[Theorem 1](#Thmtheorem1 "Theorem 1 (Simultaneous validity and cumulative progress). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
for general allocation weights $`(w_{t})`$ and $`(v_{p})`$ satisfying

|     |                                                            |     |
|-----|------------------------------------------------------------|-----|
|     |
       ``` math
       \sum_{t\geq 1}w_{t}\leq 1,\qquad\sum_{p\geq 0}v_{p}\leq 1.
       ```                                                         |     |

For pass/fail evaluation with $`\gamma=0`$, let $`\rho\in(0,1)`$ denote
the fraction of $`\delta_{t,p}`$ used for the promotion test; the
remaining fraction is used for the lower confidence bound. The proof
applies to every such $`\rho`$. If $`\delta_{t,p}=0`$, all candidates
are rejected and the running bound is unchanged. Such comparisons can be
omitted from the argument below.

###### Proof of [Theorem 1](#Thmtheorem1 "Theorem 1 (Simultaneous validity and cumulative progress). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").

Condition on the search procedure’s randomness $`R`$, development data
$`D`$, and starting system $`A_{0}`$. By
[Assumption 1](#Thmassumption1 "Assumption 1 (Independent evaluation set). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),
$`S`$ remains i.i.d. from $`Q`$. All probabilities in this proof are
conditional on $`(R,D,A_{0})`$.

For round $`t`$, let

|     |             |     |
|-----|-------------|-----|
|     |
       ``` math
       y=y_{1:t-1}
       ```          |     |

denote a possible decision history. By
[Assumption 2](#Thmassumption2 "Assumption 2 (Decision-only feedback). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),
every such history determines an incumbent

|     |          |     |
|-----|----------|-----|
|     |
       ``` math
       a(y)
       ```       |     |

and candidates

|     |                          |     |
|-----|--------------------------|-----|
|     |
       ``` math
       b_{1}(y),\ldots,b_{K}(y)
       ```                       |     |

that do not otherwise depend on $`S`$. Here $`y`$ is a fixed
hypothetical history: we do not condition on the event that the
evaluation set produces that history.

Let $`\mathcal{Y}_{t-1,p}`$ be the set of decision histories of length
$`t-1`$ containing exactly $`p`$ promotions. Then

|     |                                            |     |      |
|-----|--------------------------------------------|-----|------|
|     |
       ``` math
       |\mathcal{Y}_{t-1,p}|=\binom{t-1}{p}K^{p}.
       ```                                         |     | (11) |

The factor $`\binom{t-1}{p}`$ selects the promotion rounds and the
factor $`K^{p}`$ selects the promoted candidate at each such round.

Fix $`t`$, $`p`$, $`y\in\mathcal{Y}_{t-1,p}`$, and candidate $`k`$.
Write

|     |                                  |     |
|-----|----------------------------------|-----|
|     |
       ``` math
       \mu_{y,k}=\Delta(b_{k}(y),a(y)).
       ```                               |     |

In what follows, $`Z_{1:n}`$, $`n_{+}`$, and $`M`$ refer to this fixed
pair $`(b_{k}(y),a(y))`$. For pass/fail evaluation with $`\gamma=0`$,
define the decision failure event

|  |  |  |
|----|----|----|
|  |
``` math
E^{\mathrm{dec}}_{t,y,k}=\{\mu_{y,k}\leq 0\}\cap\left\{\pi(n_{+},M)\leq\rho\delta_{t,p}\right\},
``` |  |

and the confidence-bound failure event

|  |  |  |
|----|----|----|
|  |
``` math

``` |  |

By
[Lemma A2](#A1.Thmlemma2 "Lemma A2 (Validity of the exact paired test). ‣ A.2 Validity of the exact paired sign test ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),

|     |                                                           |     |
|-----|-----------------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(E^{\mathrm{dec}}_{t,y,k})\leq\rho\delta_{t,p},
       ```                                                        |     |

and by
[Lemma A3](#A1.Thmlemma3 "Lemma A3 (Lower confidence bound for pass/fail evaluation). ‣ A.3 A lower confidence bound for pass/fail evaluation ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),

|     |                                                                |     |
|-----|----------------------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(E^{\mathrm{cert}}_{t,y,k})\leq(1-\rho)\delta_{t,p}.
       ```                                                             |     |

$`E_{t,y,k}=E^{\mathrm{dec}}_{t,y,k}\cup E^{\mathrm{cert}}_{t,y,k}`$.
Then

|     |                                        |     |
|-----|----------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(E_{t,y,k})\leq\delta_{t,p}.
       ```                                     |     |

For the bounded-score extension, define instead

|  |  |  |
|----|----|----|
|  |
``` math

``` |  |

By
[Lemma A1](#A1.Thmlemma1 "Lemma A1 (Paired lower confidence bound). ‣ A.1 A paired lower confidence bound for bounded scores ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),

|     |                                        |     |
|-----|----------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(E_{t,y,k})\leq\delta_{t,p}.
       ```                                     |     |

Now sum over every round, promotion count, decision history, and
candidate. Using
([4](#S2.E4 "Equation 4 ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"))
and

|  |  | $`\displaystyle=\alpha\sum_{t\geq 1}w_{t}\sum_{p=0}^{t-1}v_{p}`$ |  | (13) |
|  |  | $`\displaystyle\leq\alpha.`$ |  | (14) |

Therefore, with probability at least $`1-\alpha`$, every candidate
comparison that can arise under every possible decision history is valid
simultaneously.

Consider the realized sequence. If $`y_{t}=k\neq 0`$, the promoted
candidate passed the promotion test. On the event above, with
$`\gamma=0`$ for the sign-test route and any $`\gamma\geq 0`$ for the
bounded-score route,

|     |                               |     |
|-----|-------------------------------|-----|
|     |
       ``` math

which proves the first claim.

       ``` math
       \Delta(A_{t},A_{t-1})\geq\max\{\ell_{t},\gamma\}
       ```                                               |     |

at every promoted round, where $`\ell_{t}`$ denotes the lower bound used
for the promoted comparison. Summing over promoted rounds gives

|  |  |  |  |  |

|  |  | $`\displaystyle\geq\sum_{s\leq t:y_{s}\neq 0}\max\{\ell_{s},\gamma\}`$ |  | (16) |
|  |  | $`\displaystyle=C_{t}.`$ |  | (17) |

This proves the cumulative lower bound for each fixed
$`\xi=(R,D,A_{0})`$. By the joint measurability in
[Assumption 2](#Thmassumption2 "Assumption 2 (Decision-only feedback). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),
the failure events used above, for each fixed hypothetical history, are

integrating the section-wise probability bound with respect to the law
of $`\xi`$ gives the unconditional statement.

promoted modification. We can also compare the current system $`A_{t}`$

lower bound on total progress from the same stored evaluations.

Let $`\alpha_{c}\in(0,1)`$ be a separate error level. For a decision
history of length $`t`$ containing $`p`$ promotions, define

|  |  |  |  |

|  |

``` |  | (18) |

When $`p_{t}\geq 1`$, define

|  |  |  |  |
|----|----|----|----|
|  |
``` math

``` |  | (19) |

for pass/fail outcomes. For general bounded scores, use
$`D_{t}=\mathrm{lcb}(Z_{1:n}(A_{t},A_{0});\mathcal{L}^{c}_{t,p_{t}})`$
from
[Lemma A1](#A1.Thmlemma1 "Lemma A1 (Paired lower confidence bound). ‣ A.1 A paired lower confidence bound for bounded scores ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
instead. If $`p_{t}\geq 1`$ and $`\delta^{c}_{t,p_{t}}=0`$, set
$`D_{t}=-\infty`$. When $`p_{t}=0`$, set

|     |
       ``` math

       ```       |     |

since $`A_{t}=A_{0}`$ exactly.

###### Proposition A1 (Direct lower bound on total progress).

Under
[Assumptions 1](#Thmassumption1 "Assumption 1 (Independent evaluation set). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
and [2](#Thmassumption2 "Assumption 2 (Decision-only feedback). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),
with probability at least $`1-\alpha_{c}`$,

|     |                                                          |     |
|-----|----------------------------------------------------------|-----|
|     |
       ``` math
       V(A_{t})-V(A_{0})\geq D_{t}\qquad\text{for all }t\geq 1.
       ```                                                       |     |

Under development-set screening, the same result holds with the factor
$`K^{p}`$ removed from
([18](#A1.E18 "Equation 18 ‣ A.5 A direct lower bound against the starting system ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")).
In the pass/fail setting with $`\gamma=0`$, under the conditions of
[Theorem 1](#Thmtheorem1 "Theorem 1 (Simultaneous validity and cumulative progress). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),
we additionally have

|     |                                          |     |
|-----|------------------------------------------|-----|
|     |
       ``` math
       V(A_{t})-V(A_{0})\geq\max\{C_{t},D_{t}\}
       ```                                       |     |

for all $`t`$ with probability at least $`1-\alpha-\alpha_{c}`$.

###### Proof.

Condition on $`(R,D,A_{0})`$ as in the proof of
[Theorem 1](#Thmtheorem1 "Theorem 1 (Simultaneous validity and cumulative progress). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").
Probabilities below are conditional on this tuple.

A complete decision history

|     |           |     |
|-----|-----------|-----|
|     |
       ``` math
       y=y_{1:t}
       ```        |     |

determines the current system $`a_{t}(y)`$. If the history contains
exactly $`p`$ promotions, then there are

|     |                   |     |
|-----|-------------------|-----|
|     |
       ``` math
       \binom{t}{p}K^{p}
       ```                |     |

such histories.

For each history with $`p\geq 1`$, define

|  |  |  |
|----|----|----|
|  |
``` math
F_{t,y}=\left\{\Delta(a_{t}(y),A_{0})<\ell^{\star}\left(Z_{1:n}(a_{t}(y),A_{0});\delta^{c}_{t,p}\right)\right\}.
``` |  |

For each fixed hypothetical history $`y`$, the pair $`(a_{t}(y),A_{0})`$
is fixed given $`(R,D,A_{0})`$ and does not otherwise depend on $`S`$.
We do not condition on observing $`y`$. Thus

|     |                                          |     |
|-----|------------------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(F_{t,y})\leq\delta^{c}_{t,p}.
       ```                                       |     |

For bounded scores, replace $`\ell^{\star}`$ by the bound from
[Lemma A1](#A1.Thmlemma1 "Lemma A1 (Paired lower confidence bound). ‣ A.1 A paired lower confidence bound for bounded scores ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks");
the same error bound holds. When $`p=0`$, no promotion has occurred and
$`a_{t}(y)=A_{0}`$, so the desired inequality holds deterministically;
set $`F_{t,y}=\varnothing`$ for these histories. The failure event is
also empty when the error allotment is zero.

A union bound gives

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathbb{P}\left(\bigcup_{t,p,y}F_{t,y}\right)`$ | $`\displaystyle\leq\sum_{t\geq 1}\sum_{p=0}^{t}\binom{t}{p}K^{p}\delta^{c}_{t,p}`$ |  | (20) |
|  |  | $`\displaystyle=\alpha_{c}\sum_{t\geq 1}w_{t}\sum_{p=0}^{t}v_{p}`$ |  | (21) |
|  |  | $`\displaystyle\leq\alpha_{c}.`$ |  | (22) |

The result follows for the realized decision history. Integrating over
$`(R,D,A_{0})`$ gives the unconditional statement.

Under development screening, a history is determined only by its
promotion rounds, giving $`\binom{t}{p}`$ possible histories and
removing $`K^{p}`$. The joint statement follows from a union bound over
the events of
[Theorem 1](#Thmtheorem1 "Theorem 1 (Simultaneous validity and cumulative progress). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
and this proposition. ∎

###### Corollary A1 (Carry-forward between promotions).

Suppose $`p_{t}\geq 1`$ and let

|     |                                  |     |
|-----|----------------------------------|-----|
|     |
       ``` math
       s(t)=\max\{s\leq t:y_{s}\neq 0\}
       ```                               |     |

be the most recent promotion round. On the event of
[Proposition A1](#A1.Thmproposition1 "Proposition A1 (Direct lower bound on total progress). ‣ A.5 A direct lower bound against the starting system ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),

|     |                                 |     |
|-----|---------------------------------|-----|
|     |
       ``` math
       V(A_{t})-V(A_{0})\geq D_{s(t)}.
       ```                              |     |

Hence the direct lower bound only needs to be recomputed when a
promotion occurs.

###### Proof.

No promotion occurs between rounds $`s(t)`$ and $`t`$, so

|     |                 |     |
|-----|-----------------|-----|
|     |
       ``` math
       A_{t}=A_{s(t)}.
       ```              |     |

Apply
[Proposition A1](#A1.Thmproposition1 "Proposition A1 (Direct lower bound on total progress). ‣ A.5 A direct lower bound against the starting system ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
at round $`s(t)`$. ∎

##### Comparison with the running bound.

The two bounds summarize cumulative progress differently. The running
quantity $`C_{t}`$ adds one confidence bound for each promoted step. The
direct quantity $`D_{t}`$ bounds the single comparison between $`A_{t}`$
and $`A_{0}`$. When several promotions accumulate, $`D_{t}`$ can be
substantially tighter because it pays one confidence margin rather than
one margin for every promotion.

Neither bound dominates in every configuration, so both can be reported
under their respective error levels.

### A.6 Power and the minimum detectable improvement

We next characterize the amount of population gain required to pass the
promotion test for fixed comparisons. The pairs below are fixed
independently of $`S`$. Equivalently, one may fix $`(R,D,A_{0})`$ and a
hypothetical decision history as in the proof of
[Theorem 1](#Thmtheorem1 "Theorem 1 (Simultaneous validity and cumulative progress). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").
These power statements are not conditional on reaching that history in
an adaptive run.

###### Proposition A2 (Power of the promotion tests).

Consider a fixed candidate–incumbent pair tested at round $`t`$ after
$`p`$ promotions, with i.i.d. paired differences $`Z_{1},\ldots,Z_{n}`$,
population gain $`\Delta`$, paired second moment

|     |                    |     |
|-----|--------------------|-----|
|     |
       ``` math
       m=\mathbb{E}Z^{2},
       ```                 |     |

and variance $`\sigma^{2}`$. Let

|     |                                          |     |
|-----|------------------------------------------|-----|
|     |
       ``` math
       L=\mathcal{L}_{t,p},\qquad\beta\in(0,1).
       ```                                       |     |

1.  (a)
    For the Bernstein–KL test, define

    |     |                               |     |
    |-----|-------------------------------|-----|
    |     |
           ``` math
           L_{\beta}=\ln\frac{2}{\beta},
           ```                            |     |

    |     |                                                                 |     |
    |-----|-----------------------------------------------------------------|-----|
    |     |
           ``` math
           m_{\beta}=m+\sqrt{\frac{2mL_{\beta}}{n}}+\frac{2L_{\beta}}{3n},
           ```                                                              |     |

    and

    |     |                                                        |     |
    |-----|--------------------------------------------------------|-----|
    |     |
           ``` math
           u=m_{\beta}+\sqrt{\frac{2m_{\beta}L}{n}}+\frac{2L}{n}.
           ```                                                     |     |

    If

    |     |                                                                   |     |
    |-----|-------------------------------------------------------------------|-----|
    |     |
           ``` math
           \Delta>\gamma+\varepsilon(u,L)+\varepsilon(\sigma^{2},L_{\beta}),
           ```                                                                |     |

    then this candidate passes the bounded-score promotion test with
    probability at least $`1-\beta`$.

    For pass/fail tasks with fixed $`d=\mathbb{P}(Z_{i}\neq 0)>0`$, the
    right-hand side of the sufficient condition above is

    |     |                                     |     |
    |-----|-------------------------------------|-----|
    |     |
           ``` math
           \gamma+\sqrt{\frac{2dL}{n}}(1+o(1))
           ```                                  |     |

    when $`n\to\infty`$, $`L\to\infty`$, $`L=o(n)`$, and
    $`L_{\beta}=o(L)`$.
2.  (b)
    For the exact paired sign test with $`\gamma=0`$ and $`\rho=1/2`$,
    define

    |  |  |  |
    |----|----|----|
    |  |
    ``` math
    c(M,L)=\min\left\{a\in\{0,1,\ldots,M\}:\mathbb{P}\!\left(\mathrm{Bin}(M,\tfrac{1}{2})\geq a\right)\leq e^{-L}\right\},
    ``` |  |

    with $`c(M,L)=\infty`$ when the set is empty.

    A candidate passes if and only if

    |     |                   |     |
    |-----|-------------------|-----|
    |     |
           ``` math
           n_{+}\geq c(M,L).
           ```                |     |

    For $`M\geq 1`$ and $`n_{+}\geq M/2`$,

    |  |  |  |  |
    |----|----|----|----|
    |  |
    ``` math
    M\mathrm{kl}\left(\frac{n_{+}}{M}\,\middle\|\,\frac{1}{2}\right)\geq L\quad\Longrightarrow\quad\text{pass}\quad\Longrightarrow\quad M\mathrm{kl}\left(\frac{n_{+}}{M}\,\middle\|\,\frac{1}{2}\right)\geq L-\frac{1}{2}\ln(2M).
    ``` |  | (23) |

    In particular, for $`M\geq 1`$,

    |     |                           |     |
    |-----|---------------------------|-----|
    |     |
           ``` math
           n_{+}-n_{-}\geq\sqrt{2LM}
           ```                        |     |

    is sufficient for promotion.

###### Proof.

For part (a), apply Bernstein’s inequality ([Hoeffding,
1963](#bib.bib25)) to $`Y_{i}=Z_{i}^{2}\in[0,1]`$. Here
$`Y_{i}-m\leq 1`$, so the range parameter is $`b=1`$, and

|  |  |  |
|----|----|----|
|  |
``` math
\mathrm{Var}(Y_{i})\leq\mathbb{E}Z_{i}^{4}\leq\mathbb{E}Z_{i}^{2}=m.
``` |  |

Inverting the resulting tail bound, and using
$`\sqrt{u+v}\leq\sqrt{u}+\sqrt{v}`$ for $`u,v\geq 0`$, gives

|  |  |  |
|----|----|----|
|  |
``` math
\overline{Z^{2}}\leq m+\sqrt{\frac{2mL_{\beta}}{n}}+\frac{2L_{\beta}}{3n}=m_{\beta}
``` |  |

with probability at least $`1-\beta/2`$. Applying the same Bernstein
inequality to $`-Z_{i}`$, now with $`b=2`$ and variance $`\sigma^{2}`$,
gives

|     |                                                     |     |
|-----|-----------------------------------------------------|-----|
|     |
       ``` math
       \bar{Z}\geq\Delta-\varepsilon(\sigma^{2},L_{\beta})
       ```                                                  |     |

with probability at least $`1-\beta/2`$.

The inequality

|     |                                                               |     |
|-----|---------------------------------------------------------------|-----|
|     |
       ``` math
       \mathrm{kl}(a\,\|\,q)\geq\frac{(q-a)^{2}}{2q},\qquad q\geq a,
       ```                                                            |     |

together with the definition of $`\hat{s}^{+}`$ implies

|  |  |  |
|----|----|----|
|  |
``` math
\hat{s}^{+}\leq\overline{Z^{2}}+\sqrt{\frac{2\overline{Z^{2}}L}{n}}+\frac{2L}{n}\leq u.
``` |  |

On the intersection of the two high-probability events,

|  |  |  |
|----|----|----|
|  |
``` math
\ell\geq\Delta-\varepsilon(\sigma^{2},L_{\beta})-\varepsilon(u,L)>\gamma.
``` |  |

Hence the candidate passes. The asymptotic expression follows from

|     |                                                |     |
|-----|------------------------------------------------|-----|
|     |
       ``` math
       \varepsilon(u,L)=\sqrt{\frac{2mL}{n}}(1+o(1)).
       ```                                             |     |

For part (b), the test level is

|     |                                                 |     |
|-----|-------------------------------------------------|-----|
|     |
       ``` math
       \rho\delta_{t,p}=\frac{\delta_{t,p}}{2}=e^{-L}.
       ```                                              |     |

Monotonicity of the binomial upper tail gives the characterization
through $`c(M,L)`$. When $`M=0`$, $`c(M,L)=\infty`$ and the test cannot
pass; the following calculations assume $`M\geq 1`$.

For $`n_{+}\geq M/2`$, the Chernoff–Hoeffding bound ([Hoeffding,
1963](#bib.bib25)) gives

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\!\left(\mathrm{Bin}(M,\tfrac{1}{2})\geq n_{+}\right)\leq\exp\!\left\{-M\mathrm{kl}\!\left(\frac{n_{+}}{M}\,\middle\|\,\frac{1}{2}\right)\right\}.
``` |  |

The boundary $`n_{+}=M/2`$ follows from the trivial probability bound by
one, and $`n_{+}=M`$ gives equality. This proves the first implication
in
([23](#A1.E23 "Equation 23 ‣ Item (b) ‣ Proposition A2 (Power of the promotion tests). ‣ A.6 Power and the minimum detectable improvement ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")).

The binomial point-mass bound
([29](#A1.E29 "Equation 29 ‣ Binomial coefficient and point-mass bounds. ‣ A.7.2 Auxiliary lemmas ‣ A.7 Lower bound for threshold-based promotion rules ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"))
gives, for every integer $`0\leq a\leq M`$,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\!\left(\mathrm{Bin}(M,\tfrac{1}{2})=a\right)\geq\frac{\exp\{-M\mathrm{kl}(a/M\,\|\,1/2)\}}{\sqrt{2M}}.
``` |  |

If the candidate passes, then

|  |  |  |
|----|----|----|
|  |
``` math
\frac{\exp\{-M\mathrm{kl}(n_{+}/M\,\|\,1/2)\}}{\sqrt{2M}}\leq\mathbb{P}\!\left(\mathrm{Bin}(M,\tfrac{1}{2})=n_{+}\right)\leq\pi(n_{+},M)\leq e^{-L}.
``` |  |

Taking logarithms yields
$`M\mathrm{kl}(n_{+}/M\,\|\,1/2)\geq L-\frac{1}{2}\ln(2M)`$, which is
the second implication in
([23](#A1.E23 "Equation 23 ‣ Item (b) ‣ Proposition A2 (Power of the promotion tests). ‣ A.6 Power and the minimum detectable improvement ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")).

Finally, write

|     |                                           |     |
|-----|-------------------------------------------|-----|
|     |
       ``` math
       n_{+}=\frac{M+x}{2},\qquad x=n_{+}-n_{-}.
       ```                                        |     |

For $`u=x/(2M)`$ with $`|u|<1/2`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
2u^{2}\leq\mathrm{kl}\left(\frac{1}{2}+u\,\middle\|\,\frac{1}{2}\right)\leq\frac{2u^{2}}{1-4u^{2}}.
``` |  | (24) |

The lower inequality extends to $`u=\pm 1/2`$ by continuity and gives

|  |  |  |
|----|----|----|
|  |
``` math
M\mathrm{kl}\left(\frac{n_{+}}{M}\,\middle\|\,\frac{1}{2}\right)\geq\frac{x^{2}}{2M}.
``` |  |

Thus $`x\geq\sqrt{2LM}`$ is sufficient for promotion. ∎

##### Asymptotic conditions for [Proposition 1](#Thmproposition1 "Proposition 1 (Minimum detectable improvement). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").

Let $`n\to\infty`$, keep $`K`$ and $`d\in(0,1]`$ fixed, and set
$`L=\mathcal{L}_{t,p}`$ with $`\ln n=o(L)`$ and $`L=o(n)`$. The round
and promotion count may vary with $`n`$. All candidate–incumbent pairs
are fixed independently of $`S`$; in the $`K`$-candidate statement, each
pair has the same probability $`d`$ of different outcomes. Candidates
need not be independent of one another.

###### Proof of [Proposition 1](#Thmproposition1 "Proposition 1 (Minimum detectable improvement). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").

Let

|  |  |  |
|----|----|----|
|  |
``` math
x=\sum_{i=1}^{n}Z_{i}=n_{+}-n_{-},\qquad M=\sum_{i=1}^{n}Z_{i}^{2}.
``` |  |

For pass/fail outcomes,

|     |                                                   |     |
|-----|---------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{E}x=n\Delta,\qquad\mathrm{Var}(x)\leq nd,
       ```                                                |     |

and

|     |                                              |     |
|-----|----------------------------------------------|-----|
|     |
       ``` math
       \mathbb{E}M=nd,\qquad\mathrm{Var}(M)\leq nd.
       ```                                           |     |

Hence

|     |                             |     |
|-----|-----------------------------|-----|
|     |
       ``` math
       x=n\Delta+O_{P}(\sqrt{nd}),
       ```                          |     |

and

|     |                                        |     |
|-----|----------------------------------------|-----|
|     |
       ``` math
       M=nd\left(1+O_{P}((nd)^{-1/2})\right).
       ```                                     |     |

Let

|     |                   |     |
|-----|-------------------|-----|
|     |
       ``` math
       \tau=\sqrt{2Lnd}.
       ```                |     |

Then

|     |                                                    |     |
|-----|----------------------------------------------------|-----|
|     |
       ``` math
       \Delta_{\min}=\sqrt{\frac{2dL}{n}}=\frac{\tau}{n}.
       ```                                                 |     |

Since $`L\to\infty`$,

|     |                                            |     |
|-----|--------------------------------------------|-----|
|     |
       ``` math
       \frac{\tau}{\sqrt{nd}}=\sqrt{2L}\to\infty.
       ```                                         |     |

Therefore the stochastic fluctuations in $`x`$ and $`M`$ are
$`o_{P}(\tau)`$.

If

|     |                                  |     |
|-----|----------------------------------|-----|
|     |
       ``` math
       \Delta\geq(1+\eta)\Delta_{\min},
       ```                               |     |

then

|     |                                |     |
|-----|--------------------------------|-----|
|     |
       ``` math
       x\geq(1+\eta)\tau-o_{P}(\tau),
       ```                             |     |

while

|     |                              |     |
|-----|------------------------------|-----|
|     |
       ``` math
       \sqrt{2LM}=\tau(1+o_{P}(1)).
       ```                           |     |

Thus the sufficient condition in
[Proposition A2](#A1.Thmproposition2 "Proposition A2 (Power of the promotion tests). ‣ A.6 Power and the minimum detectable improvement ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")(b)
holds with probability tending to one.

If

|     |                                  |     |
|-----|----------------------------------|-----|
|     |
       ``` math
       \Delta\leq(1-\eta)\Delta_{\min},
       ```                               |     |

then

|     |                                |     |
|-----|--------------------------------|-----|
|     |
       ``` math
       x\leq(1-\eta)\tau+o_{P}(\tau).
       ```                             |     |

On $`\{x\leq 0\}`$ the test cannot pass. On $`\{x>0\}`$, the preceding
upper bound on $`x`$, together with $`M/(nd)\to_{P}1`$ and $`L=o(n)`$,
gives $`x/M=o_{P}(1)`$ on this event. Using
([24](#A1.E24 "Equation 24 ‣ Proof. ‣ A.6 Power and the minimum detectable improvement ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")),

|  |  |  |
|----|----|----|
|  |
``` math
M\mathrm{kl}\left(\frac{n_{+}}{M}\,\middle\|\,\frac{1}{2}\right)=\frac{x^{2}}{2M}(1+o_{P}(1)).
``` |  |

A pass would require

|  |  |  |
|----|----|----|
|  |
``` math
x^{2}\geq 2M\left(L-\frac{1}{2}\ln(2M)\right)(1+o_{P}(1))=\tau^{2}(1+o_{P}(1)),
``` |  |

where

|     |                        |     |
|-----|------------------------|-----|
|     |
       ``` math
       \frac{\ln(2M)}{L}\to 0
       ```                     |     |

by $`\ln n=o(L)`$. This contradicts

|     |                                                   |     |
|-----|---------------------------------------------------|-----|
|     |
       ``` math
       x^{2}\leq\left(1-\eta+o_{P}(1)\right)^{2}\tau^{2}
       ```                                                |     |

with probability tending to one.

For fixed $`K`$, a union bound over the fixed candidate–incumbent pairs
completes the second claim. ∎

### A.7 Lower bound for threshold-based promotion rules

We now show that the dependence on promotion history identified in the
main text also appears as a lower bound for a natural class of promotion
rules. The construction uses a bounded-score model satisfying
[Assumptions 1](#Thmassumption1 "Assumption 1 (Independent evaluation set). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
and [2](#Thmassumption2 "Assumption 2 (Decision-only feedback). ‣ 2.1 Setting and objective ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
exactly.

#### A.7.1 Model and threshold gates

##### Model $`\mathsf{M}`$.

A task is an infinite sign sequence

|     |                                                  |     |
|-----|--------------------------------------------------|-----|
|     |
       ``` math
       W=(g_{1},g_{2},\ldots)\in\{-1,+1\}^{\mathbb{N}},
       ```                                               |     |

whose coordinates are independent Rademacher variables.

A system is a pair

|     |                      |     |
|-----|----------------------|-----|
|     |
       ``` math
       A=(\vartheta,\beta),
       ```                   |     |

where

|  |  |  |
|----|----|----|
|  |
``` math
\vartheta\in[-1/4,1/4],\qquad\beta\in\mathbb{R}^{\mathbb{N}},\qquad\|\beta\|_{1}\leq 1/4,
``` |  |

and $`\beta`$ has finite support. Define

|     |                                                      |     |      |
|-----|------------------------------------------------------|-----|------|
|     |
       ``` math
       s(A,W)=\frac{1}{2}+\vartheta+\sum_{j}\beta_{j}g_{j}.
       ```                                                   |     | (25) |

The score lies in $`[0,1]`$ and

|     |                             |     |
|-----|-----------------------------|-----|
|     |
       ``` math
       V(A)=\frac{1}{2}+\vartheta.
       ```                          |     |

Hence

|     |                                          |     |
|-----|------------------------------------------|-----|
|     |
       ``` math
       \Delta(B,A)=\vartheta_{B}-\vartheta_{A}.
       ```                                       |     |

Changing only $`\beta`$ leaves population value unchanged. All
constructions below start from $`A_{0}=(0,0)`$. We write $`e_{j}`$ for
the $`j`$-th coordinate vector.

Let

|     |                        |     |
|-----|------------------------|-----|
|     |
       ``` math
       S=(W_{1},\ldots,W_{n})
       ```                     |     |

be the evaluation set. Write $`g_{ij}`$ for coordinate $`j`$ of task
$`i`$, and define

|     |                                     |     |
|-----|-------------------------------------|-----|
|     |
       ``` math
       X_{j}=n^{-1/2}\sum_{i=1}^{n}g_{ij}.
       ```                                  |     |

The variables $`X_{j}`$ are independent standardized Rademacher sums.

For any systems $`A`$ and $`B`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
Z_{i}(B,A)=(\vartheta_{B}-\vartheta_{A})+\sum_{j}(\beta_{B}-\beta_{A})_{j}g_{ij}.
``` |  | (26) |

Coordinates shared by $`A`$ and $`B`$ cancel. There is no additional
evaluation randomness, so repeated evaluation is deterministic.

###### Definition A1 (Threshold gate).

Fix $`b\in[0,1]`$. For $`z\in\mathbb{R}^{n}`$, define

|  |  |  |
|----|----|----|
|  |
``` math
\bar{z}=\frac{1}{n}\sum_{i}z_{i},\qquad\overline{z^{2}}=\frac{1}{n}\sum_{i}z_{i}^{2},
``` |  |

and

|  |  |  |  |
|----|----|----|----|
|  |
``` math
T_{b}(z)=\frac{\sqrt{n}\,\bar{z}}{\sqrt{\overline{z^{2}}-b\bar{z}^{2}}}.
``` |  | (27) |

We set $`T_{b}(0)=0`$. When the denominator vanishes and
$`\bar{z}\neq 0`$, set $`T_{b}(z)=+\infty`$ for $`\bar{z}>0`$ and
$`T_{b}(z)=-\infty`$ for $`\bar{z}<0`$.

A threshold gate is specified by $`b`$ and deterministic thresholds

|     |                      |     |
|-----|----------------------|-----|
|     |
       ``` math

#### A.7.2 Auxiliary lemmas

##### Binomial coefficient and point-mass bounds.

For integers $`n\geq 2`$ and $`1\leq m\leq n-1`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\binom{n}{m}\geq\frac{\exp\{n\ln 2-n\mathrm{kl}(m/n\,\|\,1/2)\}}{\sqrt{8m(n-m)/n}}.
``` |  | (28) |

Consequently, for integers $`M\geq 1`$ and $`0\leq a\leq M`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{P}\!\left(\mathrm{Bin}(M,\tfrac{1}{2})=a\right)\geq\frac{\exp\{-M\mathrm{kl}(a/M\,\|\,1/2)\}}{\sqrt{2M}}.
``` |  | (29) |

###### Proof.

For integers $`j\geq 1`$, define

|  |  |  |
|----|----|----|
|  |
``` math
A_{j}=\frac{j!e^{j}}{j^{j+1/2}},\qquad r_{j}=\frac{A_{j+1}}{A_{j}}=e\left(\frac{j}{j+1}\right)^{j+1/2}.
``` |  |

The function $`g(x)=(x+1/2)\ln(1+1/x)`$ satisfies, for $`x>0`$,

|  |  |  |
|----|----|----|
|  |
``` math
g^{\prime}(x)=\ln(1+1/x)-\frac{1}{2}\left(\frac{1}{x}+\frac{1}{x+1}\right)<0.
``` |  |

Indeed, strict convexity of $`t\mapsto 1/t`$ gives
$`\int_{x}^{x+1}t^{-1}\,dt<\frac{1}{2}(x^{-1}+(x+1)^{-1})`$. Thus
$`\ln r_{j}=1-g(j)`$ is increasing in $`j`$. For positive integers
$`m,l`$, set $`F(m,l)=A_{m+l}/(A_{m}A_{l})`$. Then

|     |                                                      |     |
|-----|------------------------------------------------------|-----|
|     |
       ``` math
       \frac{F(m+1,l)}{F(m,l)}=\frac{r_{m+l}}{r_{m}}\geq 1,
       ```                                                   |     |

and the analogous inequality holds in the second coordinate. Hence

|     |                                                               |     |
|-----|---------------------------------------------------------------|-----|
|     |
       ``` math
       F(m,l)\geq F(1,1)=\frac{A_{2}}{A_{1}^{2}}=\frac{1}{\sqrt{8}}.
       ```                                                            |     |

Writing $`n=m+l`$ and expanding the factorials therefore gives

|  |  |  |
|----|----|----|
|  |
``` math
\binom{n}{m}=F(m,l)\sqrt{\frac{n}{ml}}\frac{n^{n}}{m^{m}l^{l}}\geq\frac{\exp\{nH(m/n)\}}{\sqrt{8ml/n}},
``` |  |

where $`H(x)=-x\ln x-(1-x)\ln(1-x)`$. Since
$`H(x)=\ln 2-\mathrm{kl}(x\,\|\,1/2)`$, this proves
([28](#A1.E28 "Equation 28 ‣ Binomial coefficient and point-mass bounds. ‣ A.7.2 Auxiliary lemmas ‣ A.7 Lower bound for threshold-based promotion rules ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")).

For $`1\leq a\leq M-1`$, divide
([28](#A1.E28 "Equation 28 ‣ Binomial coefficient and point-mass bounds. ‣ A.7.2 Auxiliary lemmas ‣ A.7 Lower bound for threshold-based promotion rules ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"))
by $`2^{M}`$ and use $`a(M-a)\leq M^{2}/4`$ to obtain
([29](#A1.E29 "Equation 29 ‣ Binomial coefficient and point-mass bounds. ‣ A.7.2 Auxiliary lemmas ‣ A.7 Lower bound for threshold-based promotion rules ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")).
For $`a=0`$ or $`a=M`$, both the point mass and
$`\exp\{-M\mathrm{kl}(a/M\,\|\,1/2)\}`$ equal $`2^{-M}`$, and
$`\sqrt{2M}\geq 1`$, so the bound still holds. ∎

###### Lemma A4 (Rademacher tail).

Let $`S_{n}`$ be a sum of $`n`$ independent Rademacher variables. For
$`n\geq 64`$ and

|     |                                |     |
|-----|--------------------------------|-----|
|     |
       ``` math
       1\leq x\leq\frac{\sqrt{n}}{8},
       ```                             |     |

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}(S_{n}>x\sqrt{n})\geq\frac{c_{R}}{x}\exp\left(-\frac{x^{2}}{2}-\frac{(x^{2}+5)^{2}}{9n}\right),
``` |  |

where

|     |                                   |     |
|-----|-----------------------------------|-----|
|     |
       ``` math
       c_{R}=\frac{e^{-5/2}}{2\sqrt{2}}.
       ```                                |     |

###### Proof.

Let

|     |                                                      |     |
|-----|------------------------------------------------------|-----|
|     |
       ``` math
       B=\frac{S_{n}+n}{2}\sim\mathrm{Bin}(n,\tfrac{1}{2}).
       ```                                                   |     |

Set

|  |  |  |
|----|----|----|
|  |
``` math
m_{0}=\left\lfloor\frac{n+x\sqrt{n}}{2}\right\rfloor+1,\qquad w=\left\lfloor\frac{\sqrt{n}}{2x}\right\rfloor,\qquad m_{1}=m_{0}+w.
``` |  |

Then

|     |                                      |     |
|-----|--------------------------------------|-----|
|     |
       ``` math
       \{S_{n}>x\sqrt{n}\}=\{B\geq m_{0}\}.
       ```                                   |     |

For $`m\geq n/2`$, the binomial probability mass is nonincreasing in
$`m`$, so

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}(B\geq m_{0})\geq(w+1)\mathbb{P}(B=m_{1})\geq\frac{\sqrt{n}}{2x}\mathbb{P}(B=m_{1}).
``` |  |

Applying
([28](#A1.E28 "Equation 28 ‣ Binomial coefficient and point-mass bounds. ‣ A.7.2 Auxiliary lemmas ‣ A.7 Lower bound for threshold-based promotion rules ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"))
with $`m=m_{1}`$, which satisfies $`1\leq m_{1}\leq n-1`$, and using
$`m_{1}(n-m_{1})\leq n^{2}/4`$, we obtain

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}(B=m_{1})\geq\frac{e^{-n\mathrm{kl}(m_{1}/n\,\|\,1/2)}}{\sqrt{2n}}.
``` |  |

Writing $`m_{1}/n=(1+v)/2`$ and $`u=\sqrt{n}\,v`$, the assumptions imply

|     |                                          |     |
|-----|------------------------------------------|-----|
|     |
       ``` math
       x<u\leq x+\frac{2}{\sqrt{n}}+\frac{1}{x}
       ```                                       |     |

and

|     |                    |     |
|-----|--------------------|-----|
|     |
       ``` math
       u^{2}\leq x^{2}+5.
       ```                 |     |

The expansion of the Bernoulli relative entropy gives

|  |  |  |
|----|----|----|
|  |
``` math
n\mathrm{kl}\left(\frac{1+v}{2}\,\middle\|\,\frac{1}{2}\right)\leq\frac{x^{2}+5}{2}+\frac{(x^{2}+5)^{2}}{9n}.
``` |  |

Combining the inequalities gives the result. ∎

###### Lemma A5 (Uniform second moment of selected probes).

Let $`n,M,P`$ be positive integers with $`P\leq M`$, and let
$`(g_{ij})_{i\leq n,j\leq M}`$ be independent Rademacher variables. For
$`J\subseteq[M]`$ with $`|J|=P`$, define

|  |  |  |
|----|----|----|
|  |
``` math
Q_{J}=\frac{1}{nP}\sum_{i=1}^{n}\left(\sum_{j\in J}g_{ij}\right)^{2}.
``` |  |

For every $`\varepsilon>0`$,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\left(\max_{|J|=P}Q_{J}\geq 1+\varepsilon\right)\leq\binom{M}{P}\exp\left\{-\frac{n}{2}\left[\varepsilon-\ln(1+\varepsilon)\right]\right\},
``` |  |

and therefore

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\left(\max_{|J|=P}Q_{J}\geq 1+\varepsilon\right)\leq\left(\frac{eM}{P}\right)^{P}\exp\left\{-\frac{n\varepsilon^{2}}{4(1+\varepsilon)}\right\}.
``` |  |

###### Proof.

Fix $`J`$ and set

|     |                                    |     |
|-----|------------------------------------|-----|
|     |
       ``` math
       Y_{i}=P^{-1/2}\sum_{j\in J}g_{ij}.
       ```                                 |     |

Then

|     |                                                                    |     |
|-----|--------------------------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{E}e^{\mu Y_{i}}=\cosh(\mu/\sqrt{P})^{P}\leq e^{\mu^{2}/2}.
       ```                                                                 |     |

If $`\xi\sim N(0,1)`$ is independent, then for $`0\leq s<1/2`$,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}e^{sY_{i}^{2}}=\mathbb{E}e^{\sqrt{2s}\xi Y_{i}}\leq\mathbb{E}e^{s\xi^{2}}=(1-2s)^{-1/2}.
``` |  |

Markov’s inequality with

|     |                                        |     |
|-----|----------------------------------------|-----|
|     |
       ``` math
       s=\frac{\varepsilon}{2(1+\varepsilon)}
       ```                                     |     |

gives

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\left(\sum_{i}Y_{i}^{2}\geq n(1+\varepsilon)\right)\leq\exp\left\{-\frac{n}{2}\left[\varepsilon-\ln(1+\varepsilon)\right]\right\}.
``` |  |

Apply a union bound over the $`\binom{M}{P}`$ possible sets $`J`$ and
use

|     |                            |     |
|-----|----------------------------|-----|
|     |
       ``` math
       \binom{M}{P}\leq(eM/P)^{P}
       ```                         |     |

and

|  |  |  |
|----|----|----|
|  |
``` math
\varepsilon-\ln(1+\varepsilon)\geq\frac{\varepsilon^{2}}{2(1+\varepsilon)}.
``` |  |

∎

###### Lemma A6 (Calibration of a probe round).

Let $`n\geq 3`$, $`b\in[0,1]`$, and $`\tau>0`$. For $`r\in[0,1/4]`$ and
$`x\in[-1,1]`$, define

|  |  |  |
|----|----|----|
|  |
``` math
h_{r}(x)=\frac{\sqrt{n}(r+x)}{\sqrt{D_{r}(x)}},\qquad D_{r}(x)=1+r^{2}+2rx-b(r+x)^{2}.
``` |  |

Then the following properties hold.

1.  1.
    If $`g\in\{-1,1\}^{n}`$ has empirical mean $`x`$, then

    |     |                                                |     |
    |-----|------------------------------------------------|-----|
    |     |
           ``` math
           T_{b}\bigl(\tau(r\mathbf{1}+g)\bigr)=h_{r}(x).
           ```                                             |     |
2.  2.
    For fixed $`r`$, $`h_{r}(x)`$ is strictly increasing in $`x`$. For
    $`x\in(-1,1)`$, it is continuous and strictly increasing in $`r`$.
3.  3.
    For $`x\in[0,1]`$,

    |     |                                           |     |
    |-----|-------------------------------------------|-----|
    |     |
           ``` math
           h_{1/4}(x)\geq\frac{\sqrt{n}}{\sqrt{17}}.
           ```                                        |     |
4.  4.
    Let

    |     |                                     |     |
    |-----|-------------------------------------|-----|
    |     |
           ``` math
           \Lambda_{n}=\{-1,-1+2/n,\ldots,1\}.
           ```                                  |     |

    For $`u\in\Lambda_{n}\cap(0,1)`$ and $`u^{-}=u-2/n`$, every
    threshold

    |     |                               |     |
    |-----|-------------------------------|-----|
    |     |
           ``` math
           h_{0}(u)\leq\theta<h_{1/4}(u)
           ```                            |     |

    admits an $`r\in(0,1/4]`$ such that

    |     |                                                      |     |
    |-----|------------------------------------------------------|-----|
    |     |
           ``` math
           h_{r}(x)>\theta\quad\Longleftrightarrow\quad x\geq u
           ```                                                   |     |

    for every $`x\in\Lambda_{n}`$.

###### Proof.

For $`z=\tau(r\mathbf{1}+g)`$,

|     |                                                                 |     |
|-----|-----------------------------------------------------------------|-----|
|     |
       ``` math
       \bar{z}=\tau(r+x),\qquad\overline{z^{2}}=\tau^{2}(1+r^{2}+2rx),
       ```                                                              |     |

which proves the first claim.

Direct differentiation gives

|     |                                                      |     |
|-----|------------------------------------------------------|-----|
|     |
       ``` math
       \partial_{x}h_{r}(x)=\sqrt{n}(1+rx)D_{r}(x)^{-3/2}>0
       ```                                                   |     |

and

|     |                                                         |     |
|-----|---------------------------------------------------------|-----|
|     |
       ``` math
       \partial_{r}h_{r}(x)=\sqrt{n}(1-x^{2})D_{r}(x)^{-3/2}>0
       ```                                                      |     |

for $`|x|<1`$. This proves the monotonicity statements.

The third claim follows from

|  |  |  |
|----|----|----|
|  |
``` math
h_{1/4}(x)\geq h_{1/4}(0)=\frac{\sqrt{n}}{4\sqrt{1+(1-b)/16}}\geq\frac{\sqrt{n}}{\sqrt{17}}.
``` |  |

For the final claim, let

|     |                                              |     |
|-----|----------------------------------------------|-----|
|     |
       ``` math
       f(r)=h_{r}(u),\qquad\varphi(r)=h_{r}(u^{-}).
       ```                                           |     |

Both functions are continuous and strictly increasing and satisfy

|     |                  |     |
|-----|------------------|-----|
|     |
       ``` math
       \varphi(r)<f(r).
       ```               |     |

The intermediate value argument therefore produces an $`r`$ for which

|     |                         |     |
|-----|-------------------------|-----|
|     |
       ``` math
       \varphi(r)<\theta<f(r).
       ```                      |     |

Monotonicity in $`x`$ gives the desired cutoff. ∎

###### Theorem A3 (Adaptive proposer defeats slowly growing thresholds).

In model $`\mathsf{M}`$, let $`(b,\lambda)`$ be a threshold gate. With
the parameters defined above, fix $`\varepsilon>0`$ and assume

1.  (B1)
    |     |                            |     |
    |-----|----------------------------|-----|
    |     |
           ``` math
           \lambda_{s,p}<\frac{n}{34}
           ```                         |     |

    for all $`s\leq t_{0}`$ and $`p\leq\min\{P-1,s-1\}`$;
2.  (B2)
    |     |                                                  |     |
    |-----|--------------------------------------------------|-----|
    |     |
           ``` math
           \lambda_{s,P}\leq\frac{a^{2}P}{2(1+\varepsilon)}
           ```                                               |     |

    for all $`P+1\leq s\leq t_{0}+1`$.

Then the proposer $`\mathcal{P}_{B}`$ satisfies

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}(\mathfrak{F}_{t_{0}+1}^{c})\leq\exp\left\{-\frac{\eta^{\prime 2}P}{2(1+\eta^{\prime})}\right\}+\binom{M}{P}\exp\left\{-\frac{n}{2}\bigl(\varepsilon-\ln(1+\varepsilon)\bigr)\right\}.
``` |  |

###### Proof.

First suppose $`n\in\{1,2\}`$. Since $`0<a\leq\sqrt{n}/8`$, the smallest
positive value of a standardized Rademacher sum is $`\sqrt{n}`$, so
$`\ell=\sqrt{n}`$ and $`u=1`$. Moreover,

|     |                                                  |     |
|-----|--------------------------------------------------|-----|
|     |
       ``` math
       h_{0}(1)=h_{1/4}(1)=\frac{\sqrt{n}}{\sqrt{1-b}},
       ```                                               |     |

where the value is interpreted as $`+\infty`$ when $`b=1`$, consistently
with the convention for $`T_{b}`$. For every $`s\leq t_{0}`$, condition
(B1) gives

|     |                                                          |     |
|-----|----------------------------------------------------------|-----|
|     |
       ``` math
       \theta_{s,0}=\sqrt{2\lambda_{s,0}}<\sqrt{n/17}<h_{0}(1).
       ```                                                       |     |

Thus, until the first false promotion, the proposer submits only neutral
probes and the promotion count remains zero. A fresh probe satisfies
$`X_{j}\geq a`$ if and only if all its $`n`$ Rademacher coordinates
equal $`+1`$. On this event its statistic is $`\sqrt{n}/\sqrt{1-b}`$ (or
$`+\infty`$ when $`b=1`$), which exceeds the threshold. Hence, if at
least one of the $`K`$ probes in a round has this property, a false
promotion occurs. Here $`q=2^{-n}`$ and $`\pi=1-(1-q)^{K}`$.
Independence of the fresh probe blocks and the definition of $`t_{0}`$
therefore yield

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}(\mathfrak{F}_{t_{0}+1}^{c})\leq(1-\pi)^{t_{0}}\leq\exp(-\pi t_{0})\leq\exp\bigl(-(1+\eta^{\prime})P\bigr)\leq\exp\left\{-\frac{\eta^{\prime 2}P}{2(1+\eta^{\prime})}\right\}.
``` |  |

The last inequality follows from
$`\eta^{\prime 2}\leq 2(1+\eta^{\prime})^{2}`$. Since the second term in
the stated bound is nonnegative, this proves the theorem for
$`n\in\{1,2\}`$.

Henceforth assume $`n\geq 3`$. Let $`\mathcal{G}_{s}`$ contain all probe
coordinates introduced through round $`s`$ and all gate randomness up to
that round. Fresh probe coordinates in round $`s+1`$ are independent of
$`\mathcal{G}_{s}`$.

For a probe or neutral round, let

|     |                              |     |
|-----|------------------------------|-----|
|     |
       ``` math
       X^{(s)}=\max_{k}X_{j_{s,k}}.
       ```                           |     |

Then

|     |                                |     |
|-----|--------------------------------|-----|
|     |
       ``` math
       \mathbb{P}(X^{(s)}\geq a)=\pi.
       ```                             |     |

If $`\theta_{s,p}<h_{0}(u)`$, a probe with $`X^{(s)}\geq a`$ crosses the
threshold even though its population gain is zero. Hence the round
produces a false promotion with conditional probability at least
$`\pi`$.

If

|     |                                      |     |
|-----|--------------------------------------|-----|
|     |
       ``` math
       h_{0}(u)\leq\theta_{s,p}<h_{1/4}(u),
       ```                                   |     |

[Lemma A6](#A1.Thmlemma6 "Lemma A6 (Calibration of a probe round). ‣ Binomial coefficient and point-mass bounds. ‣ A.7.2 Auxiliary lemmas ‣ A.7 Lower bound for threshold-based promotion rules ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
chooses $`r_{s}`$ so that promotion occurs exactly when

|     |                |     |
|-----|----------------|-----|
|     |
       ``` math
       X^{(s)}\geq a.
       ```             |     |

The promoted candidate then has population gain

|     |              |     |
|-----|--------------|-----|
|     |
       ``` math
       r_{s}\tau>0,
       ```           |     |

so this promotion is genuine.

Condition (B1) guarantees that, until a false promotion or the $`P`$-th
selected probe, every round is one of these two types. Define
$`I_{s}=\mathbf{1}\{X^{(s)}\geq a\}`$ using the fresh coordinates for
all $`s\leq t_{0}`$; these indicators are independent Bernoulli
variables with success probability $`\pi`$. On the event that no false
promotion occurs and fewer than $`P`$ probes are selected by $`t_{0}`$,
each success $`I_{s}=1`$ must have produced a genuine selected probe.
Consequently, Chernoff’s inequality gives

|  |  |  |
|----|----|----|
|  |
``` math

Suppose instead that $`P`$ genuine probe promotions have occurred. The
final candidate has paired differences

|     |                                |     |
|-----|--------------------------------|-----|
|     |
       ``` math
       z=\tau\sum_{j\in J}g_{\cdot j}

and population gain zero. On the event

|     |                                  |     |
|-----|----------------------------------|-----|
|     |
       ``` math
       \max_{|J|=P}Q_{J}<1+\varepsilon,
       ```                               |     |

we have

|     |                            |     |
|-----|----------------------------|-----|
|     |
       ``` math
       \bar{z}\geq\tau n^{-1/2}Pa
       ```                         |     |

and

|     |                                  |     |
|-----|----------------------------------|-----|
|     |
       ``` math
       \overline{z^{2}}=\tau^{2}PQ_{J}.
       ```                               |     |

Therefore

|  |  |  |
|----|----|----|
|  |
``` math
T_{b}(z)>\frac{Pa}{\sqrt{P(1+\varepsilon)}}=a\sqrt{\frac{P}{1+\varepsilon}}.
``` |  |

Condition (B2) makes this larger than the promotion threshold, so the
final neutral candidate is promoted.

The only two ways to avoid a false promotion are therefore failure to
collect $`P`$ probes by $`t_{0}`$ or failure of the uniform
second-moment event. Apply
[Lemma A5](#A1.Thmlemma5 "Lemma A5 (Uniform second moment of selected probes). ‣ Binomial coefficient and point-mass bounds. ‣ A.7.2 Auxiliary lemmas ‣ A.7 Lower bound for threshold-based promotion rules ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks").
∎

###### Corollary A4 (Linear growth in the promotion count is insufficient).

Fix $`c>0`$ and an integer $`p_{0}\geq 0`$. Suppose

|     |                      |     |
|-----|----------------------|-----|
|     |
       ``` math

       ```                   |     |

for all $`p\geq p_{0}`$, and assume

|     |                                     |     |
|-----|-------------------------------------|-----|

       ``` math
       \sup_{t,p<p_{0}}\lambda_{t,p}=o(n).
       ```                                  |     |

satisfying

|  |  |  |
|----|----|----|

``` math

``` |  |

within $`O(P)`$ rounds with probability tending to one.

###### Proof.

Choose $`\varsigma`$ large enough that

|     |                                                         |     |

       ``` math

two sample-size conditions in
[Corollary A3](#A1.Thmcorollary3 "Corollary A3 (First-order promotion-history rate). ‣ Adaptive proposer 𝒫_𝐵. ‣ A.7.4 The cost of promotion history ‣ A.7 Lower bound for threshold-based promotion rules ‣ Appendix A Proofs and Additional Theory ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")

Empirical best-of-$`K`$ edits the incumbent and promotes the candidate
with the largest strictly positive gain on $`S`$. SICA-style follows the
archive-based search of SICA ([Robeyns et al., 2025](#bib.bib10)). It
also edits the incumbent, and its prompt additionally lists up to ten
archive members with the highest evaluation accuracy. DGM-style follows
the parent selection of DGM ([Zhang et al., 2026](#bib.bib9)). Archive
member $`i`$ is chosen as parent with probability proportional to

|     |                                                            |     |
|-----|------------------------------------------------------------|-----|
|     |
       ``` math
       \frac{\sigma\!\left(40(a_{i}-a_{0}-0.08)\right)}{1+e_{i}},
       ```                                                         |     |

where $`a_{i}`$ is its evaluation accuracy, $`a_{0}`$ is that of
$`A_{0}`$, $`e_{i}`$ is the number of rounds in which it has been
parent, and $`\sigma`$ is the logistic function. Elite draws its parent
uniformly from the four archive members with the highest evaluation
accuracy, and Niche-elite groups configurations by model family and
feature subset, draws one group uniformly, and uses its best member.
These two methods follow the population-based search of AlphaEvolve
([Novikov et al., 2025](#bib.bib15)). The five methods above share the
promotion rule of Empirical best-of-$`K`$.

PACE-style and Bonferroni-style edit the incumbent and test all $`K`$
candidates against it with the one-sided McNemar test ([Dietterich,
1998](#bib.bib38)),

|  |  |  |
|----|----|----|
|  |
``` math
z_{\mathrm{MC}}=\frac{n_{+}-n_{-}}{\sqrt{n_{+}+n_{-}}},\qquad p_{\mathrm{MC}}=1-\Phi(z_{\mathrm{MC}}),
``` |  |

with $`n_{+}`$ and $`n_{-}`$ as in
[Section 2.2](#S2.SS2 "2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks"),
$`\Phi`$ the standard normal distribution function, and
$`p_{\mathrm{MC}}=1`$ when $`n_{+}+n_{-}=0`$. PACE-style tests every
candidate at level $`0.05`$, and Bonferroni-style at level
$`0.05/(TK)=0.05/1600`$. If several candidates pass, the one with the
largest gain on $`S`$ is promoted.

#### B.4.1 Robustness and Ablations

The theoretical guarantee of
[Theorem 1](#Thmtheorem1 "Theorem 1 (Simultaneous validity and cumulative progress). ‣ 2.2 Reuse ‣ 2 Methodology and Theoretical Guarantees ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
holds for any allocation weights $`w_{t}`$ and $`v_{p}`$ and split
$`\rho`$ fixed before querying $`S`$. We tested the sensitivity of Reuse
to these choices by running 11 different allocations on 10 fresh seeds
at $`n=2{,}000`$
([Table 6](#A2.T6 "In B.4.1 Robustness and Ablations ‣ B.4 Additional results ‣ Appendix B Experimental Details ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")).
Reuse successfully controlled the error across all configurations and
made exactly zero false promotions out of 317 total promotions. The
final population improvement remained stable and within the natural
variation of the proposer. The running certificate $`C_{T}`$ also
responded naturally to the split $`\rho`$.

The core guarantee of Reuse is highly robust to changes in the search
heuristics. To demonstrate this reliability we evaluated an alternative
variant that queries $`S`$ at every step. In this setup the proposer
edits the incumbent directly and the candidate with the highest
development accuracy is tested on $`S`$ at level $`\rho\delta_{t,p}`$
with $`K=1`$. The proposer receives only the promotion decision. Even
with this more conservative search structure the variant completely
avoided false promotions across 30 seeds at both evaluation set sizes
([Table 7](#A2.T7 "In B.4.1 Robustness and Ablations ‣ B.4 Additional results ‣ Appendix B Experimental Details ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")).
It made 30 strictly positive promotions at $`n=2{,}000`$ and 100 at
$`n=10{,}000`$. These results confirm that the error control mechanism
fundamentally prevents false promotions and maintains rigorous validity
regardless of the specific search mechanics or allocation parameters
used.

We further isolated the role of the exact test on $`S`$ by ablating it.
We ran Reuse at $`n=10{,}000`$ on 10 new seeds using a smaller
development set of 500 examples and a lowered pre-screening threshold of
$`z_{\mathrm{dev}}>0`$ to deliberately allow poor candidates to reach
the evaluation set. We compared this setup with a baseline that promotes
every submitted candidate without testing it on $`S`$. The proposer of
the untested version is told that each submitted candidate was tested
and accepted so the two versions differ only in the application of the
test.
[Figure 4](#A2.F4 "In B.4.1 Robustness and Ablations ‣ B.4 Additional results ‣ Appendix B Experimental Details ‣ Which Self-Improvements Should We Trust?Reliable Self-Improvement When Agents Reuse Their Benchmarks")
illustrates every evaluated candidate under these conditions. Reuse
rejected all 9 candidates with population improvement at most zero and
made no false promotion among its 47 accepted updates. Without the test
the process committed 6 false promotions across 5 of the 10 runs with

variants achieved very similar final population improvements, with no
statistically significant difference between them. This confirms the
test on $`S`$ is strictly necessary and effective at filtering out the
false improvements that pass the initial development screen.
