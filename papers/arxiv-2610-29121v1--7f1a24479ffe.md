# Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run

Erfan Darzi Affiliation: Harvard University Affiliation: Massachusetts
Institute of Technology    Sree Bhargavi Balija Affiliation: UC San
Diego    Sheng He Affiliation: Harvard University

###### Abstract

A coding agent that rewrites its own scaffold has to choose which
proposed edit to expand before that edit has been evaluated, and the
search then has to return one agent. Each run fits one linear readout on
the parent’s steering-split solve rate and eight coordinates of the
proposed diff, from 96 scaffold edits labeled by four evaluations of a
16-instance fit split, and then freezes the coefficients. HumanEval+
reserves 48 instances as the steering split and Polyglot reserves 64.
That split scores parents and keeps an archive of four nodes.
Huxley–Gödel Machine selection draws a parent by Thompson sampling on
the steering counts of nodes that have already been evaluated, and it
expands the child that parent proposes. Every method then returns the
earliest evaluated node whose steering-split solve count is maximal. The
tables report the held-out score of that node on the other 100
HumanEval+ instances and the other 145 Polyglot instances, next to the
root scaffold and the calibration edit with the highest fit-split label.
Twelve runs of GPT-4o return a node at 87.0% on held-out HumanEval+,
against 84.2% for the parent-rate ablation. On that split Huxley–Gödel
Machine selection returns 85.1%, the root is at 81.2%, and the
calibration-best edit is at 82.8%. On the same split Claude Sonnet 4.5
returns 86.6%, beside 86.5% for Huxley–Gödel Machine selection, 85.3%
for the parent-rate ablation, and 85.1% for the calibration-best edit.

## 1 Introduction

A coding agent that rewrites its own scaffold has to rank the edits it
proposes before any of them has been evaluated, because the checker runs
on one child per keep step and the child that is kept becomes a parent
of the edits that follow. The Darwin Gödel Machine adds a child to its
archive only after that child has been evaluated, and it samples parents
from observed scores ([Zhang et al., 2026](#bib.bib2)). The Huxley–Gödel
Machine draws a parent by Thompson sampling on the success and failure
counts of evaluated nodes and expands the child that parent proposes
([Wang et al., 2026](#bib.bib1)). AIDE scores a candidate after the
evaluator has run it ([Jiang et al., 2025](#bib.bib7)).
Surrogate-assisted evolution fits a predictor of fitness from earlier
evaluations of similar individuals ([Jin, 2011](#bib.bib14)). The
readout is that kind of predictor, applied to the diff before the child
is expanded. It is a linear score on the parent’s steering-split solve
rate and eight coordinates of the diff. The ablation uses the same
archive and expands by the parent’s steering rate alone. When the keep
steps end, the readout, the parent-rate ablation, and Huxley–Gödel
Machine selection each return the earliest evaluated node whose
steering-split solve count is maximal. The held-out score of that node
is the comparison, together with the root and the calibration edit whose
fit-split label is highest. Huxley–Gödel Machine selection draws
$`\theta`$ from $`\mathrm{Beta}(1+n_{s},1+n_{f})`$ for each evaluated
node, using that node’s steering counts, and expands the child of the
parent with the largest draw. Every run of every method spends the same
number of checker evaluations: the readout and the ablation label 96
calibration edits and then expand 24 children, and Huxley–Gödel Machine
selection expands 144 children on Polyglot and 176 on HumanEval+. Claude
Sonnet 4.5 and GPT-4o (gpt-4o-2024-08-06) are fit separately ([OpenAI,
2024](#bib.bib17)). The held-out splits are 100 HumanEval+ instances and
145 Polyglot instances ([Liu et al., 2023](#bib.bib15); [Gauthier,
2024](#bib.bib18)).

## 2 Method

### 2.1 Birth-time readout

The root is a scaffold: a system prompt and a loop that writes a
solution, runs the unit tests, and retries once. A proposal is a unified
diff of that scaffold. The readout scores that diff from the parent’s
steering-split solve rate and from eight coordinates of the diff, before
the diff is expanded. The diff is embedded by text-embedding-3-small as
a vector in $`\mathbb{R}^{1536}`$. Each run draws its own projection,
with i.i.d. standard normal entries and rows scaled to unit length, and
it maps that vector onto the coordinates $`e`$. The birth feature of the
full readout is $`X=(R_{\mathrm{par}},e)\in\mathbb{R}^{9}`$. Both
$`R_{\mathrm{par}}`$ and the label $`R`$ are solve rates in $`[0,1]`$.

Before the search, each run calibrates its own readout. It proposes 96
scaffold edits, 48 of the root and two from each of 24 first-generation
children of the root, and labels each edited child by its mean solve
rate over four evaluations of a fixed 16-instance split of the benchmark
being run. Each of those 24 parents is evaluated once on the steering
split, so $`R_{\mathrm{par}}`$ is measured for every calibration parent.
Because those parents do not share one rate, the least-squares slope on
$`R_{\mathrm{par}}`$ is identified, and on these pairs that slope is
positive. Each generator is fit separately on each benchmark. The full
readout minimizes $`\sum_{i=1}^{96}(R_{i}-w^{\top}X_{i}-b)^{2}`$ and
scores a proposal by $`\widehat{v}(X)=w^{\top}X+b`$. The ablation
minimizes the same squared error on $`R_{\mathrm{par}}`$ alone,

````math
\sum_{i=1}^{96}\bigl(R_{i}-w_{r}R_{\mathrm{par},i}-b_{r}\bigr)^{2},

and scores a proposal by
$`\widehat{v}_{r}(R_{\mathrm{par}})=w_{r}R_{\mathrm{par}}+b_{r}`$. The
coefficients stay fixed for the 24 keep steps.

During the search, $`R_{\mathrm{par}}`$ is the parent’s solve rate on
the steering split, 48 HumanEval+ instances or 64 Polyglot instances,
disjoint from the 16 fit instances. The readout and the ablation keep
the four evaluated nodes with the largest solve rate on that steering
split. Huxley–Gödel Machine selection keeps the tree. For each evaluated
node it draws $`\theta`$ from $`\mathrm{Beta}(1+n_{s},1+n_{f})`$ on the
success and failure counts of that node’s clade on the steering split,
and it expands the child proposed by the parent with the largest draw.
The steering split chooses the parents, the archive, and the returned
node. The fit, the archive, and the parent draw read the steering split.
The tables report the held-out score of the node that rule returns.

Each keep step of the readout and of the ablation divides eight
proposals as evenly as possible across the archive and expands the
argmax of that method’s score. On a tie the earliest proposal is
expanded. Proposals are decoded at temperature $`1.0`$, so the eight
diffs of one keep step differ in what they change and by how much, and a
diff that does not apply cleanly is discarded and redrawn. The archive
begins as the evaluated root, so the first eight proposals share
$`R_{\mathrm{par}}`$ and the ablation’s scores tie. The weights on $`e`$
are then what ranks those eight diffs. From the next keep step the
archive holds more than one parent. The positive slope $`w_{r}`$ orders
the ablation’s proposals by the parent’s steering-split rate, and the
weights on $`e`$ can prefer a diff from a lower-scoring parent. The
readout and the ablation run for $`H=24`$ keep steps. Every method
evaluates one child on the steering split at each keep step. When those
steps end, every method returns the earliest evaluated node whose
steering-split solve count is maximal, and the root remains eligible.

### 2.3 Birth-time law

Huxley–Gödel Machine selection uses the case $`\tau=1`$ of the law
below. The density, the ratio, and the event of zero clade counts are
the objects the theorem uses.

###### Definition 1 (Beta draw).

For $`\tau>0`$ and integers $`n_{s},n_{f}\geq 0`$, the law of
$`\theta_{n_{s},n_{f}}^{(\tau)}`$ is the probability measure on
$`(0,1)`$ with density
$`B(\alpha,\beta)^{-1}u^{\alpha-1}(1-u)^{\beta-1}`$, where
$`\alpha=\tau(1+n_{s})`$, $`\beta=\tau(1+n_{f})`$, and
$`B(\alpha,\beta)=\int_{0}^{1}u^{\alpha-1}(1-u)^{\beta-1}\,du\in(0,\infty)`$.

###### Definition 2 (Ratio estimator).

If $`n_{s}+n_{f}\geq 1`$, set $`\rho(n_{s},n_{f})=n_{s}/(n_{s}+n_{f})`$.
The expression is not a real number when $`n_{s}=n_{f}=0`$.

###### Definition 3 (Birth time).

A birth time of a node is an event on which that node’s clade counts, in
the sense of the subtree rooted at the node, including the node, satisfy
$`n_{s}=n_{f}=0`$. The code-change feature may still vary.

###### Assumption 1 (Positive scheduler).

$`\tau>0`$.

###### Assumption 2 (Birth-time zero counts).

The node under discussion is at a birth time in the sense of
[Definition 3](#Thmdefinition3 "Definition 3 (Birth time). ‣ 2.3 Birth-time law ‣ 2 Method ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run").

###### Theorem 1.

Assume
[1](#Thmassumption1 "Assumption 1 (Positive scheduler). ‣ 2.3 Birth-time law ‣ 2 Method ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run")
and [2](#Thmassumption2 "Assumption 2 (Birth-time zero counts). ‣ 2.3 Birth-time law ‣ 2 Method ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run").
On the event of
[Assumption 2](#Thmassumption2 "Assumption 2 (Birth-time zero counts). ‣ 2.3 Birth-time law ‣ 2 Method ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run"),
$`\theta_{0,0}^{(\tau)}`$ has law $`\mathrm{Beta}(\tau,\tau)`$. This law
does not depend on $`X`$. Its mean is $`m(0,0)=1/2`$, and its variance
is $`1/(4(2\tau+1))`$. For all integers $`n_{s},n_{f}\geq 0`$ and every
$`\tau>0`$,
$`\mathbb{E}[\theta_{n_{s},n_{f}}^{(\tau)}]=m(n_{s},n_{f})=(1+n_{s})/(2+n_{s}+n_{f})`$.
The ratio $`\rho(0,0)`$ is undefined. The case $`\tau=1`$ is a
$`\mathrm{Beta}(1,1)`$ draw, uniform on $`(0,1)`$, with mean $`1/2`$ and
variance $`1/12`$.

The experiments use $`\tau=1`$. Huxley–Gödel Machine selection draws
$`\theta`$ from this law for each evaluated node, from the success and
failure counts on that node’s steering evaluation, and expands the child
of the parent with the largest draw. The mean of the draw is
$`m(n_{s},n_{f})=(1+n_{s})/(2+n_{s}+n_{f})`$. The proof is in
Appendix [A](#A1 "Appendix A Proofs ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run").

## 3 Experiments

The held-out splits are the 100 HumanEval+ instances and the 145
Polyglot instances that remain after the 16-instance fit split and the
steering split ([Liu et al., 2023](#bib.bib15); [Chen et al.,
2021](#bib.bib16); [Gauthier, 2024](#bib.bib18)). The steering splits
contain 48 and 64 instances. Claude Sonnet 4.5
(claude-sonnet-4-5-20250929) and GPT-4o (gpt-4o-2024-08-06) are fit
separately and run separately. Each cell is twelve runs. Each run draws
its own projection, calibrates its own coefficients on its own 96 edits,
and draws its own proposals. Proposals are decoded at temperature
$`1.0`$ and the scaffold’s solutions at $`0.2`$. In four-fold
cross-validation on each run’s calibration edits, the fitted score ranks
the measured labels at Spearman $`\rho`$ between $`0.18`$ and $`0.34`$
across the four settings. Every run of every method spends the same
number of checker evaluations: 9,280 on Polyglot and 8,496 on
HumanEval+. A run of the readout or of the ablation spends 6,144 of them
labeling the calibration edits, 1,536 on Polyglot or 1,152 on HumanEval+
evaluating the 24 calibration parents on the steering split, 64 or 48
evaluating the root, and the rest on its 24 keep steps. Huxley–Gödel
Machine selection evaluates the root and expands 144 children on
Polyglot and 176 on HumanEval+, reaching the same totals. The
calibration stage is itself a search: the edit with the highest measured
label is a candidate agent, and

## 4 Related work

Gödel machines accept a self-rewrite only after a proof of higher
expected utility ([Schmidhuber, 2007](#bib.bib3)). [Good
(1966)](#bib.bib4) and [Clune (2019)](#bib.bib12) discuss
ultraintelligent machines and AI-generating algorithms. The Self-Taught
Optimizer (STOP), Automated Design of Agentic Systems (ADAS), and the
Self-Improving Coding Agent (SICA) edit a scaffold or a codebase; SICA
reports 17% to 53% on a random SWE-bench Verified subset ([Zelikman et
al., 2023](#bib.bib11); [Hu et al., 2024](#bib.bib10); [Robeyns et al.,
2025](#bib.bib6)). The Gödel Agent searches a space of agent designs
([Yin et al., 2025](#bib.bib9)). With Claude 3.5 Sonnet (new), DGM
reports 20.0% to 50.0% on a staged SWE-bench subset ([Zhang et al.,
2026](#bib.bib2)). Wang et al. report 56.7% on SWE-Verified-60 with a
different generator ([Wang et al., 2026](#bib.bib1)). In
[Table 1](#S3.T1 "In 3 Experiments ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run")
that parent draw runs for the full horizon, and the reported node is the
earliest evaluated node whose steering-split solve count is maximal. Liu
et al. report 78.3% on SWE-Verified-60 and 93.3% on Polyglot with
Qwen3.6-35B-A3B ([Liu et al., 2026](#bib.bib5)). Lai et al. aggregate
descendant outcomes into clade-level Beta beliefs and select nodes by
Thompson sampling ([Lai et al., 2026](#bib.bib13)). AIDE scores a
candidate only after an evaluator runs it, and AIDE² keeps a
self-rewrite only after a hidden evaluation ([Jiang et al.,
2025](#bib.bib7); [Srikanth et al., 2026](#bib.bib8)).

## 5 Conclusion

The readout ranks scaffold diffs by the parent’s steering-split solve
rate and by eight coordinates of the diff, and every method returns the
earliest evaluated node whose steering-split solve count is maximal. On
held-out HumanEval+ with GPT-4o, that node scores 87.0%, against 84.2%
for the same rule after parent-rate expansion. Huxley–Gödel Machine
selection returns 85.1% on that split, the root is at 81.2%, and the
calibration-best edit is at 82.8%. On the same split Claude Sonnet 4.5
returns 86.6%, beside 86.5% for Huxley–Gödel Machine selection, 85.3%
for parent-rate expansion, and 85.1% for the calibration-best edit
([Table 1](#S3.T1 "In 3 Experiments ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run"),
[Figure 1](#S1.F1 "In 1 Introduction ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run")).

## 6 Limitations

The readout is linear in eight coordinates of one projection per run,
and the coefficients stay fixed through the 24 keep steps. The fit uses
96 scaffold edits labeled on 16 instances, and the archive keeps four
nodes. The generators are Claude Sonnet 4.5 and GPT-4o
(gpt-4o-2024-08-06), on HumanEval+ and Polyglot. The steering split that
keeps the archive is disjoint from the held-out split in

## Appendix A Proofs

The argument below is the proof of
[Theorem 1](#Thmtheorem1 "Theorem 1. ‣ 2.3 Birth-time law ‣ 2 Method ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run").

### A.1 Proof of the birth-time law

*Step A, mean of a Beta law.* Let $`\alpha>0`$, $`\beta>0`$, and write
$`I(\alpha,\beta)=\int_{0}^{1}u^{\alpha-1}(1-u)^{\beta-1}\,du\in(0,\infty)`$.
The mean of the corresponding Beta law is
$`I(\alpha+1,\beta)/I(\alpha,\beta)`$. Define
$`\phi(u)=u^{\alpha}(1-u)^{\beta}`$ for $`u\in[0,1]`$, with
$`\phi(0)=\phi(1)=0`$ because $`\alpha>0`$ and $`\beta>0`$. On
$`(0,1)`$,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\phi^{\prime}(u)`$ | $`\displaystyle=\alpha u^{\alpha-1}(1-u)^{\beta}-\beta u^{\alpha}(1-u)^{\beta-1}`$ |  |
|  |  | $`\displaystyle=\alpha\,u^{\alpha-1}(1-u)^{\beta-1}-(\alpha+\beta)\,u^{\alpha}(1-u)^{\beta-1}.`$ |  |

For $`0<\delta<1/2`$, the fundamental theorem on $`[\delta,1-\delta]`$
gives
$`\int_{\delta}^{1-\delta}\phi^{\prime}(u)\,du=\phi(1-\delta)-\phi(\delta)`$.
The right-hand side tends to $`0`$ as $`\delta\downarrow 0`$. The two
integrands on the expanded right-hand side are nonnegative, so the
monotone convergence theorem yields
$`\alpha\,I(\alpha,\beta)-(\alpha+\beta)\,I(\alpha+1,\beta)=0`$, hence
$`I(\alpha+1,\beta)/I(\alpha,\beta)=\alpha/(\alpha+\beta)`$.
[Assumption 1](#Thmassumption1 "Assumption 1 (Positive scheduler). ‣ 2.3 Birth-time law ‣ 2 Method ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run")
gives $`\alpha=\tau(1+n_{s})>0`$ and $`\beta=\tau(1+n_{f})>0`$, so

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}\bigl[\theta_{n_{s},n_{f}}^{(\tau)}\bigr]=\frac{\tau(1+n_{s})}{\tau(1+n_{s})+\tau(1+n_{f})}=\frac{1+n_{s}}{2+n_{s}+n_{f}}.
``` |  |

At $`(n_{s},n_{f})=(0,0)`$ the parameters are $`(\tau,\tau)`$ and the
mean is $`1/2`$. The same ratio at parameters $`(\alpha+1,\beta)`$
yields
$`\mathbb{E}[U^{2}]=\alpha(\alpha+1)/((\alpha+\beta)(\alpha+\beta+1))`$.
Subtracting the squared mean produces

|  |  |  |
|----|----|----|
|  |
``` math
\mathrm{Var}(U)=\frac{\alpha\beta}{(\alpha+\beta)^{2}(\alpha+\beta+1)}.
``` |  |

At $`\alpha=\beta=\tau`$ this is $`1/(4(2\tau+1))`$. For $`\tau=1`$ the
variance is $`1/12`$. None of the parameters, the mean, or the variance
reads $`X`$. Under
[Assumption 2](#Thmassumption2 "Assumption 2 (Birth-time zero counts). ‣ 2.3 Birth-time law ‣ 2 Method ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run")
the counts are $`(0,0)`$, so the sampling law is
$`\mathrm{Beta}(\tau,\tau)`$ for every value of the code-change feature.
The symbol $`\rho(0,0)`$ would divide by zero and is left undefined.

## Appendix B Experimental details

Each cell of
[Tables 1](#S3.T1 "In 3 Experiments ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run")
and [2](#S3.T2 "Table 2 ‣ 3 Experiments ‣ Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run")
is twelve runs of Claude Sonnet 4.5 (claude-sonnet-4-5-20250929) or
GPT-4o (gpt-4o-2024-08-06). The steering split is 48 HumanEval+
instances or 64 Polyglot instances, and the held-out split is the other
100 or 145 instances. Huxley–Gödel Machine selection draws the parent
from $`\mathrm{Beta}(1+n_{s},1+n_{f})`$ on the steering counts of
evaluated nodes. The calibration-best row is the edit with the highest
fit-split label, scored on the held-out split.

A printed accuracy is the one-decimal rounding of $`100`$ times the
pooled solve count of the returned node divided by twelve times the
split size, and the sample standard deviation is the ordinary standard
deviation of the twelve run percentages. For the readout and the
parent-rate ablation the candidates are the root and the 24 expanded
children. For Huxley–Gödel Machine selection the candidates are the root
and the expanded children, 144 on Polyglot and 176 on HumanEval+.
````
