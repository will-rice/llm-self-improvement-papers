# Third Eye: Beyond Immediate Gains in Recursive Self-Improvement

Sujato Dutta   Padala Indira Sneha   Kypu Mahitha Affiliation: Shashank
Vanga   Neeraj Choudhary Affiliation: Mahindra University

###### Abstract

Does a useful self-update remain useful after the model updates again?
Third Eye separates immediate performance from the outcome of a further
native update. We evaluate five 3–8B backbones on math and code: 64
fresh runs, three candidates per run, and three continuations per
candidate. Selection and final scoring use disjoint items. In the
balanced Qwen3-4B/Llama-3.2-3B comparison, immediate-selected utility is
near zero, but continuation reduces it by $`1.78\,\mathrm{pp}`$
(simultaneous 95% interval $`[0.68,2.88]`$). Candidate-averaged
immediate utility is already negative: selection partly accounts for the
apparently neutral first step. Continuation also lowers utility for
SmolLM3-3B and Llama-3.1-8B; Qwen3-8B remains inconclusive. Target and
out-of-distribution losses dominate retention changes. Matched recipe
and recipient–donor controls identify neither a reliable mitigation nor
a single mechanism. The results support evaluating persistent
self-updates as adaptation transitions, with independent scoring and a
no-update baseline, rather than interpreting immediate performance as
their full value.

## 1 Introduction

Language models increasingly generate the data used to update their own
parameters ([Zelikman et al., 2022](#bib.bib4); [Huang et al.,
2022](#bib.bib5); [Yuan et al., 2024](#bib.bib9); [Zweiger et al.,
2025](#bib.bib3)). In a recursive loop, an update changes both the
model’s current answers and the model that will supply and learn from
its next training batch. An immediate evaluation measures only the
current checkpoint.

Verification addresses a different question. Answer checks and execution
tests can reject incorrect corrections ([Cobbe et al.,
2021](#bib.bib23); [Lightman et al., 2023](#bib.bib24); [Liu et al.,
2023](#bib.bib31)), but passing examples do not establish the broader
value of training on them. That value may also change after another
update.

SEAL learns self-edits using post-adaptation feedback ([Zweiger et al.,
2025](#bib.bib3)), while modification screening checks protected
behavior ([Tayebati et al., 2026](#bib.bib12)). We examine the next
native update, where persistent parameter changes also affect the
generation of new training data.

Third Eye measures both horizons
(Figure [1](#S0.F1 "Figure 1 ‣ Third Eye: Beyond Immediate Gainsin Recursive Self-Improvement")).
It constructs three equal-budget LoRA candidates from a common parent,
then follows each through three native continuations. Development items
determine candidate selection; independent items score all checkpoints
against the unchanged parent. The five-model, two-task study contains 64
fresh runs, 192 candidates, and 576 continuations.

In the balanced Qwen3-4B/Llama-3.2-3B comparison, immediate-selected
utility is $`+0.02\,\mathrm{pp}`$ and continued utility is
$`-1.76\,\mathrm{pp}`$. Their paired difference has an adjusted interval
excluding zero. However, candidate-averaged immediate utility is already
negative: selection partly explains the neutral first-step mean.
SmolLM3-3B and Llama-3.1-8B instead show immediate damage followed by
further decline; Qwen3-8B’s continuation effect remains unresolved. The
evidence concerns different assessments across horizons, with
substantial model dependence.

We contribute:

1.  1.  A paired protocol with independent scoring, repeated continuations,
        and an explicit no-update baseline.
2.  2.  Five-model evidence separating selection effects and
        target/OOD/retention changes across horizons.
3.  3.  Matched recipe and recipient–donor controls that bound explanations
        and proposed mitigations.

## 2 Measuring a Self-Update Beyond Its First Step

### 2.1 Verified data and matched branches

A parent model $`M_{0}`$ first attempts training problems. Failed
problems receive up to eight correction attempts each. Only solutions
that pass the task verifier enter the correction pool. Math corrections
are checked against answers; code corrections must pass execution tests
in an isolated sandbox. We construct $`K=3`$ compositionally distinct
batches $`B_{k}`$, each containing two different problems. Batches may
overlap with one another. This preserves candidate diversity without
requiring six different verified corrections.

Let $`A`$ denote the fixed update procedure. Candidate $`k`$ is

|     |     |     |     |
| --- | --- | --- | --- |
|     |

       ``` math
       M_{1}^{(k)}=A(M_{0},B_{k};\xi_{k}).
       ```                                  |     | (1) |

The parent is restored before each candidate is trained. For each draw
$`d\in\{1,2,3\}`$, candidate $`M_{1}^{(k)}`$ generates a native
correction batch $`C_{k,d}`$ and undergoes one further update:

|     |     |     |     |
| --- | --- | --- | --- |
|     |

       ``` math
       M_{2}^{(k,d)}=A(M_{1}^{(k)},C_{k,d};\zeta_{k,d}).
       ```                                                |     | (2) |

All candidates continue, including those not chosen by the immediate
selector. Continuation draws vary the correction/optimization procedure
jointly; they do not separately randomize each source of variation.

Updates use LoRA ([Hu et al., 2021](#bib.bib16)), rank 16 and scaling
32, on attention projections. Each full update has 50 AdamW steps,
learning rate $`10^{-4}`$, microbatch size one, and gradient
accumulation eight. Thus two corrections receive 400 example
presentations per update. Optimizer state is reset between updates,
while the candidate’s parameter changes persist into its continuation.
If a native correction pool is exhausted without supplying a full batch,
the branch is terminal: $`M_{2}=M_{1}`$, with no continuation training.
None of the 576 fresh continuation draws was terminal.

### 2.2 Immediate and continued utility

For role $`r\in\{\mathrm{target},\mathrm{OOD},\mathrm{retention}\}`$,
let $`a_{r}(M)`$ be accuracy on a fixed item set. Utility is the
equal-role mean change from the parent:

|     |     |     |     |
| --- | --- | --- | --- |
|     |

       ``` math
       U(M;M_{0})=\frac{1}{3}\sum_{r}\big[a_{r}(M)-a_{r}(M_{0})\big].
       ```                                                             |     | (3) |

We report percentage points, multiplying this quantity by 100. Equal
role weights prevent the larger retention set from dominating. They
remain a specified objective, rather than a universal measure of
quality.

The immediate selector maximizes development utility. For run $`p`$, let
$`w_{pk}`$ assign equal mass to tied best candidates and zero elsewhere.
On independent scoring items, its two endpoints are

|     |                          |                                                                                  |     |     |
| --- | ------------------------ | -------------------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle G_{1p}`$ | $`\displaystyle=\sum_{k}w_{pk}U(M_{1}^{(k)};M_{0}),`$                            |     | (4) |
|     | $`\displaystyle G_{2p}`$ | $`\displaystyle=\sum_{k}w_{pk}\frac{1}{3}\sum_{d=1}^{3}U(M_{2}^{(k,d)};M_{0}).`$ |     | (5) |

Their paired difference, $`\Delta_{p}=G_{2p}-G_{1p}`$, measures the
increment from continuation. Both endpoints use the same parent
reference. Here $`H_{2}`$ means an observed two-update outcome, not a
prediction.

We also report uniform-candidate endpoints, replacing $`w_{pk}`$ by
$`1/3`$. This separates the behavior of the update procedure from the
effect of selecting a candidate on development performance. Hold retains
$`M_{0}`$ and has zero utility by definition. Replay admits the
immediate-selected candidate only if its development target gain is
positive and both OOD and retention gains are nonnegative. These actions
are recorded before final scoring. Holding does not consume an equal
training budget; it is the decision alternative to updating.

| ------------ | ----------------------- | -------------- |
| Role         | Math                    | Code           |
| Training     | GSM8K: 1,024            | MBPP: 306      |
| Dev. target  | GSM8K: 64               | MBPP: 64       |
| Dev. OOD     | MATH: 64                | MBPP val.: 64  |
| Final target | GSM8K: 128              | MBPP test: 128 |
| Final OOD    | MATH-500: 128           | HumanEval: 128 |
| Retention    | MMLU: 256 in each suite |                |

disjoint. Retention is measured on separate development and final

### 2.3 Models, tasks, and experimental units

We evaluate Qwen3-4B and Qwen3-8B ([Yang et al., 2025](#bib.bib29)),
Llama-3.2-3B-Instruct ([Meta AI, 2024](#bib.bib2)),
Llama-3.1-8B-Instruct ([Grattafiori et al., 2024](#bib.bib30)), and
SmolLM3-3B ([Bakouch et al., 2025](#bib.bib1)). The three smaller
backbones have eight fresh runs per task; each 8B backbone has four.
This gives 64 runs, balanced between math and code within every model. A
run repeats the adaptation experiment from the same released checkpoint
with a different random seed; it is not an independently pretrained
model.

Table [1](#S2.T1 "Table 1 ‣ 2.2 Immediate and continued utility ‣ 2 Measuring a Self-Update Beyond Its First Step ‣ Third Eye: Beyond Immediate Gainsin Recursive Self-Improvement")
specifies the data. GSM8K ([Cobbe et al., 2021](#bib.bib23)) and MBPP
([Austin et al., 2021](#bib.bib26)) provide training failures and target
evaluation. MATH ([Hendrycks et al., 2021](#bib.bib27)) and HumanEval
([Chen et al., 2021](#bib.bib25)) provide final OOD problems; MMLU
([Hendrycks et al., 2020](#bib.bib28)) measures retention. Code’s
development OOD set is MBPP validation, whereas final OOD scoring uses
HumanEval. This domain change is relevant when interpreting admission.
Eight HumanEval problems used for timing calibration are excluded from
final scoring.

Every run scores 13 checkpoints: the parent, three candidates, and nine
continuations. The study therefore contains 832 checkpoint evaluations.
Checkpoints and draws are repeated measurements within a run, not
additional independent runs. Hash-locked manifests, templates, actions,
and checkpoint identities link these measurements. We freeze the date in
model templates, preventing a changing system date from changing prompts
across checkpoints.

### 2.4 Uncertainty and declared comparisons

We use 5,000 bootstrap replicates, resampling parent runs within
model/task strata and items within evaluation roles. Checkpoints sharing
an exact item pool share its item resample. This retains pairing and
avoids treating reuse of the same test questions as independent evidence
([Bouthillier et al., 2021](#bib.bib33); [Dror et al.,
2018](#bib.bib37); [Berg-Kirkpatrick et al., 2012](#bib.bib38)). The
three native continuation draws are averaged within a candidate before
resampling; they are not separately resampled. Intervals are
consequently conditional on these finite draws and the frozen selector.

Declared tests and descriptive comparisons are kept separate. For
Qwen3-4B/Llama-3.2-3B, the primary is the model difference in $`G_{2}`$,
with a joint 95% interval. The pooled continuation contrast belongs to a
six-contrast secondary family, with simultaneous 95% intervals and
Holm-adjusted centered-bootstrap $`p`$-values ([Holm,
1979](#bib.bib36)). SmolLM3’s declared primary is its paired
continuation contrast, with a 95% interval. Each 8B model has the same
endpoint with a 97.5% interval, giving joint 95% coverage for the
two-model test family. Each declaration was frozen before its
corresponding outcomes. All five-model plots and role/task
decompositions are descriptive; they do not create a new pooled
confirmatory primary.

### 3.1 A neutral immediate mean can precede a decline

In the 32-run Qwen3-4B/Llama-3.2-3B comparison, immediate-selected
utility averages $`+0.016\,\mathrm{pp}`$ (95% interval
$`[-1.319,1.326]`$). After continuation, utility is
$`-1.760\,\mathrm{pp}`$ ($`[-3.105,-0.420]`$). The paired decrement is
$`-1.776\,\mathrm{pp}`$, with simultaneous interval $`[-2.876,-0.679]`$
and Holm-adjusted $`p=0.0012`$. The same selected candidates therefore
receive materially different assessments at the two horizons.

The near-zero immediate mean is not an equivalence test: its interval
permits both benefit and harm. It also combines different model
responses. Llama-3.2-3B has immediate utility $`+0.285\,\mathrm{pp}`$
and continued utility $`-3.160\,\mathrm{pp}`$; Qwen3-4B has
$`-0.252\,\mathrm{pp}`$ and $`-0.359\,\mathrm{pp}`$. Most of the pooled
continuation decrement comes from Llama. The predeclared
Qwen-minus-Llama $`G_{2}`$ contrast is $`+2.801\,\mathrm{pp}`$
($`[0.266,5.329]`$). This is evidence of different outcomes under a
common recipe, not evidence that Qwen adaptation is beneficial: its mean
remains slightly negative.

### 3.2 Selection accounts for part of the first-step assessment

Uniform candidate weights change the interpretation of the first step
(Table [2](#S3.T2 "Table 2 ‣ 3.2 Selection accounts for part of the first-step assessment ‣ 3 What Changes After Another Update? ‣ Third Eye: Beyond Immediate Gainsin Recursive Self-Improvement")).
Across the same 32 runs, candidate-averaged immediate utility is
$`-0.686\,\mathrm{pp}`$, rather than the selector’s
$`+0.016\,\mathrm{pp}`$. Candidate-averaged continued utility is
$`-2.059\,\mathrm{pp}`$. Immediate selection thus raises both endpoints,
especially the first, but does not eliminate the continuation decrement.

This control limits the claim that immediate evaluation simply misses
all update damage. Some damage is already visible before selection, and
SmolLM3 and Llama-3.1-8B have negative immediate outcomes even after
selection. What the paired design establishes is that the immediate
endpoint alone does not describe the full update procedure.

### 3.3 Continuation effects differ across backbones

Figure [2](#S3.F2 "Figure 2 ‣ 3 What Changes After Another Update? ‣ Third Eye: Beyond Immediate Gainsin Recursive Self-Improvement")
presents the full model matrix. SmolLM3-3B declines by
$`4.262\,\mathrm{pp}`$ after continuation, with its declared 95%
interval $`[-6.163,-2.581]`$. Llama-3.1-8B declines by
$`2.501\,\mathrm{pp}`$, with adjusted 97.5% interval
$`[-4.411,-0.583]`$. Neither replicates the near-neutral first step:
their immediate means are $`-3.406\,\mathrm{pp}`$ and
$`-3.418\,\mathrm{pp}`$, respectively. They support an additional
continuation cost under this recipe, while showing that delayed loss
need not be hidden initially.

Qwen3-8B’s mean continuation change is $`-0.681\,\mathrm{pp}`$, with
adjusted interval $`[-1.914,0.629]`$. This result is inconclusive. Its
interval admits both a meaningful decline and a modest improvement. The
five-model pattern is therefore neither uniform degradation nor a
monotonic size effect. Only Qwen3-8B was executed on A100 hardware; the
remaining fresh runs used GH200 hardware. Model size, family, training
history, and runtime are not independently randomized.

### 3.4 Target and OOD loss dominate retention loss

Figure [3](#S3.F3 "Figure 3 ‣ 3.4 Target and OOD loss dominate retention loss ‣ 3 What Changes After Another Update? ‣ Third Eye: Beyond Immediate Gainsin Recursive Self-Improvement")
decomposes the continuation increment by role. For Llama-3.2-3B, target
accuracy falls by $`6.45\,\mathrm{pp}`$ and OOD accuracy by
$`3.88\,\mathrm{pp}`$, while retention changes by only
$`-0.01\,\mathrm{pp}`$. SmolLM3-3B shows target/OOD changes of
$`-6.46/-6.00\,\mathrm{pp}`$, versus $`-0.33\,\mathrm{pp}`$ in
retention. Llama-3.1-8B shows the same ordering, with
$`-4.30/-2.38/-0.83\,\mathrm{pp}`$ for target/OOD/retention. Thus the
observed loss is not adequately described as forgetting unrelated MMLU
knowledge. It also concerns the capabilities adaptation is meant to
serve.

Qwen3-4B differs: target declines by $`0.74\,\mathrm{pp}`$, OOD improves
by $`0.79\,\mathrm{pp}`$, and retention declines by
$`0.37\,\mathrm{pp}`$. These are descriptive role means, not three
independently established effects. An exploratory model-by-task
interaction in the 32-run comparison is $`+2.07\,\mathrm{pp}`$ for the
continuation contrast, with 95% interval $`[-0.98,5.11]`$; it does not
resolve a task-specific explanation.
Appendix [B](#A2 "Appendix B Role and Task Decomposition ‣ Third Eye: Beyond Immediate Gainsin Recursive Self-Improvement")
gives both horizons for every role.

Formatting also changes. On GSM8K, strict numeric-extraction failures
rise from 4.49% at $`H_{1}`$ to 10.19% at $`H_{2}`$ for Llama-3.2-3B,
and from 4.69% to 15.12% for SmolLM3. These are observable failure modes
within the measured loss. They do not establish how much loss reflects
formatting rather than problem-solving ability. We preserve the original
scoring and do not repair answers after seeing outcomes.

## 4 Controls on the Update Procedure

The main comparison couples the receiving parameters, the corrections
they generate, and subsequent optimization. We examine these factors in
16 paired follow-up parents, four per Qwen3-4B/Llama-3.2-3B task stream.
They reuse inspected parents and are not additional fresh replications.
One fixed candidate branch and two draws per parent yield 272 scored
cells. Native baselines and controls are re-scored on the same A100
runtime. The nine declared control contrasts use joint run/item
resampling, simultaneous 95% intervals, and Holm correction.

### 4.1 Fewer steps and pooled corrections do not give a resolved rescue

To test the intensity of the two-example recipe, we compare native
50-step continuations with 10 steps, 25 steps, and the union of verified
corrections from that candidate’s archived continuation batches. The
alternatives change the receiving model’s continuation recipe; they do
not redefine the main study’s training budget.

Relative to 50 steps, the 10-step contrast is $`+0.47\,\mathrm{pp}`$
($`[-0.90,1.94]`$), and the 25-step contrast is $`-0.28\,\mathrm{pp}`$
($`[-1.37,0.83]`$). Pooling yields $`+0.29\,\mathrm{pp}`$
($`[-1.57,2.04]`$). All intervals cross zero
(Figure [5](#S4.F5 "Figure 5 ‣ 4.1 Fewer steps and pooled corrections do not give a resolved rescue ‣ 4 Controls on the Update Procedure ‣ Third Eye: Beyond Immediate Gainsin Recursive Self-Improvement")).
These controls neither establish a mitigation nor prove recipe
invariance: they remain compatible with useful improvements. The native
continuation increment in this smaller subset is $`-1.20\,\mathrm{pp}`$
($`[-3.06,0.55]`$), itself inconclusive.

### 4.2 Crossed recipients and donors leave the mechanism open

We apply correction batches from the unchanged parent ($`D_{0}`$) and
the first-step model ($`D_{1}`$) to both receiving parameter states.
Comparing receivers on the same donor data tests whether receiving state
changes the update increment. The recipient contrasts are
$`-0.47\,\mathrm{pp}`$ for $`D_{0}`$ ($`[-3.02,2.03]`$) and
$`-1.10\,\mathrm{pp}`$ for $`D_{1}`$ ($`[-3.85,1.72]`$). Their
interaction is $`-0.63\,\mathrm{pp}`$ ($`[-2.79,1.56]`$). The intervals
do not isolate parameter interference, endogenous data change, or their
interaction. Applying the same native recipe directly to $`M_{0}`$ gives
$`-0.44\,\mathrm{pp}`$ ($`[-2.40,1.36]`$). Thus these controls do not
establish that the additional loss requires the first update, rather
than another application of this small-batch recipe.

The donor comparison also has a specific limit: $`D_{0}`$ was harvested
on the control runtime, while $`D_{1}`$ was archived. Its source
contrast includes generation/runtime differences alongside correction
composition. The crossed design is informative about these matched
updates, but it does not justify a causal decomposition of all native
continuation loss.

### 4.3 Reference solutions expose another recipe dependence

A matched reference-solution arm replaces verified self-generated
solutions with gold solutions for the same training problems. Under the
same 50-step recipe, it is $`11.56\,\mathrm{pp}`$ worse than the
self-generated arm (simultaneous interval $`[-14.45,-8.64]`$). This
large difference is not evidence that correct reference solutions are
intrinsically inferior.

A saved-output audit confirms identical receiving states, training
seeds, problem identities, and step budgets. Yet gold solutions contain
only 41–61% as many assistant-label tokens per example. Their resulting
completions are shorter, and code syntax-failure rates increase. For
Llama code, target syntax failures rise from 1.66% to 18.55%; for Qwen,
from 0.98% to 4.88%. Equal example presentations therefore do not match
text style or label-token exposure. These observations motivate caution
about data substitution, rather than a claim that syntax or exposure
mediates the entire utility loss.

## 5 Implications for Evaluating Self-Improvement

#### Measure transitions as well as checkpoints.

The result is not that immediate evaluation is useless. It detects
substantial first-step damage in several backbones, and candidate
selection improves the immediate mean. Its limit is that a current score
omits the subsequent update transition. A useful evaluation should
report $`G_{1}`$, $`G_{2}`$, and their paired difference, with an
unchanged parent as a decision baseline. The role breakdown matters: a
retention-only gate would overlook much of the target/OOD loss observed
here.

#### Abstention is a baseline, not a demonstrated solution.

In the 32-run comparison, Replay commits 21.9% of the selected candidate
mass and yields $`-0.27\,\mathrm{pp}`$ ($`[-0.80,0.21]`$) relative to
holding. It does not establish improvement over Hold. A fixed
development-derived Qwen-commit/Llama-hold rule likewise fails to
outperform holding or replay. Better performance than forced updating is
not sufficient evidence of a useful admission policy.

#### Selection and uncertainty require separate controls.

Selecting and scoring the same outcome creates optimism ([Cawley and
Talbot, 2010](#bib.bib35)). An eight-parent diagnostic shows
same-outcome selection optimism increasing from zero at $`K=1`$ to
$`2.09\,\mathrm{pp}`$ at $`K=3`$
(Appendix [D](#A4 "Appendix D Selection Optimism Diagnostic ‣ Third Eye: Beyond Immediate Gainsin Recursive Self-Improvement")).
Our main study instead freezes selection on separate items. Uncertainty
still depends on shared final questions: for the Qwen–Llama primary, the
run-only interval is $`[1.85,3.78]\,\mathrm{pp}`$, compared with the
joint interval $`[0.27,5.33]\,\mathrm{pp}`$. Repeated checkpoints cannot
substitute for broader evaluation support.

#### Prediction remains a distinct empirical claim.

Training-response forecasting ([Luo et al., 2026](#bib.bib11); [Liu et
al., 2026](#bib.bib15)) and modification screening ([Ji and Ding,
2026](#bib.bib13); [Xie et al., 2026](#bib.bib14)) address useful but
different decisions. The present results establish a measurement
contrast; they do not establish that a forecaster can exploit it.
Earlier held-out forecasting and admission diagnostics did not yield a
validated advantage and are not the basis of the five-model claims. No
learned predictor is fitted to, or selected using, these fresh outcomes.

## 6 Related Work

#### Self-generated adaptation and agent improvement.

STaR ([Zelikman et al., 2022](#bib.bib4)) and self-improvement with
generated reasoning ([Huang et al., 2022](#bib.bib5)) show how model
outputs can become training data. Self-Rewarding Language Models ([Yuan
et al., 2024](#bib.bib9)) extend this idea to preference supervision.
SEAL ([Zweiger et al., 2025](#bib.bib3)) learns to generate
self-adaptation data and directives using downstream performance after
training. Our study does not introduce self-generated parameter
adaptation; it measures how a candidate’s immediate value differs from
its value after another native update. Self-Refine ([Madaan et al.,
2023](#bib.bib6)), Reflexion ([Shinn et al., 2023](#bib.bib7)), and
analyses of self-correction ([Huang et al., 2023](#bib.bib8)) concern
refinement and feedback that need not persist as weight changes. The
Darwin Gödel Machine ([Zhang et al., 2025](#bib.bib10)) evolves agent
programs. These settings motivate recursive evaluation but differ from
the fixed LoRA branches studied here.

#### Predicting and screening modifications.

TuneAhead ([Luo et al., 2026](#bib.bib11)) predicts full fine-tuning
outcomes from data descriptors and short probes. Target-independent
micro-interventions ([Liu et al., 2026](#bib.bib15)) characterize
training response across models. Rehearse ([Ji and Ding,
2026](#bib.bib13)) and Predict Before You Modify ([Xie et al.,
2026](#bib.bib14)) use prior modification outcomes to guide agent
changes. The Self-Healing Harness ([Tayebati et al., 2026](#bib.bib12))
screens persistent instruction changes against triggering failures and
protected behavior. Thus beneficial local edits with collateral costs
are already documented. Our distinction is the paired
immediate/continued evaluation of persistent weight updates, with native
correction regeneration and independent scoring.

#### Forgetting and adaptation geometry.

Continual-learning methods constrain important parameters or replay past
experience ([Kirkpatrick et al., 2016](#bib.bib19); [Zenke et al.,
2017](#bib.bib21); [Lopez-Paz and Ranzato, 2017](#bib.bib20)).
Forgetting during language-model fine-tuning ([Luo et al.,
2023](#bib.bib18)), distorted pretrained features ([Kumar et al.,
2022](#bib.bib34)), and LoRA-specific intruder dimensions ([Shuttleworth
et al., 2024](#bib.bib22)) offer plausible explanations for adaptation
failures. LoRA ([Hu et al., 2021](#bib.bib16)) and QLoRA ([Dettmers et
al., 2023](#bib.bib17)) make parameter-efficient experiments accessible,
but efficiency does not establish update quality. We do not measure
spectral mediation or test a continual-learning remedy; our
recipient–donor and recipe controls leave the mechanism unresolved.

#### Verification and credible evaluation.

Outcome verification ([Cobbe et al., 2021](#bib.bib23)), process
supervision ([Lightman et al., 2023](#bib.bib24)), and stronger code
testing ([Liu et al., 2023](#bib.bib31)) improve supervision. They
answer different questions from the broader effect of a parameter
update. Evaluation reproducibility ([Melis et al., 2017](#bib.bib32)),
model-selection bias ([Cawley and Talbot, 2010](#bib.bib35)), benchmark
variation ([Bouthillier et al., 2021](#bib.bib33)), and paired
statistical testing ([Dror et al., 2018](#bib.bib37); [Berg-Kirkpatrick
et al., 2012](#bib.bib38)) motivate our independent scoring and
shared-item resampling. Third Eye applies these safeguards to the
adaptation transition, where candidates and descendants reuse both
ancestors and evaluation items.

## 7 Conclusion

Third Eye evaluates a verified self-update immediately and after a
further native update. The five-model study shows why these endpoints
should be reported together: continuation can worsen utility
substantially, while the size and visibility of that change depend on
the backbone. Candidate selection explains part of an apparently neutral
first step, and target/OOD losses can dominate retention changes. The
matched controls provide neither a universal mechanism nor a reliable
repair. The practical contribution is a controlled way to measure update
consequences before interpreting immediate gains as recursive
improvement.

## Limitations

The evidence covers five 3–8B backbones, two tasks, two-example LoRA
updates, and $`H_{2}`$. Transfer to larger batches, full fine-tuning, or
longer loops is untested. Fifty steps on two corrections may
over-specialize; the controls cannot rule out better recipes. Eight runs
per 8B model provide less precision. Hardware, checkpoint training
history, and parameter count are not isolated causal factors.

Fixed item sets offer finite coverage and may overlap pretraining data.
Intervals condition on three averaged continuations, the development
selector, and the equal-role objective. Code’s development/final OOD
domains differ. Observed sign changes are noisy estimates. The 16-parent
controls reuse inspected parents; their reference-source audit does not
establish a mediator.

## Ethical Considerations

We use public math, code, and general-knowledge benchmarks, with no
human participants or private personal data. Generated code runs in
resource-limited isolated sandboxes. Models and datasets retain their
respective license requirements. Benchmark verification cannot certify
unattended self-modification. We report adverse and unresolved outcomes,
and do not interpret nonsignificance as evidence of safety.

#### Optimization.

We use unquantized bfloat16 models with attention query, key, value, and
output LoRA projections; rank 16, alpha 32, and zero adapter dropout.
The learning rate is $`10^{-4}`$, with 50 AdamW steps, microbatch one,
gradient accumulation eight, and maximum training sequence length 1,024.
The two-example batch is repeatedly presented, giving 400 presentations.
The optimizer is reinitialized between updates. Parent restoration and
adapter hashes prevent candidate branches from inheriting one another.
The exact optimizer and tokenizer configurations accompany the
experiment manifests.

#### Generation and scoring.

Generation is capped at 512 new tokens. Evaluation uses greedy pass@1,
with conditional-likelihood scoring for multiple-choice retention.
Generation batches are 32 for greedy decoding and 16 for sampling.
Reasoning-capable checkpoints use non-thinking mode. Training failure
harvesting scans at most 1,024 GSM8K or 306 MBPP problems, with eight
correction attempts per failed problem. Only verified examples are
retained. Scoring uses separate immutable development and final
manifests. Prompt and item hashes are checked for reuse; this does not
audit external pretraining corpora.

#### Scarce corrections.

Candidate batches must differ in composition and contain no repeated
problem within a batch. Sharing a correction across candidate batches is
permitted. Candidates have equal batch size and optimizer budget. A
continuation with fewer than two verified corrections after its fixed
harvest budget preserves the incoming adapter exactly and records
continuation_available=0. No synthetic repetition is used to force an
update. All fresh study draws had available continuations.

#### Frozen prompts.

A template’s automatically inserted date can otherwise change between
model evaluations. We fix the date string to 11 Oct 2026 and bind
template and prompt hashes to the scoring manifest. Historical runs with
changing templates are excluded from the fresh five-model estimates.

#### Checkpoint revisions.

Qwen3-8B is pinned to b968826d9c46. SmolLM3-3B is pinned to
a07cc9a04f16. The Llama-3.1-8B-Instruct checkpoint uses the NousResearch
mirror at revision 0e9e39f249a1, with recorded upstream revision
d10aef7999a2. These are abbreviated revision identifiers. Full revisions
and file hashes are included in the machine-readable configurations.

## Appendix F Statistical and Artifact Accounting

The main five-model analysis contains 64 fresh runs, 192 immediate
candidates, 576 continuations, and 832 scored checkpoints. Each
checkpoint has 128 target, 128 OOD, and 256 retention outcomes. Role
weights are equal irrespective of item count. The 16 control parents
overlap previously inspected runs and are reported separately.

Bootstrap resampling preserves parent strata and shared item identities.
The three native draws are averaged before bootstrap resampling.
Consequently, neither checkpoints nor native draws are used as
independent parent observations. Primary reports retain their declared
multiplicity families; the five-model plotting analysis is a separate
descriptive re-expression of saved outcomes.

The accompanying source includes vector figures, aggregate plotting
data, analysis code, and manifest/report checksums. The saved summaries
reproduce the figures without further model execution.
