###### Abstract

Self-play methods have demonstrated remarkable success in enhancing
model capabilities across various domains. In the context of
Reinforcement Learning from Human Feedback (RLHF), self-play not only
boosts Large Language Model (LLM) performance but also overcomes the
limitations of traditional Bradley-Terry (BT) model assumptions by
finding the Nash equilibrium (NE) of a preference-based, two-player
constant-sum game. However, existing methods either guarantee only
average-iterate convergence, incurring high storage and inference costs,
or converge to the NE of a regularized game, failing to accurately
reflect true human preferences. In this paper, we introduce Magnetic
Preference Optimization (MPO), a novel approach capable of achieving
last-iterate convergence to the NE of the original game, effectively
overcoming the limitations of existing methods. Building upon Magnetic
Mirror Descent (MMD), MPO attains a linear convergence rate, making it
particularly suitable for fine-tuning LLMs. To ensure our algorithm is
both theoretically sound and practically viable, we present a simple yet
effective implementation that adapts the theoretical insights to the
RLHF setting. Empirical results demonstrate that MPO can significantly
enhance the performance of LLMs, highlighting the potential of self-play
methods in alignment.

## 1 Introduction

Self-play has emerged as an effective method for improving model
performance, particularly in domains that require strategic
decision-making and complex problem-solving ([Silver et al.,
2017](#bib.bib50); [Vinyals et al., 2019](#bib.bib59); [Perolat et al.,
2021](#bib.bib41)). By allowing models to iteratively refine their
strategies through self-competition, self-play enables them to discover
optimal policies. In the realm of Reinforcement Learning from Human
Feedback (RLHF) ([Ouyang et al., 2022](#bib.bib39); [Peng et al.,
2023](#bib.bib40); [Achiam et al., 2023](#bib.bib2); jin2025finetuning),
self-play not only has proven effective in enabling Large Language
Models (LLMs) to better align with human preferences ([Chen et al.,
2024](#bib.bib13); [Wu et al., 2024](#bib.bib64); [Zhang et al.,
2024](#bib.bib68)), but also offers unique advantages by addressing the
limitations of traditional preference modeling methods ([Munos et al.,
2023](#bib.bib36); [Swamy et al., 2024](#bib.bib52)).

Conventional RLHF methods typically rely on the Bradley-Terry
(BT) ([Bradley & Terry, 1952](#bib.bib8)) assumption for preference
modeling, which presumes transitivity in human preferences—if response A
is preferred over B, and B over C, then A should also be preferred over
C. While this may hold for individuals in specific contexts,
generalizing transitive preferences across broader populations often
fails due to the presence of non-transitive preferences ([Swamy et al.,
2024](#bib.bib52)). This limitation undermines the ability of existing
RLHF methods to capture the complexity of human preferences. Self-play,
however, offers a solution by finding the Nash equilibrium (NE) of a
two-player constant-sum game based on human preferences ([Munos et al.,
2023](#bib.bib36); [Swamy et al., 2024](#bib.bib52)).

Despite its promise, self-play in the context of LLM alignment presents
unique challenges. Most existing methods, such as Self-Play Preference
Optimization (SPO) ([Swamy et al., 2024](#bib.bib52)), rely on Mirror
Descent (MD) ([Beck & Teboulle, 2003](#bib.bib7)) based Deep RL methods
like PPO ([Schulman et al., 2017](#bib.bib47)) and SAC ([Haarnoja
et al., 2018](#bib.bib22)) to learn the NE of the preference-based game.
However, from a theoretical perspective, MD only guarantees
average-iterate convergence to the NE, while the last-iterate policy
tends to oscillate around the NE ([Mertikopoulos et al.,
2018b](#bib.bib35); [Mertikopoulos et al., 2018a](#bib.bib34); [Perolat
et al., 2021](#bib.bib41)). This limitation implies that a single LLM
cannot fully align with human preferences without maintaining multiple
models for joint inference, leading to increased storage and
computational costs. As shown in
Figure [1](#S1.F1 "Figure 1 ‣ 1 Introduction ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
where the duality gap measures the distance between the current policy
and the NE, classic Deep RL methods exhibit poor last-iterate
convergence, even in a simple Kuhn Poker game. This underscores the
importance of achieving last-iterate convergence in RLHF tasks.

![Refer to caption](2410.16714v3/figures/kuhn_gap.png)

Figure 1: Kuhn Poker Experiments.

On the other hand, Nash Learning from Human Feedback (NLHF) ([Munos
et al., 2023](#bib.bib36)) also leverages MD but achieves last-iterate
convergence by employing a geometric mixture of the current policy and a
reference poliy, commonly referred to as a first-order approximation of
the reference policy ([Munos et al., 2023](#bib.bib36)). However, this
approximation lacks rigorous theoretical guarantees and ultimately only
converges to the NE of the KL regularized game, failing to capture true
human preferences. In summary, existing methods fail to obtain a single
LLM policy that aligns with human preferences in the original game. The
reliance on multiple LLMs as proxies leads to inefficiency and high
cost ([Swamy et al., 2024](#bib.bib52); [Wu et al., 2024](#bib.bib64);
[Rosset et al., 2024](#bib.bib46)), while various approximation methods
result in misalignment ([Munos et al., 2023](#bib.bib36); [Calandriello
et al., 2024](#bib.bib10); [Zhang et al., 2024](#bib.bib68)). These
limitations collectively represent the core challenges in preference
alignment of LLMs.

![Refer to caption](2410.16714v3/figures/main.png)

Figure 2: An illustration of MPO and its background. Non-transitive
preferences are prevalent across diverse populations, necessitating a
more generalized preference model that frames the alignment problem as a
two-player constant-sum game. Existing methods either converge to the NE
of a regularized game or require maintaining multiple models. In
contrast, MPO achieves last-iterate convergence to the original NE,
aligning with diverse human preferences using only a single model.

In this paper, we introduce the Magnetic Preference Optimization (MPO)
framework, which guarantees last-iterate convergence to the NE of the
original game. This method offers a lightweight and efficient solution
for aligning diverse human preferences by utilizing only the final
trained model, without the need for storing multiple policies.
Specifically, we adapt the insight of Magnetic Mirror Descent
(MMD) ([Sokota et al., 2022](#bib.bib51)) to the RLHF context to derive
MPO and further established theoretical guarantees for convergence to
the original NE. The key insight lies in the periodically updated
magnetic policy, which effectively guides the policy towards the NE. Our
results show that MPO achieves last-iterate convergence at a
significantly faster rate than standard Mirror Descent (MD), with
empirical evaluations demonstrating substantial improvements in LLM
performance, further emphasizing the potential of self-play methods for
preference alignment.

## 2 Preliminaries

We consider a Large Language Model (LLM) denoted by $`\pi\in\Pi`$ and
parametrized by $`\theta\in\Theta`$. The model receives a prompt
$`\mathbf{x}=[x_{1},\ldots,x_{n}]`$, and generates a corresponding
output sequence $`\mathbf{y}=[y_{1},\ldots,y_{m}]`$. The output
$`\mathbf{y}`$ is sampled from the conditional probability distribution
$`\pi(\cdot\mid\mathbf{x})`$. In LLMs, $`x_{i}`$ and $`y_{i}`$ represent
individual tokens from a predetermined vocabulary $`\mathcal{V}`$. The
model generates tokens autoregressively, producing each token
sequentially based on the input and all previously generated tokens.
This autoregressive property allows us to decompose the conditional
probability as

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\pi(\mathbf{y}\mid\mathbf{x})=\prod_{t=1}^{T}\pi(y_{t}\mid\mathbf{x},\mathbf{y}_{<t}),
``` |  | (1) |

where $`\mathbf{y}_{<t}=[y_{1},\ldots,y_{t-1}]`$ for $`t>1`$, and
$`\mathbf{y}_{<1}`$ is an empty sequence.

### 2.1 Token-level MDP Formulation for LLMs

We frame the RLHF problem as a Markov decision process (MDP) ([Puterman,
2014](#bib.bib43)), defined by the tuple
$`\mathcal{M}=(\mathcal{S},\mathcal{A},\mathcal{P},\mathcal{R},\rho,T)`$.
In this formulation, $`\mathcal{S}`$ represents the state space, where
each state $`s_{t}=[\mathbf{x},\mathbf{y}_{<t}]`$ includes the prompt
$`\mathbf{x}`$ and all response tokens produced up to that point. The
action space $`\mathcal{A}`$ consists of possible tokens, where each
action $`a_{t}=y_{t}`$ represents a token from the vocabulary
$`\mathcal{V}`$. The policy $`\pi:\mathcal{S}\to\Delta(\mathcal{A})`$
maps states to distributions over actions. The transition kernel
$`\mathcal{P}:\mathcal{S}\times\mathcal{A}\to\Delta(\mathcal{S})`$
describes the dynamics of the environment. In the context of LLMs, this
transition is deterministic: given
$`s_{t}=[\mathbf{x},\mathbf{y}_{<t}]`$ and $`a_{t}=y_{t}`$, the
environment will transition to
$`s_{t+1}=[\mathbf{x},\mathbf{y}_{<t+1}]`$ with probability 1. The
token-wise reward function
$`R:\mathcal{S}\times\mathcal{A}\to\mathbb{R}`$ is defined as
$`R_{t}:=R(s_{t},a_{t})=R([\mathbf{x},\mathbf{y}_{<t}],y_{t})`$. The
accumulative reward for the generated text is
$`\sum_{t=1}^{T}\gamma^{t-1}R([\mathbf{x},\mathbf{y}_{<t}],y_{t})`$. The
initial state distribution $`\rho`$ is determined by the distribution of
input prompts, while $`T`$ denotes the maximal interaction steps,
characterizing the length limit for outputs.

### 2.2 Two-Player Constant-Sum Games and Mirror Descent

We consider a constant-sum game where the sum of payoffs for any outcome
remains constant. Let $`\mathcal{I}=\{1,2\}`$ represent a set of two
players, and $`\Pi_{i}\subset\mathbb{R}^{i}`$ denote the compact, convex
strategy space for player $`i`$. The joint strategy space $`\Pi`$ is
defined as $`\times_{i\in\mathcal{I}}\Pi_{i}`$. The strategy of player
$`i`$ is denoted by $`\pi_{i}\in\Pi_{i}`$, while the strategies of all
other players, denoted by $`\pi_{-i}`$, lie in
$`\Pi_{-i}\coloneqq\times_{j\in\mathcal{I}\setminus\{i\}}\Pi_{j}`$,
where $`-i`$ refers to all players except player $`i`$. Each player
$`i`$ has a continuous payoff function $`f_{i}:\Pi\to\mathbb{R}`$. In a
two-player constant-sum normal-form game, both players simultaneously
choose their strategies, $`\pi_{1}\in\Pi_{1}`$ and
$`\pi_{2}\in\Pi_{2}`$, respectively. The payoff for player $`i`$ is then
given by $`f_{i}(\pi_{i},\pi_{-i})`$, where the sum of the payoffs
satisfies $`\sum_{i\in\mathcal{I}}f_{i}(\pi_{i},\pi_{-i})=c`$, with
$`c\in\mathbb{R}`$ being a constant.

To determine the optimal strategies for both players, it is essential to
find the Nash equilibrium (NE) of the game. An NE is a strategy profile
$`(\pi_{1}^{*},\pi_{2}^{*})`$ such that neither player can improve their
payoff by unilaterally deviating from it:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
f(\pi_{1},\pi_{2}^{*})\leq f(\pi_{1}^{*},\pi_{2}^{*})\leq f(\pi_{1}^{*},\pi_{2}),\quad\forall(\pi_{1},\pi_{2})\in\Pi.
``` |  | (2) |

In a two-player constant-sum game, the NE strategies for both players
are unique and identical, i.e.,
$`\pi_{1}^{*}=\pi_{2}^{*}=\pi^{*}`$ ([Zhang et al., 2024](#bib.bib68);
[Ye et al., 2024](#bib.bib65); [Swamy et al., 2024](#bib.bib52)). Given
the monotonicity of the game (i.e., $`f`$ is convex-concave), it is well
known that finding the NE is equivalent to solving the associated
Variational Inequality (VI) problem ([Mertikopoulos & Zhou,
2019](#bib.bib33); [Sokota et al., 2022](#bib.bib51)). Formally, let
$`F`$ be the monotone operator defined as
$`F(\pi)=(\nabla_{\pi_{1}}f(\pi_{1},\pi_{2}),-\nabla_{\pi_{2}}f(\pi_{1},\pi_{2}))^{T}`$.
The NE $`\pi^{*}`$ is a solution to the VI problem
$`\operatorname{VI}(\Pi,F)`$, which requires finding $`\pi^{*}\in\Pi`$
such that:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\langle F(\pi^{*}),\pi-\pi^{*}\rangle\geq 0,\quad\forall\pi\in\Pi.
``` |  | (3) |

To measure the distance from a given strategy profile $`\pi`$ to the NE,
we define the duality gap ([Wei et al., 2020](#bib.bib62); [Abe et al.,
2024](#bib.bib1)) as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\epsilon(\pi)\coloneqq\max_{\pi^{\prime}\in\Pi}\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{i},\pi_{-i}),\pi_{i}^{\prime}-\pi_{i}\rangle.`$ |  | (4) |

Mirror Descent (MD) ([Beck & Teboulle, 2003](#bib.bib7); [Beck,
2017](#bib.bib6)) is a first-order optimization algorithm capable of
solving such games. The update rule for MD applied to player $`i`$ is
given by:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi^{k+1}=\argmin_{\pi\in\Pi}\left\{\langle F(\pi^{k}),\pi\rangle+\frac{1}{\eta}B_{\psi}(\pi,\pi^{k})\right\},
``` |  | (5) |

where $`\eta>0`$ is the learning rate, and
$`B_{\psi}(\pi,\pi^{\prime})=\psi(\pi)-\psi(\pi^{\prime})-\langle\nabla\psi(\pi^{\prime}),\pi-\pi^{\prime}\rangle`$
is the Bregman divergence associated with a strongly convex function
$`\psi`$. In a two-player constant-sum game, if both players follow the
MD update rule, the algorithm achieves average-iterate convergence to
the Nash equilibrium (NE). Formally, average-iterate convergence is
defined as follows:

###### Definition 2.1 (Average-Iterate Convergence).

Given a non-empty set of equilibria $`\Pi^{*}\subset\Pi`$, a sequence
$`\{\pi^{k}\}_{k\geq 1}`$ is said to exhibit average-iterate convergence
if $`\bar{\pi}^{k}`$ converges to some $`\pi^{*}\in\Pi^{*}`$ as
$`K\to\infty`$, where
$`\bar{\pi}^{k}=\frac{1}{K}\sum_{k=1}^{K}\pi^{k}`$.

### 2.3 RLHF with Bradley-Terry Model

In the standard RLHF pipeline, where the true reward function $`r`$ is
unknown, a reward model $`r_{\phi}`$ parameterized by $`\phi`$ is
trained using a dataset
$`\mathcal{D}={(\mathbf{x},\mathbf{y}_{w},\mathbf{y}_{l})}`$, where
$`\mathbf{y}_{w}`$ represents the preferred response over
$`\mathbf{y}_{l}`$. The distribution of the preference dataset is
assumed to follow the Bradley-Terry (BT) model ([Bradley & Terry,
1952](#bib.bib8); [Christiano et al., 2017](#bib.bib15))

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbb{P}_{\phi}(\mathbf{y}_{w}\succ\mathbf{y}_{l}|\mathbf{x})=\frac{\exp(r_{\phi}(\mathbf{x},\mathbf{y}_{w}))}{\exp(r_{\phi}(\mathbf{x},\mathbf{y}_{w}))+\exp(r_{\phi}(\mathbf{x},\mathbf{y}_{l}))}=\sigma(r_{\phi}(\mathbf{x},\mathbf{y}_{w})-r_{\phi}(\mathbf{x},\mathbf{y}_{l})),`$ |  | (6) |

where $`\sigma=1/(1+\exp(-\mathbf{x}))`$ is the sigmoid function. Based
on the dataset $`\mathcal{D}`$, the reward model is trained by
minimizing the negative log-likelihood
of equation [6](#S2.E6 "In 2.3 RLHF with Bradley-Terry Model ‣ 2 Preliminaries ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathcal{L}(r_{\phi})=-\mathbb{E}_{(\mathbf{x},\mathbf{y}_{w},\mathbf{y}_{l})\sim\mathcal{D}}[\log\sigma(r_{\phi}(\mathbf{x},\mathbf{y}_{w})-r_{\phi}(\mathbf{x},\mathbf{y}_{l}))].`$ |  | (7) |

Given the trained reward model $`r_{\phi}`$, online RL algorithms,
typically PPO ([Schulman et al., 2017](#bib.bib47)) are leveraged to
optimized the following objective

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\max_{\pi}\mathbb{E}_{\mathbf{x}\sim\mathcal{D},\mathbf{y}\sim\pi(\cdot\mid x)}[r_{\phi}(\mathbf{x},\mathbf{y})]-\alpha D_{\mathrm{KL}}[\pi(\cdot\mid\mathbf{x})\|\pi_{\text{ref}}(\cdot\mid\mathbf{x})],`$ |  | (8) |

where $`\alpha>0`$ controls the strength of KL penalty. The
KL-regularized objective (li2024entropic) is widely adopted to prevent
from deviating too much from the reference policy ([Ziegler et al.,
1909](#bib.bib70); [Liu et al., 2020](#bib.bib31); [Ouyang et al.,
2022](#bib.bib39); [Zheng et al., 2023](#bib.bib69)).

### 2.4 RLHF with General Preference

Although the BT model has been widely adopted in RLHF for modeling human
preferences, it has many limitations, including independence of
comparisons, linearity of preferences, transitivity and so on ([Shah
et al., 2016](#bib.bib49); [Lanctot et al., 2023](#bib.bib28)). Recent
works ([Munos et al., 2023](#bib.bib36); [Swamy et al.,
2024](#bib.bib52)) propose modeling the RLHF problem as a symmetric
two-player constant-sum game. This approach introduces a preference
model $`\mathcal{P}(\mathbf{y}_{1}\succ\mathbf{y}_{2}\mid\mathbf{x})`$,
which defines the preference between two policies as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathcal{P}(\pi_{1}\succ\pi_{2})=\mathbb{E}_{\mathbf{x}\sim\mathcal{D},\mathbf{y}_{1}\sim\pi_{1},\mathbf{y}_{2}\sim\pi_{2}}[\mathcal{P}(\mathbf{y}_{1}\succ\mathbf{y}_{2}\mid\mathbf{x})].`$ |  | (9) |

Typically, leveraging the capability of LLMs as next-token predictors
for preference modeling ([Dong et al., 2024](#bib.bib19); [Munos et al.,
2023](#bib.bib36); [Jiang et al., 2023](#bib.bib25)). The preference
model can be trained via a cross entropy loss

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}(\mathcal{P})=-\mathbb{E}_{(\mathbf{x},\mathbf{y}_{1},\mathbf{y}_{2})\sim\mathcal{D}}[\log\mathcal{P}(\mathbf{y}_{1}\succ\mathbf{y}_{2}\mid\mathbf{x})],
``` |  | (10) |

where $`\mathcal{D}`$ is the dataset of annotated preference pairs.
Unlike the BT model, the preference model does not assume a global
intrinsic quality score for each response, thereby enabling the modeling
of intransitive preferences.

Given the preference model, the NE of this game is defined as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi^{*}=\arg\max_{\pi_{1}}\min_{\pi_{2}}\mathcal{P}(\pi_{1}\succ\pi_{2}).
``` |  | (11) |

Intuitively, this NE represents a policy that minimizes the worst-case
scenario of dissatisfaction and satisfies a variety of desirable
consistency properties in social choice theory ([Swamy et al.,
2024](#bib.bib52)).

## 3 Magnetic Preference Optimization

In this section, we introduce the Magnetic Preference Optimization (MPO)
algorithm based on Magnetic Mirror Descent (MMD) ([Sokota et al.,
2022](#bib.bib51)), which enjoys a theoretical guarantee for
last-iterate convergence to the Nash equilibrium (NE) of the game.

### 3.1 Magnetic Mirror Descent

While the game defined
in equation [11](#S2.E11 "In 2.4 RLHF with General Preference ‣ 2 Preliminaries ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
can be solved when both players employ Mirror Descent (MD) ([Swamy
et al., 2024](#bib.bib52)), only the average-sequence
$`\{\bar{\pi}^{k}\}_{k\geq 1}`$ converges to the NE, where
$`\bar{\pi}^{k}=\frac{1}{K}\sum_{k=1}^{K}\pi^{k}`$. The actual sequence
$`\{\pi^{k}\}_{k\geq 1}`$, as is shown in
Figure [3](#S3.F3 "Figure 3 ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
does not converge and cycles around the NE ([Mertikopoulos et al.,
2018b](#bib.bib35); [Mertikopoulos et al., 2018a](#bib.bib34); [Perolat
et al., 2021](#bib.bib41)).

![Refer to caption](2410.16714v3/figures/cycle.png)

Figure 3: MD and MMD.

In the context of LLMs, this limitation poses significant practical
challenges. Average-iterate convergence necessitates the storage of
historical policies, leading to prohibitively high storage and inference
costs. This limitation raises a key question: *can we devise an
algorithm that achieves last-iterate convergence, thereby circumventing
the need for storing and averaging over historical policies?*

One solution to this problem is Magnetic Mirror Descent (MMD) ([Sokota
et al., 2022](#bib.bib51)). To better understand MMD, we first define
last-iterate convergence.

###### Definition 3.1 (Last-Iterate Convergence).

Consider nonempty set of equilibria $`\Pi^{*}\subset\Pi`$, we say that a
sequence $`\{\pi^{k}\}_{k\geq 1}`$ exhibits last-iterate convergence if
$`\pi^{k}`$ converges to $`\pi^{*}\in\Pi^{*}`$ as $`k\to\infty`$.

Compared to MD, MMD introduces an additional magnetic term. Formally,
the MMD update rule can be expressed as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\pi^{k+1}\in\arg\min_{\pi\in\Pi}\{\langle F(\pi^{k}),\pi\rangle+\alpha B_{\psi}(\pi;\pi_{\text{ref}})+\frac{1}{\eta}B_{\psi}(\pi;\pi^{k})\},`$ |  | (12) |

where $`\pi_{\text{ref}}`$ is the magnet, which means $`\pi^{k+1}`$ is
attracted to either $`\min_{\pi\in\Pi}\psi(\pi)`$ or
$`\pi_{\text{ref}}`$, $`\alpha`$ is the regularization temperature,
$`\eta`$ is the learning rate. In contrast to MD, MMD solves the
regularized game

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\min_{\pi_{1}\in\Pi_{1}}\max_{\pi_{2}\in\Pi_{2}}\alpha g(\pi_{1})+f(\pi_{1},\pi_{2})-\alpha g(\pi_{2}),
``` |  | (13) |

where $`f`$ and $`g`$ are both convex functions and $`g`$ can be taken
either $`\psi`$ or $`B_{\psi}(\cdot;\pi_{\mathrm{ref}})`$ for some
$`\pi_{\mathrm{ref}}`$. Let $`\pi_{r}^{*}`$ be the solution
of equation [13](#S3.E13 "In 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment").
This problem corresponds to the following $`\operatorname{VI}`$ problem
$`\operatorname{VI}(\Pi,F+\nabla g)`$

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\langle F(\pi_{r}^{*})+\nabla g(\pi_{r}^{*}),\pi-\pi_{r}^{*}\rangle\geq 0,\quad\forall\pi\in\Pi.`$ |  | (14) |

The key advantage of MMD lies in its ability to achieve linear
last-iterate convergence to the NE of the regularized game. This
property is formally stated in the following theorem [Sokota et al.
(2022)](#bib.bib51):

###### Theorem 3.2 (Theorem 3.4, ([Sokota et al., 2022](#bib.bib51))).

Consider the MMD update rule in
equation [12](#S3.E12 "In 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment").
Assume $`\pi^{k+1}\in\operatorname{int}\operatorname{dom}\psi`$ and
$`\Pi`$ is bounded, $`F`$ is monotone and L-smooth with respect to
$`\|\cdot\|`$, $`g`$ is 1-strongly convex relative to $`\psi`$ over
$`\Pi`$ with $`g`$ differentiable over
$`\operatorname{int}\operatorname{dom}\psi`$. Then the sequence
$`\{\pi^{k}\}_{k\geq 1}`$ generated by MMD exhibits linear last-iterate
convergence to the solution $`\pi_{r}^{*}`$ if
$`\eta\leq\frac{\alpha}{L^{2}}`$. Specifically,

|  |  |  |
|----|----|----|
|  |
``` math
B_{\psi}(\pi_{r}^{*};\pi^{k+1})\leq B_{\psi}(\pi_{r}^{*};\pi^{1})\left(\frac{1}{1+\eta\alpha}\right)^{k},
``` |  |

where $`\alpha>0`$ is the regularization temperature and $`\eta>0`$ is
the learning rate.

Theorem [3.2](#S3.Thmtheorem2 "Theorem 3.2 (Theorem 3.4, ( , )). ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
demonstrates that when both players follow the MMD update rule
in equation [12](#S3.E12 "In 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
their policies converge to the NE $`\pi_{r}^{*}`$ of the regularized
game with a last-iterate convergence rate of
$`O((1/(1+\eta\alpha))^{k})`$. This property is particularly valuable in
the context of LLMs, as it eliminates the need for storing and averaging
over historical policies, and achieves much faster convergence rate than
vanilla MD, which converges at $`O(1/\sqrt{k})`$ ([Beck,
2017](#bib.bib6)). This substantially reducing computational and storage
requirements.

### 3.2 Convergence to the Nash Equilibrium of the Original Game

While
Theorem [3.2](#S3.Thmtheorem2 "Theorem 3.2 (Theorem 3.4, ( , )). ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
establishes the last-iterate convergence property of MMD, it only
converges to the NE of the regularized game, not the original one. As is
illustrated in
Figure [3](#S3.F3 "Figure 3 ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
increasing the regularization strength accelerates MMD convergence, but
simultaneously causes the learned NE to deviate further from the NE of
the original game. This deviation potentially leads to a equilibrium
that fails to accurately reflect the true human preferences.
Consequently, we face a crucial challenge: *how can we achieve
last-iterate convergence to the NE of the original game defined
in equation [11](#S2.E11 "In 2.4 RLHF with General Preference ‣ 2 Preliminaries ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")*?

Formally, we define the $`n`$-th regularized game as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle J_{n}(\pi_{1},\pi_{2})=\min_{\pi_{1}\in\Pi_{1}}\max_{\pi_{2}\in\Pi_{2}}\mathcal{P}(\pi_{1}\succ\pi_{2})+\alpha D_{\mathrm{KL}}(\pi_{1}\|\pi_{r}^{*,n-1})-\alpha D_{\mathrm{KL}}(\pi_{2}\|\pi_{r}^{*,n-1}),`$ |  | (15) |

where $`\pi_{r}^{*,n-1}`$ is the NE of the $`(n-1)`$-th regularized
game. Intuitively, as the number of iterations increases, we expect the
sequence of regularized NEs, $`\{\pi_{r}^{*,n}\}_{n\geq 1}`$, to
converge to the original NE $`\pi^{*}`$. This intuition is formalized in
the following theorem.

###### Lemma 3.3.

Let $`\{\pi_{r}^{*,n}\}_{n\geq 1}`$ be the sequence of NEs of the
regularized games generated by iteratively solving
equation [15](#S3.E15 "In 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
where $`\pi_{r}^{*,1}`$ is an arbitrary initial reference policy in the
interior of $`\Pi`$. For any $`n\geq 1`$, if
$`\pi_{r}^{*,n}\in\Pi\notin\Pi^{*}`$, we have

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n+1})<\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n}).
``` |  | (16) |

Otherwise, if $`\pi_{r}^{*,n}\in\Pi^{*}`$, then
$`\pi_{r}^{*,n+1}=\pi_{r}^{*,n}\in\Pi^{*}`$.

###### Theorem 3.4.

If
Lemma [3.3](#S3.Thmtheorem3 "Lemma 3.3. ‣ 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
holds, the sequence $`\{\pi_{r}^{*,n}\}_{n\geq 1}`$ converges to the NE
$`\pi^{*}\in\Pi^{*}`$ of the original game defined
in equation [11](#S2.E11 "In 2.4 RLHF with General Preference ‣ 2 Preliminaries ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
as $`n\to\infty`$.

Theorem [3.4](#S3.Thmtheorem4 "Theorem 3.4. ‣ 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
suggests a two-stage convergence process for MMD to reach the NE of the
original game. First, as established in
Theorem [3.2](#S3.Thmtheorem2 "Theorem 3.2 (Theorem 3.4, ( , )). ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
MMD achieves linear last-iterate convergence to the NE of each
regularized game. Then, by iteratively updating the magnet policy to the
most recent regularized NE, we guide the sequence of regularized NEs
$`\{\pi_{r}^{*,n}\}_{n\geq 1}`$ towards the NE $`\pi^{*}`$ of the
original game ([Meng et al., 2023](#bib.bib32); [Perolat et al.,
2021](#bib.bib41)). Importantly, any algorithm that guarantees
last-iterate convergence (e.g., Nash-MD ([Munos et al.,
2023](#bib.bib36))) can be employed to solve the regularized games.
Additionally,
Theorem [F.4](#A6.Thmtheorem4 "Theorem F.4. ‣ Appendix F Duality Gap and Convergence Rate ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
extends the analysis to scenarios where only an approximate solution to
$`\pi_{r}^{*,n}`$ is obtained.

### 3.3 Practical Implementation

We now describe how to adapt these theoretical insights into a
practical, computationally efficient algorithm for RLHF with general
preference models.

In the context of RLHF, the MMD update rule
in equation [12](#S3.E12 "In 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
can be expressed as:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\pi^{k+1}=\arg\max_{\pi\in\Pi}\mathbb{E}_{\mathbf{x}\sim\rho,\mathbf{y}_{1}\sim\pi,\mathbf{y}_{2}\sim\pi_{\text{ref}}}[A^{k}(\mathbf{x},\mathbf{y}_{1},\mathbf{y}_{2})]-\alpha D_{\mathrm{KL}}(\pi\|\pi_{\text{ref}})-\frac{1}{\eta}D_{\mathrm{KL}}(\pi\|\pi^{k}),`$ |  | (17) |

where $`A^{k}`$ denotes the advantage function. To compute $`A^{k}`$, we
assign the preference
$`\mathcal{P}(\mathbf{y}_{1}\succ\mathbf{y}_{2}\mid\mathbf{x})`$ between
two responses $`\mathbf{y}_{1}`$ and $`\mathbf{y}_{2}`$ as the
token-level reward $`R_{t}`$. The advantage function is then calculated
via REINFORCE ([Williams, 1992](#bib.bib63)), where the baseline can be
computed using ReMax ([Li et al., 2023](#bib.bib29)) or
Leave-One-Out ([Kool et al., 2019](#bib.bib26); [Ahmadian et al.,
2024](#bib.bib3)). The KL divergence
in equation [17](#S3.E17 "In 3.3 Practical Implementation ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
between two LLM policies $`\pi_{1}`$ and $`\pi_{2}`$ is estimated as:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle D_{\mathrm{KL}}(\pi_{1}\|\pi_{2})=\sum_{t=1}^{T}D_{\mathrm{KL}}(\pi_{1}(\cdot\mid[\mathbf{x},\mathbf{y}_{<t}])\|\pi_{2}(\cdot\mid[\mathbf{x},\mathbf{y}_{<t}])).`$ |  | (18) |

This estimation, also known as the sequential KL divergence ([Zeng
et al., 2024](#bib.bib67)), has shown effective in controlling the KL
divergence between two LLM policies. The optimization objective
in equation [17](#S3.E17 "In 3.3 Practical Implementation ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
can be written in parameter space $`\Theta`$ as:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\max_{\theta}\Psi^{\text{MMD}}(\theta)=\max_{\theta}\mathbb{E}_{\mathbf{x}\sim\mathcal{D}}\Big[\mathbb{E}_{\mathbf{y}_{1}\sim\pi_{\theta},\mathbf{y}_{2}\sim\pi_{\theta^{\prime}}}\big[A_{\theta^{k}}(\mathbf{x},\mathbf{y}_{1},\mathbf{y}_{2})\big]-\alpha D_{\mathrm{KL}}(\pi_{\theta}\|\pi_{\theta^{\prime}})-\frac{1}{\eta}D_{\mathrm{KL}}(\pi_{\theta}\|\pi_{\theta^{k}})\Big].
``` |  | (19) |

To optimize this objective, we draw inspiration from Mirror Descent
Policy Optimization (MDPO) ([Tomar et al., 2020](#bib.bib57)), which
provides an RL implementation of MD, making it suitable for our
algorithm. Similar to MDPO, we take multiple gradient steps at each
iteration $`k`$ to ensure trust region constraints and introduce an
annealed stepsize, $`\eta^{k}=1-k/T_{k}`$, where $`T_{k}`$ is the
maximum number of iterations. These considerations culminate in our MPO
algorithm, detailed in
Algorithm [1](#alg1 "Algorithm 1 ‣ A.1 MPO ‣ Appendix A Pseudocode and Implementation Details ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment").

An important aspect of MMD is that it is equivalent to solving the
regularized objective
in equation [13](#S3.E13 "In 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
using standard MD with a specific stepsize ([Sokota et al.,
2022](#bib.bib51)), as formalized in the following theorem.

###### Theorem 3.5 (Proposition D.7, ([Sokota et al., 2022](#bib.bib51))).

The update rule of MMD
in equation [12](#S3.E12 "In 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
is equivalent to the following rule:

|  |  |  |
|----|----|----|
|  |
``` math
\pi^{k+1}\in\arg\min_{\pi\in\Pi}\left\{\langle F(\pi^{k})+\alpha\nabla_{\pi^{k}}B_{\psi}(\pi^{k};\pi_{\mathrm{ref}}),\pi\rangle+\frac{1}{\bar{\eta}}B_{\psi}(\pi;\pi^{k})\right\},
``` |  |

where the stepsize is defined as
$`\bar{\eta}=\frac{\eta}{1+\eta\alpha}`$.

This theorem establishes a connection between MMD and MD, showing that
MMD can be seen as a special case of MD with an adjusted gradient and
stepsize. This insight allows us to derive a theoretically equivalent
algorithm, which we refer to as MPO-RT (i.e., Reward
Transformation ([Perolat et al., 2021](#bib.bib41); [Perolat et al.,
2022](#bib.bib42); [Meng et al., 2023](#bib.bib32))). In contrast to
MPO, MPO-RT enforces a hard constraint on KL divergence by directly
modifying the reward function. This approach aligns with the idea of
standard RLHF methods ([Orabona, 2019](#bib.bib38); [Ouyang et al.,
2022](#bib.bib39); [Zheng et al., 2023](#bib.bib69)). Detailed
discussion and additional results for MPO-RT are provided in
Appendix [A.2](#A1.SS2 "A.2 MPO-RT ‣ Appendix A Pseudocode and Implementation Details ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment").

Although the theoretical framework requires simultaneous updates for
both players to converge to the NE, this presents practical challenges
in RLHF due to the added memory costs. By leveraging the symmetry of the
game, we can simplify the approach by requiring only a single player to
play against its own iterates ([Swamy et al., 2024](#bib.bib52); [Ye
et al., 2024](#bib.bib65)).

Another challenge arises from
Theorem [3.4](#S3.Thmtheorem4 "Theorem 3.4. ‣ 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
which implies that convergence to the NE of the original game requires
periodically updating the reference policy with the NE of the previous
regularized game. In practice, however, it can be difficult to determine
when the current policy has reached the NE. Therefore, we update the
reference policy every $`\tau`$ iteration, when a predefined number of
iterations $`T_{k}`$ is reached ([Abe et al., 2024](#bib.bib1)), i.e.,
$`\pi_{r}^{\tau}=\pi^{\tau T_{k}}`$. In this case, the convergence rate
to the NE of the regularized game depends on the value of $`T_{k}`$.
Formally, we present the following lemma.

###### Lemma 3.6.

Consider the sequence $`\{\pi_{r}^{\tau}\}_{\tau\geq 1}`$ generated by
the update rule
in equation [17](#S3.E17 "In 3.3 Practical Implementation ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
where the reference policy $`\pi_{r}^{\tau}`$ is updated every $`T_{k}`$
iterations as $`\pi_{r}^{\tau}=\pi^{\tau T_{k}}`$. Assume
$`\pi_{r}^{\tau}\in\operatorname{int}\operatorname{dom}\psi`$, and that
$`\mathcal{P}`$ is monotone and L-smooth with respect to $`\|\cdot\|`$.
Then, the sequence $`\{\pi_{r}^{\tau}\}_{\tau\geq 1}`$ satisfies:

|  |  |  |
|----|----|----|
|  |
``` math
D_{\mathrm{KL}}(\pi_{r}^{*}\|\pi_{r}^{\tau+1})\leq D_{\mathrm{KL}}(\pi_{r}^{*}\|\pi_{r}^{\tau})\left(\frac{1}{1+\eta\alpha}\right)^{T_{k}},
``` |  |

where $`\alpha>0`$ is the regularization temperature, and $`\eta>0`$ is
the learning rate.

Lemma [3.6](#S3.Thmtheorem6 "Lemma 3.6. ‣ 3.3 Practical Implementation ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
implies that when the update interval $`T_{k}`$ is sufficiently large,
$`\pi_{r}^{\tau+1}`$ closely approximates $`\pi_{r}^{*}`$. Based on this
result, we derive the following theorem.

###### Theorem 3.7.

If
Lemma [3.6](#S3.Thmtheorem6 "Lemma 3.6. ‣ 3.3 Practical Implementation ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
holds, the sequence $`\{\pi_{r}^{\tau}\}_{\tau\geq 1}`$ converges to
$`\pi^{*}`$ as $`\tau\to\infty`$, where $`\pi^{*}`$ is the Nash
equilibrium of the original game defined
in equation [11](#S2.E11 "In 2.4 RLHF with General Preference ‣ 2 Preliminaries ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment").

In practice, as detailed in
Algorithm [1](#alg1 "Algorithm 1 ‣ A.1 MPO ‣ Appendix A Pseudocode and Implementation Details ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
we simultaneously replace both the opponent and the reference policy
with the current policy $`\pi^{k}`$ every $`T_{k}`$ iterations. This
implementation reduces storage requirements by maintaining only one
additional model, while capturing the key insight of
Theorem [3.4](#S3.Thmtheorem4 "Theorem 3.4. ‣ 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
by periodically updating the reference policy.

## 4 Experiments

In this section, we conduct comprehensive experiments to validate the
effectiveness of our proposed MPO algorithm. We start by focusing on
safety as the primary alignment metric. Since safety is a single,
well-defined dimension, it provides a clear and straightforward way to
evaluate the algorithm’s ability to align with human preferences. We
then extend the evaluation to the model’s general capabilities, offering
a more complex, multi-dimensional analysis. This broader evaluation
explores MPO’s scalability and examines how specific abilities improve
or decline during self-play, providing deeper insights into the
strengths and limitations of self-play methods in alignment.

Table [3](#S4.T3 "Table 3 ‣ 4.2 General Capability Alignment and Analysis ‣ 4 Experiments ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
show consistent improvement in average scores. Iteration 4 outperforms
earlier iterations in several key benchmarks, including IFEval, BBH, and
MMLU PRO, highlighting the model’s enhanced ability to handle reasoning
and general knowledge tasks. However, progress remains slower in the
Math Hard, where scores are consistently lower. This suggests that while
MPO iterations are becoming more robust overall, further optimization is
needed for specialized tasks like complex mathematical reasoning.

## 5 Related Work

Bradley-Terry Model Based RLHF. RLHF has seen significant success in
aligning LLMs with human preferences ([Ouyang et al., 2022](#bib.bib39);
[Peng et al., 2023](#bib.bib40); [Achiam et al., 2023](#bib.bib2)).
Classical RLHF methods typically scalarize human preferences into
rewards ([Zheng et al., 2023](#bib.bib69); [Wang et al.,
2024](#bib.bib60); [Dong et al., 2024](#bib.bib19); xiao2024algorithmic)
and optimize a KL-regularized objective using PPO ([Schulman et al.,
2017](#bib.bib47)). To streamline the RLHF process, Direct Preference
Optimization (DPO) ([Rafailov et al., 2024](#bib.bib44)) directly learns
a policy from preference datasets. Extensions like Online DPO ([Dong
et al., 2024](#bib.bib19); [Tang et al., 2024](#bib.bib54); [Chen
et al., 2024](#bib.bib13)) enhance DPO’s performance by adopting an
iterative learning approach. However, all these methods are
fundamentally based on the Bradley-Terry (BT) model ([Bradley & Terry,
1952](#bib.bib8)), which assumes transitivity in human preferences—a
limitation that has been noted in the literature ([Cattelan,
2012](#bib.bib11); [Swamy et al., 2024](#bib.bib52); [Munos et al.,
2023](#bib.bib36)). In contrast, we explore a more general preference
model and adopt a game-theoretic approach to better capture the
complexity of human preferences.

RLHF as a Two-Player Constant-Sum Game. To address the limitations of
the BT model, recent research has proposed reformulating the RLHF
problem as a two-player constant-sum game ([Munos et al.,
2023](#bib.bib36); [Swamy et al., 2024](#bib.bib52); [Chen et al.,
2024](#bib.bib13)). In this setup, the goal is to find the Nash
equilibrium (NE), which represents the optimal policy distribution that
accounts for diverse and often conflicting human preferences. Following
this framework, Self-play Preference Optimization (SPO) ([Swamy et al.,
2024](#bib.bib52)) learns the NE of the original game through MD. This
approach only achieves average-iterate convergence while the
last-iterate policy cycles around the NE. In contrast, our method
achieves last-iterate convergence. Nash Learning from Human Feedback
(NLHF) ([Munos et al., 2023](#bib.bib36)) learns the NE of the
KL-regularized game through Mirror Descent (MD) ([Beck & Teboulle,
2003](#bib.bib7); [Beck, 2017](#bib.bib6)). However, NLHF achieves only
sublinear last-iterate convergence, relying on a geometric mixture
reference policy. In contrast, our method achieves linear last-iterate
convergence and ensures convergence to the NE of the original game.
Another line of work seeks to directly learn the NE over a preference
dataset, these methods either only guarantees average-iterate
convergence ([Wu et al., 2024](#bib.bib64); [Rosset et al.,
2024](#bib.bib46)) or only achieves last-iterate convergence of the NE
of the regularized game ([Calandriello et al., 2024](#bib.bib10); [Zhang
et al., 2024](#bib.bib68)).

## 6 Conclusion

This paper introduced Magnetic Preference Optimization (MPO), a novel
framework for aligning Large Language Models (LLMs) with human
preferences through self-play. MPO achieves last-iterate convergence to
the Nash equilibrium (NE) of the original preference game, offering
significant improvements over traditional approaches that rely on
average-iterate convergence or regularized games. Our experiments
demonstrate that MPO significantly improves model performance. Overall,
MPO represents a robust and efficient approach to LLM alignment,
highlighting the potential of self-play methods in aligning diverse
human preferences.

## Appendix A Pseudocode and Implementation Details

In this section, we present the pseudocode and implementation details
for our proposed MPO and MPO-RT algorithms. Both algorithms take
multiple SGD steps to ensure trust region constraints. The key
difference lies in how they handle KL regularization: MPO employs a KL
loss to prevent significant deviation from the reference policy, while
MPO-RT modifies the reward directly. The baseline $`b`$ can be computed
using ReMax ([Li et al., 2023](#bib.bib29)), Leave-One-Out ([Ahmadian
et al., 2024](#bib.bib3)), or simply set to 1/2 as suggested in ([Munos
et al., 2023](#bib.bib36)). In our experiments, we adopt ReMax for both
algorithms due to its ability to provide a strong baseline with only one
additional sample.

### A.1 MPO

The pseudocode of MPO is provided in
Algorithm [1](#alg1 "Algorithm 1 ‣ A.1 MPO ‣ Appendix A Pseudocode and Implementation Details ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment").

$`\mathcal{P}_{\phi}`$, dataset $`\mathcal{D}`$ of prompts,
regularization temperature $`\alpha`$, learning rate $`\eta`$, update
interval $`T_{k}`$, max iterations $`K`$

2: Reference policy $`\pi_{\theta^{\prime}}\leftarrow\pi_{\theta}`$,
$`k\leftarrow 0`$, $`\tau\leftarrow 0`$

3: for $`k=1,\ldots,K`$ do

4:   Sample batch $`\mathcal{D}_{n}=\{\mathbf{x}_{i}\}_{i=1}^{N}`$ from
$`\mathcal{D}`$

5:   for $`i=1,\ldots,N`$ do

6:    Sample responses
$`\mathbf{y}_{1}\sim\pi_{\theta}(\cdot|\mathbf{x}_{i})`$,
$`\mathbf{y}_{2}\sim\pi_{\theta^{\tau}}(\cdot|\mathbf{x}_{i})`$

7:    for $`t=1,\ldots,T`$ do

8:      Compute preference
$`R_{t}=\mathcal{P}(\mathbf{y}_{1}\succ\mathbf{y}_{2}\mid\mathbf{x}_{i})`$

9:      Estimate advantage
$`A_{t}=\sum_{\ell=t}^{T}\gamma^{\ell-t}R_{\ell}-b`$

10:    end for

### A.2 MPO-RT

For MPO-RT, we directly incorporate the KL regularization into the
reward function, resulting in a hard constraint on the policy updates.
Specifically, the reward $`R_{t}`$ is transformed as follows:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle R_{t}=\mathcal{P}(\mathbf{y}_{1}\succ\mathbf{y}_{2}\mid\mathbf{x})-\alpha\left(\log\pi(\mathbf{y}_{1}\mid\mathbf{x})-\log\pi_{\text{ref}}(\mathbf{y}_{1}\mid\mathbf{x})\right),`$ |  | (20) |

and the optimization objective becomes:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\vskip 5.0pt\max_{\theta}\Psi^{\text{MD}}(\theta)=\max_{\theta}\mathbb{E}_{\mathbf{x}\sim\mathcal{D}}\Big[\mathbb{E}_{\mathbf{y}_{1}\sim\pi_{\theta},\mathbf{y}_{2}\sim\pi_{\theta^{\prime}}}\big[A_{\theta^{k}}(\mathbf{x},\mathbf{y}_{1},\mathbf{y}_{2})\big]-\frac{1}{\eta}D_{\mathrm{KL}}(\pi_{\theta}\|\pi_{\theta^{k}})\Big].
``` |  | (21) |

The key difference between MPO and MPO-RT lies in how they handle the KL
regularization. MPO uses a soft constraint on KL divergence via a KL
loss, while MPO-RT applies a hard constraint by directly modifying the
reward function, which aligns well with the standard RLHF
methods ([Orabona, 2019](#bib.bib38); [Ouyang et al., 2022](#bib.bib39);
[Zheng et al., 2023](#bib.bib69)). The choice between these two
algorithms depends on the specific task requirements. The pseudocode of
MPO-RT is provided in
Algorithm [2](#alg2 "Algorithm 2 ‣ A.2 MPO-RT ‣ Appendix A Pseudocode and Implementation Details ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment").
We also provide additional results for MPO-RT
in [D.2](#A4.SS2 "D.2 Additional Results for MPO-RT ‣ Appendix D Additional Results ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")

## Appendix E Proofs

### E.1 Additional Lemmas

###### Lemma E.1 (Proposition 1, ([Munos et al., 2023](#bib.bib36))).

There exists a unique Nash equilibrium $`(\pi_{1}^{*},\pi_{2}^{*})`$ for
the game $`J(\pi_{1},\pi_{2})`$ defined
in equation [8](#S2.E8 "In 2.3 RLHF with Bradley-Terry Model ‣ 2 Preliminaries ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
and $`\pi_{1}^{*}=\pi_{2}^{*}`$.

###### Proof.

Since we have that
$`\mathcal{P}(\pi^{\prime}>\pi)=1-\mathcal{P}(\pi>\pi^{\prime})`$. The
minimax game can be repressed as a symmetric two-player game with
payoffs of policy $`\pi_{1}`$ and $`\pi_{2}`$ are defined as

|  |  |  |
|----|----|----|
|  |
``` math
R(\pi;\pi^{\prime})=\mathcal{P}(\pi\succ\pi^{\prime})-\alpha D_{\mathrm{KL}}(\pi||\pi_{\text{ref}}),
``` |  |

and

|  |  |  |
|----|----|----|
|  |
``` math
R(\pi^{\prime};\pi)=\mathcal{P}(\pi^{\prime}\succ\pi)-\alpha D_{\mathrm{KL}}(\pi^{\prime}||\pi_{\text{ref}}).
``` |  |

We first prove the existence the Nash equilibrium. Since the payoff of
the game is concave with respect to $`\pi`$ and $`\pi^{\prime}`$, thus
the game processes a Nash equilibrium ([Rosen, 1965](#bib.bib45)).

For uniqueness, we need to show that the corresponding variational
inequality is strictly monotone ([Rosen, 1965](#bib.bib45)). Let
$`\bar{\pi}=[\pi,\pi^{\prime}]`$ and
$`v(\bar{\pi})=[\nabla_{\pi}R(\pi;\pi^{\prime}),\nabla_{\pi^{\prime}}R(\pi^{\prime};\pi)]`$.
For every Nash equilibrium of the game satisfy

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle v^{\top}(\bar{\pi}^{*})(\bar{\pi}^{*}-\bar{\pi})\leq 0,\quad\forall\bar{\pi}\in\Pi.`$ |  | (22) |

The variational inequality is strictly monotone if and only if for every
$`\bar{\pi}_{1}`$ and $`\bar{\pi}_{2}`$, we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle(v(\bar{\pi}_{1})-v(\bar{\pi}_{2}))^{\top}(\bar{\pi}_{1}-\bar{\pi}_{2})\leq 0,`$ |  | (24) |

with equality only holds at $`\bar{\pi}_{1}=\bar{\pi}_{2}`$ ([Rosen,
1965](#bib.bib45)). We can show this inequality holds by expanding the
terms on LHS. For every context $`\mathbf{x}`$, denote
$`v(\bar{\pi})(\mathbf{x})`$ as the partial derivative for
$`\mathbf{x}`$. We have:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle v(\bar{\pi})(\mathbf{x})=\rho(\mathbf{x})[\mathcal{P}(y>\pi^{\prime}\mid\mathbf{x})-\alpha\log(\pi/\pi_{\text{ref}}\mid\mathbf{x})-1,\mathcal{P}(y>\pi|\mathbf{x})-\alpha\log(\pi^{\prime}/\pi_{\text{ref}}\mid\mathbf{x})-1],`$ |  | (26) |

Combining this with
Eq [24](#A5.E24 "In Proof. ‣ E.1 Additional Lemmas ‣ Appendix E Proofs ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
and then exploiting the non-negativity of KL-divergence implies:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle(v(\bar{\pi}_{1})-v(\bar{\pi}_{2}))^{\top}(\bar{\pi}_{1}-\bar{\pi}_{2})`$ | $`\displaystyle=\mathcal{P}(\pi_{1}>\pi_{1}^{\prime})+\mathcal{P}(\pi_{1}^{\prime}>\pi_{1})+\mathcal{P}(\pi_{2}>\pi_{2}^{\prime})+\mathcal{P}(\pi_{2}^{\prime}>\pi_{2})`$ |  | (28) |
|  |  | $`\displaystyle-\mathcal{P}(\pi_{2}>\pi_{1}^{\prime})+\mathcal{P}(\pi_{1}^{\prime}>\pi_{2})+\mathcal{P}(\pi_{1}>\pi_{2}^{\prime})+\mathcal{P}(\pi_{2}^{\prime}>\pi_{1})`$ |  | (29) |
|  |  | $`\displaystyle-\alpha(D_{\mathrm{KL}}(\pi_{1}|\pi_{2})+D_{\mathrm{KL}}(\pi_{2}|\pi_{1})+D_{\mathrm{KL}}(\pi_{1}^{\prime}|\pi_{2}^{\prime})+D_{\mathrm{KL}}(\pi_{2}^{\prime}|\pi_{1}^{\prime}))`$ |  | (30) |
|  |  | $`\displaystyle=-\alpha(D_{\mathrm{KL}}(\pi_{1}|\pi_{2})+D_{\mathrm{KL}}(\pi_{2}|\pi_{1})+D_{\mathrm{KL}}(\pi_{1}^{\prime}|\pi_{2}^{\prime})+D_{\mathrm{KL}}(\pi_{2}^{\prime}|\pi_{1}^{\prime}))\leq 0.`$ |  | (31) |

with equality only at $`\bar{\pi}_{1}=\bar{\pi}_{2}`$. This completes
the proof. ∎

###### Lemma E.2 (Lemma D.3, ([Sokota et al., 2022](#bib.bib51))).

Under the assumptions of Theorem
[3.2](#S3.Thmtheorem2 "Theorem 3.2 (Theorem 3.4, ( , )). ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
we have for all $`\pi\in\Pi`$,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle B_{\psi}(\pi;\pi^{k+1})\leq B_{\psi}(\pi;\pi^{k})-B_{\psi}(\pi^{k+1};\pi^{k})+\langle\eta F(\pi^{k})+\eta\alpha\nabla g(\pi^{k+1})),\pi-\pi^{k+1}\rangle.`$ |  | (33) |

###### Proof.

Note that

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi^{k+1}\in\argmin_{\pi\in\Pi}\eta\langle F(\pi^{k}),\pi\rangle+\eta\alpha g(\pi)+B_{\psi}(\pi;\pi^{k}),
``` |  | (34) |

we have

|  |  |  |  |  |
|----|----|----|----|----|

###### Lemma E.4.

### E.3 Proof of Lemma [3.3](#S3.Thmtheorem3 "Lemma 3.3. ‣ 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")

###### Proof.

To prove this lemma, we first show that if
$`\pi_{r}^{*,n+1}\neq\pi_{r}^{*,n}`$, for $`k\geq 1`$, we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n+1})<D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n}).`$ |  | (60) |

Consider the KL divergence between consecutive iterates. By definition:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle D_{\mathrm{KL}}(\pi_{r}^{*,n}\|\pi_{r}^{*,n+1})=\sum_{j\in\mathcal{J}}\pi_{rj}^{*,n}\ln\frac{\pi_{rj}^{*,n}}{\pi_{rj}^{*,n+1}}.`$ |  | (61) |

For any Nash equilibrium $`\pi^{*}\in\Pi^{*}`$, we can write:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\sum_{i\in\mathcal{I}}\langle\nabla_{i}D_{\mathrm{KL}}(\pi_{ri}^{*,n}\|\pi_{ri}^{*,n+1}),\pi_{ri}^{*,n+1}-\pi_{i}^{*}\rangle`$ | $`\displaystyle=\sum_{i\in\mathcal{I}}\sum_{j\in\mathcal{J}}(\pi_{ij}^{*}-\pi_{rij}^{*,n+1})\frac{\pi_{rij}^{*,n}}{\pi_{rij}^{*,n+1}}`$ |  | (62) |
|  |  | $`\displaystyle=I\exp{\big(\ln{\big(\frac{1}{I}\sum_{i\in\mathcal{I}}\sum_{j\in\mathcal{J}}\pi_{ij}^{*}\frac{\pi_{rij}^{*,n}}{\pi_{rij}^{*,n+1}}\big)}\big)}-I`$ |  |  |
|  |  | $`\displaystyle\geq I\exp{\big(\frac{1}{I}\sum_{i\in\mathcal{I}}\sum_{j\in\mathcal{J}}\pi_{ij}^{*}\ln{\frac{\pi_{rij}^{*,n}}{\pi_{rij}^{*,n+1}}\big)}}-I`$ |  |  |
|  |  | $`\displaystyle=I\exp{\big(\frac{1}{I}(D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n+1})-D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n}))\big)}-I,`$ |  |  |

where the first equality follows from the gradient of KL divergence, the
third inequality follows from Jensen’s inequality since $`\ln(\cdot)`$
is concave, and the last equality is by the definition of KL divergence.

Since $`\pi_{r}^{*,n+1}\neq\pi_{r}^{*,n}`$, we can rearrange to get:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n+1})-D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n})`$ | $`\displaystyle<I\ln\big(1+\frac{1}{I}\sum_{i\in\mathcal{I}}\langle\nabla_{i}D_{\mathrm{KL}}(\pi_{ri}^{*,n}\|\pi_{ri}^{*,n+1}),\pi_{ri}^{*,n+1}-\pi_{i}^{*}\rangle\big)`$ |  | (63) |
|  |  | $`\displaystyle\leq\sum_{i\in\mathcal{I}}\langle\nabla_{i}D_{\mathrm{KL}}(\pi_{ri}^{*,n}\|\pi_{ri}^{*,n+1}),\pi_{ri}^{*,n+1}-\pi_{i}^{*}\rangle,`$ |  | (64) |

where the the second inequality uses the fact that $`\ln{(x+1)}\leq x`$
for $`x>-1`$.

Now, we have that

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n+1})-D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n})\leq\sum_{i\in\mathcal{I}}\langle\nabla_{i}D_{\mathrm{KL}}(\pi_{ri}^{*,n}\|\pi_{ri}^{*,n+1}),\pi_{ri}^{*,n+1}-\pi_{i}^{*}\rangle.`$ |  | (65) |

Since $`\pi^{*}`$ is the Nash equilibrium of the original game,
$`\pi_{r}^{*}`$ is the Nash equilibrium of the regularized game, and
$`\pi_{r}^{*,n+1}\neq\pi_{r}^{*,n}`$, according to
Lemma [E.4](#A5.Thmtheorem4 "Lemma E.4. ‣ E.1 Additional Lemmas ‣ Appendix E Proofs ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
we have:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n+1})-D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n})\leq\pi_{r}^{*,n})\leq\sum_{i\in\mathcal{I}}\langle\nabla_{i}D_{\mathrm{KL}}(\pi_{ri}^{*,n}\|\pi_{ri}^{*,n+1}),\pi_{ri}^{*,n+1}-\pi_{i}^{*}\rangle<0.`$ |  | (66) |

Finally, let
$`\pi_{*}=\arg\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n})`$.
If $`\pi_{r}^{*,n}\in\Pi\backslash\Pi^{*}`$, then:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n+1})=D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n+1})<D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n})=\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi_{r}^{*,n}).`$ |  | (67) |

This shows that the sequence of regularized Nash equilibria strictly
approaches the of Nash equilibrium of the original game, completing the
proof. ∎

### E.4 Proof of Theorem [3.4](#S3.Thmtheorem4 "Theorem 3.4. ‣ 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")

###### Proof.

We will prove that If
Lemma [3.3](#S3.Thmtheorem3 "Lemma 3.3. ‣ 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
holds, then the sequence $`\{\pi^{*,n}_{r}\}_{n\geq 1}`$ converges to
$`\pi^{*}\in\Pi^{*}`$ as $`n\to\infty`$, where $`\pi^{*}`$ is the Nash
equilibrium of the original game.

Let us begin by noting that since
$`\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi^{*,n}_{r})`$ is
bounded below by 0, and according to
Lemma [3.3](#S3.Thmtheorem3 "Lemma 3.3. ‣ 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
this sequence is strictly decreasing unless $`\pi^{*,n}_{r}\in\Pi^{*}`$,
we can conclude that the sequence converges to some value $`b\geq 0`$.
We will prove by contradiction that $`b=0`$.

Suppose $`b>0`$. Let us define:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle c`$ | $`\displaystyle=\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi^{*,1}_{r}),`$ |  |
|  | $`\displaystyle\Omega_{b,c}`$ | $`\displaystyle=\{\pi_{r}\in\Pi\mid b\leq\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi_{r})\leq c\}.`$ |  |

Since
$`\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi^{*,n}_{r})`$
decreases monotonically according to
Lemma [3.3](#S3.Thmtheorem3 "Lemma 3.3. ‣ 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
we have $`\pi^{*,n}_{r}\in\Omega_{b,c}`$ for all $`n\geq 1`$.

First, we prove that $`\Omega_{b,c}`$ is a compact set. Note that
$`\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\cdot)`$ is a
continuous function on $`\Pi`$, and $`[b,c]`$ is a closed set.
Therefore, $`\Omega_{b,c}`$, being the preimage of $`[b,c]`$ under a
continuous function, is closed. Furthermore, since $`\Pi`$ is bounded by
assumption, $`\Omega_{b,c}`$ is also bounded. Thus, $`\Omega_{b,c}`$ is
compact as it is both closed and bounded.

Let $`F(\pi_{r}):\Pi\to\Pi`$ be the function that maps $`\pi_{r}`$ to
$`\pi^{*}_{r}`$. As proved in Lemma F.7 of [Abe et al.
(2024)](#bib.bib1), $`F`$ is a continuous function in our case. When
$`F`$ is continuous,
$`\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|F(\pi_{r}))-\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi_{r})`$
is also continuous.

Since $`\Omega_{b,c}`$ is compact and this difference is continuous,
there exists a maximum value:

|  |  |  |
|----|----|----|
|  |
``` math
\nu=\max_{\pi_{r}\in\Omega_{b,c}}\{\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|F(\pi_{r}))-\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi_{r})\}.\\
``` |  |

From
Lemma [3.3](#S3.Thmtheorem3 "Lemma 3.3. ‣ 3.2 Convergence to the Nash Equilibrium of the Original Game ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
we know that $`\nu<0`$. Therefore:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi^{*,N}_{r})`$ | $`\displaystyle=\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi^{*,1}_{r})`$ |  |
|  |  | $`\displaystyle\quad+\sum_{n=1}^{N}(\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi^{*,n+1}_{r})-\min_{\pi^{*}\in\Pi^{*}}D_{\mathrm{KL}}(\pi^{*}\|\pi^{*,n}_{r}))`$ |  |
|  |  | $`\displaystyle\leq c+N\nu.`$ |  |

This implies that there exists some $`N`$ large enough such that
$`c+N\nu\leq 0`$, contradicting our assumption that $`b>0`$. Therefore,
we must have $`b=0`$ and this proves that the sequence
$`\{\pi^{*,n}_{r}\}_{n\geq 1}`$ converges to $`\pi^{*}\in\Pi^{*}`$,
completing our proof. ∎

###### Proof.

Following the proof of
Theorem [3.2](#S3.Thmtheorem2 "Theorem 3.2 (Theorem 3.4, ( , )). ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),

|  |  |  |  |

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle D_{\mathrm{KL}}(\pi_{r}^{*}\|\pi_{r}^{k+1})\leq D_{\mathrm{KL}}(\pi_{r}^{*}\|\pi_{r}^{\tau T_{k}})(\frac{1}{1+\eta\alpha})^{k-\tau T_{k}+1}.`$ |  | (78) |

Taking $`k=(\tau+1)T_{k}-1`$, we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle D_{\mathrm{KL}}(\pi_{r}^{*}\|\pi_{r}^{(\tau+1)T_{k}})\leq D_{\mathrm{KL}}(\pi_{r}^{*}\|\pi_{r}^{\tau T_{k}})(\frac{1}{1+\eta\alpha})^{T_{k}}.`$ |  | (79) |

Since $`\pi_{r}^{\tau}=\pi^{\tau T_{k}}`$, we complete our proof. ∎

## Appendix F Duality Gap and Convergence Rate

In this section, we provide an addition theorem for duality gap and show
that
Theorem [3.2](#S3.Thmtheorem2 "Theorem 3.2 (Theorem 3.4, ( , )). ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
can be leveraged to guarantee linear convergence of the gap.

###### Theorem F.1 (Proposition D.8, ([Sokota et al., 2022](#bib.bib51))).

Assume that $`g`$ is twice continuously differentiable over
$`\operatorname{int}\operatorname{dom}\psi`$, $`\Pi`$ is bounded, and
the assumptions in
Theorem [3.2](#S3.Thmtheorem2 "Theorem 3.2 (Theorem 3.4, ( , )). ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment")
hold. Let $`G=F+\alpha\nabla g`$. For all $`k\geq 1`$, the duality gap
$`\epsilon`$ is bounded as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\epsilon(\pi^{k+1})=\sup_{\pi\in\Pi}\langle G(\pi^{k}),\pi^{k}-\pi\rangle\leq\mathcal{O}\big((\frac{1}{1+\eta\alpha})^{\frac{k}{2}}\big).`$ |  | (80) |

###### Proof.

From
Theorem [3.2](#S3.Thmtheorem2 "Theorem 3.2 (Theorem 3.4, ( , )). ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
we have that $`\{\pi^{k}\}_{k\geq 1}\cup\{\pi^{*}\}`$ is eventually
within a closed ball centered at $`\pi^{*}`$. So there exists
$`k^{\prime}`$ and a closed ball $`B`$ such
that$`\{\pi^{k}\}_{k\geq k^{\prime}}\cup\{z^{*}\}\subseteq\operatorname{int}\operatorname{dom}\psi`$.
Since $`B`$ is compact and $`\nabla^{2}g`$ is continuous over $`B`$, we
have that $`\nabla^{2}g(z)`$ is bounded on $`B`$. Therefore, there
exists $`L_{B}`$ such that
$`\|\nabla g(\pi^{\prime})-\nabla g(\pi)\|^{*}\leq L_{B}\|\pi-\pi^{\prime}\|`$
for any $`\pi,\pi^{\prime}\in B`$. We have that for any
$`\pi,\pi^{\prime}\in B`$,
$`\|G(\pi)-G(\pi^{\prime})\|_{*}\leq\tilde{L}\|\pi-\pi^{\prime}\|`$ for
$`\tilde{L}=L+\alpha L_{B}`$.

For any $`\pi\in\Pi`$, we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\langle G(\pi^{*}),\pi^{k+1}-\pi\rangle`$ | $`\displaystyle=\langle G(\pi^{*}),\pi^{k+1}-\pi\rangle+\langle G(\pi^{k+1})-G(\pi^{*}),\pi^{k+1}-\pi\rangle`$ |  |
|  |  | $`\displaystyle=\langle G(\pi^{*}),\pi^{*}-\pi\rangle+\langle G(\pi^{*}),\pi^{k+1}-\pi^{*}\rangle+\langle G(\pi^{k+1})-G(\pi^{*}),\pi^{k+1}-\pi\rangle`$ |  |
|  |  | $`\displaystyle\leq\|G(\pi^{*})\|_{*}\|\pi^{k+1}-\pi^{*}\|+\tilde{L}\|\pi^{k+1}-\pi^{*}\|\|\pi^{k+1}-\pi\|`$ |  |
|  |  | $`\displaystyle\leq\left(\|G(\pi^{*})\|_{*}+\tilde{L}D\right)\|\pi^{k+1}-\pi^{*}\|`$ |  |
|  |  | $`\displaystyle\leq C\sqrt{B_{\psi}(\pi^{*};\pi^{k+1})}`$ |  |
|  |  | $`\displaystyle\leq C\left(\sqrt{\frac{1}{1+\eta\alpha}}\right)^{k}\sqrt{B_{\psi}(\pi^{*};\pi^{1})},`$ |  |

where $`D`$ is such that
$`\max_{\pi,\pi^{\prime}\in\mathcal{\Pi}}\|\pi-\pi^{\prime}\|\leq D`$
and $`C=\|G(\pi^{*})\|_{*}+\tilde{L}D`$.

The first inequality is by the generalized Cauchy-Schwarz inequality and
the Lipschitz property of $`G`$. The second inequality is by boundness
of $`\Pi`$. The third inequality is by the fact that
$`B_{\psi}(\pi^{*};\pi^{k})\geq\frac{1}{2}\|\pi^{*}-\pi^{k}\|^{2}`$.

∎

###### Lemma F.2.

Let $`\{\pi_{r}^{*,n}\}_{n\geq 1}`$ be the sequence of NEs of the
regularized games, and $`\pi_{r}^{\tau}`$ be the approximation of
$`\pi_{r}^{*,n}`$ solved via the update rule
of equation [12](#S3.E12 "In 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment").
Under the assumptions of
Theorem [3.2](#S3.Thmtheorem2 "Theorem 3.2 (Theorem 3.4, ( , )). ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
for any $`n\geq 1`$, if $`\pi_{r}^{*,n}\in\Pi\notin\Pi^{*}`$, we have
the following inequality:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle B_{\psi}(\pi^{*};\pi_{r}^{*,n})\leq B_{\psi}(\pi^{*};\pi_{r}^{\tau})-B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau}).`$ |  | (81) |

###### Proof.

By the definition of Bregman divergence, we have:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle B_{\psi}(\pi^{*};\pi_{r}^{*,n})-B_{\psi}(\pi^{*};\pi_{r}^{\tau})+B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})=\sum_{i\in\mathcal{I}}\langle\nabla\psi(\pi_{ri}^{*,n})-\nabla\psi(\pi_{ri}^{\tau}),\pi_{ri}^{*,n}-\pi_{i}^{*}\rangle.`$ |  | (82) |

Since $`\pi_{r}^{*,n}`$ is the Nash equilibrium of the $`n`$-th
regularized game, by the first-order optimality condition, we have:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{ri}^{*,n})-\alpha\nabla_{\pi_{i}}B_{\psi}(\pi_{ri}^{*,n};\pi_{ri}^{\tau}),\pi_{i}-\pi_{ri}^{*,n}\rangle\leq 0,\quad\forall\pi\in\Pi.\\
``` |  | (83) |

Taking $`\pi=\pi^{*}`$, we obtain:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}B_{\psi}(\pi_{ri}^{*,n};\pi_{ri}^{\tau}),\pi_{ri}^{*,n}-\pi_{i}^{*}\rangle`$ | $`\displaystyle\leq\frac{1}{\alpha}\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{ri}^{*,n}),\pi_{ri}^{*,n}-\pi_{i}^{*}\rangle`$ |  | (84) |
|  |  | $`\displaystyle\leq\frac{1}{\alpha}\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{i}^{*}),\pi_{ri}^{*,n}-\pi_{i}^{*}\rangle,`$ |  | (85) |

where the second inequality holds because the game is monotonous. Since
$`\pi^{*}`$ is the Nash equilibrium of the original game, the
first-order optimality condition implies that for all $`\pi\in\Pi`$,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\frac{1}{\alpha}\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{i}^{*},\pi_{-i}^{*}),\pi_{i}-\pi_{i}^{*}\rangle\leq 0,\quad\forall\pi\in\Pi.`$ |  | (87) |

Then, taking $`\pi=\pi_{r}^{*,n}`$, we have:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}B_{\psi}(\pi_{ri}^{*,n};\pi_{ri}^{\tau}),\pi_{ri}^{*,n}-\pi_{i}^{*}\rangle`$ | $`\displaystyle=\sum_{i\in\mathcal{I}}\langle\nabla\psi(\pi_{ri}^{*,n})-\nabla\psi(\pi_{ri}^{\tau}),\pi_{ri}^{*,n}-\pi_{i}^{*}\rangle`$ |  | (89) |
|  |  | $`\displaystyle\leq\frac{1}{\alpha}\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{i}^{*}),\pi_{ri}^{*,n}-\pi_{i}^{*}\rangle\leq 0.`$ |  | (90) |

Thus, we have:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle B_{\psi}(\pi^{*};\pi_{r}^{*,n})-B_{\psi}(\pi^{*};\pi_{r}^{\tau})+B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})=\sum_{i\in\mathcal{I}}\langle\nabla\psi(\pi_{ri}^{*,n})-\nabla\psi(\pi_{ri}^{\tau}),\pi_{ri}^{*,n}-\pi_{i}^{*}\rangle\leq 0.`$ |  | (91) |

This completes the proof. ∎

###### Lemma F.3.

Under the assumptions of
Lemma [F.2](#A6.Thmtheorem2 "Lemma F.2. ‣ Appendix F Duality Gap and Convergence Rate ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
the duality gap for $`\pi_{r}^{\tau}`$ is bounded as:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\epsilon(\pi_{r}^{\tau})\leq\epsilon(\pi_{r}^{*,n})+O(\|\pi_{r}^{*,n}-\pi_{r}^{\tau}\|).`$ |  | (93) |

###### Proof.

By the definition of duality gap, we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\epsilon(\pi_{r}^{\tau})`$ | $`\displaystyle=\max_{\pi_{i}\in\Pi}\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{ri}^{\tau},\pi_{-ri}^{\tau}),\pi_{i}^{\tau}-\pi_{ri}\rangle`$ |  | (94) |
|  |  | $`\displaystyle=\max_{\pi_{i}\in\Pi}\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{ri}^{*,n},\pi_{-ri}^{*,n}),\pi_{ri}^{*,n}-\pi_{i}\rangle+\max_{\pi_{i}\in\Pi}\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{ri}^{\tau},\pi_{-ri}^{\tau}),\pi_{ri}^{\tau}-\pi_{i}\rangle`$ |  | (95) |
|  |  | $`\displaystyle-\max_{\pi_{i}\in\Pi}\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{ri}^{*,n},\pi_{-ri}^{*,n}),\pi_{ri}^{*,n}-\pi_{i}\rangle`$ |  | (96) |
|  |  | $`\displaystyle\leq\epsilon(\pi_{r}^{*,n})+\max_{\pi_{i}\in\Pi}\sum_{i\in\mathcal{I}}\langle\nabla_{\pi_{i}}f_{i}(\pi_{ri}^{*,n},\pi_{-ri}^{*,n})-\nabla_{\pi_{i}}f_{i}(\pi_{ri}^{\tau},\pi_{-ri}^{\tau}),\pi_{i}\rangle`$ |  | (97) |
|  |  | $`\displaystyle\leq\epsilon(\pi_{r}^{*,n})+L\sum_{i\in\mathcal{I}}\|\pi_{ri}^{*,n}-\pi_{ri}^{\tau}\|=\epsilon(\pi_{r}^{*,n})+L\|\pi_{r}^{*,n}-\pi_{r}^{\tau}\|,`$ |  | (98) |

where the second inequlity follows from the Lipschitz continuity of the
gradient with constant $`L`$. This completes the proof. ∎

###### Theorem F.4.

Under the assumptions of
Lemma [F.2](#A6.Thmtheorem2 "Lemma F.2. ‣ Appendix F Duality Gap and Convergence Rate ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
suppose $`\psi`$ is $`L_{\psi}`$-smooth. Then, for any $`N\geq 1`$,
$`\forall 1\leq n\leq N`$, we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\epsilon(\pi_{r}^{\tau+1})\leq O(\frac{1}{\sqrt{N}}).`$ |  | (100) |

###### Proof.

From
Lemma [F.3](#A6.Thmtheorem3 "Lemma F.3. ‣ Appendix F Duality Gap and Convergence Rate ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\epsilon(\pi_{r}^{\tau+1})=\epsilon(\pi_{r}^{*,n})+L_{0}\|\pi_{r}^{*,n}-\pi_{r}^{\tau+1}\|,`$ |  | (101) |

where $`L_{0}`$ is a game-dependant constant.

Following the bounding technique for the gap function with tangent
residuals ([Cai et al., 2022](#bib.bib9)) and the first-order optimality
condition for $`\pi_{r}^{*,n}`$, we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle r^{tan}(\pi_{r}^{*,n})\leq L_{1}\|\pi_{r}^{*,n}-\pi_{r}^{\tau}\|,`$ |  | (103) |

where $`r^{tan}(\pi_{r}^{\tau+1})`$ denotes the tangent residual ([Cai
et al., 2022](#bib.bib9)) of $`\pi_{r}^{*,n}`$ and $`L_{1}`$ is a
constant that depends on the original game. From Lemma 2 of ([Cai
et al., 2022](#bib.bib9)), for $`\forall\pi\in\Pi`$, we obtain

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\epsilon(\pi_{r}^{*,n})\leq L_{2}r^{tan}(\pi_{r}^{*,n}),`$ |  | (105) |

where $`L_{2}`$ is a game-dependent constant. According to
Theorem [3.2](#S3.Thmtheorem2 "Theorem 3.2 (Theorem 3.4, ( , )). ‣ 3.1 Magnetic Mirror Descent ‣ 3 Magnetic Preference Optimization ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
let $`\psi=\frac{1}{2}\|\cdot\|^{2}`$, we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\epsilon(\pi_{r}^{\tau+1})`$ | $`\displaystyle\leq L_{1}L_{2}\|\pi_{r}^{*,n}-\pi_{r}^{\tau}\|+L_{0}\|\pi_{r}^{*,n}-\pi_{r}^{\tau+1}\|.`$ |  | (107) |
|  |  | $`\displaystyle\leq L_{1}L_{2}\|\pi_{r}^{*,n}-\pi_{r}^{\tau}\|+L_{0}\frac{\|\pi_{r}^{*,n}-\pi_{r}^{\tau}\|}{N^{c}},`$ |  | (108) |

where $`c>0`$ is an arbitrary constant. According to
Lemma [F.2](#A6.Thmtheorem2 "Lemma F.2. ‣ Appendix F Duality Gap and Convergence Rate ‣ Magnetic Preference Optimization: Achieving Last-iterate Convergence for Language Model Alignment"),
we have

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle B_{\psi}(\pi^{*};\pi_{r}^{*,n})\leq B_{\psi}(\pi^{*};\pi_{r}^{\tau})-B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})`$ |  | (109) |
|  | $`\displaystyle\Leftrightarrow\;`$ | $`\displaystyle 0\leq B_{\psi}(\pi^{*};\pi_{r}^{\tau})-B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})-B_{\psi}(\pi^{*};\pi_{r}^{*,n})`$ |  | (110) |
|  | $`\displaystyle\Leftrightarrow\;`$ | $`\displaystyle 0\leq B_{\psi}(\pi^{*};\pi_{r}^{\tau})-B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})-B_{\psi}(\pi^{*};\pi_{r}^{\tau+1})-B_{\psi}(\pi_{r}^{\tau+1};\pi_{r}^{*,n})`$ |  | (111) |
|  |  | $`\displaystyle\quad\quad+\langle\nabla\psi(\pi_{r}^{*,n})-\nabla\psi(\pi_{r}^{\tau+1}),\pi^{*}-\pi_{r}^{\tau+1}\rangle,`$ |  | (112) |

where the last line comes from the three-point property of Bregman
divergence. For
$`\langle\nabla\psi(\pi_{r}^{*,n})-\nabla\psi(\pi_{r}^{\tau+1}),\pi^{*}-\pi_{r}^{\tau+1}\rangle`$,
we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\langle\nabla\psi(\pi_{r}^{*,n})-\nabla\psi(\pi_{r}^{\tau+1}),\pi^{*}-\pi_{r}^{\tau+1}\rangle`$ | $`\displaystyle\leq\|\nabla\psi(\pi_{r}^{*,n})-\nabla\psi(\pi_{r}^{\tau+1})\|\|\pi^{*}-\pi_{r}^{\tau+1}\|`$ |  | (113) |
|  |  | $`\displaystyle\leq\frac{N^{c}\|\nabla\psi(\pi_{r}^{*,n})-\nabla\psi(\pi_{r}^{\tau+1})\|^{2}}{2}+\frac{\|\pi^{*}-\pi_{r}^{\tau+1}\|^{2}}{2N^{c}}`$ |  | (114) |
|  |  | $`\displaystyle\leq\frac{N^{c}\|\pi_{r}^{*,n}-\pi_{r}^{\tau+1}\|^{2}}{2}+\frac{\|\pi^{*}-\pi_{r}^{\tau+1}\|^{2}}{2N^{c}},`$ |  | (115) |

where the the first inequality follows from the Cauchy-Schwarz
inequality, the second inequality follows from
$`ab\leq\rho a^{2}/2+b^{2}/2\rho,\forall\rho>0`$, and the third
inequality follows the smoothness of $`\psi(\cdot)`$.
Thus, we have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle 0`$ | $`\displaystyle\leq B_{\psi}(\pi^{*};\pi_{r}^{\tau})-B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})-B_{\psi}(\pi^{*};\pi_{r}^{\tau+1})-B_{\psi}(\pi_{r}^{\tau+1};\pi_{r}^{*,n})`$ |  | (117) |
|  |  | $`\displaystyle\quad+\langle\nabla\psi(\pi_{r}^{*,n})-\nabla\psi(\pi_{r}^{\tau+1}),\pi^{*}-\pi_{r}^{\tau+1}\rangle`$ |  | (118) |
|  |  | $`\displaystyle\leq B_{\psi}(\pi^{*};\pi_{r}^{\tau})-B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})-B_{\psi}(\pi^{*};\pi_{r}^{\tau+1})-B_{\psi}(\pi_{r}^{\tau+1};\pi_{r}^{*,n})`$ |  | (119) |
|  |  | $`\displaystyle\quad+\frac{N^{c}\|\pi_{r}^{*,n}-\pi_{r}^{\tau+1}\|^{2}}{2}+\frac{\|\pi^{*}-\pi_{r}^{\tau+1}\|^{2}}{2N^{c}}`$ |  | (120) |

Further, we obtain

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})`$ | $`\displaystyle\leq B_{\psi}(\pi^{*};\pi_{r}^{\tau})-B_{\psi}(\pi^{*};\pi_{r}^{\tau+1})-B_{\psi}(\pi_{r}^{\tau+1};\pi_{r}^{*,n})`$ |  | (122) |
|  |  | $`\displaystyle\quad+\frac{\|\pi_{r}^{*,n}-\pi_{r}^{\tau}\|^{2}}{2}+\frac{\|\pi^{*}-\pi_{r}^{\tau+1}\|^{2}}{2N^{c}}.`$ |  | (123) |
|  |  | $`\displaystyle\leq B_{\psi}(\pi^{*};\pi_{r}^{\tau})-B_{\psi}(\pi^{*};\pi_{r}^{\tau+1})+\frac{\|\pi^{*}-\pi_{r}^{\tau+1}\|^{2}}{2N^{c}}.`$ |  | (124) |

Then, summing up from $`n=1`$ to $`N`$, we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sum_{n=1}^{N}B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})\leq B_{\psi}(\pi^{*};\pi_{r}^{\tau})-B_{\psi}(\pi^{*};\pi_{r}^{\tau+1})+\sum_{n=1}^{N}\frac{\|\pi^{*}-\pi_{r}^{\tau+1}\|^{2}}{2N^{c}}.`$ |  | (125) |

Thus, we obtain

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sum_{n=1}^{N}B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})\leq C_{3},`$ |  | (126) |

where $`C_{3}`$ is a game-dependent constant, and this inequality comes
from the derivation of ([Cevher et al., 2023](#bib.bib12)). Since $`c`$
is an arbitrary constant, we then have

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})`$ | $`\displaystyle=B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{*,n-1})+B_{\psi}(\pi_{r}^{*,n-1};\pi_{r}^{\tau})`$ |  | (127) |

|  |  | $`\displaystyle\leq B_{\psi}(\pi_{r}^{\tau};\pi_{r}^{\tau-1})+B_{\psi}(\pi_{r}^{*,n-1};\pi_{r}^{\tau})+\|\pi_{r}^{*,n}-\pi_{r}^{*,n-1}\|\|\pi_{r}^{*,n-1}-\pi_{r}^{\tau}\|`$ |  | (129) |
|  |  | $`\displaystyle\leq B_{\psi}(\pi_{r}^{*,n-1};\pi_{r}^{\tau-1})+B_{\psi}(\pi_{r}^{\tau};\pi_{r}^{*,n-1})+\|\pi_{r}^{*,n}-\pi_{r}^{*,n-1}\|\|\pi_{r}^{*,n-1}-\pi_{r}^{\tau}\|`$ |  | (130) |
|  |  | $`\displaystyle\quad+B_{\psi}(\pi_{r}^{*,n-1};\pi_{r}^{\tau})+\|\pi_{r}^{\tau}-\pi_{r}^{*,n-1}\|\|\pi_{r}^{*,n-1}-\pi_{r}^{\tau-1}\|`$ |  | (131) |
|  |  | $`\displaystyle\leq B_{\psi}(\pi_{r}^{*,n-1};\pi_{r}^{\tau-1})+2B_{\psi}(\pi_{r}^{\tau};\pi_{r}^{*,n-1})+\|\pi_{r}^{*,n}-\pi_{r}^{*,n-1}\|\|\pi_{r}^{*,n-1}-\pi_{r}^{\tau}\|`$ |  | (132) |
|  |  | $`\displaystyle\quad+\|\pi_{r}^{\tau}-\pi_{r}^{*,n-1}\|\|\pi_{r}^{*,n-1}-\pi_{r}^{\tau-1}\|`$ |  | (133) |
|  |  | $`\displaystyle\leq B_{\psi}(\pi_{r}^{*,n-1};\pi_{r}^{\tau-1})+\|\pi_{r}^{\tau}-\pi_{r}^{*,n-1}\|^{2}+2C_{4}\|\pi_{r}^{*,n-1}-\pi_{r}^{\tau-1}\|`$ |  | (134) |
|  |  | $`\displaystyle\leq B_{\psi}(\pi_{r}^{*,n-1};\pi_{r}^{\tau-1})+\frac{1}{N^{4}}\|\pi_{r}^{\tau}-\pi_{r}^{*,n-1}\|^{2}+\frac{2C_{4}}{N^{2}}\|\pi_{r}^{*,n-1}-\pi_{r}^{\tau-1}\|`$ |  | (135) |
|  |  | $`\displaystyle\leq B_{\psi}(\pi_{r}^{*,n-1};\pi_{r}^{\tau-1})+\frac{C_{4}^{2}}{N^{4}}+\frac{2C_{4}^{2}}{N^{2}},`$ |  | (136) |

where $`C_{4}=\max_{\pi,\pi^{\prime}\in\Pi}\|\pi-\pi^{\prime}\|^{2}`$.
Then, we have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})\leq B_{\psi}(\pi_{r}^{*,n-1};\pi_{r}^{\tau-1})+\frac{C_{4}^{2}}{N^{4}}+\frac{2C_{4}^{2}}{N^{2}},`$ |  | (137) |
|  | $`\displaystyle B_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})\leq B_{\psi}(\pi_{r}^{*,n-2};\pi_{r}^{\tau-2})+\frac{2C_{4}^{2}}{N^{4}}+\frac{4C_{4}^{2}}{N^{2}},`$ |  | (138) |

|     |                         |     |       |
|-----|-------------------------|-----|-------|
|     | $`\displaystyle\cdots`$ |     | (140) |

Therefore, we have

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle NB_{\psi}(\pi_{r}^{*,n};\pi_{r}^{\tau})\leq\sum_{n=1}^{N}B_{\psi}(\pi_{r}^{*,n-1};\pi_{r}^{\tau-1})+\frac{C_{4}^{2}N^{2}}{N^{4}}+\frac{2C_{4}^{2}K^{2}}{K^{2}},`$ |  | (141) |

Therefore,
````
