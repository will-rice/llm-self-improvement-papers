# Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory

Keshav Ramji ^(†)^(†)thanks: Correspondence to keshav.ramji@ibm.com   
Tahira Naseem & Ramón Fernandez Astudillo Affiliation: IBM Research AI

###### Abstract

While modern large language models (LLMs) have been trained to reason
through verbalized chains-of-thought, the generation cost grows
substantially due to suboptimal paths to reach the final answer.
Furthermore, as new insights are discovered while observing various
input queries (e.g. through self-reflection), limited mechanisms exist
for carrying forward these findings to be applied to subsequent
problems. One can view the list of such strategies or behaviors as a
growing cheatsheet, with elements retrieved from this memory module at
inference-time. In this work, we consider structured cheatsheets, with
learned clusters of behaviors. We introduce a Hierarchical Dirichlet
Process Gaussian Mixture Model (HDP-GMM) over behavior embeddings, which
shares components across domains while allowing domain-specific mixing
weights, and uses the posterior predictive to retrieve relevant
behaviors for a query; we call this a Bayesian Cheatsheet. This
mechanism allows for cheap adaptation in an online test-time training
(TTT) setting, softly updating the mixture’s sufficient statistics
following each sample and enabling the creation of new components when
the synthesized behaviors are sufficiently novel. We demonstrate that
Bayesian Cheatsheet achieves clear performance gains relative to
existing memory modules across reasoning benchmarks such as AIME’25,
Omni-MATH, and PhysReason, even in the cold-start setting. We show that
the Bayesian Cheatsheet is an adaptively reorganizing memory module, as
behaviors can be re-assigned to components through a single step of
collapsed Gibbs sampling. Our findings highlight the value of
Bayesian-inspired memory modules for effective test-time adaptation and
the role of structure in metacognitive reasoning.

## 1 Introduction

Large language models increasingly solve complex problems by generating
verbalized intermediate reasoning steps ([Wei et al., 2022](#bib.bib52);
[Nye et al., 2021](#bib.bib36)). Given that related problems can often
be solved with similar strategies, storing such strategies, which we
call behaviors, can improve reasoning efficiency in solving future
problems — that is, they do not need to be rediscovered. This is a key
premise of metacognitive reasoning ([Shinn et al., 2023](#bib.bib45);
[Didolkar et al., 2024](#bib.bib10); [Didolkar et al.,
2025](#bib.bib11)), where reflecting on reasoning to extract
generalizable lessons and using those lessons to guide subsequent
attempts have been shown to be effective. At the same time, this begs
the question: how can we design systems to optimally retain and retrieve
useful abstractions for LLM reasoning and decision-making?

Recent methods accumulate and revise reasoning behaviors, reflections,
and procedural guidance over time ([Didolkar et al., 2025](#bib.bib11);
[Suzgun et al., 2026](#bib.bib47); [Zhang et al., 2026b](#bib.bib62);
[Ouyang et al., 2026](#bib.bib37)). As memory grows, context limits and
costs make it desirable to maintain an external, structured memory with
selective reuse to avoid context explosion. Existing structured memory
systems ([Xu et al., 2025](#bib.bib55); [Chhikara et al.,
2025](#bib.bib8)) often rely on LLM judgments and similarity-based
heuristics to define and evolve the memory structure; this organization
can become difficult to maintain as the memory grows.

In this work, we use the term cheatsheet to refer to a general
abstraction: it is a collection of concise, natural-language insights
that can be consulted while solving a new problem. A cheatsheet induces
two key design questions: 1) what type of information should be stored?
and 2) how should it be organized for effective reuse and continual
adaptation? In this work, we focus on the latter, while for the former,
we simply use short reasoning behaviors generated through
self-reflection to form the memory content. This allows for a clear
comparison of memory organization mechanisms without the confounding
effect of differences in the memory content. As a cheatsheet grows, its
organization must support more than the retrieval of similar entries —
related behaviors may form groups, which may also be reusable across
domains. New experiences encountered at test-time may reinforce the
contents of an existing group, or reveal a strategy that is not captured
under the current organization. However, static cheatsheets, as well as
flat similarity-based retrieval, do not address this, and while
clustering provides additional organization for reuse, it does not
facilitate principled growth and requires the number of clusters to be
known in advance.

We introduce the Bayesian Cheatsheet, a structured memory module based
on a Hierarchical Dirichlet Process Gaussian Mixture Model (HDP-GMM)
([Rasmussen, 2000](#bib.bib40); [Teh et al., 2006](#bib.bib49)) over
behavior embeddings. The HDP-GMM formulation, as a non-parametric
unbounded clustering mechanism, offers a few benefits that are
particularly desirable for test-time memory management: 1) the number of
clusters is purely driven by the data seen thus far, 2) the hierarchical
structure offers a flexible mechanism to distinguish generally usable
memories from domain-specific ones, and 3) the posterior probabilities
of cluster assignment serve a dual purpose, in assigning memories to
clusters as well as input-conditioned retrieval. The HDP prior
additionally induces a rich-get-richer bias – memory components
repeatedly observed in experience become more likely to be used in the
future, while new components may still be created.

Our Bayesian Cheatsheet memory learns globally shared components
(clusters) of behaviors, allowing for probabilistically latent
assignment. At inference time, it predicts the query’s domain and
retrieves behaviors from components to add to the language model’s
context. In an online test-time training setting with streaming samples,
Bayesian Cheatsheet cheaply incorporates newly mined behaviors into the
memory through additive sufficient statistics, while also permitting the
creation of new components for samples where the behaviors are
sufficiently novel. Bayesian Cheatsheet also allows the memory to
periodically reorganize itself as its contents evolve without requiring
a refitting step every sample. As a result, this mechanism supports
lightweight continual adaptation in a statistically-informed,
training-free manner through principled changes to an external memory
module.

## 2 Related Work

#### Test-time adaptation and continual learning.

Early test-time training methods adapted models through self-supervised
losses on test inputs ([Sun et al., 2020](#bib.bib46)), with later work
on language models drawing adaptation data from retrieved text ([Hardt &
Sun, 2024](#bib.bib16)) or input–output demonstrations supplied with a
reasoning task ([Akyürek et al., 2025](#bib.bib2)). Continual learning
additionally aims to retain previously learned capabilities across
updates; Learning without Forgetting ([Li & Hoiem, 2016](#bib.bib32))
and elastic weight consolidation ([Kirkpatrick et al.,
2017](#bib.bib25)) constrain changes in predictions and important
parameters, respectively. On-policy distillation trains a student on its
own generated sequences using a teacher’s predictions ([Agarwal et al.,
2024](#bib.bib1)); in self-distillation, the model itself supplies the
teacher predictions when conditioned on richer information.
Self-distillation fine-tuning uses demonstrations to acquire skills with
less forgetting ([Shenfeld et al., 2026](#bib.bib43)), and related
methods distill guidance from textual feedback ([Hübotter et al.,
2026](#bib.bib19)), verified solutions ([Zhao et al.,
2026](#bib.bib66)), or subsequent user messages ([Kleine Buening et al.,
2026](#bib.bib26)). While these methods parametrically update language
model weights, we focus on continual adaptation through an external
memory.

#### Memory and retrieval-augmented reasoning with LLMs.

Retrieval-augmented generation ([Lewis et al., 2020](#bib.bib29))
provides external evidence at inference time by retrieving relevant
information from a corpus or memory store, with structures ranging from
vector indexes to interconnected knowledge graphs ([Jiménez Gutiérrez
et al., 2025](#bib.bib21)). As these memories grow, their contents must
also be managed and revised: MemGPT manages information beyond the
context window ([Packer et al., 2023](#bib.bib38)), Mem0 consolidates
conversational records ([Chhikara et al., 2025](#bib.bib8)), and A-MEM
links and updates structured notes ([Xu et al., 2025](#bib.bib55)). For
reasoning, ExpeL and Metacognitive Reuse extract reusable guidance from
prior problem solving ([Zhao et al., 2024](#bib.bib65); [Didolkar
et al., 2025](#bib.bib11)), while Dynamic Cheatsheet, ACE, and
ReasoningBank maintain and refine strategies as experience accumulates
([Suzgun et al., 2026](#bib.bib47); [Zhang et al., 2026b](#bib.bib62);
[Ouyang et al., 2026](#bib.bib37)). Recent approaches also learn how
memory is constructed or used: ALMA searches over executable memory
designs ([Xiong et al., 2026](#bib.bib54)), and MILES learns selection
over an expanding library of step-level instructions ([Tong & Gong,
2026](#bib.bib50)). The focus in this work is on the probabilistic
organization of such memory content.

## 3 Structured Retrieval for Metacognitive Reasoning

#### Problem Setup.

We consider $`J`$ domains $`\mathcal{D}=\{1,\dots,J\}`$ (in our
experiments, math and physics), each with a corpus of prompts. From
these prompts we mine _behaviors_ – short natural-language reasoning
strategies, extracted by having the model solve a problem, reflect on
which general strategies its solution used, and record them (details in
Appendix [D](#A4 "Appendix D Implementation and Reproducibility ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory"))
– and embed their descriptions with a fixed sentence encoder
$`\mathcal{E}:\mathcal{S}\to\mathbb{R}^{D_{0}}`$ (where $`\mathcal{S}`$
is the space of text strings, including queries and behaviors), then
project into a lower-dimensional space via
$`f:\mathbb{R}^{D_{0}}\to\mathbb{R}^{D}`$ (PCA, fit once over the mined
corpus). We use $`e_{d,i}\in\mathbb{R}^{D}`$ to denote the projected
embedding of the $`i`$-th behavior mined from domain $`d`$, and
$`n_{d}`$ for the number of behaviors mined from domain $`d`$.

At inference, we condition generation on a small subset of behaviors
selected for relevance to the current query $`x`$: given $`e(x)`$, a
_selection rule_ $`\mathrm{Sel}`$ returns a set of behaviors whose
natural-language descriptions are inserted into the prompt. In the
online setting we study in this work, new pairs of (query,
mined-behavior) arrive sequentially as new samples are seen, and the
organizing structure itself must be able to adapt and incorporate each
one, and optionally, perform periodic reorganization. We formalize any
such structure with these properties as three operations on a state
$`\Omega`$, which represents the current memory organization:

|     |     |     |
| --- | --- | --- |
|     |

````math
\mathrm{retrieve}:\mathbb{R}^{D}\times\Omega\to\Delta^{K},\qquad\mathrm{update}:\mathbb{R}^{D}\times\Omega\to\Omega,\qquad\mathrm{refit}:\Omega\to\Omega
``` |  |

Here, $`\Delta^{K}`$ is the simplex of weights over the set of
components. If the mechanism has a flat structure, $`K`$ is simply the
total number of behaviors (each behavior is treated as its own
component); otherwise, if there is clustering, we take $`K`$ to be the
number of currently active components. This allows us to consider
different practical instantiations (organizing structures) under a
consistent online setup, with these being the central three operations
of the online TTT loop.

#### Starting Point: k-means clustering.

The simplest instantiation partitions $`\mathbb{R}^{D}`$ into $`K`$ hard
clusters with centroids $`\mu_{1},\dots,\mu_{K}`$, i.e.
$`\Omega=(\mu_{1},\dots,\mu_{K},n_{1},\dots,n_{K})`$ where $`n_{k}`$
counts points currently assigned to cluster $`k`$.

|  |  |  |
|----|----|----|
|  |
``` math
\mathrm{retrieve}(e(x),\Omega)=\mathrm{softmax}_{k}\!\left(-\frac{\|e(x)-\mu_{k}\|^{2}}{2\sigma^{2}}\right),\qquad\sigma^{2}=\frac{1}{K}\sum_{k}\sigma_{k}^{2},
``` |  |

where $`\sigma_{k}^{2}`$ is the scalar cluster variance. Given a newly
mined behavior with embedding $`e_{t}`$, the
$`\mathrm{update}(e_{t},\Omega)`$ operator allows for the mechanism to
grow the number of clusters by checking whether
$`1-\max_{j}\cos(e_{t},\mu_{j})`$ exceeds a threshold
$`\tau_{\mathrm{KM}}`$. If so, it creates a new cluster with centroid
$`\mu_{K+1}=e_{t}`$ and count $`n_{K+1}=1`$. Otherwise, it assigns the
behavior to the nearest centroid $`k^{\star}`$ and updates, while every
other centroid is unchanged:

|  |  |  |
|----|----|----|
|  |
``` math
\mu_{k^{\star}}\leftarrow\frac{n_{k^{\star}}\mu_{k^{\star}}+e_{t}}{n_{k^{\star}}+1},\qquad n_{k^{\star}}\leftarrow n_{k^{\star}}+1
``` |  |

The $`\mathrm{refit}(\Omega)`$ operator entails one full pass of Lloyd’s
algorithm: all accumulated points are reassigned to their nearest
centroids, each centroid is recomputed as the mean of its assigned
points, and any remaining empty clusters are removed.

This approach has a few key limitations. First, hard assignment assumes
clear specialization of the components in natural language, while
behaviors perhaps should actually lie in multiple clusters, and k-means
requires prescribing the number of clusters a priori for its
initialization; we want this to be determined in a data-driven manner.
Second, "growth" (in terms of the creation of new components) is not
tied to the probability-based retrieval mechanism, which can lead to
many singleton components or a few overloaded components. Also, k-means
remains flat and unable to express the notion of domain-specificity; we
want a structure that can encode domain-awareness while allowing for
behaviors to possibly be shared across domains, motivating a hierarchy.

## 4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM

We develop the Bayesian Cheatsheet, a nonparametric instantiation of a
structured cheatsheet using a Dirichlet Process Gaussian Mixture Model
(DP-GMM) ([Rasmussen, 2000](#bib.bib40)) to model behavior embeddings
and counts for each component. This serves as an analogue to the
$`k`$-means approach, with probabilistically latent assignment in lieu
of hard assignment, countably infinite components with
probability-driven growth rather than a fixed number, and an extension
to a Hierarchical DP-GMM for domain-aware modeling. The detailed
algorithm is included in Appendix
[B](#A2 "Appendix B Bayesian Cheatsheet Algorithm ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory").

### 4.1 Generative Mixtures with Dirichlet Processes

First consider a single domain. We draw a random probability measure:

|  |  |  |
|----|----|----|
|  |
``` math
G\sim\mathrm{DP}(\gamma,H),\qquad H=\mathrm{NIW}(\mu_{0},\kappa_{0},\Psi_{0},\nu_{0})
``` |  |

with the NIW distribution being the conjugate base distribution over
Gaussian parameters. G is a discrete random probability measure, and
thus can be written as

|  |  |  |
|----|----|----|
|  |
``` math
G=\sum_{k=1}^{\infty}\pi_{k}\delta_{\phi_{k}},\qquad\phi_{k}=(\mu_{k},\Sigma_{k}),\qquad\phi_{k}\overset{\mathrm{i.i.d.}}{\sim}H
``` |  |

as many observations can share the same atomic value $`\phi_{k}`$. We
model each behavior embedding $`e_{i}`$ as:

|  |  |  |
|----|----|----|
|  |
``` math
z_{i}\mid\pi\sim\mathrm{Cat}(\pi),\qquad e_{i}\mid z_{i}=k\sim\mathcal{N}(\mu_{k},\Sigma_{k}).
``` |  |

Marginalizing over $`G`$ yields the Chinese Restaurant Process (CRP).
Conditioned on the previous assignments, a new behavior is assigned to
an existing component $`k`$ with probability proportional to its
occupancy $`n_{k}`$, or instantiates a new component with probability
proportional to $`\gamma`$. As a result, the number of components
($`K`$) is determined in a data-driven manner rather than fixed a
priori.

Given a mined corpus of behavior embeddings $`X`$, the
$`\mathrm{retrieve}(x)`$ operation uses the posterior assignment
probability:

|     |                                                       |     |     |
|-----|-------------------------------------------------------|-----|-----|
|     |
       ``` math
       p(z_{x}=k\mid e(x),X)\propto n_{k}\,p(e(x)\mid X_{k})
       ```                                                    |     | (1) |

where $`X_{k}=\{e_{i}:z_{i}=k\}`$ and $`p(e(x)\mid X_{k})`$ is the
posterior predictive density for component $`k`$. Correspondingly, the
unnormalized score for spawning a new component is given by
$`\gamma\,p(e(x)\mid H)`$. Under the NIW prior, the predictive densities
are multivariate Student-$`t`$ distributions.

Crucially, the posterior of each component depends only on three
additive sufficient statistics:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
n_{k}=|\{i:z_{i}=k\}|,\qquad S_{k}^{(1)}=\textstyle\sum_{i:z_{i}=k}e_{i},\qquad S_{k}^{(2)}=\textstyle\sum_{i:z_{i}=k}e_{i}e_{i}^{\top}
``` |  | (2) |

Thus, incorporating a newly discovered behavior at test-time requires
only incrementing these three values, allowing for online adaptation
without needing to refit the full mixture after each observation.

### 4.2 Hierarchical Construction for Cross-Domain Structure

A single DP-GMM fit on a pooled corpus of cross-domain problems and
behaviors cannot express the prevalence of components at the
domain-specific level. At the same time, fitting independent DP-GMMs per
domain can result in redundancy and unnecessary overhead, preventing
components from being shared. For instance, a behavior like "use modular
arithmetic" could be useful for a number theory problem as well as for
periodic boundary conditions in a physics problem.

A Hierarchical Dirichlet Process (HDP) ([Teh et al., 2006](#bib.bib49))
addresses this by drawing the atoms $`\{\phi_{k}\}`$ once at the global
level, and letting each domain draw its own DP over them, with
$`\theta_{d,i}=(\mu_{d,i},\Sigma_{d,i})`$:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle G_{0}`$ | $`\displaystyle\sim\mathrm{DP}(\gamma,H),`$ |  |
|  | $`\displaystyle G_{d}\mid G_{0}`$ | $`\displaystyle\sim\mathrm{DP}(\alpha_{d},G_{0}),\hskip 5.69054pt\forall\hskip 1.42262ptd\in\mathcal{D},`$ |  |
|  | $`\displaystyle\theta_{d,i}\mid G_{d}`$ | $`\displaystyle\sim G_{d},`$ |  |
|  | $`\displaystyle e_{d,i}\mid\theta_{d,i}`$ | $`\displaystyle\sim\mathcal{N}(\mu_{d,i},\Sigma_{d,i})`$ |  |

Thus, the Gaussian parameters $`\phi_{k}=(\mu_{k},\Sigma_{k})`$ are
shared across domains, while the mixing weights $`\pi_{d}`$ are domain
specific. Marginalizing the global and domain-specific random measures
yields the Chinese Restaurant Franchise (CRF) representation.

As in the single-domain construction, let $`z_{d,i}=k`$ denote that
behavior $`(d,i)`$ uses the shared atom $`\phi_{k}`$. Conditional on
$`\pi_{d}`$, this assignment has probability
$`p(z_{d,i}=k\mid\pi_{d})=\pi_{d,k}`$. We distinguish the local
occupancy of component $`k`$ in domain $`d`$,
$`n_{d,k}=|\{i:z_{d,i}=k\}|`$, from its global occupancy
$`N_{k}=\sum_{d\in\mathcal{D}}n_{d,k}`$. The local counts determine the
domain-specific mixing weights, whereas the posterior of the shared
Gaussian component uses observations pooled across domains. The
sufficient statistics
(Equation [2](#S4.E2 "In 4.1 Generative Mixtures with Dirichlet Processes ‣ 4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory"))
generalize by using $`N_{k}`$ and summing $`S_{k}^{(1)}`$ and
$`S_{k}^{(2)}`$ over every domain.

### 4.3 Posterior Inference via Collapsed Gibbs Sampling

To fit the HDP-GMM, we use a collapsed Gibbs sampler ([Neal,
2000](#bib.bib35)) in the CRF representation, leveraging NIW-Gaussian
conjugacy in marginalizing out the Gaussian parameters $`\phi_{k}`$. We
also integrate out the random measures, retaining local groups and their
mappings to shared global components ([Teh et al., 2006](#bib.bib49)).
Marginalizing over the local-group choice gives the assignment
probability for an existing component:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p(z_{d,i}=k\mid\cdot)\propto\left(n_{d,k}^{-i}+\alpha_{d}\widehat{\beta}_{k}^{-i}\right)p_{k}^{-(d,i)}(e_{d,i}),\qquad k=1,\ldots,K
``` |  | (3) |

Here, $`n_{d,k}^{-i}`$ counts behaviors assigned to component $`k`$
within domain $`d`$, $`\widehat{\beta}_{k}^{-i}`$ is the global
predictive mass derived from the group-to-component counts, and
$`p_{k}^{-(d,i)}`$ is the Student-$`t`$ posterior predictive computed
from behaviors pooled across domains – all excluding observation
$`(d,i)`$.

Relative to the single-domain posterior rule
([1](#S4.E1 "In 4.1 Generative Mixtures with Dirichlet Processes ‣ 4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory")),
the hierarchical structure lets the memory reflect both domain-specific
patterns as well as cross-domain reuse. The local count $`n_{d,k}^{-i}`$
concentrates observations onto prevalent components that are already
common within domain $`d`$, following the "rich-get-richer" effect
associated with DPs. The $`\alpha_{d}\widehat{\beta}_{k}^{-i}`$ term
allows a domain to draw on components learned across the corpus through
the mixing weights. The predictive density weights this by how well the
behavior’s embedding fits the component, so assignment depends on both
the behavior itself and the frequency of its component. Overall, this
allows the memory to share existing reasoning patterns across domains
while also accommodating additional components as behaviors accumulate.

A complete step of partially collapsed Gibbs resamples every $`z_{d,i}`$
in random order and recomputes both the local counts and the globally
pooled sufficient statistics. Offline fitting of the HDP-GMM repeats
this procedure for a fixed iteration count. Further mathematical details
on the two-level sampling procedure for our collapsed Gibbs sampling
process are included in
Appendix [C](#A3 "Appendix C Collapsed Gibbs Sampling ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory").

### 4.4 Test-Time Adaptation

#### Retrieval via the posterior predictive.

In the offline phase, the embedding used is the behavior’s own embedding
(applying $`\mathcal{E}`$), and we apply PCA for efficiency in fitting
the mixture model (described in
Appendix [D.2](#A4.SS2 "D.2 Mixture Hyperparameters ‣ Appendix D Implementation and Reproducibility ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory")).
At inference time, $`e(x)`$ is approximated with a small learned
projector $`f_{\theta}`$ to map raw query embeddings into the same space
(see
Appendix [D](#A4 "Appendix D Implementation and Reproducibility ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory")).
With domain-conditioning, the query’s domain is inferred using a
nearest-centroid classifier, where $`c_{d}`$ is the centroid of domain
$`d`$’s data:

|  |  |  |
|----|----|----|
|  |
``` math
d_{x}=\widehat{d}(x)=\argmin_{d\in\mathcal{D}}\operatorname{dist}\!\left(e(x),c_{d}\right)
``` |  |

Then $`\mathrm{retrieve}(e(x),\Omega)`$ combines these domain-specific
mixture weights with the globally shared component predictives, so
domains can share the same components but retrieve them with different
probabilities. The normalized weight for each component under the
Student-$`t`$ posterior predictive is:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
w_{d_{x},k}(e(x))=\frac{\widehat{\pi}_{d_{x},k}\,p_{k}(e(x))}{\sum_{j=1}^{K}\widehat{\pi}_{d_{x},j}\,p_{j}(e(x))}
``` |  | (4) |

We consider component selection either by taking the top-$`k^{\prime}`$
components by weight or choosing every component whose weight exceeds a
threshold $`\tau`$. Once components are selected, the medoid element is
returned for each component, treated as its representative element.

#### Online updates and new component creation.

After generating a response to query $`x_{t}`$, the model mines a new
behavior by self-reflection on its reasoning, with embedding $`e_{t}`$
and domain $`d_{t}=\widehat{d}(x_{t})`$. A discrete CRF partition
produces the mixing weights, while responsibility-weighted Gaussian
statistics determine the online densities; the predictive probability of
a new component is:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\rho_{\mathrm{new}}(e_{t})=\frac{\widehat{\pi}_{d_{t},\mathrm{new}}p_{0}(e_{t})}{\widehat{\pi}_{d_{t},\mathrm{new}}p_{0}(e_{t})+\sum_{k=1}^{K}\widehat{\pi}_{d_{t},k}\,p_{k}(e_{t})}
``` |  | (5) |

Inspired by [Kulis & Jordan (2012)](#bib.bib27), we use thresholding: if
$`\rho_{\mathrm{new}}(e_{t})`$ exceeds $`\tau_{\mathrm{new}}`$, we spawn
a new globally shared component, initialize its Gaussian sufficient
statistics using $`e_{t}`$, and create a local group containing this
behavior. Otherwise, it is softly added to existing components with
$`w_{d_{t},k}(e_{t})>10^{-6}`$, weighted accordingly. The effective
Gaussian sufficient statistics for $`\mathrm{update}(e_{t},\Omega)`$
are:

|  |  |  |  |  |  |  |  |  |
|----|----|----|----|----|----|----|----|----|
|  | $`\displaystyle\widetilde{N}_{k}`$ | $`\displaystyle\leftarrow\widetilde{N}_{k}+w_{d_{t},k}(e_{t}),`$ | $`\displaystyle\widetilde{S}_{k}^{(1)}`$ | $`\displaystyle\leftarrow\widetilde{S}_{k}^{(1)}+w_{d_{t},k}(e_{t})e_{t},`$ | $`\displaystyle\widetilde{S}_{k}^{(2)}`$ | $`\displaystyle\leftarrow\widetilde{S}_{k}^{(2)}+w_{d_{t},k}(e_{t})e_{t}e_{t}^{\top}`$ |  | (6) |

We also separately store the hard assignment
$`z_{t}=\argmax_{k}w_{d_{t},k}(e_{t})`$ and sample its local group
assignment conditional on $`z_{t}`$, incrementing the local group
element count and $`n_{d_{t},z_{t}}`$. If a new local group is created,
we also increment $`M_{z_{t}}`$, the global group count.

Periodic refitting. Every $`g`$ samples (the refit interval), we perform
$`\mathrm{refit}(\Omega)`$ by rebuilding Gaussian statistics from the
stored hard assignments and performing a single collapsed Gibbs step
over all behaviors, keeping domain labels fixed. We then greedily merge
components whose symmetric Gaussian KL-divergence is $`<\epsilon`$,
updating group mappings, counts, and statistics. This allows for
reorganization to reconcile drift that may be introduced by performing
many soft updates over time.

## 5 Results

### 5.1 Experimental Setup

#### Models.

All experiments are performed with the Qwen3-32B ([Yang et al.,
2025](#bib.bib57)) and Granite-4.2-30B ([IBM Granite Team,
2026](#bib.bib20)) language models, with thinking/reasoning modes
enabled. Allowing language models to leverage their reasoning abilities
to the fullest ensures that retrieved reasoning behaviors from
cheatsheets can be reflected in their natural language reasoning traces.

#### Datasets.

We evaluate on three reasoning-intensive benchmarks: AIME’25 ([Art of
Problem Solving, 2025](#bib.bib3)), Omni-MATH¹¹ 1 Specifically, we
consider a hard subset consisting only of problems with
$`\mathrm{difficulty}\geq 7.0`$. ([Gao et al., 2025](#bib.bib14)), and
PhysReason²² 2 We consider solely the questions which do not require an
image (i.e. text-only), given that the open-weight language models we
consider do not have multimodal capabilities, yielding 226 questions
(mini has 31). ([Zhang et al., 2025](#bib.bib64)), averaged over 3
seeds. Our behavior corpus (existing memory) was mined offline from
NuminaMath-CoT ([Li et al., 2024](#bib.bib31)) and the Camel Physics
([Li et al., 2023](#bib.bib30)) datasets; the respective language model
solves each problem and produces a self-reflection of the behaviors that
were useful in solving the problem, regardless of the answers’
correctness. The corpus was mined separately for each language model,
providing an on-policy reasoning bank. Further details on the behavior
corpus are included in Appendix
[D.1](#A4.SS1 "D.1 Behavior Mining Procedure and Corpus ‣ Appendix D Implementation and Reproducibility ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory").

#### Baselines.

We consider a number of baselines, evaluated both with and without the
pre-mined memory, with the key differences being the retrieval and
adaptation mechanisms. This includes: 1. random behavior selection of
$`k^{\prime}`$ elements; 2. Metacognitive Reuse ([Didolkar et al.,
2025](#bib.bib11)), which involves flat cosine-similarity retrieval over
the behavior library (top-$`k^{\prime}`$) in embedding space; and 3.
direct behavior retrieval, performing flat retrieval in the
$`f_{\theta}`$-projected space rather than embedding space. For the
dynamic (test-time adaptation) setting, we consider the Dynamic
Cheatsheet ([Suzgun et al., 2026](#bib.bib47)) method (both DC-Cu and
DC-RS), which grows the library as it solves, with up to max_new=3
elements added per sample, and has the ability to rewrite and refine the
cheatsheet purely in natural language (as it has a flat structure). We
also consider the ACE method ([Zhang et al., 2026b](#bib.bib62)) which,
on top of Dynamic Cheatsheet, introduces iterative refinement through a
reflector as well as editing and deduplication. In practice, we use
$`k^{\prime}=5`$ for all experimental results.

#### Methods.

We evaluate the Bayesian Cheatsheet (BC) as described in Section
[4](#S4 "4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory"),
as well as $`k`$-means clustering as introduced in Section
[3](#S3 "3 Structured Retrieval for Metacognitive Reasoning ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory").
We also include BC-centroids, which selects the $`k^{\prime}`$ closest
centroids over the HDP-GMM-fitted components, rather than posterior
predictive selection. This allows us to isolate the role of 1. structure
(these mechanisms against the baselines), 2. adaptation (HDP-GMM vs
$`k`$-means), 3. flexible assignment (hard $`k`$-means vs soft
$`k`$-means and HDP-GMM), and 4. component selection (posterior
predictive vs. nearest-centroid top-$`k^{\prime}`$). To bring the
$`k`$-means algorithms to a level playing field with the HDP-GMM
mechanism, we introduce adaptive versions with online updates for each,
along with analogues for the Gibbs refit. Hard $`k`$-means assigns each
new behavior to its nearest centroid and updates that centroid, while
refitting is just Lloyd reassignment. For soft $`k`$-means (an isotropic
generative variant), the online updates fold each new behavior into
every cluster with weight above $`10^{-6}`$, with the refitting being a
responsibility-weighted soft EM procedure. To standardize across
methods, we take $`K`$ (number of initial clusters for $`k`$-means
methods) to be the same number of components yielded in fitting the
HDP-GMM, yielding 64 clusters (Qwen), and 62 clusters (Granite) – we
include a list of labels for each component in Appendix
[G.1](#A7.SS1 "G.1 Component Meta-Labels ‣ Appendix G Qualitative Examples ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory").

but also on how the memory makes them accessible for a given query.

#### Periodic Refitting of Components.

We quantify how much a refit changes the behavior-component assignment
with a maximum-overlap bipartite matching. Let
$`\ell_{\mathrm{before}},\ell_{\mathrm{after}}`$ be the cluster labels
assigned to the $`n`$ accumulated points immediately before and after a
refit (which may consist of different label sets and active label
counts). Consider the contingency table:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
M[b,a]=\big|\{i\in[n]:\ell_{\mathrm{before}}(i)=b,\;\ell_{\mathrm{after}}(i)=a\}\big|
``` |  | (7) |

We want to find the label correspondence maximizing total overlap over
one-to-one matchings $`\sigma`$:

|     |                                                       |     |     |
|-----|-------------------------------------------------------|-----|-----|
|     |
       ``` math
       \sigma^{\star}=\argmax_{\sigma}\sum_{b}M[b,\sigma(b)]
       ```                                                    |     | (8) |

This is an assignment problem, which is solvable with the Hungarian
algorithm. A point is counted as a reassignment only if its label in
$`\ell_{\mathrm{after}}`$ differs from the matched image of its label in
$`\ell_{\mathrm{before}}`$. A pure relabeling should receive zero churn,
and we are only counting the points that change clusters:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\text{\emph{churn}}=\frac{1}{n}\sum_{i=1}^{n}\mathds{1}\!\left[\ell_{\mathrm{after}}(i)\neq\sigma^{\star}(\ell_{\mathrm{before}}(i))\right],
``` |  | (9) |

#### Cold-Start Memory Accumulation.

Thus far, we have considered the setting where an offline-mined behavior
corpus is available to the language model as memory in metacognitive
reasoning. What if the language model were instead given a blank slate
and tasked with learning the cheatsheet on-the-fly, purely through
self-reflection? We evaluate our method (an empty memory initialized
with an NIW prior) as well as ACE and DC-Cu (in their cold-start
constructions), to determine whether Bayesian Cheatsheet is dependent on
a warm-started memory module.

## 6 Discussion

We introduce the Bayesian Cheatsheet, a structured memory module for
language models which uses Dirichlet Process Gaussian Mixture Models for
component structure. We leverage this mechanism to organize reasoning
strategies for inference-time retrieval, and demonstrate that this
mechanism exhibits desirable properties in continual test-time
adaptation while achieving clear gains in performance across reasoning
benchmarks. Bayesian Cheatsheets offer a potential mechanism for offline
domain adaptation through their hierarchical design; new behaviors and
mixing weights can be learned for unseen domains, while also inferring
shared cross-domain structure. In this work, we focus on single-turn
problem solving with small-to-medium-size non-agentic language models
($`\approx 30B`$ parameters); while agentic and multi-turn benchmarks
are currently beyond our scope, they offer practical potential for
iterative retrieval from the Bayesian Cheatsheet. Furthermore, the
refitting and retrieval costs eventually grow over indefinitely long
evaluation streams, suggesting the need for principled discarding
mechanisms to selectively retain behaviors. Overall, our findings
highlight the potential for Bayesian-inspired methods to yield value for
test-time adaptation of language models, given the setting’s analogues
to online learning, offering an effective, statistically-grounded
mechanism.

## Appendix A Additional Related Work

#### LLM reasoning methods.

In-context learning provides language models with the ability to infer a
task based on demonstrations, without updating their parameters ([Brown
et al., 2020](#bib.bib7)), a behavior that has an implicit Bayesian
interpretation ([Xie et al., 2022](#bib.bib53)). Reasoning-oriented
prompting makes intermediate computations available in natural language
in the context through scratchpads ([Nye et al., 2021](#bib.bib36)) and
chain-of-thought ([Wei et al., 2022](#bib.bib52)), which enables
approaches that decompose problems into simpler subproblems ([Zhou
et al., 2023](#bib.bib67)), aggregate multiple reasoning paths through
self-consistency ([Wang et al., 2023](#bib.bib51)), or search over
alternative intermediate steps ([Yao et al., 2023](#bib.bib59)).

Self-reflection extends this notion by allowing models to critique and
revise their own solutions. Self-Refine alternates between generation,
feedback, and revision ([Madaan et al., 2023](#bib.bib34)), while
Reflexion retains verbal feedback in episodic memory for subsequent
attempts ([Shinn et al., 2023](#bib.bib45)). Related work on
metacognition studies whether models can extract generalizable lessons
from problem solving ([Didolkar et al., 2024](#bib.bib10)), although
some evaluations of intrinsic self-correction show that revisions can
fail to improve reasoning without external feedback ([Huang et al.,
2024](#bib.bib18)). These behaviors can also be learned through
training, as in STaR’s fine-tuning on self-generated rationales that
lead to correct answers ([Zelikman et al., 2022](#bib.bib60)), training
to self-correct ([Kumar et al., 2024](#bib.bib28); [Ramji et al.,
2025](#bib.bib39)), and Experiential Reinforcement Learning’s use of
feedback-guided revisions ([Shi et al., 2026](#bib.bib44)).

#### Bayesian modeling for natural language.

Bayesian nonparametric models have been used in language tasks to learn
latent structures where size is not fixed a priori, ranging from word
segmentation ([Goldwater et al., 2006](#bib.bib15)) to the reusable
grammar subtrees of adaptor grammars ([Johnson et al.,
2007](#bib.bib22)). The hierarchical Dirichlet process ([Teh et al.,
2006](#bib.bib49)) is particularly useful in topic modeling, allowing
for topics to be shared across documents while having document-specific
proportions, while hierarchical Pitman–Yor language models ([Teh,
2006](#bib.bib48)) are useful for different-length contexts. Related
hierarchical sharing appears in domain adaptation, where [Finkel &
Manning (2009)](#bib.bib13) link domain-specific model parameters
through a shared Gaussian prior, which balances cross-domain guidance
with domain-specific observations. For continuous representations,
Gaussian LDA ([Das et al., 2015](#bib.bib9)) models word embeddings with
Gaussian topic distributions with a fixed topic inventory. By contrast,
infinite Gaussian mixtures, as introduced in ([Rasmussen,
2000](#bib.bib40)), should allow the number of occupied components to
grow with the data. Bayesian inference has also been used with modern
language models in uncertainty quantification and guided generation.
Laplace-LoRA approximates a posterior over adaptation parameters for
improved calibration ([Yang et al., 2024a](#bib.bib56)), while [Hu
et al. (2024)](#bib.bib17) use amortized posterior inference for
constrained generation and implicit reasoning.

#### Test-time adaptation and continual learning (continued).

SEAL ([Zweiger et al., 2025](#bib.bib68)) learns to generate synthetic
training data and the updates to adapt the language model (i.e. learning
how to adapt itself). In architectures such as Titans ([Behrouz et al.,
2025b](#bib.bib6)) and ATLAS ([Behrouz et al., 2025a](#bib.bib5)),
adaptation instead takes place through a neural memory that learns from
the incoming context. For agents, AutoHarness ([Lou et al.,
2026](#bib.bib33)) uses environment feedback to synthesize and refine
code that constrains an LLM’s actions, while Hyperagents ([Zhang et al.,
2026a](#bib.bib61)) make both the task-solving program and the procedure
for modifying it editable. Harness Continual Learning ([Kang et al.,
2026](#bib.bib23)) treats prompts, memory, skills, and routing as a
persistent, jointly updated state, evaluating candidate changes to
improve on the current task while retaining earlier capabilities before
deployment.

#### Memory and retrieval-augmented reasoning with LLMs (continued).

Nonparametric retrieval allows for new information to be incorporated
without retraining the language model; nearest-neighbor language models
can do this by changing the retrieval datastore ([Khandelwal et al.,
2020](#bib.bib24)). Hierarchical retrieval methods organize information
at multiple levels of abstraction: for example, RAPTOR recursively
clusters and summarizes document passages into a retrieval tree ([Sarthi
et al., 2024](#bib.bib42)), while MemTree incrementally builds a
hierarchy of semantic summaries as observations arrive ([Rezazadeh
et al., 2024](#bib.bib41)). Buffer of Thoughts maintains reusable
thought templates as procedural memory ([Yang et al.,
2024b](#bib.bib58)), and Memp distills trajectories into both detailed
instructions and higher-level abstractions that can be revised over time
with experience ([Fang et al., 2026](#bib.bib12)). In MemRL, the utility
of stored experiences is learned from feedback, so that retrieval
accounts for their usefulness ([Zhang et al., 2026c](#bib.bib63)). In
ALMA, memory organization is a learned goal, where executable designs
specifying what to store, how to retrieve, and how to update (the three
key operations we defined in Section
[3](#S3 "3 Structured Retrieval for Metacognitive Reasoning ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory"))
are searched over ([Xiong et al., 2026](#bib.bib54)).

## Appendix B Bayesian Cheatsheet Algorithm

The memory (modeled by $`\Omega`$) stores records of behaviors and their
embeddings, as well as domain, component, and local group assignments,
local and global CRF counts, Gaussian sufficient statistics, and the
medoid elements for retrieval.

1: Initial memory $`\Omega_{0}`$, NIW prior $`H`$, concentrations
$`\gamma,\{\alpha_{d}\}`$, queries $`x_{1:T}`$

2: Retrieval budget $`k^{\prime}`$, novelty threshold
$`\tau_{\mathrm{new}}`$, refit interval $`g`$ (or disabled), merge
threshold $`\epsilon`$

3: Set $`\Omega\leftarrow\Omega_{0}`$; compute component predictives,
CRF weights, and medoids

4: for $`t=1,2,\dots,T`$ do

5:   Embed query as $`e(x_{t})`$ and infer $`d_{t}=\widehat{d}(x_{t})`$;
use the sole domain in cold start

6:   Set the retrieved behavior set
$`\mathcal{R}_{t}\leftarrow\varnothing`$

7:   if memory is nonempty then

8:    Select up to $`k^{\prime}`$ highest-weight components via
$`w_{d_{t},k}(e(x_{t}))`$
(Eq. [4](#S4.E4 "In Retrieval via the posterior predictive. ‣ 4.4 Test-Time Adaptation ‣ 4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory"))

9:    Set $`\mathcal{R}_{t}`$ to one medoid behavior per selected
component

10:   end if

11:   Generate the response using $`\mathcal{R}_{t}`$, then mine a
behavior $`b_{t}`$ and compute its embedding $`e_{t}`$

12:   Set $`\rho_{\mathrm{new}}(e_{t})=1`$ if memory is empty; otherwise
evaluate
Eq. [5](#S4.E5 "In Online updates and new component creation. ‣ 4.4 Test-Time Adaptation ‣ 4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory")
on the current memory

13:   if memory is empty or
$`\rho_{\mathrm{new}}(e_{t})>\tau_{\mathrm{new}}`$ then

14:    Create a global component $`z_{t}`$ with zero CRF counts; set
$`\ell_{t}\leftarrow\mathrm{new}`$

15:
   $`(\widetilde{N}_{z_{t}},\widetilde{S}_{z_{t}}^{(1)},\widetilde{S}_{z_{t}}^{(2)})\leftarrow(1,e_{t},e_{t}e_{t}^{\top})`$

16:   else

17:    Cache $`w_{d_{t},k}(e_{t})`$ for all existing $`k`$ using
Eq. [4](#S4.E4 "In Retrieval via the posterior predictive. ‣ 4.4 Test-Time Adaptation ‣ 4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory"),
before changing $`\Omega`$

18:    for each $`k`$ with $`w_{d_{t},k}(e_{t})>10^{-6}`$ do

19:

## Appendix C Collapsed Gibbs Sampling

This section expands on the collapsed Gibbs sampler in
Section [4.3](#S4.SS3 "4.3 Posterior Inference via Collapsed Gibbs Sampling ‣ 4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory"),
which organizes behavior embeddings into shared components while
preserving domain-specific use patterns. We first obtain each
component’s posterior predictive from its pooled sufficient statistics,
then describe the CRF assignment updates and the resulting
domain-specific retrieval weights.

Given the global sufficient statistics for component $`k`$, the
posterior over $`\phi_{k}`$ is
$`\mathrm{NIW}(\mu_{k}^{\prime},\kappa_{k}^{\prime},\Psi_{k}^{\prime},\nu_{k}^{\prime})`$:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\kappa_{k}^{\prime}`$ | $`\displaystyle=\kappa_{0}+N_{k},\qquad\nu_{k}^{\prime}=\nu_{0}+N_{k},`$ |  |
|  | $`\displaystyle\mu_{k}^{\prime}`$ | $`\displaystyle=\frac{\kappa_{0}\mu_{0}+S_{k}^{(1)}}{\kappa_{k}^{\prime}},\qquad\Psi_{k}^{\prime}=\Psi_{0}+\left(S_{k}^{(2)}-N_{k}\bar{e}_{k}\bar{e}_{k}^{\top}\right)+\frac{\kappa_{0}N_{k}}{\kappa_{k}^{\prime}}(\bar{e}_{k}-\mu_{0})(\bar{e}_{k}-\mu_{0})^{\top}`$ |  |

Here, $`\bar{e}_{k}=\frac{S_{k}^{(1)}}{N_{k}}`$ for $`N_{k}>0`$.
Integrating $`\phi_{k}`$ out of the Gaussian likelihood gives a
multivariate Student-$`t`$ posterior predictive:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p_{k}(e)\equiv p(e\mid X_{k})=t_{\nu_{k}^{\prime}-D+1}\!\left(e\;\middle|\;\mu_{k}^{\prime},\frac{\kappa_{k}^{\prime}+1}{\kappa_{k}^{\prime}(\nu_{k}^{\prime}-D+1)}\Psi_{k}^{\prime}\right)
``` |  | (10) |

For an empty component, the sufficient statistics are zero, so the
posterior parameters reduce to
$`(\mu_{0},\kappa_{0},\Psi_{0},\nu_{0})`$. Then, integrating over this
NIW prior yields the prior predictive, which we denote
$`p_{0}(e)=p(e\mid H)`$.

When resampling observation $`(d,i)`$, we use a two-level
assignment/partition structure based on [Teh et al. (2006)](#bib.bib49).
We maintain an auxiliary partition of the behavior observations within
each domain $`d`$ into local groups, each of which is mapped to a global
component, of which there are $`K`$ total. Multiple groups may map to
the same component, inducing component-sharing across domains. Let
$`\ell_{d,i}`$ denote the local-group assignment for sample $`(d,i)`$,
so $`n_{d,\ell}^{-i}`$ is the count of behaviors already in group
$`\ell`$ excluding $`(d,i)`$, $`k_{\ell}`$ is the component that group
$`\ell`$ maps to, and
$`M_{k}^{-i}=\sum\limits_{d^{\prime}\in\mathcal{D}}m_{d^{\prime},k}^{-i}`$
is the total number of groups across all domains mapped to component
$`k`$, excluding $`(d,i)`$.

A first categorical draw is done to assign $`\ell_{d,i}`$ over the set
of existing local groups as well as a potential new group.

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p(\ell_{d,i}=\ell\mid\cdot)\propto\begin{cases}n_{d,\ell}^{-i}\,p_{k_{\ell}}^{-(d,i)}(e_{d,i}),\hskip 128.0374pt\ell\text{ is an existing local group}\\[4.0pt]
\frac{\alpha_{d}}{\gamma+\sum_{j=1}^{K}M_{j}^{-i}}\left(\sum_{k=1}^{K}M_{k}^{-i}p_{k}^{-(d,i)}(e_{d,i})+\gamma p_{0}(e_{d,i})\right),\hskip 14.22636pt\ell=\mathrm{new}\end{cases}
``` |  | (11) |

Marginalizing over local group choice gives the equivalent
component-level assignment score, for
$`\widehat{\beta}_{k}^{-i}=\frac{M_{k}^{-i}}{\gamma+\sum_{j=1}^{K}M_{j}^{-i}}`$:

|  |  |  |
|----|----|----|
|  |
``` math
p(z_{d,i}=k\mid\cdot)\propto\left(n_{d,k}^{-i}+\alpha_{d}\widehat{\beta}_{k}^{-i}\right)p_{k}^{-(d,i)}(e_{d,i}),
``` |  |

If a new group is spawned, we next sample the component this new group
maps to, setting $`z_{d,i}`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p(z_{d,i}=k\mid\ell_{d,i}=\mathrm{new},\cdot)\propto\begin{cases}M_{k}^{-i}\,p_{k}^{-(d,i)}(e_{d,i}),&k=1,\ldots,K\,(\mathrm{existing})\\[4.0pt]
\gamma\,p_{0}(e_{d,i}),&k=\mathrm{new}\end{cases}
``` |  | (12) |

The mixing weights used in retrieval are estimates derived from the
group-to-component mapping counts, which are posterior means under the
partition structure:

|  |  |  |
|----|----|----|
|  |
``` math
\widehat{\beta}_{k}=\frac{M_{k}}{\gamma+\sum_{j=1}^{K}M_{j}},\qquad\widehat{\beta}_{\mathrm{new}}=\frac{\gamma}{\gamma+\sum_{j=1}^{K}M_{j}}
``` |  |

|  |  |  |
|----|----|----|
|  |
``` math
\widehat{\pi}_{d,k}=\frac{n_{d,k}+\alpha_{d}\widehat{\beta}_{k}}{\alpha_{d}+\sum_{j=1}^{K}n_{d,j}},\qquad\widehat{\pi}_{d,\mathrm{new}}=\frac{\alpha_{d}\widehat{\beta}_{\mathrm{new}}}{\alpha_{d}+\sum_{j=1}^{K}n_{d,j}}
``` |  |

## Appendix D Implementation and Reproducibility

### D.1 Behavior Mining Procedure and Corpus

We construct a separate behavior corpus for each language model,
Qwen3-32B and Granite-4.2-30B, using the same model for behavior mining
and evaluation (i.e. the behaviors are on-policy for the respective
model). We randomly sampled 20,000 mathematics prompts from
NuminaMath-CoT ([Li et al., 2024](#bib.bib31)) and 20,000 physics
prompts from Camel Physics ([Li et al., 2023](#bib.bib30)).

Mining follows a three-stage metacognitive procedure, inspired by
[Didolkar et al. (2025)](#bib.bib11). First, the model solves each
problem by generating a chain-of-thought solution. It then reflects on
the solution, assessing its correctness and identifying missing or
reusable reasoning behaviors. Finally, it extracts these behaviors as
structured {name: description} records. Extraction is performed
regardless of whether the generated answer is correct or not. The
extraction prompt instructs the model to replace problem-specific
numerical values with symbolic placeholders, so that the descriptions
are generalizable and transferable strategies are expressed.

After extraction is performed over the full prompt set, we deduplicate
behavior records based on exact match of their labels (the name field).
The resulting Qwen corpus contains 57,955 mathematics behaviors and
75,324 physics behaviors, while the Granite corpus contains 26,305
mathematics behaviors and 15,839 physics behaviors; the difference
reflects this deduplication step. In warm-started comparisons for a
given language model, all memory-based methods use the same
model-specific corpus, for standardized comparison.

We embed behavior descriptions using granite-embedding-english-r2
([Awasthy et al., 2025](#bib.bib4)) and fit a separate PCA transform on
each model’s mined corpus, reducing the embeddings to $`D=128`$
dimensions. Each of these PCA transforms is held fixed during fitting of
the mixture as well as test-time adaptation.

### D.2 Mixture Hyperparameters

We fit a separate HDP-GMM for each model’s corpus using the
configuration detailed in
Table [3](#A4.T3 "Table 3 ‣ D.2 Mixture Hyperparameters ‣ Appendix D Implementation and Reproducibility ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory"),
using the Gibbs sampling procedure described in Section
[4.3](#S4.SS3 "4.3 Posterior Inference via Collapsed Gibbs Sampling ‣ 4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory")
and Appendix
[C](#A3 "Appendix C Collapsed Gibbs Sampling ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory").
The resulting fitted mixtures contain 64 components for Qwen and 62 for
Granite, without setting any fixed component numbers a priori. The prior
scale $`\Psi_{0}`$ is set relative to the empirical covariance of the
projected behavior embeddings. The main results use explicit domain
conditioning (described in Section
[4.4](#S4.SS4 "4.4 Test-Time Adaptation ‣ 4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory")),
where the projected query is assigned to its nearest domain centroid,

### D.3 Learning the Query Projector ($`f_{\theta}`$)

The learned query projector $`f_{\theta}`$ maps the problem’s embedding
into the (PCA-transformed) space in which the behavior mixture was
fitted. We use a multilayer perceptron with two hidden layers
(width=\[512, 256\]) and a 128-dimensional output. The training data of
(query, behavior) pairs comes from the mining procedure in Appendix
[D.1](#A4.SS1 "D.1 Behavior Mining Procedure and Corpus ‣ Appendix D Implementation and Reproducibility ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory");
for a pair $`(x,b)`$, let $`q(x)=\mathcal{E}(x)`$ be the raw query
embedding and let $`u_{b}=\operatorname{PCA}(\mathcal{E}(b))`$ be the
projected behavior embedding.

Because downstream retrieval evaluates a Student-t posterior predictive
density under the fitted mixture, which depends on the scale of
$`f_{\theta}(q(x))`$ relative to each component, we train $`f_{\theta}`$
with a mean squared error objective over the training pairs
$`\mathcal{T}`$ to train its output to match the coordinates and scale
of the behavior embeddings:

|  |  |  |
|----|----|----|
|  |
``` math
\mathcal{L}(\theta)=\frac{1}{|\mathcal{T}|}\sum_{(x,b)\in\mathcal{T}}\left\lVert f_{\theta}(q(x))-u_{b}\right\rVert_{2}^{2}.
``` |  |

We learn such a projector for the respective language models, so one
each for Qwen and Granite, ensuring that projected queries and the
stored behavior embeddings are expressed in a shared space. Our training
is performed with AdamW for 10 epochs with a batch size of 256, learning
rate of $`1\times 10^{-4}`$, and weight decay of $`10^{-4}`$. The
resulting projector $`f_{\theta}`$, which is just $`0.56M`$ parameters,
is held fixed during evaluation, with minimal overhead.

### D.4 Cold-Start Setting and Evaluation

In the cold-start setting, we no longer provide the language model with
access to offline-mined behaviors, and we do not have $`f_{\theta}`$.
This means that we directly operate in the raw embedding dimension
(768), but since Gibbs steps occur over a smaller corpus (fewer
behaviors are mined over the test set compared to the offline mining
setting), this remains computationally feasible. Since there is no
empirical covariance to work from or PCA performed, we set
$`\Psi_{0}=I_{768}`$, and $`\nu_{0}=D+2=770`$. Domain-conditioning does
not arise since we treat the samples in a test set as belonging to a
single domain, so this is analogous to the non-hierarchical
construction.

For evaluation (in both the cold-start setting as well as with the
offline-mined memory), all models are given a thinking budget of $`64`$k
tokens, and generations are sampled with temperature $`0.7`$. For both
settings, memory is reset following each evaluation run – for the
cold-start setting, this ensures every benchmark is run without memory,
while for the offline-mined memory setting, we revert back to the
"pre-trained" mixture fit on the offline behavior corpus.

### F.4 Component Creation and Merging

We also consider the protocols for new component creation, as well as
consolidation, in the online test-time training setting. As described in
Section
[4.4](#S4.SS4 "4.4 Test-Time Adaptation ‣ 4 Bayesian Cheatsheet: Behavior Mixtures via HDP-GMM ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory")
(Eq.

if $`\rho_{\mathrm{new}}(e_{t})>\tau_{\mathrm{new}}`$, we instantiate a
new component – this is analogous to deterministic cluster creation used

consider a sampling scheme where we draw a

procedure is faithful to the component-birth mechanism in the CRP,
treating $`\rho_{\mathrm{new}}(e_{t})`$ as a probability to be sampled.

components together where symmetric Gaussian KL $`<\epsilon`$, during
the refitting stage.

We find that the Bernoulli-based sampling procedure spawns many more
components than the threshold-based method, both in isolation ($`g=0`$)
and with refitting. Notably, while the final number of components
decreases slightly without KL-merge in the thresholding method, there
are fewer (2, compared to 11) novelty-triggered component births. Thus,
merging results in a higher novelty score for subsequent points by way
of condensing coverage, which leads to new components being created
through the $`\tau_{\mathrm{new}}`$ threshold. Even without the KL-based
component merging, the Gibbs refit serves to collapse some of the
components; with more components being created in the sampling variant,
refit actually contributes a net decrease in components created.

### F.5 Novelty Threshold

Our main experiments use $`\tau_{\mathrm{new}}=0.5`$; we ablate the
value of $`\tau_{\mathrm{new}}`$ in Table
[12](#A6.T12 "Table 12 ‣ F.5 Novelty Threshold ‣ Appendix F Ablations ‣ Test-Time Adaptation of Reasoning Strategies with Bayesian Nonparametric Memory").
We find that for small values of $`\tau_{\mathrm{new}}`$, the novelty
score consistently exceeds the threshold, aggressively creating new
components (212) that need to be pruned through the periodic Gibbs
sweep. We find that this likely leads to noise in retrieval, noticeably
hurting performance. As we increase it, we achieve a mix of
novelty-triggered and refit-induced component births at $`0.5`$, while
increasing it to $`0.7`$ results in novelty scores being too low to
spawn new components, so all births are purely through the periodic
refitting. Performance generally stabilizes, while peaking at
$`\tau_{\mathrm{new}}=0.5`$; given it also balances novelty-based
spawning with refit-based creation, we retain this for our main recipe.
````
