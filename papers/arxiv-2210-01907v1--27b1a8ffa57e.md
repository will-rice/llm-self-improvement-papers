###### Abstract

Existing studies on provably efficient algorithms for Markov games (MGs)
almost exclusively build on the “optimism in the face of uncertainty”
(OFU) principle. This work focuses on a different approach of posterior
sampling, which is celebrated in many bandits and reinforcement learning
settings but remains under-explored for MGs. Specifically, for episodic
two-player zero-sum MGs, a novel posterior sampling algorithm is
developed with _general_ function approximation. Theoretical analysis
demonstrates that the posterior sampling algorithm admits a
$`\sqrt{T}`$-regret bound for problems with a low multi-agent decoupling
coefficient, which is a new complexity measure for MGs, where $`T`$
denotes the number of episodes. When specialized to linear MGs, the
obtained regret bound matches the state-of-the-art results. To the best
of our knowledge, this is the first provably efficient posterior
sampling algorithm for MGs with frequentist regret guarantees, which
enriches the toolbox for MGs and promotes the broad applicability of
posterior sampling.

Machine Learning, ICML

## 1 Introduction

Multi-agent reinforcement learning (MARL) focuses on the sequential
decision-making problem involving more than one agent, each of which
aims to optimize her own long-term return by interacting with the
environment and other agents ([Zhang et al., 2021](#bib.bib38)). Today,
MARL has a diverse set of real-world applications, including Go ([Silver
et al., 2016](#bib.bib27); [Silver et al., 2017](#bib.bib28)),
autonomous driving ([Shalev-Shwartz et al., 2016](#bib.bib25)), Poker
([Brown & Sandholm, 2019](#bib.bib5)), and Dota ([Berner et al.,
2019](#bib.bib4)), just to name a few. Due to the large state space of
these practical problems, function approximation (with neural networks)
is often used in these applications for the generalization across
different state-action pairs. While there is a long line of related
works on the theoretical understanding of single-agent RL with general
function approximation ([Jiang et al., 2017](#bib.bib13); [Sun et al.,
2019](#bib.bib29); [Wang et al., 2020](#bib.bib31); [Jin et al.,
2021a](#bib.bib14); [Du et al., 2021](#bib.bib9); [Dann et al.,
2021](#bib.bib8)), the theory of MARL with general function
approximation is substantially less explored. In this paper, we aim to
explore this topic in the context of two-player zero-sum Markov games
(MGs) ([Shapley, 1953](#bib.bib26); [Littman, 1994](#bib.bib18)).

The goal of learning in a two-player zero-sum MG is to learn the Nash
equilibrium at which the policy of each player maximizes her own
cumulative rewards, provided that the policies of other agents are
fixed. Intuitively speaking, Nash equilibrium characterizes the point
from which no agent will deviate. Since the reward and the state
transition are determined jointly by the actions of both agents, in
addition to the unknown environment, each agent must also handle the
dynamics of other strategic agents. Due to this game-theoretical
feature, algorithms designed for MDP cannot be directly extended to the
MARL case. However, recent studies ([Jin et al., 2021b](#bib.bib15);
[Huang et al., 2021](#bib.bib11)) have shown that with an innovative
asymmetrical structure, similar theoretical results can be established
for the two-player zero-sum MG with general function approximation.

Nevertheless, despite a handful of recent progress on the theory of the
two-player zero-sum MG with general function approximation, the existing
works are mainly confined to algorithms based on the optimism in the
face of uncertainty (OFU) principle. In contrast, the theory of
posterior-sampling-based algorithms is less developed (in the
frequentist setting). Various empirical studies indicate that the
OFU-based algorithms can be far too optimistic for average instances and
is inferior to posterior sampling algorithms, including [Chapelle & Li
(2011)](#bib.bib6) for bandit, and [Osband et al. (2016)](#bib.bib21)
for RL. Recent works in the context of contextual multi-armed bandit and
single-agent RL demonstrate that there is no statistical efficiency gap
between OFU and posterior sampling algorithms ([Dann et al.,
2021](#bib.bib8); [Zhang, 2021](#bib.bib40)). However, whether we can
design model-free posterior sampling algorithms in MARL that achieve
similar theoretical guarantees remains open.

In this paper, we are interested in the application of posterior
sampling in the two-player zero-sum MG with general function
approximation and self-play (which means that the learning agent can
control both players). Our main result indicates that, similar to the
single-agent case, posterior sampling algorithms can achieve comparable
theoretical guarantees as to the OFU-based algorithms. Our contributions
are summarized as follows:

- •
  A provably efficient posterior sampling algorithm is designed under
  the self-play framework for the two-player zero-sum MG with general
  function approximation. To the best of our knowledge, this is the
  first posterior sampling algorithm with frequentist regret guarantee
  in the context of Markov games;
- •
  The single-agent complexity measure of decoupling coefficient, first
  introduced in [Dann et al. (2021)](#bib.bib8), is extended to the
  multi-agent setting, Moreover, a number of examples with provably
  small multi-agent decoupling coefficients are identified;
- •
  The proposed algorithm is rigorously proved to obtain a
  $`\sqrt{T}`$-regret for problems with low multi-agent decoupling
  coefficient, where $`T`$ is the number of episodes.

It is noted that the sampling procedure of the proposed algorithm may
not be computationally efficient. The lack of computational tractability
also appears in the works of [Jin et al. (2021b)](#bib.bib15); [Huang
et al. (2021)](#bib.bib11), as well as previous works with general
function approximation in the context of single-agent RL ([Jiang et al.,
2017](#bib.bib13); [Jin et al., 2021a](#bib.bib14); [Dann et al.,
2021](#bib.bib8); [Du et al., 2021](#bib.bib9)). It is an interesting
future research topic to identify cases where efficient sampling is
possible. Moreover, we do not take credit for the asymmetrical structure
in our algorithmic framework. The main contribution here is to extend
the posterior sampling algorithm to MGs under the self-play framework.

### 1.1 Related Works

There have been a lot of works focusing on designing provably efficient
algorithms for zero-sum MGs. For the tabular setting, [Bai et al.
(2020)](#bib.bib3); [Bai & Jin (2020)](#bib.bib2); [Liu et al.
(2020)](#bib.bib19) provide
$`O(\text{poly}(|\mathcal{X}|,|\mathcal{A}|,|\mathcal{B}|,H)\cdot\sqrt{T})`$
regret guarantees for the proposed algorithms, where $`|\mathcal{X}|`$
is the number of states, $`|\mathcal{A}|`$ and $`|\mathcal{B}|`$ are the
number of action spaces of two players, respectively, $`H`$ is the
episode length, and $`T`$ is the number of episodes. Then, [Xie et al.
(2020)](#bib.bib33); [Chen et al. (2021)](#bib.bib7) study two
linear-type MGs and design algorithms with
$`O(\text{poly}(d,H)\cdot\sqrt{T})`$ regret, where $`d`$ is the
dimension of the linear features. Recently, [Jin et al.
(2021b)](#bib.bib15); [Huang et al. (2021)](#bib.bib11) further propose
efficient algorithms for zero-sum MGs with general function
approximation.

Our work is also closely related to another line of work on posterior
sampling algorithms. In the context of contextual bandit, due to the
impressive empirical performance of Thompson Sampling ([Chapelle & Li,
2011](#bib.bib6); [Osband et al., 2016](#bib.bib21)), there have been
significant efforts in developing its theoretical analysis, including
[Russo & Van Roy (2014)](#bib.bib24) in the form of Bayesian regret and
[Kaufmann et al. (2012)](#bib.bib16); [Zhang (2021)](#bib.bib40) in the
frequentist setting. For the Markov Decision Process (MDP), the seminal
work [Osband & Van Roy (2014)](#bib.bib20) considers the Bayesian regret
and proposes a general posterior sampling RL method. The randomized
least-squares value iteration (RLSVI) algorithm ([Osband et al.,
2016](#bib.bib21)) is shown to admit frequentist regret bounds for
tabular MDP ([Russo, 2019](#bib.bib23); [Agrawal et al.,
2020](#bib.bib1); [Xiong et al., 2021](#bib.bib36)) and linear MDP
([Zanette et al., 2020](#bib.bib37)). Beyond the linear setting, a
recent work ([Dann et al., 2021](#bib.bib8)) proposes a conditional
posterior sampling algorithm to solve the MDP with general function
approximation.

A recent posterior-sampling-type work by [Jafarnia-Jahromi et al.
(2021)](#bib.bib12) considers the infinite-horizon zero-sum MGs with
average-reward criterion in the tabular setting, with a focus on the
Bayesian regret, whose analysis technique is fundamentally different
from ours. To the best of our knowledge, there is no posterior sampling
algorithm with a frequentist regret guarantee to date for MGs.

## 2 Problem Formulation

Markov Games (MGs) generalize the standard Markov Decision Processes to
the multi-agent setting. In this work, the episodic two-player zero-sum
MG is considered, which can be formally denoted as
$`MG(H,\mathcal{X},\mathcal{A},\mathcal{B},\mathbb{P},r)`$. Here $`H`$
denotes the length of each episode, $`\mathcal{X}`$ is the (possibly
infinite) state space, $`\mathcal{A}`$ and $`\mathcal{B}`$ are the
action spaces of two players (referred to as the max-player and the
min-player), respectively, $`\mathbb{P}_{h}(\cdot|x,a,b)`$ is the
transition measure of the next state from the current state $`x`$ with
two actions $`(a,b)`$ taken at step $`h`$, and $`r^{h}(x,a,b)`$ is the
corresponding reward received with actions $`(a,b)`$ taken for state
$`x`$ at step $`h`$.

Specifically, in this MG, each episode $`t`$ starts from an initial
state $`x_{t}^{1}`$. At each step $`h`$, two players observe the current
state $`x_{t}^{h}`$, take actions $`(a^{h}_{t},b^{h}_{t})`$
individually, and observe the next state
$`x^{h+1}_{t}\sim\mathbb{P}_{h}(\cdot|x_{t}^{h},a_{t}^{h},b_{t}^{h})`$.
The current episode ends after step $`H`$ and then a new episode starts.
Without loss of generality, each episode is assumed to have a fixed
initial state $`x_{t}^{1}=x^{1}`$, which can be easily generalized to
having $`x_{t}^{1}`$ sampled from a fixed but unknown distribution.

Also, for the ease of presentation, the reward $`r^{h}(x,a,b)`$ is
assumed to be deterministic and in the interval of $`[0,1]`$ for any
$`(x,a,b)`$ in this paper, while the algorithm designs and theoretical
results can also be applied for stochastic bounded rewards with slight
modifications.

Policies and Value Functions. With $`\Delta_{\mathcal{A}}`$ denoting the
probability simplex over the action space $`\mathcal{A}`$, a Markov
policy $`\mu`$ of the max-player can be defined as
$`\mu:=\{\mu_{h}:\mathcal{X}\to\Delta_{\mathcal{A}}\}_{h\in[H]}`$.
Similarly, we can define a Markov policy
$`\nu:=\{\nu_{h}:\mathcal{X}\to\Delta_{\mathcal{B}}\}_{h\in[H]}`$ for
the min-player.

Given a policy pair $`(\mu,\nu)`$, the value function
$`V_{h}^{\mu,\nu}:\mathcal{X}\to\mathbb{R}`$ at step $`h`$ is defined as

|     |     |     |
| --- | --- | --- |
|     |

````math
V_{h}^{\mu,\nu}(x):=\mathbb{E}_{\mu,\nu}\left[\sum_{h^{\prime}=h}^{H}r^{h^{\prime}}\left(x^{h^{\prime}},a^{h^{\prime}},b^{h^{\prime}}\right)\mid x^{h}=x\right]
``` |  |

and the Q-value function
$`Q_{h}^{\mu,\nu}:\mathcal{X}\times\mathcal{A}\times\mathcal{B}\to\mathbb{R}`$
as

|  |  |  |
|----|----|----|
|  | $`\displaystyle Q_{h}^{\mu,\nu}(x,a,b):=\mathbb{E}_{\mu,\nu}\bigg[\sum_{h=h}^{H}r^{h^{\prime}}\left(x^{h^{\prime}},a^{h^{\prime}},b^{h^{\prime}}\right)\mid`$ |  |
|  | $`\displaystyle(x^{h},a^{h},b^{h})=(x,a,b)\bigg],`$ |  |

where the expectations are taken over the randomness of the environment
and the policies.

For a clean presentation, we use the notation $`\mathbb{P}_{h}`$ (with a
slight abuse) so that
$`[\mathbb{P}_{h}V](x,a,b)=\mathbb{E}_{x^{\prime}\sim\mathbb{P}_{h}(\cdot|x,a,b)}V(x^{\prime})`$
for any value function $`V`$. Similarly, the notation
$`\mathbb{D}_{\pi}`$ is adopted so that
$`\left[\mathbb{D}_{\pi}Q\right](x):=\mathbb{E}_{(a,b)\sim\pi(\cdot,\cdot\mid x)}Q(x,a,b),`$
for any policy pair $`\pi=(\mu,\nu)`$ and action-value function $`Q`$.
With these notations, the Bellman equations are given by

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle Q_{h}^{\mu,\nu}(x,a,b)`$ | $`\displaystyle=\left[r^{h}+\mathbb{P}_{h}V_{h+1}^{\mu,\nu}\right](x,a,b);`$ |  |
|  | $`\displaystyle V_{h}^{\mu,\nu}(x)`$ | $`\displaystyle=\left[\mathbb{D}_{\mu_{h}\times\nu_{h}}Q_{h}^{\mu,\nu}\right](x).`$ |  |

Best Response. For any policy of max-player $`\mu`$, a corresponding
best response for the min-player can be found, denoted as
$`\nu^{\dagger}(\mu)`$, such that
$`V_{h}^{\mu,\nu^{\dagger}(\mu)}(x)=\inf_{\nu}V_{h}^{\mu,\nu}(x)`$ for
all $`(x,h)`$. This value is the best favorable result for the
min-player if the max-player announces that she will play strategy
$`\mu`$. Similarly, for a min-player policy $`\nu`$, there exists a best
response for the max-player, denoted as $`\mu^{\dagger}(\nu)`$, such
that $`V_{h}^{\mu^{\dagger},\nu}(x)=\sup_{\mu}V_{h}^{\mu,\nu}(x)`$ for
all $`(x,h)`$. To simplify the notation, we use

|  |  |  |
|----|----|----|
|  | $`\displaystyle V_{h}^{\mu,\dagger}(x):=V_{h}^{\mu,\nu^{\dagger}(\mu)}(x),Q_{h}^{\mu,\dagger}(x,a,b):=Q_{h}^{\mu,\nu^{\dagger}(\mu)}(x,a,b);`$ |  |
|  | $`\displaystyle V_{h}^{\dagger,\nu}(x):=V_{h}^{\mu^{\dagger}(\nu),\nu}(x),Q_{h}^{\dagger,\nu}(x,a,b):=Q_{h}^{\mu^{\dagger}(\nu),\nu}(x,a,b).`$ |  |

Nash Equilibrium. Moreover, there exists a set of Nash equilibrium (NE)
policies $`(\mu^{*},\nu^{*})`$ ([Filar & Vrieze, 2012](#bib.bib10)) that
are optimal against their best response such that

|  |  |  |
|----|----|----|
|  |
``` math
V_{h}^{\mu^{*},\dagger}(x)=\sup\nolimits_{\mu}V_{h}^{\mu,\dagger}(x),\quad V_{h}^{\dagger,\nu^{*}}(x)=\inf\nolimits_{\nu}V_{h}^{\dagger,\nu}(x),
``` |  |

for all $`(x,h)\in\mathcal{X}\times[H]`$. For this NE, the following
famous minimax equation holds:

|  |  |  |
|----|----|----|
|  |
``` math
\sup\nolimits_{\mu}\inf\nolimits_{\nu}V_{h}^{\mu,\nu}(x)=V_{h}^{\mu^{*},\nu^{*}}(x)=\inf\nolimits_{\nu}\sup\nolimits_{\mu}V_{h}^{\mu,\nu}(x)
``` |  |

for all $`(x,h)\in\mathcal{X}\times[H]`$. For simplicity, we denote
$`V_{h}^{*}(x):=V_{h}^{\mu^{*},\nu^{*}}(x)`$ and
$`Q_{h}^{*}(x):=Q_{h}^{\mu^{*},\nu^{*}}(x)`$. Note that although there
might exist multiple NE policies, the NE value function is unique for a
zero-sum MG.

Performance metrics. A max-player’s policy $`\mu`$ is said to be
$`\epsilon`$-close to the NE if it satisfies
$`V^{*}(x^{1})-V^{\mu,\dagger}(x^{1})<\epsilon`$. Note that we have
$`V^{*}(x^{1})-V^{\mu,\nu}(x^{1})\leq V^{*}(x^{1})-V^{\mu,\dagger}(x^{1})`$
for all min-player’s policy $`\nu`$ as the best response is the
strongest opponent for the max-player. The main goal of this paper is to
find an $`\epsilon`$-close policy for the max-player and her regret over
$`T`$ episodes can be defined as

|  |  |  |
|----|----|----|
|  | $`\displaystyle\mathop{\mathrm{Reg}}(T):=\sum_{t=1}^{T}\left[V_{1}^{*}\left(x_{1}\right)-V_{1}^{\mu_{t},\dagger}\left(x_{1}\right)\right],`$ |  |

where $`\mu_{t}`$ is the policy adopted by the max-player for episode
$`t`$. Note that we can switch the roles of two players to learn a
policy $`\nu`$ that is $`\epsilon`$-close to the NE for the min-player.

### 2.1 Function Approximation

As mentioned in
Sec. [1](#S1 "1 Introduction ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
real-world applications of RL often encounter the challenge of a large
state space where storing a table as in the classical Q-learning is
generally infeasible. To overcome this challenge, function approximation
is proposed and proven to be efficient with many practical successes.
Following similar attempts in MDP, we aim to approximate the $`Q`$-value
functions for the MGs considered in this work by a class of functions
$`{{\mathcal{F}}}={{\mathcal{F}}}_{1}\times\cdots\times{{\mathcal{F}}}_{H}`$
where
$`{{\mathcal{F}}}_{h}\subset(\mathcal{X}\times\mathcal{A}\times\mathcal{B}\to\mathbb{R})`$.

For $`f\in{{\mathcal{F}}}`$, a NE can be induced and the corresponding
policy $`\mu_{f}`$ of the max-player is defined for all $`(x,h)`$ as

|  |  |  |
|----|----|----|
|  |
``` math
\small\mu_{f,h}(x)=\mathop{\mathrm{argmax}}\nolimits_{\mu\in\Delta_{\mathcal{A}}}\min\nolimits_{\nu\in\Delta_{\mathcal{B}}}\mu^{\top}f^{h}(x,\cdot,\cdot)\nu.
``` |  |

The induced value function for all $`(x,h)`$ is then given by

|  |  |  |
|----|----|----|
|  |
``` math
V_{f,h}(x)=\max\nolimits_{\mu\in\Delta_{\mathcal{A}}}\min\nolimits_{\nu\in\Delta_{\mathcal{B}}}\mu^{\top}f^{h}(x,\cdot,\cdot)\nu.
``` |  |

Moreover, for a fixed max-player policy $`\mu`$ and a function
$`f\in{{\mathcal{F}}}`$, the induced value function of the best response
of the min-player is defined for all $`(x,h)`$ as

|  |  |  |
|----|----|----|
|  |
``` math
V_{f,h}^{\mu}(x)=\min\nolimits_{\nu\in\Delta_{\mathcal{B}}}\mu_{h}(x)^{\top}f^{h}(x,\cdot,\cdot)\nu.
``` |  |

This is mainly for the min-player to choose her policy, given the
max-player’s policy $`\mu`$. Details can be found in
Sec. [3](#S3 "3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").

As common in [Perolat et al. (2015)](#bib.bib22); [Jin et al.
(2021b)](#bib.bib15); [Huang et al. (2021)](#bib.bib11), two types of
Bellman operators are defined as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\left(\mathcal{T}_{h}f\right)(x,a,b)`$ | $`\displaystyle:=\left[r^{h}+\mathbb{P}_{h}V_{f,h+1}\right](x,a,b);`$ |  |
|  | $`\displaystyle\left(\mathcal{T}_{h}^{\mu}f\right)(x,a,b)`$ | $`\displaystyle:=\left[r^{h}+\mathbb{P}_{h}V_{f,h+1}^{\mu}\right](x,a,b).`$ |  |

The corresponding Bellman residual are denoted as

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathcal{E}_{h}(f;x,a,b)`$ | $`\displaystyle=\mathcal{E}(f^{h},f^{h+1};x,a,b)`$ |  | (2.1) |
|  |  | $`\displaystyle=f^{h}(x,a,b)-({\mathcal{T}}_{h}f)(x,a,b);`$ |  |  |
|  | $`\displaystyle\mathcal{E}_{h}^{\mu}\left(f;x,a,b\right)`$ | $`\displaystyle=\mathcal{E}^{\mu}(f^{h},f^{h+1};x,a,b)`$ |  |  |
|  |  | $`\displaystyle=f^{h}(x,a,b)-({\mathcal{T}}^{\mu}_{h}f)(x,a,b).`$ |  |  |

Sometimes the state-action pair $`(x,a,b)`$ may be replaced with a
trajectory
$`\zeta=\{(x^{h^{\prime}},a^{h^{\prime}},b^{h^{\prime}},r^{h^{\prime}})\}_{h^{\prime}=1}^{H}`$,
which indicates that the corresponding state-action pair at step $`h`$,
i.e. $`(x^{h},a^{h},b^{h})`$, is taken as input.

Recent advances show that RL with function approximation is, in general,
intractable without any further assumption ([Krishnamurthy et al.,
2016](#bib.bib17); [Weisz et al., 2021](#bib.bib32)). It is thus common
to adopt additional assumptions over the function class in the
literature on general function approximation in MDPs, especially the
realizability and completeness assumptions ([Wang et al.,
2020](#bib.bib31); [Jin et al., 2021a](#bib.bib14); [Dann et al.,
2021](#bib.bib8)). As MGs are natural extensions of MDPs, the
generalized realizability and completeness assumptions are also adopted
in this work. Note that
Assumptions [1](#Thmassumption1 "Assumption 1 (Realizability). ‣ 2.1 Function Approximation ‣ 2 Problem Formulation ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
and
[2](#Thmassumption2 "Assumption 2 (Completeness). ‣ 2.1 Function Approximation ‣ 2 Problem Formulation ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
are also required by other recent works on MGs with general function
approximation ([Jin et al., 2021b](#bib.bib15); [Huang et al.,
2021](#bib.bib11)).

###### Assumption 1 (Realizability).

For the Nash equilibrium, it holds that
$`Q^{*}_{h}\in{{\mathcal{F}}}_{h},\forall h\in[H]`$. Moreover, for any
$`f\in{{\mathcal{F}}}`$, it holds that
$`Q_{h}^{\mu_{f},\dagger}\in{{\mathcal{F}}}_{h},\forall h\in[H]`$.

The realizability assumption states that the function class
$`{{\mathcal{F}}}`$ is large enough so that it contains the $`Q`$-value
function of the NE and also the $`Q`$-value function of any induced
policy and its best response.

The completeness assumption is more restrictive where the main drawback
is that completeness is non-monotone, meaning that adding one function
into $`{{\mathcal{F}}}`$ may violate the assumption. However, it is the
key to handling the variance of sampling in the literature and analysis
without completeness seems very challenging.

###### Assumption 2 (Completeness).

For any $`f,g\in{{\mathcal{F}}}`$ and the induced policy $`\mu_{f}`$, it
holds that
$`{\mathcal{T}}_{h}^{\mu_{f}}g\in{{\mathcal{F}}}_{h},\forall h\in[H]`$.

Additionally, the following boundedness assumption¹¹ 1 $`(\beta-1)`$ is
usually assumed to be either $`1`$ or $`H`$ in the literature. is
considered, which is natural for bounded rewards and a finite episode
length.

###### Assumption 3 (Boundedness).

There exists $`\beta>1`$ s.t.
$`f^{h}(x,a,b)\in[0,\beta-1],\forall(f,h,x,a,b)\in{{\mathcal{F}}}\times[H]\times\mathcal{X}\times\mathcal{A}\times\mathcal{B}`$.

## 3 Algorithm

The proposed Conditional Posterior Sampling with Booster algorithm is
presented in this section. ”Conditional” refers to the design of
$`q(f^{h}|f^{h+1},S_{t})`$ (the denominator in
Eqn. ([3.2](#S3.E2 "Equation 3.2 ‣ 3.2 The Main Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"))),
which allows us to use the true Bellman operator $`{\mathcal{T}}_{h}`$
in the analysis even though we do dot know it in the executed algorithm.
”Booster” is a synonym for exploiter ([Jin et al., 2021b](#bib.bib15))
in the context and refers to the asymmetric structure as the second
agent aims to assist the main agent’s learning. Another reason is that
when we wrote this paper, one of the authors had a fever due to the
booster vaccine, and another author tested positive for covid.

1:  Input: function class: $`{{\mathcal{F}}}`$, learning rate $`\eta`$,
horizon $`T`$, prior parameter $`\lambda`$.

2:  $`S_{0}`$ is initialized to be empty.

3:  for Stage $`t=1,\dots,T`$ do

4:   Main agent: $`\mu_{t}\leftarrow`$
Main($`{{\mathcal{F}}},\eta,S_{t-1},T,\lambda`$);

5:   Booster agent: $`\nu_{t}\leftarrow`$
Booster($`{{\mathcal{F}}},\eta,S_{t-1},\mu_{t},T,\lambda`$);

6:   Execute the policies $`(\mu_{t},\nu_{t})`$ and collect the
trajectory
$`(x_{t}^{1},a_{t}^{1},b_{t}^{1},r_{t}^{1},\cdots,x_{t}^{H},a_{t}^{H},b_{t}^{H},r_{t}^{H})`$
to obtain $`S_{t}`$.

7:  end for

Algorithm 1 Conditional Posterior Sampling with Booster

### 3.1 Overview

The existing algorithms with frequentist guarantees are confined to
OFU-based algorithms. Algorithmically, these algorithms typically
maintain a confidence set $`\mathcal{C}`$ whose components are
empirically consistent with the Bellman equation so far. Then, an
optimistic function $`f\in\mathcal{C}`$ is selected to approximate the
true value function through some optimization subroutine ([Jin et al.,
2021b](#bib.bib15); [Huang et al., 2021](#bib.bib11)). In contrast, the
posterior sampling algorithm starts with a prior $`p_{0}(\cdot)`$ over
the function class $`{{\mathcal{F}}}`$ and collects trajectories to
compute the likelihood; they together lead to a posterior distribution
$`p(\cdot)`$ over $`{{\mathcal{F}}}`$. Then, a function is sampled from
the posterior distribution to approximate the target. In addition to the
difference in algorithm structure, the analysis techniques for the
posterior sampling algorithm are also different, particularly due to the
lack of explicit optimism from the planning step.

A frequentist theoretical guarantee of posterior sampling algorithms has
been lacking for a long time, even in the context of contextual bandit.
Recently, [Zhang (2021)](#bib.bib40) and [Dann et al. (2021)](#bib.bib8)
show that adding an extra optimistic term can lead to frequentistly
optimal posterior sampling algorithm in contextual bandit and MDP,
respectively. However, in the MARL setting, the multi-agent nature leads
to complicated statistical dependence across the players. In particular,
in addition to the environment, the agent will also be affected by other
strategic agents. Therefore, the situation is more complicated even in
the two-player case and the algorithms designed for MDPs cannot be
directly extended to MGs. To overcome this issue, inspired by [Jin
et al. (2021b)](#bib.bib15); [Huang et al. (2021)](#bib.bib11), we
leverage the innovative asymmetric structure to pick the max-player and
the min-player as the main agent and the booster agent, respectively,
where the booster agent, as the name suggests, aims to assist the main
agent’s learning.

Algorithm [1](#alg1 "Algorithm 1 ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
where the main agent’s algorithm and the booster agent’s algorithm are
given in
Algorithms [2](#alg2 "Algorithm 2 ‣ 3.1 Overview ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
and
[3](#alg3 "Algorithm 3 ‣ 3.2 The Main Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
respectively.

1:  Draw $`f\sim p(\cdot|\mathcal{D})`$ where the posterior is given by
Eqn. ([3.3](#S3.E3 "Equation 3.3 ‣ 3.2 The Main Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"));

2:
 $`\mu_{f,h}(x)=\mathop{\mathrm{argmax}}\nolimits_{\mu\in\Delta_{\mathcal{A}}}\min_{\nu\in\Delta_{\mathcal{B}}}\mu^{\top}f^{h}(x,\cdot,\cdot)\nu,\forall(x,h)`$;

3:  Return $`\mu_{f}`$.

### 3.2 The Main Agent

The main agent’s goal is to learn a $`\epsilon`$-close policy for the
max-player, i.e., $`V^{*}(x^{1})-V^{\mu,\dagger}(x^{1})<\epsilon`$. With
function class $`{{\mathcal{F}}}`$ available, she aims to find a
function $`f\in{{\mathcal{F}}}`$ to approximate the Nash $`Q`$-value
function, i.e., $`Q^{*}`$, which can be used to solve the Nash policy
via the minimax equation. The following optimistic prior and temporal
difference error likelihood are carefully crafted to induce a desired
posterior distribution over $`{{\mathcal{F}}}`$, which is further used
to sample a suitable function $`f`$.

Optimistic prior. The following prior $`\tilde{p}_{0}(\cdot)`$ over the
function class $`{{\mathcal{F}}}`$ is adopted for the main agent:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\tilde{p}_{0}(f)\propto\exp(\lambda V_{f,1}(x^{1}))\prod_{h=1}^{H}p_{0}^{h}(f^{h}),
``` |  | (3.1) |

where $`\lambda>0`$ is a tuning parameter, and $`p_{0}^{h}(\cdot)`$ is a
distribution over $`{{\mathcal{F}}}_{h}`$. Note that other than the
standard prior of $`p_{0}(f)=\prod_{h=1}^{H}p_{0}^{h}(f^{h})`$, an
additional *optimistic* term, i.e., $`\exp(\lambda V_{f,1}(x^{1})`$, is
involved in the prior, which plays an important role of encouraging
exploration for the main agent.

This prior is referred to as an optimistic one because it favors large
values for the initial state. Also, technically, it compensates for one
extra term arising in the value decomposition in
Lemma [1](#Thmlemma1 "Lemma 1 (Value decomposition for the main agent.). ‣ 4.1 Value-Decomposition Lemmas ‣ 4 Sketch of the Main Ideas ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
when the optimism is not inherently available as in OFU-based
algorithms. Similar techniques are also adopted in the design of
posterior sampling for MDPs ([Dann et al., 2021](#bib.bib8)) and
contextual bandits ([Zhang, 2021](#bib.bib40)). Furthermore, [Zhang
(2021)](#bib.bib40) argues that in the context of contextual bandit,
such an optimistic component is necessary to design optimal
posterior-sampling-based algorithms in the frequentist setting.

Also, apart from the optimism itself, the global optimism mechanism,
meaning that we only add an optimistic term in the prior distributions
at the initial value, is the key to achieving improvement in the feature
dimension for linear MGs. We will return to this in
Sec. [5.3](#S5.SS3 "5.3 Interpretation of Theorem ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").

Likelihood for the main agent. If we denote the history up to the end of
episode $`t`$ as
$`S_{t}=\{x_{s}^{h},a_{s}^{h},b_{s}^{h},r_{s}^{h}\}_{s\in[t],h\in[H]}`$,
a likelihood over $`S_{t}`$ is specified as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\small p(S_{t}|f)\propto\prod_{h=1}^{H}\frac{\exp\left(-L^{h}(f^{h},f^{h+1};S_{t})\right)}{\mathbb{E}_{f^{h}\sim p_{0}^{h}}\exp(-\eta L^{h}(f^{h},f^{h+1};S_{t}))}.
``` |  | (3.2) |

$`\{L^{h}(\cdot)\}_{h=1}^{H}`$ is a collection of squared loss functions
as

|  |  |  |
|----|----|----|
|  | $`\displaystyle L^{h}(f^{h},f^{h+1};S_{t})=\sum_{s=1}^{t}\left[f^{h}(x_{s}^{h},a^{h}_{s},b^{h}_{s})-r_{s}^{h}-V_{f^{h+1}}(x^{h+1}_{s})\right]^{2},`$ |  |

which is a proxy to the squared $`{\mathcal{T}}_{h}`$-Bellman error. The
likelihood in
Eqn. ([3.2](#S3.E2 "Equation 3.2 ‣ 3.2 The Main Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"))
introduces a special denominator, which is motivated by that for MDP
([Dann et al., 2021](#bib.bib8)). We will see that the denominator is
the key to handling the variance of sampling, but that is also why we
need the strong completeness assumption. We will discuss this in
Sec. [4.3](#S4.SS3 "4.3 Connection to Likelihood ‣ 4 Sketch of the Main Ideas ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").

Posterior distribution for the main agent. Given the prior distribution
and the likelihood, the posterior at the end of episode $`t`$ can be
naturally expressed as

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle{p}(f|S_{t})\propto\exp(\lambda V_{f,1}(x^{1}))\prod_{h=1}^{H}q(f^{h}|f^{h+1},S_{t}),`$ |  | (3.3) |

where

|  |  |  |
|----|----|----|
|  | $`\displaystyle q(f^{h}|f^{h+1},S_{t})=\frac{p_{0}^{h}(f^{h})\exp\left(-\eta L^{h}(f^{h},f^{h+1};S_{t})\right)}{\mathbb{E}_{f^{h}\sim p_{0}^{h}}\exp(-\eta L^{h}(f^{h},f^{h+1};S_{t}))}.`$ |  |

1:  Draw $`g\sim p^{\mu_{f}}(\cdot|\mathcal{D})`$ where the posterior is
given by
Eqn. ([3.6](#S3.E6 "Equation 3.6 ‣ 3.3 The Booster Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"))

2:
 $`\nu_{h}(x)=\nu_{f,g,h}(x)=\mathop{\mathrm{argmin}}_{\nu\in\Delta_{\mathcal{B}}}\mu_{f,h}^{\top}g^{h}(x,\cdot,\cdot)\nu,\forall(x,h)`$

3:  Return $`\nu`$.

Algorithm 3
Booster($`{{\mathcal{F}}},\eta,\mathcal{D},\mu_{f},T,\lambda`$)

### 3.3 The Booster Agent

As aforementioned, the main agent aims to learn an $`\epsilon`$-close
policy. However, given the competing nature of MGs, this task is not
feasible if her opponent is naive. Thus, inspired by [Jin et al.
(2021b)](#bib.bib15); [Huang et al. (2021)](#bib.bib11), the second
learning agent is set to be the booster agent. As opposed to the main
agent, the booster agent does not aim at find her $`\epsilon`$-close
policy. Instead, her goal is to assist the main agent’s learning.
Specifically, she examines the adopted policy of the main agent and
tries to find the best response for it (since the best response is the
strongest opponent). In this way, the underlying weakness of the main
agent is exploited, which facilitates the learning of the NE. To better
illustrate the role of the booster agent, we consider the following
decomposition of the regret:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathop{\mathrm{Reg}}(T)=`$ | $`\displaystyle\underbrace{\left(\sum_{t=1}^{T}V_{1}^{*}(x^{1})-V_{1}^{\mu_{t},\nu_{t}}(x^{1})\right)}_{\text{main agent}}`$ |  | (3.4) |
|  |  | $`\displaystyle+\underbrace{\left(\sum_{t=1}^{T}V_{1}^{\mu_{t},\nu_{t}}(x^{1})-V_{1}^{\mu_{t},\dagger}(x^{1})\right)}_{\text{booster agent}}.`$ |  |  |

The technical advantage of involving $`V_{1}^{\mu_{t},\nu_{t}}(x^{1})`$
in the main agent part is that we can apply the value-decomposition
lemma from [Jiang et al. (2017)](#bib.bib13) as in
Lemma [1](#Thmlemma1 "Lemma 1 (Value decomposition for the main agent.). ‣ 4.1 Value-Decomposition Lemmas ‣ 4 Sketch of the Main Ideas ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
because $`(\mu_{t},\nu_{t})`$ is the executed policy pair for trajectory
collection (see
Lemma [1](#Thmlemma1 "Lemma 1 (Value decomposition for the main agent.). ‣ 4.1 Value-Decomposition Lemmas ‣ 4 Sketch of the Main Ideas ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
for details). In this case, the non-negative booster agent part is zero
if we can find the best response to $`\mu_{t}`$ exactly. Motivated by
this observation, the booster agent keeps learning to approximate the
best response to the given max-player’s policy based on the historical
trajectories so as to minimize the booster agent part. Due to the
different goals, the design philosophy of the booster agent is different
from that of the main agent. Especially, she takes a different but also
optimistic prior (for the min-player) and a different format of the
likelihood.

Optimistic prior of the booster agent. An optimistic prior is adopted
for the booster agent, defined as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p^{\mu}_{0}(g)\propto\exp(-\lambda V^{\mu}_{g,1}(x^{1}))\prod_{h=1}^{H}p_{0}^{h}(g^{h}).
``` |  | (3.5) |

Intuitively, the booster agent favors small values for the initial
state, which is optimistic for the min-player. The motivation for such
an optimistic prior will be clearer after the value decomposition lemma,
i.e.,
Lemma [2](#Thmlemma2 "Lemma 2 (Value decomposition for the booster agent.). ‣ 4.1 Value-Decomposition Lemmas ‣ 4 Sketch of the Main Ideas ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
is presented. The reason why we only modify the prior will also be
illustrated in
Sec. [5.3](#S5.SS3 "5.3 Interpretation of Theorem ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").

Likelihood for the booster agent. As the booster agent mainly focuses on
approximating the best response policy to $`\mu`$ instead of finding NE,
a different squared loss function is specified as:

|  |  |  |
|----|----|----|
|  | $`\displaystyle L^{h}_{\mu}(g^{h},g^{h+1};S_{t})=\sum_{s=1}^{t}[g^{h}(x_{s}^{h},a^{h}_{s},b^{h}_{s})-r_{s}^{h}-V^{\mu}_{g^{h+1}}(x^{h+1}_{s})]^{2},`$ |  |

which can be viewed as a proxy to the squared
$`{\mathcal{T}}_{h}^{\mu}`$-Bellman error. Consequently, a corresponding
likelihood can be obtained by replacing $`L^{h}`$ in
Eqn. ([3.2](#S3.E2 "Equation 3.2 ‣ 3.2 The Main Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"))
with $`L^{h}_{\mu}`$.

Posterior distribution for the booster agent. With the prior and the
likelihood, the posterior distribution for the booster agent can be
obtained as:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p^{\mu}(g|S_{t})\propto\exp(-\lambda V^{\mu}_{g,1}(x^{1}))\prod_{h=1}^{H}q^{\mu}(g^{h}|g^{h+1},S_{t}),
``` |  | (3.6) |

where

|  |  |  |
|----|----|----|
|  | $`\displaystyle q^{\mu}(g^{h}|g^{h+1},S_{t})=\frac{p_{0}^{h}(g^{h})\exp\left(-\eta L^{h}_{\mu}(g^{h},g^{h+1};S_{t})\right)}{\mathbb{E}_{g^{h}\sim p_{0}^{h}}\exp(-\eta L^{h}_{\mu}(g^{h},g^{h+1};S_{t}))}.`$ |  |

Note that sometimes we also employ the notation
$`q(g^{h}|g^{h+1},\mu,S_{t})=q^{\mu}(g^{h}|g^{h+1},S_{t})`$ when we need
to use the superscript $`h`$.

### 3.4 The Learning Process

With the main agent and the booster agent specified, the training
proceeds as the following. For each episode $`t`$, the main agent first
samples one $`f_{t}\in{{\mathcal{F}}}`$ according to the posterior
distribution $`p(\cdot|S_{t-1})`$ and adopts the induced Nash policy as

|  |  |  |
|----|----|----|
|  | $`\displaystyle\mu_{t,h}(x)\leftarrow\mu_{f_{t},h}(x):=\mathop{\mathrm{argmax}}\nolimits_{\mu\in\Delta_{\mathcal{A}}}\min\nolimits_{\nu\in\Delta_{\mathcal{B}}}\mu^{\top}f_{t}^{h}(x,\cdot,\cdot)\nu`$ |  |

for all $`(x,h)\in\mathcal{X}\times[H]`$.

Then, the booster agent samples some $`g_{t}\in{{\mathcal{F}}}`$ from
her posterior distribution $`p^{\mu_{t}}(\cdot|S_{t-1})`$ computed from
$`S_{t-1}`$ and $`\mu_{t}`$. The approximated best response is computed
according to $`g_{t}`$ and $`\mu_{t}`$ as

|  |  |  |
|----|----|----|
|  |
``` math
\small\nu_{t,h}(x)\leftarrow\nu_{f_{t},g_{t},h}(x)=\mathop{\mathrm{argmin}}\nolimits_{\nu\in\Delta_{\mathcal{B}}}\mu_{f_{t},h}^{\top}g^{h}_{t}(x,\cdot,\cdot)\nu
``` |  |

for all $`(x,h)\in\mathcal{X}\times[H]`$.

Finally, both players execute $`(\mu_{t},\nu_{t})`$ for episode $`t`$,
resulting in a trajectory $`\zeta_{t}`$. This collected trajectory is
then added to $`S_{t}`$ and used to compute the policy for the next
episode.

## 4 Sketch of the Main Ideas

In this section, a sketch of the main ideas is provided for the proposed
algorithm and the theoretical proof.

### 4.1 Value-Decomposition Lemmas

It is known that the immediate regret in one episode can be related to
the Bellman residuals in the single-agent setting ([Jiang et al.,
2017](#bib.bib13)), and this technique is well-adopted in the literature
([Jin et al., 2021a](#bib.bib14); [Dann et al., 2021](#bib.bib8); [Du
et al., 2021](#bib.bib9)). For our setting, with regret decomposed as in
Eqn. ([3.4](#S3.E4 "Equation 3.4 ‣ 3.3 The Booster Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")),
the immediate regrets of the main agent part and the booster agent part
can be related to the $`{\mathcal{T}}`$-Bellman residuals and the
$`{\mathcal{T}}^{\mu_{t}}`$-Bellman residuals, respectively, as we show
below.

###### Lemma 1 (Value decomposition for the main agent.).

Let $`\mu=\mu_{f}`$ and $`\nu`$ be an arbitrary policy taken by the
min-player. It holds that

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle V^{*}(x^{1})-V_{1}^{\mu,\nu}(x^{1})`$ |  |
|  |  | $`\displaystyle\leq\sum_{h=1}^{H}\mathbb{E}_{\mu,\nu}\mathcal{E}_{h}(f^{h},f^{h+1};\zeta)+V^{*}(x^{1})-V_{f,1}(x^{1}).`$ |  |

###### Lemma 2 (Value decomposition for the booster agent.).

Suppose that $`\mu=\mu_{f}`$ is taken by the max-player and $`g`$ is
sampled from the posterior by the booster agent. Let $`\nu`$ be taken as
in
Sec. [3.4](#S3.SS4 "3.4 The Learning Process ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").
Then, it holds that

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle V_{1}^{\mu,\nu}(x^{1})-V_{1}^{\mu,\dagger}(x^{1})`$ |  |
|  |  | $`\displaystyle=-\sum_{h=1}^{H}\mathbb{E}_{\mu,\nu}\mathcal{E}^{\mu}_{h}(g^{h},g^{h+1},\zeta)+V_{g,1}^{\mu}(x^{1})-V_{1}^{\mu,\dagger}(x^{1}).`$ |  |

We remark that these two lemmas also account for the extra optimistic
terms in the prior distributions. The proofs of these two lemmas are
deferred to
Appendix [E](#A5 "Appendix E Proof of the Value-Decomposition Lemma ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").

### 4.2 Multi-Agent Decoupling Coefficients

In the previous subsection, we convert the problem of bounding
$`\mathop{\mathrm{Reg}}(T)`$ to bounding the summation of Bellman
residuals. However, the posterior distribution is more related to the
*squared* Bellman residuals. Therefore, we need some structural
information to relate the growth of the cumulative Bellman residuals to
the growth of the cumulative squared Bellman residuals. To this end, the
multi-agent decoupling coefficient is introduced, which is an extension
of the single-agent version in [Dann et al. (2021)](#bib.bib8), as
follows.

###### Definition 1 (Multi-agent decoupling coefficient).

Given an $`MG(H,\mathcal{X},\mathcal{A},\mathcal{B},\mathbb{P},r)`$, a
function class $`{{\mathcal{F}}}`$, a time horizon $`T`$, and a
parameter $`\mu>0`$, the multi-agent decoupling coefficient
$`dc({{\mathcal{F}}},MG,T,\mu)`$ is defined to be the smallest integer
such that

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\sum_{h=1}^{H}\sum_{t=1}^{T}\left[\mathbb{E}_{\pi_{{t}}}\left[\mathcal{E}_{h}^{\mu_{f_{t}}}\left(g_{t};x^{h},a^{h},b^{h}\right)\right]\right]`$ |  |
|  |  | $`\displaystyle\leq\mu\sum_{h=1}^{H}\sum_{t=1}^{T}\left[\sum_{s=1}^{t-1}\mathbb{E}_{\pi_{{s}}}\left[\mathcal{E}_{h}^{\mu_{f_{t}}}\left(g_{t};x^{h},a^{h},b^{h}\right)\right]^{2}\right]+\frac{K}{4\mu},`$ |  |

where $`\pi_{s}`$ is a policy pair $`(\mu_{f_{s}},\nu_{f_{s},g_{s}})`$
induced by $`(f_{s},g_{s})`$ as introduced in
Sec. [3.4](#S3.SS4 "3.4 The Learning Process ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").
The set of these distributions induced by $`f,g\in{{\mathcal{F}}}`$ is
denoted as $`\mathcal{D}_{{\mathcal{F}}}`$.

Equipped with the multi-agent decoupling coefficient, it remains to
bound the cumulative squared Bellman residuals
$`\sum_{s=1}^{t-1}\left[\mathbb{E}_{\pi_{{s}}}\mathcal{E}_{h}^{\mu_{f_{t}}}\left(g_{t};x^{h},a^{h},b^{h}\right)\right]^{2}`$
by connecting it to the likelihood
$`L^{h}_{\mu_{f_{t}}}(g^{h},g^{h+1};S_{t-1})`$ used in the posterior
distributions.

### 4.3 Connection to Likelihood

We focus on the main agent and the booster agent is similar. We consider
the $`L^{h}(g^{h}_{t},g_{t}^{h+1};\zeta_{s})`$ (when we only evaluate
the loss with only one trajectory, we directly use the notation
$`\zeta_{s}`$). Taking expectation, we have

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbb{E}_{\pi_{s}}L^{h}(g_{t}^{h},g_{t}^{h+1};\zeta_{s})=\left[\mathbb{E}_{\pi_{s}}\mathcal{E}_{h}(g_{t};x^{h},a^{h},b^{h})\right]^{2}+\sigma^{2},
``` |  | (4.1) |

where $`\sigma^{2}`$ is the expectation of
$`({\mathcal{T}}_{h}f^{h+1}(x_{s}^{h},a_{s}^{h},b_{s}^{h})-r_{s}^{h}-V_{f^{h+1}}(x_{s}^{h+1}))^{2}`$
or the variance, which is hard to deal with. However, the denominator in
the likelihood allows us to rewrite the algorithm by replacing
$`L^{h}(g_{t}^{h},g_{t}^{h+1};\zeta_{s})`$ with the following excess
loss:

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\Delta L^{h}(f^{h},f^{h+1};\zeta_{s}):=L^{h}(f^{h},f^{h+1};\zeta_{s})`$ |  |  |
|  |  | $`\displaystyle\qquad-({\mathcal{T}}_{h}f^{h+1}(x_{s}^{h},a_{s}^{h},b_{s}^{h})-r_{s}^{h}-V_{f^{h+1}}(x_{s}^{h+1}))^{2},`$ |  | (4.2) |

whose expectation is the desired
$`\left[\mathbb{E}_{\pi_{s}}\mathcal{E}_{h}(g_{t};x^{h},a^{h},b^{h})\right]^{2}`$.
After resolving the issue of variance, the analysis follows from the
online aggregation techniques. However, the completeness assumption is
required to analyze the introduced denominator (see the proof of
Lemma [11](#Thmlemma11 "Lemma 11. ‣ Appendix C Proof of the Theorem ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
and
Lemma [17](#Thmlemma17 "Lemma 17. ‣ Appendix D Proof of the Theorem ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")).

### 4.4 More Intuition

We emphasize that the feature of the self-play setting that the learning
agent can control both the max-player and the min-player plays a central
role in the algorithm design and analysis. This allows us to decompose
the regret into two parts as in
Eqn. ([3.4](#S3.E4 "Equation 3.4 ‣ 3.3 The Booster Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"))
and further employ the asymmetric structure to handle two parts. The
analysis in the single-agent case essentially relies on the Markov
property of transition, (conditional) sub-Gaussianity of the noise of
transition, and the fact that the regret in one episode is upper bounded
by the sum of Bellman residuals. We note that both the main agent and
the booster agent retain these properties separately. Therefore, the
techniques from MDP can be applied but with some additional efforts to
handle the game nature.

### 4.5 Complexity of $`{{\mathcal{F}}}`$

For optimization-based algorithms, the complexity of the function class
$`{{\mathcal{F}}}`$ is usually characterized through the cardinality
$`|{{\mathcal{F}}}|`$ or the covering number ([Jiang et al.,
2017](#bib.bib13); [Wang et al., 2020](#bib.bib31); [Jin et al.,
2021a](#bib.bib14); [Jin et al., 2021b](#bib.bib15); [Huang et al.,
2021](#bib.bib11)). On the other hand, the posterior sampling algorithm
employs a prior distribution $`p_{0}`$ over $`{{\mathcal{F}}}`$, which
allows the algorithm to favor certain parts of it. Accordingly, our
theoretical result depends on the complexity of $`{{\mathcal{F}}}`$
through the prior preference, which is characterized by the following
quantity.

###### Definition 2.

For a policy $`\mu_{f},f\in{{\mathcal{F}}}`$ and for any function
$`g^{\prime}\in{{\mathcal{F}}}_{h+1}`$, we define

|  |  |  |
|----|----|----|
|  |
``` math
\small{{\mathcal{F}}}^{\mu_{f}}_{h}(\epsilon,g^{\prime})=\{g\in{{\mathcal{F}}}_{h}:\sup\nolimits_{x,a,b}|\mathcal{E}^{\mu_{f}}_{h}(g,g^{\prime};x,a,b)|\leq\epsilon\},
``` |  |

containing the functions that have small
$`{\mathcal{T}}^{\mu_{f}}_{h}`$-Bellman error against $`g^{\prime}`$ for
all state-action pairs. We then define

|  |  |  |
|----|----|----|
|  |
``` math
\kappa_{\mu}(\epsilon)=\sup\nolimits_{g\in{{\mathcal{F}}}}\sum_{h=1}^{H}\ln\left(1/p_{0}^{h}({{\mathcal{F}}}^{\mu}_{h}(\epsilon,g^{h+1}))\right),
``` |  |

and

|  |  |  |
|----|----|----|
|  |
``` math
\kappa(\epsilon)=\sup\nolimits_{f\in{{\mathcal{F}}}}\kappa_{\mu_{f}}(\epsilon).
``` |  |

Under
Assumption [2](#Thmassumption2 "Assumption 2 (Completeness). ‣ 2.1 Function Approximation ‣ 2 Problem Formulation ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
it is assumed that $`\kappa(\epsilon)<\infty`$, which is supported by
the following two specific examples.

For the finite function class with completeness, with a uniform prior
$`p_{0}^{h}(f)=1/|{{\mathcal{F}}}_{h}|`$, we have

|  |  |  |
|----|----|----|
|  |
``` math
\kappa(\epsilon)\leq\sum_{h=1}^{H}\ln|{{\mathcal{F}}}_{h}|=\ln|{{\mathcal{F}}}|,
``` |  |

due to the realizability assumption. For an infinite function class, by
replacing $`|{{\mathcal{F}}}|`$ with its covering number, similar result
can also be ontained.

For a $`d`$-dimensional parametric models
$`{{\mathcal{F}}}_{h}=\{g_{\theta}\in\mathbb{R}^{d}:\theta\in\Omega_{h}\}`$
where $`\Omega_{h}`$ is compact, we can generally assume that
$`\sup_{\theta}\ln\frac{1}{p_{0}^{h}\left(\left\{\theta^{\prime}:\left\|\theta^{\prime}-\theta\right\|\leq\epsilon\right\}\right)}\leq d\ln\left(c^{\prime}/\epsilon\right)`$
for some constant $`c^{\prime}`$ depending on the prior. If we further
assume that $`g_{\theta}`$ is Lipschitz in $`\theta`$ (e.g., linear MG
([Xie et al., 2020](#bib.bib33))), then we can assume that
$`\ln\frac{1}{p_{0}^{h}\left(\mathcal{F}_{h}^{\mu_{f}}\left(\epsilon,g^{h+1}\right)\right)}\leq c_{0}d\ln\left(c_{1}/\epsilon\right)`$
for some constants $`c_{0}`$ and $`c_{1}`$ depending on the prior and
the Lipschitz constant $`L`$. In this case, we have

|     |                                                  |     |
|-----|--------------------------------------------------|-----|
|     |
       ``` math
       \kappa(\epsilon)\leq c_{0}Hd\ln(c_{1}/\epsilon).
       ```                                               |     |

## 5 Main Results

In this section, we state the main theoretical result of this paper and
interpret it using several examples.

### 5.1 Theoretical Guarantee

We now provide an upper bound for the overall regret.

###### Theorem 1 (Overall regret).

Let
Assumptions [1](#Thmassumption1 "Assumption 1 (Realizability). ‣ 2.1 Function Approximation ‣ 2 Problem Formulation ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
[2](#Thmassumption2 "Assumption 2 (Completeness). ‣ 2.1 Function Approximation ‣ 2 Problem Formulation ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
and [3](#Thmassumption3 "Assumption 3 (Boundedness). ‣ 2.1 Function Approximation ‣ 2 Problem Formulation ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
hold. If $`{\eta}{\beta^{2}}\leq 0.5`$ and $`\lambda\beta^{2}\geq 1`$
hold, and let $`dc({{\mathcal{F}}},MG,T)`$ be an upper bound for the
$`\sup_{\mu\leq 1}dc({{\mathcal{F}}},MG,T,\mu)`$, and we further take
$`\lambda=\sqrt{\frac{T\kappa(\frac{\beta}{T^{2}})}{\beta^{2}dc({{\mathcal{F}}},MG,T)}}`$,
$`\eta=\frac{1}{4\beta^{2}}`$, then, it holds that

|  |  |  |
|----|----|----|
|  | $`\displaystyle\mathbb{E}\mathop{\mathrm{Reg}}(T)\leq O\bigg(\beta\sqrt{dc({{\mathcal{F}}},MG,T)\kappa(\frac{\beta}{T^{2}})T}+{dc({{\mathcal{F}}},MG,T)}\bigg).`$ |  |

Notably, if the multi-agent decoupling coefficient is provably small,
Algorithm [1](#alg1 "Algorithm 1 ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
admits a $`\sqrt{T}`$-regret. According to the decomposition in
Eqn. ([3.4](#S3.E4 "Equation 3.4 ‣ 3.3 The Booster Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")),
Theorem [1](#Thmtheorem1 "Theorem 1 (Overall regret). ‣ 5.1 Theoretical Guarantee ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
can be established once we can bound the main agent part and the booster
agent part.

###### Theorem 2 (Bound of the main agent).

With the same conditions as
Theorem [1](#Thmtheorem1 "Theorem 1 (Overall regret). ‣ 5.1 Theoretical Guarantee ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
it holds that

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\sum_{t=1}^{T}\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim p_{t}}\mathbb{E}_{g_{t}\sim p^{\mu_{t}}_{t}}\left[V_{1}^{*}(x^{1})-V_{1}^{\mu_{t},\nu_{t}}(x^{1})\right]`$ |  |
|  |  | $`\displaystyle\leq O\bigg(\beta\sqrt{dc({{\mathcal{F}}},MG,T)\kappa(\frac{\beta}{T^{2}})T}+dc({{\mathcal{F}}},MG,T)\bigg).`$ |  |

We then turn to the booster agent and provide an upper bound for the
regret induced by approximating the best response policy.

###### Theorem 3 (Bound of the booster agent).

With the same conditions as
Theorem [1](#Thmtheorem1 "Theorem 1 (Overall regret). ‣ 5.1 Theoretical Guarantee ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
it holds that

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\sum_{t=1}^{T}\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim p_{t}}\mathbb{E}_{g_{t}\sim p^{\mu_{t}}_{t}}\left[V_{1}^{\mu_{t},\nu_{t}}(x^{1})-V_{1}^{\mu_{t},\dagger}(x^{1})\right]`$ |  |
|  |  | $`\displaystyle\leq O\bigg(\beta\sqrt{dc({{\mathcal{F}}},MG,T)\kappa(\beta/T^{2})T}+{dc({{\mathcal{F}}},MG,T)}\bigg).`$ |  |

The detailed proofs can be found in the appendix.

### 5.2 Bounds for the Multi-Agent Decoupling Coefficient

In this subsection, we provide several examples whose multi-agent
decoupling coefficient is provably small. The proof can be found in
Appendix [F](#A6 "Appendix F Proof of the Decoupling Coefficient Bounds ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").

Linear MG. The first example is the MG with linear function
approximation ([Xie et al., 2020](#bib.bib33)). In this case, there
exists a feature map $`\phi(x,a,b)\in\mathbb{R}^{d}`$ and it holds that
$`r^{h}(x,a,b)=\phi(x,a,b)^{\top}\theta^{h}_{*}`$ and
$`\mathbb{P}^{h}(x^{\prime}|x,a,b)=\phi(x,a,b)^{\top}\mu_{h}(x^{\prime})`$
for some unknown $`\theta^{h}_{*}\in\mathbb{R}^{d}`$ and
$`\mu_{h}(\cdot)\in\mathbb{R}^{d}`$ satisfying
$`\max\{\left\|\theta^{h}_{*}\right\|,\left\|\mu_{h}\right\|\}\leq\sqrt{d}`$.
We have the following upper bound for the multi-agent decoupling
coefficient.

###### Proposition 1 (Linear MG).

For a d-dimensional MG with
$`{{\mathcal{F}}}_{h}=\{\phi_{h}(\cdot,\cdot,\cdot)^{\top}\theta^{h}:\left\|\theta^{h}\right\|\leq(H+1-h)\sqrt{d}\}`$
and
$`\left\|\phi(x,a,b)\right\|\leq 1,\forall(x,a,b)\in\mathcal{X}\times\mathcal{A}\times\mathcal{B}`$,
then for all $`\mu\leq 1`$, it holds that

|     |                                                          |     |
|-----|----------------------------------------------------------|-----|
|     |
       ``` math
       \small dc({{\mathcal{F}}},MG,T,\mu)\leq 2dH(2+\ln(2HT)).
       ```                                                       |     |

Note that [Jin et al. (2021b)](#bib.bib15) considers a more general
setting of linear function approximation whose multi-agent decoupling
coefficient is also provably small due to
Proposition [3](#Thmproposition3 "Proposition 3 (Reduction to multi-agent Bellman Eluder dimension). ‣ 5.2 Bounds for the Multi-Agent Decoupling Coefficient ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").
Also note that as a special case, tabular MG is a linear MG of dimension
$`d=|\mathcal{X}||\mathcal{A}||\mathcal{B}|`$.

Generalized Linear MG. We then consider the generalized linear MG. In
this case, we have
$`(f^{h}-{\mathcal{T}}^{\mu}_{h}f_{h+1})(x,a,b)=\sigma(\phi(x,a,b)^{\top}\theta^{h})`$
for any $`\mu`$ induced by some function in $`{{\mathcal{F}}}`$ and
$`f\in{{\mathcal{F}}}`$ where $`\sigma`$ is differentiable and strictly
increasing. We further assume that $`\sigma^{\prime}\in(c_{1},c_{2})`$
and
$`\max\{\left\|\phi(x,a,b)\right\|,\left\|\theta^{h}\right\|\}\leq R`$
for some $`c_{1},c_{2},R>0`$.

###### Proposition 2 (Generalized Linear MG.).

For a generalized linear MG, with
$`{{\mathcal{F}}}=\{(x,a,b)\to\sigma(\phi(x,a,b)^{\top}\theta:\left\|\theta\right\|\leq H\sqrt{d}\}`$,
then for all $`\mu\leq 1`$, it holds that

|  |  |  |
|----|----|----|
|  |
``` math
dc({{\mathcal{F}}},MG,T,\mu)\leq 2dH(c_{2}^{2}/c_{1}^{2})(2+\ln(2HT)).
``` |  |

We can also derive an upper bound for the multi-agent decoupling
coefficient through multi-agent Bellman Eluder dimension introduced in
[Jin et al. (2021b)](#bib.bib15).

###### Proposition 3 (Reduction to multi-agent Bellman Eluder dimension).

Let $`\Pi_{{{\mathcal{F}}}}=\mathcal{D}_{{\mathcal{F}}}`$ be the set of
probability measures over
$`\mathcal{X}\times\mathcal{A}\times\mathcal{B}`$ at each step $`h`$
obtained by following $`(\mu_{f},\nu_{f,g})`$ for some
$`f,g\in{{\mathcal{F}}}`$. If
$`\mathrm{dim_{BE}}({{\mathcal{F}}},\Pi,1/T)=E`$, then the multi-agent
decoupling coefficient satisfies:

|     |                                                     |     |
|-----|-----------------------------------------------------|-----|
|     |
       ``` math
       dc({{\mathcal{F}}},MG,T,\mu)\leq(1+\log(T)+8\mu)EH.
       ```                                                  |     |

Similar to the single-agent case, the multi-agent decoupling coefficient
exhibits an additional factor of $`H`$ due to the formulation of
summation over all steps instead of maximum as in the multi-agent
Bellman Eluder dimension case. This formulation can offer advantages
when the complexity of the function class varies with time steps $`h`$.
Combining this with
Theorem [1](#Thmtheorem1 "Theorem 1 (Overall regret). ‣ 5.1 Theoretical Guarantee ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
the regret bound of our algorithm matches that of OFU-based algorithms.
However, we do remark that the results of [Jin et al.
(2021b)](#bib.bib15); [Huang et al. (2021)](#bib.bib11) are in a
high-probability fashion, which is stronger than the bound in
expectation.

### 5.3 Interpretation of Theorem [1](#Thmtheorem1 "Theorem 1 (Overall regret). ‣ 5.1 Theoretical Guarantee ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")

We now illustrate
Theorem [1](#Thmtheorem1 "Theorem 1 (Overall regret). ‣ 5.1 Theoretical Guarantee ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
by concrete examples. The first example is for the finite function
classes.

###### Corollary 4 (Finite function classes with completeness).

Let $`{{\mathcal{F}}}`$ be a finite function class satisfying
Assumptions [1](#Thmassumption1 "Assumption 1 (Realizability). ‣ 2.1 Function Approximation ‣ 2 Problem Formulation ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
[2](#Thmassumption2 "Assumption 2 (Completeness). ‣ 2.1 Function Approximation ‣ 2 Problem Formulation ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
and [3](#Thmassumption3 "Assumption 3 (Boundedness). ‣ 2.1 Function Approximation ‣ 2 Problem Formulation ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
with $`\beta=2`$. Assume that the prior is uniform
$`p_{0}^{h}(f)=1/|{{\mathcal{F}}}_{h}|`$, and
$`|{{\mathcal{F}}}|=\prod_{h=1}^{H}|{{\mathcal{F}}}_{h}|`$. With
$`\eta=0.1`$ and
$`\lambda=\sqrt{\frac{T\ln|{{\mathcal{F}}}|}{dc({{\mathcal{F}}},MG,T)}}`$,
we have

|  |  |  |
|----|----|----|
|  |
``` math
\small\mathbb{E}\mathop{\mathrm{Reg}}(T)=O(\sqrt{dc({{\mathcal{F}}},MG,T)T\ln(|{{\mathcal{F}}}|}).
``` |  |

Note that it is straightforward to generalize this result to the
infinite function classes by replacing the cardinality
$`|{{\mathcal{F}}}|`$ with its covering number
$`\mathcal{N}_{\infty}({{\mathcal{F}}},\epsilon)`$ with an appropriate
choice of $`\epsilon`$. We then illustrate
Theorem [1](#Thmtheorem1 "Theorem 1 (Overall regret). ‣ 5.1 Theoretical Guarantee ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
by considering the MGs with linear function approximation.

###### Corollary 5 (Linear MG).

For the linear MG, if we assume that the prior is uniform, we have
$`\kappa(\epsilon)=O(Hd\ln(1/\epsilon))`$. With
$`\eta=\frac{0.4}{H^{2}}`$ and
$`\lambda=\sqrt{\frac{T\kappa(H/T^{2})}{dH^{3}(1+\ln(2HT))}}`$, we have

|     |                                                                |     |
|-----|----------------------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{E}\mathop{\mathrm{Reg}}(T)={O}(H^{2}d\sqrt{T}\ln(HT)).
       ```                                                             |     |

Compared with [Xie et al. (2020)](#bib.bib33), our algorithm improves
the regret bound for linear MGs by a factor of $`\sqrt{d}`$. We remark
that the improvement is mainly due to the global optimism mechanism
instead of a step-wise one. Specifically, we add an optimistic term only
in the prior distributions at the initial value as in
Eqn. ([3.1](#S3.E1 "Equation 3.1 ‣ 3.2 The Main Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"))
and
Eqn. ([3.5](#S3.E5 "Equation 3.5 ‣ 3.3 The Booster Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")).
On the contrary, OMVI from [Xie et al. (2020)](#bib.bib33) establishes
optimism at every step (see lines $`8`$ and $`9`$ of their pseudo code).
The main bottleneck is that due to the temporal dependency, OMVI needs
to construct uniform concentration for the optimistic bonus function at
every step, whose covering number leads to the extra $`\sqrt{d}`$
factor. See Eqn. 5 and Lemma 18 of [Xie et al. (2020)](#bib.bib33) for
details.

Recently, [Xiong et al. (2022)](#bib.bib35) adopt the dataset splitting
trick from MDP ([Xie et al., 2021](#bib.bib34)) to resolve this issue in
the offline setting where the trajectories are independently collected
by some behavior policy. However, their technique cannot apply directly
in online setting as the policy used to collect new trajectory depends
on the history. Also, we remark that while the OMVI is also
computationally efficient, both our posterior sampling algorithm and
GOLF of [Jin et al. (2021b)](#bib.bib15); [Huang et al.
(2021)](#bib.bib11) are only information-theoretic. Therefore, it
remains open whether we could close this gap by designing
computationally efficient algorithm.

## 6 Conclusion

In this paper, a self-play posterior sampling algorithm is proposed for
two-player zero-sum Markov games with general function approximation,
which is the first to the best of our knowledge. A new complexity
measure, multi-agent decoupling coefficient, is introduced to
characterize the complexity of function class. Rigorous theoretical
analysis showed that the proposed algorithm could achieve comparable
regret bounds compared with other OFU-based algorithms for problems with
low multi-agent decoupling coefficient, which extends the results in the
single-agent RL.

As existing algorithms with general function approximation are
computationally inefficient in general, one important direction for
future works is to design computationally tractable algorithms for MGs
(and MDPs). Another interesting open question is how to extend the
posterior sampling algorithms for general-sum Markov games.

## Appendix A Equivalent Algorithms

We will consider a slightly more general posterior sampling algorithm
with an extra parameter $`\alpha\in(0,1]`$. We recall that the posterior
defined in
Eqn. ([3.3](#S3.E3 "Equation 3.3 ‣ 3.2 The Main Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"))
is

|  |  |  |
|----|----|----|
|  |
``` math
{p}(f|S_{t})\propto\exp(\lambda V_{f,1}(x^{1}))\prod_{h=1}^{H}q(f^{h}|f^{h+1},S_{t}),
``` |  |

where

|  |  |  |
|----|----|----|
|  |
``` math
q(f^{h}|f^{h+1},S_{t})=\frac{p_{0}^{h}(f^{h})\exp\left(-\eta L^{h}(f^{h},f^{h+1};S_{t})\right)}{\mathbb{E}_{f^{h}\sim p_{0}^{h}}\exp(-\eta L^{h}(f^{h},f^{h+1};S_{t}))}.
``` |  |

Equivalently, we may consider the excess loss

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\Delta L^{h}(f^{h},f^{h+1};\zeta_{s})=`$ | $`\displaystyle(f^{h}(x_{s}^{h},a^{h}_{s},b^{h}_{s})-r_{s}^{h}-V_{f^{h+1}}(x^{h+1}_{s}))^{2}`$ |  |  |
|  |  | $`\displaystyle\qquad-({\mathcal{T}}_{h}f^{h+1}(x_{s}^{h},a_{s}^{h},b_{s}^{h})-r_{s}^{h}-V_{f^{h+1}}(x_{s}^{h+1}))^{2},`$ |  | (A.1) |

where we employ the notation that
$`\zeta_{s}=\{[x_{s}^{h},a_{s}^{h},b_{s}^{h},r_{s}^{h}]\}_{h=1}^{H}`$.
We then define the potential function as

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\Phi_{t}^{h}(f)=`$ | $`\displaystyle-\ln p_{0}^{h}\left(f^{h}\right)+\alpha\eta\sum_{s=1}^{t-1}\Delta L^{h}\left(f^{h},f^{h+1};\zeta_{s}\right)`$ |  | (A.2) |
|  |  | $`\displaystyle+\alpha\ln\mathbb{E}_{\tilde{f}^{h}\sim p_{0}^{h}}\exp\left(-\eta\sum_{s=1}^{t-1}\Delta L^{h}\left(\tilde{f}^{h},f^{h+1};\zeta_{s}\right)\right),`$ |  |  |

where $`\alpha\in(0,1]`$ is the extra parameter to facilitate the proof.
We also define

|     |                                                      |     |
|-----|------------------------------------------------------|-----|
|     |
       ``` math
       \Delta f^{1}(x^{1})=V_{f,1}(x^{1})-V_{1}^{*}(x^{1}).
       ```                                                   |     |

Then, we obtain a generalized posterior distribution on
$`{{\mathcal{F}}}`$:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\hat{p}_{t}(f)\propto\exp\left(-\sum_{h=1}^{H}\Phi_{t}^{h}(f)+\lambda\Delta f^{1}(x^{1})\right),
``` |  | (A.3) |

where it is equivalent to the posterior given in
Eqn. ([3.3](#S3.E3 "Equation 3.3 ‣ 3.2 The Main Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"))
when $`\alpha=1`$.

We then recall the posterior distribution of the booster agent defined
in
Eqn. ([3.6](#S3.E6 "Equation 3.6 ‣ 3.3 The Booster Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"))
is given by

|  |  |  |
|----|----|----|
|  |
``` math
p^{\mu}(g|S_{t})\propto\exp(-\lambda V^{\mu}_{g,1}(x^{1}))\prod_{h=1}^{H}q^{\mu}(g^{h}|g^{h+1},S_{t}),
``` |  |

where

|  |  |  |
|----|----|----|
|  |
``` math
q^{\mu}(g^{h}|g^{h+1},S_{t})=\frac{p_{0}^{h}(g^{h})\exp\left(-\eta L^{h}_{\mu}(g^{h},g^{h+1};S_{t})\right)}{\mathbb{E}_{g^{h}\sim p_{0}^{h}}\exp(-\eta L^{h}_{\mu}(g^{h},g^{h+1};S_{t}))}.
``` |  |

Similarly, we define the excess loss for the booster agent:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\Delta L^{h}_{\mu}(g^{h},g^{h+1};\zeta_{s})=`$ | $`\displaystyle(g^{h}(x_{s}^{h},a^{h}_{s},b^{h}_{s})-r_{s}^{h}-V^{\mu}_{g^{h+1}}(x^{h+1}_{s}))^{2}`$ |  | (A.4) |
|  |  | $`\displaystyle-({\mathcal{T}}_{h}^{\mu}g^{h+1}(x_{s}^{h},a_{s}^{h},b_{s}^{h})-r_{s}^{h}-V^{\mu}_{g^{h+1}}(x_{s}^{h+1}))^{2}.`$ |  |  |

and

|  |  |  |
|----|----|----|
|  |
``` math
\Delta g^{1}_{\mu}(x^{1})=V_{1}^{\mu,\dagger}(v^{1})-V^{\mu}_{g,1}(x^{1}),
``` |  |

and use the following notation (with slight abuse of notation) for the
potential function:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\Phi_{t}^{h}(g,\mu)=`$ | $`\displaystyle-\ln p_{0}^{h}\left(g^{h}\right)+\alpha\eta\sum_{s=1}^{t-1}\Delta L^{h}_{\mu}\left(g^{h},g^{h+1};\zeta_{s}\right)`$ |  | (A.5) |
|  |  | $`\displaystyle+\alpha\ln\mathbb{E}_{\tilde{g}^{h}\sim p_{0}^{h}}\exp\left(-\eta\sum_{s=1}^{t-1}\Delta L^{h}_{\mu}\left(\tilde{g}^{h},g^{h+1};\zeta_{s}\right)\right),`$ |  |  |

since the analyses for
Algorithm [2](#alg2 "Algorithm 2 ‣ 3.1 Overview ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
and
Algorithm [3](#alg3 "Algorithm 3 ‣ 3.2 The Main Agent ‣ 3 Algorithm ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
are separate so the meaning of $`\Phi_{t}^{h}(\cdot)`$ will be clear
from the context. Finally, we obtain a generalized posterior function
for the booster agent:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\hat{p}^{\mu}_{t}(g)\propto\exp\left(-\sum_{h=1}^{H}\Phi_{t}^{h}(g,\mu)+\lambda\Delta g^{1}_{\mu}(x^{1})\right).
``` |  | (A.6) |

The main motivation to use $`\Delta L^{h}(\cdot)`$
($`\Delta L^{h}_{\mu}(\cdot)`$) is that the variance will be cancelled
during our theoretical analysis as it is equivalent to the case where we
know the Bellman operator. This is possible because the novel
denominator term is introduced in the likelihood as in [Dann et al.
(2021)](#bib.bib8).

## Appendix B Useful Lemmas and Additional Notations

In this section, we provide several useful lemmas and additional
notations that are useful later. We start with the following
definitions. First, we further define a quantity similar to
Definition [2](#Thmdefinition2 "Definition 2. ‣ 4.5 Complexity of ℱ ‣ 4 Sketch of the Main Ideas ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
which will be used for the analysis of the main agent.

###### Definition 3.

For any $`f^{\prime}\in{{\mathcal{F}}}_{h+1}`$, we define the set

|  |  |  |
|----|----|----|
|  |
``` math
{{\mathcal{F}}}_{h}(\epsilon,f^{\prime}):=\{f\in{{\mathcal{F}}}_{h}:\sup_{x,a,b}|\mathcal{E}_{h}(f,f^{\prime};x,a,b)|\leq\epsilon\}
``` |  |

containing the functions that have small $`{\mathcal{T}}_{h}`$-Bellman
error against $`f^{\prime}`$ for all state-action pairs. We then define
the quantity

|  |  |  |
|----|----|----|
|  |
``` math
\kappa_{1}(\epsilon)=\sup_{f\in{{\mathcal{F}}}}\sum_{h=1}^{H}\ln\frac{1}{p_{0}^{h}({{\mathcal{F}}}_{h}(\epsilon,f^{h+1}))},
``` |  |

which is the probability assigned by the prior to functions that
approximately satisfy the Bellman equation w.r.t. $`f`$ for all
state-action pair.

Note that $`\kappa_{1}(\epsilon)\leq\kappa(\epsilon)`$ because

|  |  |  |
|----|----|----|
|  |
``` math
\kappa_{1}(\epsilon)=\sup_{g\in{{\mathcal{F}}}}\sum_{h=1}^{H}\ln\frac{1}{p_{0}^{h}({{\mathcal{F}}}^{\mu_{g}}_{h}(\epsilon,g^{h+1}))}\leq\sup_{f\in{{\mathcal{F}}}}\sup_{g\in{{\mathcal{F}}}}\sum_{h=1}^{H}\ln\frac{1}{p_{0}^{h}({{\mathcal{F}}}^{\mu_{f}}_{h}(\epsilon,g^{h+1}))}=\kappa(\epsilon).
``` |  |

###### Definition 4.

For $`\alpha\in(0,1)`$, we also use the notations:

|  |  |  |
|----|----|----|
|  | $`\displaystyle\kappa^{h}_{1}(\alpha,\epsilon)=(1-\alpha)\ln\mathbb{E}_{f^{h+1}\sim p_{0}^{h+1}}p_{0}^{h}({{\mathcal{F}}}_{h}(\epsilon,f^{h+1}))^{-\alpha/(1-\alpha)},`$ |  |

and
$`\kappa^{h}_{1}(1,\epsilon)=\lim_{\alpha\to 1^{-}}\kappa^{h}(\alpha,\epsilon)`$
where it holds that

|  |  |  |
|----|----|----|
|  |
``` math
\kappa^{h}_{1}(1,\epsilon)=\sup_{f^{h+1}\in\mathcal{F}_{h+1}}\ln\frac{1}{p_{0}^{h}\left(\mathcal{F}_{h}\left(\epsilon,f^{h+1}\right)\right)}<\infty,
``` |  |

and

|  |  |  |
|----|----|----|
|  |
``` math
\kappa_{1}(\epsilon)=\sum_{h=1}^{H}\kappa_{1}^{h}(1,\epsilon)\leq\kappa(\epsilon).
``` |  |

Similarly, we define

|  |  |  |
|----|----|----|
|  |
``` math
\kappa^{h}_{\mu}(\alpha,\epsilon)=(1-\alpha)\ln\mathbb{E}_{f^{h+1}\sim p_{0}^{h+1}}p_{0}^{h}({{\mathcal{F}}}^{\mu}_{h}(\epsilon,f^{h+1}))^{-\alpha/(1-\alpha)},
``` |  |

and
$`\kappa^{h}_{\mu}(1,\epsilon)=\lim_{\alpha\to 1^{-}}\kappa^{h}_{\mu}(\alpha,\epsilon)`$,
Then, it holds that

|  |  |  |
|----|----|----|
|  |
``` math
\kappa_{\mu}^{h}(1,\epsilon)=\sup_{f^{h+1}\in{{\mathcal{F}}}_{h+1}}\ln\frac{1}{p_{0}^{h}({{\mathcal{F}}}_{h}^{\mu}(\epsilon,f^{h+1}))}<\infty,
``` |  |

and

|  |  |  |
|----|----|----|
|  |
``` math
\kappa_{\mu}(\epsilon)=\sum_{h=1}^{H}\kappa^{h}_{\mu}(1,\epsilon)\leq\kappa(\epsilon).
``` |  |

###### Lemma 3.

For any fixed $`g\in{{\mathcal{F}}}`$ and max-player’s policy
$`\mu:=\mu_{f}`$ for some $`f\in{{\mathcal{F}}}`$, we define a random
variable for all $`s`$ and $`h`$ as follows:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\xi_{s}^{h}\left(g^{h},g^{h+1},\zeta_{s}\right)=`$ | $`\displaystyle-2\eta\Delta L^{h}_{\mu}\left(g^{h},g^{h+1},\zeta_{s}\right)-\ln\mathbb{E}_{x_{s}^{h+1}\sim\mathbb{P}^{h}\left(\cdot\mid x_{s}^{h},a_{s}^{h}\right)}\exp\left(-2\eta\Delta L^{h}_{\mu}\left(g^{h},g^{h+1},\zeta_{s}\right)\right).`$ |  |

Then, for all $`h`$, we have

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{S_{t-1}}\exp\left(\sum_{s=1}^{t-1}\xi_{s}^{h}\left(g^{h},g^{h+1},\zeta_{s}\right)\right)=1.
``` |  |

A special case is that $`f=g`$ where we have

|  |  |  |
|----|----|----|
|  |
``` math
\Delta L_{\mu_{f}}^{h}(f^{h},f^{h+1},\zeta_{s})=\Delta L^{h}(f^{h},f^{h+1},\zeta_{s}).
``` |  |

###### Proof.

This lemma is from [Zhang (2005)](#bib.bib39) and is also proved in
[Dann et al. (2021)](#bib.bib8). ∎

###### Lemma 4.

Let $`\nu`$ be a probability distribution. Then,
$`\mathbb{E}_{\nu}f-H(\nu)`$ is minimized at
$`\nu(x)\propto\exp(-f(x))`$.

###### Proof.

This is a corollary of Gibbs variational principle whose proof can be
found in [Van Handel (2014)](#bib.bib30), Lemma 4.10. ∎

## Appendix C Proof of the Theorem [2](#Thmtheorem2 "Theorem 2 (Bound of the main agent). ‣ 5.1 Theoretical Guarantee ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")

In this section, we provide the proof for
Theorem [2](#Thmtheorem2 "Theorem 2 (Bound of the main agent). ‣ 5.1 Theoretical Guarantee ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").
The proof provided in this section basically follows the same line of
that of single-agent RL because essentially the algorithms employ the
same properties of the problem as discussed in
Section [4](#S4 "4 Sketch of the Main Ideas ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
and for the main agent, and the Bellman residuals is free of the
min-player’s policy.

###### Lemma 6.

For all functions $`f\in{{\mathcal{F}}}`$, we have

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{x_{s}^{h+1}\sim\mathbb{P}^{h}\left(\cdot\mid x_{s}^{h},a_{s}^{h},b_{s}^{h}\right)}\Delta L^{h}\left(f^{h},f^{h+1},\zeta_{s}\right)=\left(\mathcal{E}_{h}\left(f;x_{s}^{h},a_{s}^{h},b_{s}^{h}\right)\right)^{2}
``` |  |

and

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{x_{s}^{h+1}\sim\mathbb{P}^{h}\left(\cdot\mid x_{s}^{h},a_{s}^{h},b_{s}^{h}\right)}\Delta L^{h}\left(f^{h},f^{h+1},\zeta_{s}\right)^{2}\leq\frac{4\beta^{2}}{3}\left(\mathcal{E}_{h}\left(f;x_{s}^{h},a_{s}^{h},b_{s}^{h}\right)\right)^{2}
``` |  |

###### Proof.

We define the random variable

|  |  |  |
|----|----|----|
|  |
``` math
Z=f^{h}(x_{s}^{h},a_{s}^{h},b_{s}^{h})-r_{s}^{h}-V_{f,{h+1}}(x_{s}^{h+1}).
``` |  |

Let $`\mathbb{E}`$ be conditioned on
$`[x_{s}^{h},a_{s}^{h},b_{s}^{h}]`$. Then, the randomness is from the
state transition and we have

|     |                                                               |     |
|-----|---------------------------------------------------------------|-----|
|     |
       ``` math
       \mathbb{E}Z=\mathcal{E}_{h}(f;x_{s}^{h},a_{s}^{h},b_{s}^{h}).
       ```                                                            |     |

We also have

|     |                                                                  |     |
|-----|------------------------------------------------------------------|-----|
|     |
       ``` math
       \Delta L^{h}(f^{h},f^{h+1},\zeta_{s})=Z^{2}-(Z-\mathbb{E}Z)^{2}.
       ```                                                               |     |

and

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}[Z^{2}-(Z-\mathbb{E}Z)^{2}]=\mathbb{E}Z^{2}-\text{var}(Z)=(\mathbb{E}Z)^{2}=(\mathcal{E}_{h}(f;x_{s}^{h},a_{s}^{h},b_{s}^{h}))^{2}.
``` |  |

Also note that $`Z\in[-\beta,\beta-1]`$ and $`\max Z-\min Z\leq\beta`$
if it is conditioned on $`[x_{s}^{h},a_{s}^{h},b_{s}^{h}]`$, this
implies that

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}(Z^{2}-(Z-\mathbb{E}Z)^{2})^{2}\leq\frac{4}{3}\beta^{2}(\mathbb{E}Z)^{2}.
``` |  |

∎

###### Lemma 7.

If the learning rate $`\eta`$ is sufficiently small such that
$`\eta\beta^{2}\leq 0.8`$, then for all functions
$`f\in{{\mathcal{F}}}`$, we have

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\ln\mathbb{E}_{x_{s}^{h+1}\sim\mathbb{P}^{h}\left(\cdot\mid x_{s}^{h},a_{s}^{h},b_{s}^{h}\right)}\exp\left(-\eta\Delta L^{h}\left(f^{h},f^{h+1},\zeta_{s}\right)\right)`$ |  |
|  |  | $`\displaystyle\leq\mathbb{E}_{x_{s}^{h+1}\sim\mathbb{P}^{h}\left(\cdot\mid x_{s}^{h},a_{s}^{h},b_{s}^{h}\right)}\exp\left(-\eta\Delta L^{h}\left(f^{h},f^{h+1},\zeta_{s}\right)\right)-1`$ |  |
|  |  | $`\displaystyle\leq-0.25\eta\left(\mathcal{E}_{h}\left(f;x_{s}^{h},a_{s}^{h},b_{s}^{h}\right)\right)^{2}.`$ |  |

###### Proof.

With $`\eta\beta^{2}\leq 0.8`$, for all $`f\in{{\mathcal{F}}}`$, we have

|     |                                                     |     |
|-----|-----------------------------------------------------|-----|
|     |
       ``` math
       -\eta\Delta L^{h}(f^{h},f^{h+1},\zeta_{s})\leq 0.8.
       ```                                                  |     |

This implies that

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\exp\left(-\eta\Delta L^{h}(f^{h},f^{h+1},\zeta_{s})\right)`$ |  |
|  |  | $`\displaystyle\leq 1-\eta\Delta L^{h}(f^{h},f^{h+1},\zeta_{s})+0.67\eta^{2}\Delta L^{h}(f^{h},f^{h+1},\zeta_{s})^{2},`$ |  |

where we use the fact that $`\psi(z)=(e^{z}-1-z)/z^{2}`$ is increasing
in $`z`$ and $`\psi(0.8)<0.67`$. Therefore, we have

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\ln\mathbb{E}_{x_{s}^{h+1}\sim\mathbb{P}^{h}\left(\cdot\mid x_{s}^{h},a_{s}^{h},b_{s}^{h}\right)}\exp\left(-\eta\Delta L^{h}\left(f^{h},f^{h+1},\zeta_{s}\right)\right)`$ |  |
|  |  | $`\displaystyle\leq\mathbb{E}_{x_{s}^{h+1}\sim\mathbb{P}^{h}\left(\cdot\mid x_{s}^{h},a_{s}^{h},b_{s}^{h}\right)}\exp\left(-\eta\Delta L^{h}\left(f^{h},f^{h+1},\zeta_{s}\right)\right)-1`$ |  |
|  |  | $`\displaystyle\leq\mathbb{E}_{x_{s}^{h+1}\sim\mathbb{P}^{h}\left(\cdot\mid x_{s}^{h},a_{s}^{h},b_{s}^{h}\right)}-\eta\Delta L^{h}(f^{h},f^{h+1},\zeta_{s})+0.67\eta^{2}\Delta L^{h}(f^{h},f^{h+1},\zeta_{s})^{2}`$ |  |
|  |  | $`\displaystyle\leq-0.25\eta(\mathcal{E}_{h}(f^{h},f^{h+1},\zeta_{s})^{2},`$ |  |

where the first inequality is because $`\ln z\leq z-1`$ and the last
inequality is because
Lemma [6](#Thmlemma6 "Lemma 6. ‣ Appendix C Proof of the Theorem ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
and $`(\frac{4}{3}\eta b^{2}0.67)\leq 0.75`$. ∎

###### Lemma 8.

It holds that

|  |  |  |
|----|----|----|
|  | $`\displaystyle\inf_{p}\mathbb{E}_{S_{t-1}}\mathbb{E}_{f\sim p(\cdot)}\left[\sum_{h=1}^{H}{\Phi}_{t}^{h}(f)-\lambda\Delta f^{1}\left(x^{1}\right)+\ln p(f)\right]\leq\lambda\epsilon+4\alpha\eta(t-1)H\epsilon^{2}-\sum_{h=1}^{H}\ln p_{0}^{h}\left(\mathcal{F}_{h}\left(\epsilon,Q_{h+1}^{*}\right)\right).`$ |  |

###### Proof.

Consider any fixed $`f\in{{\mathcal{F}}}`$. For any
$`\tilde{f}^{h}\in{{\mathcal{F}}}^{h}`$ that depends on $`S_{s-1}`$, we
obtain from
Lemma [7](#Thmlemma7 "Lemma 7. ‣ Appendix C Proof of the Theorem ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
that

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{\zeta_{s}}\exp\left(-\eta\Delta L^{h}\left(\tilde{f}^{h},f^{h+1},\zeta_{s}\right)\right)-1\leq-0.25\eta\mathbb{E}_{\zeta_{s}}\left(\tilde{f}^{h}(x,a)-\mathcal{T}_{h}f^{h+1}(x,a,b)\right)^{2}\leq 0.
``` |  |

We let

|  |  |  |
|----|----|----|
|  |
``` math
W_{t}^{h}:=\mathbb{E}_{S_{t}}\mathbb{E}_{f\sim p(\cdot)}\ln\mathbb{E}_{\tilde{f}^{h}\sim p_{0}^{h}}\exp\left(-\eta\sum_{s=1}^{t}\Delta L^{h}(\tilde{f}^{h},f^{h+1},\zeta_{s})\right),
``` |  |

and recall that

|  |  |  |
|----|----|----|
|  |
``` math
\hat{q}_{t}^{h}\left(\tilde{f}^{h}\mid f^{h+1},S_{t-1}\right)=\frac{p_{0}^{h}(\tilde{f}^{h})\exp\left(-\eta\sum_{s=1}^{t-1}\Delta L^{h}\left(\tilde{f}^{h},f^{h+1},\zeta_{s}\right)\right)}{\mathbb{E}_{\tilde{f}^{\prime}\sim p_{0}^{h}}\exp\left(-\eta\sum_{s=1}^{t-1}\Delta L^{h}\left(\tilde{f}^{\prime},f^{h+1},\zeta_{s}\right)\right)}.
``` |  |

We have

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle W_{s}^{h}-W_{s-1}^{h}`$ | $`\displaystyle=\mathbb{E}_{S_{s}}\mathbb{E}_{f\sim p(\cdot)}\ln\mathbb{E}_{\tilde{f}^{h}\sim p_{0}^{h}}\frac{\exp\left(-\eta\sum_{t=1}^{s-1}\Delta L^{h}\left(\tilde{f}^{h},f^{h+1},\zeta_{t}\right)\right)}{\mathbb{E}_{\tilde{f}^{\prime}\sim p_{0}^{h}}\exp\left(-\eta\sum_{t=1}^{s-1}\Delta L^{h}\left(\tilde{f}^{\prime},f^{h+1},\zeta_{t}\right)\right)}\exp\left(-\eta\Delta L^{h}\left(\tilde{f}^{h},f^{h+1},\zeta_{s}\right)\right)`$ |  |
|  |  | $`\displaystyle=\mathbb{E}_{S_{s}}\mathbb{E}_{f\sim p(\cdot)}\ln\mathbb{E}_{\tilde{f}^{h}\sim\hat{q}_{s}^{h}\left(\cdot\mid f^{h+1},S_{s-1}\right)}\exp\left(-\eta\Delta L^{h}\left(\tilde{f}^{h},f^{h+1},\zeta_{s}\right)\right)`$ |  |
|  |  | $`\displaystyle\leq\mathbb{E}_{S_{s}}\mathbb{E}_{f\sim p(\cdot)}\left(\mathbb{E}_{\tilde{f}^{h}\sim\hat{q}_{s}^{h}\left(\cdot\mid f^{h+1},S_{s-1}\right)}\exp\left(-\eta\Delta L^{h}\left(\tilde{f}^{h},f^{h+1},\zeta_{s}\right)\right)-1\right)\leq 0`$ |  |

where we use $`\ln z\leq z-1`$. By $`W_{0}^{h}=0`$, we know that

|     |                                                                  |     |
|-----|------------------------------------------------------------------|-----|
|     |
       ``` math
       W_{t}^{h}=W_{0}^{h}+\sum_{s=1}^{t}[W_{s}^{h}-W_{s-1}^{h}]\leq 0,
       ```                                                               |     |

equivalently,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{S_{t}}\mathbb{E}_{f\sim p(\cdot)}\ln\mathbb{E}_{\tilde{f}^{h}\sim p_{0}^{h}}\exp\left(-\eta\sum_{s=1}^{t}\Delta L^{h}(\tilde{f}^{h},f^{h+1},\zeta_{s})\right)\leq 0.
``` |  |

This implies that for any $`p(\cdot)`$, we have

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\mathbb{E}_{S_{t-1}}\mathbb{E}_{f\sim p(\cdot)}\left[\sum_{h=1}^{H}\Phi_{t}^{h}(f)-\lambda\Delta f^{1}\left(x^{1}\right)+\ln p(f)\right]`$ |  |
|  |  | $`\displaystyle=\mathbb{E}_{S_{t-1}}\mathbb{E}_{f\sim p(\cdot)}\left[-\lambda\Delta f^{1}\left(x^{1}\right)+\alpha\eta\sum_{h=1}^{H}\sum_{s=1}^{t-1}\Delta L^{h}\left(f^{h},f^{h+1},\zeta_{s}\right)\right.`$ |  |
|  |  | $`\displaystyle\left.+\alpha\sum_{h=1}^{H}\ln\mathbb{E}_{\tilde{f}^{h}\sim p_{0}^{h}}\exp\left(-\eta\sum_{s=1}^{t-1}\Delta L^{h}\left(\tilde{f}^{h},f^{h+1},\zeta_{s}\right)\right)+\ln\frac{p(f)}{p_{0}(f)}\right]`$ |  |

|  |  | $`\displaystyle\leq\epsilon T+\frac{1}{\lambda}\alpha\eta(5\epsilon+2\beta)\frac{T(T-1)}{2}H-\frac{T}{\lambda}\sum_{h=1}^{H}\ln p_{0}^{h}(\mathcal{F}(\epsilon,Q_{h+1}^{*}))+\frac{T}{\lambda}\sum_{h=1}^{H}\kappa^{h}(\alpha,\epsilon)+\frac{\lambda}{\alpha\eta}dc({{\mathcal{F}}},MG,T,0.25\alpha\eta/\lambda)`$ |  |
|  |  | $`\displaystyle\leq O(\beta\sqrt{dc({{\mathcal{F}}},MG,T)\kappa(\beta/T^{2})T}+dc({{\mathcal{F}}},MG,T)).`$ |  |

Here in the last step, we first let $`\alpha\to 1^{-}`$ and note that

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle-\ln p_{0}^{h}\left(\mathcal{F}{(}\epsilon,Q_{h+1}^{*}\right)`$ | $`\displaystyle\leq\kappa^{h}_{1}(1,\epsilon),`$ |  |
|  | $`\displaystyle-\sum_{h=1}^{H}\ln p_{0}^{h}\left(\mathcal{F}(\epsilon,Q_{h+1}^{*}\right)+\sum_{h=1}^{H}\kappa^{h}_{1}(1,\epsilon)`$ | $`\displaystyle\leq 2\kappa(\epsilon).`$ |  |

Then, we take $`\epsilon=\frac{\beta}{T^{2}}`$,
$`\lambda=\sqrt{\frac{T\kappa(\beta/T^{2})}{\beta^{2}dc({{\mathcal{F}}},MG,T)}}`$,
and $`\eta=\frac{1}{4\beta^{2}}`$. This concludes the proof. ∎

###### Lemma 14.

|  |  |  |
|----|----|----|
|  |

|  |  |  |

|     |                                                                  |     |

|     |
       ``` math

       ```                                                               |     |

###### Proof of Theorem [3](#Thmtheorem3 "Theorem 3 (Bound of the booster agent). ‣ 5.1 Theoretical Guarantee ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").

Let $`\pi_{t}`$ denote the distribution induced by

|  |

\delta_{t}^{h}=-\lambda\mathcal{E}^{\mu_{t}}_{h}(g_{t},x_{t}^{h},a_{t}^{h},b_{t}^{h})-0.25\alpha\eta\sum_{s=1}^{t-1}\mathbb{E}_{\pi_{s}}\left(\mathcal{E}^{\mu_{t}}_{h}(g_{t},x_{t}^{h},a_{t}^{h},b_{t}^{h})\right)^{2}.

|  |  | $`\displaystyle=-\lambda\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\mathbb{E}_{g_{t}\sim\hat{p}^{\mu_{t}}_{t}}\Delta g^{\mu_{t}}_{t,1}(x^{1})+0.25\alpha\eta\sum_{h=1}^{H}\sum_{s=1}^{t-1}\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\mathbb{E}_{g_{t}\sim\hat{p}^{\mu_{t}}_{t}}\mathbb{E}_{\pi_{s}}\left(\mathcal{E}_{h}^{\mu_{t}}(g_{t},x_{t}^{h},a_{t}^{h},b_{t}^{h})\right)^{2}`$ |  |
|  |  | $`\displaystyle\leq\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\mathbb{E}_{g_{t}\sim\hat{p}_{t}}\left(\sum_{h=1}^{H}\Phi_{t}^{h}(g_{t},\mu_{t})-\lambda\Delta g^{\mu_{t}}_{t,1}(x^{1})+\ln\hat{p}^{\mu_{t}}_{t}(g_{t})\right)`$ |  |

|  |  | $`\displaystyle=\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\inf_{p}\mathbb{E}_{g\sim p}\left(\sum_{h=1}^{H}\Phi_{t}^{h}(g,\mu_{t})-\lambda\Delta g^{\mu_{t}}_{t,1}(x^{1})+\ln p(g)\right)`$ |  |
|  |  | $`\displaystyle+\alpha\eta\epsilon(2\beta+\epsilon)(t-1)H+\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{h=1}^{H}\kappa^{h}_{\mu_{t}}(\alpha,\epsilon)`$ |  |
|  |  | $`\displaystyle\leq\lambda\epsilon+\alpha\eta\epsilon(\epsilon+4\epsilon+2\beta)(t-1)H-\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{h=1}^{H}\ln p_{0}^{h}(\mathcal{F}_{h}(\epsilon,Q_{h+1}^{\mu_{t},\dagger}))+\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{h=1}^{H}\kappa^{h}_{\mu_{t}}(\alpha,\epsilon).`$ |  |

Summing over $`t`$, we obtain that

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\sum_{t=1}^{T}\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\mathbb{E}_{g_{t}\sim\hat{p}_{t}}(V_{1}^{\mu_{t},\nu_{t}}(x^{1})-V_{1}^{\mu_{t},\dagger}(x^{1}))`$ |  |

|  |  | $`\displaystyle+\frac{1}{\lambda}\sum_{t=1}^{T}\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{h=1}^{H}\kappa^{h}_{\mu_{t}}(\alpha,\epsilon)+\frac{\lambda}{\alpha\eta}dc({{\mathcal{F}}},MG,T,0.25\alpha\eta/\lambda)`$ |  |
|  |  | $`\displaystyle\leq O(\beta\sqrt{dc({{\mathcal{F}}},MG,T)\kappa(\beta/T^{2})T}+dc({{\mathcal{F}}},MG,T)).`$ |  |

The last step is proved as follows. We find an upper bound for
$`\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{t=1}^{T}\sum_{h=1}^{H}\kappa^{h}_{\mu_{t}}(\alpha,\epsilon)`$.
We note that for all $`\mu_{t}`$,
$`\kappa_{\mu_{t}}^{h}(\alpha,\epsilon)`$ is increasing w.r.t.
$`\alpha`$ with the limit
$`\kappa_{\mu_{t}}^{h}(1,\epsilon)\leq\kappa(\epsilon)<\infty`$. By
monotone convergence theorem, we know that

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{t=1}^{T}\sum_{h=1}^{H}\kappa^{h}_{\mu_{t}}(\alpha,\epsilon)\to\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{t=1}^{T}\sum_{h=1}^{H}\kappa^{h}_{\mu_{t}}(1,\epsilon)=\sum_{t=1}^{T}\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\kappa_{\mu_{t}}(\epsilon)\leq T\kappa(\epsilon).
``` |  |

We also have

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{t=1}^{T}\sum_{h=1}^{H}-\ln p_{0}^{h}\left(\mathcal{F}_{h}{(}\epsilon,Q_{h+1}^{\mu_{t},\dagger})\right)\leq\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{t=1}^{T}\kappa_{\mu_{t}}(\epsilon)\leq T\kappa(\epsilon).
``` |  |

It follows that

|  |  |  |
|----|----|----|
|  |
``` math
\begin{gathered}-\sum_{t=1}^{T}\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{h=1}^{H}\ln p_{0}^{h}(\mathcal{F}_{h}(\epsilon,Q_{h+1}^{\mu_{t},\dagger}))+\sum_{t=1}^{T}\mathbb{E}_{S_{t-1}}\mathbb{E}_{f_{t}\sim\hat{p}_{t}}\sum_{h=1}^{H}\kappa^{h}_{\mu_{t}}(1,\epsilon)\leq 2T\kappa(\epsilon).\end{gathered}
``` |  |

Now we first let $`\alpha\to 1^{-}`$. Then, we take
$`\epsilon=\frac{\beta}{T^{2}}`$,
$`\lambda=\sqrt{\frac{T\kappa(\beta/T^{2})}{\beta^{2}dc({{\mathcal{F}}},MG,T)}}`$,
$`\eta=\frac{1}{4\beta^{2}}`$. This concludes the proof. ∎

Let $`\mu=\mu_{f}`$ and $`\nu`$ be an arbitrary policy taken by the

|----|----|----|----|
|  |  | $`\displaystyle V^{*}_{1}(x^{1})-V_{1}^{\mu,\nu}(x^{1})`$ |  |
|  |  | $`\displaystyle=\sum_{h=1}^{H}\mathbb{E}_{\mu,\nu}V_{f,h}(x^{h})-r^{h}(x^{h},a^{h},b^{h})-V_{f,h+1}(x^{h+1})+V^{*}_{1}(x^{1})-V_{f,1}(x^{1})`$ |  |

|  |  | $`\displaystyle\leq\sum_{h=1}^{H}\mathbb{E}_{\mu,\nu}\mathbb{D}_{\mu,\nu}f^{h}(x^{h})-r^{h}(x^{h},a^{h},b^{h})-V_{f,h+1}(x^{h+1})+V^{*}_{1}(x^{1})-V_{f,1}(x^{1})`$ |  |

## Appendix F Proof of the Decoupling Coefficient Bounds

In this section, we provide proofs for the decoupling coefficient
bounds. We need the following lemma.

###### Lemma 18 (Elliptical Potential Lemma, Lemma $`10`$ of [Xie et al. (2020)](#bib.bib33)).

Suppose $`\{\phi_{t}\}_{t\geq 0}`$ is a sequence in $`\mathbb{R}^{d}`$
satisfying $`\left\|\phi_{t}\right\|\leq 1`$. Let
$`\Lambda_{0}\in\mathbb{R}^{d\times d}`$ be a positive definite matrix,
and $`\Lambda_{t}=\Lambda_{0}+\sum_{i=1}^{t}\phi_{i}\phi_{i}^{\top}`$.
If the smallest eigenvalues of $`\Lambda_{0}`$ is lower bounded by
$`1`$, then

|  |  |  |
|----|----|----|
|  |
``` math
\log\left(\frac{\operatorname{det}\Lambda_{t}}{\operatorname{det}\Lambda_{0}}\right)\leq\sum_{i\in[t]}\phi_{i}^{\top}\Lambda_{j-1}^{-1}\phi_{i}\leq 2\log\left(\frac{\operatorname{det}\Lambda_{t}}{\operatorname{det}\Lambda_{0}}\right).
``` |  |

###### Proof of Proposition [1](#Thmproposition1 "Proposition 1 (Linear MG). ‣ 5.2 Bounds for the Multi-Agent Decoupling Coefficient ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").

We first note that the completeness assumption is satisfied in linear MG
case whose proof can be found in [Huang et al. (2021)](#bib.bib11). Now
we consider two arbitrary $`{\theta^{h}},\theta^{h+1}`$ whose norms are
bounded by $`H\sqrt{d}`$ and $`f\in{{\mathcal{F}}}`$. We also define a
function $`g\in{{\mathcal{F}}}`$ s.t. $`g^{h}=g({\theta^{h}})`$ and
$`g^{h+1}=g({\theta^{h+1}})`$. By
Assumption [2](#Thmassumption2 "Assumption 2 (Completeness). ‣ 2.1 Function Approximation ‣ 2 Problem Formulation ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games"),
we can find some $`\theta^{h}(f)\in\mathbb{R}^{d}`$ with
$`\left\|\theta^{h}(f)\right\|\leq H\sqrt{d}`$ s.t.
$`{\mathcal{T}}^{\mu_{f}}_{h}(\phi(x,a,b)^{\top}\theta^{h+1})=\phi(x,a,b)^{\top}\theta^{h}(f)`$.
Therefore, we have

|  |  |  |
|----|----|----|
|  |
``` math
\mathcal{E}_{h}^{\mu_{f}}(g;x,a,b)=\phi(x,a,b)^{\top}(\theta^{h}-\theta^{h}(f))=\phi(x,a,b)^{\top}w^{h}(f,g),
``` |  |

where $`w^{h}(f,g)\in\mathbb{R}^{d}`$ satisfies
$`\left\|w^{h}(f,g)\right\|\leq 2H\sqrt{d}`$. We denote
$`\phi^{h}_{s}=\mathbb{E}_{\pi_{s}}[\phi(x^{h},a^{h},b^{h})]`$ and
$`\Phi_{t}^{h}=\lambda I+\sum_{s=1}^{t}\phi(x^{h},a^{h},b^{h})\phi(x^{h},a^{h},b^{h})^{\top}`$
where $`\lambda\geq 1`$ is a tuning parameter. Then, we have

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\mathbb{E}_{\pi_{{t}}}\left[\mathcal{E}^{\mu_{f_{t}}}_{h}\left(g_{t};x_{t}^{h},a_{t}^{h},b_{t}^{h}\right)\right]-\mu\sum_{s=1}^{t-1}\mathbb{E}_{\pi_{{s}}}\left[\mathcal{E}_{h}^{\mu_{f_{t}}}\left(g_{t};x_{s}^{h},a_{s}^{h}\right)^{2}\right]`$ |  |
|  |  | $`\displaystyle=w^{h}\left(f_{t},g_{t}\right)^{\top}\phi_{t}^{h}-\mu w^{h}\left(f_{t},g_{t}\right)^{\top}\sum_{s=1}^{t-1}\mathbb{E}_{\pi_{{s}}}\left[\phi\left(x^{h},a^{h},b^{h}\right)\phi\left(x^{h},a^{h},b^{h}\right)^{\top}\right]w^{h}\left(f_{t},g_{t}\right)`$ |  |
|  |  | $`\displaystyle\leq w^{h}\left(f_{t},g_{t}\right)^{\top}\phi_{t}^{h}-\mu w^{h}\left(f_{t},g_{t}\right)^{\top}\Phi_{t-1}^{h}w^{h}\left(f_{t},g_{t}\right)+4\mu\lambda dH^{2}`$ |  |
|  |  | $`\displaystyle\leq\frac{1}{4\mu}\left(\phi_{t}^{h}\right)^{\top}\left(\Phi_{t-1}^{h}\right)^{-1}\phi_{t}^{h}+4\mu\lambda dH^{2}`$ |  |

where the first inequality uses Jensen’s inequality and
$`\left\|w^{h}(f_{t},g_{t})\right\|\leq 2H\sqrt{d}`$ and the second
inequality comes from the fact
$`(a^{\top}b)\leq(\left\|a\right\|_{\Phi_{t-1}^{h}}\left\|b\right\|_{(\Phi_{t-1}^{h})^{-1}})\leq\frac{1}{2}(\left\|a\right\|^{2}_{\Phi_{t-1}^{h}}+\left\|b\right\|^{2}_{(\Phi_{t-1}^{h})^{-1}})`$.
Summing over $`t\in[T]`$ and $`h\in[H]`$, we have

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\sum_{t=1}^{T}\sum_{h=1}^{H}\mathbb{E}_{\pi_{{t}}}\left[\mathcal{E}^{\mu_{f_{t}}}_{h}\left(g_{t};x_{t}^{h},a_{t}^{h},b_{t}^{h}\right)\right]-\mu\sum_{s=1}^{t-1}\mathbb{E}_{\pi_{{s}}}\left[\mathcal{E}_{h}^{\mu_{f_{t}}}\left(g_{t};x_{s}^{h},a_{s}^{h}\right)^{2}\right]`$ |  |
|  |  | $`\displaystyle\leq\sum_{h=1}^{H}\left[\frac{\ln(\text{det}(\Phi_{T}^{h})-d\ln(\lambda)}{2\mu}+4\mu\lambda dH^{2}T\right]`$ |  |
|  |  | $`\displaystyle\leq H(\frac{d\ln(\lambda+T/d)-d\ln(\lambda)}{2\mu}+4\mu\lambda dH^{2}T),`$ |  |

where we use the Elliptical Potential lemma in the first inequality and
the second inequality uses

|  |  |  |
|----|----|----|
|  |
``` math
\ln\text{det}(\Phi_{T}^{h})\leq d\ln\frac{\text{trace}(\Phi_{T}^{h})}{d},\text{ and, }\text{trace}(\Phi_{t}^{h})\leq\lambda d+T.
``` |  |

By setting $`\lambda=\min\{1,\frac{1}{\mu^{2}H^{2}T}\}`$, we conclude
the proof. ∎

###### Proof of Proposition [2](#Thmproposition2 "Proposition 2 (Generalized Linear MG.). ‣ 5.2 Bounds for the Multi-Agent Decoupling Coefficient ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").

feature maps and the link function accordingly. By similar arguments
with the completeness assumption as in the proof of

we have

|  |  |  |
|----|----|----|
|  |
``` math

``` |  |

By the Lipschitz property, we have

|  |  |  |
|----|----|----|
|  |
``` math

``` |  |

for some $`w(f,g)\in\mathbb{R}^{d}`$ satisfying
$`w(f,g)\leq 2H\sqrt{d}`$. We denote
$`\phi_{h}^{s}=\mathbb{E}_{\pi_{s}}[\phi(x^{h},a^{h},b^{h})]`$ and
$`\Phi_{t}^{h}=\lambda I+\sum_{s=1}^{t}\phi(x^{h},a^{h},b^{h})\phi(x^{h},a^{h},b^{h})^{\top}`$
where $`\lambda\geq 1`$ is a tuning parameter. Then, we have

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\mathbb{E}_{\pi_{{t}}}\left[\mathcal{E}^{\mu_{f_{t}}}_{h}\left(g_{t};x_{t}^{h},a_{t}^{h},b_{t}^{h}\right)\right]-\mu\sum_{s=1}^{t-1}\mathbb{E}_{\pi_{{s}}}\left[\mathcal{E}_{h}^{\mu_{f_{t}}}\left(g_{t};x_{s}^{h},a_{s}^{h}\right)^{2}\right]`$ |  |
|  |  | $`\displaystyle\leq c_{2}|w^{h}\left(f_{t},g_{t}\right)^{\top}\phi_{t}^{h}|-\mu c_{1}^{2}w^{h}\left(f_{t},g_{t}\right)^{\top}\sum_{s=1}^{t-1}\mathbb{E}_{\pi_{{s}}}\left[\phi\left(x^{h},a^{h},b^{h}\right)\phi\left(x^{h},a^{h},b^{h}\right)^{\top}\right]w^{h}\left(f_{t},g_{t}\right)`$ |  |
|  |  | $`\displaystyle\leq c_{2}|w^{h}\left(f_{t},g_{t}\right)^{\top}\phi_{t}^{h}|-\mu c_{1}^{2}w^{h}\left(f_{t},g_{t}\right)^{\top}\Phi_{t-1}^{h}w^{h}\left(f_{t},g_{t}\right)+4\mu c_{1}^{2}\lambda dH^{2}`$ |  |
|  |  | $`\displaystyle\leq\frac{c_{2}^{2}}{4\mu c_{1}^{2}}\left(\phi_{t}^{h}\right)^{\top}\left(\Phi_{t-1}^{h}\right)^{-1}\phi_{t}^{h}+4\mu c_{1}^{2}\lambda dH^{2}.`$ |  |

Summing over $`t\in[T]`$ and $`h\in[H]`$, we have

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle\sum_{t=1}^{T}\sum_{h=1}^{H}\mathbb{E}_{\pi_{{t}}}\left[\mathcal{E}^{\mu_{f_{t}}}_{h}\left(g_{t};x_{t}^{h},a_{t}^{h},b_{t}^{h}\right)\right]-\mu\sum_{s=1}^{t-1}\mathbb{E}_{\pi_{{s}}}\left[\mathcal{E}_{h}^{\mu_{f_{t}}}\left(g_{t};x_{s}^{h},a_{s}^{h}\right)^{2}\right]`$ |  |
|  |  | $`\displaystyle\leq\sum_{h=1}^{H}c_{2}^{2}\left[\frac{\ln(\text{det}(\Phi_{T}^{h})-d\ln(\lambda)}{2\mu c_{1}^{2}}+4\mu\lambda c_{1}^{2}H^{2}dT\right]`$ |  |
|  |  | $`\displaystyle\leq Hc_{2}^{2}(\frac{d\ln(\lambda+T/d)-d\ln(\lambda)}{2\mu c_{1}^{2}}+4\mu\lambda c_{1}^{2}H^{2}dT).`$ |  |

Setting $`\lambda=\min\{1,\frac{1}{\mu^{2}c_{1}^{2}H^{2}T}\}`$ concludes
the proof. ∎

In what follows, we prove the reduction of Bellman-Eluder dimension to
the decoupling coefficient following the analysis of [Dann et al.
(2021)](#bib.bib8). From a high level, the multi-agent decoupling
coefficient bounds the out-of-sample prediction error by the in-sample
error. In particular, we remark that the existing techniques in the
literature of Eluder dimension (e.g., Lemma 41 of [Jin et al.
(2021a)](#bib.bib14)) is not sufficient for our needs. This is because a
deterministic upper bound of the in-sample error, i.e., the confidence
radius, is not available for the posterior sampling. We start the
following lemma from [Dann et al. (2021)](#bib.bib8).

###### Lemma 19.

For any sequence of positive reals $`x_{1},\cdots,x_{n}`$, we have

|  |  |  |
|----|----|----|
|  |
``` math
f(x):=\frac{\sum_{i=1}^{n}x_{i}}{\sqrt{\sum_{i=1}^{n}ix_{i}^{2}}}\leq\sqrt{1+\log(n)}.
``` |  |

###### Proof of Proposition [3](#Thmproposition3 "Proposition 3 (Reduction to multi-agent Bellman Eluder dimension). ‣ 5.2 Bounds for the Multi-Agent Decoupling Coefficient ‣ 5 Main Results ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games").

We consider a fixed $`h\in[H]`$. We first introduce some short-hand
notations. We denote
$`\hat{\epsilon}_{st}^{h}=|\mathbb{E}_{\mu_{s}}\mathcal{E}_{h}^{\mu_{f_{t}}}(g_{t},x^{h},a^{h})|`$
and
$`\epsilon^{h}_{st}=\hat{\epsilon}_{st}^{h}\mathbf{1}(\hat{\epsilon}_{st}^{h}>\epsilon)`$.
The proof proceeds as follows. We initialize $`T`$ empty buckets
$`B_{0}^{h},\cdots,B_{T-1}^{h}`$ and go through $`\epsilon_{tt}^{h}`$
one by one for $`t\in[T]`$.

If $`\epsilon_{tt}^{h}=0`$, we discard the timestep. Otherwise, we go
through the buckets from $`0`$ in increasing order. At bucket $`i`$,

- •
  if
  $`\sum_{s\leq t-1,s\in B_{i}^{h}}(\epsilon_{st}^{h})^{2}<(\epsilon_{tt}^{h})^{2}`$,
  we add $`t`$ into $`B_{i}^{h}`$;
- •
  otherwise, we continue with the next bucket.

We denote the index of bucket that each non-zero timestep ends up in as
$`b_{t}^{h}`$. As $`\epsilon_{tt}^{h}`$ skip the bucket
$`0,\cdots,b_{t}^{h}-1`$, by construction, we have

|  |  |  |
|----|----|----|
|  | $`\displaystyle\sum_{t=1}^{T}\sum_{s=1}^{t-1}\left(\epsilon_{st}^{h}\right)^{2}\geq\sum_{t=1}^{T}\sum_{0\leq i\leq b_{t}^{h}-1}\sum_{s\leq t-1,s\in B_{i}^{h}}\left(\epsilon_{st}^{h}\right)^{2}\geq\sum_{t=1}^{T}b_{t}^{h}\left(\epsilon_{tt}^{h}\right)^{2}.`$ |  |

Note by the definition of Eluder dimension, for the measures in
$`B_{i}^{h}`$, say, $`\{\mu_{t_{i}}:i=1,\cdots,m\}`$, $`\mu_{t_{j}}`$ is
$`\epsilon`$-independent from all the predecessors
$`\mu_{t_{1}},\cdots,\mu_{t_{j-1}}`$. Therefore, the size of each bucket
cannot exceed the Bellman Eluder dimension
$`E_{\epsilon}=\mathrm{dim_{BE}}({{\mathcal{F}}},\Pi,\epsilon)`$. By
Jensen’s inequality, we can obtain that

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sum_{t=1}^{T}b_{t}^{h}\left(\epsilon_{tt}^{h}\right)^{2}`$ | $`\displaystyle=\sum_{i=1}^{T-1}i\sum_{s\in B_{i}^{h}}(\epsilon_{ss}^{h})^{2}\geq\sum_{i=1}^{T-1}i|B_{i}^{h}|\left(\sum_{s\in B_{i}^{h}}\frac{\epsilon_{ss}^{h}}{|B_{i}^{h}|}\right)^{2}\geq\sum_{i=1}^{T-1}iE_{\epsilon}\left(\sum_{s\in B_{i}^{h}}\frac{\epsilon_{ss}^{h}}{E_{\epsilon}}\right)^{2},`$ |  |

where the last inequality uses $`|B_{i}^{h}|\leq E_{\epsilon}`$. By
Lemma [19](#Thmlemma19 "Lemma 19. ‣ Appendix F Proof of the Decoupling Coefficient Bounds ‣ A Self-Play Posterior Sampling Algorithm for Zero-Sum Markov Games")
with $`x_{i}=\sum_{s\in B_{i}^{h}}\epsilon_{ss}^{h}`$, we know that

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sum_{i=1}^{T-1}E_{\epsilon}i\left(\sum_{s\in B_{i}^{h}}\frac{\epsilon_{ss}^{h}}{E_{\epsilon}}\right)^{2}`$ | $`\displaystyle=\frac{1}{E_{\epsilon}}\sum_{i=1}^{T-1}i\left(\sum_{s\in B_{i}^{h}}\epsilon_{ss}^{h}\right)^{2}\geq\frac{1}{E_{\epsilon}(1+\log(T))}\left(\sum_{i=1}^{T-1}\sum_{s\in B_{i}^{h}}\epsilon_{ss}^{h}\right)^{2}`$ |  |
|  |  | $`\displaystyle=\frac{1}{E_{\epsilon}(1+\log(T))}\left(\sum_{s\in[T]\backslash B_{0}^{h}}\epsilon_{ss}^{h}\right)^{2}.`$ |  |

To summarize, we have proved that
$`\sum_{t=1}^{T}\sum_{s=1}^{t-1}\left(\epsilon_{st}^{h}\right)^{2}\geq\frac{1}{E_{\epsilon}(1+\log(T))}\left(\sum_{s\in[T]\backslash B_{0}^{h}}\epsilon_{ss}^{h}\right)^{2}.`$
It follows that

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sum_{h=1}^{H}\sum_{t=1}^{T}\hat{\epsilon}_{tt}^{h}`$ | $`\displaystyle\leq HT\epsilon+\sum_{h=1}^{H}\sum_{t=1}^{T}\epsilon_{tt}^{h}\leq HT\epsilon+E_{\epsilon}H+\sum_{h=1}^{H}\sum_{s\in[T]\backslash B_{0}^{h}}\epsilon_{ss}^{h}`$ |  |
|  |  | $`\displaystyle\leq HT\epsilon+E_{\epsilon}H+\sum_{h=1}^{H}\sqrt{\left(E_{\epsilon}(1+\log(T))\right)\sum_{t=1}^{T}\sum_{s=1}^{t-1}\left(\epsilon_{st}^{h}\right)^{2}}`$ |  |
|  |  | $`\displaystyle\leq HT\epsilon+E_{\epsilon}H+\mu\sum_{h=1}^{H}\sum_{t=1}^{T}\left[\sum_{s=1}^{t-1}(\epsilon_{st}^{h})^{2}\right]+\frac{(1+\log(T))E_{\epsilon}H}{4\mu}`$ |  |
|  |  | $`\displaystyle\leq\mu\sum_{h=1}^{H}\sum_{t=1}^{T}\left[\sum_{s=1}^{t-1}(\epsilon_{st}^{h})^{2}\right]+\frac{(1+\log(T)+8\mu)E_{\epsilon}H}{4\mu}`$ |  |

where the second inequality follows from
$`|B_{0}^{h}|\leq E_{\epsilon}`$ and the last inequality follows from
$`\epsilon=1/T`$. ∎
````
