# Reliable Self-Evolution with Imperfect Proxy Rewards.

Kangjun Noh Affiliation: Yonsei University    Soyu Kim
Affiliation: Yonsei University    Kyungwoo Song^(†) Affiliation: Yonsei
University

###### Abstract

Large language model (LLM)-based self-evolving search is a promising
approach to scientific discovery. However, high-fidelity evaluation of
every candidate is prohibitively expensive in some domains.
Self-evolving systems in such settings therefore rely on low-cost but
imperfect proxy rewards, which may assign high scores to infeasible
candidates. These false positives may contaminate both the final output
and the feedback used to guide subsequent generations. This motivates
statistically calibrated reward intervals for more reliable
self-evolving search. We propose Conformal Interval-Driven
Self-Evolution (CISE), which constructs candidate-specific reward
intervals using conditional conformal inference and iteration-wise
online density-ratio estimation. CISE uses conservative interval-based
rewards for evolutionary feedback and returns candidates only when all
required property intervals lie entirely within their respective
feasible regions. We derive fixed-iteration coverage results under
explicit assumptions of independence and covariate shift. We evaluate
CISE on three self-evolving search tasks in materials science. In our
experiments, all candidates returned by CISE are true positives under
high-fidelity evaluation, whereas the baselines return more candidates
but include false positives. These results highlight the value of a
smaller, more precise shortlist when downstream validation budgets are
limited. Our repository is available at
[https://github.com/MLAI-Yonsei/CISE.git](https://github.com/MLAI-Yonsei/CISE.git).

## 1 Introduction

Self-evolving search uses large language models (LLMs) to generate
candidates and improve subsequent candidates using feedback from
previous evaluations. This paradigm has recently emerged as an approach
to scientific discovery ([Romera-Paredes et al., 2024](#bib.bib13);
[Novikov et al., 2025](#bib.bib10); [Liu et al., 2026](#bib.bib15)).
These methods retain previously evaluated candidates together with their
rewards and reuse them to guide subsequent search. The effectiveness of
self-evolution therefore depends on the reliability of the rewards that
determine which candidates are treated as successful and reused in later
iterations.

However, obtaining the true reward for every generated candidate is
often slow or expensive in iterative search. In such settings,
self-evolving systems often rely on computationally inexpensive proxy
rewards that approximate the true reward. For example, in materials
discovery, evaluating every candidate with high-fidelity density
functional theory (DFT) calculations or experimental validation is
prohibitively expensive. Property prediction models are therefore often
used as proxy rewards during search ([Abhyankar et al.,
2026](#bib.bib6)). Although proxy rewards make iterative search
practical, prediction errors may produce false positives: candidates
that satisfy the target constraints under the proxy reward but fail
under the true reward. In self-evolving search, such errors affect more
than the returned candidates. Once a false positive is assigned a
favorable reward and stored as a successful example, it is reused to
guide subsequent generations. This false-positive propagation may steer
the search toward regions where the proxy reward is overly optimistic
rather than toward candidates with genuinely high true rewards.

This motivates uncertainty-aware reward estimates rather than relying
solely on point-valued proxy rewards. Conformal inference ([Vovk et al.,
2005](#bib.bib1); [Angelopoulos and Bates, 2022](#bib.bib3)) provides a
principled way to construct such estimates by converting model
predictions into calibrated intervals with statistical coverage
guarantees. In particular, conditional conformal inference ([Gibbs et
al., 2025](#bib.bib4)) incorporates candidate characteristics into
calibration, which is useful when proxy-reward reliability varies across
candidates. These calibrated intervals support conservative decisions
about which candidates guide subsequent evolution and which candidates
are returned as outputs.

We propose Conformal Interval-Driven Self-Evolution (CISE), a
self-evolving framework that replaces point-valued proxy rewards with
candidate-specific calibrated reward intervals. CISE uses conditional
conformal inference to construct candidate-specific reward intervals
with adaptive widths. The resulting reward interval is stored in the
archive and used to guide subsequent generations, while only candidates
whose entire reward intervals satisfy the task-specific constraints are
returned as outputs. Because the candidate distribution can change as
the archive, selected parents, and generation context evolve, CISE
additionally performs iteration-wise online density-ratio
estimation ([Kanamori et al., 2009](#bib.bib7)) to characterize the
difference between the source distribution and the current candidate
distribution and incorporates the estimated ratio into conditional
conformal inference. As a result, calibrated reward intervals are used
for both evolutionary feedback and final candidate selection.

Theoretically, we analyze fixed-iteration marginal coverage under
explicit independence and covariate-shift assumptions and characterize
how density-ratio estimation error affects the resulting guarantee.
Empirically, we evaluate CISE on three self-evolving material-property
search tasks and validate the returned candidates using high-fidelity
DFT calculations. Across the reported experiments, CISE trades output
yield for higher observed DFT-validated output precision: all CISE
outputs with resolved DFT evaluations are true positives, whereas the
baseline methods return false positives. We further show under a matched
downstream validation budget that the reliability improvement cannot be
explained solely by CISE returning fewer candidates. These results
demonstrate the potential of calibrated reward intervals to make
self-evolving search more reliable when accurate true rewards are too
expensive to use throughout evolution. To the best of our knowledge,
CISE is the first framework to use conformal proxy-reward intervals for
both evolutionary feedback and final candidate selection in LLM-based
self-evolving candidate search.

## 2 Related Work

Self-evolving search reuses previously generated candidates and their
rewards to guide subsequent generations across domains, including
program discovery ([Romera-Paredes et al., 2024](#bib.bib13); [Novikov
et al., 2025](#bib.bib10)), video-prompt optimization ([Ji et al.,
2024](#bib.bib20)), scientific hypothesis generation ([Gottweis et al.,
2026](#bib.bib21)), and materials discovery ([Abhyankar et al.,
2026](#bib.bib6)). While some settings provide directly verifiable
rewards, others rely on learned or LLM-generated proxy rewards to enable
efficient iterative search. In such cases, proxy-favored candidates may
not correspond to true improvements, and reusing them as successful
examples can propagate reward errors across subsequent generations. This
motivates accounting for proxy-reward uncertainty in both evolutionary
feedback and final selection.

Recent work has sought to improve the reliability of proxy evaluations
and rewards through calibration and uncertainty-aware optimization. For
LLM-as-a-judge, post-hoc score calibration learns regression models from
limited human feedback to adjust judge scores using their original
scores and rationales ([Sahoo et al., 2026](#bib.bib16)), while linear
probes on judge hidden states provide calibrated confidence estimates
for the correctness of their judgments ([Radharapu et al.,
2025](#bib.bib17)). Related work on learned reward models addresses
uncertainty and overoptimization directly: ensemble-based conservative
objectives use disagreement among reward models to reduce optimization
against errors in an imperfect reward model ([Coste et al.,
2024](#bib.bib18)). Process reward models have also been calibrated
using quantile regression to better align their predictions with
empirical success probabilities and support uncertainty-aware allocation
of inference-time computation ([Park et al., 2025](#bib.bib19)). These
approaches improve the calibration, interpretation, or robustness of
model-derived rewards. However, they do not statistically control
false-positive rewards under task-specific true-reward constraints in
iterative self-evolving search.

Conformal inference provides a complementary framework for uncertainty
quantification by converting model predictions into calibrated
prediction sets or intervals with finite-sample coverage guarantees
under explicit assumptions ([Vovk et al., 2005](#bib.bib1);
[Angelopoulos and Bates, 2022](#bib.bib3)). Conditional conformal
inference formulates conditional validity through classes of covariate
shifts and provides finite-sample guarantees for shifts represented by a
finite-dimensional calibration function space ([Gibbs et al.,
2025](#bib.bib4)). More recently, conformal inference has been applied
to LLM-as-a-judge evaluation, replacing point-valued judge scores with
calibrated intervals that explicitly represent evaluation
uncertainty ([Sheng et al., 2025](#bib.bib2); [Noh et al.,
2026](#bib.bib14)). Building on this line of work, we use conformal
inference to construct calibrated intervals for proxy rewards and use
these reward intervals in both evolutionary feedback and final candidate
selection in self-evolving search.

## 3 Preliminaries: Self-Evolving Agent for Material Search with Proxy Reward

We consider a self-evolving agent that searches a candidate space
$`\mathcal{X}`$ for solutions satisfying task-specific constraints. For
each candidate $`x\in\mathcal{X}`$, $`r(x)\in\mathbb{R}`$ denotes a
scalar true reward, and $`\hat{r}(x)\in\mathbb{R}`$ denotes an
inexpensive and imperfect proxy reward. During search, generated
candidates are evaluated using the proxy reward. The task-specific
constraints are specified before evolution. Let $`\mathcal{F}_{r}`$ and
$`\mathcal{F}_{\hat{r}}`$ denote the sets of candidates satisfying these
constraints according to the true and proxy rewards, respectively.
Membership in $`\mathcal{F}_{\hat{r}}`$ is determined by computing
$`\hat{r}(x)`$ and checking it against the specified constraints. A
candidate $`x\in\mathcal{F}_{\hat{r}}\setminus\mathcal{F}_{r}`$ is a
false positive: it satisfies the constraints under the proxy reward but
violates them under the true reward.

The archive $`\mathcal{H}_{t}`$ stores candidates generated through
iteration $`t`$ together with their proxy rewards. The parent-selection
policy $`\pi_{t}(\cdot\mid\mathcal{H}_{t})`$ selects $`K`$ candidates
from the archive to form the parent set $`\mathcal{S}_{t}`$, which
guides candidate generation at the next iteration. We treat
$`\{\pi_{t}\}_{t=0}^{T}`$ as a given sequence of selection rules; we do
not consider a separate policy-learning step. As the archive and its
stored rewards change, the selected parents and the resulting candidate
generation can nevertheless change across iterations.
Algorithm [2](#alg2 "Algorithm 2 ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
summarizes the proxy-reward-driven search process. At iteration $`t`$,
the agent uses the previous parents $`\mathcal{S}_{t-1}`$ and their
stored rewards to generate a batch
$`\mathcal{C}_{t}=\{x_{t,1},\ldots,x_{t,M}\}`$ of $`M`$ new candidates.
The proxy reward is computed for each candidate, and the resulting
candidate-reward pairs are added to the archive. Candidates whose proxy
rewards satisfy the task-specific constraints are also added to the
cumulative output set, giving
$`\mathcal{O}_{t}=\mathcal{O}_{t-1}\cup(\mathcal{C}_{t}\cap\mathcal{F}_{\hat{r}})`$.
The updated archive is then used to select the next parent set. The
archive and output set serve different purposes: the archive retains
generated candidates as search experience, whereas the output set
contains only candidates that satisfy the proxy-reward constraints.

## 4 Methodology

### 4.1 Problem Setup

We are given a labeled source dataset
$`\mathcal{D}=\{(X_{i},r(X_{i}))\}_{i=1}^{n}`$ of independent
candidate-reward pairs drawn from a joint distribution
$`\mathbf{P}_{0}`$, with candidate marginal $`\mathbf{P}_{0}^{X}`$. We
partition $`\mathcal{D}`$ into three mutually disjoint subsets:
$`\mathcal{D}_{\mathrm{fit}}`$, $`\mathcal{D}_{\mathrm{cal}}`$, and
$`\mathcal{D}_{\mathrm{src}}`$. The fitting set
$`\mathcal{D}_{\mathrm{fit}}`$ is used to train a model $`\hat{q}(x)`$
that predicts an upper conditional quantile of the absolute proxy error
$`|r(x)-\hat{r}(x)|`$. The calibration set
$`\mathcal{D}_{\mathrm{cal}}`$ is used to construct conformal reward
intervals, while $`\mathcal{D}_{\mathrm{src}}`$ provides the source
reference for density-ratio estimation. Only the candidate information
in $`\mathcal{D}_{\mathrm{src}}`$ is used for density-ratio estimation.
The proxy reward model, fitted quantile model, and candidate
representation are fixed before evolution.

For a fixed iteration $`t`$, let $`\mathbf{P}_{t}`$ denote the joint
distribution of a candidate and its true reward under the current
archive, selected parents, and generation configuration. For a fresh
candidate–reward pair $`(X^{\prime},r(X^{\prime}))\sim\mathbf{P}_{t}`$,
CISE uses conditional conformal inference ([Gibbs et al.,
2025](#bib.bib4)) to construct an iteration-specific prediction interval
$`\mathcal{I}_{t}(X^{\prime})`$ for the true reward. This interval
represents uncertainty in the proxy reward and is used for both
evolutionary feedback and output selection.

For evolutionary feedback, a candidate with a nonempty, bounded interval
is evaluated conservatively over that interval using a task-specific
rule. The resulting interval reward is stored with the candidate in
$`\mathcal{H}_{t}`$. The parent-selection policy
$`\pi_{t}(\cdot\mid\mathcal{H}_{t})`$ uses these stored rewards to
select the next parents, and subsequent generation uses the selected
parents and their rewards as feedback. For output selection, a candidate
is added to $`\mathcal{O}_{t}`$ only when its interval is nonempty and
bounded and every reward value in the interval satisfies the
task-specific constraints. A lower-bound constraint is checked using the
lower endpoint, an upper-bound constraint using the upper endpoint, and
a bounded-range constraint requires the entire interval to lie within
the prescribed range. Thus, a candidate with a valid interval may be
retained in the archive even when it does not satisfy the output
criterion.

Our target is iteration-wise marginal coverage: for a fresh
candidate–reward pair at a fixed iteration $`t`$, the true reward should
lie in its prediction interval with probability at least $`1-\alpha`$,

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\mathbb{P}\!\left(r(X^{\prime})\in\mathcal{I}_{t}(X^{\prime})\right)\geq 1-\alpha,\qquad t=1,\ldots,T.
``` |  | (1) |

The probability is marginal over the source data and the fresh
candidate–reward pair under the assumptions stated below. The guarantee
is evaluated separately at each iteration and does not assert
simultaneous coverage over the full search trajectory. We first analyze
this target under exchangeability and then characterize the effect of
covariate shift and density-ratio estimation error.

Let $`A_{t}`$ denote acceptance at iteration $`t`$. Since acceptance
requires the entire interval to satisfy the task constraint,

|  |  |  |
|----|----|----|
|  |
``` math
A_{t}\cap\{X^{\prime}\notin\mathcal{F}_{r}\}\subseteq\{r(X^{\prime})\notin\mathcal{I}_{t}(X^{\prime})\},
``` |  |

and hence
$`\mathbb{P}(A_{t},X^{\prime}\notin\mathcal{F}_{r})\leq\alpha`$ whenever
equation [1](#S4.E1 "In 4.1 Problem Setup ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
holds. This controls the joint acceptance-and-false-positive event, not
the false-positive probability conditional on acceptance.

### 4.2 Conformal Interval-driven Self-Evolution under Exchangeability

We first consider an exchangeable reference setting with
$`\mathbf{P}_{t}=\mathbf{P}_{0}`$ for a fixed iteration $`t`$ before
considering covariate shift. Write the calibration pairs as
$`\{(X_{i},r(X_{i}))\}_{i=1}^{n_{\mathrm{cal}}}`$, and let
$`(X^{\prime},r(X^{\prime}))\sim\mathbf{P}_{t}`$ denote an independent
fresh candidate-reward pair. The equality
$`\mathbf{P}_{t}=\mathbf{P}_{0}`$ means that the calibration candidates
and the newly generated candidate follow the same joint distribution
over material structures and true rewards. We hold the archive, selected
parents, and generation configuration fixed, and assume that the
resulting candidate distribution is independent of
$`\mathcal{D}_{\mathrm{cal}}`$.

Let $`S(x,u;\hat{r})`$ denote a fixed nonconformity score measuring the
discrepancy between a hypothetical reward value $`u`$ and the proxy
prediction $`\hat{r}(x)`$. Let $`\hat{q}(x)`$ denote a fitted
conditional quantile of the absolute proxy error. We define the score as
$`S(x,u;\hat{r})=|u-\hat{r}(x)|-\hat{q}(x)`$, so that larger values
indicate discrepancies that are unusually large relative to the
prediction error expected at $`x`$. For each calibration pair
$`(X_{i},r(X_{i}))`$, we write $`S_{i}=S(X_{i},r(X_{i});\hat{r})`$. Let
$`\mathcal{G}`$ be a finite-dimensional linear function space spanned by
the constant function and fixed functions of the candidate
representation $`\phi(x)`$. For example, $`\mathcal{G}`$ may be chosen
as
$`\mathcal{G}=\operatorname{span}\{1,\phi_{1}(x),\ldots,\phi_{d}(x)\}`$.
This space allows the calibration adjustment to vary with candidate
characteristics.

Following [Gibbs et al. (2025)](#bib.bib4), we calibrate the scores
through an augmented quantile regression that includes the fresh
candidate. For a fixed $`X^{\prime}`$ and an imputed test score
$`s\in\mathbb{R}`$, define

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{q}_{s}\in\underset{q\in\mathcal{G}}{\arg\min}\left\{\sum_{i=1}^{n_{\mathrm{cal}}}\ell_{\alpha}\!\left(q(X_{i}),S_{i}\right)+\ell_{\alpha}\!\left(q(X^{\prime}),s\right)\right\},
``` |  | (2) |

where $`\ell_{\alpha}(a,b)=(1-\alpha)(b-a)_{+}+\alpha(a-b)_{+}`$ is the
pinball loss for the $`(1-\alpha)`$-quantile, with
$`(v)_{+}=\max\{v,0\}`$. The additional term incorporates the fresh
candidate into calibration using a hypothetical score, allowing the
adjustment to account for $`X^{\prime}`$ before its true reward is
observed.

Let $`\eta_{s}(X^{\prime})\in[-\alpha,1-\alpha]`$ denote the dual
variable associated with the fresh candidate
in equation [2](#S4.E2 "In 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").
This variable is nondecreasing in $`s`$. The nonrandomized score cutoff
and the resulting reward interval are

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\widehat{\tau}_{t}(X^{\prime})`$ | $`\displaystyle=\sup\left\{s\in\mathbb{R}:\eta_{s}(X^{\prime})<1-\alpha\right\},`$ |  | (3) |
|  | $`\displaystyle\mathcal{I}_{t}(X^{\prime})`$ | $`\displaystyle=\left\{u\in\mathbb{R}:S(X^{\prime},u)\leq\widehat{\tau}_{t}(X^{\prime})\right\}.`$ |  |  |

The cutoff is computed from the dual boundary of the unpenalized
augmented problem. Inverting the chosen absolute-error score yields an
interval centered at $`\hat{r}(X^{\prime})`$, with its width determined
by the fixed normalization, fitted base quantile, and calibrated cutoff.
An empty interval leads to abstention under the output rule in
Section [4.1](#S4.SS1 "4.1 Problem Setup ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").

###### Theorem 1 (Iteration-wise marginal coverage under exchangeability).

For a fixed iteration $`t`$, assume that the calibration pairs are
i.i.d. draws from $`\mathbf{P}_{0}`$, and that the fresh pair
$`(X^{\prime},r(X^{\prime}))`$ is an independent draw from
$`\mathbf{P}_{t}=\mathbf{P}_{0}`$. Suppose that the score $`S`$ and
finite-dimensional linear space $`\mathcal{G}`$ are fixed independently
of these pairs, and that $`\mathcal{G}`$ contains the constant function.
If equation [2](#S4.E2 "In 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
is solved exactly with a dual-solution rule symmetric under permutations
of the augmented observations, then the interval
in equation [3](#S4.E3 "In 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
satisfies

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\left(r(X^{\prime})\in\mathcal{I}_{t}(X^{\prime})\right)\geq 1-\alpha.
``` |  |

At the true test score, the augmented observations are exchangeable. The
constant function in $`\mathcal{G}`$ imposes a zero-sum constraint on
the optimal dual variables. Together with their bounds, this limits the
fraction reaching the upper boundary $`1-\alpha`$ to at most $`\alpha`$.
The result
establishes equation [1](#S4.E1 "In 4.1 Problem Setup ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
in the reference setting. The next subsection adapts the calibration
function space to the current candidate distribution when
$`\mathbf{P}_{t}\neq\mathbf{P}_{0}`$.

### 4.3 Conformal Interval-driven Self-Evolution under Evolutionary Covariate Shift

As evolution proceeds, changes in the archive, selected parents, and
generation strategy alter the distribution of materials proposed by the
agent. For a fixed iteration $`t`$, let $`\mathbf{P}_{t}`$ denote the
joint distribution of a candidate and its true reward under the current
archive, parent set, and generation configuration. We consider
evolutionary covariate shift satisfying

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbf{P}_{t}(r(X)\mid X)=\mathbf{P}_{0}(r(X)\mid X),\qquad\mathbf{P}_{t}^{X}\ll\mathbf{P}_{0}^{X},\qquad w_{t}(x)=\frac{d\mathbf{P}_{t}^{X}}{d\mathbf{P}_{0}^{X}}(x)\leq W,
``` |  | (4) |

where $`W<\infty`$ is a bounded-overlap constant. Thus, evolution may
change how frequently different material structures are generated while
preserving the conditional relationship between a structure and its true
reward. The density ratio $`w_{t}`$ describes this change relative to
the source distribution.

At iteration $`t`$, we generate an unlabeled probe batch
$`\mathcal{B}_{t}`$ from $`\mathbf{P}_{t}^{X}`$ using the current
parents and their stored rewards. The probe batch is used only for
density-ratio estimation, and fresh candidates are subsequently
generated for interval evaluation and archive updates. The archive,
parents, and generation configuration remain fixed throughout both
stages. We assume that the probe candidates and the subsequent
candidates are independent draws from the same current distribution,
with $`\mathcal{D}_{\mathrm{cal}}`$ independent of both stages.

Let $`\phi(X)`$ be the fixed candidate representation, and let
$`\mathcal{W}=\{w_{\theta}:w_{\theta}(x)=h_{\theta}(\phi(x))\in[0,W],\theta\in\Theta\}`$
be a bounded density-ratio model class. We estimate the current ratio
through least-squares importance fitting ([Kanamori et al.,
2009](#bib.bib7)):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{\theta}_{t}\in\underset{\theta\in\Theta}{\arg\min}\left\{\frac{1}{2|\mathcal{D}_{\mathrm{src}}|}\sum_{(X_{i},r(X_{i}))\in\mathcal{D}_{\mathrm{src}}}w_{\theta}(X_{i})^{2}-\frac{1}{|\mathcal{B}_{t}|}\sum_{X^{\prime}\in\mathcal{B}_{t}}w_{\theta}(X^{\prime})+\lambda\Omega(\theta)\right\},\qquad\widehat{w}_{t}=w_{\widehat{\theta}_{t}}.
``` |  | (5) |

Here, $`\lambda\geq 0`$ controls regularization of the ratio estimator
through a fixed penalty $`\Omega`$. The population counterpart of the
first two terms equals
$`\frac{1}{2}\mathbb{E}_{\mathbf{P}_{0}^{X}}[(w_{\theta}(X)-w_{t}(X))^{2}]`$
up to a constant independent of $`\theta`$.
Equation [5](#S4.E5 "In 4.3 Conformal Interval-driven Self-Evolution under Evolutionary Covariate Shift ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
therefore approximates the current ratio using source candidates and
unlabeled target candidates. Repeating this update with
$`\mathcal{B}_{t}`$ at each iteration gives an online density-ratio
estimation procedure for the sequence
$`\{\mathbf{P}_{t}^{X}\}_{t=1}^{T}`$.

We incorporate the estimated ratio into CCI by extending the calibration
function space from
Section [4.2](#S4.SS2 "4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards."):

|  |  |  |
|----|----|----|
|  |
``` math
\mathcal{G}_{t}=\mathcal{G}+\operatorname{span}\{\widehat{w}_{t}\}.
``` |  |

The ratio enters as an additional basis function, while the augmented
quantile regression retains its unweighted pinball loss and unpenalized
calibration objective. For each fresh candidate $`x`$, we
solve equation [2](#S4.E2 "In 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
over $`\mathcal{G}_{t}`$ and construct $`\mathcal{I}_{t}(x)`$
through equation [3](#S4.E3 "In 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").
Finite-dimensional CCI provides coverage under covariate shifts
represented by nonnegative functions in its calibration space ([Gibbs et
al., 2025](#bib.bib4)). Adding $`\widehat{w}_{t}`$ therefore connects
the calibration adjustment to the current generation distribution.

For the coverage analysis, suppose that
$`\mathbb{E}_{\mathbf{P}_{0}^{X}}[\widehat{w}_{t}(X)]>0`$ and define

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\epsilon_{t}=\frac{1}{2}\mathbb{E}_{\mathbf{P}_{0}^{X}}\left[\left|w_{t}(X)-\frac{\widehat{w}_{t}(X)}{\mathbb{E}_{\mathbf{P}_{0}^{X}}[\widehat{w}_{t}(X)]}\right|\right].
``` |  | (6) |

The normalized ratio defines a candidate distribution relative to
$`\mathbf{P}_{0}^{X}`$, and $`\epsilon_{t}`$ is its total variation
distance from $`\mathbf{P}_{t}^{X}`$. This term captures density-ratio
estimation error and misspecification of the representation or ratio
model. Normalization preserves membership in $`\mathcal{G}_{t}`$, since
multiplying a basis function by a positive constant leaves its linear
span unchanged.

Algorithm [1](#alg1 "Algorithm 1 ‣ 4.3 Conformal Interval-driven Self-Evolution under Evolutionary Covariate Shift ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
summarizes the resulting search process. The current probe batch
determines $`\widehat{w}_{t}`$ and $`\mathcal{G}_{t}`$, while each fresh
candidate receives its own test-point calibration. The archive stores
the resulting interval rewards, and the cumulative output contains
candidates whose entire intervals satisfy the task-specific constraints.

$`\hat{r}`$; data splits $`\mathcal{D}_{\mathrm{fit}}`$,
$`\mathcal{D}_{\mathrm{cal}}`$, and $`\mathcal{D}_{\mathrm{src}}`$; base
calibration space $`\mathcal{G}`$; density-ratio model class
$`\mathcal{W}`$; parent-selection policies $`\{\pi_{t}\}_{t=0}^{T}`$;
task-specific reward constraints; miscoverage level $`\alpha`$; probe
budget; candidate budget $`M`$; parent budget $`K`$; number of
iterations $`T`$

The following result combines the finite-dimensional CCI guarantee with
the distribution discrepancy in

###### Theorem 2 (Iteration-wise marginal coverage under evolutionary covariate shift).

For a fixed iteration $`t`$, condition on the current generation state,
$`\mathcal{D}_{\mathrm{fit}}`$, $`\mathcal{D}_{\mathrm{src}}`$, and
$`\mathcal{B}_{t}`$. Assume that, conditionally on these quantities, the
calibration pairs remain i.i.d. draws from $`\mathbf{P}_{0}`$, and the
fresh pair $`(X^{\prime},r(X^{\prime}))`$ is an independent draw from
$`\mathbf{P}_{t}`$
satisfying equation [4](#S4.E4 "In 4.3 Conformal Interval-driven Self-Evolution under Evolutionary Covariate Shift ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").
Suppose that $`\widehat{w}_{t}`$ is nonnegative with positive source
expectation, and that the score $`S`$ and finite-dimensional space
$`\mathcal{G}_{t}`$ are fixed under this conditioning. If the augmented
calibration over $`\mathcal{G}_{t}`$ is solved exactly with the
symmetric dual-solution rule in
Theorem [1](#Thmtheorem1 "Theorem 1 (Iteration-wise marginal coverage under exchangeability). ‣ 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards."),
then

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\left(r(X^{\prime})\in\mathcal{I}_{t}(X^{\prime})\right)\geq 1-\alpha-\epsilon_{t},
``` |  |

where $`\epsilon_{t}`$ is defined
in equation [6](#S4.E6 "In 4.3 Conformal Interval-driven Self-Evolution under Evolutionary Covariate Shift ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").
The probability is conditional on the quantities held fixed and marginal
over the calibration data and the fresh candidate–reward pair.

The normalized estimated ratio belongs to $`\mathcal{G}_{t}`$, so the
finite-dimensional CCI result gives coverage of at least $`1-\alpha`$
under its induced candidate distribution. The calibration distribution
remains $`\mathbf{P}_{0}`$ in both settings, and the conditional reward
law is shared. Replacing the induced candidate distribution by
$`\mathbf{P}_{t}^{X}`$ therefore changes the coverage probability by at
most $`\epsilon_{t}`$, establishing
Theorem [2](#Thmtheorem2 "Theorem 2 (Iteration-wise marginal coverage under evolutionary covariate shift). ‣ 4.3 Conformal Interval-driven Self-Evolution under Evolutionary Covariate Shift ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").
Averaging over the estimation data gives the corresponding marginal
bound with $`\mathbb{E}[\epsilon_{t}]`$. The same $`1-\alpha`$ coverage
follows directly whenever $`w_{t}\in\mathcal{G}_{t}`$. By the output
rule in
Section [4.1](#S4.SS1 "4.1 Problem Setup ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards."),
the probability of returning a false positive is bounded by
$`\alpha+\epsilon_{t}`$ under the same fixed-iteration setting.

## 5 Experiments

### 5.1 Experimental Setup

We evaluate CISE on three multi-constraint material-discovery tasks from
the LLEMA benchmark ([Abhyankar et al., 2026](#bib.bib6)): wide-bandgap
semiconductors (WBG), which require $`E_{g}\geq 2.5`$ eV and
$`E_{\mathrm{form}}\leq-1.0`$ eV/atom; solid-state electrolytes (SSE),
which require $`E_{\mathrm{form}}\leq-1.0`$ eV/atom,
$`E_{g}\geq 2.0`$ eV, and at least one mobile species from
$`\{\mathrm{Li},\mathrm{Na},\mathrm{K},\mathrm{Mg},\mathrm{Ca},\mathrm{Al}\}`$;
and photovoltaic absorbers (PV), which require
$`0.7\leq E_{g}\leq 2.0`$ eV, $`E_{\mathrm{form}}\leq 0.0`$ eV/atom, and
compositions restricted to earth-abundant, non-toxic elements. A
candidate is counted as a task hit only when all corresponding
constraints are satisfied. We provide detailed descriptions of each task
in
Appendix [A.2](#A1.SS2 "A.2 Detailed task descriptions ‣ Appendix A Detailed experimental settings ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").
We set $`\alpha=0.1/\#\text{constraint}`$ for each property. For
example, we set $`\alpha=0.05`$ for both $`E_{g}`$ and
$`E_{\mathrm{form}}`$ in the WBG task.

We compare CISE against MatterGen ([Zeni et al., 2025](#bib.bib8)),
LLMatDesign ([Jia et al., 2024](#bib.bib5)), and LLEMA ([Abhyankar et
al., 2026](#bib.bib6)). CISE modifies only the archive-admission and
output-selection steps of LLEMA; its generator and evolutionary
operators remain unchanged. For proxy evaluation, we use MGT in place of
CGCNN for band-gap prediction, while otherwise following the LLEMA
experimental protocol, including the task definitions, hierarchical
proxy-property pipeline, proxy-reward construction, candidate budgets,
and method-specific generation settings. For tasks involving multiple
predicted properties, we apply CISE separately to each property and
return only candidates that satisfy all property-specific CISE criteria.
During search, surrogate predictions provide the proxy properties used
to score and qualify candidates. We then re-evaluate the candidates
returned by each method using DFT implemented in Quantum
ESPRESSO ([Giannozzi et al., 2009](#bib.bib9)). A proxy hit is a
candidate satisfying the task constraints under surrogate predictions,
whereas a DFT hit satisfies the same physical-property constraints under
Quantum ESPRESSO calculations, together with any deterministic
compositional restrictions. A proxy hit that fails this final evaluation
is recorded as a false positive. We use gpt-5-mini ([OpenAI,
2026](#bib.bib11)) as a solver LLM to generate candidates. More detailed
experimental settings are provided in
Appendix [A](#A1 "Appendix A Detailed experimental settings ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").

### 5.2 Empirical results

Main results.
Table [1](#S5.T1 "Table 1 ‣ 5.1 Experimental Setup ‣ 5 Experiments ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
shows a trade-off between the number of returned structures and their
DFT results. This contrast is particularly clear between LLEMA and CISE
on WBG and SSE. LLEMA returns 102 and 104 candidates, respectively, but
7.84% and 31.73% fail DFT validation. In contrast, CISE returns 41 WBG
candidates and 51 SSE candidates, with no observed false positives among
candidates with resolved DFT evaluations: all 41 WBG candidates and 51
SSE candidates are confirmed true positives. A smaller but more reliable
shortlist can be valuable when downstream experimental validation is the
bottleneck. The objective is not simply to maximize the number of
structures satisfying proxy constraints, but to prioritize candidates
worth further investigation. Under a limited validation budget, higher
output precision can reduce the fraction of resources allocated to
candidates that do not satisfy the intended properties. We therefore
view the WBG and SSE results as a reliability-yield trade-off. This
trade-off is consistent with CISE’s joint interval-based selection rule.
Whereas proxy-based selection checks whether each point prediction
satisfies its constraint, CISE requires the entire prediction interval
of every required property to lie within the corresponding feasible
region. A candidate can therefore satisfy all point constraints yet be
excluded because at least one interval extends beyond an admissible
boundary.

Calibrated interval rewards facilitate reliable LLM evolution.
Figure [2](#S5.F2 "Figure 2 ‣ 5.1 Experimental Setup ‣ 5 Experiments ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
shows a clear difference in the search trajectories of LLEMA and CISE on
the SSE task. Although LLEMA continues to assign favorable proxy
rewards, its DFT-evaluated candidates increasingly populate the failure
region in later iterations. This is particularly visible in the
upper-right of
Figure [2](#S5.F2 "Figure 2 ‣ 5.1 Experimental Setup ‣ 5 Experiments ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")(b),
where many late-iteration LLEMA candidates lie above the
$`E_{\mathrm{form}}=-1.0`$ threshold, including selected false
positives. In contrast, CISE shows no comparable accumulation, and its
output mean remains within the feasible region throughout evolution.
This pattern suggests that calibrated interval rewards help prevent
overly optimistic proxy evaluations from being repeatedly reinforced
during LLM evolution.

Comparison of fixed-budget shortlists of LLEMA and CISE. To examine
whether the higher reliability of CISE is simply a consequence of
returning fewer candidates, we perform an equal-budget comparison on the
PV task. CISE returns six candidates in this experiment, so we restrict
LLEMA to the same downstream validation budget of six structures. Among
the proxy-qualified LLEMA outputs, we select the six candidates whose
proxy-predicted band gaps are closest to $`1.2`$ eV, representing a
natural point-estimate-based prioritization strategy for PV screening.
Importantly, this selection is performed before DFT evaluation, so the
true-positive and false-positive labels are unavailable when the
candidates are ranked. As shown in
Table [2](#S5.T2 "Table 2 ‣ 5.2 Empirical results ‣ 5 Experiments ‣ Reliable Self-Evolution with Imperfect Proxy Rewards."),
only three of the six selected LLEMA candidates satisfy the PV band-gap
constraint after DFT evaluation, while the remaining three are false
positives. In contrast, all six candidates returned by CISE are
confirmed as true positives. This result indicates that the reliability
gain of CISE cannot be explained solely by its smaller output set: even
under the same validation budget and a stricter post-hoc truncation of
the LLEMA output, point-estimate-based prioritization can still select
candidates whose apparent quality is caused by proxy error, whereas
interval-based selection excludes such uncertain candidates before
expensive validation.

## 6 Conclusion

In this work, we study reliable self-evolution when accurate true
rewards are too expensive to obtain throughout iterative search. We
propose CISE, which replaces point-valued proxy rewards with calibrated
reward intervals constructed using conditional conformal inference and
iteration-wise online density-ratio estimation. These intervals are used
for both evolutionary feedback and final candidate selection, allowing
proxy-reward uncertainty to directly influence the search process. Under
explicit independence and covariate-shift assumptions, we provide
fixed-iteration coverage guarantees and characterize the effect of
density-ratio estimation error. Across three material-discovery tasks,
CISE consistently returns a smaller but more reliable set of candidates,
with no observed false positives among its DFT-validated outputs and
improved reliability under a matched validation budget. Our results
suggest that calibrated interval rewards provide a practical route
toward more reliable self-evolving agents when true rewards are costly
to obtain.

## Appendix A Detailed experimental settings

### A.1 Implementations

Calibration set. We construct the calibration set
$`\mathcal{D}_{\mathrm{cal}}`$ using 10,000 material structures from
JARVIS-QE-TB (QETB) ([Choudhary, 2025](#bib.bib12)). The calibration
samples are separated from the model-fitting data at the
composition-group level to avoid overlap between the two sets.

Model-fitting set. We use $`\mathcal{D}_{\mathrm{fit}}`$ consisting of
423,205 structures from QETB to train the conditional quantile
regression model. The proxy models remain fixed throughout the evolution
process.

Probe generation. At each generation context, we generate eight valid
probe structures using the same parent structures and prompt context as
the main candidate generation. These probes are used to characterize the
current candidate distribution for online density-ratio estimation.

Conditional quantile regression. We implement the conditional quantile
regression model using a gradient-boosted regression model
(HistGradientBoostingRegressor) with quantile loss. The model is trained
to predict the conditional $`0.95`$ quantile of absolute proxy error.
Its input consists of 27 structural features together with the
corresponding proxy prediction.

CCI features. For conditional conformal inference, the structural
features are used to capture heterogeneous proxy uncertainty across
materials. The online density ratio estimated from the probe structures
and a fixed source set is additionally incorporated into the
finite-dimensional Gibbs calibration basis, allowing the calibration
procedure to adapt to the candidate distribution at the current
generation step.

DFT evaluation. Selected material structures are evaluated using Quantum
ESPRESSO under a PBEsol fixed-structure protocol consistent with the
QETB calculations. We use the Modified GBRV PBEsol pseudopotentials and
evaluate the target material properties independently from the proxy
models.

### A.2 Detailed task descriptions

- •
  Wide-bandgap semiconductors (WBG): the target constraints are
  $`E_{g}\geq 2.5`$ eV and $`E_{\mathrm{form}}\leq-1.0`$ eV/atom. Here,
  $`\hat{r}(X)=(\widehat{E}_{g},\widehat{E}_{\mathrm{form}})`$ and
  $`r(X)=(E_{g},E_{\mathrm{form}})`$, where the latter quantities are
  obtained by DFT. Since a larger predicted $`E_{g}`$ and a smaller
  predicted $`E_{\mathrm{form}}`$ can make a candidate appear more
  favorable,

  |  |  |  |
  |----|----|----|
  |  |
  ``` math
  Y(X)=\mathbb{I}\left\{\widehat{E}_{g}-E_{g}\leq\delta_{E_{g}},\;E_{\mathrm{form}}-\widehat{E}_{\mathrm{form}}\leq\delta_{E_{\mathrm{form}}}\right\}.
  ``` |  |
- •
  Solid-state electrolytes (SSE): the constraints are
  $`E_{\mathrm{form}}\leq-1.0`$ eV/atom, $`E_{g}\geq 2.0`$ eV, and the
  presence of at least one mobile species from
  $`\{\mathrm{Li},\mathrm{Na},\mathrm{K},\mathrm{Mg},\mathrm{Ca},\mathrm{Al}\}`$.
  We use $`\hat{r}(X)=(\widehat{E}_{g},\widehat{E}_{\mathrm{form}})`$
  and $`r(X)=(E_{g},E_{\mathrm{form}})`$, with

  |  |  |  |
  |----|----|----|
  |  |
  ``` math
  Y(X)=\mathbb{I}\left\{\widehat{E}_{g}-E_{g}\leq\delta_{E_{g}},\;E_{\mathrm{form}}-\widehat{E}_{\mathrm{form}}\leq\delta_{E_{\mathrm{form}}}\right\}.
  ``` |  |

  The mobile-species requirement is determined directly from the
  composition and therefore does not require proxy calibration.
- •
  Photovoltaic absorbers (PV): the constraints are
  $`0.7\leq E_{g}\leq 2.0`$ eV, $`E_{\mathrm{form}}\leq 0.0`$ eV/atom,
  and compositions restricted to earth-abundant, non-toxic elements. We
  again use $`\hat{r}(X)=(\widehat{E}_{g},\widehat{E}_{\mathrm{form}})`$
  and $`r(X)=(E_{g},E_{\mathrm{form}})`$. Because $`E_{g}`$ is
  constrained on both sides, its proxy error is controlled in both
  directions:

  |  |  |  |
  |----|----|----|
  |  |
  ``` math
  Y(X)=\mathbb{I}\left\{|\widehat{E}_{g}-E_{g}|\leq\delta_{E_{g}},\;E_{\mathrm{form}}-\widehat{E}_{\mathrm{form}}\leq\delta_{E_{\mathrm{form}}}\right\}.
  ``` |  |

  The elemental restriction is evaluated directly from the composition.

## Appendix B Additional Empirical Results

Interval rewards mitigate false-positive propagation.
Figure [3](#A1.F3 "Figure 3 ‣ A.2 Detailed task descriptions ‣ Appendix A Detailed experimental settings ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
qualitatively illustrates how proxy errors can propagate through
self-evolving search and how CISE changes this feedback process. In the
LLEMA trajectory in
Figure [3](#A1.F3 "Figure 3 ‣ A.2 Detailed task descriptions ‣ Appendix A Detailed experimental settings ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")(a),
the agent repeatedly reuses proxy-qualified candidates along the
parent-child lineage
$`\mathrm{Na_{2}O}\rightarrow\mathrm{Li_{2}O}\rightarrow\mathrm{Na_{2}O}`$.
Although all three candidates satisfy the photovoltaic band-gap
constraint according to their proxy predictions, DFT evaluation shows
that each is a false positive. Importantly, the recorded LLM rationales
explicitly refer to previous surrogate evaluations when proposing
subsequent candidates, showing that an erroneous proxy reward can become
reusable feedback rather than remaining an isolated output error. In
contrast, the corresponding CISE intervals extend beyond the feasible
band-gap range, preventing these candidates from being treated as
reliable successes under the interval-based criterion.
Figure [3](#A1.F3 "Figure 3 ‣ A.2 Detailed task descriptions ‣ Appendix A Detailed experimental settings ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")(b)
shows the complementary case: the full CISE interval for
$`\mathrm{RbLiO}`$ lies within the target range, and the candidate is
subsequently confirmed as a true positive by DFT. Together, these
examples illustrate how interval rewards can suppress the propagation of
uncertain proxy successes while retaining candidates whose
uncertainty-aware rewards remain feasible.

## Appendix C Proofs

Throughout this section, we fix an iteration $`t`$ and write
$`N=n_{\mathrm{cal}}+1`$. All scores, basis functions, and solution
rules are taken to be measurable. Symmetry of the dual-solution rule
means that permuting the augmented observations permutes the selected
dual coordinates in the same way. We interpret the supremum in
Equation [3](#S4.E3 "In 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
in the extended real line, with $`\sup\emptyset=-\infty`$.

### C.1 Proof of Theorem [1](#Thmtheorem1 "Theorem 1 (Iteration-wise marginal coverage under exchangeability). ‣ 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")

###### Proof.

Condition on the independently fixed score $`S`$ and calibration space
$`\mathcal{G}`$. Set $`X_{N}=X^{\prime}`$ and write
$`S_{i}=S(X_{i},r(X_{i}))`$ for $`i=1,\ldots,N`$. At the true test score
$`S_{N}`$, the augmented calibration problem
in equation [2](#S4.E2 "In 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
becomes

|     |                                                                    |     |
|-----|--------------------------------------------------------------------|-----|
|     |
       ``` math
       \min_{q\in\mathcal{G}}\sum_{i=1}^{N}\ell_{\alpha}(q(X_{i}),S_{i}).
       ```                                                                 |     |

The pinball loss admits the representation

|     |                                                                  |     |
|-----|------------------------------------------------------------------|-----|
|     |
       ``` math
       \ell_{\alpha}(a,b)=\max_{-\alpha\leq\eta\leq 1-\alpha}\eta(b-a).
       ```                                                               |     |

Since $`\mathcal{G}`$ is a finite-dimensional linear space, the
augmented problem is a finite-dimensional linear program. It is feasible
and has a finite optimal value: its objective is nonnegative, and the
choice $`q=0`$ gives a finite value. Linear-programming duality
therefore yields the dual problem

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\max_{\eta\in\mathbb{R}^{N}}`$ | $`\displaystyle\sum_{i=1}^{N}\eta_{i}S_{i}`$ |  | (7) |
|  | $`\displaystyle\text{subject to}`$ | $`\displaystyle-\alpha\leq\eta_{i}\leq 1-\alpha,\qquad i=1,\ldots,N,`$ |  |  |
|  |  | $`\displaystyle\sum_{i=1}^{N}\eta_{i}g(X_{i})=0,\qquad\text{for every }g\in\mathcal{G}.`$ |  |  |

The last constraint follows because the coefficients of
$`q\in\mathcal{G}`$ are unrestricted. The dual feasible set is nonempty
and compact, so an optimal dual solution exists.

Let $`\eta=(\eta_{1},\ldots,\eta_{N})`$ be the optimal dual solution
selected by the symmetric rule. Since the constant function belongs to
$`\mathcal{G}`$,
equation [7](#A3.E7 "In Proof. ‣ C.1 Proof of Theorem ‣ Appendix C Proofs ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
implies

|     |                           |     |
|-----|---------------------------|-----|
|     |
       ``` math
       \sum_{i=1}^{N}\eta_{i}=0.
       ```                        |     |

The box constraints also give, for every $`i`$,

|     |                                                     |     |
|-----|-----------------------------------------------------|-----|
|     |
       ``` math
       \mathbf{1}\{\eta_{i}=1-\alpha\}\leq\eta_{i}+\alpha.
       ```                                                  |     |

Consequently,

|  |  |  |
|----|----|----|
|  |
``` math
\sum_{i=1}^{N}\mathbf{1}\{\eta_{i}=1-\alpha\}\leq\sum_{i=1}^{N}(\eta_{i}+\alpha)=N\alpha.
``` |  |

Under the assumptions of the theorem, the $`N`$ augmented pairs are
independent draws from $`\mathbf{P}_{0}`$. The fixed score and symmetric
dual-solution rule therefore make the selected dual coordinates
exchangeable. It follows that

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbb{P}(\eta_{N}=1-\alpha)`$ | $`\displaystyle=\frac{1}{N}\mathbb{E}\left[\sum_{i=1}^{N}\mathbf{1}\{\eta_{i}=1-\alpha\}\right]`$ |  |
|  |  | $`\displaystyle\leq\alpha.`$ |  |

At the true test score, $`\eta_{N}=\eta_{S_{N}}(X_{N})`$. If
$`\eta_{N}<1-\alpha`$, then $`S_{N}`$ belongs to the set whose supremum
defines $`\widehat{\tau}_{t}(X_{N})`$. Thus,
$`S_{N}\leq\widehat{\tau}_{t}(X_{N})`$, which implies
$`r(X_{N})\in\mathcal{I}_{t}(X_{N})`$
by equation [3](#S4.E3 "In 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").
We therefore have the pointwise inequalities

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbf{1}\{r(X_{N})\notin\mathcal{I}_{t}(X_{N})\}\leq\mathbf{1}\{\eta_{N}=1-\alpha\}\leq\eta_{N}+\alpha.
``` |  | (8) |

Combining the first inequality with the boundary-probability bound gives

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\bigl(r(X^{\prime})\notin\mathcal{I}_{t}(X^{\prime})\bigr)\leq\alpha.
``` |  |

Averaging over any independently fitted quantities conditioned on above
proves the stated guarantee.

Only an inclusion between the miscoverage event and the dual boundary
event is needed. In particular, the argument remains valid when the true
score equals the cutoff or when optimal solutions are not unique,
provided that the selected dual solution follows the stated symmetric
rule. ∎

We also verify the monotonicity of $`\eta_{s}(X^{\prime})`$ used in
Section [4.2](#S4.SS2 "4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").
Fix the calibration observations, the fresh candidate $`X^{\prime}`$,
and the calibration space. For $`s_{1}<s_{2}`$, let $`\eta^{(1)}`$ and
$`\eta^{(2)}`$ be optimal dual solutions with imputed test scores
$`s_{1}`$ and $`s_{2}`$, respectively. The dual feasible set
in equation [7](#A3.E7 "In Proof. ‣ C.1 Proof of Theorem ‣ Appendix C Proofs ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
does not depend on the imputed score. Optimality therefore gives

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\sum_{i=1}^{N-1}S_{i}\eta_{i}^{(1)}+s_{1}\eta_{N}^{(1)}`$ | $`\displaystyle\geq\sum_{i=1}^{N-1}S_{i}\eta_{i}^{(2)}+s_{1}\eta_{N}^{(2)},`$ |  |
|  | $`\displaystyle\sum_{i=1}^{N-1}S_{i}\eta_{i}^{(2)}+s_{2}\eta_{N}^{(2)}`$ | $`\displaystyle\geq\sum_{i=1}^{N-1}S_{i}\eta_{i}^{(1)}+s_{2}\eta_{N}^{(1)}.`$ |  |

Adding these inequalities yields

|     |                                                               |     |
|-----|---------------------------------------------------------------|-----|
|     |
       ``` math
       (s_{2}-s_{1})\bigl(\eta_{N}^{(2)}-\eta_{N}^{(1)}\bigr)\geq 0.
       ```                                                            |     |

Hence $`\eta_{s_{2}}(X^{\prime})\geq\eta_{s_{1}}(X^{\prime})`$. This
argument applies to any choices of optimal dual solutions and remains
valid when $`\mathcal{G}`$ is replaced by a fixed $`\mathcal{G}_{t}`$.

### C.2 Proof of Theorem [2](#Thmtheorem2 "Theorem 2 (Iteration-wise marginal coverage under evolutionary covariate shift). ‣ 4.3 Conformal Interval-driven Self-Evolution under Evolutionary Covariate Shift ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")

###### Proof.

Condition on the current generation state,
$`\mathcal{D}_{\mathrm{fit}}`$, $`\mathcal{D}_{\mathrm{src}}`$, and
$`\mathcal{B}_{t}`$, as specified in the theorem. All probabilities and
expectations below are conditional on these quantities unless stated
otherwise. In particular, the score $`S`$, estimated ratio
$`\widehat{w}_{t}`$, and calibration space $`\mathcal{G}_{t}`$ are
fixed. By assumption, the calibration pairs retain their independent
$`\mathbf{P}_{0}`$ laws under this conditioning.

Define

|  |  |  |
|----|----|----|
|  |
``` math
\mu_{t}=\mathbb{E}_{\mathbf{P}_{0}^{X}}[\widehat{w}_{t}(X)],\qquad\widetilde{w}_{t}(x)=\frac{\widehat{w}_{t}(x)}{\mu_{t}}.
``` |  |

The bounded ratio model and the positive-source-expectation assumption
give $`0<\mu_{t}<\infty`$. Therefore, $`\widetilde{w}_{t}`$ is
nonnegative and satisfies

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{E}_{\mathbf{P}_{0}^{X}}[\widetilde{w}_{t}(X)]=1,\qquad\widetilde{w}_{t}\in\mathcal{G}_{t}.
``` |  |

The latter inclusion follows from $`\widehat{w}_{t}\in\mathcal{G}_{t}`$
and linearity of $`\mathcal{G}_{t}`$.

Let $`\widetilde{\mathbf{P}}_{t}`$ be the joint distribution defined by

|  |  |  |
|----|----|----|
|  |
``` math
\frac{d\widetilde{\mathbf{P}}_{t}}{d\mathbf{P}_{0}}(x,u)=\widetilde{w}_{t}(x).
``` |  |

This is a probability distribution because $`\widetilde{w}_{t}`$ is
nonnegative and has source expectation one. It changes only the
candidate marginal while preserving the conditional reward law of
$`\mathbf{P}_{0}`$.

First consider an auxiliary experiment in which all $`N`$ augmented
pairs are independent draws from $`\mathbf{P}_{0}`$. Let
$`\mathbb{E}_{0}`$ denote expectation in this experiment, with the
conditioned quantities above still held fixed. For each realization of
the augmented sample, solve the same calibration problem over
$`\mathcal{G}_{t}`$ at the true test score. Let $`\eta`$ denote the
selected optimal dual solution.

The dual formulation
in equation [7](#A3.E7 "In Proof. ‣ C.1 Proof of Theorem ‣ Appendix C Proofs ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
applies with $`\mathcal{G}_{t}`$ in place of $`\mathcal{G}`$. Since
$`\widetilde{w}_{t}\in\mathcal{G}_{t}`$, dual feasibility gives

|     |                                                   |     |
|-----|---------------------------------------------------|-----|
|     |
       ``` math
       \sum_{i=1}^{N}\widetilde{w}_{t}(X_{i})\eta_{i}=0.
       ```                                                |     |

Under the auxiliary source experiment, the augmented pairs are
exchangeable. Since $`\widetilde{w}_{t}`$ is fixed and the dual-solution
rule is symmetric, the pairs $`(\widetilde{w}_{t}(X_{i}),\eta_{i})`$ are
also exchangeable. Consequently,

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\mathbb{E}_{0}[\widetilde{w}_{t}(X_{N})\eta_{N}]`$ | $`\displaystyle=\frac{1}{N}\mathbb{E}_{0}\left[\sum_{i=1}^{N}\widetilde{w}_{t}(X_{i})\eta_{i}\right]`$ |  |
|  |  | $`\displaystyle=0.`$ |  |

These expectations are well-defined because the dual variables are
bounded and $`\mathbb{E}_{0}[\widetilde{w}_{t}(X_{N})]=1`$.

The pointwise bound
in equation [8](#A3.E8 "In Proof. ‣ C.1 Proof of Theorem ‣ Appendix C Proofs ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
also applies to the calibration problem over $`\mathcal{G}_{t}`$.
Multiplying it by $`\widetilde{w}_{t}(X_{N})\geq 0`$ and taking
expectations gives

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\mathbb{E}_{0}\left[\widetilde{w}_{t}(X_{N})\mathbf{1}\{r(X_{N})\notin\mathcal{I}_{t}(X_{N})\}\right]`$ |  | (9) |
|  |  | $`\displaystyle\leq\mathbb{E}_{0}\left[\widetilde{w}_{t}(X_{N})(\eta_{N}+\alpha)\right]=\alpha.`$ |  |  |

Changing measure for the last observation only, the left-hand side
of equation [9](#A3.E9 "In Proof. ‣ C.2 Proof of Theorem ‣ Appendix C Proofs ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
is exactly the miscoverage probability when the calibration pairs are
independent draws from $`\mathbf{P}_{0}`$ and the independent fresh pair
has law $`\widetilde{\mathbf{P}}_{t}`$. Thus, the prediction interval
has miscoverage at most $`\alpha`$ under this auxiliary target law. The
fitted score, estimated ratio, calibration space, and
interval-construction rule remain unchanged in this comparison.

It remains to replace $`\widetilde{\mathbf{P}}_{t}`$ by the actual
target distribution $`\mathbf{P}_{t}`$. The covariate-shift assumption
in equation [4](#S4.E4 "In 4.3 Conformal Interval-driven Self-Evolution under Evolutionary Covariate Shift ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
implies

|     |                                                        |     |
|-----|--------------------------------------------------------|-----|
|     |
       ``` math
       \frac{d\mathbf{P}_{t}}{d\mathbf{P}_{0}}(x,u)=w_{t}(x).
       ```                                                     |     |

Since both target laws preserve the conditional reward law of
$`\mathbf{P}_{0}`$, their total variation distance is

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle d_{\mathrm{TV}}\bigl(\mathbf{P}_{t},\widetilde{\mathbf{P}}_{t}\bigr)`$ | $`\displaystyle=\frac{1}{2}\mathbb{E}_{\mathbf{P}_{0}^{X}}\left[|w_{t}(X)-\widetilde{w}_{t}(X)|\right]`$ |  |
|  |  | $`\displaystyle=\epsilon_{t},`$ |  |

where the last equality follows
from equation [6](#S4.E6 "In 4.3 Conformal Interval-driven Self-Evolution under Evolutionary Covariate Shift ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").

The calibration sample has the same independent law under both target
distributions. Therefore,

|  |  |  |  |
|----|----|----|----|
|  |  | $`\displaystyle d_{\mathrm{TV}}\left(\mathbf{P}_{0}^{\otimes n_{\mathrm{cal}}}\otimes\mathbf{P}_{t},\,\mathbf{P}_{0}^{\otimes n_{\mathrm{cal}}}\otimes\widetilde{\mathbf{P}}_{t}\right)`$ |  |
|  |  | $`\displaystyle=d_{\mathrm{TV}}\bigl(\mathbf{P}_{t},\widetilde{\mathbf{P}}_{t}\bigr)=\epsilon_{t}.`$ |  |

Applying the defining total-variation bound to the miscoverage event
shows that replacing the auxiliary target law by $`\mathbf{P}_{t}`$
increases its probability by at most $`\epsilon_{t}`$. Combining this
with equation [9](#A3.E9 "In Proof. ‣ C.2 Proof of Theorem ‣ Appendix C Proofs ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.")
yields

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\bigl(r(X^{\prime})\notin\mathcal{I}_{t}(X^{\prime})\bigr)\leq\alpha+\epsilon_{t},
``` |  |

or equivalently,

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\bigl(r(X^{\prime})\in\mathcal{I}_{t}(X^{\prime})\bigr)\geq 1-\alpha-\epsilon_{t}.
``` |  |

This is the conditional guarantee stated in the theorem.

When the stated conditional assumptions hold almost surely, averaging
over all quantities conditioned on above gives the unconditional bound

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}\bigl(r(X^{\prime})\in\mathcal{I}_{t}(X^{\prime})\bigr)\geq 1-\alpha-\mathbb{E}[\epsilon_{t}].
``` |  |

Finally, if $`w_{t}\in\mathcal{G}_{t}`$, the weighted argument can be
applied directly with $`w_{t}`$ in place of $`\widetilde{w}_{t}`$.
Indeed, $`w_{t}`$ is nonnegative and
$`\mathbb{E}_{\mathbf{P}_{0}^{X}}[w_{t}(X)]=1`$, while dual feasibility
gives $`\sum_{i=1}^{N}w_{t}(X_{i})\eta_{i}=0`$. Changing measure then
leads directly to the actual target law $`\mathbf{P}_{t}`$, so no
total-variation comparison is needed. The resulting coverage is at least
$`1-\alpha`$. In particular, this applies when
$`\widehat{w}_{t}=w_{t}`$, in which case $`\epsilon_{t}=0`$. ∎

For completeness, the false-positive implication follows directly from
the output rule. Let $`A_{t}`$ be the acceptance event defined in
Section [4.1](#S4.SS1 "4.1 Problem Setup ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards.").
On $`A_{t}`$, every reward value in $`\mathcal{I}_{t}(X^{\prime})`$
satisfies the task-specific constraints. If $`r(X^{\prime})`$ also
belongs to this interval, then $`X^{\prime}\in\mathcal{F}_{r}`$. Hence

|  |  |  |
|----|----|----|
|  |
``` math
A_{t}\cap\{X^{\prime}\notin\mathcal{F}_{r}\}\subseteq\{r(X^{\prime})\notin\mathcal{I}_{t}(X^{\prime})\}.
``` |  |

Under the assumptions of
Theorem [1](#Thmtheorem1 "Theorem 1 (Iteration-wise marginal coverage under exchangeability). ‣ 4.2 Conformal Interval-driven Self-Evolution under Exchangeability ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards."),
this gives
$`\mathbb{P}(A_{t},\,X^{\prime}\notin\mathcal{F}_{r})\leq\alpha`$. Under
the conditioning and assumptions of
Theorem [2](#Thmtheorem2 "Theorem 2 (Iteration-wise marginal coverage under evolutionary covariate shift). ‣ 4.3 Conformal Interval-driven Self-Evolution under Evolutionary Covariate Shift ‣ 4 Methodology ‣ Reliable Self-Evolution with Imperfect Proxy Rewards."),
it gives

|  |  |  |
|----|----|----|
|  |
``` math
\mathbb{P}(A_{t},\,X^{\prime}\notin\mathcal{F}_{r})\leq\alpha+\epsilon_{t}.
``` |  |

These bounds concern the joint event that a fresh proposal is accepted
and is a false positive. They do not assert the same bounds conditional
on acceptance or simultaneously over the full search trajectory.
````
