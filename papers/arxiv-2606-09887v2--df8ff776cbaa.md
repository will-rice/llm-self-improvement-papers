###### Abstract

Reinforcement learning (RL) for large language models usually supervises
reasoning with scalar outcome rewards, such as binary correctness. Such
rewards provide an optimization direction but rarely explain how a model
should revise its mistaken reasoning, which can encourage shortcut
learning and brittle policies. We propose SocraticPO (Socratic Policy
Optimization), a policy-optimization framework that augments RL rollouts
with Socratic-style natural-language guidance. During rollout, the
student first answers independently; if the answer is incorrect, a
teacher diagnoses the attempt and provides concise corrective guidance,
after which the student continues under the expanded context. Crucially,
this guidance is paired with reward decay: correct answers obtained
after teacher intervention only receive decayed rewards, preventing the
policy from treating teacher help as a free path to reward. Since
SocraticPO only modifies the rollout process while leaving the standard
expected-reward objective intact, it can be plugged into existing
policy-gradient backends such as Reinforce++. Moreover, because the
teacher provides only text-level guidance, SocraticPO can leverage
stronger black-box teacher models without requiring access to logits or
distribution matching. On undergraduate-level scientific reasoning
benchmarks from SciKnowEval, SocraticPO improves over strong RL and
self-distillation baselines. Ablations show that both targeted guidance
and reward decay are necessary, with reward decay mitigating reliance on
assisted correction.

## 1 Introduction

Large language models (LLMs) have advanced rapidly with transformer
architectures, scaling, and instruction tuning \[[35](#bib.bib20),
[5](#bib.bib21), [31](#bib.bib22), [1](#bib.bib1), [3](#bib.bib2)\].
Their post-training increasingly relies on reinforcement learning (RL),
where a policy is optimized from task rewards or preference-derived
signals \[[8](#bib.bib23), [27](#bib.bib25), [22](#bib.bib11)\]. For
reasoning tasks, however, RL feedback is often reduced to a scalar
outcome signal, such as binary correctness. Such feedback tells the
model which trajectories should be reinforced, but not how a mistaken
reasoning process should be repaired \[[7](#bib.bib41)\].

This limitation is especially problematic in multi-step scientific
reasoning. A wrong final answer may arise from a localized conceptual
error, an incorrect comparison, or a misplaced intermediate value.
Outcome rewards provide gradient-level optimization pressure, but they
do not provide thought-level correction. As a result, the policy may
discover shortcuts that satisfy the verifier without learning robust
reasoning.

Human learning offers a different pattern of supervision. Teachers
rarely provide only a grade; they inspect the learner’s attempt,
identify the source of the mistake, and give hints, critiques, or
next-step suggestions \[[39](#bib.bib8), [34](#bib.bib10)\]. The
Socratic tradition frames this process as guided inquiry rather than
direct answer transfer \[[24](#bib.bib7), [20](#bib.bib9)\]. Inspired by
this view, we introduce Socratic Policy Optimization (SocraticPO), which
brings Socratic-style guidance into the rollout stage of RL. A student
first attempts the problem independently. If the attempt is incorrect, a
teacher provides natural-language guidance conditioned on the student’s
response, and the student continues under the expanded context.

Guidance must be introduced carefully. If a response corrected after
teacher intervention receives the same reward as one solved
independently, the policy may learn a training-time shortcut: wait for
help, use the teacher-provided clue, and still collect full reward.
Assisted correctness can then improve without a corresponding
improvement in unassisted reasoning. SocraticPO therefore pairs teacher
guidance with reward decay: correct answers obtained after teacher
intervention receive decayed rewards, and the reward decreases as more
guidance rounds are needed. This encourages the student not only to
reach the correct answer, but also to internalize the correction and
solve earlier with less assistance.

SocraticPO changes only the rollout process. The student still optimizes
a standard expected-reward objective, while teacher utterances are
appended as text context for subsequent student attempts rather than
optimized as imitation targets. As a result, SocraticPO can be
instantiated with existing policy-gradient backends such as Reinforce++
\[[15](#bib.bib19)\]. Since the teacher is required only to produce
text-level guidance, the framework can also leverage stronger black-box
teacher models without accessing logits, token-level likelihoods, or
matching teacher and student distributions, unlike probability-matching
approaches such as OPD \[[2](#bib.bib4), [11](#bib.bib36)\].

We evaluate SocraticPO on undergraduate-level scientific reasoning
benchmarks derived from SciKnowEval \[[10](#bib.bib18)\]. Compared with
strong RL baselines, including Reinforce++ \[[15](#bib.bib19)\] and GRPO
\[[25](#bib.bib13)\], as well as self-distillation-style training such
as SDPO \[[17](#bib.bib32)\], SocraticPO achieves the best average
performance. Ablations further show that both components are necessary:
targeted guidance provides useful correction beyond blind retrying,
while reward decay mitigates reliance on teacher-assisted correction.

Our main contributions are:

- •
  A general SocraticPO framework. We propose an interactive
  policy-optimization framework that augments RL with teacher-guided
  reasoning correction and remains compatible with existing
  policy-gradient backends.
- •
  Reward decay for SocraticPO. To make teacher-guided RL train the
  student rather than reward dependence on assistance, we introduce a
  reward decay mechanism for assisted correctness. We further
  characterize its normalized-advantage properties, showing
  non-negativity, monotonicity, and saturation decay.
- •
  Black-box teacher compatibility. Our method only requires teachers to
  provide text-level guidance instead of distribution matching, making
  it compatible with stronger API-based or otherwise black-box teachers.
- •
  Empirical evidence and analysis. We show gains on scientific reasoning
  benchmarks and provide ablations on teacher guidance, reward decay,
  teacher-side information, and teacher–student similarity.

## 2 Related Work

### 2.1 Reinforcement Learning for LLMs

Reinforcement learning has become a central paradigm for aligning LLMs
with human preferences and task rewards \[[8](#bib.bib23),
[43](#bib.bib24), [27](#bib.bib25), [22](#bib.bib11),
[19](#bib.bib40)\]. PPO \[[23](#bib.bib12)\] is widely used in RLHF
pipelines, and feedback can also be provided by AI systems rather than
direct human annotation \[[4](#bib.bib26)\]. More recent LLM training
methods adopt simpler or more scalable policy-gradient variants,
including REINFORCE-style updates \[[38](#bib.bib15), [28](#bib.bib16),
[15](#bib.bib19)\] and group-wise relative objectives such as GRPO
\[[25](#bib.bib13)\].

Most of these methods optimize scalar reward signals
\[[12](#bib.bib38)\]. In reasoning tasks, such rewards identify whether
a trajectory should be reinforced but do not explain which part of the
reasoning process should be corrected \[[29](#bib.bib39),
[6](#bib.bib42)\]. Process-supervision work shows that intermediate
feedback can be more informative than outcome supervision alone
\[[33](#bib.bib17)\], yet how to inject corrective information into
on-policy RL rollouts remains underexplored. SocraticPO addresses this
gap by adding natural-language correction to rollout sampling while
retaining a standard policy-gradient objective.

### 2.2 Human Guided Teaching

Educational research emphasizes that effective teaching is interactive
rather than purely evaluative. Tutors scaffold learning by inspecting a
student’s current attempt, diagnosing misconceptions, and providing
hints or next-step guidance \[[39](#bib.bib8), [34](#bib.bib10)\]. The
Socratic tradition similarly frames learning as guided inquiry:
questions and critiques help the learner revise an answer without simply
copying an expert solution \[[24](#bib.bib7)\]. Recent NLP work has
explored Socratic tutoring and personalized teaching dialogues with LLMs
\[[20](#bib.bib9)\].

SocraticPO adapts this teaching principle to RL training. The teacher
does not merely label an answer as wrong; it provides language-level
correction conditioned on the student’s failed attempt. At the same
time, SocraticPO differs from tutoring systems whose goal is to optimize
dialogue quality. Our goal is to improve the student policy through RL,
so teacher guidance is paired with a reward design that encourages the
student to solve earlier and rely less on future intervention.

### 2.3 Student–Teacher Paradigms in LLMs

Teacher–student learning is widely used in LLM post-training to transfer
capability from stronger models to smaller or weaker students. One
common paradigm is teacher-generated supervised fine-tuning (SFT), where
a stronger model produces instructions, answers, or reasoning traces
that are then treated as demonstration data for the student.
Self-Instruct, Alpaca, WizardLM, Orca, and step-by-step distillation all
follow this broad pattern \[[37](#bib.bib27), [30](#bib.bib28),
[40](#bib.bib29), [21](#bib.bib30), [14](#bib.bib31)\]. Recent work also
studies how to synthesize student-consistent SFT data from a teacher so
that the demonstrations better match the student’s learning state
\[[16](#bib.bib6)\].

Another paradigm is knowledge or policy distillation, where the student
is trained to approximate a teacher’s behavior more directly. Classical
distillation matches teacher distributions or soft targets
\[[13](#bib.bib14)\], while on-policy distillation adapts this idea to
LLMs by using model-generated or teacher-shaped trajectories during
training \[[2](#bib.bib4), [26](#bib.bib5), [11](#bib.bib36)\].
Self-distillation and hybrid distillation variants further use the
model’s own successful responses, privileged trajectories, or routed
samples as training targets \[[17](#bib.bib32), [18](#bib.bib33),
[9](#bib.bib34), [41](#bib.bib35), [32](#bib.bib43)\]. Despite
differences in data source and objective, these methods generally ask
the student to imitate, approximate, or absorb teacher-like behavior.

SocraticPO adopts a different teacher–student relation. The teacher is
not a demonstration generator whose answer should be copied, nor a
distributional target whose probabilities should be matched. Instead, it
acts as an interactive guide: after a failed student attempt, the
teacher diagnoses the mistake and provides concise corrective guidance,
while the student still produces its own subsequent response and is
optimized only through task reward. Because this guidance is text-level,
SocraticPO can also use black-box teachers as an additional benefit of
the design.

## 3 Preliminaries

We first introduce the standard policy-gradient formulation for
single-turn LLM training, then use it to clarify what SocraticPO
changes: the rollout distribution rather than the expected-reward
objective.

### 3.1 Language Model Policy

Given an input prompt $`x`$, an autoregressive language model with
parameters $`\theta`$ defines a policy $`\pi_{\theta}(y\mid x)`$ over
response sequences $`y=(y_{1},\dots,y_{T})`$. The response probability
factorizes token by token:

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\pi_{\theta}(y\mid x)=\prod_{t=1}^{T}\pi_{\theta}(y_{t}\mid x,y_{<t}).
``` |  | (1) |

In the standard single-turn setting, one sampled response is treated as
a trajectory $`\tau=y`$ and assigned a scalar reward $`R(\tau)`$, such
as a correctness score.

### 3.2 Expected-Reward Objective

Policy optimization maximizes the expected reward under the current
policy \[[38](#bib.bib15), [28](#bib.bib16)\]:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{J}(\theta)=\mathbb{E}_{\tau\sim\pi_{\theta}(\cdot\mid x)}[R(\tau)].
``` |  | (2) |

For a sequence-level reward, the corresponding policy-gradient estimator
can be written as:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\nabla_{\theta}\mathcal{J}(\theta)=\mathbb{E}_{\tau\sim\pi_{\theta}}\left[R(\tau)\sum_{t=1}^{T}\nabla_{\theta}\log\pi_{\theta}(y_{t}\mid x,y_{<t})\right].
``` |  | (3) |

Practical implementations often add baselines, reward normalization,
clipping, or group-wise comparison to reduce variance and stabilize
training \[[23](#bib.bib12), [25](#bib.bib13), [15](#bib.bib19)\].

### 3.3 Rollout Sampling

The rollout distribution determines which trajectories the policy learns
from. In conventional LLM RL, the rollout is sampled only from the
student policy:

|     |                                    |     |     |
|-----|------------------------------------|-----|-----|
|     |
       ``` math
       \tau\sim\pi_{\theta}(\cdot\mid x).
       ```                                 |     | (4) |

The reward is then computed after generation, and the same trajectory is
used for the policy update.

### 3.4 Verifier and Correctness Notation

For each prompt $`x`$, let $`\mathcal{G}`$ denote the information used
by the verifier, such as the ground-truth answer and optional reference
solution. The teacher may also receive side information $`\mathcal{I}`$,
which can be empty, restricted, or include reference material depending
on the teaching protocol. We define a correctness function

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\delta(y,\mathcal{G})=\mathbb{I}[\text{correct}(y,\mathcal{G})].
``` |  | (5) |

## 4 Method

Traditional scalar rewards only tell the model whether an answer is
correct or incorrect. They provide an optimization signal, but not a
diagnosis of the reasoning error that caused the failure. In human
learning, a teacher often plays this diagnostic role: by pointing out
where the student’s current attempt goes wrong, the teacher can help the
student revise more efficiently than a grade alone. SocraticPO turns
this idea into a policy-optimization mechanism. It modifies the rollout
stage by inserting conditional teacher feedback after failed student
attempts, so that the policy learns from trajectories that contain both
the original mistake and a correction-oriented context for the next
attempt.

### 4.1 Interactive Rollout

Using the notation from Section
[3](#S3 "3 Preliminaries ‣ SocraticPO: Policy Optimization via Interactive Guidance"),
the rollout is organized as a sequence of student attempts rather than a
single long generation. This step-wise structure gives the verifier a
chance to identify failure points and allows the teacher to respond to
the student’s actual mistake, instead of providing generic hints before
the model has committed to a line of reasoning. At each interaction step
$`k`$ with $`1\leq k\leq K`$, the dialogue context is denoted by
$`c^{(k)}`$, with $`c^{(1)}=x`$. The student then generates a complete
response:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
y^{(k)}=(y^{(k)}_{1},\dots,y^{(k)}_{T_{k}})\sim\pi_{\theta}(\cdot\mid c^{(k)}).
``` |  | (6) |

Equivalently, the response probability factorizes at the token level as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\pi_{\theta}(y^{(k)}\mid c^{(k)})=\prod_{t=1}^{T_{k}}\pi_{\theta}(y^{(k)}_{t}\mid c^{(k)},y^{(k)}_{<t}).
``` |  | (7) |

The response is then evaluated by

|     |                                           |     |     |
|-----|-------------------------------------------|-----|-----|
|     |
       ``` math
       \delta^{(k)}=\delta(y^{(k)},\mathcal{G}).
       ```                                        |     | (8) |

If $`\delta^{(k)}=1`$, the rollout terminates. If $`\delta^{(k)}=0`$ and
$`k<K`$, the teacher is queried with a teaching prompt that includes the
current dialogue context, the student’s latest response, and the
teacher-side information $`\mathcal{I}`$. The teacher then generates
concise natural-language feedback, such as an error diagnosis, a
correction hint, or a suggested next step. We provide the prompt
template in Appendix
[B.2](#A2.SS2 "B.2 Teacher Prompt Templates ‣ Appendix B Detailed Experimental Settings ‣ SocraticPO: Policy Optimization via Interactive Guidance").
Formally,

|     |                                                               |     |     |
|-----|---------------------------------------------------------------|-----|-----|
|     |
       ``` math
       f^{(k)}\sim\pi_{\phi}(\cdot\mid c^{(k)},y^{(k)},\mathcal{I}),
       ```                                                            |     | (9) |

and the next context is constructed as

|     |                                      |     |      |
|-----|--------------------------------------|-----|------|
|     |
       ``` math
       c^{(k+1)}=c^{(k)}||y^{(k)}||f^{(k)}.
       ```                                   |     | (10) |

Thus teacher feedback appears only after an incorrect student response.
A sampled interaction trajectory can be written as

|     |                                                              |     |      |
|-----|--------------------------------------------------------------|-----|------|
|     |
       ``` math
       \tau=\left(x,y^{(1)},f^{(1)},\dots,f^{(L-1)},y^{(L)}\right),
       ```                                                           |     | (11) |

where $`L\leq K`$ is the number of student attempts actually made, and
$`f^{(k)}`$ is present only when $`\delta^{(k)}=0`$ and $`k<L`$. This
defines an interaction-conditioned rollout distribution

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\tau\sim\pi_{\theta,\phi}^{\mathrm{int}}(\cdot\mid x,\mathcal{G},\mathcal{I},K).
``` |  | (12) |

Only the student factors in this distribution depend on $`\theta`$;
teacher outputs are sampled conditioning variables.

### 4.2 Policy Optimization

We keep the expected-reward objective but evaluate it under the
interaction-conditioned rollout distribution. This preserves
compatibility with standard policy-gradient training: SocraticPO changes
which trajectories are sampled, not the principle that the student is
reinforced by task reward.

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{J}(\theta)=\mathbb{E}_{\tau\sim\pi_{\theta,\phi}^{\mathrm{int}}}\left[R(\tau)\right].
``` |  | (13) |

In our step-wise rollout, each generated student response receives a
reward $`r^{(k)}`$, and the trajectory return is

|     |                                |     |      |
|-----|--------------------------------|-----|------|
|     |
       ``` math
       R(\tau)=\sum_{k=1}^{L}r^{(k)}.
       ```                             |     | (14) |

Using step-wise rewards is important for within-trajectory credit
assignment\[[36](#bib.bib37)\]. A final trajectory-level reward would
mark the whole interaction as successful once the last answer is
correct, but it would not identify which student attempt should receive
credit. Step-wise rewards instead attach the learning signal to the
specific response that becomes correct and leave earlier failed attempts
unrewarded. This separates independent success, recovery after one
targeted hint, and recovery after repeated intervention inside the same
trajectory. The policy-gradient update is applied only to student
tokens:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\nabla_{\theta}\mathcal{J}(\theta)\approx\sum_{k=1}^{L}r^{(k)}\sum_{t=1}^{T_{k}}\nabla_{\theta}\log\pi_{\theta}(y^{(k)}_{t}\mid c^{(k)},y^{(k)}_{<t}).
``` |  | (15) |

### 4.3 Reward Decay

Figure 2: Step-wise reward and reward decay in SocraticPO. Step-wise
rewards assign credit to the specific student attempt that becomes
correct within an interaction trajectory, while reward decay calibrates
credit across the batch by assigning smaller rewards to answers that
require more rounds of teacher guidance.

Step-wise rewards alone, however, do not solve credit assignment across
samples in the same batch. If every correct response receives the same
reward, then a problem solved independently at step $`1`$ and another
problem solved only after several rounds of guidance would contribute
the same positive reward, even though they reflect different degrees of
student competence. This creates an assisted reward-hacking failure
mode: the student can benefit from teacher intervention during training
without learning to solve earlier or independently. We discuss this
situation in Section
[5.3](#S5.SS3 "5.3 Ablation Study ‣ 5 Experiments ‣ SocraticPO: Policy Optimization via Interactive Guidance").
Therefore, after locating credit within each trajectory, SocraticPO
further calibrates credit across the batch by decaying rewards for
later-step correctness.

Consider a training batch. Let $`\mathcal{A}_{k}`$ be the set of samples
that are active at step $`k`$, meaning they have not been solved before
step $`k`$. For sample $`i\in\mathcal{A}_{k}`$, let

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\delta_{i}^{(k)}=\mathbb{I}[\text{correct}(y_{i}^{(k)},\mathcal{G}_{i})].
``` |  | (16) |

The first-step reward is

|     |                               |     |      |
|-----|-------------------------------|-----|------|
|     |
       ``` math
       r_{i}^{(1)}=\delta_{i}^{(1)}.
       ```                            |     | (17) |

For $`k\geq 2`$, we compute the historical average reward over previous
active attempts:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mu_{k-1}=\frac{\sum_{j=1}^{k-1}\sum_{i\in\mathcal{A}_{j}}r_{i}^{(j)}}{\sum_{j=1}^{k-1}|\mathcal{A}_{j}|},
``` |  | (18) |

and define

|  |  |  |  |
|----|----|----|----|
|  |
``` math
r_{i}^{(k)}=\mu_{k-1}\cdot\delta_{i}^{(k)},\qquad i\in\mathcal{A}_{k}.
``` |  | (19) |

Incorrect responses always receive zero reward. Correct responses at
later steps receive a reward scaled by the average success value of
earlier attempts, which makes delayed correction less valuable than
immediate success. This reward rule gives the following properties and
the proof is provided in Appendix
[A](#A1 "Appendix A Proof of Theorem 1 ‣ SocraticPO: Policy Optimization via Interactive Guidance"):

prompt dataset $`\mathcal{D}`$; verifier information $`\mathcal{G}`$;
teacher-side information $`\mathcal{I}`$; maximum interaction steps
$`K`$; batch size $`B`$.

Output: Optimized student policy $`\pi_{\theta}`$.

repeat Sample a batch
$`\{(x_{i},\mathcal{G}_{i},\mathcal{I}_{i})\}_{i=1}^{B}\sim\mathcal{D}`$;

Initialize $`c_{i}^{(1)}\leftarrow x_{i}`$, active set
$`\mathcal{A}_{1}\leftarrow\{1,\dots,B\}`$, and trajectory buffer
$`\mathcal{T}\leftarrow\emptyset`$;

for *$`k=1`$ to $`K`$* do

foreach *$`i\in\mathcal{A}_{k}`$* do

    Generate
$`y_{i}^{(k)}\sim\pi_{\theta}(\cdot\mid c_{i}^{(k)})`$; Compute
$`\delta_{i}^{(k)}\leftarrow\mathbb{I}[\text{correct}(y_{i}^{(k)},\mathcal{G}_{i})]`$; Store
$`(c_{i}^{(k)},y_{i}^{(k)},\delta_{i}^{(k)})`$ in $`\mathcal{T}`$;

       if *$`\delta_{i}^{(k)}=0`$ and $`k<K`$* then

       Generate
$`f_{i}^{(k)}\sim\pi_{\phi}(\cdot\mid c_{i}^{(k)},y_{i}^{(k)},\mathcal{I}_{i})`$; Set
$`c_{i}^{(k+1)}\leftarrow c_{i}^{(k)}||y_{i}^{(k)}||f_{i}^{(k)}`$;

          Compute rewards $`\{r_{i}^{(k)}:i\in\mathcal{A}_{k}\}`$ using
the step-wise rule;

    Set
$`\mathcal{A}_{k+1}\leftarrow\{i\in\mathcal{A}_{k}:\delta_{i}^{(k)}=0\}`$;

    if *$`\mathcal{A}_{k+1}=\emptyset`$* then

    break;

       Update $`\pi_{\theta}`$ with Reinforce++ using student responses
in $`\mathcal{T}`$ and their rewards;

until convergence

###### Theorem 1 (Assistance-Aware Advantage under Reward Decay).

Define the normalized advantage

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\hat{a}_{i}^{(k)}=\frac{r_{i}^{(k)}-\mu_{t}}{\sigma_{t}+\epsilon},
``` |  | (20) |

where $`\mu_{t},\sigma_{t}`$ are the mean and standard deviation after
step $`t`$ with $`1\leq t\leq k\leq K`$. Then the following properties
hold:

1.  1.
    (Non-negativity) If sample $`i`$ is correct at step $`k`$, i.e.,
    $`\delta_{i}^{(k)}=1`$, then $`\hat{a}_{i}^{(k)}\geq 0`$.
2.  2.
    (Monotonicity) If $`t\geq 2`$ and samples $`i,j`$ are correct at
    step $`k,l(k<l)`$, i.e., $`\delta_{i}^{(k)}=\delta_{j}^{(l)}=1`$,
    then $`\hat{a}_{i}^{(k)}>\hat{a}_{j}^{(l)}`$.
3.  3.
    (Saturation decay) Let
    $`p_{k}=\frac{1}{|\mathcal{A}_{k}|}\sum_{i\in\mathcal{A}_{k}}\delta_{i}^{(k)}`$
    be the correction rate among active samples. Then if
    $`p_{t}\rightarrow 1`$, we have $`\hat{a}_{i}^{(t)}\rightarrow 0`$.

The first property shows that SocraticPO does not punish corrected
reasoning. Once a sample is answered correctly, the corresponding
student tokens receive a non-negative normalized advantage, even if the
answer is obtained after teacher guidance. Thus, reward decay does not
discard assisted successes; it keeps them as valid positive learning
signals.

The second property formalizes the batch-level credit assignment
discussed above. Among samples that eventually become correct within the
same batch, SocraticPO gives a larger normalized advantage to those
corrected at earlier steps. This prevents an independently solved
problem and a problem solved only after multiple rounds of guidance from
receiving indistinguishable credit. In this sense, reward decay
calibrates positive reward across samples by favoring trajectories that
become correct with fewer guidance rounds.

The third property explains how reward decay mitigates assisted reward
hacking. If teacher guidance makes almost all active samples correct,
then $`p_{k}\rightarrow 1`$ and the advantage approaches zero. Once a
guidance round becomes non-discriminative because nearly everyone can
solve the task with that amount of help, trajectories from that round no
longer provide strong positive reinforcement. This means that reward
decay can prevent the student policy from gaining excessive advantage
merely by relying on teacher intervention.

## 5 Experiments

We evaluate SocraticPO on scientific reasoning tasks. The experiments
are designed to answer two main questions: (1) whether SocraticPO
improves over standard RL and student–teacher baselines; and (2) whether
its two key components, teacher guidance and reward decay, are both
necessary for effective learning. We further include diagnostic analyses
on teacher-side information and teacher–student similarity to better
understand when the interaction mechanism helps.

### 5.1 Experimental Setup

#### Models.

We use Qwen3-4B-Instruct as the student policy $`\pi_{\theta}`$. For
teacher guidance, we consider two settings: Qwen3-4B-Instruct as a
self-guidance teacher and Qwen3.5-27B as a stronger teacher. This allows
us to separate the effect of the interaction mechanism from the effect
of teacher capacity.

#### Datasets and metric.

Following the SDPO evaluation setup, we use four undergraduate-level
scientific reasoning benchmarks from the reasoning subsets of
SciKnowEval \[[10](#bib.bib18)\]: Chemistry, Physics, Biology, and
Material. We report accuracy on each domain and the unweighted average
across domains.

#### Baselines.

We compare against Reinforce++ \[[15](#bib.bib19)\], GRPO

### 5.2 Main Results

Table
[1](#S5.T1 "Table 1 ‣ Datasets and metric. ‣ 5.1 Experimental Setup ‣ 5 Experiments ‣ SocraticPO: Policy Optimization via Interactive Guidance")
reports the main results. With Qwen3.5-27B as the teacher, SocraticPO
achieves the best average accuracy, improving from 0.7388 with
Reinforce++ to 0.7624. It also obtains the best score on Physics,
Biology, and Material, suggesting that Socratic guidance is especially
useful when errors can be localized and corrected through intermediate
reasoning feedback. Chemistry is the main exception, where SDPO achieves
the highest single-domain score. Under self-guidance, SocraticPO remains
competitive and reaches an average accuracy of 0.7498, which is still
higher than Reinforce++ and GRPO. This indicates that the interaction
mechanism itself contributes to learning, while a stronger teacher
further amplifies the benefit.

In Figure
[3](#S5.F3 "Figure 3 ‣ Datasets and metric. ‣ 5.1 Experimental Setup ‣ 5 Experiments ‣ SocraticPO: Policy Optimization via Interactive Guidance"),
we observe a two-stage pattern in the training dynamics. In the early
stage, the student rapidly improves its ability to answer correctly
after receiving teacher guidance, as reflected by the guided-performance
curve. This is consistent with the role of interaction-conditioned
rollouts: the model sees its own failed attempts followed by targeted
corrective feedback, and first learns how to use guidance to repair its
reasoning. In the later stage, reward decay gradually reduces the
advantage of answers that are correct only after guidance, while
unassisted correct answers receive relatively stronger credit. As a
result, the learning pressure shifts from “being correct with help” to
“being correct earlier and without help.” Combined with the correction
ability learned in the early stage, this shift eventually improves the
student’s unassisted performance as well. This pattern supports our
design intuition: teacher guidance creates learnable repairs, and reward
decay encourages the student to internalize those repairs into
independent reasoning.

We evaluate three variants of SocraticPO. SocraticPO (w/o tg) removes
adaptive teacher guidance and replaces it with a fixed retry prompt.
SocraticPO (w/o rd) keeps teacher guidance but removes reward decay,
assigning full reward to any correct answer regardless of the
interaction step. SocraticPO (0.8 rd) replaces our step-dependent reward
decay with a fixed exponential decay factor of 0.8.

Table
[2](#S5.T2 "Table 2 ‣ 5.3 Ablation Study ‣ 5 Experiments ‣ SocraticPO: Policy Optimization via Interactive Guidance")
separates the component analysis from the main comparison. Removing
teacher guidance and using a fixed retry prompt underperforms full
SocraticPO, especially on Biology and Material. This shows that the
improvement is not explained by repeated attempts alone: the teacher
must provide feedback conditioned on the student’s actual mistake so
that the next rollout context contains useful correction.

Reward decay is even more critical. As visualized in Figure
[4](#S5.F4 "Figure 4 ‣ 5.3 Ablation Study ‣ 5 Experiments ‣ SocraticPO: Policy Optimization via Interactive Guidance"),
removing reward decay can make the guided ability improve faster in the
early stage, as shown by the orange curve. This is expected: once
corrected answers after guidance receive the same reward as independent
correct answers, the model is strongly incentivized to exploit
teacher-assisted contexts. However, this early improvement does not
translate effectively into unassisted ability in the later stage. The
resulting performance drop is substantial, especially with the stronger
teacher, where the average decreases from 0.7624 to 0.7057. Using a
fixed decay factor of 0.8 partially recovers the performance to 0.7406
and 0.7259 under the two teachers, but still underperforms the full
reward-decay scheme. This supports the assisted reward-hacking concern:
teacher guidance can quickly improve assisted correctness, but reward
decay is needed to turn those guided repairs into independent reasoning
ability.

### 5.4 Additional Analysis

#### Teacher access to ground truth.

We study whether the teacher should receive ground-truth answers.
Although such access seems useful for generating precise feedback,
Figure
[5](#S5.F5 "Figure 5 ‣ Teacher access to ground truth. ‣ 5.4 Additional Analysis ‣ 5 Experiments ‣ SocraticPO: Policy Optimization via Interactive Guidance")
shows that it can degrade student performance in most cases. We
attribute this to two factors. First, even when the prompt explicitly
asks the teacher not to reveal the answer, a teacher with ground-truth
access may still leak solution-specific hints. This failure mode is
inherently limited by the teacher model’s instruction-following ability.
Second, ground-truth access can shift the teacher from diagnosing the
student’s reasoning process to reverse-engineering hints from the known
answer. Both effects may encourage shortcut learning rather than robust
correction.

At the same time, ground-truth information is not intrinsically harmful.
If the teacher can avoid answer leakage and use the reference solution
to diagnose the student’s error, then access to the answer or even a
standard reasoning process can substantially improve the quality of
guidance, as suggested by the Qwen3-8B-Instruct self-guidance result on
Chemistry. The effect of ground-truth access is therefore conditional:
it can strengthen Socratic guidance when the teacher follows the
teaching protocol well, but it can become negative when the teacher
turns the answer into overly direct hints.

#### Teacher–student similarity.

To examine whether SocraticPO works by implicitly making the student
imitate the teacher, we measure the KL divergence between the student
and teacher during training. We use Qwen3-8B as the teacher and
Qwen3-4B-Instruct as the student on the Material benchmark. This pair is
chosen because KL computation requires aligned tokenization, and the two
models share a compatible tokenizer.

If SocraticPO were primarily a distillation mechanism, we would expect
teacher–student divergence to decrease as training proceeds. Figure
[6](#S5.F6 "Figure 6 ‣ Teacher access to ground truth. ‣ 5.4 Additional Analysis ‣ 5 Experiments ‣ SocraticPO: Policy Optimization via Interactive Guidance")
shows that SocraticPO does not consistently reduce the KL divergence
between teacher and student, even though it improves downstream task
performance. This supports the distinction made in our method: the
teacher participates in rollout as an interactive guide, but the student
is not optimized to reproduce the teacher’s token distribution or
reasoning trace. In other words, SocraticPO improves the student through
guided correction rather than by making the student become more
teacher-like.

Together, these analyses suggest that effective teaching protocols
require more than a stronger teacher. The information exposed to the
teacher, the form of feedback, and the training objective jointly
determine whether interaction improves policy learning.

## 6 Conclusion

We presented SocraticPO, a policy-optimization framework that addresses
a limitation of scalar reward feedback in LLM reinforcement learning.
Outcome rewards indicate whether a response should be reinforced, but
they do not explain how a mistaken reasoning process should be repaired.
SocraticPO augments rollout sampling with natural-language teacher
guidance: the student first attempts a solution, receives targeted
correction only after an incorrect response, and continues under the
expanded dialogue context.

Teacher guidance must be controlled carefully. If assisted correct
answers are rewarded as strongly as independent correct answers, the
student may exploit teacher intervention instead of improving its own
reasoning. SocraticPO therefore pairs guidance with reward decay,
assigning smaller rewards to answers that become correct only after more
interaction rounds. Experiments on SciKnowEval scientific reasoning
benchmarks show that SocraticPO improves average performance over strong
RL and self-distillation baselines, while ablations highlight the
importance of both targeted guidance and reward decay.

Our findings suggest that natural-language correction can serve as
process-level supervision inside RL without requiring teacher
distribution matching. Because the teacher is used only as a
text-producing guide, SocraticPO can leverage black-box mentors and
remains modular with respect to the underlying RL optimizer. Future work
can further study teaching protocols, teacher-side information, and
broader tasks where reasoning errors are diagnosable before the final
answer.

## Appendix A Proof of Theorem 1

###### Proof.

We prove the three properties in Theorem
[1](#Thmtheorem1 "Theorem 1 (Assistance-Aware Advantage under Reward Decay). ‣ 4.3 Reward Decay ‣ 4 Method ‣ SocraticPO: Policy Optimization via Interactive Guidance").
Let $`m_{k}=|\mathcal{A}_{k}|`$ and

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p_{k}=\frac{1}{m_{k}}\sum_{i\in\mathcal{A}_{k}}\delta_{i}^{(k)}.
``` |  | (21) |

Let $`N_{k-1}=\sum_{j=1}^{k-1}|\mathcal{A}_{j}|`$. The batch mean after
including the step-$`k`$ active samples is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mu_{k}=\frac{N_{k-1}\mu_{k-1}+\sum_{i\in\mathcal{A}_{k}}r_{i}^{(k)}}{N_{k-1}+m_{k}}.
``` |  | (22) |

By the reward definition,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\sum_{i\in\mathcal{A}_{k}}r_{i}^{(k)}=\mu_{k-1}\sum_{i\in\mathcal{A}_{k}}\delta_{i}^{(k)}=\mu_{k-1}m_{k}p_{k}.
``` |  | (23) |

Thus,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mu_{k}=\frac{N_{k-1}\mu_{k-1}+m_{k}p_{k}\mu_{k-1}}{N_{k-1}+m_{k}}=\mu_{k-1}\frac{N_{k-1}+m_{k}p_{k}}{N_{k-1}+m_{k}}.
``` |  | (24) |

For any correct sample $`i`$ at step $`k`$, we have
$`\delta_{i}^{(k)}=1`$ and therefore $`r_{i}^{(k)}=\mu_{k-1}`$. Its
centered advantage is

|  |  |  |  |
|----|----|----|----|
|  |
``` math
a_{i}^{(k)}=r_{i}^{(k)}-\mu_{t}=\mu_{k-1}-\mu_{t}=\mu_{k-1}\left(1-\frac{N_{k-1}+\sum_{h=k}^{t}m_{k}p_{k}}{N_{k-1}+\sum_{h=k}^{t}m_{k}}\right)\geq 0.
``` |  | (25) |

The normalized advantage has the same sign because
$`\sigma_{t}+\epsilon>0`$, so $`\hat{a}_{i}^{(k)}\geq 0`$. This proves
the first property.

For the second property, consider two correct samples at steps $`k`$ and
$`l`$ with $`k<l`$.

|  |  |  |  |
|----|----|----|----|
|  |
``` math
a_{i}^{(k)}-a_{j}^{(l)}=r_{i}^{(k)}-\mu_{t}-(r_{j}^{(l)}-\mu_{t})=\mu_{k-1}-\mu_{l-1}=\mu_{k-1}\left(1-\frac{N_{k-1}+\sum_{h=k}^{l-1}m_{h}p_{h}}{N_{k-1}+\sum_{h=k}^{l-1}m_{h}}\right).
``` |  | (26) |

Consider that $`l>k`$, according to the definition of rollout, it is
inevitable that $`p_{k}<1`$, then $`a_{i}^{(k)}-a_{j}^{(l)}>0`$, which
lead to $`\hat{a}_{i}^{(k)}\geq\hat{a}_{j}^{(l)}`$.

For the third property, the expression above shows that the centered
advantage for a correct sample at step $`t`$ is proportional to
$`1-p_{t}`$:

|     |                                                           |     |      |
|-----|-----------------------------------------------------------|-----|------|
|     |
       ``` math
       a_{i}^{(t)}=\frac{\mu_{t-1}m_{t}}{N_{t-1}+m_{t}}(1-p_{t})
       ```                                                        |     | (27) |

Therefore, when $`p_{k}\rightarrow 1`$, i.e., almost all active samples
are corrected at that step, we have $`a_{i}^{(k)}\rightarrow 0`$. Since
$`\sigma_{t}+\epsilon>\epsilon>0`$, the normalized advantage also
satisfies $`\hat{a}_{i}^{(t)}\rightarrow 0`$. ∎
````
